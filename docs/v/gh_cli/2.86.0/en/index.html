GitHub CLI 2.86.0

Released: 2026-01-21

Release notes

FEATURE

Install and launch Copilot CLI directly through gh

You can now get to Copilot CLI from the same terminal workflow you use for GitHub.

Run gh copilot and gh will offer to install Copilot CLI if it is missing, then launch it. Add arguments or flags after the command and gh passes them through to Copilot CLI unchanged. Copilot has not gained a new capability here; the update simply joins installation and launch into one route instead of making you find a separate installer and switch commands, like buying a ticket and boarding at the same station counter.

FEATURE

Clear every cache for a ref and catch duplicate PR targets early

You can now clear all cached results attached to one ref—a Git name that points to a branch or version—with a single gh cache delete action instead of removing them one by one.

gh pr create also now errors when its head and base refs are identical, because there is nothing to merge between the same starting point and destination. The contributor guide was clarified, and the release records two first-time contributors. It is like emptying every old box in one warehouse aisle while a guard stops a form addressed from you to you before it reaches the desk.
