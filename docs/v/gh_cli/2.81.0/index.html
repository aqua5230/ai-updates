zh-TW

gh 新增 release verify 指令，確認發行版沒被人動過手腳

你打包版本發布給同事下載，或反過來下載別人放上去的檔案，想確認沒被偷換——這正是 gh 新增的 release verify 與 release verify-asset 要處理的事。每個發行版能附上一份 attestation（證明文件，帶簽章與時間戳，把版本、git 標籤與檔案綁在一起）。就像精品出廠附的保證書印著編號跟日期，對得起來才確定是真品，沒被掉包。驗證最新的發行版，打 gh release verify；驗證特定版本，加上標籤打 gh release verify v1.2.3。手上某個附件檔案，想對到最新發行版，打 gh release verify-asset my-asset.zip；要對到特定版本，標籤也加進去，打 gh release verify-asset v1.2.3 my-asset.zip。

en

gh adds a release verify command so you can confirm a release hasn't been tampered with

You've packaged a release for coworkers to download, or you're the one downloading something someone else uploaded, and you want to be sure it wasn't swapped for something else — that's what gh's new release verify and release verify-asset handle. Every release can carry an attestation, a signed, timestamped document that ties the release to its version, its git tag, and its files. It's like a luxury item's warranty card printed with a serial number and a date — if they match, you know it's the real thing and nothing's been switched. To verify the latest release, run gh release verify; to verify a specific one, add the tag: gh release verify v1.2.3. Got an asset file you want to match against the latest release? Run gh release verify-asset my-asset.zip; to match it against a specific release, add the tag too: gh release verify-asset v1.2.3 my-asset.zip.

ja

gh に release verify コマンドが追加され、リリースが改ざんされていないか確認できるようになった

同僚にダウンロードしてもらうためリリースをまとめた、あるいは逆に誰かが上げたファイルを落とす立場で、すり替えられていないか確かめたい——それに応えるのが gh に追加された release verify と release verify-asset だ。各リリースには attestation（証明書、署名とタイムスタンプ付きで、バージョンと git タグとファイルを結び付ける文書）を添付できる。高級品の箱に入っている保証書にシリアル番号と日付が印字されていて、それが一致して初めて本物だと分かる、すり替えられていないと分かるのと同じだ。最新リリースを確認するには gh release verify を打つ。特定のバージョンを確認するにはタグを付けて gh release verify v1.2.3 を打つ。手元のアセットファイルを最新リリースと照合したいなら gh release verify-asset my-asset.zip を打ち、特定のバージョンと照合するならタグも加えて gh release verify-asset v1.2.3 my-asset.zip を打つ。

ko

gh, 릴리스가 조작되지 않았는지 확인하는 release verify 명령을 추가했다

동료가 내려받을 릴리스를 만들어 올렸거나 반대로 남이 올린 파일을 받는 입장에서, 바꿔치기되지 않았는지 확인하고 싶을 때 gh에 새로 추가된 release verify와 release verify-asset이 그 일을 해결해 준다. 릴리스마다 attestation(증명서, 서명과 타임스탬프가 붙어 버전과 git 태그와 파일을 하나로 묶어 주는 문서)을 첨부할 수 있다. 명품에 딸려 오는 보증서에 일련번호와 날짜가 찍혀 있어서 그게 맞아떨어져야 진품이고 바꿔치기되지 않았다고 확신하는 것과 같다. 최신 릴리스를 확인하려면 gh release verify를 입력한다. 특정 버전을 확인하려면 태그를 붙여 gh release verify v1.2.3을 입력한다. 가지고 있는 자산 파일을 최신 릴리스와 맞춰 보고 싶다면 gh release verify-asset my-asset.zip을 입력하고, 특정 버전과 맞추려면 태그도 함께 넣어 gh release verify-asset v1.2.3 my-asset.zip을 입력한다.
