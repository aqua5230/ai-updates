GitHub CLI 2.92.0

發布日期：2026-04-28

zh-TW

擴充技能安裝與預覽更簡明，全面支援企業雲端資料存儲

現在你在預覽自訂擴充技能時，可以直接帶上參數來允許讀取隱藏的資料夾；如果你的公司使用限制資料只能存在特定地區的企業雲（GHEC，GitHub 企業雲端版），系統也能正常連線支援。同時，安裝這些技能時，系統會直接用技能本身的名稱存檔，不再加上複雜的前綴命名空間，讓路徑更簡潔。就像你的手機安裝小工具，以前必須按照開發者名字分類塞在好幾層資料夾裡，現在安裝直接放在案頭，而且在資料必須存於特定地區時也能正常使用。

過濾日誌控制碼防禦終端機注入攻擊，新增擴充功能安全警告

現在當你在查看執行紀錄時，系統會先過濾掉可能隱藏的惡意控制碼，防止有心人士透過終端機注入攻擊（terminal injection）來控制你的畫面。同時，當你查閱擴充功能說明時，畫面會貼心顯示安全免責聲明，提醒你只安裝信任的工具。此外，自動部署設定檔（deployment.yml）中關於變數替換的寫法也修正了，避免自動化流程出錯。就像你在路邊看佈告欄，以前可能有人在海報下偷黏按鈕騙你按，現在不僅海報被防護玻璃罩住，佈告欄旁邊還立了警告標語提醒你小心詐騙。

忽略專案看板無權限錯誤，修復 Linux 自動補完與統計回報

現在在 Debian 系統上使用 zsh（一種終端機 shell 軟體）時，自動補完功能可以正常運作了。同時，如果你在存取專案看板時遇到「資源無法存取」的錯誤，系統會自動忽略，不會再像以前那樣直接中斷崩潰。底層也升級了 Go 語言與多個終端介面套件，修復了統計回報率沒有正確更新的問題。就像你去圖書館借書，以前遇到沒權限的書櫃機器人會直接死機，而且查詢系統還經常打錯字、自動推薦按不出來；現在它會自動跳過不合適的書，找書的過程也更順暢。

en

Extensions install flat by name and support GHEC with data residency

You can now preview and install custom extensions with more flexibility, and easily comply with corporate data residency policies. When previewing skills, you can pass a flag to allow access to hidden directories, and the system now fully supports GitHub Enterprise Cloud (GHEC) with data residency hosts. Additionally, skills are now installed flatly by their name rather than namespaces, making file paths much cleaner. It's like installing widgets on your phone: instead of nesting them deep inside folders named after developers, they now sit directly on your home screen, and it supports corporate data-residency requirements.

Clean logs to prevent terminal injection and add security warnings to extensions

You can now review logs and install third-party extensions with much better protection against malicious exploits. The CLI now filters unsafe escape codes when outputting logs to prevent terminal injection from manipulating your screen. Additionally, help pages for extensions now display a clear trust disclaimer, reminding you to only run extensions you trust. A syntax fix was also applied to variable interpolation in deployment workflows (deployment.yml) to keep automated processes stable. It's like looking at a public bulletin board: previously someone could hide sticky buttons under posters to trick you, but now the posters are behind safety glass and there's a warning sign reminding you to watch out for scams.

Ignore project access errors and fix Linux autocompletion and telemetry metrics

You can now enjoy a smoother autocompletion experience and more stable CLI runs across different Linux environments. When running tab completions with zsh on Debian, autocomplete options now resolve correctly. In project management, accessing boards and hitting a "Resource not accessible" error will be gracefully ignored instead of crashing your session. Telemetry metrics also received a fix, ensuring the sample rate updates correctly. It's like visiting a library: previously, if you walked past a locked door, the guide robot would freeze completely, the lookup catalog had typos, and search suggestions didn't work. Now, it silently bypasses restricted sections, and looking up books is completely frictionless.
