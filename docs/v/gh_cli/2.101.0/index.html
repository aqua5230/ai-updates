GitHub CLI 2.101.0

發布日期：2026-09-15

繁體中文

Linux 套件庫全面換用新金鑰，舊安裝需更新金鑰圈

你在 Linux 上更新或安裝 gh 若遇到驗證錯誤，可能是本機尚未登記新印鑑。

這好比社區大樓換了新門禁印章，住戶若沒登記新印記，警衛核對舊印鑑就會拒絕放行。

GitHub CLI 的 APT 與 RPM 套件庫（Linux 下載與管理軟體的官方倉庫）與個別 RPM 包。它們現在僅以新的 PGP 金鑰（fingerprint: 7F38BBB59D064DBCB3D84D725612B36462313325）簽署。若你在 2026 年 4 月 8 日前透過官方 APT 或 RPM 套件庫安裝 gh 且尚未更新金鑰圈（存放信任憑證的鑰匙庫），安裝或升級可能失敗。請依照官方的 PGP 簽章金鑰輪換指引更新金鑰圈以排除問題。Windows 與 macOS 使用者，或透過 Homebrew、GitHub Releases、其他套件管理器及原始碼安裝者，則不受影響。

登入驗證碼預設自動複製，省下繁瑣手動步驟

登入 GitHub 帳號或刷新授權時，終端機現在會自動幫你保管驗證碼，省下一道手動複製手續。過去執行 gh auth login 登入或 gh auth refresh 刷新權限時，畫面會給出一組要在瀏覽器填寫的 OAuth 裝置代碼（在授權網頁輸入以確認本機身分的驗證碼）。以往得手動反白並複製，現在執行這兩項指令時，預設會主動將代碼複製進剪貼簿，切換視窗直接貼上即可。

這好比到櫃檯辦業務時，人員直接把號碼牌遞到你手裡，不必自己拿筆在旁邊抄號碼。

若想永久關閉此功能，可執行設定指令：

gh config set clipboard disabled

單次呼叫時若有明確指定剪貼簿選項，依然享有最高優先權。

English

Linux Package Repositories Switch to New Signing Key, Existing Installs Require Keyring Update

If you encounter verification errors when updating or installing gh on Linux, your system may not have registered the new stamp yet.

This is like a residential community switching to a new access control stamp; if residents haven't registered the new mark, security checking the old stamp will deny entry.

GitHub CLI's APT and RPM package repositories and individual RPM packages are now signed only with the new PGP key (fingerprint: 7F38BBB59D064DBCB3D84D725612B36462313325). If you installed gh through the official APT or RPM repositories before April 8, 2026, and have not yet updated your keyring, package installation or upgrades may fail. Follow the official PGP signing key rotation guidance to update your keyring and resolve the issue. Users on Windows and macOS, or those who installed via Homebrew, GitHub Releases, other package managers, or from source, are not affected.

Authentication Codes Copied to Clipboard by Default, Saving Manual Steps

When signing in to your GitHub account or refreshing authorization, the terminal now automatically handles the verification code for you, saving a manual copy step. Previously, running gh auth login to sign in or gh auth refresh to refresh permissions displayed an OAuth device code to be entered in the browser. While you previously had to manually highlight and copy it, running these two commands now copies the code to the clipboard by default, allowing you to switch windows and paste directly.

This is like visiting a service counter where the staff hands the queue slip directly to you, so you don't have to write the number down yourself with a pen.

To permanently disable this feature, run the configuration command:

gh config set clipboard disabled

Explicit clipboard options specified for an individual invocation still take highest precedence.

## Linux package repository signing key rotation

GitHub CLI's APT and RPM repositories, along with individual RPM packages, are now signed only with the new PGP key (fingerprint: `7F38BBB59D064DBCB3D84D725612B36462313325`)

Follow the [PGP signing key rotation guidance](https://github.com/cli/cli/issues/13118) to check and update your keyring. Users on Windows or macOS, and users who installed `gh` through Homebrew, GitHub Releases, another package manager, or from source, are not affected.
