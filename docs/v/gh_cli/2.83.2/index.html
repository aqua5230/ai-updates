GitHub CLI 2.83.2

發布日期：2025-12-10

繁體中文

新功能

搜尋字詞不再和背景條件混在一起

你輸入的搜尋字詞現在會和工具另外加上的背景條件分開處理，不必擔心兩者被混成一句而改變原本想找的內容。

這項調整針對使用者自己提供的 search query（搜尋條件，告訴工具要找什麼的文字）與 contextual qualifiers（背景限定條件）之間的界線；公告沒有改動其他搜尋功能。就像你交代圖書館員「找食譜」，再補一句「限館內藏書」：兩張便條各自清楚，才不會把限制誤當成書名的一部分。

新功能

安裝資訊與授權檢查更明確

想找安裝來源或協助打包的人，現在能看到 Debian 與 Ubuntu 被列入非官方套件來源；這是資訊補充，不代表官方提供了新的套件。

開發或發行時，若 go-licenses（檢查程式相依套件授權的工具）不在 PATH（終端機用來尋找可執行工具的路徑清單）裡，流程會直接報錯，而不是悄悄帶過。公告也加入 PGP key rotation 的概念驗證，用來測試更新簽章金鑰的輪替。就像工具箱少了必需扳手會立刻亮紅燈，門口也多貼了一張可參考的店家清單。

新功能

內部程式與相依套件完成例行整理

日常使用不需要改指令，但這版整理了 GitHub API 用戶端的設定處理、移除了說明用法裡多餘的旗標預設值，並以 Go 標準函式庫取代 multierror。

也更新 Go 1.25.4、1.25.5、dev-tunnels SDK，以及加密、protobuf、gRPC、終端介面等相依套件；這些都是程式底層借來運作的零件。兩位貢獻者也在這批變更中首次參與。公告沒有宣稱這些更新帶來特定新功能，所以最準確的理解是維護與相容性整理。就像保養車子時換好零件、整理線路，不必改變方向盤，車仍照原本方式開。

English

FEATURE

Search terms no longer get mixed with background qualifiers

Your search words are now kept separate from the contextual qualifiers the tool adds around them, so those two pieces are less likely to be treated as one muddled request.

This change specifically isolates a user-provided search query from its background qualifiers; the release notes do not claim any other search behavior changed. It is like giving a librarian one note saying “cookbooks” and another saying “in this branch only,” instead of accidentally making the restriction part of the title.

FEATURE

Installation information and license checks are clearer

People looking for installation sources can now see Debian and Ubuntu listed among unofficial packages; that is an information update, not a claim that new official packages were released.

For development or releases, the process now errors when go-licenses, a license-checking tool, is absent from PATH, the list of places a terminal searches for runnable tools. The notes also add a proof of concept for PGP key rotation, testing how signing keys can be changed. Like a toolbox that immediately flags a missing wrench, while the door gains a useful directory of nearby shops.

FEATURE

Internal code and dependencies received routine maintenance

You do not need to change your everyday commands, but this release tidied configuration handling in a GitHub API client, removed an extra flag default from help usage, and replaced multierror with Go’s standard library.

It also updated Go 1.25.4 and 1.25.5, the dev-tunnels SDK, and dependencies for cryptography, protobuf, gRPC, and terminal interfaces—the components the program relies on underneath. Two contributors made their first contributions in this batch. The notes do not promise a specific new feature from these changes, so routine maintenance and compatibility work is the accurate reading. Like servicing a car’s parts and wiring without changing the steering wheel.
