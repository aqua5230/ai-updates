免登入下載公開專案的發布檔

你是不是常在沒有登入帳號的乾淨電腦上，只想快速下載某個公開專案的安裝檔，卻被登入提示卡住？以往即使你想抓取的軟體是放在完全公開的專案中，執行命令時，系統還是會硬性要求進行 authentication（驗證程序，確認使用者身分的程序）才能下載。現在這個不方便的門檻被移除了，只要是公開專案，任何人都可以免登入直接把發布檔抓下來。這就像走進免費開放的市立圖書館拿一份導覽手冊，以前警衛還會擋在門口硬要你掏出借書證來登記，現在只要是公開擺在架上的東西，你推開門就能直接拿走。當你在新主機上需要快速抓取公開安裝檔時，這正是你輸入 gh release download 的時刻，保證一路暢通。

廣納更多 AI 代理工具，技能安裝更聽話

你正在為 AI 代理工具配置新的擴充能力，卻因為指令一直彈出不必要的提問而感到心煩？這次更新擴大了支援，讓 gh skill 指令能自動偵測更多第三方的 coding agents（寫程式碼代理，能協助撰寫程式碼的 AI 助手），並完整支援 antigravity-cli 與 antigravity2.0。此外，通用技能的預設安裝路徑也更正為 ~/.agents/skills；更棒的是，如果你已經指定了安裝目錄參數，系統就不會再彈出冗餘的 prompt（互動提示，指程式在終端機中要求使用者輸入或選擇的畫面），會直接遵守你的選擇。這就像買了一支萬用遙控器，它學會了最新電視的頻率，而且當你指著電視按開關時，它不會再跳出選單囉唆地問你要遙控哪台設備。當你想自訂路徑且不想被打擾，這正是你使用 gh skill 指令的時刻。

修正 Codespace 轉發當機與 CI 狀態空白

你是否遇過雲端開發環境突然崩潰，或是自動化檢查被取消後，狀態欄只顯示一片空白？這次修復專門為這些不穩定的角落提供保護。首先，處理 codespace port forwarding（連接埠轉發，將雲端開發機器的網路連接埠導引至本機的傳輸技術）時，背後因 concurrent map writes（併發寫入衝突，指多個處理程序同時修改同一份內部資料造成的當機錯誤）導致連線崩潰的問題已解決。此外，當 CI checks（自動化檢查）被全部取消時，摘要畫面的空白已被老實顯示的取消通知取代。這就像餐廳裡兩個服務生同時往同個格子上寫點單，紙張撕破導致系統當機的問題被修好了；而且如果整桌退單，看板也會清楚寫明「已取消」而非留下一塊讓人瞎猜的空白黑板。

資料庫識別碼升級與工作流安全性補強

當專案資料庫的識別碼數量日益膨脹，或是自動化工作流面臨被惡意修改的安全風險？為了解決底層的潛在危機，系統在多處細節做出了補強。首先，將 database IDs（資料庫識別碼，用來標示每筆資料唯一身分的數字代號）的資料型態升級為更大的 64 位元整數，防止隨著 GitHub 資料量成長而溢位。同時，將可重複使用的 triage workflows（工作流，特定事件觸發時自動執行的指令腳本）固定在特定的 commit SHA，防止工作流遭到篡改，並在說明中澄清了複製指令的行為。這就像將倉庫的舊鎖頭升級，把不夠大的抽屜換成超大保險櫃，並對自動門鎖裝上硬體鎖定，不管資料如何成長或外部如何變化，系統都能牢牢守護一切，不再因老舊漏洞而動搖。

說明文件優化與依賴套件版本升級

你正在為專案尋找更多搜尋範例以提升開發效率，或者想讓部署流程跑得更穩定無誤？為了讓開發者使用更順暢，本次更新在搜尋文件補上了多個 qualifiers（限定符，用來過濾或精準匹配搜尋結果的修飾關鍵字）的實用範例，並修復了發布流程文件裡失效的 anchor link（錨點連結，指向網頁內特定段落的書籤連結）。同時，開發團隊也為多個內部依賴套件進行了版本升級。這就像重新繪製了大樓裡印錯的樓層指引招牌，並順手更換了多個老舊零件。這些微小的保養工作雖然不顯眼，卻能保證每位訪客都不會在大樓中迷路，也讓整座系統運作得更穩定安全。

English

Download public releases without authentication

Have you ever tried to quickly fetch a release installer from a public repository on a clean system, only to be blocked by login prompts? Previously, even when a tool was hosted in a completely public project, trying to grab it would trigger a mandatory authentication (verification process confirming your identity) flow. We have now removed this hurdle, allowing anonymous access to all public releases. It is like walking into a public library to grab a brochure: the guard used to stubbornly demand your library card just to take a free leaflet, but now you can just walk in and take it. When you need to fetch a public installer on a new machine, that is when to run gh release download and download it without any hassle.

More AI agents supported and smarter skill installation

Are you setting up custom capabilities for your AI helper, only to be annoyed by redundant terminal questions? This update expands the reach of the gh skill command to detect more third-party coding agents (AI assistants that help you write code) and officially support antigravity-cli and antigravity2.0. Under the hood, universal skills are now correctly routed to ~/.agents/skills. Best of all, if you specify the installation path directly, the system will honor it without prompting (asking questions via terminal menu dialogs). It is like using a universal remote that supports the latest TVs; when you point it at the screen and press power, it no longer pops up a menu asking which device you wish to control. When you want a silent, customized install, that is when to run gh skill.

Fixes for Codespace port forwarding crashes and blank CI summaries

Have you ever had your cloud development environment crash, or been left guessing when cancelled automation runs showed nothing at all? We have hardened these fragile areas. We resolved a crash where codespace port forwarding (connecting network ports of a remote container to your local machine) failed due to concurrent map writes (a data collision error when multiple processes modify the same memory table simultaneously). Additionally, if CI checks (automated checks) are cancelled, the summary screen now reports the status instead of displaying a blank void. It's like a restaurant fixing a glitch where two waiters writing on the same order ticket caused a system crash, and ensuring that if a table cancels, the kitchen screen displays "Cancelled" instead of an empty black board.

Database ID upgrades and workflow security reinforcement

Are you worried about database identifiers overflowing as records grow, or automated pipelines facing security threats from malicious changes? To address these underlying risks, we have reinforced several security and architectural details. The database IDs are now upgraded to 64-bit integers to prevent truncation on large data sets. Additionally, we pinned reusable triage workflows to a specific commit SHA to lock down their versions against unexpected alterations, and clarified command behavior in help files. It is like replacing shallow storage drawers with a giant vault and adding a physical lock to automated doors; the system stands secure and robust, unaffected by data growth or external tampering.

Documentation polish and dependency version updates

Are you searching the documents for better query examples, or looking to keep your pipeline builds stable? To keep instructions clear, we added practical examples using multiple qualifiers and fixed a broken anchor link in the release guide. Additionally, several build and environment dependencies were updated. It is like fixing spelling mistakes on floor guide maps and swapping out standard elevator parts. Although these maintenance steps are small, they prevent visitors from getting lost and keep the whole building operating safely.
