zh-TW

gh 新增 agent-task 指令組，在終端機裡派工給程式碼代理

剩一段程式碼想整理，你正忙著別的事，於是把它交給 GitHub 的 coding agent（程式碼代理，替你動手改程式的自動助手）——gh 新增的 agent-task 指令組，就是在終端機裡派工與追蹤的工具。

gh agent-task create "refactor the codebase"   # 派一件工作出去
gh agent-task list                             # 列出你所有任務
gh agent-task view 1234                        # 看某一件的細節
gh agent-task view 1234 --log --follow         # 邊跑邊看

最後那個寫法會即時印出執行紀錄（log，程式跑的時候一行一行留下的文字）。同一組指令另外給了三個順手的別名，gh agent-tasks、gh agent、gh agents 打起來都通。一個人有本名，也有幾個熟人喊的小名，喊哪一個，到場的都是同一位。這組指令還在預覽階段，用法可能說改就改，不會事先通知。

en

gh adds an agent-task command group to hand code work to the coding agent from your terminal

You've got a chunk of code that needs cleaning up but you're busy with something else, so you hand it to GitHub's coding agent — an automated assistant that edits code for you. gh's new agent-task command group is how you dispatch and track that work right from the terminal.

gh agent-task create "refactor the codebase"   # send off a task
gh agent-task list                             # list all your tasks
gh agent-task view 1234                        # see details on one
gh agent-task view 1234 --log --follow         # watch it run live

That last form streams the log in real time as the task runs. The same command group ships with three handy aliases — gh agent-tasks, gh agent, and gh agents all work the same way. You go by your given name, but the people who know you well call you by a nickname too — whichever one gets used, it's still you who shows up. The command group is still in preview, so its behavior can change without notice.
