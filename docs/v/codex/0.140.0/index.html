繁體中文

查詢用量、無縫搬家，指令工具大擴充

想要管好自己的帳號與專案變得超容易。現在輸入 /usage 就能看你每天、每週或累積用了多少代幣（token）；想清掉不需要的紀錄時，只要用 codex delete 或 /delete 就能永久刪除對話，系統還會貼心地幫你把底下的代理人（subagent）清乾淨並加上防呆確認。如果你是從 Claude Code 跳槽過來的，現在也能透過 /import 輕鬆把設定、專案組態跟最近的聊天紀錄無縫搬家過來。就像你有了專屬的管家，隨時能查這個月花了多少錢、幫你把不要的雜物連同地下室一起清掉，連搬家時都能直接把舊公寓的傢俱原封不動搬到新家。

聊天介面更自由，貼上大量文字與圖片不再出包

終端機裡的聊天介面變得更寬容、更方便了。使用 /goal 指令時，就算你貼上超長的文章、龐大的程式碼區塊或是附加圖片，它都能完好保留不會吃字。現在只要打出 @ 符號，就會自動跳出一個整合式的選單，讓你輕鬆指定要參考哪個檔案、外掛（plugin）或技能。此外，如果你之前按過「不再提醒更新」，系統現在會乖乖記住不再煩你，且對話結束後也不會殘留奇怪的執行中指標。對了，實驗性質的 /realtime 語音功能已經功成身退，從介面裡移除了。就像你換了個大容量信箱，以前塞不下的大包裹跟照片現在都能輕鬆投遞；寫信時只要打個代號，通訊錄就會自動幫你填好所有聯絡人，而且它終於記住你貼在門上「謝絕推銷」的貼紙了。

安全儲存憑證，外掛與工具連線更穩固

你的登入身分與外掛連線現在受到更高級的保護。系統新增了 Amazon Bedrock 的 API 金鑰認證，並用加密的方式把你的憑證（credentials，證明你是合法使用者的金鑰）安全地鎖在本地端。在連線外部工具（MCP）時，如果一開始沒連上系統會聰明地重試，如果發現憑證不能用也會直接回報你「已登出」，而且不會再偷偷把你自己停用的伺服器打開。遠端外掛的解除安裝現在也能順利運作，並清楚提示哪些應用程式需要先認證。就像你把家裡鑰匙放進了指紋保險箱，保全系統遇到接觸不良會自己多試兩下，確認門禁卡消磁就會請你重新登記，而且你不想要的警報器絕對不會半夜自己響起來。

防呆與防當機，壞掉的資料庫會自己修好

如果底層紀錄狀態的 SQLite 資料庫不幸毀損（甚至資料夾壞成不明檔案），系統現在會自動備份並從歷史紀錄把它原地復活。當你在自動審查（/review）遇到指引時按下 Esc 退出，畫面不會再直接當機，且你取消審查後指引還會乖乖留著。跑在背景的非互動指令，現在也能讓你用 Ctrl-C 隨時中斷，而且還能完好保留最後的輸出結果；面對超大專案跟落落長的對話，系統也學會了快取跟減少重複讀取，反應速度大躍進。就像你的車子裝了黑盒子跟自動修復烤漆，不管是不小心按錯按鈕還是被石頭砸到，都不會拋錨，甚至還能自己把刮痕補好、讓引擎跑得更順暢。

English

Expanded CLI tools for usage stats, cleanup, and seamless migration

Managing your account and projects is now much easier. You can use /usage to view your daily, weekly, or cumulative token activity; when you want to clean house, running codex delete or /delete permanently wipes a session, complete with confirmation safeguards and automatic subagent cleanup. If you're switching over from Claude Code, the new /import command lets you seamlessly bring over your setups, project configurations, and recent chats. Like having a dedicated butler who can show you exactly how much you've spent this month, safely throws out junk (clearing the basement along with it), and flawlessly moves all your furniture straight from your old apartment to your new one.

Freer chat UI with flawless handling of massive text and images

The terminal chat interface has become much more forgiving and convenient. The /goal command now flawlessly preserves oversized text, massive code blocks, and image attachments without truncating them. When you type @, a unified menu now automatically pops up, letting you easily mention specific files, plugins, or skills. Additionally, if you dismiss an update reminder, the system now reliably remembers your choice and stops bothering you, and stale loading indicators are correctly cleared after a turn ends. Oh, and the experimental /realtime voice control feature has gracefully retired and been removed. Like upgrading to a jumbo mailbox that easily swallows the giant packages and photo albums that used to jam the slot; writing a letter now magically auto-completes your addresses, and the postman finally respects the "No Solicitors" sign on your door.

Secure credential storage with rock-solid tool connections

Your authentication and plugin connections are now under tighter security. We've added managed Amazon Bedrock API-key authentication, and your credentials (keys proving you're a valid user) are now safely locked in encrypted local storage. When connecting to external tools (MCP), the system now smartly retries if it fails to start on the first try, explicitly reports unusable credentials as logged out, and completely respects your choice if you've explicitly disabled a server. Remote plugin uninstallations are now completely fixed, and it clearly flags apps that require authentication during installation. Like locking your house keys in a biometric safe: the security system will now try twice if the sensor is finicky, politely ask you to re-register if your badge is wiped, and absolutely refuses to turn on an alarm module you explicitly disabled.

Auto-repairing databases and crash-proof safety nets

If the underlying SQLite state database gets corrupted (even if the folder morphs into an unrecognizable file), the system now automatically backs it up and rebuilds it perfectly from your rollout history. Pressing Esc to exit a /review while guidance is queued no longer crashes the screen, and cancelling the review leaves that guidance safely intact. You can now interrupt background commands with Ctrl-C on the fly, and the system will still cleanly capture their final output. For massive codebases and marathon chat sessions, it also learned to cache UI rendering and skip duplicate history reads, delivering a massive speed boost. Like a car equipped with a black box and self-healing paint: mashing the wrong buttons or getting hit by flying gravel won't leave you stranded on the highway; it just quietly fixes the scratches and keeps the engine purring smoothly.
