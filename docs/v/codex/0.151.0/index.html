Codex 0.151.0

發布日期：2026-08-29

繁體中文

為非必要 MCP 伺服器的工具搜尋新增可自訂的寬限期

好比會議主持人給線上連線的外部專家預留彈性的報到緩衝，不會因為網路稍慢就直接跳過對方的名額。

在連接選用或非必要的 MCP（Model Context Protocol，讓 AI 連接外部工具的協定）伺服器時，若外部工具啟動稍慢，搜尋流程不再立刻判定逾時。系統為非必要 MCP 伺服器的工具探索過程新增了可自訂的 grace period（寬限期，等待回應的緩衝時間）。當你掛載需要暖機或遠端連線的擴充伺服器時，可自行設定等待寬限時間，讓所有外部工具都有充裕時間完成註冊。

擴充套件可在 MCP 工具回傳結果送交模型前檢查或替換內容

需要過濾敏感資料或微調工具輸出格式的開發者，現在能在資料管線中精準介入。擴充套件獲得了在 MCP（Model Context Protocol，讓 AI 連接外部工具的協定）工具執行完畢後、回傳結果尚未送交模型之前，先行檢視或替換該結果的能力。你可以藉此檢查輸出的資料結構，或在必要時抽換回傳內容，避免原始雜訊或機密資訊直接進入模型的提示詞脈絡。

這宛如報社的審稿編輯在記者交稿後、正式排版送印前先進行校對與篩選，確保刊登內容完全合規。

外掛目錄合併個別儲存庫設定，回報無效市集且不隱藏有效外掛

在專案中管理多個外掛來源時，外掛目錄的設定整合變得更加周全。外掛目錄現在會主動合併各個儲存庫（repository，存放專案程式碼與歷史紀錄的目錄）的個別設定。同時，當專案中存在格式錯誤或無法連線的無效市集（marketplace）時，系統會明確回報該問題，而不會因此隱藏其他正常可用的有效外掛。這讓你在排除特定市集故障時，依然能順暢存取其餘工具。

像商場把各櫃位各自提供的資料合併成一張總導覽；其中一櫃資料失效時標出問題，其他店舖仍照常列出。

在終端介面中保留還原的權限設定檔，並防止 /cd 削弱沙盒限制

如同進入管制大樓時核發的通行證，在跨樓層走動時始終維持原有權限等級，且換到隔壁房間也絕不會意外解除安全門禁。

在終端機互動操作時，安全防護的連貫性獲得了加強。在 TUI（終端機使用者介面，在純文字終端裡操作的互動畫面）的多輪對話中，系統現在會妥善保留先前還原的權限設定檔。這些 permission profiles 不會在下一輪對話中遺失狀態。此外，當在對話中執行 /cd 指令切換目錄時，系統會嚴格防止沙盒（sandbox，隔離程式執行範圍的防護機制）的存取限制被削弱，確保邊界防護不留漏洞。

切換或備援至其他模型時正確維持工具可用性與推理強度

在對話中更換使用的 AI 模型時，工具配置與推論參數不再出現錯亂。當你手動切換模型，或是觸發 fallback（備援，改用另一個模型接手）機制時，目標模型的工具可用性都會被精確維持。同時，模型進行深度思考的 reasoning effort（推理強度，思考運算量的設定）也會維持正確。這避免了切換後工具清單遺失或推論設定不相容的情況。

正如賽車進站更換不同特性的輪胎時，技師團隊會同步調校儀表數據與底盤設定，確保換胎後車輛操控完全精準。

依據遠端執行器的家目錄、作業系統與路徑慣例強化沙盒防護

在遠端主機上隔離執行指令時，沙盒的邊界檢查現在完全貼合目標環境的真實狀態。系統強化了遠端沙盒（sandbox，隔離執行範圍的安全機制）的防護。權限判定改為直接依據遠端執行器實際的家目錄（home directory）、作業系統以及路徑慣例進行計算。這消除了本機與遠端主機因斜線方向或大小寫等格式差異而產生的判定偏差。

彷彿海關邊檢直接依照入境國當地的法規與道路標誌核查車輛，而非套用出發地的規則，落實了精確的在地把關。

在應用程式伺服器回應中完整保留結構化的 MCP 工具與資源錯誤

好比檢驗所回傳健康檢查報告時，完整保留了各項數值的代碼、異常指標與備註欄位，而非只丟出一張模糊的檢查失敗單據。

當外部服務呼叫失敗時，應用程式伺服器現在能為前端提供完整詳細的錯誤資訊。在與 MCP（Model Context Protocol，讓 AI 連接外部工具的協定）伺服器溝通時，若工具執行或資源讀取發生例外，app-server 的回應會完整保留結構化的錯誤代碼與詳細欄位。這避免了將錯誤壓平成字串而遺失細節，讓開發者能精確定位問題發生的根源。

將巢狀子代理的 Token 用量納入根目標的總額度計算

指派多層任務讓 AI 自行拆解執行時，運算資源的控管變得更加嚴密。當主要任務委派多層巢狀子代理（subagent，分派任務的次級助手）協同作業時，其資源消耗有了統籌計算。所有子代理消耗的 token（AI 處理與計費的文字單位）用量，現在都會全數計入根目標的總預算中。這防止了底層子代理消耗過多運算資源而超出整體預算的狀況。

這像總承包商進行工程預算管控，底下各包商與下包工班的所有開銷，都必須逐筆即時記在總工程款帳目上一併核銷。

防止權限狀態變更後因過期的 Guardian 分類結果而誤予授權

調整防護等級時，系統的安全閘門能即時反映最新狀態。Guardian（負責審查指令安全性並進行風險分類的防護機制）過去留存的判定結果，在使用者更改權限設定後不再被沿用。系統現在會在權限狀態變更時立即將舊判定標記為失效，嚴格防止過期（stale，不再適用於當前狀態的舊資料）分類資料在新的權限規則下誤放行危險操作。這確保了每一次安全決策都符合當前的防護規則。

好比銀行調降信用卡安全額度時，系統同步註銷先前簽發但尚未請款的預先授權碼，防止持卡人在新規生效後被舊核准扣款。

為升級的標準輸入審查與遠端執行器 MCP 探索新增遙測日誌

像維運記錄器分別記下需要升級審查的標準輸入事件，以及遠端執行器探索 MCP 伺服器的事件。

系統運作監控與除錯分析的涵蓋範圍在本次更新中獲得擴充。當 stdin（標準輸入，程式接收打字或指令輸入的管道）審查需要升級時，系統會自動記錄相關事件。在遠端執行器探索 MCP（Model Context Protocol，讓 AI 連接外部工具的協定）伺服器時，也會發送對應的遙測數據。這協助維護者深入掌握安全審查與遠端工具連接的執行狀況。

提升慢速與高併發持續整合環境下 Guardian WebSocket 與核心測試的穩定度

Guardian WebSocket 與核心 fixture 測試在網路延遲或高負載下較不會假性失敗，也能穩定通過。系統全面加固了 Guardian（安全審查守護模組）的通訊機制，使其 WebSocket 雙向連線更加可靠。核心 fixture（測試治具，提供測試環境與初始資料的輔助套件）測試也進行了相應的穩定化調整。

這如同在風雨交加或多車同時通行的跨海大橋上加裝減震結構，確保橋梁在惡劣氣候與尖峰車流下依然平穩暢通。

Add configurable grace period for optional MCP server tool discovery

It is like a meeting host giving remote guest speakers a brief grace period to join before moving on with the agenda.

When connecting to optional MCP (Model Context Protocol) servers, tool discovery will no longer fail immediately if an external tool takes a moment to respond. Codex introduces a configurable grace period for discovering tools from optional MCP servers. This gives background or remote servers enough time to complete initialization and register their tools.

Extensions can inspect or replace MCP tool results before reaching the model

Developers who need to sanitize tool outputs or adjust formats can now intercept data directly in the pipeline. Extensions can now inspect or replace MCP (Model Context Protocol) tool execution results before they are delivered to the model. This allows custom logic to filter out sensitive data or rewrite payload structures before the model processes them.

It is like a copy editor reviewing a reporter's draft before it heads to the printing press, ensuring all published material is properly checked.

Plugin catalogs combine repository configs and report invalid marketplaces

Managing plugin sources across projects is now much more reliable. Plugin catalogs now combine per-repository configuration into their listings. Furthermore, when a project contains an invalid marketplace, the system reports the issue clearly without hiding the remaining valid plugins. You can troubleshoot broken marketplace links while continuing to use all working extensions.

a mall directory combining each shop’s details into one board, flagging one invalid listing while keeping the other shops visible.

Preserve restored permission profiles in TUI and prevent /cd sandbox weakening

It is like a building security badge that maintains your verified clearance across different floors, ensuring that stepping into an adjacent room never disables door locks.

Security consistency in the terminal interface is now reinforced. Restored permission profiles are properly preserved across turns in the TUI (terminal user interface). Switching directories using the /cd command is strictly prevented from loosening or bypassing active sandbox restrictions, keeping execution boundaries intact.

Keep tool availability and reasoning effort correct across model switches and fallbacks

Switching models mid-task no longer disrupts tool setups or reasoning levels. When you manually switch models or trigger a fallback to an alternative model, Codex now keeps tool availability and reasoning effort aligned with the target model. This prevents tools from vanishing unexpectedly and ensures reasoning parameters remain valid for the active provider.

It is like a pit crew changing a race car's tires while instantly recalibrating dashboard telemetry and suspension to match the new setup.

Improve remote sandbox enforcement using actual executor environment details

Running commands in remote environments now benefits from accurate isolation boundaries. Remote sandbox enforcement now aligns with the executor's actual home directory, operating system, and path conventions. This eliminates authorization discrepancies caused by mismatched path separators, root structures, or platform conventions between local and remote hosts.

It is like a customs border checkpoint inspecting vehicles according to the destination country's road rules rather than the departure location's laws.

Preserve structured MCP tool and resource errors in app-server responses

It is like a medical lab report retaining specific diagnostic codes and reference ranges instead of printing a generic test failure message.

When external services encounter issues, app-server responses now preserve structured MCP (Model Context Protocol) tool and resource errors. Rather than flattening error responses into plain text strings, the system keeps structured fields intact so client applications and developers can programmatically handle failures and identify root causes.

Count nested subagent token usage toward root goal budgets

Budget tracking across multi-agent workflows is now strictly enforced. When a primary task delegates work to nested subagents across multiple tiers, token consumption from every child agent is counted toward the root goal budget. This prevents deep subagent branches from silently exceeding the project token allocation.

It is like a general contractor accounting for every subcontractor and specialist on a project, ensuring all labor hours bill against the master construction budget.

Prevent stale Guardian classifications from authorizing actions after permission changes

Security enforcement now reacts instantly whenever authorization rules change. Previously cached classifications from Guardian (the security component that categorizes action risks) are no longer used after permission states change. The system invalidates stale classification data immediately upon permission updates, ensuring that outdated approvals cannot authorize new actions after permission state changes.

It is like a bank revoking outstanding pre-authorization holds the moment a credit limit is lowered, preventing old approvals from charging against the updated cap.

Add telemetry for escalated stdin reviews and remote executor MCP discovery

a maintenance recorder separately logging escalated stdin review events and MCP discovery events from remote executors.

Observability into security reviews and remote connections is now expanded. Codex introduces dedicated telemetry tracking for escalated stdin reviews whenever interactive input requires elevated approval. It also logs remote executor MCP (Model Context Protocol) discovery events, giving maintainers clearer visibility into tool registration flows.

Stabilize Guardian WebSocket and core fixture tests in slow or concurrent CI

Guardian WebSocket connections and core fixture tests now run reliably under high load or network latency. Guardian WebSocket connections and core test fixtures have been hardened against timing issues. Even when test suites run on slow CI (continuous integration) runners or under heavy concurrency, core fixture tests complete predictably without false alarms.

It is like reinforcing a suspension bridge with dampers so that it stays completely stable through severe storms and rush hour traffic.
