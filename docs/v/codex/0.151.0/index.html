為非必要 MCP 伺服器的工具搜尋新增可自訂的寬限期

好比會議主持人給線上連線的外部專家預留彈性的報到緩衝，不會因為網路稍慢就直接跳過對方的名額。在連接選用或非必要的 MCP（Model Context Protocol，讓 AI 連接外部工具的協定）伺服器時，若外部工具啟動稍慢，搜尋流程不再立刻判定逾時。系統為非必要 MCP 伺服器的工具探索過程新增了可自訂的 grace period（寬限期，等待回應的緩衝時間）。當你掛載需要暖機或遠端連線的擴充伺服器時，可自行設定等待寬限時間，讓所有外部工具都有充裕時間完成註冊。

擴充套件可在 MCP 工具回傳結果送交模型前檢查或替換內容

需要過濾敏感資料或微調工具輸出格式的開發者，現在能在資料管線中精準介入。擴充套件獲得了在 MCP（Model Context Protocol，讓 AI 連接外部工具的協定）工具執行完畢後、回傳結果尚未送交模型之前，先行檢視或替換該結果的能力。你可以藉此檢查輸出的資料結構，或在必要時抽換回傳內容，避免原始雜訊或機密資訊直接進入模型的提示詞脈絡。這宛如報社的審稿編輯在記者交稿後、正式排版送印前先進行校對與篩選，確保刊登內容完全合規。

在專案中管理多個外掛來源時，外掛目錄的設定整合變得更加周全。外掛目錄現在會主動合併各個儲存庫（repository，存放專案程式碼與歷史紀錄的目錄）的個別設定。同時，當專案中存在格式錯誤或無法連線的無效市集（marketplace）時，系統會明確回報該問題，而不會因此隱藏其他正常可用的有效外掛。這讓你在排除特定市集故障時，依然能順暢存取其餘工具。像商場把各櫃位各自提供的資料合併成一張總導覽；其中一櫃資料失效時標出問題，其他店舖仍照常列出。

在終端介面中保留還原的權限設定檔，並防止 /cd 削弱沙盒限制

如同進入管制大樓時核發的通行證，在跨樓層走動時始終維持原有權限等級，且換到隔壁房間也絕不會意外解除安全門禁。在終端機互動操作時，安全防護的連貫性獲得了加強。在 TUI（終端機使用者介面，在純文字終端裡操作的互動畫面）的多輪對話中，系統現在會妥善保留先前還原的權限設定檔。這些 permission profiles 不會在下一輪對話中遺失狀態。此外，當在對話中執行 /cd 指令切換目錄時，系統會嚴格防止沙盒（sandbox，隔離程式執行範圍的防護機制）的存取限制被削弱，確保邊界防護不留漏洞。

切換或備援至其他模型時正確維持工具可用性與推理強度

在對話中更換使用的 AI 模型時，工具配置與推論參數不再出現錯亂。當你手動切換模型，或是觸發 fallback（備援，改用另一個模型接手）機制時，目標模型的工具可用性都會被精確維持。同時，模型進行深度思考的 reasoning effort（推理強度，思考運算量的設定）也會維持正確。這避免了切換後工具清單遺失或推論設定不相容的情況。正如賽車進站更換不同特性的輪胎時，技師團隊會同步調校儀表數據與底盤設定，確保換胎後車輛操控完全精準。

將巢狀子代理的 Token 用量納入根目標的總額度計算

指派多層任務讓 AI 自行拆解執行時，運算資源的控管變得更加嚴密。當主要任務委派多層巢狀子代理（subagent，分派任務的次級助手）協同作業時，其資源消耗有了統籌計算。所有子代理消耗的 token（AI 處理與計費的文字單位）用量，現在都會全數計入根目標的總預算中。這防止了底層子代理消耗過多運算資源而超出整體預算的狀況。這像總承包商進行工程預算管控，底下各包商與下包工班的所有開銷，都必須逐筆即時記在總工程款帳目上一併核銷。

防止權限狀態變更後因過期的 Guardian 分類結果而誤予授權

調整防護等級時，系統的安全閘門能即時反映最新狀態。Guardian（負責審查指令安全性並進行風險分類的防護機制）過去留存的判定結果，在使用者更改權限設定後不再被沿用。系統現在會在權限狀態變更時立即將舊判定標記為失效，嚴格防止過期（stale，不再適用於當前狀態的舊資料）分類資料在新的權限規則下誤放行危險操作。這確保了每一次安全決策都符合當前的防護規則。好比銀行調降信用卡安全額度時，系統同步註銷先前簽發但尚未請款的預先授權碼，防止持卡人在新規生效後被舊核准扣款。

為升級的標準輸入審查與遠端執行器 MCP 探索新增遙測日誌

像維運記錄器分別記下需要升級審查的標準輸入事件，以及遠端執行器探索 MCP 伺服器的事件。系統運作監控與除錯分析的涵蓋範圍在本次更新中獲得擴充。當 stdin（標準輸入，程式接收打字或指令輸入的管道）審查需要升級時，系統會自動記錄相關事件。在遠端執行器探索 MCP（Model Context Protocol，讓 AI 連接外部工具的協定）伺服器時，也會發送對應的遙測數據。這協助維護者深入掌握安全審查與遠端工具連接的執行狀況。

オプションの MCP サーバーのツール検出に設定可能な猶予期間を追加

会議の司会者がリモート参加の外部ゲストに少しの接続猶予時間を設け、通信の遅れですぐに順番を飛ばさないようにするようなものだ。必須ではないオプションの MCP（外部ツールと連携するためのプロトコル）サーバーに接続する際、ツールの起動に時間がかかっても検出処理が即座に失敗しなくなった。オプションの MCP サーバーからツールを検出する処理に対して、設定可能な grace period（猶予期間、応答を待つための時間枠）が追加された。初期化に時間のかかる外部サーバーでもツールを確実に登録できる。

拡張機能が MCP ツールの結果をモデル送信前に検査・置換可能に

ツールの出力から機密情報を除外したり形式を整えたりしたい開発者は、データ処理の途中に介入できるようになった。拡張機能は、MCP（外部ツールと連携するためのプロトコル）ツールの実行結果がモデルに届く前に、その内容を検査または置換できる。これにより不要な情報を取り除き、モデルへ渡すプロンプトの文脈を適切に制御できる。記者が提出した原稿を印刷機へ送る前に校閲記者がチェックし、必要に応じて表現を差し替える工程に似ている。

プラグイン目録がリポジトリ設定を統合し無効な市場があっても正常なプラグインを表示

複数のプラグイン配布元を扱う際のカタログ管理がより柔軟になった。プラグインカタログは、リポジトリごとの個別設定を組み合わせて読み込むようになった。さらに、プロジェクト内に無効なマーケットプレイス（marketplace、プラグインの配布市場）が存在する場合でも、エラーを報告しつつ正常なプラグインを隠さずに表示し続ける。これにより一部の設定不備があっても他のプラグインを問題なく利用できる。各テナントの情報を一枚の案内板にまとめ、無効な一件には印を付けながら他の店舗は表示し続けるようなものだ。

TUI で復元した権限プロファイルを保持し /cd によるサンドボックス緩和を防止

管理ビルで発行された通行証がフロアを移動しても同じ権限を維持し、隣の部屋へ入ったからといってセキュリティ制限が勝手に解除されないようなものだ。端末操作時の安全対策が強化された。TUI（テキスト端末上で動作する対話型インターフェース）の会話ターンをまたいでも、復元された権限プロファイルが確実に維持される。また、/cd コマンドで作業ディレクトリを変更した際に、サンドボックス（プログラムの実行範囲を隔離する安全機構）の制限が緩まる現象を防止した。

モデル切り替えや代替切り替え時にもツールの有効性と推論負荷設定を維持

対話の途中で AI モデルを変更した際、ツールの設定や推論パラメータが崩れなくなった。手動でモデルを切り替える場合や、別のモデルへ自動で fallback（別のモデルへ処理を引き継ぐ仕組み）する場合でも、移行先モデルのツール利用可否が正しく維持される。さらに、モデルの思考の深さを指定する reasoning effort（推論負荷設定）も適切に保持される。レース中にタイヤを交換する際、メカニックが新しいタイヤに合わせて計器と車体設定を即座に最適化するようなものだ。

リモート実行環境のホームディレクトリ・OS・パス規則に合わせたサンドボックス強化

リモート環境でコマンドを隔離実行する際、安全境界の判定が対象環境の実態に即して行われるようになった。リモートサンドボックス（安全な隔離実行領域）の制限処理が改善された。実行環境の実際のホームディレクトリ（home directory）、オペレーティングシステム、およびパスの記述規則を基準にして権限が判定される。これにより、ローカル側とリモート側の表記差による判定の不一致を防ぐ。入国審査官が出発地の基準ではなく入国先の交通規則や標識に基づいて車両を検査するようなものだ。

アプリサーバーの応答で構造化された MCP ツール・リソースのエラー情報を維持

検査機関が検査報告書を返す際、単なる不合格通知ではなく数値コードや詳細項目をそのまま残して渡すようなものだ。外部ツールとの通信で問題が発生した際、アプリサーバーが詳細なエラー情報をそのまま維持するようになった。MCP（外部ツールと連携するためのプロトコル）サーバーのツール実行やリソース取得で例外が起きた場合、構造化されたエラー情報が保持される。エラーが単純な文字列に丸められないため、開発者は原因を迅速に特定できる。

ネストされたサブエージェントのトークン消費量をルート目標の予算に合算

階層的なエージェントに作業を任せる際のコスト管理が厳格になった。メインタスクが複数階層のサブエージェント（親から作業を委譲された補助エージェント）を呼び出す処理が見直された。子エージェントが消費したトークン（AI の処理・課金単位）はすべてルート目標の予算枠に合算される。これにより、深い階層のエージェントが意図せず予算を超過する事態を防ぐ。元請け業者が下請けや孫請けの経費をすべて総工事費の予算枠内でまとめて管理するようなものだ。

権限変更後に古い Guardian 分類結果で処理が誤承認される問題を防止

権限レベルを変更した際、セキュリティ機構が最新の状態を即座に反映するようになった。Guardian（コマンドの安全性を審査・分類する保護機能）による過去の判定結果が、権限状態の変更後に再利用されるのを防ぐ。権限が変更された時点で古い分類データは無効化され、新しい制限下で不正な操作が実行されるリスクを排除する。クレジットカードの利用限度額を引き下げた際、以前の仮売上枠を破棄して古い承認での引き落としを防ぐようなものだ。

昇格された標準入力審査とリモート MCP 検出のテレメトリを追加

昇格した標準入力の審査イベントと、リモート実行環境による MCP 検出イベントを別々に記録する運用ログのようなものだ。動作ログとトラブル解析の対象が拡大された。権限昇格を伴う stdin（標準入力、キーボードからの文字入力を受け取る仕組み）の審査が行われた際、関連イベントが自動記録される。さらに、リモート実行環境が MCP（外部ツールと連携するためのプロトコル）サーバーを検出する際にも詳細なテレメトリが収集される。これによりセキュリティ審査とツール連携の状況を正確に追跡できる。

低速・高並行 CI 環境下での Guardian WebSocket とコアテストの安定化

Guardian WebSocket とコア fixture テストで失敗が起きにくくなり、安定してパスする。Guardian（セキュリティ審査モジュール）の通信機構が強化され、WebSocket 接続の安定性が向上した。また、コア fixture（テスト環境や初期データを準備する仕組み）テストの処理も見直された。強風や渋滞が重なる大橋に制震ダンパーを取り付け、過酷な条件下でも橋を揺らさず安全に保つようなものだ。

추가 승인이 필요한 표준 입력 심사 이벤트와 원격 실행기의 MCP 검색 이벤트를 각각 기록하는 운영 로그와 같다.시스템 점검과 문제 분석을 위한 로그 수집 범위가 넓어졌다. 추가 승인이 필요한 stdin(표준 입력, 키보드 타이핑이나 명령 입력을 받는 통로) 심사가 진행될 때 관련 이벤트가 자동으로 기록된다. 또한 원격 실행기가 MCP(외부 도구를 연결하는 표준 규약) 서버를 검색하는 과정에서도 원격 측정 데이터가 수집된다. 이를 통해 보안 심사와 원격 도구 연결 상태를 한눈에 파악할 수 있다.

저속 및 고동시성 CI 환경에서 Guardian WebSocket과 핵심 테스트 안정화

Guardian WebSocket과 핵심 fixture 테스트가 안정적으로 통과한다. 속도가 느리거나 동시 작업이 몰리는 CI(지속적 통합, 자동 빌드 및 테스트 환경) 서버에서도 테스트가 안정적으로 통과한다.강풍과 차량 정체가 겹치는 다리에 제진 장치를 보강하여 악천후와 출퇴근길에도 흔들림 없이 통행을 유지하는 모습과 같다.
