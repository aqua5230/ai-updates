Codex 0.167.0

發布日期：2026-11-06

繁體中文

新功能

代理人指揮中心標記未讀結果，切換後端工作階段保留草稿

平時如果習慣讓多個助理分頭調查專案，終端機現在能讓你清楚掌握每位幫手的最新進度。執行 codex agents --no-daemon 就能進入常駐的代理人指揮中心，指揮中心與終端機工作階段（session，正在進行中的對話作業）選取器現在都會主動標記出未讀的執行結果。

猶如總機櫃台的分機信箱，信件送達時格子會亮起提示燈，即使轉身前往另一張辦公桌交涉，手中寫到一半的便箋也不會遺失。

當你在工作階段選取器中切換不同的已連線後端時，輸入框中還沒送出的草稿會完整保留下來，不會因為更換後端就遭到清空。

新功能

終端機輸入框即時預覽附加圖片，逐字稿路徑支援點擊開啟

在終端機請模型排查版面外觀或分析架構圖時，最怕挑錯要送出的圖檔。現在只要使用支援的終端機，在輸入框撰寫內容時就能直接預覽附加的本機圖片。

彷彿在公文夾附上拍立得縮圖，夾上檔案的當下就能先瞄一眼畫面確認無誤，事後查閱歸檔清單時也能隨手按壓標籤快速調閱原圖。

而在對話逐字稿（transcript，記錄完整互動內容的文字檔）中，顯示的本機圖片路徑現在也支援點擊，輕點路徑就能直接開啟剛剛檢視過的圖片。

新功能

登入選單支援 Vertex AI 設定精靈，切換模型提供者仍可查閱舊紀錄

需要連線到不同雲端平台調用模型時，設定登入與管理既有紀錄往往讓人傷腦筋。在「以其他方式登入（Sign in another way）」選單中，現在新增了 API 金鑰與雲端提供者選項。只要啟用 gcp_setup_wizard 設定項，就能透過引導精靈以應用程式預設憑證（ADC，Google Cloud 用來自動驗證身分的機制）或憑證檔，快速串接 Google Cloud Vertex AI。

如同聘請不同事務所的顧問，櫃台提供制式表單幫你快速登記授權，而先前與上一家顧問往來的會議備忘錄依舊留在手邊，就算無法直接續約也能抄錄結論另開新專案。

切換模型提供者後，先前儲存的聊天紀錄依然會留在清單中。如果舊對話無法直接繼續執行，你也可以隨時閱讀歷史逐字稿，並把重點整理成可編輯的提示詞，在全新聊天中直接接續工作。

問題修復

審批提示下可展開修補細節，清螢幕保留紀錄且退格不跳指令模式

在終端機審查程式碼修改並輸入回應時，細節檢視與打字體驗迎來了一批順手改進。 跳出審批提示（approval prompt）時，你現在能直接在對話逐字稿中展開修補程式細節，不必先退出提示才能看清改動。 在終端機整理畫面時，按下 Ctrl+L 會清空螢幕顯示內容，先前的對話訊息依然隨時能透過 Ctrl+T 叫出查閱。 在輸入框退格刪除文字時，就算露出開頭的驚嘆號 !，草稿依然會維持一般對話模式，不再被誤觸成執行外部指令的模式。

新功能

支援系統網路代理設定，網路請求逐一排隊審批並明定權限規範

在需要透過特定通道連線或對外部請求有嚴密資安管制的環境中，網路連線行為現在更容易掌握。 現在輸入 /experimental 就能選擇加入 macOS 或 Windows 的系統代理伺服器（proxy，協助轉發網路封包的中繼伺服器）設定，讓工具連線直接遵循作業系統的網路轉發規則。 遇到需要手動核准的網路連線時，網路審批提示會在請求結束時自動關閉。多個連往同一個端點的並行請求也不會再同時跳出干擾，而是依序逐一跳出提示讓你確認。 應用程式伺服器（app-server）的說明文件中，也正式補齊了設定檔 [permissions.network] 底下的受控網路限制說明，並明列了哪些 prompt-user 指令規則必須取得最新的人工審批才能放行。

新功能

Realtime V3 語音自動存入對話歷史，上下文壓縮納入失敗回應產出

當你進行長時間的即時對話或複雜的多輪問答時，對話內容的完整記錄與記憶管理至關重要。在長期的 Realtime V3 即時語音對話中，隨著逐字稿長度增長，工具會即時將已結束的語音內容保存至聊天歷史記錄中。

好比速記員一邊開會一邊將說完的發言謄進議事錄，管帳人員在打包過長卷宗時，也會把印壞的草稿和漏蓋計費章的廢頁通通算入紙張重量。

在對話長度過長觸發自動上下文壓縮時，計算機制現在也會如實算入執行失敗回應留下的輸出，以及缺少 token（AI 處理與計費的文字單位）用量數據的回應，確保容量估算不會失準。

新功能

淘汰模型主動推薦替代方案，Linux musl 降低閒置記憶體佔用

開發者在維護長期專案或將工具部署在輕量環境時，模型升級與底層資源消耗現在都有更省心的安排。 如果正在使用的模型即將淘汰，內建的 openai-docs 技能（skill，擴充 AI 能力的指引包）在引導遷移時，會直接根據官方文件推薦合適的替代模型。 針對安裝部署，DotSlash 的設定清單現在會直接參照本次版本隨附發布的 Cargo 套件，確保版本依賴關係保持一致。 若是在 Linux musl 環境編譯，底層改用較少的記憶體配置區（allocator arenas，底層向系統申請記憶體的緩衝區塊），有效降低對話工作階段卸載之後殘留的閒置記憶體。

English

FEATURE

Agent command center marks unread results, and switching backend sessions preserves drafts

If you regularly have several assistants investigate different parts of a project, the terminal now makes it easier to keep track of each helper’s latest progress. Run codex agents --no-daemon to enter the persistent agent command center. Both the command center and the terminal session picker (for ongoing conversations) now mark unread results.

Like extension mailboxes at a switchboard desk, a compartment lights up when mail arrives, and even if you turn to another desk to discuss something, the note you are halfway through writing stays with you.

When you switch between connected backends in the session picker, any unsent draft in the input box stays intact instead of being cleared.

FEATURE

Preview attached images in the terminal input box and click transcript paths to open them

When asking a model in the terminal to troubleshoot a layout or analyze an architecture diagram, choosing the wrong image to send is a particular concern. On supported terminals, you can now preview attached local images directly while composing in the input box.

Picture attaching a Polaroid thumbnail to a document folder: you can glance at the image as soon as you attach the file to check that it is right, then press its label while reviewing the archive list later to quickly retrieve the original image.

Local image paths shown in the conversation transcript (a text file recording the full interaction) are now clickable too. Click a path to open the image you just viewed.

FEATURE

Sign-in menu supports a Vertex AI setup wizard, and old chats remain accessible after switching providers

When connecting to different cloud platforms to use models, setting up sign-in and managing existing records can be a headache. The “Sign in another way” menu now includes API key and cloud provider options. Enable gcp_setup_wizard to quickly connect to Google Cloud Vertex AI through a guided wizard using Application Default Credentials (Google Cloud’s mechanism for automatically authenticating your identity) or a credential file.

Think of hiring consultants from different firms: the front desk supplies standard forms to quickly register your authorization, while meeting notes from your previous consultants remain at hand, so even if you cannot renew the engagement directly, you can copy the conclusions into a new project.

After you switch model providers, previously saved chats remain in the list. If an old conversation cannot resume directly, you can still read its historical transcript and turn the key points into an editable prompt to continue working in a new chat.

BUGFIX

Expand patch details during approval, clear the screen while keeping history, and backspace without entering command mode

Reviewing code changes and typing responses in the terminal now comes with several improvements to detail viewing and typing. While an approval prompt is open, you can now expand patch details directly in the conversation transcript without leaving the prompt to inspect the changes. When tidying up the terminal view, pressing Ctrl+L clears the screen display. Earlier conversation messages remain available through Ctrl+T whenever you want to review them. When backspacing in the input box exposes a leading exclamation mark !, the draft stays in ordinary chat mode instead of accidentally switching to the mode for running external commands.

FEATURE

System proxy settings supported, network approvals queued individually, and permission rules documented

In environments that require connections through specific channels or tightly control external requests for security, network connection behavior is now easier to keep track of. Enter /experimental to opt into macOS or Windows system proxy settings (relay servers that help forward network packets), so tool connections directly follow the operating system’s network forwarding rules. For network connections that require manual approval, the network approval prompt now closes automatically when the request ends. Concurrent requests to the same endpoint no longer interrupt you with simultaneous prompts. Instead, prompts appear one at a time for you to confirm. The app-server (application server) documentation now also covers managed network constraints under [permissions.network] in the configuration file and explicitly lists which prompt-user command rules require fresh human approval before they can proceed.

FEATURE

Realtime V3 speech saves automatically to chat history, and context compaction counts output from failed responses

When you have long real-time conversations or complex exchanges with multiple rounds of questions and answers, complete conversation records and memory management are essential. During long Realtime V3 voice conversations, the tool saves completed speech to chat history as the transcript grows.

Imagine a stenographer transcribing completed remarks into the minutes as a meeting proceeds, while the bookkeeper packing up overly long files counts misprinted drafts and discarded pages missing billing stamps toward the total paper weight.

When a conversation gets long enough to trigger automatic context compaction, the calculation now also counts retained output from failed responses and responses missing token usage data (the text units AI processes and bills for), keeping capacity estimates accurate.

FEATURE

Retiring models get replacement recommendations, and Linux musl reduces idle memory use

For developers maintaining long-running projects or deploying tools in lightweight environments, model upgrades and underlying resource use now require less attention. If the model you are using is being retired, the built-in openai-docs skill (a package of instructions that extends AI capabilities) now recommends a suitable replacement directly from the official documentation when guiding migration. For installation and deployment, DotSlash manifests now directly reference the Cargo packages shipped with this release, keeping version dependencies consistent. Builds for Linux musl now use fewer allocator arenas (buffer blocks used to request memory from the system), reducing idle memory left behind after conversation sessions unload.
