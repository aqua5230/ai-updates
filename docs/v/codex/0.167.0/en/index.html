Codex 0.167.0

Released: 2026-11-06

Release notes

FEATURE

Agent command center marks unread results, and switching backend sessions preserves drafts

If you regularly have several assistants investigate different parts of a project, the terminal now makes it easier to keep track of each helper’s latest progress. Run codex agents --no-daemon to open the agent command center. Both the command center and the terminal session picker (for ongoing conversations) now mark unread results.

Like extension mailboxes at a switchboard desk, a compartment lights up when mail arrives, and even if you turn to another desk to discuss something, the note you are halfway through writing stays with you.

When you switch between connected backends in the session picker, any unsent draft in the input box stays intact instead of being cleared.

FEATURE

Preview attached images in the terminal input box and click transcript paths to open them

When asking a model in the terminal to troubleshoot a layout or analyze an architecture diagram, choosing the wrong image to send is a particular concern. On supported terminals, you can now preview attached local images directly while composing in the input box.

Picture attaching a Polaroid thumbnail to a document folder: you can glance at the image as soon as you attach the file to check that it is right, then press its label while reviewing the archive list later to quickly retrieve the original image.

Local image paths shown in the conversation transcript (a text file recording the full interaction) are now clickable too. Click a path to open the image you just viewed.

FEATURE

Sign-in menu supports a Vertex AI setup wizard, and old chats remain accessible after switching providers

When connecting to different cloud platforms to use models, setting up sign-in and managing existing records can be a headache. You can find API key and cloud provider options under the “Sign in another way” menu. Enable gcp_setup_wizard to connect to Google Cloud Vertex AI through a guided wizard using Application Default Credentials (Google Cloud’s mechanism for automatically authenticating your identity) or a credential file.

Think of hiring consultants from different firms: the front desk supplies standard forms to quickly register your authorization, while meeting notes from your previous consultants remain at hand, so even if you cannot renew the engagement directly, you can copy the conclusions into a new project.

After you switch model providers, previously saved chats remain in the list. If an old conversation cannot resume directly, you can still read its historical transcript and turn the key points into an editable prompt to continue working in a new chat.

BUGFIX

Expand patch details during approval, clear the screen while keeping history, and backspace without entering command mode

Reviewing code changes and typing responses in the terminal now comes with several improvements to detail viewing and typing. While an approval prompt is open, you can now expand patch details directly in the conversation transcript. When tidying up the terminal view, pressing Ctrl+L clears the screen display. Earlier conversation messages remain available through Ctrl+T whenever you want to review them. When backspacing in the input box exposes a leading exclamation mark !, the draft stays in ordinary chat mode instead of accidentally switching to the mode for running external commands.

FEATURE

System proxy settings supported, network approvals queued individually, and permission rules documented

In environments that require connections through specific channels or tightly control external requests for security, network connection behavior is now easier to keep track of. Enter /experimental to opt into macOS or Windows system proxy settings (relay servers that help forward network packets), so tool connections directly follow the operating system’s network forwarding rules. For network connections that require manual approval, the network approval prompt now closes automatically when the request ends. Concurrent requests to the same endpoint no longer interrupt you with simultaneous prompts. Instead, prompts appear one at a time for you to confirm. The app-server (application server) documentation now also covers managed network constraints under [permissions.network] in the configuration file and explicitly lists which prompt-user command rules require fresh human approval before they can proceed.

FEATURE

Realtime V3 speech saves automatically to chat history, and context compaction counts output from failed responses

When you have long real-time conversations or complex exchanges with multiple rounds of questions and answers, complete conversation records and memory management are essential. During long Realtime V3 voice conversations, the tool saves completed speech to chat history as the transcript grows.

Imagine a stenographer transcribing completed remarks into the minutes as a meeting proceeds, while the bookkeeper packing up overly long files counts misprinted drafts and discarded pages missing billing stamps toward the total paper weight.

When a conversation gets long enough to trigger automatic context compaction, the calculation now also counts retained output from failed responses and responses missing token usage data (the text units AI processes and bills for).

FEATURE

Retiring models get replacement recommendations, and Linux musl reduces idle memory use

For developers maintaining long-running projects or deploying tools in lightweight environments, model upgrades and underlying resource use now require less attention. If the model you are using is being retired, the built-in openai-docs skill (a package of instructions that extends AI capabilities) now recommends a suitable replacement directly from the official documentation when guiding migration. For installation and deployment, DotSlash (a tool that downloads the right executable for each platform) manifests now directly reference the Cargo packages shipped with this release. Builds for Linux musl now use fewer allocator arenas (buffer blocks used to request memory from the system), reducing idle memory left behind after conversation sessions unload.
