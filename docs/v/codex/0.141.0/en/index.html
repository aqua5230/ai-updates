Codex 0.141.0

Released: 2026-06-18

Release notes

FEATURE

End-to-end encrypted remote execution with native cross-platform environments

Running code remotely is now more powerful and secure.

Remote executors (the underlying engines running your code) now default to end-to-end encrypted Noise relay channels, and idle connections will not drop randomly. If you're on a Mac connecting to a Windows server, the system perfectly preserves the native working directories, shell environment, and filesystem permissions across the boundary without complaining about platform differences. It also supports P-521 certificate signatures commonly used by enterprise proxies and fixes a database (SQLite) corruption bug. Like teleoperating a foreign cleanroom from your home: the communication is now fully encrypted, the feed never drops, and your controller movements are perfectly translated to the local robotic arm's specifications so nothing breaks.

FEATURE

Expanded plugin marketplaces with curated lists and "Created by me"

Finding plugins (add-ons extending system capabilities) now feels like browsing a modern marketplace.

There is a new "Created by me" section to quickly locate the tools you built, and the system loads curated catalogs tailored to your specific authentication mode. If different plugins declare the same name (conflicting declarations), the system now neatly deduplicates them while preserving the marketplace's ranking order. Furthermore, selected executor plugins can now activate their own MCP (a protocol letting AI control external tools) servers on a per-thread (independent workflow) basis. Like a department store remodeling: you now get your own custom boutique section, personalized shopping catalogs, and they finally fixed the inventory system so identical products from different vendors don't mess up the price tags.

PERF

Smoother performance and reduced memory usage in heavy sessions

Heavy projects loaded with tools will now run significantly smoother.

The system optimized its core logic by caching tool search results and eliminating repeated copies of conversation history, drastically reducing latency and memory consumption. It also put a hard 64 MiB cap on the prompt-image cache and restricted feedback uploads to a maximum of eight related threads (independent workflows), preventing the system from ravenously eating up all your RAM. Additionally, terminal text reflow upon resizing is now always enabled, overriding any obsolete settings that might freeze the view. Like an old office that used to print out every database record for archiving, but finally learned to use digital indexes — not only is the desk (RAM) no longer crushed by paper mountains, but finding information is much faster.

FEATURE

Flexible terminal interactions and auto-repairing Windows sandboxes

Interacting with the AI in the terminal has become much more user-friendly.

Input prompts will now automatically resolve themselves after a period of inactivity (the countdown pauses the moment you interact); during Realtime sessions, you can explicitly append speech and control how responses enter the context. For Windows users, running commands in the sandbox (an isolated, secure execution environment) now automatically repairs stale credentials, and PowerShell commands are given a bit more breathing room before being shunted into the background. Like a sharp assistant who politely closes a dialog box if you've walked away from your desk, instantly stops to listen the moment you speak up, and quietly renews your expired IDs when dealing with tedious paperwork.

FEATURE

Stricter security hooks and transparent API usages

The PostToolUse security hooks (interception mechanisms that trigger before or after specific actions) now correctly block non-compliant tool calls in Code mode, and your trust-bypass status persists perfectly through codex exec thread starts and resumes.

On the app-server side, you can now cleanly list child threads, accurately correlate external agent records with their results, and read or redeem your API rate-limit reset credits. Like a corporate security and accounting upgrade: the guards used to forget a VIP's clearance when they switched departments or failed to inspect back-door packages, but now the gates are airtight, and every department's budget and remaining quotas are tracked down to the penny.
