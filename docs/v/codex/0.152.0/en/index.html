Codex 0.152.0

Released: 2026-09-01

Release notes

FEATURE

Vim mode supports in-draft search and starts fresh drafts ready for typing

When editing long drafts in Vim mode within the Codex composer, finding an earlier filename no longer requires manual scrolling.

You can now press / to search forward or ? to search backward with highlighted matches, and navigate with n and N to jump between occurrences.

It works like marking every instance of a word with a highlighter and jumping directly between highlighted marks instead of scanning line by line.

Furthermore, fresh drafts now start directly ready for typing: whether you just submitted a message or ran a slash command, you can start typing immediately without manually switching modes.

FEATURE

Rate-limit banners let you check usage and manage limits directly

When hit by a rate limit, users previously saw only a plain banner stating that requests were temporarily blocked, leaving them to figure out the next step on their own.

The banner now includes direct action buttons to check current usage, manage credits, reset limits, and manage subscription plans, allowing you to handle each task immediately without dismissing the alert to search through settings.

It is like a low-fuel warning light on a dashboard that displays buttons for gas station navigation, prepaid card balance, and extended warranty right beside it, rather than forcing you to pull over and step out of the car to find help.
FEATURE

Reauthentication progress is now visible in the terminal UI and codex exec

The terminal UI and the non-interactive codex exec command now display live progress when refreshing credentials, including multi-step flows like Amazon Bedrock reauthentication.

Previously, reauthentication would leave the screen hanging with no feedback, making it impossible to tell whether the process was working or frozen.

It is like an automated airport immigration gate where the screen previously went black after scanning an ID, but now displays step-by-step progress like "verifying fingerprints" and "confirming details" until the green light lets you through.
FEATURE

MCP server names support package formats, and tool outputs can set limits

MCP server names were previously limited to simple characters.

They can now include :, @, /, and ., enabling standard package-style naming such as @scope/name across all CLI commands and authentication flows. In addition, individual MCP tools now support an output_token_limit setting to cap output tokens per invocation, maintaining consistent truncation rules across resumed sessions.

It is like apartment mailboxes upgrading from three-digit numbers to full addresses with floor numbers, while also setting individual capacity limits so no single delivery overflows someone else's box.
FEATURE

The planning tool is now disabled by default and requires explicit configuration

Codex previously enabled its built-in planning tool out of the box, but the feature is now disabled by default.

To use it, you must add the following snippet to your configuration file:

{"tools": {"update_plan": {"enabled": true}}}

This sets tools.update_plan.enabled to true.

Rather than introducing a new feature, this update makes an existing capability opt-in.

It is like an appliance shipping with power-hungry optional modes turned off, requiring you to check the manual and press a button on the panel to turn them on.
FEATURE

Automatic approval reviews retain longer transcripts and preserve authorizations across compaction

Automatic approval reviews now retain richer conversation context.

While earlier reviews were limited when handling lengthy exchanges, the system can now hold longer messages and larger conversation transcripts. Crucially, when conversations undergo history compaction to condense past turns, original user instructions, provided answers, and granted authorizations are preserved rather than compressed away, ensuring reviews retain full context.

It is like a court case file where older records are archived into summaries, but key testimony and signed authorization forms are preserved intact so original records remain verifiable later.
FEATURE

Background operations refined across thread resumption, caching, and model menus

This release fixes multiple background edge cases.

Clients connecting to app-server can now configure thread/shellCommand timeouts, including deadlines longer than one hour. Resumed threads automatically restore their previous working directory when none is specified, and client metadata updates preserve existing filesystem permissions. In addition, MCP tools remain callable during cache refreshes and remote plugin updates, while authentication retries adopt newly refreshed helper headers. Opening the model picker refreshes the model list without losing your currently selected item, and plugin recommendations begin loading at startup to minimize delays before the first prompt.

It is like stepping out during a movie and returning to find your ticket stub in place, the projection running, your seat held, and your coat, pre-ordered popcorn, and counter receipt all waiting without anything expiring while you were away.
BUGFIX

Three Windows fixes resolved and cloud tasks reject untrusted URLs

Three issues on Windows have been resolved in this release: sandbox execution errors with Microsoft Store PowerShell, subprocess hangs during terminal queries, and cursor-related display corruption in older JediTerm terminals.

In addition, cloud task requests now reject untrusted backend URLs and disable automatic redirects to prevent saved credentials from being leaked to unintended destinations.

It is like repairing a batch of malfunctioning access card readers and display panels, while tightening gate rules to only recognize certified vendors so unrecognized cards cannot open the gate.
