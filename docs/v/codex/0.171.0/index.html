Codex 0.171.0

發布日期：2026-11-20

繁體中文

新功能

模型目錄新增 GPT-6.2 Sol 與 Astra

開新對話前打開選單，裡頭現在多了兩位新成員。模型目錄已加入 GPT-6.2 Sol 與 Astra，並直接將 Sol 設為目錄的預設選項。

好比文具店把兩款新筆放上陳列架，以前架上只有舊款式，現在不只多了新選擇，其中一款還直接擺在最順手的預設位置。
新功能

TUI 工作區預設開啟並排顯示預覽

一邊請 AI 改資料、一邊還得另外開視窗翻文件，視線常在好幾個地方跳來跳去。現在 TUI（終端機裡的文字操作介面）的工作區會預設開啟，不用另外切換就能直接看到並排畫面。 主對話旁邊會直接列出可搜尋的文件預覽與圖片預覽。如果有子代理（幫主對話分頭處理工作的助手）在執行，它的完整對話紀錄也會一併擺在旁邊方便對照。

就像整理報告時把資料夾攤在書桌兩側，以前要逐份翻找核對，現在主稿旁直接擺好參考文件、圖片和分頭調查的筆記。
新功能

非 Vim 輸入區新增可自訂復原與重做鍵

整理報告貼了一大段參考資料又附了檔案，卻手滑把整塊指令全刪掉。現在只要不是在 Vim（一種純鍵盤操作的編輯模式）下，提示詞輸入區都能設定復原與重做快捷鍵。 操作時不只純文字會恢復，先前夾帶的附件和大段貼上的內容也會完整回到輸入框裡。

跟在剪貼簿做拼貼一樣，不小心把剪好的圖文整塊掃掉，拉回一步就能把整張照片和長剪報原封不動放回桌面。
新功能

codex exec 新增 --remote 參數

遠端機器上已經跑著一個 Codex 服務，想在腳本裡直接交辦任務。只要執行下面這行指令，就能連上既有的應用程式伺服器，啟動或接續非互動式工作階段（送出指令後直接跑完、不需來回對話）：

codex exec --remote <ADDR> # 將 <ADDR> 換成目標伺服器位址

如同工廠裡早就開機運轉的產線，直接把物料送上既有產線就能開工或續跑。
新功能

終端機新增 /rc 與 /remote 管理遠端控制

人離開電腦桌，想改用另一台裝置遙控本機跑著的對話，該怎麼快速配對？在終端機介面輸入 /rc 或 /remote，就能管理本機的遠端控制功能，並直接顯示裝置配對碼。

像在客廳連接智慧電視一樣，直接在螢幕叫出配對碼。
新功能

/statusline 可自訂與選用 MCP 狀態列

盯著終端機底部看久了，難免想把常用的外部工具資訊也釘在那一排。只要啟用 tui_extensions_statusline，就能用 /statusline 管理底部的資訊欄。 透過這個指令，你可以自由挑選現成樣式，或自己編寫要顯示的 MCP（讓 AI 連接外部工具的協定）狀態列。

拿汽車儀表板來比方，以前出廠給哪幾顆燈號就只能看哪幾顆，現在能自己挑選或組裝想看的小工具欄位擺上去。
新功能

切換或插話調整時不再覆蓋既有進度與權限

在多個任務之間切換、或在對話途中調整方向，原本的設定與寫到一半的內容現在都能穩穩留住。 切換或接續工作階段時，打到一半的草稿、排隊等送出的後續訊息，以及被打斷的輸入都會跟著原本的對話串留存。 把工作目錄換到別的資料夾時，原本設定好的權限設定檔會原封不動保留下來。 上一輪如果延遲送出完成通知，不會再誤把新一輪正在等待確認的權限核准直接取消。 在進行中的這一輪中途插話調整方向時，彙總的變更差異裡依然會保留更早之前的修改。 以前切個對話或改個目錄就得擔心草稿、權限與修改紀錄不見，現在這些進行中的狀態都能完整延續。

問題修復

修正終端機捲動輸入與重繪異常

在終端機裡滑動畫面查看內容，以前可能會碰到捲動時突然多出奇怪字元、輸入區游標亂跳，或沿用舊的終端機尺寸重繪畫面。這些問題已經修好，現在捲動、游標位置與終端機尺寸重繪都會正常運作。

問題修復

修正只發 ID token 的企業版 MCP 登入問題

透過公司帳號驗證身分，有些服務只會核發 ID token（用來確認身分的授權令牌）。由於沒有附上用來續期的 refresh token，以前這種設定會讓企業版 MCP 登入失敗。這個問題已經修好，現在只拿到 ID token 也能正常登入企業版 MCP。

新功能

給自行編譯者：建置工具與 XML 套件更新

這組底層調整主要針對從原始碼自行編譯、或負責打包發布的開發者。 原始碼建置流程與發布工具已經升級到 Rust 1.99.1。 處理 XML（一種常見的標籤式資料格式）的相依套件同步更新，並移除了已經過時的安全公告例外設定。

English

FEATURE

Model Catalogs Add GPT-6.2 Sol and Astra

Open the menu before starting a new conversation, and you will find two new additions. GPT-6.2 Sol and Astra have been added to the model catalogs, with Sol set as the default catalog selection.

Picture a stationery shop putting two new pens on display—previously only older styles sat on the rack, and now there are not only new choices, but one sits right in the handiest default spot.
FEATURE

TUI Workspace Enabled by Default with Side-by-Side Previews

Having to open a separate window to flip through documents while asking AI to edit data often leaves your eyes jumping between several places. Now the TUI (a text-based interface in the terminal) workspace is enabled by default, so you can see a side-by-side layout without switching views. Searchable document previews and image previews appear right next to the main conversation. If a subagent (an assistant that handles parallel work for the main conversation) is running, its full transcript is placed alongside it for easy comparison.

Think of spreading folders across both sides of your desk while organizing a report: instead of flipping through files one by one, your reference docs, images, and side-investigation notes sit right next to your main draft.
FEATURE

Non-Vim Composer Adds Configurable Undo and Redo Shortcuts

You paste a large block of reference material and attach a file while organizing a report, only to slip and delete the entire prompt. Now, as long as you are not in Vim (a keyboard-only editing mode), you can configure undo and redo shortcuts in the prompt composer. When you trigger them, not only is plain text restored, but previously attached files and large pasted blocks also return intact to the input box.

Just like making a collage on a clipboard, if you accidentally sweep away a whole chunk of cut-out text and images, stepping back puts the entire photo and long clipping right back on the table.
FEATURE

codex exec Adds --remote Flag

A Codex service is already running on a remote machine, and you want to dispatch tasks to it from a script. By running the command below, you can connect to an existing app server and start or resume noninteractive sessions (runs that finish after you send a command, without back-and-forth):

codex exec --remote <ADDR> # Replace <ADDR> with the target server address

A factory production line is already up and running—you simply feed materials onto the existing line to start or continue work.
FEATURE

Terminal Adds /rc and /remote to Manage Remote Control

When you step away from your desk and want to use another device to remotely control a conversation running locally, how do you pair quickly? In the terminal interface, enter /rc or /remote to manage local remote control and display device pairing codes directly.

It is like connecting a smart TV in the living room by bringing up the pairing code right on the screen.
FEATURE

/statusline Supports Custom and Selectable MCP Status Lines

After staring at the bottom of the terminal for a while, it is natural to want information from your frequently used external tools pinned right there. Once tui_extensions_statusline is enabled, you can use /statusline to manage the bottom status bar. Through this command, you can pick from ready-made styles or author your own MCP (a protocol that lets AI connect to external tools) status line to display.

Compare it to a car dashboard: before, you could only watch the factory indicator lights, whereas now you can pick or assemble the widget fields you want to display.
FEATURE

Switching or Steering No Longer Overwrites Progress and Permissions

Switching between tasks or adjusting direction mid-conversation now keeps your existing settings and half-written work intact. When switching or resuming sessions, in-progress drafts, queued follow-up messages, and interrupted input stay with their original threads. When changing your working directory to another folder, previously configured permission profiles remain untouched. A late completion notification from a previous turn will no longer mistakenly cancel a pending permission approval for a newer turn. When steering an active turn mid-way, aggregate diffs still preserve earlier edits. Previously, switching conversations or changing directories meant worrying about losing drafts, permissions, and edit history; now these active states carry over intact.

BUGFIX

Fixed Terminal Scrolling Input and Redraw Issues

When scrolling through content in the terminal, you might previously have run into stray characters appearing during scrolling, the composer caret jumping, or the screen redrawing with stale terminal dimensions. These issues are now fixed, so scrolling, caret placement, and terminal-dimension redraws all work properly.

BUGFIX

Fixed Enterprise MCP Sign-In When Only ID Tokens Are Issued

When verifying identity through a company account, some services only issue an ID token (an authorization credential used to verify identity). Because no refresh token was included for renewal, this setup previously caused enterprise MCP sign-in to fail. That issue is now fixed, so enterprise MCP sign-in works normally even when only an ID token is received.

FEATURE

For Source Builders: Build Tooling and XML Package Updates

This set of underlying updates is primarily for developers who build from source or handle packaging and releases. Source build workflows and release tooling have been upgraded to Rust 1.99.1. Dependencies for handling XML (a common tag-based data format) have been updated as well, and obsolete security advisory exceptions have been removed.
