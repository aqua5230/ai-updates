Codex 0.172.0

Released: 2026-11-24

Release notes

FEATURE

Open conversation links directly from search and transcripts

When digging through old transcripts in the terminal, you often see thread links pointing to other conversations. Now you can follow those links from search results or transcripts to open saved conversations directly in the terminal, along with the nested agents (helper programs dispatched underneath by the main task) inside them.

After finding a name in a paper address book, you used to have to open another page and redial the number; now tapping the contact connects the conversation right away.
FEATURE

New terminal shortcuts for argument completion and switching

Typing commands, switching tasks, or picking options in the terminal can now all be driven directly from the keyboard. When typing a supported slash command, press Tab to autocomplete its arguments. For example, typing /mcp lo and pressing Tab completes it to /mcp login. When viewing tasks in the agent command center, use Shift+Up and Shift+Down to jump between different task groups. For long lists whose choices are taller than the terminal's answer area, use PageUp and PageDown to scroll through the options and submit your answer.

FEATURE

Cached optional MCP servers now start on first call

Workflows often attach multiple optional stdio MCP (a protocol that lets AI connect to external tools) servers. As long as those servers already have a cached tool list, they now wait until the first actual tool call to start by default.

Home appliances already have manuals taped to the wall: instead of powering on and preheating every machine the moment you walk in, you wait until you actually need to press a button.
FEATURE

Set approval reviewers for individual app tools

When multiple external services are connected to your account, different items often need different people to review them. You can now set an approval reviewer in config.toml for each individual connected app tool.

When using different equipment at a community sports center, a single front-desk attendant used to sign off on everything, whereas now the weight room and the pool can each have their own dedicated reviewer.
FEATURE

Support for selecting Amazon Bedrock Runtime

Clients running through app-server can select Amazon Bedrock Runtime directly during initial setup or sign-in.

FEATURE

Resumed and cross-OS remote sessions preserve paths and permissions

When picking up a previous task or connecting across operating systems for remote work, the last thing you want is for working paths and permission settings to drift. When running codex exec resume to continue a task, previously saved sandbox (an isolated environment that restricts program access) permissions, the working directory, and workspace roots are automatically restored. Unless explicitly overridden, those settings apply as before. If the client and server run on different operating systems, remote sessions also preserve working directories, workspace roots, and writable paths.

Picture carrying a paintbox to sketch in different cities: you used to have to rearrange your paints and brushes at every stop, but now opening the lid brings back your familiar layout.
FEATURE

Report errors immediately and identify API spend limits reached

While waiting for a model's word-by-word reply, seeing a clear error right away saves you from waiting in vain when something goes wrong. Codex now reports provider errors as soon as they arrive in a response stream (data sent back incrementally as the model generates it). If an API spend limit is reached, it also identifies which limit was hit.

Think of a failed card charge: instead of waiting for the monthly statement to spot the problem, an alert pops up the moment the transaction happens, and if a limit is full, it tells you which card hit it.
FEATURE

Preserve queued child-agent replies when interrupting a parent turn

When you stop a main conversation mid-way, child agents dispatched underneath may still have replies waiting in line. Now, interrupting that parent turn keeps those queued child-agent replies instead of dropping them, carrying them over to the next turn.

During an orchestra rehearsal, when the conductor raises a hand to stop a section, the phrases each voice part was ready to sing next used to be discarded, but now they stay on the music stand for the next beat.
FEATURE

Late cloud replies update in place to keep order

After you open an old conversation and load its history, tasks sent to the cloud earlier may finish right afterward. Those late-arriving cloud replies now update in place at their original position, keeping the terminal transcript in the right order.

Imagine organizing a photo album while a few prints are still being developed: late arrivals used to get stuck onto the last page, whereas now the album reserves their original slots until they come in.
FEATURE

openai-docs adds GPT-6.2 migration guidance

Before switching an existing integration to a new model, you often need to check request formats and configuration details first. Codex's bundled openai-docs skill now covers migrating to GPT-6.2 Astra and Sol, including endpoint (the connection address for calling a model service) choices and tool-calling requirements.

FEATURE

Code Mode Standardizes on gRPC and Deprecates Old Setting

The days of adjusting how Code Mode connects in the configuration file are over. Code Mode now uses gRPC (a common data-transfer protocol) for all host connections, and the original code_mode_host_grpc setting is marked as deprecated.

An old building once kept a toggle for legacy phone lines, and now that every extension has moved to a single digital line, the wall switch has been retired as well.
FEATURE

Python Formatting and SDK Types Verify Package Hashes

This change mainly affects contributors working on the project. When running Python code formatting and generating SDK type definitions, the workflow now checks dependency hashes (digital fingerprints used to confirm whether file contents match) against the repository lockfile.
