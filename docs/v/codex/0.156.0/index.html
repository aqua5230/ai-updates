Codex 0.156.0

發布日期：2026-09-22

繁體中文

新功能

選用 /tui 全螢幕介面，支援搜尋紀錄與滑鼠右鍵複製

全螢幕介面現在是可選的：在 Codex 裡輸入 /tui 做選擇，下次啟動時就會改用全螢幕的操作畫面。

好比走進挑高寬敞的大型閱覽室，桌面上能一口氣展開整份研究卷宗，想找特定段落直接查目錄，還能隨手拿螢光筆圈選重點並按一下印表機複印。

進入全螢幕後，你可以直接用搜尋功能快速翻查過往的對話轉錄紀錄，也能直接用滑鼠游標圈選畫面上的文字，並點擊滑鼠右鍵快速複製內容。

問題修復

語音對話改為預設開啟，附快捷鍵、設定選單與播放修復

雙手忙著寫程式或翻查文件時，開口直接跟 AI 討論變得更自然省事。

就像車載免持對講系統在出廠時就預先安裝好喇叭與麥克風，按下方向盤按鈕就能隨時切換通話，而且遇到播放暫停或語音突然大量湧入時，車機喇叭依然會把每個字完整唸完，絕不漏字。

語音對話現在預設直接開放，Linux 與 Windows 版本也已內建打包好的音訊執行階段，開箱即可運作。你只要按下 F8 鍵就能開關語音對話，或在對話中輸入 /voice settings 開啟選單挑選偏好的語音設定。另外，系統修復了音訊播放暫停或短時間湧入大量語音時容易丟失字句的問題。

新功能

新增 /usage 分析儀表板，用量、token 與外掛活動一目了然

想知道自己的帳號用掉多少額度、哪些外掛與技能最常派上用場？現在只要在終端機輸入 /usage 指令，就能叫出專屬的數據分析總覽。

宛如家庭智慧電表配備的即時數據面板，隨時翻看就能清楚查閱總耗電度數、各個家電插座的用電紀錄與每日用量走勢，不再需要等到月底收帳單才盲猜。

在這個儀表板中，你可以檢視帳號的整體用量，掌握消耗的 token（AI 處理與計費的文字單位）累積總計。同時，介面還會列出各項外掛與技能的呼叫活動紀錄，方便你評估各項擴充工具的運作情形。

新功能

代理人控制中心支援狀態篩選，工作樹建立與支援預設開啟

指揮多個背景代理人處理複雜任務時，追蹤進度與分流目錄變得更加井井有條。

如同專案總監巡視工地的中央調度台，不僅能依據施工狀態分類篩選待辦工單，還能為特定小組直接開啟獨立的隔離施工艙，且這種分流作業規範現在一開工就全面啟用。

在代理人控制中心裡，你可以依照任務狀態快速篩選待辦清單，並直接針對特定任務建立專屬的工作樹（worktree，Git 讓同一專案平行開多份副本的功能）工作階段。同時，工作樹支援在本次更新中改為預設開啟，讓你在開發多條分支時無須額外設定即可直接享受獨立目錄的隔離優勢。

新功能

終端機推出六款新主題配色，支援即時渲染 Mermaid 圖表與數學公式

看膩了預設的黑底白字，或是讀到複雜的流程邏輯只能盯著純文字自行腦補？

好似替客廳換上多種風格的新壁紙與沙發套，而且電視牆還能直接播放流程圖與清楚排版的數學公式看板，不必再把草稿紙翻得眼花撩亂。

這次更新為終端機加入了六款全新主題配色，讓你能自由客製化視覺介面。更棒的是，當 AI 在回覆中給出受支援的 Mermaid 圖表或數學展示公式時，終端機現在能直接在回答中將它們視覺化呈現出來，省去將圖表程式碼複製到外部編輯器才能預覽的麻煩。

新功能

支援 /daemon 指令更新背景伺服器，或用 --no-daemon 完全繞過

想升級在本機默默運作的背景服務，或是想單次乾淨啟動而不依賴常駐程序？

正如給社區中央供水泵補上獨立升級開關，管理員隨時能下令進行設備更新，住戶若想測試自備水塔也能直接切換獨立閥門、完全不經過中央管線。

你現在可以在 Codex 裡輸入 /daemon，直接更新本機的守護行程（daemon，在背景持續運作的常駐服務程式）。如果這次不想經過背景伺服器，只要在啟動命令列加上 --no-daemon 旗標，就會直接繞過它。

新功能

對話中斷或編輯提示詞時，完整保留已生成的答案、計畫與設定

當你請 AI 規劃冗長步驟卻不幸碰上網路瞬斷、手動中斷，或是想回頭修改剛才的提問時，先前的心血不再瞬間歸零。

猶如繪畫師在長卷上作畫，即便畫到一半顏料用盡或臨時被電話打斷，已經勾勒好的底稿與著色計畫依然會穩穩留在畫布上；重新拿起畫筆時能立即接續先前的畫法模式，即使擦改前幾筆線條也不會弄丟整幅畫的圖層標籤與筆刷設定。

系統現在會在回合失敗、遭使用者中斷或接收到子代理完成事件時，妥善保留已經串流產生的回覆內容與執行計畫。當你重新續接工作階段時，先前開啟的 Plan 模式會自動精準還原；而在編輯更早之前的提示詞時，對話串的身分識別與自訂設定也能完整延續。

問題修復

修復 tmux 與 SSH 剪貼簿轉發，貼上文字時保留 Tab 縮排

透過遠端連線或終端機分頁軟體工作時，複製貼上程式碼最怕遇到剪貼簿失效或縮排格式被壓扁。

跟在辦公室使用跨樓層文件輸送管一樣，遠端傳送的文件能精準送達收件匣，而且就算遇到老舊傳送機把整疊報表拆成單頁逐張送出，系統依然會依照原本的格線與分欄標記工整排好，絕不讓表格欄位錯位。

這次更新修正了在 tmux 與 SSH 工作階段中剪貼簿無法正確轉發的問題。同時，當某些終端機將貼上的大段文字拆成個別按鍵訊號逐一送出時，Codex 現在也能完整保留原始的 Tab 縮排格式，不再將排版打亂成純文字。

問題修復

支援透過系統代理伺服器復原登入，修復 MCP 憑證 503 重新整理

公司網路規定所有連線都得先繞經代理時，Codex 的登入以前容易卡在半路。

彷彿外賓進園區規定要走公司的接待櫃台，以前走這條路常被擋在門外，現在能照常換證進門；遇到換證窗口回「忙線中」時，櫃台也會主動幫你重換一張有效的通行證，不再讓你在門口枯等。

Codex 現在能透過系統代理伺服器順利復原登入工作階段，確保特殊網路架構下的認證暢通。此外，當外部伺服器的 OAuth 身分探索回傳 503 服務暫時無法使用錯誤時，系統會自動重新整理 MCP（Model Context Protocol，讓 AI 連接外部工具的協定）的授權憑證，提升外部工具連線的穩定度。

問題修復

修補沙盒隔離漏洞，防堵連線穿透、特權通訊端與檔案寫入

讓 AI 在受限環境中測試未知腳本時，環境隔離的防護邊界現在更加固若金湯。

類似給金庫隔離艙加裝多重防護閥，既封鎖了外部未經許可的傳入管線，又切斷了內部程式暗中調用高特權通訊通道的可能，並嚴格鎖死唯讀公文櫃的鎖扣、防止任何人偷偷提筆篡改。

這次更新修補了沙盒（sandbox，隔離程式執行權限的保護環境）的數項隔離漏洞：堵住了涉及 Windows 傳入連線的漏洞、阻斷了 Linux 與 macOS 上存取特權通訊端的管道，並徹底禁止透過 macOS 唯讀檔案控制代碼進行寫入操作。

新功能

淘汰舊版個性設定，釐清代理規則萬用字元並升級 TLS 套件

這批更新收攏了幾項設定規則、網路比對與底層套件的規格細節。

官方明確釐清先前已標記為棄用的 friendly 與 pragmatic 個性設定，現在已不再對 AI 的回覆語氣風格產生任何影響。在網路代理的允許與拒絕比對規則中，規則說明補上了問號 ? 代表匹配單一字元的定義，方便你寫出更精確的代理規則。同時，系統打包的 TLS 安全傳輸相依套件也完成升級，包含為 Linux musl 建置版本納入了 OpenSSL 3.6.4。以前如果對代理規則語法不確定或受限於舊版通訊套件，現在規則寫得清楚，打包的套件也更新到新版。

English

FEATURE

Choose the optional /tui fullscreen UI with transcript search and right-click copying

The fullscreen interface is now optional: enter /tui in Codex to select it, and your next launch will switch to a fullscreen operational display.

Picture stepping into a spacious reading hall where you can spread out an entire research dossier across the desk, look up specific passages directly in the index, highlight key notes with a marker, and make instant copies on a printer.

Once in fullscreen mode, you can quickly search through past conversation transcripts, select text on screen directly with your mouse cursor, and right-click to copy content quickly.

BUGFIX

Voice conversations are enabled by default with shortcuts, a settings menu, and playback fixes

Speaking directly with AI becomes much more natural when your hands are busy writing code or looking through documentation.

Much like a factory-installed hands-free car intercom with built-in speakers and microphones, you can toggle calls from the steering wheel, and the car speakers read out every word completely without dropping speech even during pauses or sudden bursts of incoming audio.

Voice conversations are now enabled by default, and Linux and Windows builds bundle pre-packaged audio runtimes that work out of the box. Simply press F8 to toggle voice conversations, or type /voice settings in a conversation to open a menu and choose your preferred voice options. In addition, the system fixes an issue where speech was dropped during playback pauses or bursts of incoming audio.

FEATURE

Add /usage analytics dashboard to track consumption, token totals, and plugin activity

Want to know how much quota your account has used or which plugins and skills are called most often? Now you can simply enter the /usage command in the terminal to bring up a dedicated analytics overview.

Think of a smart home electricity meter equipped with a live dashboard that lets you check total kilowatt-hours, monitor power usage across individual appliance outlets, and track daily consumption trends instead of guessing before the bill arrives at the end of the month.

In this dashboard, you can view your overall account usage and track cumulative token totals. The interface also lists invocation activity across plugins and skills, making it easy to evaluate how your extensions are performing.

FEATURE

Agent command center supports status filtering, with worktree creation and support enabled by default

Tracking progress and compartmentalizing directories becomes far more organized when directing multiple background agents on complex tasks.

A project director inspecting a site from a central dispatch console can filter pending work orders by construction status and spin up dedicated, isolated work bays for specific crews, with this compartmentalized workflow now active right from the start.

In the agent command center, you can quickly filter tasks by status and create dedicated worktree sessions for specific assignments. Meanwhile, worktree support is enabled by default in this update, letting you enjoy the isolation benefits of independent directories across multiple branches without extra configuration.

FEATURE

Terminal introduces six new themes, supporting direct rendering of Mermaid diagrams and math equations

Tired of the default black-and-white terminal or struggling to visualize complex process logic from plain text?

Imagine refitting a living room with new wallpapers and sofa covers while the media wall renders flowcharts and neatly formatted math equations directly on screen, sparing you from flipping through messy scratch paper.

This update adds six brand-new color themes to the terminal, allowing you to freely customize your visual interface. Even better, when AI provides supported Mermaid diagrams or display equations in its responses, the terminal can now render them visually right in the output, eliminating the hassle of copying diagram code into external editors just to preview it.

FEATURE

Support /daemon command to update background server or bypass it completely with --no-daemon

Need to upgrade a background service running quietly on your local machine, or prefer a clean one-off launch without relying on a resident process?

Just as a community water pump receives a dedicated upgrade switch so managers can trigger equipment updates at any time, residents can also turn an independent valve to test their own water tank without routing through central pipes.

You can now use /daemon inside Codex to update the local daemon. If you would rather not go through the background server this time, add the --no-daemon flag when launching and it is bypassed.

FEATURE

Preserve streamed answers, plans, and settings when conversations are interrupted or prompts are edited

When you ask AI to plan complex multi-step tasks and run into network dropouts, manual interruptions, or simply want to edit a previous prompt, your earlier progress is no longer lost.

When an artist paints on a long scroll, the sketched drafts and coloring plans remain firmly on canvas even if the paint runs out or a phone call interrupts mid-stroke; picking up the brush immediately restores the previous painting mode, and erasing earlier strokes never loses the layer tags or brush settings.

The system now preserves streamed responses and execution plans when turns fail, are interrupted by the user, or receive subagent completion events. When you resume a session, previously activated Plan mode is restored accurately, and editing earlier prompts preserves thread identity and custom settings.

BUGFIX

Fix clipboard forwarding in tmux and SSH, preserving Tab indentation on pasted text

When working over remote connections or terminal multiplexers, copying and pasting code often risks broken clipboards or flattened indentations.

Operating like a multi-floor document pneumatic tube system in an office, remotely dispatched files arrive accurately in the inbox, and even if an aging feeder sends a report sheet by sheet, the system arranges them neatly along original gridlines and column markers without misaligned columns.

This update fixes clipboard forwarding failures in tmux and SSH sessions. Additionally, when certain terminals send pasted text as individual keystrokes, Codex now preserves the original Tab indentation format rather than scrambling it into plain unformatted text.

FEATURE

Recover login through system proxies and refresh MCP credentials on 503 errors

On corporate networks that route every connection through a proxy, Codex sign-in used to get stuck halfway.

Picture a visitor who has to enter a campus through the company reception desk: that route used to leave them stuck outside, and now it gets them in; when the badge office answers "line busy", the desk now fetches a fresh pass instead of leaving them waiting at the door.

Codex can now recover login sessions smoothly through system proxies, so sign-in works on networks that route traffic through a proxy. Furthermore, when OAuth identity discovery returns a 503 Service Unavailable error from an external server, the system automatically refreshes MCP (Model Context Protocol) authorization credentials, improving connection stability for external tools.

FEATURE

Patch sandbox isolation gaps to block inbound connections, privileged sockets, and file writes

When having AI test unknown scripts in restricted environments, the protective perimeter of environmental isolation is now significantly tighter.

Installing multiple protective valves on a vault isolation chamber blocks unauthorized inbound pipelines, cuts off covert attempts by internal programs to access privileged communication channels, and firmly locks read-only document cabinets to prevent illicit alterations.

This update patches several isolation gaps in the sandbox: it closes a gap involving inbound connections on Windows, shuts down avenues for accessing privileged sockets on Linux and macOS, and strictly prohibits write operations through read-only macOS file handles.

FEATURE

Retire legacy personality settings, clarify proxy wildcard rules, and upgrade TLS dependencies

This batch of updates consolidates specification details across configuration rules, network matching, and underlying packages.

The release explicitly clarifies that the previously deprecated friendly and pragmatic personality settings no longer have any effect on AI response style. In network proxy allow and deny matching rules, the documentation now explains that the question mark ? matches a single character, helping you write more precise proxy rules. Meanwhile, bundled TLS security dependencies have been upgraded, including OpenSSL 3.6.4 for Linux musl builds. If you were previously uncertain about proxy rule syntax or constrained by older communication packages, the rules are now spelled out and the bundled secure-connection libraries are up to date.
