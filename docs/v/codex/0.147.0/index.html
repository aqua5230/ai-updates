zh-TW

外掛帶著走，失手時先斷網

你換電腦或加入新工作區時，現在能安裝可攜式 Agent Plugins（代理外掛，替 Codex 加上工作能力的小工具），也能在本機、個人、工作區和遠端目錄找它們。像一只可攜式工具箱：工具可在不同工具櫃找到；若封條檢查失敗，箱子就先不接外部管線。安全邊界也加厚了：外掛會被更嚴格隔離；如果更新安全政策失敗，Codex 會拒絕網路連線。

把長對話分冊收藏，匯入內容不重複

一串對話越聊越長，找上週那段決定常像翻亂掉的筆記本。現在可把 conversations（對話）放進會保留的區段，自己調整順序；很長的逐字稿則分段載入，不必一次塞滿畫面。另一頭，Cursor 管理的 skills（技能，教 AI 做特定工作的說明）可以匯入，已匯入的 Claude 和 Cursor 對話也會同步變更而不複製出兩份。像替筆記貼標籤、逐頁翻閱，再把兩本筆記對齊同一頁。

把核准交給審核，陌生專案先問清楚

你在命令列跑重複任務時，可用新的 --approve-for-me CLI flag（命令列旗標，附在指令後的開關）開啟自動審核過的核准，不必每一步都手動按許可。但新本機專案不是直接放行：Codex 會要求你明確信任，並在使用 credentials（登入憑證，證明身分的資料）前套用受管理的登入限制。像把常用包裹交給通過規則的收件櫃；沒有寄件人資訊的新包裹，仍要你親自簽收。

MCP 換了新規格，找工具不再堵車

你叫 Codex 接上外部服務時，MCP（Model Context Protocol，讓 AI 連接外部工具的協定）現在可選用 2026-07-28 版規格。它支援分頁探索：工具清單很長時分批拿，不必整包搬進來；也能多輪請求，並讓伺服器在背景慢慢啟動而不堵住其他工作。這像餐廳不再把整本菜單塞到你手上，先翻一頁、再點下一輪；廚房備料時，桌邊對話照樣繼續。

Bedrock 查過的網頁先暫存，對話也能遠端壓縮

用 Amazon Bedrock 跑 Codex 時，重看剛查過的網頁不必每次從頭取資料。網路搜尋可使用快取（把查過的結果暫存起來直接用），對話也支援遠端壓縮：把過長的對話收成較短的上下文，交給遠端處理。像旅行筆記本：查過的地圖頁先收在夾層，需要時直接翻回；內容太多時把舊頁整理成摘要，旅程仍接得上。原本的問題和最近脈絡仍會留在眼前。

螢幕上的密碼和令牌，先遮住再重播

你把命令貼到螢幕分享或回頭翻對話時，最怕登入資料跟著露出來。Codex 現在會從顯示的命令和重播的對話歷史遮蔽 secrets（機密資料，例如密碼）與完整的 bearer tokens（持有人令牌，拿到就能通行的授權令牌）。像銀行對帳單把帳號中段塗黑：你仍看得出是哪筆操作，旁人卻不能拿那串字直接冒用。它遮的是畫面與重播內容，不是替你撤銷已經外流的憑證。

游標回來後，終端機不再吞掉你剛打的字

切回終端機正要補一個指令，字卻消失或卡著不動，往往不是你手快按錯。這版修正三種會弄丟或堵住輸入的時刻：視窗重新取得焦點、MCP 伺服器初始化，以及 Ghostty 處理鍵盤快捷鍵時。像接線員剛回到座位、後台正開機、同事按下內線鍵的同時，電話還是會接進來，不會把你剛說的第一句丟掉。中斷工作再回來，也不必先猜剛才那行有沒有送出。

日文、表情和連結，游標終於站對位置

你在終端機看日文、emoji 或超連結時，游標有時像踩錯格子，文字也可能在畫面邊緣歪掉。這版修正日文字元、emoji、hyperlinks（超連結，點了會跳到其他位置的文字）以及靠近 viewport boundaries（可視畫面邊界）的文字顯示和游標位置。它像方格紙的尺終於認得寬字和窄字：走到紙張邊緣前會量好，不把下一格畫到紙外。

Windows 背景程序叫得停，路徑也不再認錯門牌

在 Windows 上叫停背景程序時，Codex 現在會正確中斷它，不必等它自己收工。Windows filesystem paths（檔案系統路徑，像檔案地址的寫法）也會一致處理，避免同一個資料夾因為路徑格式不同而找錯地方。這像工地的總開關終於接到每台機器，也把每條巷弄的門牌統一寫清楚：該停的能停，要找的門不會繞到隔壁去。

內建 OpenAI 文件助手，少繞一圈找官方答案

你想確認 Codex 怎麼用、該選哪個模型，或 API workflow（API 工作流程，程式如何呼叫服務的一連串步驟）要怎麼接，現在內建的 OpenAI documentation skill（文件技能，協助查找官方說明的工具）會更有針對性地查官方來源，並給更清楚的指引。它像圖書館員先聽懂你要找的是使用說明、型號比較還是接線圖，再帶你到正確書架，而不是把整棟館藏推來。

底層零件升級，簽章鑰匙不再帶出保險庫

這版也換了幾個底層零件：MCP SDK 升至 3.0.0、Ratatui 升至 0.30.2、V8 升至 150.4.0。macOS 發行版的 notarization（公證，讓系統確認軟體來源可信的簽章程序）則改用 Azure Key Vault 保護，不再匯出私密簽章金鑰。Linux 也不再發佈重複的 bundle archives（套裝壓縮檔），改用標準 codex-package-<target> 檔案。像工廠更新生產線：設備換新，簽章用的印章留在廠內保管櫃，出貨也統一走一種箱規。

舊的全自動旗標退場，改用工作區沙盒

若你的腳本還寫著 codex exec --full-auto，這版起它已被移除。改用 --sandbox workspace-write：sandbox（沙盒，限制程式可碰範圍的隔離區）把可寫入範圍限在工作區。像舊鑰匙已停用，改領一把只能開辦公室的卡；你仍能在專案內工作，但卡片清楚標示能到哪裡。更新自動化指令時，直接把舊旗標換成新參數。

An unfamiliar local project does not get that treatment: Codex asks for explicit trust and applies managed authentication restrictions before using credentials. Keeping terminal keystrokes from getting lost

Stopping Windows background work and reading its paths correctly

A sharper built-in guide to OpenAI docs

When you need to check how Codex works, choose a model, or connect an API workflow, the bundled OpenAI documentation skill now performs more targeted official-source lookup and gives clearer guidance. Updated internals and signing keys kept in the vault

Several internal parts move forward in this release: MCP SDK 3.0.0, Ratatui 0.30.2, and V8 150.4.0. macOS release notarization now uses Azure Key Vault rather than exporting private signing keys. Linux also stops publishing redundant bundle archives and uses the standard codex-package-<target> archives. Think of updating a factory production line: the equipment is replaced, the signing seal stays in a storage cabinet at the factory, and every shipment uses one box standard.

The old full-auto flag exits; workspace sandboxing replaces it

If a script still says codex exec --full-auto, that flag has been removed. Use --sandbox workspace-write instead. A sandbox limits where a program may act; this setting limits writes to the workspace. It is like retiring an old master key and issuing a card that opens the office only. When updating automation, replace the old flag with the new argument.

画面共有や会話の再生で、ログイン情報まで見えてしまうのは困る。Codex は表示するコマンドと再生する会話履歴から secrets と完全な bearer token を伏せるようになった。明細の口座番号の中央を塗りつぶすようなもので、操作は見分けられても、その文字列を他人が使うことはできない。守るのは表示と再生であり、すでに漏れた認証情報を取り消す機能ではない。

戻った直後のキー入力を端末が取りこぼさない

端末へ戻ってコマンドを補おうとしたのに、打った文字が消えたり止まったりすることがあった。この版は、ウィンドウにフォーカスが戻る時、MCP サーバーの初期化時、Ghostty がキーボードショートカットを処理する時の入力取りこぼしや停止を直す。交換手が席に戻る時や裏方が起動中でも、電話の最初の一言を落とさないようなものだ。

日本語や絵文字のそばでも、カーソルが正しい場所に立つ

端末で日本語、絵文字、ハイパーリンクを見ると、カーソルが一つずれたり、画面端で文字が乱れたりすることがあった。この版はそれらの表示とカーソル位置、さらに表示領域の端に近い文字を正しく扱う。方眼紙の定規が幅の広い字と狭い字を見分け、紙の端の前で長さを測るような修正である。

Windows の裏方プロセスを止め、パスも正しく読む

Windows でバックグラウンドのプロセスを止める指示が、正しく中断として届くようになった。Windows のファイルシステムパスも一貫して扱うため、同じフォルダを表記の違いで取り違えにくい。非常停止のスイッチが全ての機械につながり、路地の番地もそろえて書き直すようなものである。

OpenAI 文書を狙って探せる内蔵ガイド

Codex の使い方、モデル選び、API ワークフローのつなぎ方を確かめたい時、同梱の OpenAI 文書 skill が公式情報をより狙って探し、分かりやすく案内する。司書が説明書、機種比較、配線図のどれを求めているか先に聞き、正しい棚へ連れていくようなものである。

内部部品を更新し、署名鍵は金庫から持ち出さない

この版では内部部品も更新された。MCP SDK は 3.0.0、Ratatui は 0.30.2、V8 は 150.4.0 である。macOS のリリース公証は秘密署名鍵を外へ出さず、Azure Key Vault を使う。Linux は重複したバンドルアーカイブの公開をやめ、標準の codex-package-<target> を使う。工場の生産ラインを更新するようなものだ。設備を入れ替え、署名用の印章は工場内の保管棚に置き、出荷も一種類の箱の規格に統一する。

旧 full-auto フラグをやめ、ワークスペースのサンドボックスへ

スクリプトに codex exec --full-auto が残っているなら、この版から使えない。代わりに --sandbox workspace-write を使う。sandbox はプログラムが触れられる範囲を隔てる仕組みで、この指定では書き込み先をワークスペースに限る。古い万能鍵を止め、事務所だけ開くカードへ替えるようなものである。自動化を更新する時は古いフラグをこの引数へ置き換える。

들고 다니는 플러그인과 실패 시 차단

다른 컴퓨터나 작업 공간으로 옮겨도 추가 기능을 다시 찾느라 헤맬 일이 줄어든다. 휴대 가능한 Agent Plugins를 설치하고 로컬, 개인, 작업 공간, 원격 카탈로그에서 찾을 수 있다. 휴대용 공구 상자와 같다. 도구는 서로 다른 공구함에서 찾을 수 있고, 봉인 검사가 실패하면 상자는 외부 회선에 연결하지 않는다. 플러그인 격리도 더 엄격해졌고, 정책 갱신에 실패하면 네트워크 접속을 거부한다.

긴 대화를 칸에 나누고 중복 없이 가져오기

몇 주째 이어진 대화에서 결정 하나를 찾는 일은 뒤섞인 공책을 넘기는 것과 같았다. 이제 대화를 계속 남는 구역에 넣고 순서를 직접 정할 수 있으며, 긴 기록은 조금씩 읽는다. Cursor가 관리하는 skills도 가져올 수 있고, 가져온 Claude와 Cursor 대화의 변경은 사본을 만들지 않고 동기화된다. 공책에 꼬리표를 붙이고 필요한 쪽만 펼친 뒤 두 권을 같은 쪽에 맞추는 느낌이다.

검토된 승인과 낯선 프로젝트 앞의 멈춤

반복하는 명령줄 작업에서는 새 --approve-for-me 플래그로 자동 검토된 승인을 쓸 수 있어 매 단계에서 클릭으로 멈추지 않는다. 다만 낯선 로컬 프로젝트는 바로 통과하지 못한다. Codex는 명시적인 신뢰를 요구하고 자격 증명을 쓰기 전에 관리되는 인증 제한을 적용한다. 조건에 맞는 소포만 받는 무인 보관함과, 출처가 불분명한 상자에는 서명을 요구하는 접수대의 조합이다.

새 MCP 규격으로 도구 찾기의 정체 줄이기

Codex를 외부 서비스에 연결할 때 2026-07-28판 MCP 프로토콜을 선택할 수 있다. 긴 도구 목록은 쪽마다 찾아보고, 요청은 여러 차례에 걸쳐 보낼 수 있으며, 서버는 다른 일을 막지 않고 뒤에서 시작한다. 두꺼운 메뉴를 한꺼번에 받지 않고 한 쪽씩 보며 주방이 준비하는 동안 다음 주문을 넣는 것과 같다.

Bedrock의 검색 결과 보관과 원격 대화 압축

Amazon Bedrock으로 Codex를 쓸 때 웹 검색 결과를 캐시에 보관해 다시 쓸 수 있고, 긴 대화는 원격에서 짧은 문맥으로 압축할 수 있다. 여행 노트와 같다. 확인한 지도 페이지는 주머니에 넣어 필요할 때 바로 다시 펼치고, 내용이 너무 많으면 오래된 페이지를 요약으로 정리해도 여행은 이어진다.

명령을 다시 보여 주기 전 비밀과 토큰 가리기

화면 공유나 대화 다시 보기에서 로그인 정보까지 보이면 곤란하다. Codex는 표시하는 명령과 다시 재생하는 대화 기록에서 secrets와 완전한 bearer token을 가린다. 거래 내역의 계좌 번호 가운데를 검게 칠하는 것과 같아서, 어떤 작업인지는 알아봐도 다른 사람이 그 문자열을 재사용할 수 없다. 이미 다른 곳으로 새어 나간 자격 증명을 취소하는 기능은 아니다.

다시 초점을 받을 때 터미널 입력을 놓치지 않기

터미널로 돌아와 명령을 마저 쓰려는데 방금 친 글자가 사라지거나 멈추는 일이 있었다. 이 판은 창이 다시 초점을 받을 때, MCP 서버가 초기화될 때, Ghostty가 키보드 바로 가기를 처리할 때 입력이 사라지거나 막히는 문제를 고친다. 교환원이 자리에 막 돌아왔거나 뒷방이 켜지는 중이어도 전화 첫마디를 놓치지 않는 것과 같다.

일본어와 이모지 곁에서도 커서가 제자리를 찾기

터미널에서 일본어, 이모지, 하이퍼링크를 보면 커서가 한 칸 어긋나거나 화면 가장자리에서 글자가 흐트러질 때가 있었다. 이 판은 이들의 표시와 커서 위치, 그리고 보이는 화면 끝 가까이의 글자를 바로잡는다. 모눈종이의 자가 넓은 글자와 좁은 글자를 구분하고 종이 끝 전에 길이를 재는 것과 같은 수정이다.

Windows 백그라운드 작업을 멈추고 경로도 바르게 읽기

Windows에서 백그라운드 프로세스를 멈추라고 하면 이제 스스로 끝날 때까지 기다리지 않고 제대로 중단한다. Windows 파일 시스템 경로도 일관되게 다뤄 같은 폴더를 다른 주소 표기 때문에 잘못 찾는 일을 줄인다. 비상 정지 스위치를 모든 기계에 연결하고 골목의 번지를 통일해 적는 것과 같다.

OpenAI 문서를 겨냥해 찾는 내장 안내

Codex 사용법, 모델 선택, API 작업 흐름 연결을 확인하고 싶을 때 내장 OpenAI 문서 skill이 공식 자료를 더 겨냥해 찾고 안내를 더 분명하게 한다. 사서가 설명서, 모델 비교, 배선도 중 무엇이 필요한지 먼저 듣고 맞는 서가로 데려가는 것과 같다.

내부 부품을 올리고 서명 키는 금고에 둔다

이 판은 내부 부품도 올렸다. MCP SDK는 3.0.0, Ratatui는 0.30.2, V8은 150.4.0이 되었다. macOS 배포 공증은 개인 서명 키를 밖으로 내보내지 않고 Azure Key Vault를 쓴다. Linux는 겹치는 묶음 압축 파일을 더 내놓지 않고 표준 codex-package-<target> 압축 파일을 쓴다. 공장 생산 라인을 업데이트하는 것과 같다. 설비를 새로 바꾸고, 서명용 도장은 공장 안 보관함에 두며, 출고도 한 종류의 상자 규격으로 통일한다.

옛 full-auto 플래그를 빼고 작업 공간 샌드박스로

스크립트에 codex exec --full-auto가 남아 있다면 이 판부터는 쓸 수 없다. 대신 --sandbox workspace-write를 쓴다. sandbox는 프로그램이 손댈 수 있는 범위를 가두는 장치이며, 이 지정은 쓰기 위치를 작업 공간으로 제한한다. 낡은 만능 열쇠를 없애고 사무실만 여는 카드를 받는 것과 같다. 자동화 명령을 고칠 때 옛 플래그를 새 인수로 바꾸면 된다.
