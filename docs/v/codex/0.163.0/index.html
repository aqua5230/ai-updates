Codex 0.163.0

發布日期：2026-10-15

繁體中文

新功能

/config 支援跨類別搜尋設定，即時修改並提示重啟

當你想調整 Codex 的各項參數，卻記不清具體設定名稱藏在哪個分類時，現在直接輸入 /config 就能解決。

彷彿走進大型量販店使用智慧導覽機，以前要一層層貨架慢慢找商品，現在直接搜尋關鍵字就能立刻取貨，機器還會貼心提醒哪些生鮮結帳後必須馬上冷藏。

輸入 /config 後，你可以跨越不同分類快速搜尋偏好設定，支援的選項能當場修改；哪些變更需要重啟，介面也會清楚標示，不必再自己猜測設定是否需要重啟。

新功能

生成中途可即時追問轉向，中斷時同步停止程式碼與工具呼叫

看著 AI 劈頭往錯誤的方向洋洋灑灑寫下去，你不用再乾等它講完廢話才能打字糾正。

好比教練在場邊即時對球員大喊變更戰術，以前只能眼睜睜看著整套戰術打完才能檢討，現在哨音一響場上球員立刻改變跑位，正在熱身準備上場的替補球員也會全部停下動作。

Codex 正在回答的當下，你可以隨時送出後續追問來即時引導思考方向。如果你決定中斷這次回應，正在執行的 Code Mode（逐格執行程式碼的模式）儲存格會立刻停止，連同其巢狀工具呼叫也一併結束，避免背景程序白白空轉。

新功能

/keymap 支援自訂前導鍵，快捷鍵提示常駐且語音靜音改為 F9

習慣用鍵盤快速叫出各種操作的讀者，現在調整自訂按鍵更加得心應手。

如同樂團指揮設定了預備拍，以前比劃動作稍縱即逝容易漏看，現在提示手勢會穩穩停在空中等你接招，也把靜音操作換到另一個指定琴鍵。

在 /keymap 設定中，你可以自由配置前導鍵（按下一組按鍵後等待後續指令的引導鍵），系統預設組合為 Ctrl+X。按下後跳出的快捷鍵提示會持續停留在畫面上，直到你做出選擇或取消為止。語音靜音功能則移到了 F9 按鍵。

新功能

/daemon 支援重啟背景伺服器，中斷前主動警告並自動重連

當背景執行的伺服器連線卡住或需要重載時，你不必再大費周章手動終止處理程序。

就像大樓總電源維護前廣播通知，以前電閘一拉整棟直接斷電，現在管理員會先警告哪些電梯與設備即將暫停，重啟完畢後還會自動幫大家把照明重新接通。

現在從 /daemon 指令就能直接重啟受管的背景伺服器（常駐在系統底層默默運作的背景程序）。重啟前，Codex 會先跳出警告，提醒這次重啟可能會中斷哪些進行中的工作。確認執行後，系統會在伺服器重啟完成時自動重新連線，省去手動重連的繁瑣步驟。

新功能

唯讀工具支援平行執行，技能、記憶與對話紀錄查詢不再排隊

提問時需要 AI 同時調閱多項過往資訊的讀者，現在能感受到明顯更快的查詢反應。

跟圖書館調派多位館員同時分頭找書一樣，以前一個人要先找完歷史檔案才能去翻閱典藏技能，現在三位館員各自朝不同書架出發，找齊資料後一口氣交到你手上。

Codex 現在能夠平行（同時多工處理而不依序等待）執行彼此互不干擾的獨立唯讀工具。這項機制涵蓋了擴充技能檢索、記憶調閱，以及對話歷史紀錄查詢。這些互不衝突的讀取工作現在能同步展開，縮短等待回答的時間。

新功能

Daybreak 模型對合格帳號預設啟用，codex exec 支援金鑰指定選用

想體驗最新 Daybreak 模型的讀者，只要帳號符合資格，打開程式就能直接用上。

宛若高鐵會員自動升級商務車廂，以前必須特地到櫃檯出示證件申請，現在符合條件的旅客刷票進站就能直接入座，在自動售票機輸入個人憑證也能順利劃位。

針對符合資格的帳號，Codex 現已預設啟用 Daybreak 模型。如果你習慣使用終端機指令 codex exec 執行任務，在伺服器提供存取權限的前提下，只要附上 OpenAI API 金鑰（存取雲端服務的通關密鑰），也能透過該指令自由選用 Daybreak 模型。

新功能

對話串切換支援 /side 回到分支，重啟時完整恢復授權與網路許可

頻繁在多個任務之間切換對話串（在同一專案中分頭進行的獨立對話紀錄）的讀者，現在不用擔心進度與設定跑位。

有如在辦公室借調多份專案公文，以前換個案子審核印章就得重新蓋過，現在換回舊案能直接調閱已批准的用印紀錄，派出去的公文回函也會精準送回當初發文的專案夾。

切換對話串後，你可以隨時輸入 /side 指令回到先前的旁支對話。如果切換前有尚未回覆完畢的提示詞，產生的答案也會準確送回當初提問的對話串。當你重新打開已保存的對話串時，先前擁有的權限與網路存取許可都會完整還原，同時依然遵守手動覆寫與現行的管理政策。

新功能

網路代理加強防護：DNS 查詢前先審核、阻擋重複標頭與憑證別名繞過

在需要透過代理伺服器連接外部網路的環境中，這項更新替連線安全築起了更嚴格的防線。

猶如機場海關加強查驗流程，以前旅客報出目的地前不會先核驗護照，現在查驗官在查詢航線前就先確認出境許可，嚴查重複填寫的申報表，也不再讓換了別名的違禁證件繞過檢查站。

網路代理現在會在發起網域名稱查詢（將網址轉譯為伺服器位址的查詢）前，先行檢查該連線是否具備相應權限。代理伺服器也會主動拒絕帶有重複 Host 標頭的請求，並防止憑證別名繞過檢查掛鉤（特定事件發生時被觸發的小程式），杜絕未經授權的潛在連線漏洞。

問題修復

Windows 支援快捷鍵貼圖，WSL 剪貼簿重複讀取並防止複製卡死

在 Windows 或 WSL（Windows 系統內建的 Linux 子系統）環境下操作終端機的讀者，剪貼內容時將順暢許多。

恰似換了一組靈敏的櫃檯讀卡機，兩組指定快捷鍵都能把文字與圖片直接貼進視窗；頻繁讀取時能共用讀取模組，複製操作也會逾時退出，不再一直卡住。

在 Windows 中，Ctrl+V 與 Shift+Insert 現在都能貼上文字與圖片。而在 WSL 環境下，連續多次貼上會重複使用剪貼簿讀取器；複製操作在遇到阻礙時則會逾時退出，不再無休止地卡死畫面。

問題修復

指令輸出修復：本地與遠端傳輸更穩，codex exec 不再重複印出差異

經常在終端機執行本機指令或遠端遙控工作的讀者，這次更新修復了多項令指令卡住或資訊混亂的輸出問題。

宛如貨運物流中心整頓了出貨流程，以前只要下游包裝箱還沒封口，送貨司機就算卸完貨也只能在原地枯等，現在確認卸貨完成就能迅速出發，晚到的包裹也能妥善入庫而不被遺漏。

以前執行本機指令時，只要底層的子行程（由主程式衍生出來獨立處理任務的分支程式）沒有關閉輸出管道，整個指令就會乾等而不肯結束。現在本地指令在工作完成後能迅速結束。執行遠端指令時，晚到的輸出內容現在會妥善保留，確保最後一次輪詢時依然能完整收集。使用 codex exec 執行無關指令後，終端機也不會再重複印出先前的檔案差異清單。

新功能

隨附技術文件更新：收錄 GPT-6 遷移指引與 Linux 沙箱架構說明

正在規劃將專案升級至新世代模型，或關注系統底層安全防護的讀者，現在能從隨附文件中查閱更詳盡的官方指南。

正如工廠設備手冊換上新版擴建指南，不僅詳細列出升級新型機具時的運轉特性與資料所在地考量，也公開了安全防護罩如何隔絕危險區域並過濾高壓氣流。

隨附的 OpenAI 文件已更新針對 GPT-6 系列模型的遷移指引，詳細說明了各模型特定的推理特性、外部工具使用方式，以及資料駐留（資料儲存與處理的地理位置）相關考量。隨附說明也進一步釐清了 Linux 沙箱機制的運作方式，詳細介紹系統如何透過 bubblewrap 達成檔案系統隔離，並藉由 seccomp 進行系統呼叫過濾。

新功能

安裝包體積縮減，改用 Codex 的標準 shell 執行器並提示設定遷移

在 Linux 與 macOS 環境下安裝或更新 Codex 的讀者，這次會發現下載更輕盈且底層執行器更單純。

與出差輕裝上陣的概念相同，以前行李箱裡硬塞了一整套自備工具組，現在改用原有的標準工具，並把非必要的裝飾吊牌全數卸下，讓行李箱體積與重量減輕不少。

官方透過從安裝二進位檔中剝除符號（除錯用的內部名稱標籤），縮減了 Linux 與 macOS 版本的安裝套件體積，原始建置產物則依然保留完整符號。在執行架構上，Codex 現在改用 Codex 的標準 shell 執行器（負責執行命令的工具），不再隨附修補版的 zsh。如果既有設定仍包含已淘汰的 shell 標記，系統會跳出遷移通知協助你平順過渡。

English

FEATURE

/config Supports Cross-Category Setting Search, Instant Edits, and Restart Prompts

When you want to adjust parameters in Codex but cannot recall which category a specific setting is tucked under, typing /config now solves the problem immediately.

Picture using a smart kiosk in a large wholesale store: previously you had to browse through aisle after aisle of shelves to find an item, but now searching by keyword lets you pick it up immediately, and the machine even helpfully reminds you which perishables must be refrigerated right after checkout.

After entering /config, you can quickly search for preferences across different categories, and supported options can be modified on the spot. The interface also clearly indicates which changes require a restart, sparing you from guessing whether a setting demands one.

FEATURE

Steer Generations Mid-Stream with Follow-Up Prompts, Halting Code and Tool Calls on Interrupt

Watching the AI dash off in the wrong direction with paragraph after paragraph, you no longer have to wait idly until it finishes before typing a correction.

Think of a coach shouting tactical changes from the sidelines to players in real time: previously you had to watch the entire play run its course before reviewing it, but now players shift positions the moment the whistle blows, while bench substitutes warming up to enter the game halt their movements as well.

While Codex is in the middle of responding, you can send follow-up prompts at any time to steer its train of thought on the fly. If you decide to interrupt the response, currently executing Code Mode (a mode that executes code cell by cell) cells stop immediately, and their nested tool calls are terminated alongside them, preventing background processes from spinning in vain.

FEATURE

/keymap Supports Custom Leader Keys, Sticky Shortcut Prompts, and Moves Voice Mute to F9

Readers accustomed to invoking operations swiftly via the keyboard can now customize key bindings with far greater ease.

Imagine an orchestra conductor establishing a preparatory beat: previously the fleeting gesture was easily missed, but now the cueing hand rests steadily in the air waiting for your response, while the mute control is reassigned to another designated piano key.

Within /keymap settings, you can freely configure a leader key (a guiding key that waits for follow-up inputs once pressed), with the system defaulting to Ctrl+X. The shortcut prompt that appears after pressing it remains on screen until you make a choice or cancel. Voice muting has been moved to the F9 key.

FEATURE

/daemon Supports Restarting Background Servers with Disruption Warnings and Auto-Reconnect

When a background server connection hangs or requires a reload, you no longer need to go through the hassle of manually killing the process.

Consider a building announcement prior to main electrical maintenance: previously throwing the main switch cut power to the entire building without ceremony, but now the superintendent first warns which elevators and facilities will temporarily halt, and automatically reconnects lighting once the restart completes.

You can now restart managed background servers (daemons running quietly at the system level) directly from the /daemon command. Before restarting, Codex displays a warning outlining which active tasks might be disrupted. Once confirmed, the system automatically reconnects as soon as the server finishes rebooting, eliminating tedious manual reconnection steps.

FEATURE

Read-Only Tools Support Parallel Execution: Skills, Memory, and Session History Queries No Longer Queue Up

Readers whose questions require the AI to retrieve multiple pieces of past information at once will now notice noticeably faster query responses.

A library dispatches multiple librarians to fetch books simultaneously: where one person previously had to search historical archives before checking archived skills, three librarians now head toward separate shelves at once and deliver everything into your hands the moment it is gathered.

Codex can now execute mutually independent read-only tools in parallel (processing tasks concurrently without waiting in line). This mechanism covers skill retrieval, memory lookups, and session history queries. These non-conflicting read tasks now run concurrently, cutting down the wait time for answers.

FEATURE

Daybreak Model Enabled by Default for Eligible Accounts, with Key-Based Selection in codex exec

Readers eager to experience the latest Daybreak model can now use it right out of the box, provided their account is eligible.

A high-speed rail membership automatically upgrades passengers to business class: where travelers once had to present identification at the counter to apply, eligible passengers can now swipe their tickets at the gate to take their seats directly, while entering personal credentials at automated ticketing machines also secures a seat smoothly.

Codex now enables the Daybreak model by default for eligible accounts. If you prefer running tasks with the terminal command codex exec, you can also freely select the Daybreak model through that command by supplying an OpenAI API key (the secret pass for accessing cloud services), provided the server grants access.

FEATURE

Thread Switching Supports /side to Return to Branches, Fully Restoring Authorizations and Network Permissions on Reopen

Readers who frequently switch between threads (independent conversation logs running concurrently in the same project) no longer need to worry about losing progress or configuration state.

Handling multiple project dossiers in an office setting once required restamping approvals whenever you switched cases, but returning to an earlier case now pulls up previously approved seal records directly, and replies to dispatched memos return precisely to the originating project folder.

After switching threads, you can type the /side command at any point to return to a previous side discussion. If a prompt was still generating when you switched, the resulting response is routed accurately back to the thread where the question originated. When reopening a saved thread, your previously granted authorizations and network access permissions are fully restored, while continuing to respect manual overrides and active administrative policies.

FEATURE

Network Proxy Security Tightens: Pre-DNS Query Audits, Blocking Duplicate Headers and Credential Alias Bypasses

In environments that route external network traffic through a proxy server, this update erects a stricter line of defense for connection security.

Customs inspectors at an airport checkpoint tighten screening procedures: where officers previously did not verify passports before travelers stated their destinations, inspectors now confirm exit permits before looking up flight routes, strictly scrutinize duplicate declaration forms, and block contraband credentials disguised under aliases from slipping past checkpoints.

The network proxy now verifies whether a connection holds appropriate permissions before initiating a domain name query (resolving a web address into a server destination). The proxy server also actively rejects requests bearing duplicate Host headers and prevents credential aliases from bypassing check hooks (small routines triggered when specific events occur), plugging potential unauthorized connection loopholes.

BUGFIX

Windows Gains Image Pasting Shortcuts, While WSL Reuses Clipboard Readers and Prevents Copy Freezes

Readers running terminals under Windows or WSL (Windows Subsystem for Linux) will experience far smoother clipboard workflows.

Upgrading to a responsive card reader at a checkout counter allows two designated shortcuts to feed both text and images straight into the window, frequent scans share the reader module, and stalled copy operations time out instead of hanging indefinitely.

On Windows, both Ctrl+V and Shift+Insert can now paste text and images. Under WSL, successive pastes reuse the clipboard reader, while copy operations encountering obstacles time out gracefully rather than freezing the screen indefinitely.

BUGFIX

Command Output Fixes: Steadier Local and Remote Transfers, codex exec Stops Reprinting Diffs

For readers who regularly run local commands or remote tasks in the terminal, this update resolves several output glitches that previously hung commands or cluttered information.

A freight logistics hub overhauls its shipping workflow: previously, as long as downstream packing crates remained unsealed, delivery drivers had to wait idly on site even after finishing unloading, but now drivers depart promptly once unloading is confirmed, and late-arriving parcels are safely warehoused rather than missed.

Previously when running local commands, as long as underlying subprocesses (child processes spawned by the main program to handle tasks independently) kept output pipes open, the overall command would stall indefinitely rather than terminate. Local commands now exit promptly once their work is done. When executing remote commands, late-arriving output is now safely retained, ensuring it is fully collected during the final poll. Running unrelated commands via codex exec also no longer causes the terminal to reprint previous file diffs.

FEATURE

Bundled Documentation Update: GPT-6 Migration Guide and Linux Sandbox Architecture Details

Readers planning to upgrade projects to next-generation models or keeping an eye on low-level system security can now consult more detailed official guidance in the bundled documentation.

A factory equipment manual swaps in a fresh expansion guide, not only detailing the operational characteristics and data location considerations when upgrading to new machinery, but also revealing how safety shields isolate hazardous areas and filter high-pressure airflow.

The bundled OpenAI documentation updates migration guidance for the GPT-6 model family, detailing model-specific reasoning characteristics, external tool usage, and data residency (the geographic location where data is stored and processed) considerations. The bundled documentation also clarifies how the Linux sandbox mechanism operates, detailing how the system achieves filesystem isolation through bubblewrap and filters system calls via seccomp.

FEATURE

Package Size Reduced with Codex's Standard Shell Runner and Config Migration Notice

Readers installing or updating Codex on Linux and macOS will find lighter downloads and a simpler underlying runner.

A business traveler packs light under the same principle: rather than stuffing a custom toolkit into a suitcase, they rely on existing standard tools and strip away nonessential decorative tags, significantly reducing suitcase size and weight.

The team reduced package sizes for Linux and macOS releases by stripping symbols (internal name labels used for debugging) from installation binaries, while raw build artifacts still retain full symbols. In terms of execution architecture, Codex now switches to Codex's standard shell runner (a tool responsible for executing commands), no longer bundling a patched zsh. If existing configurations still contain deprecated shell flags, the system displays a migration notice to help you transition smoothly.
