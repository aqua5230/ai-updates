Codex 0.146.1

發布日期：2026-08-05

zh-TW

資安模型的自動審查更保守，權限變動看得懂

使用具資安能力的模型（cyber-capable models，能處理網路安全工作的 AI 模型）幫忙做自動審查時，最怕看不出預設值為何改了。Codex 現在把這類模型的自動審查（automatic review，不必先手動調整的審查設定）預設改得更保守，並在終端機（terminal，用文字輸入指令的操作畫面）說明權限怎麼變動。像公司換了保全規則，門禁變嚴前後都會貼出告示；你看到權限調整時，能在操作畫面直接知道改了什麼。

en

Cyber-capable model reviews get safer defaults and clearer permission notices

When you use a cyber-capable model to review work automatically, a changed default can be hard to spot. Codex now uses more cautious automatic-review defaults for these models and explains permission changes in the terminal. Think of a company updating its security rules and posting a notice at the door: when permissions change, the command-line screen tells you what changed.

zh-CN

网络安全模型的自动审查更保守，权限变动看得懂

用具备网络安全能力的模型（cyber-capable models，能处理网络安全工作的 AI 模型）帮忙做自动审查时，最怕看不出默认值为什么变了。Codex 现在把这类模型的自动审查（automatic review，不必先手动调整的审查设置）默认改得更保守，并在终端机（terminal，用文字输入命令的操作界面）说明权限如何变动。好比公司换了安保规则，门禁变严前后都会贴出告示；看到权限调整时，你能在操作界面直接知道改了什么。

ja

サイバー対応モデルの自動レビューが慎重になり、権限変更も分かる

サイバーセキュリティの仕事を扱えるモデルで自動レビューをすると、既定値がなぜ変わったのか見えにくい。Codex はこの種のモデルで、自動レビューの既定値をより慎重なものにし、端末で権限がどう変わるかも説明する。会社が警備規則を変え、出入口に告知を貼るようなものだ。権限が変われば、操作画面で何が変わったか分かる。

ko

사이버 기능 모델의 자동 검토는 더 신중해지고 권한 변경도 알기 쉬워진다

사이버 보안 작업을 다룰 수 있는 모델로 자동 검토를 하면 기본값이 왜 바뀌었는지 알기 어렵다. Codex는 이런 모델의 자동 검토 기본값을 더 신중하게 바꾸고, 터미널에서 권한이 어떻게 달라지는지도 설명한다. 회사가 보안 규칙을 바꾸고 출입문에 안내문을 붙이는 것과 같다. 권한이 바뀌면 작업 화면에서 무엇이 달라졌는지 알 수 있다.
