批准審查會照模型帶來的 Node REPL 規定判斷

實驗室的器材借用規定寫在器材本身的說明卡上，管理員照那張卡放行；以前卡片擺在那裡卻沒人看，管理員只按自己那套老規矩辦。Codex 的 Guardian 批准審查（動手做事前先判斷這件事該不該放行的關卡）現在會遵守模型 metadata 裡帶的 Node REPL 政策。metadata 是隨模型一起送來、描述它自身的一小份資料；Node REPL 則是直接輸入一行 JavaScript 就立刻執行的互動環境。換句話說，該不該放行這類指令，依據來自模型自己聲明的那份規定，而不是審查關卡自行認定。

en

Approval review now follows the Node REPL policies the model provides

A lab keeps the rules for borrowing a piece of equipment on the card attached to it, and the keeper follows that card; before, the card sat there unread and the keeper went by their own old habits. Codex's Guardian approval review, the gate that decides whether an action may go ahead, now honors the Node REPL policies provided through model metadata. Metadata is the small description that travels with a model, and a Node REPL is the interactive prompt where a line of JavaScript runs the moment you type it. In other words, whether such a command is allowed through comes from the rules the model itself declares, not from what the review gate decides on its own.
