批准審查會照模型帶來的 Node REPL 規定判斷

實驗室的器材借用規定寫在器材本身的說明卡上，管理員照那張卡放行；以前卡片擺在那裡卻沒人看，管理員只按自己那套老規矩辦。Codex 的 Guardian 批准審查（動手做事前先判斷這件事該不該放行的關卡）現在會遵守模型 metadata 裡帶的 Node REPL 政策。metadata 是隨模型一起送來、描述它自身的一小份資料；Node REPL 則是直接輸入一行 JavaScript 就立刻執行的互動環境。換句話說，該不該放行這類指令，依據來自模型自己聲明的那份規定，而不是審查關卡自行認定。

en

Approval review now follows the Node REPL policies the model provides

A lab keeps the rules for borrowing a piece of equipment on the card attached to it, and the keeper follows that card; before, the card sat there unread and the keeper went by their own old habits. Codex's Guardian approval review, the gate that decides whether an action may go ahead, now honors the Node REPL policies provided through model metadata. Metadata is the small description that travels with a model, and a Node REPL is the interactive prompt where a line of JavaScript runs the moment you type it. In other words, whether such a command is allowed through comes from the rules the model itself declares, not from what the review gate decides on its own.

zh-CN

批准审查会照模型带来的 Node REPL 规定判断

实验室的器材借用规定写在器材本身的说明卡上，管理员照那张卡放行；以前卡片摆在那里却没人看，管理员只按自己那套老规矩办。Codex 的 Guardian 批准审查（动手做事前先判断这件事该不该放行的关卡）现在会遵守模型 metadata 里带的 Node REPL 政策。metadata 是随模型一起送来、描述它自身的一小份数据；Node REPL 则是直接输入一行 JavaScript 就立刻执行的交互环境。换句话说，该不该放行这类命令，依据来自模型自己声明的那份规定，而不是审查关卡自行认定。

ja

承認レビューがモデル由来の Node REPL ポリシーに従う

実験室では器材の貸出規則が器材そのものの説明カードに書かれ、管理者はそのカードに従って許可を出す。以前はカードが置かれていても読まれず、管理者は自分の古いやり方だけで判断していた。Codex の Guardian 承認レビューは、実行前にその行為を通してよいか判断する関門である。これがモデルの metadata に含まれる Node REPL ポリシーに従うようになった。metadata とはモデルに付いてくる、それ自身を説明する小さなデータである。Node REPL は JavaScript を一行打てばその場で実行される対話環境を指す。つまり、この種のコマンドを通すかどうかの根拠はモデル自身が宣言した規則にあり、関門が独自に決めるのではない。

ko

승인 검토가 모델이 전달한 Node REPL 정책을 따른다

실험실에서는 기자재 대여 규칙이 기자재에 붙은 설명 카드에 적혀 있고 관리자는 그 카드를 보고 내준다. 예전에는 카드가 놓여 있어도 읽히지 않아 관리자가 자기 방식대로만 판단했다.Codex의 Guardian 승인 검토는 실행 전에 그 행위를 통과시킬지 판단하는 관문이다. 이제 이 관문이 모델 metadata에 담긴 Node REPL 정책을 따른다. metadata는 모델과 함께 오는, 그 자신을 설명하는 작은 데이터를 말한다. Node REPL은 JavaScript를 한 줄 입력하면 그 자리에서 실행되는 대화형 환경이다. 곧 이런 명령을 통과시킬지의 근거가 모델이 스스로 밝힌 규칙에 있고, 관문이 알아서 정하지 않는다.
