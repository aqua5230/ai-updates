Codex 0.169.0

發布日期：2026-11-13

繁體中文

新功能

終端機工作區可開多個旁聊分頁

寫程式寫到一半想另開話題發問，不必擠在同一個對話框裡來回翻找。開啟選用性質的終端機工作區後，你可以在側邊同時建立多個旁聊分頁，直接用鍵盤或滑鼠在分頁間切換。 就算把 Codex 關掉重新啟動，之前留在本機的旁聊紀錄依然能再次打開接著用。

就像煮菜備料多擺幾個小碗，以前只能全倒進同一個碗裡混著攪，現在每道菜分開裝，隔餐打開冰箱還能原封不動端出來接著煮。
新功能

代理指令中心可依關鍵字搜尋舊任務

想找幾天前跑過的那個任務，不用再從清單一路往下慢慢滑。打開代理指令中心後，現在可以直接用任務名稱、提示詞預覽或工作目錄來搜尋較早的任務。 昨天剛處理完一份專案報告、今天想沿用當時的任務紀錄，只要輸入對應的工作目錄或提示詞裡的字句就能找出來。

跟去 KTV 點歌一樣，以前得一頁頁翻厚重的歌本找曲目，現在打歌名、歌詞片段或歌手名字就能立刻叫出來。
新功能

全螢幕紀錄可收合過程只留回答

回頭檢視長長的對話紀錄，最常被中間一大段工具執行過程洗版，想看最終回答得捲好久。現在只要在全螢幕對話紀錄開啟 **Collapse turn details**，每個提問底下已經完成的執行過程就會自動摺疊起來。 摺疊後回答本身依然清楚顯示在畫面上，而收起來的工具輸出內容也還是能直接搜尋。

好比逛展看畫作，以前連運送木箱和包裝紙都還堆在畫框底下，現在把打包材料收進儲藏室只留作品本身，真要查物流標籤依然調得到。
新功能

終端機可管理自訂供應商並用裝置碼登入

連進遠端主機或沒有瀏覽器的純文字環境，想接入自訂的模型供應商常卡在無法跳轉網頁登入。現在你可以直接在終端機新增或修改自訂模型供應商。 只要啟用自訂閘道器引導設定，登入過程中就能順手建立供應商。遇到支援的閘道器，就算是在 SSH（遠端文字連線）或沒有本機瀏覽器的機器上，也能改用裝置碼完成驗證。

如同在沒有刷卡機的自助寄物櫃前，以前非得帶著實體感應卡才打得開，現在只要螢幕跳出一組取件碼，拿旁邊的手機輸入就能把櫃門連上打開。
新功能

回報編輯器按 Ctrl+S 可本機存診斷檔

公司電腦限制網路或環境停用上傳功能，出狀況卻找不到地方把診斷資料帶出來給人排查。現在只要在終端機回報編輯器按下 Ctrl+S，就能把診斷用 ZIP 壓縮檔直接存到本機，就算上傳功能被關閉也一樣能存。

彷彿在沒有手機訊號的山區寫工作日誌，以前送不出去就只能留在畫面上乾瞪眼，現在按一下存檔鍵就能先存進隨身記憶卡帶下山。
新功能

終端機 Cloud 連線支援傳圖與封存對話

用 macOS 或 Linux 開著終端機連上 Cloud，以前遇到要傳截圖或調整思考深度時，還是得另外找別的介面處理。現在啟用這項選用連線後，直接在終端機就能傳送圖片，也能挑選要用的模型和推理力度。 討論告一段落，或想還原 Cloud 對話時，在終端機同樣可以直接封存或還原 Cloud 對話。

比方說智慧手錶原本只能收到文字提醒，現在直接能在錶面上傳照片、調推播強度，還能把舊通知收起來或翻出來。
新功能

未信任目錄執行 codex exec 不載入設定

從網路下載陌生專案準備跑自動檢查，最怕資料夾裡夾帶的設定偷偷啟動外部連線。就算加上 --sandbox workspace-write，只要資料夾還沒被信任，codex exec 仍會把專案設定和 MCP（讓 AI 連接外部工具的協定）伺服器保持停用。 確認目錄安全、想正式儲存信任狀態，可在 codex exec 或 codex review 加上 --trust 參數。

拿電腦插上來路不明的隨身碟來說，就算你允許電腦寫入檔案，裡頭附帶的自動執行腳本還是會被鎖住，非得你親手點下信任按鈕才會放行並記住。
codex exec --trust    # 執行任務並儲存專案信任
codex review --trust  # 進行審查並儲存專案信任
新功能

清空脈絡開始實作時會完整交接計畫

跟 Codex 敲定修改方案後，很多人會先清空脈絡重新開局，免得前面討論佔住記憶空間。現在點選 **Yes, clear context and implement**，Codex 會把整份已經核准的計畫完整交給新的工作階段。萬一交接失敗，原本的工作階段仍會保持開啟，不會當場關閉。

就跟銀行辦理舊戶結清轉存一樣，一定要確認完整金額已經入到新帳戶，行員才會把舊存摺剪角，要是中途轉帳失敗，原本的戶頭就會原封不動留著。
問題修復

修正 Windows 沙盒路徑與目錄權限問題

用 Windows 沙盒跑指令，遇到帶引號的 cmd.exe 路徑，或是工作目錄上層無法讀取的 PowerShell 工作階段，過去沙盒處理會出狀況。這個問題已經修好，現在這兩種情況都能正常處理。

新功能

macOS 貼上圖片保留方向與原生格式

在 macOS 複製圖片直接貼進對話框，過去偶爾會碰到照片方向歪掉的困擾。現在貼上的圖片會保留原本預期的方向。只要剪貼簿裡有原生的 PNG 或 JPEG 資料，也會直接採用這些格式。

問題修復

終端機不再卡在等待或被前輪中斷波及

在終端機跑完或喊停一輪對話，最怕上一輪的等待或殘留訊號卡住接下來的新操作。 面對共用應用伺服器沒有回報的 MCP 伺服器，終端機現在不會再一直停在忙碌狀態苦等。 被打斷的對話回合也會乾淨收尾；就算前面遲來的中止訊號或檔案核准取消比較晚才到，也不會再打斷後面的回合。

有如攝影棚接連拍兩組客人，上一組提前收工就得把現場清乾淨，沒送到的器材或遲來的取消通知才不會打亂下一組開拍。
新功能

openai-docs 技能聚焦團隊設定與上手

剛上手想搞懂 Codex 與 ChatGPT Work，或是第一次串接 API（程式對接介面）不知從何起步，都可以直接找 openai-docs 技能幫忙。更新後的 openai-docs 把重心放在這兩項產品的疑問與首次 API 設定，還加入在團隊中統一配置 Codex 的專門指南。

像把綜合手冊換成城市專區摺頁一樣，第一次怎麼搭車、熱門疑問跟團體帶隊須知全集中在同一份裡。
新功能

應用伺服器客戶端補齊模型與閘道器文件

給正在開發串接程式的工程師：想針對個別已設定的供應商做操作，卻不想動到原本的預設選項，可以參考這次的說明。文件裡現在清楚說明，如何在不改動預設供應商的前提下，替已設定好的供應商列出模型，或是替它的閘道器完成授權。

問題修復

內建 SQLite 升級 3.54 納入日誌修復

Codex 背後靠內建的 SQLite 資料庫把資料存進本機，平時大多數人不會直接操作它。這次將內建的 SQLite 更新到 3.54 版，納入預寫式日誌（資料正式寫入前先留底的機制）的相關修復。

跟寄包裹前先把寄件單留底一樣，這次更新把這道預先記一筆的程序毛病修好，在背後平穩執行。
新功能

外掛市集升級可沿用本機資料省下載

在外掛市集進行升級，最煩的就是明明電腦裡已經存過很多檔案，卻還是得再從網路抓一次。現在外掛市集升級可以直接沿用硬碟上既有的 Git（版本控制工具）資料物件，減少重複下載。

拿拼樂高換新版造型來比喻，以前每次改版都整盒積木重新買一套，現在發現桶子裡本來就有的零件可以直接拿來組，不必全都重買。

English

FEATURE

Terminal workspace supports multiple side-chat tabs

When you want to ask about a separate topic mid-coding, you no longer have to scroll back and forth inside a single chat box. With the opt-in terminal workspace enabled, you can open multiple side-chat tabs along the side and switch between them with your keyboard or mouse. Even if you quit and restart Codex, you can still reopen saved local side chats and pick up where you left off.

Picture prepping ingredients with several small bowls instead of dumping everything into one bowl to mix together: each dish stays separate, and when you open the fridge for the next meal, you can pull it out intact and keep cooking.
FEATURE

Search older tasks by keyword in agent command center

To find a task you ran a few days ago, you no longer have to scroll all the way down a long list. Inside the agent command center, you can now search older tasks by task name, prompt preview, or working directory. If you finished a project report yesterday and want to reuse that task record today, just type the matching working directory or words from the prompt to pull it up.

Think of picking songs at karaoke: instead of flipping page by page through a thick songbook, you type the title, a lyric snippet, or the artist's name to bring it right up.
FEATURE

Collapse activity in full-screen transcript to keep answers

Reviewing a long transcript often means wading through walls of tool execution steps just to reach the final answer. Now, when you turn on **Collapse turn details** in the full-screen transcript, completed activity beneath each prompt folds away automatically. Your answers stay clearly visible on screen, while the collapsed tool output remains directly searchable.

A gallery exhibition works the same way: instead of leaving shipping crates and wrapping paper piled under every frame, the packing materials go into storage so only the artwork stays on display, yet you can still look up the shipping labels whenever needed.
FEATURE

Manage custom providers and sign in with device code in terminal

Connecting to a remote host or a text-only environment without a browser often stalls when a custom model provider expects a web login redirect. You can now add or edit custom model providers directly from the terminal. With custom gateway onboarding enabled, you can create a provider right during sign-in. For supported gateways, even over SSH (remote text connection) or on a machine without a local browser, you can authenticate using a device code instead.

Imagine standing at a self-service locker with no card reader: where you once needed a physical tap card, the screen now shows a pickup code that you enter on your phone beside it to open the door.
FEATURE

Press Ctrl+S in report editor to save diagnostics locally

When a corporate network is restricted or uploads are disabled, getting diagnostic data out for troubleshooting can be a dead end. Now, pressing Ctrl+S in the terminal report editor saves a diagnostic ZIP archive directly to your machine, even when uploads are turned off.

It feels like writing a field log on a mountain with no cell signal: instead of staring at an unsent screen, you hit save to write it onto a portable memory card and carry it down with you.
FEATURE

Terminal Cloud connection supports images and archiving

When connected to Cloud from a terminal on macOS or Linux, sending a screenshot or adjusting reasoning depth used to mean switching to another interface. With this opt-in connection enabled, you can now send images and choose your model and reasoning effort directly from the terminal. Once a discussion wraps up, or when you want to bring back an earlier thread, you can archive or restore Cloud conversations right from the terminal as well.

Say a smartwatch could previously only display text alerts, and now lets you send photos, adjust notification intensity, and tuck away or pull back old alerts straight from your wrist.
FEATURE

codex exec skips project config in untrusted directories

Running automated checks on an unfamiliar project downloaded from the web always carries the risk of bundled settings silently opening external connections. Even with --sandbox workspace-write, codex exec keeps project configuration and MCP (a protocol that connects AI to external tools) servers disabled as long as the directory is untrusted. Once you verify the directory is safe and want to save its trusted status, pass --trust to codex exec or codex review.

Plug an unfamiliar USB drive into your computer, and even if you allow writing files to it, its autorun scripts stay locked until you explicitly click trust to let them run and remember your choice.
codex exec --trust    # Run task and save project trust
codex review --trust  # Run review and save project trust
FEATURE

Full approved plan handed off when clearing context

After finalizing a plan with Codex, clearing context for a fresh start keeps earlier discussion from eating up memory. Now, selecting **Yes, clear context and implement** hands the full approved plan over to the fresh session. If the handoff fails, the current session stays open instead of closing on the spot.

Like closing an old bank account to transfer the balance, the teller only cancels the old passbook after confirming the full amount has landed in the new account, leaving the original account untouched if the transfer fails midway.
BUGFIX

Fix Windows sandbox path and directory permission handling

Running commands in the Windows sandbox previously broke on quoted cmd.exe paths or PowerShell sessions whose working directory had an unreadable parent. This has been fixed, and both cases now work properly.

FEATURE

Preserve orientation and native format for pasted macOS images

Copying and pasting an image directly into the chat box on macOS could occasionally leave the photo rotated the wrong way. Pasted images now retain their intended orientation. Whenever native PNG or JPEG data is available on the clipboard, those formats are used directly as well.

BUGFIX

Terminal no longer gets stuck waiting or hit by prior interruptions

After finishing or stopping a conversation turn in the terminal, the last thing you want is waiting or leftover signals from the previous round blocking your next step. When a shared app server does not report back on MCP servers, the terminal no longer stays stuck in a busy state waiting. Interrupted turns also wrap up cleanly, so even a late abort signal or a delayed file approval cancellation will no longer cut off a later turn.

Just as a photo studio shooting two clients back-to-back must clear the set when the first wraps early, undelivered gear or late cancellation notices will not disrupt the next shoot.
FEATURE

openai-docs skill focuses on team setup and onboarding

If you are just getting started with Codex and ChatGPT Work, or unsure where to begin with your first API (an interface for connecting programs) integration, you can turn straight to the openai-docs skill. The updated openai-docs focuses on questions about these two products and first-time API setup, and adds dedicated guidance for configuring Codex consistently across a team.

Swapping a general handbook for a city-specific brochure puts first-time transit tips, popular questions, and group-leader notes all in one place.
FEATURE

App-server clients get docs for models and gateways

For engineers building integrations who want to target a specific configured provider without touching the default option, this update has you covered. The documentation now clearly explains how to list models for a configured provider or authorize its gateway without changing the default provider.

BUGFIX

Bundled SQLite upgraded to 3.54 with log fixes

Under the hood, Codex relies on a bundled SQLite database to store data locally, though most people never interact with it directly. This update upgrades bundled SQLite to version 3.54 and pulls in fixes for the write-ahead log (a mechanism that keeps a backup record before data is officially saved).

Much like keeping a copy of the shipping slip before sending a package, this update fixes a glitch in that pre-recording step so it runs smoothly behind the scenes.
FEATURE

Plugin marketplace upgrades reuse local data to cut downloads

When upgrading in the plugin marketplace, few things are more annoying than having to download files all over again when plenty of them are already on your computer. Plugin marketplace upgrades can now reuse existing Git (a version control tool) objects already on disk, reducing repeat downloads.

Take rebuilding a LEGO set into a new model: instead of buying a whole new box every time, you can use parts you already have in the bin and skip buying everything again.
