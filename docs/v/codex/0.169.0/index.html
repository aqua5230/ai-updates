Codex 0.169.0

發布日期：2026-11-13

繁體中文

新功能

終端機工作區支援多個側邊對話分頁，重啟後可重新開啟

專案改到一半想順便問其他問題時，單一對話窗往往不夠用。

就像在螢幕旁釘上好幾張各自獨立的便條，以前只有一張紙容易互相蓋掉，現在可以各寫各的，重開程式也找得回本機留存的紀錄。

只要開啟這個需手動啟用的終端機工作區（支援多個側邊對話分頁的模式），就能同時開出多個側邊對話分頁。例如你正請 Codex 整理一份簡報大綱，順手想再問幾個語法問題，就能另開一個分頁處理。你可以隨時用鍵盤或滑鼠在分頁之間切換，就算把 Codex 關掉重開，先前儲存在本機的側邊對話也還能重新打開。

新功能

代理指揮中心新增舊任務搜尋，可依名稱與目錄篩選

用過好幾輪 AI 任務後，想回頭找先前處理過的那一筆，往往得在一長串清單裡慢慢翻。現在在代理指揮中心（集中管理各項任務的控制畫面），可以直接搜尋過去的舊任務。你可以用任務名稱或提示詞預覽（當初下指令的開頭內容）來查。如果只記得當時放在哪個專案資料夾，也能直接輸入工作目錄（任務運作的資料夾路徑）搜尋。假設你上週請它幫忙整理會議紀錄，只要打進幾個當時寫的詞，就能立刻把那筆舊任務找出來。

好比在手機相簿翻找去年拍的旅遊照，以前得從最新一張一路往上滑，現在只要打地點、相簿名稱或畫面關鍵字就能直接跳到那一張。
新功能

全螢幕紀錄可折疊回合細節，保留回覆並支援搜尋工具輸出

對話累積了不少來回步驟後，全螢幕對話紀錄（展開檢視完整往來過程的畫面）常被大量執行細節佔滿版面。

想像一份夾著大疊附錄的報告，以前得一頁頁越過查證過程才能看見正文，現在把附錄對折收起來只留結論，真要核對細節時也依然查得到。

只要在畫面裡打開 **Collapse turn details**，每次提問底下已經完成的活動就會摺疊收起。當你請它改完報告想順著讀一遍回覆時，AI 的答案依然會直接顯示在畫面上。就算細節收起來了，被折疊的工具輸出（外部工具回傳的執行結果）還是支援搜尋，隨時能翻出需要的片段。

新功能

終端機支援新增與編輯自訂模型供應商，可透過裝置代碼登入

如果你的團隊自架了 AI 服務，或是連到沒有圖形介面的遠端主機，要在終端機設定模型來源往往相當繞路。現在你可以直接在終端機新增或編輯自訂模型供應商（提供 AI 模型的服務窗口）。只要開啟自訂閘道器引導（協助首次連上自訂轉接閘道的設定流程），登入時就能順手建立供應商。當你透過 SSH（安全外殼協定，用來遠端操作主機的連線方式）連線，或是手邊沒有本機瀏覽器時，這個流程就很實用了。只要該閘道器支援，登入時便能改用裝置代碼（在別台裝置輸入即可驗證的短碼）完成授權。

跟在飯店電視登入串流帳號一樣，以前螢幕沒有瀏覽器就沒辦法當場開通，現在直接跳出一組配對碼，在手機輸入就能連好自訂來源。
新功能

終端機回報編輯器按 Ctrl+S 可本機儲存診斷壓縮檔

碰到問題想整理錯誤資訊，偏偏上傳功能被關掉了，資料很容易卡在當下送不出去。現在只要在終端機回報編輯器（用來編輯與送出問題回報的介面）按下 Ctrl+S，就能把診斷用的 ZIP 壓縮檔直接存到本機。即使上傳功能處於停用狀態，這組快捷鍵依然可以正常存檔。當你在隔離網路環境下需要留下現場紀錄時，打開編輯器按下 Ctrl+S，就能把打包好的診斷檔案留在電腦裡。

試想寄件遇上投遞口封閉時，以前整疊資料只能卡在現場送不出去，現在隨時能先封進檔案袋自己收好。
新功能

macOS 與 Linux 終端機雲端連線支援傳圖、選模型與封存對話

待在 macOS 或 Linux 終端機工作時，過去連上雲端對話後能調整的項目並不多。只要開啟需手動啟用的雲端連線（從本機終端機接上雲端服務的通道），現在在終端機裡就能直接操作更多項目。

彷彿把原本只通簡訊的遠端分機換成全功能桌面，現在圖片寄得過去、推理力道挑得動，談完的紀錄還能順手歸檔或救回來。

你可以直接在終端機傳送圖片，也能選擇要使用的模型與推理力度（決定 AI 推敲答案深度的檔位）。當你手邊有一張設計草圖想請雲端模型分析，或是想為複雜問題換個模型時，待在終端機就能一次完成。對話告一段落後，還能順手將雲端對話封存，日後有需要也能再還原回來。

新功能

codex exec 在未受信任目錄停用專案設定，可加 --trust 儲存信任

剛接手一個來路不明的專案資料夾時，直接跑自動化任務難免擔心裡頭的設定被擅自啟用。在未受信任的目錄中，codex exec 現在會持續停用專案設定與 MCP（讓 AI 連接外部工具的協定）伺服器。就算你同時加上了 --sandbox workspace-write（允許在工作區寫入檔案的沙盒權限），這兩項還是不會啟用。若確認該資料夾可以放心，可用 codex exec 或 codex review 搭配 --trust 明確儲存專案信任：

codex exec --trust
codex review --trust

如同陌生訪客來家裡幫忙搬東西，就算你准許他進客廳動手，在屋主正式授權前，屋裡的電器開關依舊全部上鎖。
新功能

清空脈絡並實作會完整交接核准計畫，失敗時保留原工作階段

討論並核准一份執行計畫後，點選 **Yes, clear context and implement**，就能清空前面冗長的脈絡並直接動工。這個選項現在會把整份核准計畫，完整交接給新開啟的工作階段（單次獨立的對話與執行環境）。萬一交接中途失敗，原本的工作階段也會維持開啟狀態。當你花了不少心思對齊步驟、準備放手讓 Codex 執行時，就能放心按下清空，不怕進到新對話後計畫缺漏，或是交接出錯就兩頭落空。

宛如醫院輪班時把整本核定的醫囑交給下一班，要是對方沒順利接手，原本這一班就會繼續留在崗位上不撤離。
問題修復

修正 Windows 沙盒處理引號 cmd.exe 路徑與 PowerShell 權限問題

在 Windows 上使用沙盒（限制程式存取範圍的隔離環境）時，以前只要 cmd.exe 的路徑帶有引號，或是 PowerShell 工作階段的工作目錄上層資料夾無法讀取，執行就會出錯。這兩個情境下的 Windows 沙盒處理問題現在已經修好。

新功能

macOS 貼上圖片保留正確方向，可取用原生 PNG 與 JPEG 資料

從 macOS 複製圖片直接貼進對話想請 AI 判讀時，方向歪掉一直很讓人困擾。現在在 macOS 貼上圖片，會確實保留圖片原本預期的方向。只要剪貼簿（暫存複製內容的系統空間）裡本身帶有原生的 PNG 或 JPEG 資料，就會使用這些原生格式。當你從修圖工具或相簿複製好一張直式畫面貼上時，不用再擔心貼進來變成橫躺的。

打個比方，拿剛調正角度的相片傳給朋友，以前送過去偶爾會翻倒，現在方向會維持原樣。
問題修復

終端機不再苦等未回報的 MCP 伺服器，中斷回合收尾更乾淨

操作到一半按下停止或等候外部連線時，偶爾會遇上終端機持續忙碌、甚至誤傷下一輪對話的狀況。

猶如舞台剛落幕就該把上一場收乾淨，以前沒報到的名單或晚到的喊卡聲會拖累下一幕，現在這場一停就乾脆收尾，不再牽連下一場。

終端機不再一直忙著等待共用應用程式伺服器未回報的 MCP（讓 AI 連接外部工具的協定）伺服器。共用應用程式伺服器是在背景協調連線的程式。 至於被中斷的對話回合，現在結束得更乾淨。先前延遲抵達的中止指令或檔案核准取消操作，也不會再誤打斷後面的新回合。

新功能

更新 openai-docs 技能與文件，補齊團隊設定與閘道器授權說明

剛開始導入工具或替整個團隊統一設定時，官方說明若不夠聚焦，常讓人不知道該從哪份指引看起。

好似重新編寫公司的新人報到包，個人剛進門要辦哪些手續、整個部門怎麼統一規矩，連合作窗口怎麼查表都一次寫明白。

openai-docs 技能（預先寫好給 AI 查閱的專業知識模組）已經更新，內容改為聚焦在 Codex 與 ChatGPT Work 的相關問題，以及第一次使用 API 的設定步驟，並加入專章說明如何在整個團隊裡統一設定 Codex。 官方也補上了給應用程式伺服器客戶端（連上背景服務進行操作的外部程式）參考的文件，說明如何在不更動預設供應商的前提下，列出已設定供應商的模型或為閘道器授權。

問題修復

內建 SQLite 升級至 3.54 版，納入預寫日誌修復

查看 Codex 這次更新的隨附元件時，你會看到資料庫引擎的版本也有變動。Codex 這次將隨附的 SQLite（輕量級的本機檔案型資料庫）升級到 3.54 版。這次版本更新主要是為了納入預寫日誌（把資料變更先記進日誌檔再寫回主檔的機制）相關的修復項目。

正像會計師換用新版流水帳本，把先記草稿再謄進總帳這道工序裡的毛病修好，日常在背後默默把紀錄抄穩。
新功能

外掛市集升級可沿用本機 Git 物件，減少重複下載

當你準備替擴充商店更新到最新版時，若每次都得把整包資料從頭抓過一次，總會多傳許多電腦裡早就有過的內容。現在外掛市集（用來瀏覽與安裝擴充功能的商店）升級時，可以沿用電腦裡的既有資料。升級過程中會直接重複使用已經存在硬碟上的 Git 物件（版本控制系統用來保存檔案與歷程紀錄的資料單位），藉此減少重複下載的資料量。當你升級外掛市集時，不必再把已經下載過的內容通通重抓一遍。

譬如更換新版百科全書時，以前得整套厚書重寄一箱，現在發現書架上原本就有前幾冊，只要把新頁面補齊就好。

English

FEATURE

Terminal workspace supports multiple side-chat tabs and reopens saved chats after restart

When you want to ask unrelated questions mid-project, a single chat pane is often not enough.

Think of it like pinning several separate sticky notes beside your screen: previously one sheet easily got written over, whereas now each holds its own notes and local records stay retrievable after restarting.

Once you turn on the opt-in terminal workspace (a mode supporting multiple side-chat tabs), you can open several side-chat tabs at once. For example, if you have Codex drafting a presentation outline and want to ask a few syntax questions on the side, you can open another tab for that. You can switch between tabs anytime with the keyboard or mouse, and even if you close and restart Codex, previously saved local side chats can still be reopened.

FEATURE

Agent command center adds search for older tasks by name and directory

After running several rounds of AI tasks, finding a past item often meant scrolling through a long list. Now, in the agent command center (the control screen for managing tasks centrally), you can search older tasks directly. You can look them up by task name or prompt preview (the opening text of your original instruction). If you only remember which project folder a task lived in, you can also search by entering its working directory (the folder path where the task runs). Suppose you asked it to organize meeting notes last week: typing a few words you wrote then brings that older task right back up.

Picture scrolling through your phone's photo album for a trip from last year: previously you had to swipe up from the newest shot, whereas now typing a place, album name, or visual keyword jumps straight to that photo.
FEATURE

Full-screen transcript folds turn details while keeping answers visible and tool output searchable

After a conversation builds up many back-and-forth steps, the full-screen transcript (the expanded view showing the complete exchange) often fills up with execution details.

Imagine a report clipped to a thick stack of appendices: previously you had to flip past pages of verification steps to reach the main text, whereas now folding the appendices away leaves the conclusions visible while still letting you look up details when needed.

Turn on **Collapse turn details** in this view to fold completed activity beneath each prompt. When you want to read straight through the reply after it finishes revising a report, the AI's answers still stay visible on screen. Even with those details tucked away, folded tool output (execution results returned by external utilities) remains searchable so you can pull up any snippet anytime.

FEATURE

Terminal supports adding and editing custom model providers with device-code sign-in

If your team self-hosts an AI service or connects to a remote machine without a graphical interface, configuring a model source in the terminal used to be roundabout. Now you can add or edit custom model providers (service endpoints that supply AI) directly from the terminal. With custom gateway onboarding (the setup flow for connecting to your own relay for the first time) enabled, you can create a provider during sign-in. This flow is handy when connecting over SSH (a protocol for securely operating remote machines) or working without a local browser. When supported by that gateway, you can authorize sign-in using a device code (a short verification string you enter elsewhere) instead.

Signing in works much like activating a streaming account on a hotel TV: without a browser on the screen you could not authorize on the spot before, whereas now a pairing code pops up for you to enter on your phone and link your custom source.
FEATURE

Pressing Ctrl+S in the terminal report editor saves a diagnostic ZIP locally

When you run into an issue and want to gather error details while uploads are turned off, that data can easily get stuck unsent. Now you can press Ctrl+S in the terminal report editor (the interface for writing and submitting issue details) to save a diagnostic ZIP archive directly to your machine. Even when uploads are disabled, this shortcut still saves the file as expected. When you need to keep on-site records in an isolated network environment, opening the editor and pressing Ctrl+S keeps the packaged diagnostic archive right on your computer.

When a mail drop slot is sealed shut, a stack of papers previously stayed stuck at the counter with nowhere to go, whereas now you can seal them into a folder and keep them yourself anytime.
FEATURE

Cloud connection on macOS and Linux terminals supports sending images, choosing models, and archiving chats

When working in a macOS or Linux terminal, there used to be few options you could adjust once connected to a Cloud conversation. With the opt-in Cloud connection (a bridge from your local terminal to hosted services) enabled, you can now handle much more right inside the terminal.

An old remote extension that only sent text messages has turned into a full-featured desk: now images go through, thinking depth is selectable, and finished conversations can be filed away or brought back.

You can send images directly from the terminal, and choose both the model and the reasoning effort (the setting that controls how deeply the AI thinks through answers). Whether you have a design sketch for a Cloud model to inspect or want to switch models for a complex question, you can do it all without leaving the terminal. Once a conversation wraps up, you can archive that Cloud chat and restore it later if needed.

FEATURE

codex exec keeps project config disabled in untrusted directories unless saved with --trust

When taking over an unfamiliar project folder, running automated tasks right away raises the concern of its settings being activated without your say. In untrusted directories, codex exec continues to keep project configuration and MCP (a protocol that lets AI link to external tools) servers disabled. Even if you also pass --sandbox workspace-write (a permission level that allows writing files in the project folder), neither will be enabled. Once you confirm the folder is safe, use --trust with codex exec or codex review to explicitly save project trust:

codex exec --trust
codex review --trust

A stranger coming over to help move furniture might be allowed into your living room to work, yet every appliance switch stays locked until the homeowner explicitly grants permission.
FEATURE

Yes, clear context and implement hands off the full approved plan and keeps the original session on failure

After discussing and approving an execution plan, selecting **Yes, clear context and implement** clears the lengthy prior context and starts work right away. This option now hands the full approved plan over to the fresh session (a single standalone conversation and execution environment). If the handoff fails partway through, the original session stays open. Once you have spent time aligning the steps and are ready to let Codex run, you can clear context with confidence without worrying about missing parts of the plan in the new chat or losing both sides if the handoff errors out.

At a hospital shift change, handing the entire approved chart to the next shift means the outgoing team stays at its post rather than walking away if the handoff falls through.
BUGFIX

Fixed Windows sandbox handling for quoted cmd.exe paths and PowerShell permissions

When using the sandbox (an isolated environment that restricts what programs can access) on Windows, execution used to fail whenever a cmd.exe path was quoted or a PowerShell session's working directory had an unreadable parent folder. Windows sandbox handling for both scenarios has now been fixed.

FEATURE

Pasted images on macOS keep their orientation and use native PNG or JPEG data

Copying an image on macOS and pasting it into a chat for the AI to inspect used to be frustrating when its orientation came out sideways. Pasted images on macOS now reliably retain their intended orientation. Whenever native PNG or JPEG data is present on the clipboard (the system space that temporarily holds copied items), those native formats are used. When you copy a portrait shot from an image editor or photo album and paste it in, you no longer have to worry about it landing on its side.

Sending a freshly straightened photo to a friend used to flip sideways on arrival sometimes, whereas now it keeps its upright orientation.
BUGFIX

Terminal no longer waits on unreported MCP servers, and interrupted turns close cleanly

When you hit stop mid-task or wait on external connections, the terminal can occasionally stay busy or even disrupt the next conversation turn.

Once the curtain falls, the stage crew clears the previous act right away; previously, missing roll calls or late cue-to-stop shouts dragged down the next scene, but now ending one act wraps it up cleanly without spilling into the next.

The terminal no longer stays busy waiting for MCP (the protocol that lets AI connect to external tools) servers that a shared app server did not report. A shared app server is a program that coordinates connections in the background. Interrupted conversation turns now close more cleanly. Delayed aborts or file approval cancellations also no longer mistakenly interrupt a later turn.

FEATURE

Updated `openai-docs` skill and documentation with team setup and gateway authorization

When first adopting a tool or standardizing settings for an entire team, unfocused official documentation can leave you unsure where to start.

Rewriting a company onboarding packet makes everything clear at once: what steps a newcomer takes on arrival, how the whole department aligns its rules, and even how partner contacts look up the directory.

The openai-docs skill (a prewritten module of specialized knowledge for AI to consult) has been updated to focus on Codex and ChatGPT Work questions as well as first-time API setup steps, and adds a dedicated section on configuring Codex across a team. Official documentation has also been added for app-server clients (external programs that connect to a background service to operate), explaining how to list models or authorize a gateway for a configured provider without changing the default provider.

BUGFIX

Bundled SQLite upgraded to 3.54 with write-ahead log fixes

When checking the bundled components in this Codex update, you will notice a version bump for the database engine. Codex upgrades its bundled SQLite (a lightweight local file-based database) to version 3.54. This update mainly picks up fixes related to the write-ahead log (a mechanism that records data changes to a journal file before writing them back to the main file).

Just as an accountant switches to a newer ledger, the flaws in jotting down a draft before posting it to the general ledger are fixed, keeping everyday records steady behind the scenes.
FEATURE

Plugin marketplace upgrades reuse local Git objects to reduce repeat downloads

When updating an extension store to the latest version, fetching the entire bundle from scratch every time transfers a lot of content your computer already has. Now, when the plugin marketplace (the store used to browse and install extensions) upgrades, it can reuse existing data on your computer. During the upgrade, it directly reuses Git objects (the data units a version control system uses to store files and history) already on disk, reducing the amount of data downloaded again. When you upgrade the plugin marketplace, you no longer have to re-download everything you have already fetched.

Replacing an encyclopedia with a newer edition used to mean shipping a whole box of heavy volumes again, whereas now, seeing the earlier volumes already on the shelf, only the new pages need to be filled in.
