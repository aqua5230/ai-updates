Codex 0.150.0

Released: 2026-08-26

Release notes

FEATURE

Reference tasks with @ mentions and manage tasks via terminal agents

When running multiple parallel tasks in the terminal, coordinating across workflows is now as natural as using team chat.

It is like @-mentioning a project ticket in a group channel so an assistant can immediately inspect another team's progress, open a new task, or drop a memo.

You can now use @ mentions to reference other Codex tasks directly in your prompt. You can also ask agents from the terminal to inspect existing tasks, spin up new ones, or dispatch messages to active tasks without manual copy-pasting.

FEATURE

/copy introduces an interactive picker for responses, code blocks, and quotes

When extracting a specific snippet or excerpt from a long reply, you no longer need to drag your mouse across terminal text.

Running /copy now opens an interactive picker menu. You can explicitly choose between copying the full response, individual code blocks, or markdown blockquotes.

It is like a bento box where main dishes, sides, and rice are neatly partitioned so you can pick out the exact portion you want without dumping the whole container.
FEATURE

Unnamed tasks get automatic titles and /rename suggests conversation-based edits

When juggling multiple background tasks in your terminal, identifying what each task is doing is now effortless.

It is like a diligent librarian who glances at an unlabelled folder to affix a descriptive spine label, and offers a pencil draft when you ask to rename it.

Unnamed terminal tasks now automatically receive descriptive titles based on context. Furthermore, running /rename inspects your conversation history and suggests an editable title proposal, saving you from having to type names manually.

FEATURE

Clickable Markdown link labels in supported terminals with URLs preserved elsewhere

Reviewing responses that contain hyperlinks is now much cleaner in your terminal.

On supported terminals, Markdown links render as tidy, clickable text labels. In environments without hyperlink support, the full visible URLs remain intact so you can still read and copy them easily.

It is like a modern touchscreen display where keywords are directly tap-friendly, while a printed guide still prints the full web address alongside them for completeness.
FEATURE

Custom shortcuts cycle permission modes

You can bind cycling through permission modes to a custom shortcut.

A permission mode determines how Codex handles confirmation before an action, and the bound key moves through the available modes in sequence.

It is like the program dial on a washing machine: each turn advances to the next wash cycle, and that dial has only one job—choosing a cycle.

When your work calls for a different confirmation approach, press the shortcut you configured to cycle to it.

FEATURE

Vim mode uses `.` to repeat the last edit

When the same text change is needed in several places in Vim mode, pressing . now repeats your last edit.

Vim mode is a keyboard-command way to edit text; . reruns the edit you just completed, so you do not need to type that same change again.

It is like a word processor's Repeat Last Action button: after one edit, pressing it applies that edit again, and it does not switch any work mode.

This is the editing-repeat feature for Vim mode.

FEATURE

New Interrupt hooks trigger commands or MCP handlers on cancelled turns

When cancelling an active turn midway, automated cleanup and custom actions can now take over immediately.

It is like an emergency stop switch on an assembly line that instantly triggers exhaust vents and safe power-down sequences to keep the floor clean.

Codex introduces Interrupt hooks. When an active top-level conversation turn is interrupted, these hooks can automatically run shell commands or trigger MCP handlers, allowing your environment to safely persist state or release held resources instead of abruptly terminating.

FEATURE

Block untrusted project AGENTS.md and preserve managed deny-read rules

Opening repositories from unknown sources is now significantly safer.

Untrusted projects are no longer allowed to supply project-level AGENTS.md instruction files, preventing malicious repositories from hijacking AI behavior with embedded prompts. Additionally, managed deny-read security rules remain strictly enforced even after interactive permission changes occur during a session.

It is like a visitor who cannot bring their own house rules to security, and even after receiving a temporary pass, confidential archive access remains firmly locked.
FEATURE

Enhanced credential redaction for provider, refresh, and attestation diagnostics

Exporting diagnostic reports for troubleshooting is now much safer.

Codex has expanded credential redaction across app-server diagnostics. Sensitive data is now automatically masked across provider details, authentication refresh flows, and hardware attestation fields. When you share debug output with maintainers, secret tokens and verification payloads will never leak into log files.

It is like preparing an audited statement where an automated marker blacks out personal IDs, refresh codes, and security stamp certificates before export.
BUGFIX

Fix remote MCP bearer token lookup and startup while keeping executor compatibility

Connecting to remote tool extensions is now much more dependable.

It is like a retail network upgrading its authentication lines to reliably verify access tokens and boot core servers, while remaining fully backwards-compatible with older register hardware.

Codex has resolved issues with remote MCP server connections. The system now reliably looks up bearer tokens and initializes required servers without failure, all while maintaining full backwards compatibility with older executor environments.

BUGFIX

Fix elevated Windows sandbox setup and launch aliases under Unicode paths

Running Codex on Windows with elevated permissions or special account names is now completely smooth.

Previously, if a user profile folder contained non-ASCII Unicode characters (such as accents or non-Latin scripts), launch aliases would often fail. Elevated sandbox environments running with administrator privileges also encountered initialization errors. Both path handling and privilege escalation setups are now resolved.

It is like a print shop tuning its typesetting and setup line: labels in different scripts are recognized correctly, and an isolated work bay needing high-spec equipment is prepared without a hitch.
FEATURE

Prevent Unix shutdown hangs caused by detached processes or full buffers

Exiting Codex on Unix systems like macOS or Linux is now fast and reliable.

Previously, shutting down could hang indefinitely if detached background processes still held terminal handles or if output buffers were completely full. The shutdown sequence now cleans up detached processes and flushes full buffers properly.

It is like locking up an office at the end of the day: even if a paper shredder in the corner is still plugged in or its output tray is full, the master switch reliably cuts power and lets you lock the doors.
BUGFIX

Fix Amazon Bedrock conversation compaction and multi-agent compatibility

Running long conversations and multi-agent setups through cloud platforms is now much more reliable.

It is like a remote conference team where an assistant cleanly summarizes lengthy meeting records while specialized specialists collaborate on the same call without stepping on each other.

For developers using Amazon Bedrock models, Codex has fixed errors during conversation compaction when compressing long context windows. Multi-agent compatibility issues have also been resolved, allowing multiple sub-agents to collaborate smoothly.
