Codex 0.164.0

發布日期：2026-10-23

繁體中文

新功能

/presets 新增十組快捷欄位，常用提示詞與指令隨選即用

當你反覆在對話中輸入相同的檢查指令或固定提問時，重新打字往往耗費時間。

宛若汽車音響上的電台記憶功能，以前想聽固定頻道每次都要手動調頻，現在可以選取已儲存的頻道。

現在你可以打 /presets 將常用的提示詞與斜線指令儲存到十個編號欄位中。呼叫時還會跳出專屬的鍵盤選單，讓你透過鍵盤快速選取所需的預設項目。例如每次開始整理報告時，就能透過鍵盤選單選取儲存好的審查指令，省去反覆翻找與複製貼上的麻煩。

新功能

/model 與 /permissions 支援行內參數，單行直接套用設定

臨時需要切換模型或調整執行權限時，你可以把要用的設定直接接在指令後面。

如同在義式咖啡機直接轉動濃淡旋鈕，以前分開調整的出杯速度與風味濃度，現在點選飲品時順手一扭就能一併指定。

現在打 /model 或 /permissions 時，可以直接在同一行指令接上參數。你能直接在指令後方指定模型名稱、運算速度與推理解題力度（reasoning effort）。如果需要變更授權層級，也可以透過行內參數指定權限設定檔（permission profile）。這讓你輸入一行指令就能立刻切換到所需的執行環境。

新功能

支援 Kitty 與 Sixel 協定，全螢幕紀錄直接預覽圖片

在純文字終端機中請 AI 產生或查看圖片時，常常必須切換到外部檢視器才能確認成果。

彷彿按下數位相機快門後直接在電子觀景窗回放相片，以前非得把記憶卡插進電腦螢幕才能檢視構圖，現在眼睛不用離開目鏡就能看清影像細節。

如果你的終端機支援 Kitty 或 Sixel 圖形協定，現在全螢幕對話紀錄中可以直接預覽圖片。無論是讓工具讀取既有的本機圖檔，或是由模型新產生的圖片，畫面都會直接在紀錄中渲染顯示，不必再特地跳出視窗開啟檔案。

新功能

企業級 MCP 支援專用登入與帳號授權，納入金鑰用戶端

企業團隊在將內部系統串接至外部工具時，往往受限於嚴格的身分核驗與安全規範。

跟持員工證進入特約商務中心一樣，以前訪客通道只能辨識一般識別貼紙，現在閘門不僅支援企業總部的數位權限卡，也能核對附帶安全密鑰的專屬通行條。

現在企業級 MCP（Model Context Protocol，讓 AI 連接外部工具的協定）連線支援更多元的驗證方式。你可以使用符合資格的 Codex 帳號授權直接通行，或是使用專屬登入通道完成驗證。對於需要用戶端密鑰（client secret）的 OAuth 用戶端，現在也能順利通過身分確認，安全連接各項企業服務。

新功能

Amazon Bedrock 設定精靈預設啟用，自動整合 AWS 登入方式

初次在工具中設定雲端模型提供者時，複雜的認證流程常讓人無所適從。

好比智慧電視初次開機的引導流程，以前要自己翻出網路線與遙控器代碼手動輸入，現在一開機就自動跳出連線精靈，還會把同品牌的登入選項整合在同一個畫面。

現在 Amazon Bedrock 的設定引導精靈改為預設開啟。當系統偵測到環境中的憑證時，API 金鑰輸入選項會自動與其他 AWS 登入方式歸類在同一個區塊，讓你清楚檢視並選取合適的登入途徑，不必再四處尋找設定入口。

問題修復

對話壓縮失敗自動備援，恢復工作階段完整保留討論串設定

長時間與 AI 討論累積了大量對話紀錄時，背後的摘要壓縮機制是維持流暢對答的關鍵。

就像編輯長篇文件時的自動存檔機制，以前存檔失敗會在草稿夾留下一半的殘缺摘要，重開檔案時個人偏好也被重設成原廠設定；現在即使背景壓縮失敗也會平穩備援，重新開啟時還能精準還原原本的排版。

現在對話歷史壓縮（compaction）若不幸失敗，不會再於對話紀錄中留下半截殘缺的摘要內容，背景壓縮失敗時也會安全備援而不引發程式異常崩潰。恢復工作階段（session）時，工具現在能確實找到已壓縮的歷史紀錄，並完整復原原本討論串儲存的設定，而不是擅自將它們覆蓋成全域預設值。

新功能

自動清理未使用的安裝與市集暫存，設定日誌上限釋放磁碟空間

工具在背景持續運作或頻繁下載外掛後，磁碟空間常常在不知不覺間被暫存檔案佔滿。

類似手機定期執行儲存空間大掃除，以前沒在用的舊版本與未再使用的檔案包會一直堆在角落，背景服務的紀錄簿也無限膨脹；現在清理工具會主動清空廢棄包裝，並替紀錄簿設下頁數上限。

現在工具加入了多項磁碟維護機制來降低空間佔用。系統會主動修剪不再使用的安裝版本，清理市集中已棄置的 checkout（取出的檔案副本）。同時替常駐程式（daemon）的日誌檔案設定大小上限，防止日誌無限制增長消耗硬碟空間。

新功能

強化執行環境安全防護，遮蔽終端機憑證並嚴格檢驗路徑

在執行腳本或調用系統環境時，防止敏感資訊外洩與防堵潛在執行漏洞是保障系統安全的核心關鍵。 終端機操作方面，支援的遠端 Bash 指令與 Zsh 快照工作階段（session）現在會自動遮蔽各類憑證，包含來自自訂提供者的敏感認證金鑰，避免機密在紀錄或螢幕輸出中曝光。 沙盒防護也有所強化，針對 macOS 系統上大小寫變形的中繼資料路徑，以及用來尋找執行檔的符號連結（symlink，指向另一個位置的捷徑檔），都加入了嚴格的檢驗機制，防止路徑被惡意替換。 內嵌的 JavaScript 執行環境也完成更新，為最佳化後的 Array.sort 排序操作加入安全檢查，防範異常。以前在遠端執行或排查腳本時容易擔心金鑰外洩或路徑被掉包，現在各個執行環節都有專門的安全防線把關。

問題修復

Windows 支援代理伺服器驗證，指令列設定覆寫與排隊流程修復

在企業網路環境或複雜的指令列流程中，連線驗證與參數傳遞的正確性直接影響工作進展。 在 Windows 系統中，HTTPS 與 WebSocket 連線現在能正確處理代理伺服器（proxy）的驗證要求，自動使用已登入使用者的 Negotiate 或 NTLM 憑證完成身分查核，避免連線失敗中斷。 在終端機執行多層子指令時，若在不同層級重複帶入 -c 或 --config 參數，現在各層級的設定覆寫值都會完整保留，不再被意外覆蓋或遺失。 排隊等待執行的提示詞也調整了執行邏輯，現在會確實等候前方擱置中的權限確認選單完成選擇，才會繼續往下執行。以前遇到內網代理或連續提問時容易卡在連線中斷或權限錯亂，現在整套指令與排程流程都能順暢運行。

English

FEATURE

/presets adds ten shortcut slots for instant access to frequent prompts and commands

When you repeatedly enter the same inspection commands or standard questions during a conversation, retyping them is often time-consuming.

Picture a car radio with station presets, where listening to a favorite channel once required manual tuning each time, but now only takes selecting a saved station.

You can now type /presets to store frequently used prompts and slash commands into ten numbered slots. Invoking it brings up a dedicated keyboard menu so you can quickly choose the preset you need. For example, whenever you start compiling a report, you can select a saved review command through the keyboard menu, eliminating the hassle of searching around and copy-pasting.

FEATURE

/model and /permissions support inline arguments to apply settings in one command

When you need to switch models or adjust execution permissions on the fly, you can append your desired settings directly to the command.

Think of turning a brew strength knob on an espresso machine, where cup speed and flavor intensity once had to be adjusted separately, but now can be set with a quick twist when selecting a beverage.

When typing /model or /permissions, you can now pass arguments directly on the same line. You can specify the model name, compute speed, and reasoning effort right after the command. If you need to change authorization levels, you can also specify a permission profile through inline arguments. This lets you switch immediately to the required runtime environment with a single command.

FEATURE

Kitty and Sixel protocols supported to preview images directly in fullscreen logs

When asking AI to generate or inspect images in a plain-text terminal, you often have to switch to an external viewer to verify results.

Much like checking a digital camera's electronic viewfinder right after pressing the shutter, where reviewing composition once required plugging a memory card into a computer monitor, you can now inspect image details without taking your eye off the eyepiece.

If your terminal supports the Kitty or Sixel graphics protocol, you can now preview images directly inside fullscreen conversation transcripts. Whether the tool reads an existing local image file or displays a new image generated by the model, the graphic renders directly within the log without opening an external window.

FEATURE

Enterprise MCP supports dedicated login and account authorization with secret client access

When enterprise teams connect internal systems to external tools, they are often constrained by strict identity verification and security policies.

Just as entering a partner business center with an employee badge once only supported basic visitor decals, the gate now accepts corporate digital access cards as well as dedicated passes with security keys.

Enterprise MCP (a protocol connecting AI to external tools) connections now support more diverse authentication methods. You can authenticate directly using eligible Codex account authorization or complete verification through dedicated login channels. OAuth clients requiring client secrets can now also pass identity verification smoothly and securely connect to various enterprise services.

FEATURE

Amazon Bedrock setup wizard enabled by default to integrate AWS login methods

When configuring a cloud model provider in the tool for the first time, complex authentication flows can feel overwhelming.

Consider the initial setup guide of a smart TV, where you once had to find Ethernet cables and enter remote codes manually, but now a setup wizard appears automatically and brings brand login options together on one screen.

The configuration setup wizard for Amazon Bedrock is now enabled by default. When credentials are detected in the environment, the API key input option is automatically grouped into the same section alongside other AWS login methods. This allows you to clearly view and select the appropriate sign-in path without searching around for configuration menus.

BUGFIX

Compaction failures fall back smoothly while resumed sessions preserve thread settings

When extensive discussions with AI accumulate substantial conversation history, the underlying summary compaction mechanism is essential for maintaining smooth exchanges.

Like an autosave feature while editing a long document, where a save failure once left a broken half-summary in drafts and reset personal preferences to factory defaults upon reopening, background compaction failures now fall back smoothly and restore original layouts upon relaunch.

If conversation history compaction fails, it no longer leaves partial summary fragments in transcripts, and background compaction failures now fall back safely without triggering crashes. When resuming a session, the tool reliably finds compacted history and fully restores the thread's saved settings instead of overwriting them with global defaults.

FEATURE

Prune unused installs and marketplace caches while capping daemon logs to free disk space

When tools run continuously in the background or download plugins frequently, disk space often fills up unnoticed with temporary files.

Similar to periodic storage cleanups on a smartphone, where unused old versions and abandoned package archives once piled up in corners while background logs grew without bound, cleanup tools now purge obsolete packages and cap log pages.

The tool now includes several disk maintenance mechanisms to reduce disk usage. The system actively prunes unused installation versions and cleans up abandoned marketplace checkouts (extracted working copies of files). It also sets a size limit on daemon log files to prevent logs from growing indefinitely and consuming disk storage.

FEATURE

Harden runtime security by masking terminal credentials and strictly validating paths

When executing scripts or invoking system environments, preventing sensitive information leaks and closing potential execution vulnerabilities are essential to securing the system. For terminal operations, supported remote Bash commands and Zsh snapshot sessions now automatically mask various credentials, including sensitive authentication keys from custom providers, preventing secrets from being exposed in logs or screen output. Sandbox defenses have also been strengthened by adding strict validation mechanisms against case-variant metadata paths on macOS and symlinks (shortcut files pointing to another location) used to locate executables, preventing paths from being maliciously substituted. The embedded JavaScript runtime has also been updated to add safety checks to optimized Array.sort operations, guarding against anomalies. While running or debugging scripts remotely once raised concerns about leaked keys or swapped paths, dedicated security safeguards now protect each execution stage.

BUGFIX

Windows supports proxy authentication alongside fixes for CLI config overrides and prompt queuing

In enterprise network environments or complex command-line workflows, the reliability of connection authentication and parameter passing directly impacts work progress. On Windows, HTTPS and WebSocket connections now properly handle proxy authentication challenges by automatically verifying identities with the logged-in user's Negotiate or NTLM credentials, preventing connection failures. When running nested subcommands in the terminal with -c or --config arguments repeated across different levels, configuration overrides at each tier are now fully preserved instead of being accidentally overwritten or lost. Queued prompts have also received updated execution logic, now reliably waiting for preceding pending permission menus to finish their selection before continuing execution. While corporate proxies or consecutive prompts once led to dropped connections or permission mix-ups, the entire command and scheduling pipeline now runs smoothly.
