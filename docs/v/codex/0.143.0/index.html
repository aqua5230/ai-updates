遠端外掛預設開放，自動穿透公司代理伺服器

以後找幫手更方便了。系統現在「預設」為你開啟遠端外掛功能，不僅清單顯示得更豐富、看得到遠端和本地端的版本差異，還支援直接從 npm 商城抓取資源。最棒的是，如果你在公司裡使用，不管是認證還是呼叫 API 的網路流量，現在都會乖乖走 macOS 和 Windows 內建的系統代理伺服器（proxy），連 PAC 或 WPAD 這種複雜的自動設定也能輕鬆搞定。就像逛國外網購變成全自動，商品型錄變得更精美還標示了產地；而且如果你在公司裡網購，包裹現在懂得自動走公司的收發室跟保全通道，再也不會被卡在防火牆外了。

迎接 GPT-5.6 家族，還有除錯跟手動配對新招

現在 Amazon Bedrock 使用者可以選擇 GPT-5.6 家族（Sol、Terra、Luna），並支援使用最高等級的「全力思考（max）」推論。對開發者來說，應用伺服器端現在多了一堆像顯微鏡一樣的超強工具：你可以直接查看環境變數、列出往下衍生的所有子對話，甚至從某一個特定對話的瞬間「分岔（fork）」出新的歷史紀錄來做測試。此外，我們也加了 codex remote-control pair 指令，讓你從執行中的後台程式手動產出配對碼。就像你手下多了一批能全功率運轉的天才員工；同時你還拿到了一支能倒轉時光的懷錶，隨時能暫停會議、偷看大家的筆記，或是從十分鐘前的那句話分岔出另一個平行宇宙來看看結果會怎樣，甚至還有一把萬能備用鑰匙幫你手動解鎖遙控器。

工具搜尋更自動，底層套件補上安全漏洞

AI 呼叫 MCP（外部工具通訊協定）時，現在預設會用關鍵字去搜尋合適的工具；且 ChatGPT 代管的 MCP 伺服器，現在能明確指定使用當前對話（session）的專屬認證。我們也在底層幫你鞏固了防線，一口氣更新了 OpenSSL、Hono、fast-uri、quick-xml 這些套件來修補最近被發現的安全漏洞。此外，官方還貼心地補上了關於 UUID7 代碼的說明文件，並幫開發者整理了測試遠端連線的最佳流程。就像你的萬能瑞士刀現在學會了自動幫你挑出對的刀片，並且修補了刀把上容易鬆脫的螺絲，最後還附上一本詳細的保養手冊，確保你用起來又順手又安全。

Windows 終端機不再亂跳，除蟲大軍修好各種斷線問題

如果你用 Windows 終端機（ConPTY），換行跟倒退鍵（Backspace）終於不會再錯亂了。畫面上那些已經取消的「安全警告」也不會再死皮賴臉地卡在畫面上，害系統看起來像是在忙碌卡死。如果遇到遠端伺服器短暫斷線，系統現在恢復得更好，不會再發瘋似地狂重試刷爆驗證碼；而且在系統關機時，原本那些來不及印完的即時對話尾巴，現在也都會好好存下來，不會憑空消失。此外，系統懂得在比對 WebSocket 請求時忽略不重要的後設資料，讓連線更成功；安裝程式也變得更聰明，會重複利用下載過的發布資訊，不會動不動就被 GitHub 阻擋下載。就像維修工一次修好了鍵盤上卡住的倒退鍵、擦掉螢幕上殘留的警告貼紙、讓網路斷線時路由器不再發出崩潰的嗶嗶聲，還確保你關機前最後一句打完的話都有被好好存檔。

en

Remote plugins by default and flawless system proxy routing

Bringing in outside help is easier than ever. The system now enables remote plugins by default, featuring a much richer catalog that clearly shows both remote and local version differences, plus it now supports pulling directly from the npm marketplace. Best of all, if you're working behind a corporate firewall, all authentication and API network traffic will now seamlessly route through your macOS and Windows system proxies—including complex PAC and WPAD auto-configurations. Like international online shopping finally becoming effortless: the product catalogs are gorgeous and clearly label exactly where things come from, and if you're ordering from the office, the packages magically know how to navigate the company's strict mailroom and security checkpoints without ever getting stuck.

Welcome the GPT-5.6 family and powerful new debugging tools

Amazon Bedrock users can now select the GPT-5.6 family (Sol, Terra, and Luna) and use their absolute maximum (max) reasoning effort. For developers, the app-server client has gained microscope-level debugging tools: you can now inspect underlying environments, list out all descendant thread branches, and even fork your conversation history straight from a specific past turn to test different outcomes. Additionally, there's a new codex remote-control pair command that lets you manually generate pairing codes directly from a running daemon. It's like hiring a squad of brilliant geniuses who can run at 100% brain capacity; while simultaneously being handed a magical pocket watch that lets you pause meetings, peek at everyone's notes, or branch off an alternate universe from something said ten minutes ago just to see what would happen—plus a trusty backup skeleton key for manual remote unlocking.

Automated tool search and patched underlying security flaws

When calling MCP (the protocol for external tools), the AI now defaults to searching for the right tool by keyword; additionally, MCP servers hosted by ChatGPT can now explicitly specify session-specific authentication. We've also fortified the underlying defenses, upgrading core packages like OpenSSL, Hono, fast-uri, and quick-xml to immediately patch recently disclosed security vulnerabilities. For developers, the team thoughtfully added documentation explaining how UUID7 IDs work for threads and turns, along with recommended workflows for testing remote execution. Like a Swiss Army knife that automatically pops out the correct blade for the job, while the manufacturer tightened a few loose screws on the handle to prevent accidents, and tossed in a detailed maintenance manual to ensure it stays sharp and safe.

Fixed Windows terminal inputs and smoothed out disconnect hiccups

If you're using a Windows terminal (ConPTY), line endings and the backspace key will finally stop acting weird. Cancelled "safety prompts" will no longer stubbornly stick to your screen, falsely making the system look like it's busy stalling out. When a remote server drops offline temporarily, the system now recovers much more gracefully instead of panic-retrying and blowing up the token refresh limits; and when the system shuts down, any trailing real-time conversation text that hasn't finished printing will now be properly saved instead of vanishing into thin air. Furthermore, incremental WebSocket requests are now much more reliable because the system smartly ignores irrelevant metadata during comparisons; and the installer is now clever enough to reuse release metadata, so it stops getting rate-limited and blocked by GitHub. Like a mechanic who finally unstuck your jammed backspace key, peeled the obsolete warning stickers off your monitor, stopped your router from panic-beeping during a lag spike, and made sure your very last sentence was safely saved before your computer powered down.
