API 支援指定 GPT-6-Astra，不改預設也不進選單

如果你透過 API 串接 Codex 跑程式，現在可以直接在呼叫時指定使用 GPT-6-Astra 模型。它既不會動到你日常使用的預設模型，也不會出現在模型挑選器（model picker，供手動切換模型的選單）裡面。這讓需要特定模型的後端腳本能順利運作，一般在介面挑模型的人看不到這個選項。這就像餐廳為外燴訂單開放私房菜色，廚房能照單出菜，但大廳的常態菜單與櫃檯點餐看板依然維持原樣，不必擔心常客點餐時眼花。

en

Support specifying GPT-6-Astra via API without changing defaults or appearing in the picker

If you connect to Codex via API to run code, you can now specify the GPT-6-Astra model directly in your API calls. It will neither modify your everyday default model nor appear in the model picker (the menu for manually switching models). This allows backend scripts requiring a specific model to run smoothly without exposing the option to users selecting models in the interface. It is like a restaurant offering off-menu specialties exclusively for catering orders: the kitchen prepares them as requested, while the dining hall's regular menu and ordering board remain unchanged, preventing regular diners from getting confused when ordering.
