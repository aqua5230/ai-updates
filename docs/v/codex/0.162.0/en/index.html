Codex 0.162.0

Released: 2026-10-08

Release notes

FEATURE

Support for Managing Git Worktrees to Develop Multiple Branches in Parallel

When you want to develop different features in the same project simultaneously without interrupting progress by frequently switching branches, dedicated tools are now available in trusted local projects.

Once the worktree feature is enabled, the AI can directly create and list managed Git worktrees (parallel copies of the same project managed by Git).

Picture laying an extra sheet of tracing paper beside your drawing paper: whereas sketching a new idea previously meant erasing original lines, you can now work on two drafts simultaneously and cross-reference them at any time.
FEATURE

Pin Important Tasks via Keystroke to Group Them at the Top

When tracking multiple tasks simultaneously in the agent command center and looking to keep the most critical items prominent, you can now press the p key on your keyboard to pin them quickly.

As long as the server supports this capability, pinned tasks are consolidated into a shared Pinned group, making it easy to review their progress at any time.

Like placing sticky notes on an office whiteboard, where a growing list of to-dos once got buried under incoming tasks, you can now pin pressing items to a dedicated top section for immediate visibility.
FEATURE

Flexible Terminal UI Copying and Adjustable Scroll Speed

When browsing long conversations in the terminal UI, extracting specific code snippets or key responses is now much smoother.

You can enter /copy to select and copy conversation blocks, or press Ctrl+Insert to copy text currently highlighted by the mouse. If the terminal UI scrolls too fast or too slow, you can also add tui.mouse_scroll_speed in the settings to adjust the mouse wheel scroll speed.

Think of switching to a handy page-turner while reading a long e-book, where selecting and copying text was once constrained by window interactions, but you can now capture exact passages and fine-tune your scrolling pace.
FEATURE

Clickable Terminal Prompt URLs with Unbroken Multi-Line Links

When the AI displays confirmation questions or warning messages in the terminal with reference URLs, you no longer need to manually highlight and copy them.

Whether a URL appears in a confirmation header, question list, warning banner, verification prompt, or an MCP (Model Context Protocol, a protocol that connects AI to external tools) prompt, you can click to open it directly. Even if a URL is long and wrapped to the next line by the terminal, the link still opens completely without breaking in two.

A printed book includes a complete QR code next to its footnotes: whereas long URLs split across two lines were once prone to copying errors, scanning directly now opens the exact page.
FEATURE

Custom Models Gain Web Access and Remote Compaction Support

If you connect custom model providers compatible with the Responses API, you can now enable more advanced capabilities for them.

You can configure live web access directly for these custom models so they can retrieve the latest web information. You can also configure remote compaction so that conversation summaries are processed remotely.

Equipping an external expert assistant with an updated encyclopedia and a secretary allows you to provide tools for looking up fresh data while also assigning a secretary to condense conversation logs.
FEATURE

JavaScript Async Streaming Support and Ranked Tools in Code Mode

When writing automation scripts or handling numerous tools in Code Mode, the development experience is further enhanced.

New JavaScript helper utilities now stream results back immediately as multiple asynchronous operations (Promise instances) complete individually, without waiting for every task to finish. Furthermore, in Code Mode, you can actively enable ranked tool search so the system recommends the most relevant tools by relevance.

Food delivery orders send real-time alerts as each dish leaves the kitchen: instead of waiting for the entire table of dishes to be cooked before serving, you receive each item as it is ready and locate utensils much faster.
FEATURE

Terminal Sessions Follow Default Models While Preserving Manual Overrides

When starting a new terminal conversation, the system now prioritizes server-configured defaults for models and reasoning summaries.

Whereas creating a new conversation previously could ignore default server settings, the system now adheres fully to these defaults. If you manually pass specific parameters at launch, the system also prioritizes and retains your explicit override values instead of overwriting them with defaults.

Dining at a chain restaurant illustrates the change: while the kitchen previously could mix up standard recipes, it now serves according to the standard menu by default while still honoring any custom preferences specified on your order.
FEATURE

Patch Application Preserves Line Endings Without Corrupting Windows Files

When patching code in Windows environments, you no longer need to manually specify settings to preserve original line endings.

Previously, updating files with apply_patch could alter existing CRLF line endings (the standard Windows line-ending format) unless an extra option was enabled; apply_patch now automatically preserves the file's original line endings. This issue is resolved, preventing unintended diffs across the entire file when committing changes to version control.

Maintaining legacy documents once required ticking an extra box on every revision to keep original formatting from getting overwritten, but applying edits now preserves line endings automatically.
BUGFIX

Enhanced Linux Sandbox Startup Protections and Enforced File Isolation

When using the security sandbox to isolate execution environments on Linux, the system fixed several security constraints related to startup and file access.

The sandbox previously could fail to start when multiple denied files were configured, but this startup process is now fixed. Sandboxes now reject writable executables used to construct the sandbox. The ripgrep configuration was also corrected to ensure search settings do not weaken deny-glob file mask protections.

A bank vault fixes a stall that occurred whenever access denial lists grew too long, rejects modifiable installation tools, and ensures search settings never undermine restricted lists.
FEATURE

Restored Windows 10 Drive Access and Consistent Sandbox Temp Permissions

If you run commands or use sandboxed environments on Windows 10, previously encountered missing path and permission errors are now resolved.

Standard drive letter file access (such as common C: and D: drives) is restored, preventing errors when reading or writing existing files. Permissions for temporary directories inside the Windows sandbox are also aligned with environments of subprocesses (child processes started by the main program), preventing programs from hanging due to permission mismatches during execution.

Obtaining a matching keycard resolves previous hurdles on Windows 10 where drives were unreadable or temp directories locked you out, ensuring all operations proceed smoothly with consistent permissions.
FEATURE

Retrying Requests Following Server Recommendations

When using Codex, if a sent request or real-time connection fails, you may need to wait for a while before retrying.

Retryable failures for Responses (the interface for sending model requests) now follow the server's Retry-After recommendation. This header tells the client how long to wait before trying again. Retryable failures for WebSocket connections (which maintain two-way, real-time communication) also follow this rule by waiting for the suggested duration before retrying.

When dialing a busy customer service line, a caller follows the automated voice prompt to wait for the suggested time before calling back.
FEATURE

Windows Installers Include Digital Signatures for Safer Version Downloads

When installing or updating the system on Windows, installer scripts and version download mechanisms now offer higher security and compatibility.

Windows releases now include a signed PowerShell installer. When PowerShell 7 module paths exist in the environment, archive checksum verification failures that previously occurred when installing through Windows PowerShell are now fixed. For download management, the system now prevents older or preview versions from accidentally overwriting newer stable download targets and installation aliases.

Receiving an official package with a verifiable signature ensures that old parcels are no longer mistakenly used to replace brand-new items.
