Codex 0.157.0

發布日期：2026-09-25

繁體中文

新功能

GPT-6 Sol 與 Luna 模型上線，支援 Bedrock 並附帶舊版遷移提示

如果你正準備挑選模型處理專案，現在多了 GPT-6 Sol 與 Luna 兩款新模型可供切換使用。

就像工坊添購了兩台新設備，連接著企業專用線路的廠區能直接啟用，操作台旁還附上了舊機型的換機指引。

習慣透過 Amazon Bedrock（AWS 提供的雲端模型託管服務）串接模型的團隊，現在也能直接選用這兩款模型。如果手邊的專案仍在運行舊版模型，也可以參考附帶的遷移提示，順利將工作過渡到新模型。

新功能

背景伺服器自動啟動，遠端工作階段支援匯入指令

當你開啟互動式工作階段（與 AI 即時交談的操作階段）時，符合條件的環境現在會自動在背後啟動伺服器。

彷彿走進智能廚房時備料烤箱就已自動熱機，以前每次動工都要先手動啟動各台設備，現在一進場就能直接開始；遇到設定規格不合時，控制台還會主動提供調整方案讓你點選修復。

萬一伺服器設定與當前環境衝突，畫面會給出修復選項供你選擇，避免操作直接中斷。在遠端連線或本機背景伺服器的工作階段中，你現在也能隨時使用 /import 指令。

新功能

快捷鍵快速分岔對話，草稿與語音通話切換不中斷

你正在與 AI 討論專案，如果想開闢新分支探索不同方案，這正是按下 f 快捷鍵分岔對話（從既有討論衍生新分支）的時刻。

會議室另開一桌討論時，草稿與排隊待談的問題會跟著到新桌；在兩桌之間換位時，耳機裡的通話則持續進行。

透過這項功能分岔在其他應用程式中開啟的對話時，你尚未送出的草稿與排隊中的提示詞都會完整保留。當你在不同討論串之間切換時，進行中的語音通話不會被迫中斷。如果在回合結束時你輸入框裡還有未送出的回答，內容會自動恢復到輸入框中，而且不會干擾當前進行中的歷史紀錄搜尋。

新功能

全螢幕對話紀錄預設開啟，終端機排版與選取捲動體驗升級

當你需要在終端機裡查閱長篇回應、或是想跨行複製特定段落時，畫面空間與文字選取都很重要。

對話紀錄現在預設以全螢幕顯示，並支援按住 Shift 鍵配合點擊來延伸選取文字。

跟把粗糙的黑白草稿換成排版講究的印刷手冊一樣，以前數學符號與清單容易擠成一團，現在符號排得整齊，也能拉著尺標連續標記整段文字。

畫面渲染也更加細緻，完整支援 Unicode（通用文字編碼）項目符號、核取方塊、對齊方程式與最佳化數學標記。當你在自動螢幕模式下透過 SSH（遠端連線通道）使用 Terminal.app 時，現在能再次使用原生捲動紀錄。終端機也會遵循 tmux（終端機多工工具）的滑鼠設定。

問題修復

代理伺服器路由修復，檔案上傳支援重試並強化連線管制

在受管制或需要透過代理伺服器（替你轉發網路請求的中繼主機）連網的環境中，現在網路傳輸更加可靠且安全。

好比替物流轉運站加裝智慧閘門與重送輸送帶，以前遇到訊號微弱包裹就容易掉單、轉運路線也偶爾走錯，現在傳送失敗會自動重試且等候時間更長，遇到安全通行證被撤銷時也會立刻阻斷違規包裹。

過去即時連線與獨立網路搜尋在遇到轉址時，代理伺服器路由可能走錯，這個問題已經修好。上傳檔案時若遇到暫時性網路故障會自動重試，上傳逾時時間也延長至五分鐘。所有轉址與進行中的 HTTP（網頁傳輸規則）連線都會嚴格落實網路限制。WebSocket（即時雙向連線）也一樣；一旦安全規則變更撤銷了權限，連線會立刻被主動中斷。

English

FEATURE

GPT-6 Sol and Luna Models Launch with Bedrock Support and Legacy Migration Tips

If you're picking a model for your project, two new models, GPT-6 Sol and Luna, are now available to switch to.

Picture a workshop that just added two new machines: the facility connected to the dedicated enterprise line can power them on right away, and a replacement guide for the old models sits next to the console.

Teams used to connecting models through Amazon Bedrock (AWS's cloud model hosting service) can now choose these two models directly. If your project still runs on an older model, you can also follow the included migration tips to move your work over to the new models smoothly.

FEATURE

Background Servers Auto-Start, Remote Sessions Support the Import Command

When you open an interactive session (a live conversation with the AI), eligible environments now automatically start a server behind the scenes.

It's like walking into a smart kitchen where the prep oven is already warming up: you used to have to manually start every machine before getting to work, but now you can begin the moment you walk in; and when the settings don't match the spec, the console proactively offers adjustment options you can click to fix.

If the server configuration conflicts with your current environment, the screen offers repair options so your work isn't interrupted outright. In sessions running on a remote connection or a local background server, you can now also use the /import command at any time.

FEATURE

Fork Conversations with a Shortcut, Drafts and Voice Calls Survive Switching

You're discussing a project with the AI, and if you want to open a new branch to explore a different approach, this is the moment to press the f shortcut to fork the conversation (spinning a new branch off the existing discussion).

When a meeting room opens a second table for discussion, the drafts and queued questions follow you to the new table; and as you move between the two tables, the call in your headset keeps going.

When you fork a conversation that was opened in another application, your unsent drafts and queued prompts are all preserved intact. As you switch between discussion threads, an ongoing voice call is not forced to disconnect. If you still have an unsubmitted reply in the input box when a turn ends, the content is automatically restored to the input box, without interfering with any history search currently in progress.

FEATURE

Fullscreen Conversation History On by Default, Terminal Layout and Selection Scrolling Upgraded

When you need to read long responses in the terminal or copy a specific passage across lines, screen space and text selection both matter.

Conversation history now displays fullscreen by default, and supports holding the Shift key while clicking to extend a text selection.

Think of swapping a rough black-and-white draft for a carefully typeset printed manual: math symbols and lists used to get crammed together, but now the symbols line up neatly, and you can drag along the ruler to mark an entire passage in one go.

Rendering is also more refined, with full support for Unicode (universal text encoding) bullets, checkboxes, aligned equations, and optimization notation. When you use Terminal.app over SSH (a remote connection channel) in automatic screen mode, native scrollback works again. The terminal also respects the mouse settings of tmux (a terminal multiplexer).

BUGFIX

Proxy Routing Fixed, File Uploads Gain Retries and Stricter Connection Enforcement

In managed environments or ones that reach the network through a proxy server (a relay host that forwards your network requests), network transfers are now more reliable and secure.

Like fitting a logistics hub with smart gates and a resend conveyor belt: packages used to get dropped whenever the signal was weak and transfer routes occasionally went the wrong way, but now failed deliveries retry automatically with a longer wait, and any package whose security pass has been revoked is blocked on the spot.

Previously, live connections and standalone web searches could take the wrong proxy route when hitting a redirect; that problem is fixed. File uploads now retry automatically on transient network failures, and the upload timeout has been extended to five minutes. All redirects and in-flight HTTP (web transfer protocol) connections strictly enforce network restrictions. The same goes for WebSocket (a real-time two-way connection): once a security rule change revokes permission, the connection is actively terminated immediately.
