If your automatic code review suddenly started acting up, this release puts it back the way it was. A prior change to the prompting (the wording of the instructions telling the AI how to do its job) for Codex's Guardian auto-review (Guardian, an AI reviewer that automatically inspects your code) caused a regression (a step backward where the new version is worse than the old one). This release reverts it (undoing a change and returning to the previous version), restoring the old review policy, request format (the message structure used when the AI sends a request), and tool behavior (how the AI acts when calling external tools). Like a restaurant chef who tried a new recipe, got panned by regulars for worse food, and hurriedly dug out the old recipe to cook the original way again.
