Amazon Bedrock 路由選單加入 GPT-6-Astra 模型

你在 Amazon Bedrock 雲端環境中調用 Codex 時，挑選模型有了新選項。如同連鎖餐廳在特定分店的點餐機上，正式把最新招牌菜加入螢幕選單，走進指定門市的顧客直接按螢幕就能點選。這項改動涵蓋 Mantle 路由，以及 Runtime 的 global 與 US 路由（route，雲端服務分配請求路徑的通道）。只要連線走這幾條途徑，你就能在模型挑選器（model picker，供手動切換不同 AI 版本的選單）中直接選取 GPT-6-Astra 模型。走 Mantle 或 Runtime 的 global／US 路由時，可在模型挑選器直接選 GPT-6-Astra。

修正 GPT-6-Astra 非同步提問指引，改用支援工具且認得純文字限制

交給 GPT-6-Astra 的任務如果需求不明確，它在背景發問釐清的流程現在更穩定。這項改動修正了該模型提出非同步釐清問題（asynchronous clarification questions，不中斷手邊工作、在背景等候回覆的提問機制）時的內建指引。現在它會確實呼叫官方受支援的工具（supported tool，環境中明訂可用來向外部發問的功能模組），不再誤用不相容的管道。同時，它也能正確辨識該工具僅接受純文字內容，避免送出不支援的格式而引發錯誤。宛如助理遇到交代不清的待辦事項時，會準確把疑問寫成便條紙投進專用留言箱，不再投錯信箱或塞進格式不符的包裹。

Amazon Bedrock Route Picker Adds GPT-6-Astra Model

When calling Codex in the Amazon Bedrock cloud environment, you now have a new option when selecting models. Much like a chain restaurant officially adding its latest signature dish to the screen menu on ordering kiosks at specific branches, allowing customers entering designated stores to select it directly on the screen. This change covers the Mantle route as well as Runtime's global and US routes. As long as your connection uses these paths, you can directly select the GPT-6-Astra model in the model picker. When routing through Mantle or Runtime global/US, you can directly choose GPT-6-Astra in the model picker.

Corrected GPT-6-Astra Guidance for Asynchronous Clarifications to Use Supported Tools and Recognize Text-Only Limits

When tasks assigned to GPT-6-Astra have unclear requirements, its process for asking clarifying questions in the background is now more reliable. This change corrects the model's built-in guidance when asking asynchronous clarification questions. It now properly calls officially supported tools instead of misusing incompatible channels. At the same time, it correctly recognizes that the tool accepts only plain text, avoiding errors caused by sending unsupported formats. Much like an assistant dealing with an unclearly explained task who accurately writes questions on a memo note and drops it into a dedicated message box, rather than dropping it into the wrong mailbox or stuffing in a parcel with an incompatible format.
