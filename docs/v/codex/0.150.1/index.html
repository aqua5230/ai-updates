zh-TW

遠端壓縮納入保留的圖片算額度，舊圖依需求自動削減

在長篇對話裡傳送多張截圖，就像在一本厚度有限的專案剪貼簿裡貼滿照片與說明，一旦紙張有限，厚重的相片往往最容易佔滿整本手冊的配額。現在 Codex 在背景執行遠端壓縮（remote compaction，在伺服器端壓縮長對話紀錄的機制）時，預設會把保留的圖片也一併算進可用配額。這項機制會把保留的圖片計入 token（AI 處理與計量的文字單位）預算，並在需要時自動削減較早傳入的舊圖片。如此一來，長篇對話就不會因為累積過多歷史圖片而悄悄撐破長度上限，同時也能確保最新的畫面資訊持續被妥善保留。

en

Remote compaction counts retained images toward token budgets and reduces older ones as needed

Sending multiple screenshots in a long conversation is like pasting photos and notes into a project scrapbook of limited thickness, where bulky pictures easily eat up the binder's allowance. When Codex runs remote compaction to compress lengthy conversation histories on the server, it now counts retained images toward its token budget by default. The mechanism reduces older images as needed to keep things lean. This ensures that long discussions stay safely within context limits without silently overflowing due to accumulated image history, while preserving your most recent visual references.
