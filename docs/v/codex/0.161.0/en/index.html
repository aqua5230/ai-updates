Codex 0.161.0

Released: 2026-10-07

Release notes

FEATURE

Default Model Upgraded to GPT-6.1 Sol, Amazon Bedrock Adds Multi-Agent and Advanced Inference Support

If you rely on cloud platforms for model dispatch, the default model built into the system and the Amazon Bedrock catalog has officially switched to GPT-6.

1 Sol. When paired with compatible models on Bedrock, the system simultaneously supports multi-agent V2 and Ultra inference features. At the same time, Bedrock Mantle now accepts AWS GovCloud regions.

A fleet upgrades to a new standard engine, but complementary features still depend on vehicle compatibility, and driving regions also have their own applicable boundaries.

Compatible models can use multi-agent V2 and Ultra inference on Amazon Bedrock, while Bedrock Mantle accepts AWS GovCloud regions.

FEATURE

Log In to MCP Servers from an Active Terminal Session

When you need to grant AI temporary access to external databases or services, you can initiate a login directly from your current session.

MCP stands for Model Context Protocol (a protocol that lets AI connect to external tools). Enter the following command in an active terminal session to log in to the specified MCP server:

/mcp login <name>

Replace <name> with the name of the server you want to log in to.

Just like using an intercom next to your seat in an office meeting to announce which department you are visiting, you can enter a command in your active session to specify which server to log in to.
FEATURE

Select Microphones and Speakers for Voice Conversations with Local Preference Storage

When discussing projects with AI using headphones, you can now freely choose where sound enters and exits.

This update lets you pick dedicated microphones, speakers, and microphone input channels during voice conversations, with all preferences automatically saved to your local machine.

Think of a sound engineer adjusting a mixing console in a professional recording studio: you pick the recording microphone, output speakers, and input channels, then save the setup in your local configuration book.

The next time you start a voice call, the system remembers your preferred audio input and output devices.

FEATURE

Daybreak Switches to Explicit Opt-In, Cyber Access Program Configurable per Turn

To use Daybreak features, you must now explicitly enable them.

Setting daybreak=true alone no longer works; you must add --enable cli_daybreak or add the following to your configuration file:

{
  "features": {
    "cli_daybreak": true
  }
}

By default, controls and indicators are hidden, /daybreak is disabled, and saved threads skip automatic Cyber routing, though preferences remain preserved.

Enabling routing requires an eligible ChatGPT login, an OpenAI provider, and explicit model and program support.

Picture an instrument whose control panel stays locked until you insert a key to open the channel, while single tests can still connect directly with a valid pass.

For single-turn responses, you can specify the Cyber program via codex exec --cyber-access-program or the TypeScript SDK's cyberAccessProgram. After disabling cli_daybreak, explicit overrides with codex exec remain usable without altering saved program selections.

FEATURE

Write Permission Elevation Preserves Read Restrictions, Launch Permissions Support Reconnection

When you approve expanded file access for AI, the system now delineates security boundaries with higher precision.

Approved file system permission elevations can relax write scopes independently while strictly maintaining existing read denials and network connection limits. Background tasks faithfully inherit existing permissions from the turn that spawned them. When reconnecting in a terminal or launching a new session (an interactive connection for conversing with AI), explicitly specified launch permissions remain valid, and implicit client settings no longer accidentally overwrite server-side or saved-thread web search configurations.

Consider applying to building management for a construction permit on a specific floor: where approvals previously unlocked unrelated doors, the system now issues keys strictly for the work zone, and even if a crew leaves and re-badges, the registered access rules remain intact.
FEATURE

Windows Elevated Sessions Switch to Embedded Server, Pressing Enter After Paste Submits Text Properly

When running the terminal with administrator privileges on Windows, elevated sessions can now start smoothly via an embedded server.

Meanwhile, under protected user profile directories, PowerShell running inside the sandbox correctly preserves relative paths. Additionally, once the paste detection countdown finishes, pressing Enter properly submits text stored in the staging buffer, functioning normally even in Vim insert mode.

Like a shipping counter that organizes documents before pressing confirm to send, pressing Enter after paste detection expires submits the buffered text as expected.

Elevated sessions can launch, relative paths are preserved under protected directories, and pressing Enter submits normally after paste detection expires.

FEATURE

Thread Resumption Includes Latest History, Connection Retries Follow Server Guidance

If you resume a previously paused thread, the system now fully incorporates the latest committed history.

At startup, the system detects recoverable SQLite database corruption earlier and preserves the corrupted database as a backup file. For network connections, response retries and WebSocket-to-HTTP fallback (a backup option used when the primary connection is unavailable) strictly follow server retry instructions, reducing premature failure decisions during server overloads. Login authentication guidance has been updated to explain that credentials may reside in the system keyring (the system's storage for security credentials) rather than implying they always live in auth.json. Furthermore, publishing older alpha versions or hotfix packages no longer accidentally rolls back the alpha tag on npm. Recoverable database corruption is detected earlier with damaged files retained, and connection retries follow server guidance to minimize early failures during overloads.
