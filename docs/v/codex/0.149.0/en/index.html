Codex 0.149.0

Released: 2026-08-20

Release notes

FEATURE

Interactive agents dashboard for managing background tasks

When juggling multiple AI tasks, you no longer have to switch blindly across terminal windows.

It is like a dispatch whiteboard on a workshop wall, keeping every job ticket in plain view and ready for quick key commands.

Run codex agents in your terminal to open an interactive dashboard. Inside this view, you can search, start, open, rename, and stop tasks. The interface also provides configurable shortcuts so you can navigate and manage all your background jobs using your preferred keystrokes.

FEATURE

Manage working directories in TUI sessions with /cd, /pwd, and /cwd

When talking with Codex in the terminal, you no longer need to exit and restart just to switch folders.

Inside a TUI (text-based user interface) session, you can now enter /cd to change your working directory, or run /pwd and /cwd to print your current location. This allows you to navigate across different project folders within the same conversation without losing your ongoing thread.

It is like moving to a neighboring study desk in a library without packing your backpack and checking in again.
FEATURE

Send messages to local and remote sessions with codex queue

When you need to send instructions from another window to an existing task, codex queue offers a direct channel.

It is like dropping a note into a colleague's inbox tray: it gently wakes them if they are resting and routes accurately even when coworkers share a name.

This new command delivers messages to existing local or remote sessions. Queued messages now reliably wake idle sessions, resolve duplicate session names more intelligently, and preserve the original semantics of pasted or deferred commands without corruption.

FEATURE

Expanded Vim editing motions and character replacement

For developers accustomed to Vim bindings in the terminal, editing prompts is now much smoother.

Codex has expanded Vim editing with single-character replacement and additional change motions. You can now use cw to change a word, c$ to change to the end of the line, or cc to rewrite the entire current line. These key combinations let you reshape text in place without backspacing character by character.

It is like a woodcarver switching to specialized chisels, trimming a word or reshaping a line without sanding down the entire block.
FEATURE

codex doctor diagnoses endpoint protection and network failures

When troubleshooting connection hiccups or frozen environments, the built-in diagnostic tool can pinpoint issues faster.

It is like a clinic checkup adding immune defense and circulation scans to identify hidden trouble spots in one visit.

Running codex doctor now inspects four critical areas: endpoint protection software interference, network and proxy failures, desktop application state, and update server connectivity. When something breaks, you can immediately tell whether corporate security software or network routing is at fault.

FEATURE

SDK config overrides and max or ultra reasoning effort

Developers calling Codex through an SDK (Software Development Kit) now enjoy much tighter control over execution.

You can directly pass exact CLI configuration overrides from your code to fine-tune settings for specific tasks. In addition, when tackling complex logic that requires deep deliberation, you can set the reasoning effort to max or ultra to dedicate maximum reasoning capacity to the problem.

It is like a racing driver precisely tuning chassis parameters while having access to an ultra-boost gear for challenging terrain.
FEATURE

Resumed and forked threads restore their permission profiles

When picking up a paused conversation or forking a new branch from it, your configured permission rules are now fully preserved.

It is like reopening a paused project and receiving your designated access badge rather than getting demoted to a generic guest pass.

Resuming or forking a thread now restores its active permission profile instead of silently falling back to the current system defaults. This ensures that tasks configured with specific security guardrails retain the exact same authorization boundaries when resumed.

BUGFIX

Fix duplicate sub-agent actions and tighten approval routing

When a primary agent delegates work to sub-agents, communication and scheduling are now significantly cleaner.

Sub-agents previously could trigger duplicate activities, while notifications and approval requests sometimes took confusing paths through the interface. Codex has now resolved the duplicate actions and tightened TUI routing for sub-agent alerts and approvals.

It is like an airport control tower sending each arrival alert and takeoff-clearance request down the right radio channel, without issuing the same aircraft a takeoff order twice.
FEATURE

WebRTC sideband reconnects without dropping pending output

When receiving output over real-time channels, brief network hiccups will no longer cause missing data.

It is like a walkie-talkie passing through a tunnel: once signal returns, it plays back buffered speech without clipping a single word.

Realtime WebRTC sideband connections now automatically reconnect after an unexpected transport loss. Once reconnected, pending output generated during the interruption is preserved and delivered rather than dropped, ensuring you never miss streamed responses.

FEATURE

Windows Terminal scrollback retains inline TUI history

For developers running Codex inside Windows Terminal, reviewing past discussions is now completely effortless.

Previously in inline TUI mode, conversation output was not properly retained in the terminal's native scrollback buffer. Inline TUI history now remains available in Windows Terminal scrollback, allowing you to scroll up anytime to inspect previous code snippets and explanations.

It is like unrolling a long notebook scroll where earlier meeting notes remain cleanly preserved at the top.
FEATURE

Bounded replay buffers for inactive threads prevent memory bloat

When keeping multiple background tasks open, Codex will no longer consume excessive memory by hoarding old streamed text.

It is like setting a strict size limit on storage boxes so paused recordings do not overflow the warehouse.

Replay buffers for inactive TUI threads are now strictly bounded. This restriction prevents inactive sessions from retaining massive amounts of streamed output in memory, reducing system resource usage and keeping long-running sessions lightweight and stable.

FEATURE

External contributions prioritized through issues and design discussions

For developers looking to contribute to Codex, the contribution guidelines are now clearer.

The documentation clarifies that external contributions should begin with an issue and architectural design discussion rather than jumping straight to a pull request. Aligning on the design before writing code helps avoid wasted effort.

It is like reviewing blueprints with an architect to agree on room layouts before ordering bricks and knocking down walls.
FEATURE

Documentation on DNS exfiltration risks and devcontainer trust limits

When running untrusted code inside secure containers, developers now have clearer guidance on potential security boundaries.

The documentation now details the trust limitations of secure devcontainers (isolated containerized development environments). It specifically highlights DNS exfiltration risks, explaining how malicious code could leak sensitive data via domain lookup requests. This guidance reminds teams to audit outbound network policies even within containerized setups.

It is like working in a soundproof room: if anyone can mail letters outside, the address written on the envelope can still leak secrets.
