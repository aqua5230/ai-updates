macOS 支援系統代理設定，公司網路不再卡關

現在 macOS 使用者在公司等有嚴格網路管制的地方，也能順利登入驗證了。只要你開啟 respect_system_proxy 設定，系統就能讀懂 macOS 裡的 PAC、WPAD（自動配置代理的腳本與協定）等系統代理（system proxy，幫你轉發網路請求的中繼站）設定。就像你在管制嚴格的大樓有了專屬通行證，現在連用蘋果電腦也能自動繞過門禁，順利連上網。

外掛目錄大升級，找工具更準還支援深色模式

找外掛（plugin，擴充系統功能的附加元件）變得更方便了。遠端的外掛目錄現在會提供編輯精選外掛排行；MCP（讓 AI 控制外部工具的協定）工具也預設改用新的搜尋機制，讓系統更容易找到你需要的工具，同時不影響舊版模型。此外，外掛開發者現在可以專門為深色模式提供專屬的標誌圖片了。就像逛應用程式商店，以前貨架亂糟糟，現在不僅有了「熱門推薦」專區，連店面在晚上也會換上專屬的漂亮招牌。

圖片與憑證錯誤不再謎語，操作失敗直接教你解

遇到錯誤時，系統不再只會吐出看不懂的代碼了。如果你使用 Amazon Bedrock 時憑證（credentials，證明你是合法使用者的金鑰）過期，系統現在會直接給你具體的恢復步驟，而不是丟一個籠統的「授權失敗」；處理遠端的 HTTP 圖片輸入失敗時，也會直接退回清楚的驗證錯誤訊息，讓 AI 模型能看懂並告訴你哪裡有問題（本地圖片與行內資料不受影響）。就像去銀行辦事被退件，以前櫃檯只會冷冷地蓋個「不合格」，現在會明確拿單子告訴你「身分證過期了，請去戶政事務所換發」。

PowerShell 複雜指令防偷渡，排版成功不再洗頻

執行 PowerShell（Windows 上強大的指令碼環境）指令變得更安全了。如果指令裡藏著安全檢查器看不懂的複雜執行區塊（AST regions），系統現在會一律攔下來要求你親自核准，防止惡意程式偷渡。另外，當程式碼排版工具（formatter）成功跑完時，現在會乖乖保持安靜，只有失敗時才會印出診斷訊息；寫程式模式（Code Mode）在選錯模型規格時也會提早警告你。就像機場安檢，行李掃描機看不透的怪異金屬盒一定會要求你親自打開檢查；而順利過關的旅客就可以安靜通行，警報器只在真正抓到違禁品時才會響起。

遠端路徑自動轉換，安全緩衝介面更豐富

當你的客戶端與伺服器在不同作業系統（例如 Mac 連到 Windows）時，路徑問題不再讓人頭痛。遠端連線的 MCP 伺服器現在能直接讀懂並接受遠端平台原生格式的絕對路徑，不用再手動轉換斜線。同時，應用程式的介面也能接收伺服器傳來的可見度與模型資料，展現更豐富的「安全緩衝」（safety-buffering，避免危險操作立刻執行的確認畫面）介面。就像寄國際包裹，以前你要自己查明當地的地址格式怎麼填，現在郵局系統會自動幫你翻譯好，還會換上更清楚的防撞包裝。

en

Opt-in macOS system proxy support for smoother authentication

macOS users in places with strict network controls like corporate offices can now log in without getting blocked. By enabling the respect_system_proxy setting, the system now understands PAC, WPAD (scripts and protocols for automatic proxy configuration), and other system proxies (intermediary servers that forward your network requests) configured on your Mac. Like getting a VIP pass in a highly secured building, your Apple computer can now automatically navigate the checkpoints to get you connected.

Upgraded plugin catalogs with better search and dark mode logos

Finding plugins (add-ons that extend system capabilities) is now much easier. Remote plugin catalogs now provide curated featured-plugin rankings, and MCP (a protocol letting AI control external tools) tools now default to a new tool search mechanism, helping the system discover what you need while staying compatible with older models. Additionally, plugin developers can now provide dedicated logo images specifically for dark mode. Like browsing an app store — the shelves used to be a mess, but now there's a "Featured" section, and the storefronts even put up beautiful neon signs at night.

Clearer errors for remote images and expired Bedrock credentials

When things go wrong, the system no longer just spits out cryptic codes. If your Amazon Bedrock credentials (the keys proving you're a valid user) expire, the system now provides actionable recovery guidance instead of throwing a generic "authorization failed" error; similarly, failing to process remote HTTP images now returns clear validation errors that the AI model can read and explain to you (local images and inline data remain unaffected). Like getting a form rejected at the bank: the teller used to just coldly stamp "Denied," but now they hand you a checklist explaining "Your ID is expired, please go renew it at the government office."

Safer PowerShell execution and quieter successful formatters

Executing PowerShell (a powerful scripting environment on Windows) commands is now safer. If a command contains complex executable blocks (AST regions) that the safety classifier can't inspect, the system will now block it and require your explicit approval, preventing malicious code from sneaking through. Additionally, when the code formatter runs successfully, it now stays quiet, only printing diagnostic messages when something fails; Code Mode will also warn you early if the selected model lacks required metadata. Like airport security: a weird metal box the X-ray machine can't see through will definitively require you to open it manually, while cleared passengers can walk through quietly, with the alarm only sounding when contraband is actually found.

Automatic remote path conversion and richer safety UI

Path formatting headaches are gone when your client and server are on different operating systems (like a Mac connecting to Windows). Remote connected MCP servers can now accept absolute working directories written in the remote platform's native path format, saving you from manually swapping slashes. Meanwhile, the app UI can now consume visibility and faster-model metadata from the server to display a richer safety-buffering UI (a confirmation screen that pauses dangerous actions before they execute). Like sending an international package where you used to have to figure out the exact local address format yourself, but now the postal system automatically translates it for you and puts clearer fragile-handling stickers on the box.
