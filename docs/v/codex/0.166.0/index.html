Codex 0.166.0

發布日期：2026-10-29

繁體中文

新功能

鍵盤支援選取對話紀錄，按單字換行翻頁與內建搜尋

查閱終端機裡長串的除錯紀錄時，頻繁移開雙手去抓滑鼠反白文字常常打斷思緒。

宛若在厚重字典裡用檢索標籤翻查單字，以前只能用肉眼一行行硬找並手動標記，現在手指一撥就能按章節跳頁並直接定位字彙。

對話紀錄（終端機中保留的歷史問答內容）現在完整支援純鍵盤選取操作。你能使用鍵盤按單字、整行或整頁幅度移動游標，精準框選想複製的段落。介面內建搜尋功能，當你請 AI 檢查長篇日誌並想擷取特定段落時，直接鍵入關鍵字就能跳到該行。所有移動與選取的按鍵組合也開放自訂，方便你依照習慣配置個人快捷鍵。

問題修復

終端介面修復排版與離線退出，還原草稿保留附加圖片

在終端機與 AI 密集互動時，文字排版錯亂或突發斷線往往會打亂操作節奏。非同步提問、選項清單、回答內容與對話紀錄回覆中的 Markdown（將文字標記為標題或粗體的輕量排版語法），現在皆能維持一致的渲染呈現。還原被清除的輸入框文字時，原本附加的本機圖片也會一起留下。終端介面也改善了重連後的復原，離線時輸入 /quit 或 /exit 也能正確處理。

新功能

新增 GPT-6.1 Terra 模型，支援內建與兩大雲端目錄

規劃專案架構並評估模型效能時，能否在自己習慣的雲端託管環境調用最新架構是關鍵考量。

好比連鎖量販店引進新型高效冷氣，以前想購買只能透過少數專門管道，現在官方型錄與各大特約通路貨架都同步補齊規格。

Codex 模型目錄現已正式加入 GPT-6.1 Terra 模型。除了本地內建的預載型錄外，使用 Google Cloud 的 Vertex AI 或 AWS 的 Amazon Bedrock 託管服務的團隊，也能在各自的模型清單中看到它。在這三份目錄的任一份裡，都能選到 GPT-6.1 Terra。

新功能

討論串回復與分支保留授權，佇列後可接續，子串一併復原

將中斷的工作階段重新接續或另開分支時，對話狀態與先前確認過的設定往往需要被妥善延續。 現在使用 codex queue --resume 指令，能在將新訊息加入佇列後，自動喚醒並接續已卸載的討論串。 當你回復既有進度或建立分支時，先前已經過確認的放行批准與權限設定會完整保留，不必在分支裡逐項重新授權。 回復與分支過程也會一併保留推理 token（AI 思考過程消耗的計費文字單位）的累計數據。這避免了系統因遺失思考紀錄而誤判對話長度，導致過早觸發上下文壓縮。 若先前將某個討論串封存，現在只要解封存該父討論串，所有由它衍生出的子討論串都會同步復原。以往分支後總要重新確認權限、子串在解封存時不知去向的麻煩，現在都不會再發生。

新功能

安全防護阻擋提示更清晰，提供替代提示詞直接選取

在終端機輸入特定提示詞若意外觸發安全防護，突然中斷的對話常讓人摸不著頭緒。

彷彿圖書館珍本庫的借閱櫃台，以前被拒絕調閱只得到一張空白退件單，現在館員會清楚說明受限章則，還會主動列出可借閱的替代篇章。

終端使用者介面（TUI，以文字選單排版的終端畫面）現在提供更清楚的安全攔截說明。當你的請求因安全原則遭到阻擋時，畫面會明確解釋被限制的具體原因，不再只丟出一行模糊的拒絕訊息。介面同時會自動生成數個調整過措辭的安全替代提示詞，你可以直接按鍵盤選取並重新送出。這讓你在探索程式碼防護或敏感測試情境時，能立刻知道邊界在哪，並快速調整詢問方向繼續工作。

新功能

診斷指令新增專注網路選項，快速檢測連線與協定狀態

當終端機突然連不上伺服器或回覆中斷時，快速抓出是本機環境還是網路連線出問題至關重要。

如同音響工程師拿著導線專用測試儀，以前排查雜音得把整套擴大機與調音台拆開通盤安檢，現在只要接上線頭就能單獨測量訊號導通狀況。

現在診斷工具新增了 codex doctor --network-only 參數選項。這項指令只針對設定、連線能力與 WebSocket（雙向即時通訊的網路協定）狀態做診斷。當你在公司內部網路或代理伺服器環境下遭遇請求逾時，只要打：

codex doctor --network-only

終端機就會只回報設定、連線與 WebSocket 這三項的檢查結果。

新功能

獨立執行器隨附於正式安裝包，整頓背景服務與建置工具

在建置環境部署與升級工具時，底層架構的打包完整度與資源釋放直接影響執行穩定。正式釋出的命令列工具與 app-server（應用程式背景伺服器）安裝包中，現在已直接隨附獨立執行器。背景服務修復了執行緒啟動與關閉時的競爭衝突，執行完成後會即時釋放占用資源。同時，macOS 上若安裝路徑包含中文等非 ASCII 字元，或程式仍在使用中，獨立版本的清理錯誤也已修好。在專案建置方面，Bazel 改採原始碼自編譯的 V8 引擎，搭配相符的 Rust 綁定並支援 Windows 原生 MSVC 封裝；開發與正式發行版本也全面標準化至 Node.js 24.22.1 與 Rust 1.95.0。以往在特定路徑清理失敗或背景程序殘留資源的問題，現在都已排除。

English

FEATURE

Keyboard Transcript Selection with Word, Line, and Page Motions and Integrated Search

When reviewing long debug logs in the terminal, frequently moving your hands away to grab the mouse and highlight text often breaks your train of thought.

Think of looking up words in a thick dictionary using index tabs: in the past, you had to scan line by line with your eyes and mark text manually, whereas now a flick of the finger lets you skip across sections and pinpoint a vocabulary word directly.

The transcript (historical question-and-answer exchanges kept in the terminal) now fully supports keyboard-only selection. You can use the keyboard to move the cursor by word, line, or page increments to precisely highlight the passages you want to copy. The interface features integrated search, so when you ask AI to inspect long logs and want to capture specific sections, typing keywords takes you straight to that line. All keybindings for motion and selection are also open to customization, making it easy to configure your personal shortcuts based on your habits.

BUGFIX

Terminal Interface Fixes Rendering and Offline Exit While Preserving Image Attachments

When interacting intensively with AI in the terminal, garbled text formatting or sudden disconnections often disrupt the operational flow. Markdown (a lightweight markup syntax that formats text into headings or bold text) across asynchronous questions, choice lists, answers, and transcript replies is now consistently rendered. When restoring cleared composer text, original local image attachments are also preserved. The terminal interface also improves reconnection recovery, properly handling /quit or /exit even when offline.

FEATURE

GPT-6.1 Terra Model Added with Support for Bundled and Two Major Cloud Catalogs

When planning project architectures and evaluating model performance, being able to invoke the latest architecture in your preferred cloud hosting environment is a critical consideration.

Consider a retail chain stocking a new high-efficiency air conditioner: where buyers previously had to rely on a few specialized channels, both the official catalog and the shelves of major authorized partners now carry the model simultaneously.

The Codex model catalog has now officially added the GPT-6.1 Terra model. In addition to the local bundled catalog, teams using hosting services such as Vertex AI on Google Cloud or Amazon Bedrock on AWS can also see it in their respective model listings. You can select GPT-6.1 Terra from any of these three catalogs.

FEATURE

Thread Resuming and Forking Preserve Approvals with Queue Resume and Child Thread Restoration

When resuming an interrupted session or branching into a new fork, conversation state and previously confirmed settings often need to be properly carried forward. Running the codex queue --resume command now automatically wakes and resumes unloaded threads after queueing a new message. When you resume existing progress or create a fork, previously acknowledged approvals and permission settings are preserved in full, eliminating the need to reauthorize permissions item by item in the branch. The resume and fork process also retains cumulative counts for reasoning tokens (billable text units consumed during an AI thought process). This prevents the system from misjudging conversation length due to lost deliberation records, which previously triggered premature context compaction. If a thread was previously archived, unarchiving that parent thread now restores all child threads spawned from it simultaneously. The past annoyances of repeatedly re-confirming permissions after branching or losing track of child threads upon unarchiving no longer occur.

FEATURE

Clearer Safety-Block Explanations with Direct Selection of Safer Follow-Up Prompts

When entering certain prompts in the terminal unexpectedly triggers safety guardrails, a sudden conversation halt often leaves users bewildered.

Picture the circulation desk of a rare book library: where a denied request once yielded only a blank rejection slip, the librarian now clearly explains the restricted regulations and proactively suggests alternative chapters available for loan.

The TUI (terminal interface formatted with text-based menus) now provides clearer safety-block explanations. When your request is blocked due to safety policies, the screen clearly explains the specific reason for the restriction instead of merely returning a vague rejection line. The interface simultaneously generates several rephrased, safe follow-up prompts that you can select directly with your keyboard and resubmit. When exploring code defenses or sensitive testing scenarios, this lets you immediately recognize boundaries and swiftly adjust your questioning direction to continue working.

FEATURE

Focused Network Option Added to Doctor Command for Rapid Diagnostics

When the terminal suddenly loses connection to the server or replies are cut off, quickly pinpointing whether the issue lies in the local environment or the network connection is critical.

An audio engineer uses a dedicated cable tester: whereas troubleshooting noise previously required dismantling and inspecting the entire amplifier and mixing console, plugging in the leads now immediately tests signal continuity on its own.

The diagnostic tool has now added the codex doctor --network-only option. This command runs diagnostics exclusively on configuration, connectivity, and WebSocket (a networking protocol for bidirectional real-time communication) status. When encountering request timeouts in corporate intranets or proxy environments, you simply run:

codex doctor --network-only

The terminal then reports only the configuration, connectivity, and WebSocket checks.

FEATURE

Standalone Executor Shipped in Official Packages Alongside Service and Build Improvements

When deploying and upgrading tools in build environments, the packaging integrity and resource release of underlying architectures directly dictate execution stability. Canonical CLI and app-server (application background server) release packages now bundle the standalone executor directly. The background service fixes thread startup and shutdown races, promptly releasing occupied resources upon completion. Meanwhile, standalone release cleanup errors on macOS when installations are in use or paths contain non-ASCII characters such as Chinese have also been resolved. For project builds, Bazel switches to source-built V8 with target-matched Rust bindings and native Windows MSVC archive support. Development and release builds are also standardized across the board on Node.js 24.22.1 and Rust 1.95.0. Past issues where cleanups failed on specific paths or background processes left lingering resources are now eliminated.
