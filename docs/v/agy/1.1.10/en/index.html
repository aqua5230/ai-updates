Antigravity 1.1.10

Released: 2026-08-04

Release notes

FEATURE

Three new sign-in routes for enterprise accounts

If your company gives you a Gemini Enterprise account, you can now sign in through a Google Cloud project, use an assigned or automatically assigned GE-Standard or GE-Plus license seat, choose the region where inference runs, and retain the controls set by your administrator.

If your organization uses an outside identity provider, choose Use advanced SSO config on the Google Cloud sign-in screen for Workforce Identity Federation. Application Default Credentials is another route for using Agent Platform. Think of one office building adding three entrances for different badges while keeping the same company access rules.

FEATURE

A warning before two sessions write into one conversation

If you open another CLI window on the same machine and load the same conversation, you now get an advisory that does not interrupt your work.

It points to /fork, which creates a new branch of the conversation before you continue. Previously, both windows could write into the same conversation trajectory, like two people sharing one pen on the same line and mixing their sentences together. Now there is a signpost before that happens, so you can choose separate lines.

FEATURE

The sandbox can inspect Git, but cannot rewrite it

When an agent works in a Git repository, the .git directory is now read-only: it can be inspected but not changed.

That directory holds version-control information such as commits and branches, so the agent can still understand the project's history while being unable to rewrite it from inside the sandbox, an isolated execution area. It is like replacing a filing cabinet door with a display case: you can read the records inside, but cannot reach in and alter a page.

FEATURE

Hooks can finally catch the final handoff

If you add hooks, small programs triggered by particular events, to record or finish a workflow, the final step no longer slips past them.

Hooks defined in hooks.json now run before the built-in termination checks. That lets PostInvocation observe the final call in a turn, and lets Stop run instead of remaining unreachable behind those checks. It is like placing the timekeeper beside the track before the last relay runner arrives; only then can the stopwatch be pressed at the finish.

FEATURE

The scheduler now understands numeric values

When a model calls the schedule tool, DurationSeconds and MaxIterations no longer fail just because they arrive as JSON, a text format for exchanging data, numbers without quotation marks.

Integral values are now accepted, so a duration in seconds or a maximum iteration count can be written as a number. Decimal values get a clear error because these fields require whole numbers. It is like a reservation form finally understanding “3 people” without demanding that 3 be turned into a text label, while still rejecting the nonsensical “3.5 people.”

BUGFIX

Your selected model and effort no longer get quietly replaced

You may have specified --model or --effort yet found an interactive session or headless -p run quietly using the saved or default model.

That is fixed: the flags are applied before model configuration is initialized. A bare --effort is also resolved against the model you selected, rather than the default model that could move you elsewhere. Effort is the setting for how much reasoning work a model uses. It is like ordering both a main dish and its portion size; the kitchen now follows the order you gave instead of serving the back-office default.

BUGFIX

Background work can now actually stop or stay in the background

When coordinating several subagents, stopping no longer ends only the current conversation while descendant subagents and their background tasks keep running.

The whole subagent tree now stops together. A coordinator waiting for active work also no longer keeps injecting empty continue steps, wasting tokens, units of AI processing and billing, and blocking progress. Another fix makes tools that an MCP server marks as always-background genuinely avoid blocking a turn. It is like switching off a power strip and cutting power to every connected appliance, rather than darkening only the first lamp.

BUGFIX

Options, cursor keys, and the model picker work normally again

In multi-select prompts, the spacebar can select an option again, including in the ask_question dialog and the onboarding import checkbox; the hint bar now says so instead of leaving x as the only toggle.

When the input box shows a suggestion dropdown, Left and Right no longer get captured by that dropdown, so you can move the cursor and edit text. If the model picker has no models available, it now still shows its header, footer, and an esc hint to return. It is like putting three everyday buttons back on a control panel so they do not disappear when you reach for them.

BUGFIX

A dropped MCP connection no longer leaves a process behind

When an MCP server, using the Model Context Protocol that lets AI connect to external tools, drops its connection unexpectedly, it no longer leaves an unclosed process behind.

Such a process may be invisible on screen yet keep using computer resources; this fix handles that leak when the connection falls away. It is like a customer-service call dropping without leaving an operator at the other end still wearing a headset and waiting for an answer.

BUGFIX

Documents and denied network requests are no longer hidden

When you open a plain document in the artifact viewer, it no longer gets horizontally clipped by default.

Only diagram artifacts, viewable output pieces, need that treatment, so ordinary documents now display normally. Another fix fills in the sandbox network record: even if the command itself ends successfully, a network request denied by the sandbox is recorded. It is like a gallery no longer trimming every work to poster proportions while the entrance desk also logs every visitor denied admission.
