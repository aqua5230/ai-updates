發布日期：2026-07-28

zh-TW

命令列輸出能直接交給程式接手

把命令列工具接進 CI（自動跑測試與部署的流程）時，最怕它只吐一大段人看得懂、程式卻接不住的文字。現在在 -p 後加 --output-format json 或 --output-format stream-json，就能拿到結構化輸出；--help 也找得到。選 stream-json 時，結果會像接力直播：一開始送出 init，每一步送 step_update，最後才送 result，不必等整趟工作結束。每個事件有固定的 step_type；工具呼叫才會附工具名稱、參數與輸出。如果有委派子代理，也帶上對話 ID 與紀錄位置。想固定答案格式，可加 --json-schema，給規格或檔案路徑。輸出的使用量也多了 cache_read_tokens，看得出有多少 token 命中快取（把先前結果暫存再利用）。

選取文字要不要自動複製，自己決定

你在終端機裡拖曳選取一段結果，原本只是想看清楚，鬆開滑鼠卻可能把內容自動塞進剪貼簿，甚至弄壞特定資料。現在 TUI（終端機裡用文字畫出的互動介面）的 altscreen 呈現模式新增 copyOnSelect，預設開啟：選取後放開滑鼠便會複製。它像影印機自動送紙，省掉按複製，卻不適合每種紙張。若你貼上後發現內容怪掉，打開 /settings，把 copyOnSelect 關閉，就只保留選取、不再自動複製。

常用串接指令核准一次就夠

你每天都要更新專案，輸入 git fetch && git rebase 後又得重複核准，流程像同一張通行證每天重新蓋章。現在可以把這條完全相同的串接指令存成「永遠允許」規則。下次再跑同一條指令時，不必再等，權限確認不會重跳。它認的是整串命令，不是看到 git 就一概放行；因此常用流程少一步，其他不同命令仍各自檢查。

en

Command-line output is now ready for programs to consume

When you connect a command-line tool to CI, a wall of text that only humans can read is a dead end. In print mode, add --output-format json or --output-format stream-json to hand structured output to a program; both flags now also appear in --help. stream-json works like a live relay: it sends init, then step_update events as work progresses, and ends with result, so nothing has to wait for the whole run. Each event has a fixed step_type; only tool calls include names, parameters, and output. Delegated subagents also provide a conversation ID and log location. Add --json-schema with either an inline schema or a schema-file path to require a particular final shape. Usage data now includes cache_read_tokens, showing how many tokens hit the prompt cache.

You decide whether selecting text copies it automatically

You may drag across terminal text only to inspect it, then release the mouse and find that the selection has already landed in your clipboard — sometimes corrupting certain payloads. The TUI's altscreen renderer now has copyOnSelect, enabled by default: release a text selection and it copies automatically. It is like a copier that feeds every sheet the moment you touch it: handy when you want a copy, awkward when you do not. If pasted content comes out wrong, open /settings and turn copyOnSelect off. You can still select text, but releasing the mouse will no longer copy it.

Approve a familiar chained command once, not every time

When you update a project every day, approving git fetch && git rebase again and again feels like getting the same pass stamped from scratch. You can now save that exact chained command as an always-allow rule. The next time you run the identical command, the permission prompt stays away. The rule recognizes the whole chain, not every command that happens to begin with git; your routine loses a step while different commands still receive their own check.

zh-CN

命令行输出能直接交给程序接手

把命令行工具接进 CI（自动跑测试和部署的流程）时，最怕它只吐出一大段人看得懂、程序却接不住的文字。现在在 -p 后加 --output-format json 或 --output-format stream-json，就能拿到供程序读取的结构化输出；--help 也找得到这些选项。选 stream-json 时，结果像接力直播：一开始送出 init，每一步送 step_update，最后才送 result，不用等整趟工作结束。每个事件都有固定的 step_type 类别；工具调用才会附上工具名称、参数与输出。如果有委派子代理，也带上对话 ID 与记录位置。想让最后答案固定格式，可加 --json-schema，直接给规则文字或文件路径。输出的用量也多了 cache_read_tokens，看得出有多少 token 命中缓存（把先前结果暂存再利用）。

选取文字要不要自动复制，自己决定

你在终端里拖动选取一段结果，本来只是想看清楚，松开鼠标却可能把内容自动塞进剪贴板，甚至弄坏特定数据。现在 TUI（终端里用文字画出的交互界面）的 altscreen 呈现模式新增 copyOnSelect，默认开启：选取后放开鼠标便会复制。它像复印机自动送纸，省掉按复制，却不适合每种纸张。若你贴上后发现内容变怪，打开 /settings，把 copyOnSelect 关闭，就只保留选取、不再自动复制。

常用复合命令批准一次就够

你每天都要更新项目，输入 git fetch && git rebase 后又得重复批准，流程像同一张通行证每天重新盖章。现在可以把这条完全相同的复合命令存成「永远允许」规则。下次再跑同一条命令时，权限确认不会重跳。它认的是整串命令，不是看到 git 就一概放行；因此常用流程少一步，其他不同命令仍各自检查。

ja

コマンドラインの出力をそのままプログラムへ渡せる

CI にコマンドラインツールをつなぐとき、人には読めてもプログラムが受け取れない長文だけでは困る。print モードで --output-format json または --output-format stream-json を加えれば、プログラム用の構造化出力を渡せるようになり、両方のフラグは --help にも表示される。stream-json は中継放送のように、最初に init、進行中に step_update、最後に result を送るため、完走まで待つ必要がない。各イベントには固定の step_type があり、ツール呼び出しにだけ名前、引数、出力が入る。委任したサブエージェントには会話 ID とログの場所も付く。--json-schema に規格文字列か規格ファイルへのパスを渡せば、最後の結果の形式を決められる。使用量には cache_read_tokens も加わり、prompt cache にヒットした token 数が分かる。

文字を選んだら自動コピーするか自分で決められる

端末で結果の一部をドラッグして見やすくしただけなのに、マウスを離すと内容がクリップボードへ自動で入り、特定のデータを壊してしまうことがある。TUI の altscreen 描画には、選択してマウスを離すとコピーする copyOnSelect が追加され、初期状態では有効である。触れた紙をすぐ送り出すコピー機のように、コピーしたいときは便利だが、そうでないときは困る。貼り付けた内容がおかしくなったら /settings を開き、copyOnSelect を無効にすればよい。選択は残るが、自動コピーは起きなくなる。

いつもの連結コマンドは一度の許可で済む

毎日プロジェクトを更新し、git fetch && git rebase を打つたびに許可し直すのは、同じ通行証に毎日あらためて判を押すようなものだ。この完全に同じ連結コマンドは、常に許可する規則として保存できるようになった。次回も同じコマンドを実行するなら、権限確認は再び出ない。git で始まるものをまとめて通すのではなく、連結した命令全体を見分けるため、いつもの手順だけが一段減り、別の命令はそれぞれ確認される。

ko

명령줄 출력을 프로그램에 바로 넘길 수 있다

명령줄 도구를 CI에 연결할 때 사람이 읽는 긴 글만 나오면 프로그램은 다음 일을 받지 못한다. print 모드에서 --output-format json 또는 --output-format stream-json을 더하면 프로그램이 읽을 구조화된 출력을 넘길 수 있고, 두 플래그는 --help에서도 찾을 수 있다. stream-json은 중계 방송처럼 처음에 init을 보내고, 진행 중에는 step_update를 보내며, 끝에 result를 보낸다. 그래서 전체 실행이 끝날 때까지 기다릴 필요가 없다. 각 이벤트에는 고정된 step_type이 있고, 도구 호출에만 이름과 매개변수, 출력이 담긴다. 위임한 하위 에이전트에는 대화 ID와 로그 위치도 붙는다. --json-schema에 규격 문자열이나 규격 파일 경로를 주면 마지막 결과의 모양을 강제할 수 있다. 사용량에는 cache_read_tokens도 추가돼 prompt cache에 적중한 token 수를 알 수 있다.

글자를 선택하면 자동 복사할지 직접 정한다

터미널에서 결과 일부를 드래그해 읽기만 하려 했는데, 마우스를 놓자마자 내용이 클립보드에 자동으로 들어가 특정 데이터가 망가질 수 있다. TUI의 altscreen 표시 모드에 copyOnSelect가 추가됐으며 기본값은 켜짐이다. 글자를 선택하고 마우스를 놓으면 곧바로 복사한다. 손댄 종이를 바로 넣는 복사기처럼 복사가 필요할 때는 편하지만, 아닐 때는 곤란하다. 붙여 넣은 내용이 이상해지면 /settings를 열어 copyOnSelect를 끄면 된다. 선택은 그대로 하되 자동 복사는 일어나지 않는다.

자주 쓰는 연결 명령은 한 번만 허용하면 된다

매일 프로젝트를 업데이트하며 git fetch && git rebase를 입력할 때마다 다시 허용하는 일은 같은 통행증에 매일 도장을 새로 찍는 것과 같다. 이제 이 완전히 같은 연결 명령을 항상 허용하는 규칙으로 저장할 수 있다. 다음에 같은 명령을 실행하면 권한 확인이 다시 뜨지 않는다. git으로 시작하는 모든 명령을 통과시키는 것이 아니라 연결된 명령 전체를 알아본다. 그래서 익숙한 절차만 한 단계 줄고, 다른 명령은 각각 확인한다.

原始 CHANGELOG

Original changelog
Print mode (`-p` / `--print`) now supports structured, machine-readable output via the `--output-format` flag (`text` (default), `json`, or `stream-json`), so headless runs in CI, eval harnesses, and scripts can consume the CLI's output programmatically; these flags are now discoverable in `--help`.
Added the `stream-json` output format: a strongly-typed NDJSON event stream that emits typed `init`, `step_update`, and terminal `result` events with a stable, closed-vocabulary `step_type` discriminator, so consumers receive progress incrementally instead of waiting for the whole run to finish.
Added the `--json-schema` flag to enforce a custom JSON schema on the structured output, accepting either an inline schema string or a path to a schema file; for `stream-json` the schema applies to the final `result` event.
Enriched the structured stream with a `tool_info` object for each tool call (canonical tool name, parameters, and output) and a `subagent_info` payload for delegated subagents (including `conversation_id` and `log_uri`) so consumers can correlate child trajectories.
The JSON usage object emitted by `json` and `stream-json` now reports token accounting including `cache_read_tokens`, so non-interactive consumers can attribute prompt-cache hits.
Original changelog
Added a `copyOnSelect` setting (default on, toggleable in `/settings`) that controls whether releasing a mouse text-selection auto-copies it to the system clipboard in the TUI's altscreen rendering mode; disable it to stop the automatic copy on release — useful when the auto-copy is unwanted or corrupts certain payloads.
Original changelog
Improved compound-command permissions so an exact chained command (such as `git fetch && git rebase`) can be saved as an allow-always rule and no longer re-prompts on the next identical run.
