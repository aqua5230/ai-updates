Antigravity 1.5.17

Released: 2026-11-25

Release notes

FEATURE

Mouse Cursor Placement and Selection in Full-Screen Input

When you have typed a long prompt and want to change a few words in the middle, you no longer have to hold down arrow keys to nudge the cursor over. Inside the prompt box in full screen (altscreen) rendering mode, a single click moves the cursor right where you want it. You can also drag, double-click, or double-click and drag by word to highlight text without overwriting your clipboard on release. Once selected, you can type or paste to replace it, or use Backspace, Delete, Ctrl+C to copy, and Ctrl+X to cut. When Vim mode is on, selecting text with the mouse outside Insert mode enters characterwise Visual mode so Vim operators and motions act directly on the selection. Clicking past the end of a line in Normal mode places the cursor on the last character of that line.

Editing those few lines used to feel like nudging an old typewriter carriage one space at a time, whereas now you can click and drag right on the screen to highlight and move or swap whole chunks effortlessly.
FEATURE

Active Wakeups Replace Polling for Background Commands

After handing off a long-running background shell command, the agent used to spin up separate polling timers to check on progress back and forth. Now, tracking a background command can schedule a wakeup notification directly, so the CLI automatically notifies the agent if the command is still running and saves extra check-in turns.

Instead of opening the door every few minutes to check for a delivery, the courier texts you while still on the way, saving you all those wasted trips.
FEATURE

Direct Single-Agent Runs and New Labels in Orchestrator

Picking a model on the Orchestrator row in /model is now clearer and avoids unnecessary detours. The currently selected thinking Effort option is wrapped in brackets, such as [high], and the Tab hint changes from tab Effort to tab Next Field. Whenever Planner and Executor use the same model and Effort, it runs directly as a single agent on that model. At that point, the status line at the bottom of the terminal shows that model, /btw inherits it, and /context switches to its context window (the maximum amount of content a model can process at once). If you choose different Effort levels within the same model family, it continues running the two-phase plan-and-execute mode.

Think of writing a piece: if you apply the same standard to both outlining and polishing, it makes more sense to write it straight through, and only split into two passes when each stage calls for a different level of effort.
FEATURE

/usage Shows Quota Countdowns in Days Over 24 Hours

When checking how long until your quota resets, any number over a full day used to require converting hours into days in your head. Now, running /usage displays quota refresh countdowns of 24 hours or longer in days, hours, and minutes. For example, the screen shows in 3d 3h 59m instead of in 75h 59m.

FEATURE

Remote Logins in /mcp and /plugin No Longer Expire Mid-Session

Connecting to a remote tool only to get disconnected after a while often happens because the initial login credential expires. Now, signing in with OAuth for an MCP (Model Context Protocol, a standard for connecting AI to external tools) server via /mcp and /plugin adds an extra check. Whenever the server specifies scopes and its authorization server advertises offline_access, the CLI requests offline_access as well. That way, remote servers like Vercel issue refresh tokens (credentials used for authentication) so you do not get disconnected as soon as the initial access credential expires.

Picture entering a building with a temporary visitor pass that forces another ID check once it expires; requesting a renewable pass upfront lets it swap for a fresh one before time runs out, so you are not escorted out mid-visit.
BUGFIX

Fixed Tab Completion in the Slash-Command Menu

After typing / to open the command completion menu, pressing Tab used to do nothing whenever multiple commands shared a prefix, after navigating items with ↑ or ↓, or right after typing plugin:. That is fixed now: whenever no longer common prefix can be extended, pressing Tab completes the highlighted command and closes the menu.

BUGFIX

Fixed Panel and Menu Scrolling in Full-Screen Mode

In full screen (altscreen) rendering mode, trying to scroll an open panel or menu used to scroll the conversation behind it instead. That is fixed now: scrolling the mouse wheel over an open bottom panel or a /, @, or argument dropdown only scrolls the panel itself. The same goes for panels that page themselves, such as /help, /permissions, /skills, /context, and /usage. Pressing PgUp, PgDn, Shift+↑, or Shift+↓ only flips pages within the panel without scrolling the conversation behind it.

BUGFIX

Fixed Staircase Indentation in agy update Status Output

When running the update command in a terminal with raw output mode enabled, each printed status line used to drift further to the right. That is fixed now: running agy update aligns every status line cleanly, while piped or file-redirected output keeps the original newline-only format.

BUGFIX

Long Sessions Resume Through Token Expiry and Capacity Limits

When letting an agent run a longer task continuously, the worst feeling is hitting a mid-run connection issue right before the finish line and losing the whole stretch. When a Google OAuth access token crosses its one-hour expiry, it used to fail right away with UNAUTHENTICATED and 401 errors. Now the CLI refreshes the token before it expires, and automatically retries if it hits a 401 before streaming starts. For long, multi-part streaming model responses, hitting a temporary 503 or MODEL_CAPACITY_EXHAUSTED capacity error during continuation used to discard progress and restart or fail. Now the CLI retries automatically and picks up right where it left off.

BUGFIX

Fixed Error Message When Enterprise Prepaid Balance Hits Zero

When a Gemini Enterprise prepaid wallet hit zero, the CLI used to retry repeatedly and mistakenly report You have exhausted your quota on this model.. Now the CLI stops immediately and displays the following message instead:

Your organization's prepaid balance is insufficient. Contact your administrator to add funds.

The Remote Control web view also shows an Organization prepaid wallet is empty notice.

BUGFIX

Fix sensitive file protections bypassed by enterprise external access

When you used Gemini Enterprise or enterprise model-gateway sessions with access to paths outside the workspace allowed, confirmation and block checks used to be skipped. Affected sensitive files include .git, .env, config.json, hooks.json, and mcp_config.json. This issue is fixed, and built-in approval and deny protections are no longer bypassed.

BUGFIX

Fix missing token when running plugins across Windows drives

When the terminal sandbox was off on Windows and your workspace and user profile were on different drives, launching CLI tools used to miss authentication details. This issue is fixed, so plugin tools now run with their configured authentication token.

BUGFIX

Fix model picker locked during responses in Remote Control

While a turn was still running, trying to switch options in the browser to ask a question meant the toggle in the message box would not respond at all. This issue is fixed, so the Remote Control browser view now lets you switch models mid-turn for /btw side questions or messages sent after the current turn.

BUGFIX

Fix LaTeX math with \label failing to render in Remote Control

When opening LaTeX formulas generated by AI in the browser, any formula containing a label used to trigger a Failed to render LaTeX error on screen. This issue is fixed, and the Remote Control browser view now properly renders math blocks containing \label{...} tags.
