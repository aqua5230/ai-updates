Antigravity 1.1.23

發布日期：2026-09-01

繁體中文

新功能

模型補齊支援 Tab 鍵，指令不再卡死與崩潰

你在終端機切換模型或輸入指令時，操作變得更加乾淨俐落。

這好比駕駛座上的智慧儀表板，看到導航浮現建議路線的淡色虛影時，只要輕按一下方向盤按鈕就能直接套用，遇到外接配件訊號異常也會自動略過而非讓引擎熄火。

現在輸入 /model <name> 時，只要按下 Tab 鍵就能直接採納灰色的模型名稱建議文字；執行帶有子指令的命令（如 models 或 agents）時，不再因繼承未關閉的標準輸入管線卡死，而是立即執行。同時，程式能妥善攔截提示詞掛鉤（hook，特定事件發生時被觸發的小程式）引發的異常，並拒絕模型請求中的空完成設定，防止命令列意外當機；輸入框在打字並清空後，引導模式的佔位文字也不會再莫名跳出干擾。

問題修復

登入與驗證流程修復，權杖提前換發不中斷

剛登入帳號或進行身分驗證時，現在不會再遇到提示詞被吞掉或對話壞掉的問題。先前若 Google Cloud 認證與新手引導工作階段未設定完成或意外中斷，畫面會直接掉進故障的對話視窗，現在則會正常顯示登入介面。針對電腦時鐘偏差造成的偶發認證錯誤，瀏覽器與 WIF 的 OAuth 權杖（token，驗證身分的授權令牌）現在會在到期前 5 分鐘主動提前換發。此外，剛完成登入就送出的提示詞不會再因帳號驗證提示而被丟棄，而是會自動排隊等待背景資格驗證完成後依序執行。

宛如出國通關時，證件到期前就有專人主動蓋章換新，剛驗完票說的需求也會先寫入登記簿依序處理，手續中斷更會清楚指引你回到正確櫃檯。
問題修復

子代理傳輸效能提升，工具調度與狀態同步修復

指派多個子代理（subagent，負責分工處理特定子任務的輔助助理）處理複雜工作時，整體執行變得更輕快可靠。

這好比專案經理向外勤專員派工，專員不再每走一步就打通電話回報，而是分段提交彙整報告，同時專員手上配有標準工具箱，任務一旦撤銷，派工看板也會立即更新標記。

系統現在改為每個子軌跡僅發送一次軌跡詮釋資料，不再每一步都發送，大幅降低串流傳輸的額外負擔；針對設定了 enable_mcp_tools=true 的子代理，執行器現在能正確取得 MCP（讓 AI 連接外部工具的協定）分派器中繼工具，排除找不到工具的錯誤；而在上層對話中被取消或終止的子代理，工作抽屜介面也會即時更新，不再卡在執行中的狀態。

問題修復

工具授權顯示清楚動作，歷史紀錄與設定解析修復

使用各類擴充工具時，現在確認權限與讀取設定都更加清楚精確。當發起直接工具或 MCP（讓 AI 連接外部工具的協定）工具呼叫時，彈出的權限確認提示會直接顯示宣告的人類可讀動作描述，不再只印出模糊的通用標題。在為 Gemini 模型重組請求歷史紀錄時，系統已修正工具呼叫與結果遺漏識別碼的問題，確保上下文能精準對照。此外，在 Windows 系統中若把 MCP 的 JSON 設定檔儲存為帶有 UTF-8 BOM 標記的格式，現在也能正常讀取而不報錯。

這如同公司簽呈審核，申請單上明確寫著具體事由而非含糊的常規申請，審核後的每張回條也都蓋上流水號對應原始單據，即使文件開頭帶有排版記號也不會卡件。

English

FEATURE

Model Autocompletion Supports Tab Key, Commands No Longer Hang or Crash

When switching models or entering commands in the terminal, your workflow is now cleaner and smoother.

It is like a smart dashboard on a steering console: when a faint ghost line of a recommended route appears on the navigation, you can accept it with a simple press of a steering wheel button, and any abnormal signal from external accessories is safely bypassed rather than stalling the engine.

Now when entering /model <name>, you can press the Tab key to directly accept the grey ghost text suggesting the model name; executing commands with subcommands (such as models or agents) no longer hangs on an inherited, unclosed standard input pipe and runs immediately. At the same time, the program properly catches exceptions raised by prompt hooks (helper routines triggered by specific events) and rejects nil completion configurations in model requests to prevent accidental CLI crashes; placeholders in instructional cycle mode will also no longer unexpectedly reappear after typing and clearing the input prompt.

BUGFIX

Login and Authentication Flow Fixed, Tokens Proactively Refreshed

When signing into an account or verifying identity, you will no longer encounter dropped prompts or broken conversations. Previously, if Google Cloud authentication and onboarding sessions were unconfigured or interrupted, the interface would drop into a broken chat session; now it properly displays the sign-in screen. To prevent transient authentication errors caused by computer clock skew, browser and WIF OAuth tokens (authorization credentials used to verify identity) are now proactively refreshed 5 minutes before expiration. In addition, prompts submitted immediately after login will no longer be discarded due to account verification alerts, but are queued until background eligibility verification completes.

It is like clearing border control: expiring documents are renewed ahead of time by dedicated staff, requests made right after ticket checks are entered into a log for orderly processing, and any interrupted procedure clearly directs you back to the right counter.
BUGFIX

Subagent Streaming Performance Improved, Tool Dispatch and Status Sync Fixed

When assigning multiple subagents (auxiliary assistants that handle specific subtasks) to tackle complex work, overall execution is now faster and more dependable.

It is like a project manager dispatching field specialists: instead of calling to report at every single step, specialists submit consolidated reports in stages, carry standard toolkits, and have their task board statuses updated immediately if an assignment is cancelled.

The runner now sends subtrajectory metadata once per subtrajectory instead of at every step, significantly reducing streaming overhead; for subagents configured with enable_mcp_tools=true, the executor can now properly access the MCP (protocol connecting AI to external tools) dispatcher meta-tool, eliminating unknown tool errors; and for subagents cancelled or killed in ancestor conversations, the task drawer interface updates promptly rather than remaining stuck in the running state.

BUGFIX

Clear Action Descriptions in Tool Permissions, History and Config Parsing Fixed

When using various extension tools, reviewing permissions and loading configurations is now clearer and more precise. When initiating direct or MCP (protocol connecting AI to external tools) tool calls, the permission confirmation prompt now directly shows declared human-readable action descriptions instead of displaying generic prompt titles. When reconstructing request history for Gemini models, the missing tool-call IDs in tool invocations and results have been fixed to ensure precise context matching. Additionally, saving MCP JSON configuration files with a UTF-8 byte order mark (BOM) on Windows is now parsed properly without errors.

It is like corporate expense approvals: the request form states the exact purpose rather than a vague generic category, every approval slip is stamped with a serial number corresponding to the original invoice, and documents are never held up even if they begin with formatting marks.
