Antigravity 1.2.3

Released: 2026-09-15

Release notes

FEATURE

Add /copy btw to copy full text of side-question responses, with argument ghost hints when typing commands

While waiting for AI to handle primary tasks, asking side questions via /btw and retrieving the answer text is now much smoother.

This is like attending a conference lecture and jotting down an expert's elaboration on a sticky note at the corner of your desk; even if the note happens to be covered by heavy handouts or folded away, your dedicated assistant can still copy the exact text from the entire note into your binder for you.

When you ask an assistant to draft a long-form proposal and use /btw during downtime to look up technical terms, and then want to paste the full answer into your report after reading, this is the exact moment to type /copy btw. This newly added slash subcommand copies the full text of the active /btw side-question response directly to your clipboard, even if the response card is collapsed or scrolled out of view. In addition, when you type /copy in the terminal, the command input bar displays argument ghost hints (faded suggestions for parameters to fill in while typing commands) to remind you of available options you can enter next.

FEATURE

Translate tool-choice constraints into native backend configurations to improve calling fidelity

When directing AI to call tools for specific workflows, the model's adherence to calling restrictions is now more precise and reliable.

Previously, when specifying per-request tool-choice constraints—such as any requiring calling any tool, required enforcing tool invocation, or specifying named functions—executions could still occasionally deviate from instructions if not integrated into the underlying layer. Now, the system directly translates per-request tool-choice constraints into native backend function-calling configurations (a mechanism where the model service's underlying interface directly manages tool selection), ensuring complete fidelity in tool calling.

Just like a sorting conveyor belt in a precision logistics center, when a package is labeled 'must inspect' or assigned a specific lane, the system writes routing instructions directly into the conveyor's underlying sensor circuits, allowing packages to arrive precisely along the track without errors.
BUGFIX

Include hook configurations bundled inside enabled plugins in /hooks and inspection utilities

When inspecting hook configurations in automated workflows, rules bundled with plugins no longer invisibly disappear.

Previously, when running the /hooks command in the terminal or using hook inspection utilities to list active hooks.json configurations, the system omitted hooks bundled inside enabled plugin packages (small programs triggered when specific events occur), making it difficult to verify whether plugin features were intercepting as expected. This omission issue is now fixed, and listings faithfully include all hook configurations bundled with enabled plugins.

BUGFIX

Custom subagents inherit parent MCP servers and correctly resolve relative configuration paths

When configuring custom subagents for specialized division of labor, two issues with tool connections and file paths have been fixed.

Previously, even if enable_mcp_tools: true was specified when creating a custom subagent, the subagent only received an empty server list and failed to inherit the configured MCP (Model Context Protocol, a protocol allowing AI to connect to external tools) servers from the parent agent. At the same time, if a declarative subagent configuration specified a relative configuration file path using relative_path_to_config, the system failed to resolve it against the parent agent's directory. Both path and configuration inheritance issues are now fixed, ensuring subagents properly inherit the parent agent's external tool servers and relative paths align smoothly.

BUGFIX

Proactive feedback prompts no longer trigger prematurely, eliminating early-session and transient-error disruptions

When starting a new conversation in the terminal or using tools, feedback rating prompts no longer pop up unexpectedly to disrupt your flow.

Previously, during the first few turns of a session or when tools encountered transient errors that quickly recovered, proactive feedback prompts triggered prematurely, soliciting feedback before tasks were clear. This premature triggering issue is now fixed, preventing pop-up prompts from interrupting your train of thought during early conversations or recovered transient errors.
