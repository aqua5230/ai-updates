Antigravity 1.1.24

Released: 2026-09-02

Release notes

FEATURE

Smoother `/mcp` Panel Navigation with Clear Arrow and Escape Key Roles

When navigating MCP (protocol connecting AI to external tools) servers and plugins in the /mcp panel, the roles of arrow keys are now clearly divided.

Up and down arrow keys strictly move vertically between individual servers and plugins, left and right arrow keys cycle through available actions for the selected item, and pressing Esc exits action mode or closes the panel.

It is like navigating a TV menu: up and down keys switch channels, left and right keys adjust audio tracks or video quality, and pressing back cleanly returns to the previous level without accidentally jumping across unrelated fields.
BUGFIX

Automatic Deduplication in `/agents` Picker Eliminates Duplicate Agents Across Sources

When contact books across different departments list the exact same person, a smart phone merges them into a single entry rather than cluttering your list with duplicate profiles.

When you define agents (assistants that perform specific tasks) with identical names across multiple configuration sources or plugins, opening the /agents picker no longer shows distracting duplicates.

Previously during discovery, finding an agent with the same name across different sources or plugins listed every instance in the picker; the menu now automatically deduplicates entries, keeping your selection list clean.

BUGFIX

Tool and Agent Initialization Succeeds Even from Deleted Working Directories

Even if your temporary waypoint disappears under your feet while traveling, navigation continues smoothly as long as your guidebook records full global coordinates.

Launching the command line from a working directory that has been deleted or is inaccessible will no longer cause tool initialization or agent startup to crash.

Previously, parameter schemas held in memory lost relative references when the directory was invalid; switching fully to absolute URI schemes ensures all tools and agents initialize reliably regardless of directory state.

BUGFIX

Headless CLI Invocations with Pipes Exit Cleanly Without Hanging

It is like workers shutting off the main water valve before leaving a construction site, ensuring pipes do not stay pressurized and stall subsequent inspections.

When running automation scripts in headless mode (background execution without a visual interface) with piped standard output or standard error, invocations no longer hang on exit.

Previously, spawned child processes kept the caller's pipes open and prevented the main process from shutting down cleanly; setting FD_CLOEXEC on preserved streams now ensures all pipe resources are fully released on exit.

BUGFIX

Lenient `mcp_config.json` Parsing Supports Comments and Trailing Commas

When manually editing tool configurations, you no longer need to worry about quick notes or extra commas breaking your setup.

Previously, adding single-line comments //, multi-line comments /* */, or trailing commas in mcp_config.json caused MCP (protocol connecting AI to external tools) configuration parsing to fail; the parser is now more forgiving and reads configurations containing comments and trailing commas smoothly.

It is like an understanding form inspector who effortlessly processes notes in margins or accidental punctuation marks without rejecting the entire submission.
BUGFIX

Deleting Conversations Thoroughly Cleans Up Orphaned Annotation Files

When clearing old conversations, your local disk space is now kept completely tidy.

Previously, deleting a conversation removed the main chat but often left associated annotation files in local storage, gradually accumulating useless orphaned files over time; the deletion logic has been updated to automatically prune matching annotations alongside the conversation.

It is like removing an old poster from a wall and scraping off the leftover adhesive tape around the edges, preventing stray scraps from piling up in corners.
BUGFIX

Side Questions via `/btw` No Longer Force Goal Progress or Trigger Unintended Tools

While AI is actively working through a major project, you can now safely ask quick side questions without derailment.

When running a long-term goal with /goal, asking a side question with /btw (by the way, a command for asking auxiliary questions) previously led to treating the tangent as part of the active goal, forcing unwanted progression and unintended tool calls; their execution states are now decoupled so side questions resolve your query without interrupting the main task.

It is like asking a chef cooking an elaborate meal where the salt is: they answer and resume cooking immediately, rather than dumping the entire salt container into the soup.
