Antigravity 1.0.3

Released: 2026-07-13

Release notes

FEATURE

Never run out of quota: G1 credits support is now live

You no longer have to wait agonizingly when your standard quota runs out.

The system now officially supports "G1 credits" and introduces a new UseG1Credits setting; when enabled, it seamlessly starts using your credits the moment your standard quota is depleted. You can monitor your remaining credits in real-time right on the bottom status bar, use the brand-new /credits command to open a dedicated panel, and even click a direct link within it to purchase more. Like running out of your phone's monthly data plan: you used to get cut off from the internet and forced to wait for the next month, but now the system automatically taps into a prepaid card to keep you surfing at full speed, letting you check your balance and top up with a single click.

FEATURE

Refined layouts and UI dialogs that remember your answers

We've made several thoughtful tweaks to the visual layout.

If you use Apple Terminal, you'll now be greeted by a newly redesigned logo. When previewing or setting the application's color theme, the preview is much more realistic, now including samples for "warnings" and "thought processes," and fixing an issue where URL underlines were drawn haphazardly. When viewing code differences (/diff), if a line is too long, it now smartly wraps text based on your window size instead of cutting it off completely. When the system asks you a sequence of questions (like in a setup wizard) and you press the left arrow to go back and change a previous answer, it used to completely suffer from amnesia and wipe out everything you had just painstakingly typed; it finally knows how to remember your progress. Like filling out an online form: hitting "back" used to delete all your entered data and force you to start over, but now the system thoughtfully preserves everything you've written so far.

BUGFIX

Fixes input hangs, editor launch failures, and fragile project discovery

We've eradicated several highly confusing system bugs.

Previously, when typing in the input box, if you hit the shortcut to jump left while at the very beginning of the blank space, the program would get trapped in an infinite loop and completely hang; this has been fixed. When trying to disable an external MCP tool from the terminal UI, clicking "Disable" used to do absolutely nothing because the system was writing to the wrong config file path; it now correctly unloads the tool. If you use a custom text editor with complex arguments (like --alternate-editor=vi in your $EDITOR variable), the system used to crash because it didn't know how to handle the equals sign; it parses it perfectly now. Additionally, when searching for your project folders, encountering a broken shortcut (symlink) used to make the system throw a tantrum and completely give up searching; it now smartly skips the broken links and continues finding your valid projects. Like a night guard doing rounds: previously, if one door was jammed, the guard would just go home and abandon the rest of the patrol, but now they know how to walk past the broken door and check the remaining rooms.

Fixed `$EDITOR` environment variable parsing: resolved issues where arguments containing `=` (e.g., `--alternate-editor=vi`) were incorrectly split, causing editor launch failures.
Fixed project discovery robustness: updated the CLI to skip invalid or broken symlinks in `.antigravitycli/` rather than failing immediately, allowing discovery of valid projects.
