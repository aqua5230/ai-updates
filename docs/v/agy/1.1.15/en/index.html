Antigravity 1.1.15

Released: 2026-08-19

Release notes

FEATURE

Stream JSON keeps external programs in one conversation

When an external program needs to send Antigravity a run of prompts, print mode can now take --input-format stream-json.

It reads one newline-delimited JSON prompt from stdin for each turn in one conversation. A driver can keep that session open instead of starting a new conversation for every message.

It is like keeping one sketch on a whiteboard: every new stroke continues the same idea.
FEATURE

Agents and plugins can name rule files to apply

When setting rules for an agent, add rules: to its Markdown frontmatter and name rule files directly.

A rule named there always applies, without inheriting whole rule tree. A plugin can also put rules.json at top level to declare rule files it ships, as it already declares skills.

It is like giving new hire named handbook pages, not whole filing cabinet; plugin lists own pages on cover.
FEATURE

Spinner names tool call and stops reverting to generic label

While agent runs tool, spinner line now names current tool call.

It also no longer flickers back to generic label in gaps between quick tool calls.

It is like repair desk showing name badge of person handling your job; fast handoffs do not turn badge into blank sign.

You can see what agent is doing instead of only watching spinner.

BUGFIX

CLI starts on hosts that preload a memory allocator

Some hosts use LD_PRELOAD to load own allocator before program starts.

CLI used to abort before interface appeared on those hosts, including Cloud TPU VM images. CLI now starts on these hosts.

It is like venue installing own plug adapter before doors open; reception desk can open rather than losing power before anyone enters.
BUGFIX

Restored sign-in data keeps account and billing choices

When saved credentials return from system keyring, personal accounts no longer hit resource-exhausted error at startup and repeated account checks are cut.

After CLI restarts, billing project and license tier it selects also stay put.

It is like a stage console reloading its chosen lighting setup after a restart: it does not repeatedly test at opening or forget selected mode.
BUGFIX

Enterprise accounts no longer get false out-of-credits alert

Enterprise users signed in through Application Default Credentials no longer see spurious "Out of credits" message.

This update fixes that false alert.

It is like balance sign at gate misreading valid pass as empty balance; spurious "Out of credits" message no longer appears.

Enterprise users who saw this message no longer see spurious "Out of credits" message.

BUGFIX

Model picker scrolls and aligns columns in short terminals

If terminal is too short to show every model, /model picker now scrolls instead of cutting off models or own header.

For model names beyond plain ASCII, columns measure display cells rather than bytes and stay aligned.

It is like short bookcase using scrollable catalog, with every title lined up in same column no matter character width.

You can read whole list and each row more clearly.

BUGFIX

Streamed text preserves non-ASCII characters

When reply arrives as stream, non-ASCII characters used to become replacement characters.

Both interactive display and text deltas from --output-format stream-json were affected. They now preserve original characters instead of changing text midstream into unreadable symbols.

It is like fax machine crushing special letterforms into boxes; pages now retain original letters at both receiving slots.
BUGFIX

Conversation artifacts in subdirectories appear in list

A file written under subdirectory of conversation artifact directory, such as scratch/, used to miss artifact list.

Artifact directory stores conversation artifacts. Those artifacts now appear in list too.

It is like filing work papers inside labeled inner folder; list now opens folder rather than counting only top of desk.

Files in scratch/ can be found with other conversation artifacts.

BUGFIX

WAV audio reads after media type normalization

Reading .wav file could fail as unsupported media type.

It now normalizes non-canonical MIME types such as audio/wave before they reach model.

It is like clerk rewriting unusual address form into format post office recognizes before package reaches sorting belt.

A .wav is not rejected only because type label uses different form.
