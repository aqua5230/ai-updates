Antigravity 1.1.19

發布日期：2026-08-23

zh-TW

遠端控制啟動時會改用空著的連接埠

要以 --remote-control 開啟遠端控制（remote control，讓另一端連入操作的功能）時，連接埠若已有人使用，工具原本會拒絕啟動。現在它會請作業系統提供可用的連接埠。這像計程車到停靠處發現已有車佔著，不必取消行程，而是由調度員帶它去空位。 對需要啟動遠端控制的人來說，連接埠被占用不再直接使它無法開始。

終端機太窄時可隱藏開頭標誌圖案

在窄終端機查看輸出、用螢幕閱讀器讀內容或準備錄影時，若開頭橫幅的標誌圖案擋住資訊，設定 AGY_CLI_HIDE_LOGO。這個環境變數（程式在啟動時收到的設定）會在這次啟動隱藏橫幅上的標誌圖案，版本和帳號資訊仍會照原樣保留顯示。這像把窄公告欄上佔位的海報取下；版本與帳號資訊仍留著。 它不會連版本和帳號資訊一起隱藏。

可略過終端機畫面的繪製最佳化

Antigravity 的渲染器（把文字畫到終端機畫面的部分）通常會使用兩項最佳化。它先以 diffing 最佳化（比對新舊內容差異）找出變動區域，接著以 dirty-rectangle 最佳化重畫。後者只繪製變動區域。當終端機畫面不如預期，想不用這兩項最佳化來檢查時，設定 AGY_CLI_DISABLE_ESCAPE_SEQUENCE_OPTIMIZATIONS。這會在這次啟動略過兩者。這像修補壁畫，先核對新舊草稿找出變色格子，再補畫那些格子；這個開關容許不走這套修補流程。

en

Remote control now finds an open port when starting

When you start remote control with --remote-control, the tool used to refuse to start if its port was already taken. It now asks the operating system for an available port. It is like a taxi reaching its stand, finding another cab there, and being directed to an open space instead of cancelling the trip. A taken port no longer stops remote control from getting started.

Hide banner art when it gets in the way

When banner art blocks information in a narrow terminal, a screen reader, or a recording, set AGY_CLI_HIDE_LOGO. This environment variable (a setting passed to a program when it starts) hides the art for that launch. It is like taking an oversized poster off a cramped noticeboard while leaving the version and account notices in place. The version and account lines remain visible.

A switch to bypass terminal rendering optimizations

Antigravity's renderer (the part that draws text in the terminal) uses two optimizations. It first uses diffing optimization (comparing old and new content) to find changed areas, then uses dirty-rectangle optimization to redraw them. The latter redraws only changed areas. When terminal output does not look right and you want to check it without either optimization, set AGY_CLI_DISABLE_ESCAPE_SEQUENCE_OPTIMIZATIONS. This bypasses both for that launch. It is like restoring a mural by comparing the old and new sketches to find changed tiles, then repainting those tiles; this switch allows that restoration routine to be bypassed.

zh-CN

远程控制启动时会改用空闲端口

用 --remote-control 打开远程控制（remote control，让另一端连入操作的功能）时，如果端口已被占用，工具原本会拒绝启动。现在它会让操作系统提供可用端口。这像出租车到了停靠处发现已有车占着，不必取消行程，而是由调度员带它去空位。 对需要启动远程控制的人来说，端口被占用不再直接让它无法开始。

终端机太窄时可隐藏开头标志图案

在狭窄终端机查看输出、用屏幕阅读器读内容或准备录制时，如果开头横幅的标志图案挡住信息，设置 AGY_CLI_HIDE_LOGO。环境变量（启动时交给程序的设置）会在这次启动隐藏图案。这像把狭窄公告栏上占位的海报取下；版本和账号信息仍留着。 它不会连版本和账号信息一起隐藏。

可跳过终端机画面的绘制优化

Antigravity 的渲染器（把文字画到终端机画面的部分）通常会使用两项优化。它先以 diffing 优化（比对新旧内容差异）找出变化区域，接着以 dirty-rectangle 优化重画。后者只绘制变化区域。当终端机画面不如预期，想不用这两项优化来检查时，设置 AGY_CLI_DISABLE_ESCAPE_SEQUENCE_OPTIMIZATIONS。这会在这次启动跳过两者。这像修补壁画，先核对新旧草稿找出变色格子，再补画那些格子；这个开关允许不走这套修补流程。

ja

リモート操作は起動時に空いているポートを使う

--remote-control でリモート操作（remote control、別の場所から接続して操作する機能）を始める際、ポートがすでに使われていると以前は起動を拒否していた。今はオペレーティングシステムに空いているポートを求める。タクシーが乗り場に着いて先客を見つけても、運行を取りやめず係員が空いた場所へ案内するようなものだ。 ポートの使用中だけでリモート操作を始められなくなることはない。

邪魔になるバナーのロゴを隠せるようになった

狭い端末で出力を確認するとき、スクリーンリーダーで内容を読むとき、または録画を始めるときにロゴ画像が情報を遮るなら、AGY_CLI_HIDE_LOGO を設定する。環境変数（起動時にプログラムへ渡す設定）により、その起動では画像が隠れる。狭い掲示板を占めるポスターだけを外し、バージョンとアカウントの情報は残すようなものだ。 バージョンとアカウントの情報までは隠れない。

端末画面の描画最適化を省ける

Antigravity のレンダラー（文字を端末画面に描く部分）は、通常二つの最適化を使う。まず diffing 最適化（新旧の内容を比べて変化した領域を見つける処理）を行い、その後 dirty-rectangle 最適化で描き直す。後者は変化した領域だけを描く。端末画面が期待どおりに見えず、両方を使わず確認したいときは、AGY_CLI_DISABLE_ESCAPE_SEQUENCE_OPTIMIZATIONS を設定する。これにより、その起動では両方を省ける。壁画の修復で新旧の下絵を照合して変色したマスを見つけ、それからそのマスを塗るようなものだ。この切り替えではその修復手順を通らない。

ko

원격 제어는 시작할 때 빈 포트를 사용한다

--remote-control로 원격 제어(remote control, 다른 곳에서 연결해 조작하는 기능)를 시작할 때 포트가 이미 사용 중이면 도구가 예전에는 시작을 거부했다. 이제는 운영체제에 사용 가능한 포트를 요청한다. 택시가 승강장에 도착해 다른 차가 자리를 차지한 것을 봐도 운행을 취소하지 않고 안내원이 빈자리로 데려가는 것과 같다. 포트가 사용 중이라는 이유만으로 원격 제어를 시작하지 못하지는 않는다.

방해되는 배너 로고 그림을 숨길 수 있다

좁은 터미널에서 출력을 확인하거나 스크린 리더로 내용을 읽거나 녹화를 시작할 때 로고 그림이 정보를 가리면, AGY_CLI_HIDE_LOGO를 설정한다. 환경 변수(시작할 때 프로그램에 전달하는 설정)에 따라 그 실행에서 그림을 숨긴다. 좁은 게시판을 차지한 포스터만 떼고 버전과 계정 정보는 남기는 것과 같다. 버전과 계정 정보까지 숨기지는 않는다.

터미널 화면의 그리기 최적화를 건너뛸 수 있다

Antigravity의 렌더러(텍스트를 터미널 화면에 그리는 부분)는 보통 두 최적화를 사용한다. 먼저 diffing 최적화(새 내용과 옛 내용을 비교해 바뀐 영역을 찾는 처리)를 하고, 이어 dirty-rectangle 최적화로 다시 그린다. 후자는 바뀐 영역만 그린다. 터미널 화면이 기대와 다르게 보이고 두 최적화 없이 확인하고 싶을 때는 AGY_CLI_DISABLE_ESCAPE_SEQUENCE_OPTIMIZATIONS를 설정한다. 그러면 그 실행에서는 둘 다 건너뛴다. 벽화를 복원할 때 새 밑그림과 옛 밑그림을 대조해 변색된 칸을 찾고, 그 칸을 다시 칠하는 것과 같다. 이 설정은 그 복원 절차를 거치지 않게 한다.
