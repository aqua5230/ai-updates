Antigravity 1.1.19

發布日期：2026-08-23

繁體中文

遠端控制啟動時會改用空著的連接埠

要以 --remote-control 開啟遠端控制（remote control，讓另一端連入操作的功能）時，連接埠若已有人使用，工具原本會拒絕啟動。現在它會請作業系統提供可用的連接埠。

這像計程車到停靠處發現已有車佔著，不必取消行程，而是由調度員帶它去空位。

對需要啟動遠端控制的人來說，連接埠被占用不再直接使它無法開始。

終端機太窄時可隱藏開頭標誌圖案

在窄終端機查看輸出、用螢幕閱讀器讀內容或準備錄影時，若開頭橫幅的標誌圖案擋住資訊，設定 AGY_CLI_HIDE_LOGO。這個環境變數（程式在啟動時收到的設定）會在這次啟動隱藏橫幅上的標誌圖案，版本和帳號資訊仍會照原樣保留顯示。

這像把窄公告欄上佔位的海報取下；版本與帳號資訊仍留著。

它不會連版本和帳號資訊一起隱藏。

可略過終端機畫面的繪製最佳化

Antigravity 的渲染器（把文字畫到終端機畫面的部分）通常會使用兩項最佳化。它先以 diffing 最佳化（比對新舊內容差異）找出變動區域，接著以 dirty-rectangle 最佳化重畫。後者只繪製變動區域。當終端機畫面不如預期，想不用這兩項最佳化來檢查時，設定 AGY_CLI_DISABLE_ESCAPE_SEQUENCE_OPTIMIZATIONS。這會在這次啟動略過兩者。

這像修補壁畫，先核對新舊草稿找出變色格子，再補畫那些格子；這個開關容許不走這套修補流程。

English

Remote control now finds an open port when starting

When you start remote control with --remote-control, the tool used to refuse to start if its port was already taken. It now asks the operating system for an available port.

It is like a taxi reaching its stand, finding another cab there, and being directed to an open space instead of cancelling the trip.

A taken port no longer stops remote control from getting started.

Hide banner art when it gets in the way

When banner art blocks information in a narrow terminal, a screen reader, or a recording, set AGY_CLI_HIDE_LOGO. This environment variable (a setting passed to a program when it starts) hides the art for that launch.

It is like taking an oversized poster off a cramped noticeboard while leaving the version and account notices in place.

The version and account lines remain visible.

A switch to bypass terminal rendering optimizations

Antigravity's renderer (the part that draws text in the terminal) uses two optimizations. It first uses diffing optimization (comparing old and new content) to find changed areas, then uses dirty-rectangle optimization to redraw them. The latter redraws only changed areas. When terminal output does not look right and you want to check it without either optimization, set AGY_CLI_DISABLE_ESCAPE_SEQUENCE_OPTIMIZATIONS. This bypasses both for that launch.

It is like restoring a mural by comparing the old and new sketches to find changed tiles, then repainting those tiles; this switch allows that restoration routine to be bypassed.
