Antigravity 1.5.9

發布日期：2026-11-14

繁體中文

新功能

開放 run_workflow 工具，讓子代理分工跑 Python 流程

當你手上有整批問卷或報告要整理，單靠單一視窗逐份處理太慢時，現在所有人都能使用 run_workflow 工具。

想像以前大廚得一個人從洗菜做到擺盤，現在直接把切菜、熬湯、擺盤分派給多位助手平行或分階段處理，最後由他匯總上菜，連廚具都自帶齊全。

你在跟代理整理大量資料或拆解多步驟任務時，只要請它啟用 run_workflow，代理就能執行 Python 工作流程腳本（一串照步驟跑的自動化程式）。這份腳本會把工作平行派發或分階段交給多個子代理執行，最後再把結果彙整起來。即使你的電腦沒有另外安裝 Python，它也能直接使用 CLI（指令列工具）隨附的 Python 來跑。

新功能

管理員設定新增 pluginControls，非企業方案也能控管外掛

沒有導入 Gemini Enterprise 的團隊，過去很難統一控管成員電腦裡的外掛。

好比學校圖書室依規定調整借閱，完全停用時連館內現有書架都封起來不准翻閱，若只關閉新書採購櫃位，大家手邊已借出的書仍能繼續使用。

管理員現在可以在受控管的管理員設定裡加入 pluginControls 區段，按需求選擇兩種控制開關：pluginsDisabled 用來停用所有外掛（包含內建外掛），並禁止安裝或啟用任何外掛。marketplaceDisabled 則只會關閉外掛市集，已經安裝好的外掛仍可照常運作。若是 Gemini Enterprise 使用者，依舊會遵循所屬組織在 Cloud Console（Google 雲端管理主控台）設定的政策。

效能優化

自動模式改採直接翻查加快沙盒外指令審查

開著自動模式讓 AI 幫忙跑指令時，只要指令準備跨出終端機沙盒（隔離執行的安全環境），審查步驟就常讓人等得心急甚至逾時。

猶如編輯審查稿件時，以前每確認一個細節都要發公文去外單位查證，常常等到逾期；現在手邊就有通訊錄和檔案夾能直接翻找，立刻就能決定放行或擋下。

以前審查員每做一項檢查，都得另外啟動一個沙盒內的指令來跑。現在審查員可以直接搜尋對話內容、列出資料夾清單並搜尋檔案，因此能更快做出判斷，也較少發生逾時。

新功能

改善 /resume 載入效能並支援短 ID 與查無提示

想接續昨天的長對話繼續工作，輸入 /resume 卻只看到畫面一直卡在「Loading conversations...」嗎？

就像到大型行李寄物區領包裹一樣，以前店員要把每個櫃子都打開清點一遍才讓你挑，人一多就卡在門口；現在只對櫃號前幾碼就能精準取出，遇到空號也會直接告訴你。

現在開啟對話選擇器時，不再抓取每個開啟中對話的完整歷史紀錄，因此在較長的工作階段裡不會再卡在載入畫面。用 /resume <id> 指定對話時，只要輸入的開頭字元能唯一對應到一個對話（例如狀態列顯示的短 ID）就能直接恢復。如果輸入了不存在的 ID，畫面會明確回報 conversation <id> not found，不再靜悄悄地直接打開選擇清單。

新功能

瀏覽器子代理錄影改用 Chrome 內建錄製並存成 .mp4

請 /browser 子代理代為操作網頁時，它錄下的工作階段影像現在有了新變化。以前這類瀏覽器操作錄影會存成 .webm 檔，現在則改由 Chrome 內建的螢幕錄影功能進行錄製，直接產出 .mp4 檔案。

彷彿活動側錄換成場地內建的錄影機，交片的格式也跟著換了；原本用一種規格收片，現在改收另一種。

下次你打開 /browser 子代理的工作階段錄影回顧操作過程時，拿到的就會是 .mp4 檔案。

問題修復

修復 HTTP MCP 重新導向時誤傳自訂標頭的安全性問題

替遠端 HTTP MCP（讓 AI 連接外部工具的協定）伺服器設定自訂標頭後，只要對方回傳重新導向就可能出狀況。像 API 金鑰這類自訂標頭先前可能會被轉送給其他主機，現在這項安全性問題已經修好，只會送給原本設定的伺服器來源。

問題修復

忽略異常的終端機視窗尺寸回報避免畫面凍結

操作 CLI（指令列工具）時，程式有時會突然凍結或佔用過多記憶體。這是因為誤傳的逸出字元序列（控制游標或畫面的特殊字元組合）送出了負數或極端龐大的視窗尺寸回報，過去終端機介面會照單全收，現在這些無效回報會被直接忽略。

問題修復

修復 agy acp 登入備援、特殊字元名稱與錯誤回報問題

使用 agy acp 時，過去容易撞上的四個問題現在已經修復。 執行 agy acp --login 後，就算 settings.json 指定了缺少憑證的驗證方式（例如設成 gemini-api-key 卻沒給 GEMINI_API_KEY），工作階段也不會再跳出「Authentication required」失敗，CLI 會改用已儲存的登入資料作為備援。 當 ACP 用戶端傳入名稱含空白或其他特殊字元的 MCP（讓 AI 連接外部工具的協定）伺服器時，送出提示詞不再因此失敗。回合失敗時，現在會回報模型或額度這類具體錯誤，不再只顯示「Agent execution terminated due to error.」。編輯完成後送出的差異比對中，oldText 與 newText 結尾也不再多出一個多餘的換行符號。

問題修復

修妥 UTF-8 BOM 檔頭導致設定與外掛驗證誤判的問題

檔案若在儲存時帶有 UTF-8 BOM（用來標記編碼的隱藏開頭標記），過去常會被錯誤處理。現在包含這三種情況都已修復：首次執行時會正確套用 settings.json 裡的 "modelProvider" 設定；agy acp 也會正常載入你的設定與驗證選項，不再退回使用預設值作為備援。對這類 hooks.json（設定特定事件觸發動作的檔案）執行 agy plugin validate 時，也會跑完所有檢查並回報真正的語法錯誤與行號，不再怪罪到 BOM 頭上。

問題修復

修復搭配遠端代理接續對話時互動提示誤開新串的問題

想在遠端代理接續舊對話並馬上送出一句互動提示時，原本的指令組合卻沒把話接回同一串。過去將 -i（或 --prompt-interactive）搭配 --remote-agent 與 --conversation 或 --continue 使用時，提示詞會誤開成新對話；現在工具會等歷史紀錄載入完成後，再將提示詞送進該段接續的對話。這段提示詞會比照手動輸入的方式處理，因此會立刻顯示在畫面上、排在進行中的回合之後等待，並在傳送失敗時回報錯誤。

問題修復

修復 Windows 平台指令引號、SSH 剪貼簿與排程提示問題

在 Windows 上跑自動化、遠端連線複製內容或執行指令時，這三個容易卡關的毛病已經修好。 使用 ! 執行指令時，PowerShell 不再吃掉雙引號，像 ! git commit -m "two words" 會照原樣執行；離開 CLI 或在任務面板終止工作時，連帶啟動的程式也會一併結束，不會繼續留在背景執行，工作也不會繼續被標示為執行中。 透過 SSH 遠端連線使用 /copy 或其他剪貼簿功能時，複製的內容現在能順利送到你的本機剪貼簿，且不會再被寫進 CLI 的紀錄檔。 Windows 的排程自動化任務不再只讀到多行提示詞的第一行，現在無論是定時排程還是手動觸發執行，都會收到完整的多行提示詞。

問題修復

修正 macOS 反覆彈出鑰匙圈找不到提示框的問題

在 macOS 上使用工具時，過去「Keychain Not Found」視窗大約每小時就會重新跳出一次。現在當鑰匙圈寫入失敗後，CLI 會在該工作階段的剩餘期間改把登入 token（用來驗證身分的授權令牌）存進檔案式儲存空間，不再於每次更新 token 時重複嘗試寫入鑰匙圈。

問題修復

修復 MCP 伺服器與外掛的啟動競爭及登入異常

啟用多個外掛或外部工具並進行帳號驗證時，以下三項連線與登入問題已獲修復。 在多個子代理剛啟動之際重新載入 MCP（讓 AI 連接外部工具的協定）伺服器，過去會因競爭狀態啟動重複的伺服器程序，導致部分子代理的 MCP 工具失效或登入失敗，現在已解決。 在沒有 IPv4 本機迴環位址的機器上進行 MCP 伺服器與外掛的 OAuth 登入時（例如僅支援 IPv6 的虛擬機），過去在 127.0.0.1 無法使用時會無聲失敗，現在登入回呼會改用 [::1] 作為備援。 從 /plugin 登入外掛時，即使登入剛完成，偶爾會錯誤回報登入尚未完成的問題也已修好。

問題修復

修正 Ctrl+O 展開工具群組的排版與摘要顯示

當你按 Ctrl+O 展開工具群組想看細節時，過去群組位置會跟著跳動。現在收合提示會與展開提示維持在同一行，而在低詳細度模式下，token（計費用的文字單位）摘要列也不會再從展開後的畫面消失。

問題修復

修正手機版遠端控制網頁的模型選單捲動故障

拿手機開啟遠端控制網頁想換模型時，過去手指滑動清單卻過不了第一屏，後面的選項怎麼樣都點不到。這個問題已經修好，現在可以觸控捲動超過第一屏，選取清單後段的模型。

English

FEATURE

The run_workflow tool is now available for subagents to run Python workflows

When you have a whole batch of surveys or reports to organize and handling them one by one in a single window is too slow, everyone can now use the run_workflow tool.

Imagine a head chef who used to handle everything from washing vegetables to plating alone, but now delegates chopping, simmering soup, and plating to multiple assistants in parallel or in stages before combining the dishes to serve, with all the kitchenware already included.

When you are organizing large amounts of data or breaking down multi-step tasks with the agent, just ask it to enable run_workflow, and it can run a Python workflow script (an automated program that follows a sequence of steps). This script fans work out to multiple subagents in parallel or in stages, then combines their results. Even if Python is not separately installed on your computer, it can run directly using the Python bundled with the CLI (command-line tool).

FEATURE

Admin settings add pluginControls so non-enterprise teams can manage plugins

Teams that have not adopted Gemini Enterprise previously had a hard time centrally controlling plugins on members' computers.

Think of a school library adjusting its lending rules: a full shutdown seals off even the existing shelves so nothing can be browsed, whereas closing only the new-book acquisition desk lets everyone keep using the books they have already borrowed.

Admins can now add a pluginControls section to managed admin settings and choose between two control switches as needed: pluginsDisabled disables all plugins (including built-in ones) and blocks installing or enabling any plugin. Meanwhile, marketplaceDisabled only turns off the plugin marketplace, so already installed plugins continue working as usual. Gemini Enterprise users still follow their organization's policy set in Cloud Console (Google's web-based admin hub).

PERF

Auto mode switches to direct lookups to speed up out-of-sandbox command reviews

When Auto mode is on and the AI runs commands for you, the review step often made you wait anxiously or even timed out whenever a command was about to leave the terminal sandbox (an isolated security environment for execution).

An editor reviewing a manuscript used to send an official memo to an outside office for every detail they needed to verify, often missing deadlines; now they have the directory and folders right at hand to flip through and decide immediately whether to approve or block it.

Previously, the reviewer had to launch a separate sandboxed command for each check. Now the reviewer can search the conversation, list directories, and search files directly, allowing it to decide faster and time out less often.

FEATURE

Improve /resume loading performance and add short ID and not-found support

Want to pick up yesterday's long conversation where you left off, only to type /resume and see the screen stuck on "Loading conversations..."?

At a large luggage check counter, attendants previously had to open and inventory every locker before letting you pick, causing a bottleneck at the door; now matching just the first few digits of a locker number pulls out the exact item, and an empty number is reported to you right away.

Opening the conversation picker no longer fetches the full history of every open conversation, so it no longer stalls on the loading screen in longer sessions. When specifying a conversation with /resume <id>, any prefix that uniquely matches one conversation (such as the short ID shown in the status line) resumes it directly. If you enter an ID that does not exist, it clearly reports conversation <id> not found instead of silently opening the picker.

FEATURE

Browser subagent recordings now use Chrome built-in capture and save as .mp4

When you ask the /browser subagent to operate web pages for you, its session video recordings have a new update. Previously these browser operation recordings were saved as .webm files, whereas now they are recorded using Chrome's built-in screen recording feature to output .mp4 files directly.

Switching an event shoot to the venue's built-in recorder changes the delivery format too; where footage used to arrive in one specification, it now comes in another.

Next time you open a /browser subagent session recording to review the steps taken, you will get an .mp4 file.

BUGFIX

Fix security issue where HTTP MCP redirects forwarded custom headers

After configuring custom headers for a remote HTTP MCP (a protocol that lets AI connect to external tools) server, returning a redirect could cause trouble. Custom headers like API keys could previously be forwarded to a different host, and this security issue is now fixed so they are sent only to the originally configured server origin.

BUGFIX

Ignore abnormal terminal window-size reports to prevent UI freezes

When using the CLI (command-line tool), the program could sometimes freeze suddenly or consume excessive memory. This happened because stray escape sequences (special character combinations that control the cursor or screen) sent negative or extremely large window-size reports that the terminal UI previously accepted as-is, and these invalid reports are now ignored.

BUGFIX

Fix agy acp login fallback, special-character names, and error reporting

Four issues you could easily run into when using agy acp have now been fixed. After running agy acp --login, even if settings.json specifies an authentication method without a credential (such as gemini-api-key without GEMINI_API_KEY), the session no longer fails with "Authentication required", and the CLI falls back to your saved login. When the ACP client passes an MCP (a protocol that lets AI connect to external tools) server whose name contains spaces or other special characters, sending prompts no longer fails because of it. When a turn fails, it now reports specific errors such as a model or quota error instead of only showing "Agent execution terminated due to error.". In the diffs sent after edits complete, oldText and newText also no longer carry an extra trailing newline.

BUGFIX

Fix UTF-8 BOM headers causing settings and plugin validation misreads

Files saved with a UTF-8 BOM (a hidden leading marker that indicates encoding) were previously often mishandled. Three such cases are now fixed: "modelProvider" in settings.json is properly applied on the first run, and agy acp loads your settings and authentication options normally instead of falling back to defaults. When running agy plugin validate on such a hooks.json (the file that configures actions triggered by specific events), it also runs all checks and reports the real syntax error and line number instead of blaming the BOM.

BUGFIX

Fix interactive prompts starting a new thread when resuming with a remote agent

When you wanted to resume an old conversation with a remote agent and send an interactive prompt right away, the command combination previously failed to attach it to the same thread. Using -i (or --prompt-interactive) together with --remote-agent and --conversation or --continue previously started a new conversation by mistake; now the tool waits for the history to finish loading before sending the prompt into that resumed conversation. The prompt is handled like typed input, so it appears on screen right away, waits behind a running turn, and reports an error if sending fails.

BUGFIX

Fix Windows Command Quotes, SSH Clipboard, and Scheduled Prompt Issues

Three issues that used to trip up running automations, copying over remote connections, or executing commands on Windows are now fixed. When running commands with !, PowerShell no longer drops double quotes, so commands like ! git commit -m "two words" run exactly as typed. Quitting the CLI or killing a task in the tasks panel now also ends the programs it started, so they no longer keep running in the background or leave the task marked as running. When using /copy or other clipboard actions over SSH, the copied content now reaches your local clipboard and is no longer written to the CLI log file. Scheduled automations on Windows no longer read only the first line of a multi-line prompt; both scheduled runs and manually triggered runs now receive the full multi-line prompt.

BUGFIX

Fix Recurring "Keychain Not Found" Dialog on macOS

When using the tool on macOS, the "Keychain Not Found" dialog used to reappear about once an hour. Now, after a keychain write fails, the CLI saves your sign-in token (an authentication credential used to verify your identity) to file-based storage for the rest of the session instead of retrying the keychain on every token refresh.

BUGFIX

Fix MCP Server and Plugin Startup Race and Sign-In Issues

Three connection and sign-in issues when enabling multiple plugins or external tools and authenticating accounts are now fixed. Reloading MCP (the protocol that lets AI connect to external tools) servers while multiple subagents were starting up used to launch duplicate server processes due to a race condition, leaving some subagents with broken MCP tools or failed sign-ins. That issue is now resolved. When performing OAuth sign-in for MCP servers and plugins on machines without an IPv4 loopback address (such as IPv6-only VMs), sign-in used to fail silently when 127.0.0.1 was unavailable; the sign-in callback now falls back to [::1] instead. Signing in to a plugin from /plugin also no longer occasionally reports that sign-in has not finished when it has just succeeded.

BUGFIX

Fix Layout and Summary Display When Expanding Tool Groups with Ctrl+O

When you press Ctrl+O to expand a tool group for details, the group position used to jump around. Now the collapse hint stays on the same line as the expand hint, and in low-verbosity mode the token (the text unit used for billing) summary line no longer disappears from the expanded view.

BUGFIX

Fix Model Selector Scrolling in the Mobile Remote Control Web View

When opening the Remote Control web view on a phone to switch models, swiping the list used to stop at the first screen, making options further down unreachable. This is now fixed, so you can touch-scroll past the first screen and select models near the end of the list.

Fixed the macOS "Keychain Not Found" dialog reappearing about once an hour: after a keychain write fails, the CLI now saves your sign-in token to its file-based storage for the rest of the session instead of retrying the keychain on every token refresh.
Original changelog修復 MCP 伺服器與外掛的啟動競爭及登入異常
Fixed a race where reloading MCP servers while several subagents were starting could launch duplicate MCP server processes, leaving some subagents with broken MCP tools or failed sign-ins.
Fixed MCP server and plugin OAuth sign-in on machines without an IPv4 loopback address, such as IPv6-only VMs; the sign-in callback now falls back to `[::1]` when `127.0.0.1` is unavailable instead of failing silently.
Fixed signing in to a plugin from `/plugin` sometimes reporting that the sign-in didn't finish when it had just succeeded.
Original changelog修正 Ctrl+O 展開工具群組的排版與摘要顯示
Fixed tool groups jumping around when expanded with `Ctrl+O`: the collapse hint now stays on the same line as the expand hint, and in low verbosity the token summary line no longer disappears from the expanded view.
Original changelog修正手機版遠端控制網頁的模型選單捲動故障
Fixed the model selector in the Remote Control browser view on phones, where the list could not be scrolled by touch past the first screen, so models near the end of the list could not be selected.
