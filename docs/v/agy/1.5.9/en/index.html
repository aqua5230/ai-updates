Antigravity 1.5.9

Released: 2026-11-14

Release notes

FEATURE

Added run_workflow to dispatch multi-agent workflows

When you had a stack of meeting notes to summarize, categorize, and compile into a master table, you used to watch the screen and give commands step by step. Now everyone can use the run_workflow tool to have the agent run a Python workflow script directly. It splits tasks across multiple subagents (helpers that divide up the work) in parallel or in stages, then combines the results. It still runs even if Python is not installed on your computer, because the tool uses the version bundled with the CLI (text-based command interface).

Before, you had to carry a broom from the living room to the balcony all by yourself; now a class monitor posts a chore chart, sends classmates to wipe windows and mop floors at the same time, and waits for the floor to dry before having the next group arrange the desks and chairs.
FEATURE

Added pluginControls to admin settings for plugin management

For companies that have not purchased Gemini Enterprise, admins previously had no way to manage plugins centrally. Now admin settings include a pluginControls section with plugin controls. pluginsDisabled not only blocks installing or enabling plugins, it also stops built-in plugins from loading. marketplaceDisabled turns off the plugin marketplace while keeping already installed plugins working. Organizations already using Gemini Enterprise continue to follow their own Cloud Console policies without any change.

Without the enterprise platform, you had to let everyone install plugins on their own; now it is like removing new shelves in a store so nothing more can go on display, or pulling the main power breaker for the whole shop so even the built-in equipment stops running.
PERF

Faster Auto mode review with fewer timeouts for cross-sandbox commands

When turning on Auto mode to run commands that might step outside the terminal sandbox (an isolated safety zone that restricts what programs can do), you often had to wait a long time for a review result, or even see it fail. Now the reviewer can directly search the conversation, list folders, and search files instead of starting a separate isolated command for each check, so decisions are faster and less likely to time out.

Picture checking records in a cleanroom: before, you had to put on a full protective suit and go inside for every single detail, which easily timed out; now you can flip through the logs right at the door and approve it.
FEATURE

Faster /resume loading and unique prefix matching for conversations

When using /resume to pick up an old conversation in a long session, the picker used to fetch the full history of every open conversation and often stalled on Loading conversations.... Now the list no longer fetches all history upfront, so opening it is much smoother. When typing /resume <id> directly, as long as the prefix you enter matches just one conversation (such as the short ID shown in the status line), it jumps straight there. If you enter an ID that cannot be found, it now clearly reports conversation <id> not found instead of silently opening the picker.

Like looking someone up in an address book, before you had to haul every contact's complete file onto the desk just to pick one; now a simple list lets you choose, and typing the first few characters jumps straight to a match.
FEATURE

/browser session recordings now save as .mp4 files

When asking the browser subagent to operate web pages with /browser and record the session, the saved file format used to be .webm. Now it records through Chrome's built-in screen recording feature, and the saved file format is .mp4 instead.

BUGFIX

Patched HTTP MCP redirect leak of custom headers

For an HTTP-connected MCP (a protocol that lets AI connect to external tools) server, you can configure custom headers such as API keys. Previously, whenever that server returned a redirect, those headers could be forwarded along to another host. That security issue is now fixed, so custom headers are sent only to the server origin you originally configured and will not be forwarded to other hosts.

Think of visiting a partner shop with a sealed envelope containing a secret phrase: before, if a note on the door told you to go to another shop instead, you handed the secret letter to the new address; now only the shop you originally arranged with can receive it.
BUGFIX

Terminal no longer accepts implausible window sizes that cause freezes

The terminal occasionally receives negative or extremely large width and height numbers from stray escape sequences, which used to make the CLI freeze on the spot or use excessive memory. This issue is now fixed, and malformed or implausible size reports are ignored.

BUGFIX

Fixed agy acp login fallback, error reporting, and related issues

After running agy acp --login, if the authentication method specified in settings.json has no matching credential, the session used to fail with Authentication required. For example, when gemini-api-key is set without GEMINI_API_KEY, the CLI now falls back to your saved login instead of failing right away. Prompts now run normally instead of failing when an ACP client passes an MCP server name containing spaces or other special characters. When a turn fails, instead of showing only the generic Agent execution terminated due to error., it now reports the specific reason, such as a model or quota error. For developers integrating ACP clients, diffs sent after edits are completed no longer include an extra trailing newline in the before and after text.

BUGFIX

Config and auth files with UTF-8 BOM markers no longer fail

Some files are saved with a UTF-8 BOM (a hidden encoding marker) at the beginning, which used to cause read errors, and several major issues with this are now fixed. When "modelProvider" is written in settings.json, it is now applied on the first run. agy acp also loads your settings and authentication options properly instead of falling back to defaults. When checking a hooks.json with this marker using agy plugin validate, it now runs all checks and points out the actual syntax error and line number instead of blaming the BOM.

BUGFIX

Fixed resuming remote conversations with -i prompts

When resuming a conversation from the command line with --remote-agent together with --conversation or --continue, adding an interactive prompt flag used to cause an error. Passing -i or --prompt-interactive at the same time would unexpectedly start a new conversation instead of sending the prompt into the old one. This is now fixed: it waits for the old conversation history to finish loading before sending the prompt into that conversation. The prompt also appears on screen right away like typed input, queues up if the previous turn is still running, and reports if sending fails.

BUGFIX

Windows `!` Commands Keep Quotes and Close Child Programs

When running shell commands with ! on Windows, PowerShell used to strip double quotes, so commands like ! git commit -m "two words" could not run as typed. Double quotes are now preserved, so commands run exactly as entered. When killing a task in the tasks panel or quitting the CLI directly, programs started by ! used to stay running in the background while the task remained marked as running. Closing the CLI or stopping the task now ends those started programs as well instead of leaving them running.

BUGFIX

Windows /copy over SSH Now Copies to Local Clipboard

When running the CLI on Windows over an SSH connection and using /copy or other clipboard actions, copied text used to fail to reach your local clipboard. That text was also written into the CLI log file. This is now fixed, so copied content goes to your local clipboard as expected and is no longer written to the log file.

BUGFIX

Fix Missing Multi-Line Prompts in Windows Scheduled Automations

When running tasks on a schedule on Windows, multi-line prompts used to deliver only the first line when executed. This is now fixed, so every run receives the full prompt whether it runs on schedule or is triggered manually.

BUGFIX

macOS No Longer Repeats Keychain Error Dialogs Hourly

For Mac users whose system keychain write fails, a Keychain Not Found dialog used to pop up about once an hour. This happened because the CLI retried writing to the keychain every time it refreshed the sign-in token (an authorization credential for verifying identity). This is now fixed: once a write fails, the CLI saves sign-in data to a file for the rest of the session instead of retrying the keychain.

BUGFIX

MCP and Plugin Startup and Sign-In No Longer Fail Unexpectedly

Connecting to MCP servers or signing in to plugins used to stall midway in a few situations. If MCP servers were reloaded just as several subagents were starting, duplicate server processes could accidentally launch, breaking tools or causing sign-ins to fail for some subagents. This is now fixed, so reloading servers no longer spawns duplicate processes. On machines without an IPv4 loopback address, such as IPv6-only VMs, running OAuth (a web-redirect authorization sign-in flow) for MCP or plugins used to fail silently. Now, whenever 127.0.0.1 is unreachable, the sign-in callback URL automatically falls back to [::1]. When signing in to a plugin account from /plugin, the screen sometimes wrongly reported that sign-in had not finished even though it had succeeded; it now accurately reflects the completed status.

BUGFIX

Expanding Tool Groups with Ctrl+O No Longer Jumps or Drops Summaries

Pressing Ctrl+O to expand tool groups on screen used to cause the interface to jump up and down. This is now fixed: the collapse hint stays on the same line as the expand hint, so the view no longer shifts when expanded. In low verbosity mode, the expanded view used to drop the token (the unit used to measure text usage) summary line, which now appears as well.

BUGFIX

Fix Touch Scrolling in Phone Remote Control Model Selector

When using a phone browser for Remote Control and trying to pick a different option, scrolling used to get stuck after the first screen of the list, making items further down impossible to tap. This is now fixed, so you can scroll down smoothly by touch in the Remote Control web view and select models near the end of the list.
