Antigravity 1.1.1

發布日期：2026-07-08 ~ 07-11

繁體中文

預設改成「寫檔前先給你過目」：逐行看差異、想留哪段自己挑

Antigravity 動你的檔案之前，現在預設會先停下來給你過目。新的 request-review 模式（顧名思義「請求審核」——動你的檔案前先請你過目）在每次寫檔前攤開逐行差異預覽（diff preview，把改前改後逐行並排、標紅標綠的對照畫面，按 f 開啟），你可以整批接受，也可以一段留一段丟；連新建檔案都有專屬的「Create file」預覽，讓你先看內容再點頭。就像裁縫改衣服前先讓你試穿別上珠針的版本，滿意哪段留哪段，而不是改完才給你看成品。

shift+tab 循環三種執行模式，/plan 取代 /planning

執行模式切換正式開放：按 shift+tab 就能在 default（每次寫檔先問）、accept-edits（放行編輯）、plan（只規劃不動手）三檔之間循環。指令也整併了——/plan 取代舊的 /planning、/fast 直接移除，切換方式收斂成一套，不再多頭馬車。就像檯燈從三顆分開的開關變成一顆旋鈕，轉一下換一檔。

預設模式進 /settings 面板，改完立刻生效

想固定用某個執行模式，現在到 /settings 面板挑 Agent Mode 就好，改完即時生效，不用再手動編輯 settings.json（設定檔）、也不用每次啟動都掛 --mode 參數。就像冷氣終於有了遙控器上的「預設模式」鈕，不必每次開機都爬去主機上按。

啟動就能指定要用哪個自訂代理

啟動時就能指定要用哪個自訂代理（custom agent，你事先寫好個性與專長的分身）：掛上 --agent 旗標直接點名，agent／agents 子指令還能列出手上有哪些分身可挑。以前得先進門再換人，現在像叫車 App 直接指定司機，上車前就選好。

成果檢視器能按 / 搜尋、n/N 跳轉了

在成果檢視器（artifact viewer，看代理產出的檔案或報告的畫面）裡按 / 就能就地搜尋關鍵字，n 跳下一個、N 跳上一個，長報告不用再用眼睛慢慢掃。就像看紙本說明書終於改成看 PDF，Ctrl+F 一按直達你要的那行。

腳本派工救星：-p 失敗會老實報錯，也不再卡住不動

用腳本呼叫 agy 的人這條最有感：print 模式（--print／-p，不開介面、印完答案就走的無頭用法）以前伺服器端失敗時會裝沒事——回傳成功代碼、輸出空白，害你的腳本以為任務完成了；現在錯誤會寫進 stderr（標準錯誤輸出，專門裝錯誤訊息的通道）並回傳非零代碼。另外在 shell 腳本或子程序裡跑 agy -p 會卡住等輸入的毛病也修了。就像外送員以前送失敗會默默把空袋子掛你門口，現在會確實打電話告訴你「餐沒送到」。

放行過的寫檔不再重複問

你在 settings.json 的 permission.allow 允許清單（事先放行的白名單）裡核准過的寫檔動作，預設模式現在會直接放行，不再每次都跳審查。就像機場的常客快速通關——身家早就查核過的人，不必每趟都重新排安檢。

介面細節總打磨：差異預覽、快捷鍵提示、表格對齊都變順眼

這輪順手把一圈介面細節磨亮了：檔案編輯的差異預覽補上前後文和分段線更好讀；各面板頁尾的快捷鍵提示會尊重你自訂的鍵位、不再寫死；/resume 選單裡重新命名對話的輸入框不再把長標題吃掉；聊天輸出裡帶檔案連結的 Markdown 表格也不再歪掉。像車子進廠保養——沒換引擎，但每個按鈕都變順手了。

English

New default: Antigravity pauses before writing files and shows a line-level diff

Before Antigravity touches your files, it now pauses by default and shows its work. The new request-review mode spreads out a line-level diff preview before every write (a view marking removals red and additions green line by line, opened with f), letting you accept the whole batch or keep some chunks and toss others; even brand-new files get their own "Create file" preview so you approve the content first. Like a tailor pinning the alterations and letting you try them on before sewing, instead of showing you the finished jacket.

Cycle execution modes with shift+tab; /plan replaces /planning

Execution-mode switching is now public: shift+tab cycles through default (ask before each write), accept-edits (edits sail through), and plan (plan only, hands off). Commands got consolidated too — /plan replaces the old /planning and /fast is removed, folding mode switching into one coherent set. Like a lamp trading three scattered switches for a single knob you click through.

Set your default execution mode right in /settings

To make one execution mode your default, just pick Agent Mode in the /settings panel — it takes effect immediately, with no more hand-editing settings.json (the config file) and no more passing --mode at every launch. Like an air conditioner finally getting a "default mode" button on the remote, so you stop climbing up to the unit each time.

Pick a custom agent right at launch with --agent

You can now pick a custom agent (a persona you've pre-written with its own skills and style) right at launch: name it with the --agent flag, and the agent/agents subcommands list which personas you have. You used to have to walk in first and swap afterwards; now it's like a ride-hailing app that lets you choose the driver before getting in.

Search inside artifacts with / and hop between matches with n/N

In the artifact viewer (the screen for reading files and reports an agent produced), press / to search for a keyword in place, then n and N to hop between matches — no more eyeball-scanning long reports. Like trading a paper manual for a PDF where one Ctrl+F jumps straight to the line you need.

Script users rejoice: -p now reports failures honestly and never hangs

If you call agy from scripts, this is your fix: print mode (--print / -p, the headless usage that prints an answer and exits) used to play innocent when a request failed server-side — exiting with a success code and empty output, so your script believed the job was done; failures now go to stderr (the standard error stream, the channel reserved for error messages) with a non-zero exit code. The bug where agy -p hung waiting for input inside shell scripts and subprocesses is fixed too. Like a delivery courier who used to silently hang an empty bag on your door after a failed run — now they actually call to say the food didn't make it.

Pre-approved file writes skip the review prompt

File writes you've already allowlisted under permission.allow in settings.json (the pre-approved whitelist) now sail through in default mode instead of prompting for review every time. Like an airport trusted-traveler lane — once you've been vetted, you don't re-queue for screening on every trip.

A round of UI polish: diff previews, keybinding hints, and table alignment

A lap of interface polish landed this round: file-edit diff previews gain context lines and section separators for easier reading; footer keybinding hints across panels now respect your customized keys instead of showing hardcoded ones; the rename box in the /resume picker stops swallowing long titles; and Markdown tables with file links in chat output stop skewing. Like a car service visit — same engine, but every knob feels smoother.
