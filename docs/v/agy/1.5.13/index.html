Antigravity 1.5.13

發布日期：2026-11-20

繁體中文

新功能

模型清單新增 Gemini 4 Neon

想改用新模型處理手邊的開發或資料整理工作，現在只要透過 AGY_ADC_AUTH 應用程式預設憑證登入，就能在指令裡選到它。在對話輸入 /model，或於啟動時帶上 --model，裡面多了 Gemini 4 Neon 的 Low、Medium、High 與 XHigh 四個選項。公司有架設企業模型閘道（集中控管連線的模型入口）的話，透過閘道也已支援 Gemini 4 Neon。

就像工具箱裡新添了一把四段力道的電鑽，不論用個人識別證或走公司統一入口，都能直接拿來上工。
新功能

Markdown 表格拖曳複製只取選定欄位

從 AI 生成的表格複製一欄文字，以前常把框線跟旁邊那欄的字一併帶進剪貼簿。這個改動套用在 full screen (altscreen) 顯示模式，以及用來瀏覽生成結果的產物檢視器。 只要滑鼠從 Markdown 表格內開始拖曳，選取範圍就會沿著欄位走。只在單一欄內拖曳，就只會複製那一欄的文字；跨欄拖曳時，則會複製完整儲存格並以 Tab 字元隔開，不再帶入框線或隔壁欄的字。

抄寫藥盒背面那張成分表時，以前手指一滑就會連格線和隔壁欄一起念錯行，現在視線會穩穩鎖在你要的那幾欄上。
新功能

代理合併執行多步驟任務以減少輪數

交辦一個包含搜尋、讀寫檔案和下指令的任務，過去代理常拆成多輪分次處理。現在遇到這類多步驟任務，它會把彼此獨立的搜尋、讀檔與編輯集中到同一步驟一起執行，並將相關的終端機指令串成單一指令，因此能用更少的輪數完成任務。

跟進廚房備料一樣，以前洗一根蔥走一趟流理台、拿瓶醬油又走一趟，現在把互不衝突的備菜一次做好，相連的動作順手串起來，出餐就少繞好多彎。
問題修復

自訂模型不再忽略 settings.json 停用旗標

接上自己設定的模型卻老是收到思考或工具呼叫請求，以前就算把功能關掉也照送不誤。這個問題已經修好，現在只要在 settings.json 的 modelFeatures 把 supportsThinking 或 supportsToolCalls 設為 false，CLI 就不會再向不支援的模型要求這些功能。

問題修復

代理不再擅自開啟 swarm 消耗額度

沒輸入 /swarm 的情況下，以前代理有時會擅自啟動 swarm（多代理協作模式），消耗比單一代理多出許多的額度。這個問題已經修好，目前不會再將 swarm 技能提供給代理主動呼叫，而你手動輸入 /swarm 依然跟以前一樣能正常使用。

問題修復

非 QWERTY 鍵盤快捷鍵改依配置對應

習慣用非標準 QWERTY 鍵盤在 Ghostty 等終端機打字，以前按 Ctrl 或 Alt 快捷鍵常會誤觸別的鍵。這個問題已經修好，無論 Neo2、Dvorak、AZERTY 或德文 QWERTZ 配置，Ctrl+C、Ctrl+D 等組合鍵現在都會依實際鍵盤配置運作。

問題修復

Vim 模式在驚嘆號模式執行命令不再只換行

開著 Vim 操作、打 ! 進終端機下指令，過去打完按 Enter 卻只會往下多空一行，指令送不出去。這個問題已經修好，現在於相同模式下按 Enter 就會直接執行指令。

問題修復

Termux 執行 agy update 不再失敗

跑 agy update 更新工具，Android 的 Termux 環境過去總是失敗。畫面上會跳出 directory /apex/com.android.runtime/bin is not fully accessible 錯誤。這個問題已經修好，現在在 Termux 執行這項指令不會再出現這個錯誤。

問題修復

/config 的 Send Immediately 提示更正

代理還在跑的時候想先插話傳訊息，以前看設定畫面的說明會以為送出就會直接打斷目前工作。這項說明現在已經更正，在 /config 的 Queued Messages 底下查看 Send Immediately 選項，會清楚寫明你的訊息會加入目前這輪對話，代理跑完眼前的這一步後就會讀到。

問題修復

JSON 輸出重試成功後改回報 SUCCESS

用 --output-format json 或 stream-json 讀取結果，過去只要中途重試過模型請求，就算最後成功，status 仍會顯示 ERROR 並夾帶舊錯誤。這個問題已經修好，現在只要 CLI 重試後完成執行，結果的 status 就會正確寫成 SUCCESS。

問題修復

外部編輯器連 agy acp 的操作與顯示修正

透過 agy acp 把 Zed 或 JetBrains AI Chat 這類編輯器連上 Antigravity，現在檔案路徑、選單與訊息呈現都照實運作。 代理執行終端機指令的目錄以前會誤用編輯器啟動時的位置，例如家目錄；現在改回在該工作階段的專案資料夾執行。 在 Zed 等編輯器附上還沒存檔的內容給代理時，以前代理只看得到硬碟上舊的存檔；現在能直接讀取編輯器傳來的最新內容。 接上企業模型閘道時，編輯器模型選單過去會出現內部 MODEL_PLACEHOLDER_... 代號與重複名稱；現在每個模型只依代號列一次，同名模型旁也會標出代號。 模型請求重試時，編輯器聊天室以前每次都會跳出 API error (attempt N)，連後來成功也不例外。現在重試過程比照終端機保持安靜，只有全部重試都失敗時才顯示錯誤。

問題修復

/antigravity-guide 不再讀成轉址頁

問代理最新版本有什麼新東西，讓它透過內建 /antigravity-guide 技能查官方文件或更新紀錄時，過去只會讀到轉址通知，讀不到實際頁面。這個問題已經修好，現在能讀到頁面內容來回答問題。

問題修復

遠端控制網頁回答權限提示不再跳位或重置

在遠端控制網頁替代理批核請求，以前送出回答後畫面常會跑掉，網路微斷一下還得重填。 回答完權限提示後，過去對話畫面會隨著提示框關閉往下滑動，打亂原本的閱讀位置；現在對話會停在你正在看的段落。 若遇到短暫斷線，權限提示原本會整個重置，導致你挑好的選項、修改過的指令或路徑，以及在 No 欄位輸入的文字全部遺失；現在這些內容都會保留下來。

English

FEATURE

Gemini 4 Neon added to model list

If you want to switch to a new model for your development or data-wrangling work, you can now select it in commands as long as you sign in with Application Default Credentials (AGY_ADC_AUTH). Enter /model in a conversation or pass --model at startup to see four new options for Gemini 4 Neon: Low, Medium, High, and XHigh. If your company runs an enterprise model gateway (a central entry point that controls model connections), Gemini 4 Neon is supported through it as well.

Picture adding a four-speed power drill to your toolbox: whether you badge in with your own ID or walk through the company gate, you can pick it up and get right to work.
FEATURE

Markdown table drag-copy selects only chosen columns

Copying a column of text from an AI-generated table used to pull borders and words from the neighboring column into your clipboard. This change applies to the full screen (altscreen) rendering mode and the artifact viewer used to browse generated results. Whenever a mouse drag starts inside a Markdown table, the selection now follows its columns. Dragging within a single column copies only the text in that column; dragging across columns copies whole cells separated by tabs, without bringing in borders or text from adjacent columns.

Think of reading an ingredients chart on the back of a medicine box: a slip of your finger used to drag your eyes across grid lines into the wrong column, whereas now your gaze stays locked onto the columns you want.
FEATURE

Agent batches multi-step tasks to take fewer turns

When given a task involving searches, file reads and writes, and shell commands, the agent used to split the work across multiple turns. Now, on multi-step tasks like these, it runs independent searches, file reads, and edits together in a single step and chains related shell commands into one command, completing the task in fewer turns.

A cook prepping ingredients in a kitchen used to walk to the sink to wash one scallion and make another trip just for soy sauce; now all non-conflicting prep happens at once and connected steps are chained together, cutting out wasted trips before plating.
BUGFIX

Custom models no longer ignore disabled flags in settings.json

Connecting a custom model used to still trigger thinking or tool-call requests even when those features were turned off. This issue is fixed: setting supportsThinking or supportsToolCalls to false under modelFeatures in settings.json now stops the CLI from requesting those features from models that do not support them.

BUGFIX

Agents no longer start swarm on their own and burn quota

Even without typing /swarm, agents used to occasionally launch swarm (multi-agent collaboration mode) on their own and use far more quota than a single agent. This issue is fixed: the swarm skill is no longer offered to the agent to invoke proactively, while typing /swarm manually still works as before.

BUGFIX

Shortcuts on non-QWERTY keyboards now follow your layout

If you type on a non-QWERTY keyboard in terminals like Ghostty, pressing Ctrl or Alt shortcuts used to register as a different key. This issue is fixed: across Neo2, Dvorak, AZERTY, and German QWERTZ layouts, shortcuts like Ctrl+C and Ctrl+D now follow your active keyboard layout.

BUGFIX

Enter in Vim `!` shell mode now runs commands instead of adding a newline

When Vim mode was on and you typed ! to enter shell mode and run a command, pressing Enter used to just insert a blank line instead of submitting it. This issue is fixed: pressing Enter in that mode now runs the command directly.

BUGFIX

agy update no longer fails in Termux

Running agy update to update the tool used to fail in Android's Termux environment with a directory /apex/com.android.runtime/bin is not fully accessible error. This issue is fixed, and running the command in Termux no longer triggers that error.

BUGFIX

Corrected Send Immediately hint in /config

When you wanted to send a message while the agent was still running, the hint on the settings screen used to make it sound like sending would interrupt the current work right away. That hint is now corrected: under Queued Messages in /config, the Send Immediately option clearly states that your message joins the current turn and the agent reads it after finishing its current step.

BUGFIX

JSON output now reports SUCCESS after a retried request succeeds

When reading output with --output-format json or stream-json, any run that had retried a model request along the way used to still report status as ERROR along with the stale error, even if it ultimately succeeded. This issue is fixed: once the CLI completes a run after a retry, the result's status is now accurately reported as SUCCESS.

BUGFIX

Operation and display fixes for external editors connected via agy acp

When you connect editors like Zed or JetBrains AI Chat to Antigravity via agy acp, file paths, menus, and messages now work as expected. Previously, the agent ran terminal commands in the directory the editor launched from, such as your home directory; it now runs them in the session's project folder instead. When attaching unsaved content to the agent in editors like Zed, the agent previously only saw the older saved version on disk; it can now read the latest content sent by the editor directly. When connected to an enterprise model gateway, the editor's model picker previously showed internal MODEL_PLACEHOLDER_... IDs and duplicate names; each model is now listed once by its ID, and models sharing a name show their ID next to it. When a model request was retried, the editor's chat previously displayed API error (attempt N) every time, even if the retry later succeeded. Retries are now silent, just like in the terminal, and an error is shown only when all retries fail.

BUGFIX

/antigravity-guide no longer reads a redirect page

When you asked the agent what's new in the latest release and it used the built-in /antigravity-guide skill to check the official docs or changelog, it previously read only a redirect notice instead of the actual page. This has been fixed, and it can now read the page content to answer your questions.

BUGFIX

Remote Control web view no longer jumps or resets when answering permission prompts

When approving requests for the agent in the Remote Control web view, the view previously often jumped after you submitted an answer, and a brief network drop forced you to fill it out again. After answering a permission prompt, the conversation view previously slid down as the prompt closed, disrupting your reading position; the conversation now stays on the section you are reading. If a brief disconnection occurred, the permission prompt previously reset completely, losing the option you picked, your edits to the command or path, and any text typed into the No field; all of these are now preserved.
