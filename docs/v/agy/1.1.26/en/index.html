Antigravity 1.1.26

Released: 2026-09-04

Release notes

FEATURE

Artifact viewer adds half-page scrolling, clearer terminal Mermaid flowcharts

Reading long architecture documents or analysis reports generated by AI is now smoother with clearer diagrams.

Like flipping through a long sheet music score in a terminal where you previously had to scroll line by line, you can now turn half a page with a single keypress, while process arrows and structural symbols stay neatly aligned.

The artifact viewer (a browsing window for inspecting standalone files generated by AI) now supports pressing Ctrl+D to scroll down half a page and Ctrl+U to scroll up half a page. Meanwhile, when rendering Mermaid flowcharts in conversation history and the artifact viewer, the system improves terminal ASCII plain-text diagram layouts, making box nodes and connecting lines cleaner and easier to read.

FEATURE

`/resume` adds `pickerGrouping` setting to customize default conversation list view

When using /resume to pick past conversations, you can now lock in a default list view based on personal preference.

Like setting your weather app's default city to Taipei so opening the app immediately shows Taipei's weather without having to reselect, switching to grouping by region or showing all cities flat requires just one setting tweak and applies automatically thereafter.

The system adds the pickerGrouping setting to the /config command and settings.json configuration file. You can configure it to group by workspace or display a flat list, ensuring the conversation picker opens in your preferred layout:

{
  "pickerGrouping": "workspace"
}

It can be set to workspace or flat in the configuration file.

FEATURE

Unselected model families in `/model` picker now default to medium reasoning effort instead of low

When selecting models via /model in the terminal, model families without an explicitly specified thinking depth now proactively invest more reasoning effort.

Previously, when switching models in the interactive picker, models without extra configuration defaulted to low reasoning effort. The default level has now been updated to medium reasoning effort, enabling models to perform more thorough reasoning when writing code or analyzing architecture.

Like changing an electric fan's default speed from low to medium—powering it on immediately runs at medium speed without needing to manually toggle up to your preferred setting every time.
BUGFIX

Subagents stay fully automated without stopping when opening details panel in always-proceed mode

Checking live progress while letting subagents work autonomously no longer unexpectedly interrupts automated workflows.

When running in always-proceed mode (an automatic execution mode that approves tool usage without prompting for each one), opening the subagent details panel previously caused subagent tasks running smoothly in the background to suddenly pop up tool approval prompts, halting continuous operations. This issue has now been resolved, so subagents continue running fully automatically when opening or viewing the details panel.

Like watching a car wash's progress through a transparent observation window, where the robotic arms do not suddenly brake and demand manual confirmation just because someone is looking through the glass.
BUGFIX

Terminating subagents and deleting conversations now cleans up orphaned Git worktrees to free disk space

Ending multi-agent collaboration or cleaning up old conversations no longer silently accumulates temporary folders on disk.

Like a workshop automatically dismantling and clearing out temporary parallel workstations when apprentices pack up or projects wrap up, preventing discarded frames from piling up in warehouse corners.

When calling subagents for parallel execution, the system creates worktrees (a Git feature that creates multiple parallel copies of the same project) under the .system_generated/worktrees directory. Previously, when forcefully terminating subagents or deleting conversation history, these temporary worktrees were often not fully removed, leaving behind orphaned lingering files. The cleanup mechanism is now fixed to reliably remove them upon completion and reclaim disk space.

FEATURE

Faster `/logout`, metadata flushed to disk on exit, and spurious logs eliminated for temporary directories

Underlying state handling and persistence mechanisms have received a batch of enhancements during account logout, command exits, and customization loading.

When logging out via /logout, if the system keyring is bypassed or unreachable, the system now short-circuits token removal directly to file storage, speeding up logout execution. When exiting the command-line interface, the system fixes SQLite database WAL checkpointing to ensure trailing session metadata is fully flushed to disk before shutdown. Furthermore, customization discovery no longer logs spurious errors when accessing temporary directories or paths outside the active workspace.

Like backstage wrap-up after a theater show ends: staff first register props into storage, verify the lighting control system is fully reset and saved, and finally lock the gates without accidentally triggering alarms for public corridors outside the backstage area.
