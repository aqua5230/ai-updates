發布日期：2026-09-04

zh-TW

產物檢視器支援快速翻半頁，Mermaid 流程圖終端圖表更清晰

閱讀 AI 產出的長篇架構文件或分析報告時，畫面瀏覽與圖表呈現變得更加流暢。猶如在終端機裡翻閱長篇樂譜，以前只能一行行微調捲動，現在輕按按鍵就能一次翻過半面樂譜，頁面上的流程箭頭與架構符號也排版得井然有序。在產物檢視器（artifact viewer，檢視 AI 產生之獨立檔案的瀏覽視窗）中，現在支援按下 Ctrl+D 向下翻動半頁與 Ctrl+U 向上翻動半頁。同時，在對話紀錄與產物檢視器裡繪製 Mermaid 流程圖時，系統改進了終端機 ASCII 純文字圖表的渲染排版，讓方塊節點與連線更整齊易讀。

`/resume` 新增 `pickerGrouping` 設定，自由指定歷史對話預設檢視

每次使用 /resume 挑選歷史對話時，現在可以依照個人偏好鎖定預設的呈現清單。就像在氣象 App 裡把預設城市鎖定成台北——每次開啟就直接顯示台北的天氣頁面，不必重選；要切換成依地區分組或平鋪全部城市，只要調一次設定，日後開啟自動套用。系統在 /config 指令與 settings.json 設定檔中新增了 pickerGrouping 設定項目。你可以將其設定為依工作區分組或是平鋪清單（flat），讓對話挑選介面一開啟就呈現你習慣的版面結構：

{
  "pickerGrouping": "workspace"
}

可在設定檔中指定為 workspace 或 flat。

`/model` 選單未指定模型預設思考力度，由低檔提升為中檔

在終端機使用 /model 挑選模型時，未特別手動指定思考深度的模型家族現在會主動投入更多推理思考。過去在互動式選單中切換模型時，未經額外設定的模型預設會採用 low（低推理努力程度）。現在預設檔位全面調整為 medium（中等推理努力程度），讓模型在處理程式碼或分析架構時進行更周全的推導。就像把電風扇的預設風速從低速換成中速——插上電一啟動就直接在中速運轉，不必每次手動往上撥到慣用的檔位。

子代理全自動執行不再誤停，開啟詳細面板不跳授權詢問

放手讓子代理獨立執行任務時，查看即時進度不再意外打斷自動化流程。在啟用 always-proceed（一律放行，不逐一詢問工具授權的自動執行模式）的狀態下，過去使用者只要切換開啟子代理詳細資訊面板，原本在背景順暢運作的子代理任務會突然跳出工具執行確認視窗，中斷原本的連續作業。這項問題已經修復，現在開啟或瀏覽詳細面板時，子代理會維持全自動推進。這好比在全自動洗車機旁透過透明觀景窗查看清洗進度，機械手臂不會因為有人在窗外觀看就突然煞車要求手動確認。

終止子代理與刪除對話自動清除孤立工作樹，釋放磁碟空間

結束多代理協作或清理舊對話時，硬碟不再默默累積暫存資料夾。如同工坊在學徒收工或專案結案時，自動將臨時搭建的平行副工作台拆卸清理，不再讓廢棄支架堆滿倉庫角落。系統在呼叫子代理進行平行作業時，會於 .system_generated/worktrees 目錄下建立 worktree（Git 讓同一專案平行開多份副本的功能）。過去在強制終止子代理或刪除歷史對話時，這些臨時工作樹常未被完全移除而變成孤立殘留檔案。現在清理機制已修正，會在結束時確實移除並釋放磁碟空間。

改善登出速度並落盤中繼資料，排除暫存目錄虛假日誌

在登出帳號、結束指令與載入自訂設定時，底層的狀態處理與儲存機制進行了一批強化。使用 /logout 登出時，若系統金鑰圈被繞過或無法連線，系統會直接捷徑刪除檔案中的 token（授權令牌），縮短登出耗費的時間。在離開命令列介面時，系統修復了 SQLite 資料庫的預寫日誌檢查點機制，確保關閉前將最後的工作階段中繼資料完整寫入硬碟。此外，自訂功能探索機制在存取暫存目錄或工作區以外的路徑時，也不會再印出多餘的虛假錯誤日誌。猶如劇院散場後的後台收尾：工作人員先把道具登記入庫，再確認燈控系統完整歸零存檔，最後閘門落鎖，不再對後台外的公共走廊誤觸警報。

en

Artifact viewer adds half-page scrolling, clearer terminal Mermaid flowcharts

Reading long architecture documents or analysis reports generated by AI is now smoother with clearer diagrams. Like flipping through a long sheet music score in a terminal where you previously had to scroll line by line, you can now turn half a page with a single keypress, while process arrows and structural symbols stay neatly aligned. The artifact viewer (a browsing window for inspecting standalone files generated by AI) now supports pressing Ctrl+D to scroll down half a page and Ctrl+U to scroll up half a page. Meanwhile, when rendering Mermaid flowcharts in conversation history and the artifact viewer, the system improves terminal ASCII plain-text diagram layouts, making box nodes and connecting lines cleaner and easier to read.

`/resume` adds `pickerGrouping` setting to customize default conversation list view

When using /resume to pick past conversations, you can now lock in a default list view based on personal preference. Like setting your weather app's default city to Taipei so opening the app immediately shows Taipei's weather without having to reselect, switching to grouping by region or showing all cities flat requires just one setting tweak and applies automatically thereafter. The system adds the pickerGrouping setting to the /config command and settings.json configuration file. You can configure it to group by workspace or display a flat list, ensuring the conversation picker opens in your preferred layout:

{
  "pickerGrouping": "workspace"
}

It can be set to workspace or flat in the configuration file.

Unselected model families in `/model` picker now default to medium reasoning effort instead of low

When selecting models via /model in the terminal, model families without an explicitly specified thinking depth now proactively invest more reasoning effort. Previously, when switching models in the interactive picker, models without extra configuration defaulted to low reasoning effort. The default level has now been updated to medium reasoning effort, enabling models to perform more thorough reasoning when writing code or analyzing architecture. Like changing an electric fan's default speed from low to medium—powering it on immediately runs at medium speed without needing to manually toggle up to your preferred setting every time.

Subagents stay fully automated without stopping when opening details panel in always-proceed mode

Checking live progress while letting subagents work autonomously no longer unexpectedly interrupts automated workflows. When running in always-proceed mode (an automatic execution mode that approves tool usage without prompting for each one), opening the subagent details panel previously caused subagent tasks running smoothly in the background to suddenly pop up tool approval prompts, halting continuous operations. This issue has now been resolved, so subagents continue running fully automatically when opening or viewing the details panel. Like watching a car wash's progress through a transparent observation window, where the robotic arms do not suddenly brake and demand manual confirmation just because someone is looking through the glass.

Terminating subagents and deleting conversations now cleans up orphaned Git worktrees to free disk space

Ending multi-agent collaboration or cleaning up old conversations no longer silently accumulates temporary folders on disk. Like a workshop automatically dismantling and clearing out temporary parallel workstations when apprentices pack up or projects wrap up, preventing discarded frames from piling up in warehouse corners. When calling subagents for parallel execution, the system creates worktrees (a Git feature that creates multiple parallel copies of the same project) under the .system_generated/worktrees directory. Previously, when forcefully terminating subagents or deleting conversation history, these temporary worktrees were often not fully removed, leaving behind orphaned lingering files. The cleanup mechanism is now fixed to reliably remove them upon completion and reclaim disk space.

Faster `/logout`, metadata flushed to disk on exit, and spurious logs eliminated for temporary directories

Underlying state handling and persistence mechanisms have received a batch of enhancements during account logout, command exits, and customization loading. When logging out via /logout, if the system keyring is bypassed or unreachable, the system now short-circuits token removal directly to file storage, speeding up logout execution. When exiting the command-line interface, the system fixes SQLite database WAL checkpointing to ensure trailing session metadata is fully flushed to disk before shutdown. Furthermore, customization discovery no longer logs spurious errors when accessing temporary directories or paths outside the active workspace. Like backstage wrap-up after a theater show ends: staff first register props into storage, verify the lighting control system is fully reset and saved, and finally lock the gates without accidentally triggering alarms for public corridors outside the backstage area.
