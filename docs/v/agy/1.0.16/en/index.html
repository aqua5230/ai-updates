Antigravity 1.0.16

Released: 2026-07-01 ~ 07-08

Release notes

FEATURE

New real-time status bar showing all subagents working in the background

A new interactive status line has been added directly under the input prompt.

It reports on active subagents (helper AIs spawned in the background to analyze code or write docs) and background tasks (long-running processes like code compilation or test suites running behind the scenes) in real-time, allowing you to see if anything is stuck without typing queries. It's like replacing solid walls with glass windows in an office; now you can see if your assistants are typing away, without having to knock on their doors every five minutes.

FEATURE

Task detail panel now auto-scrolls down to show live logs as they write

To save you from constantly fighting the scrollbar to see progress, the /tasks detail panel now auto-scrolls down in sync with log streams.

As new background task log output (log, text streams outputted by programs as they run to describe their progress) arrives, the panel scrolls to show the latest lines, but pauses if you manually scroll up to inspect earlier entries. It's like typing in a chat app where the view scrolls to keep up with new incoming messages, but stays put if you scroll up to reread what was said earlier.

FEATURE

Added Alt+V on Windows as an alternative shortcut to paste clipboard images

App features an alternative paste hotkey.

If your standard Ctrl+V is hijacked by your terminal emulator (the shell window programs like CMD or PowerShell), you can press Alt+V instead to insert clipboard images or text directly, avoiding shortcut conflicts. It's like a revolving entrance door (Ctrl+V) that keeps locking because your large luggage (images) gets stuck; now security has opened a side door (Alt+V) so you can carry your luggage straight in.

FEATURE

Press Ctrl+G on an artifact to edit it directly in your favorite editor

You can now open files directly in your preferred editor.

While viewing generated artifacts (artifacts, documents or files of code generated by the AI for you to read), pressing Ctrl+G opens the file in your configured $EDITOR (your default text editor, such as VS Code, Vim, or Notepad), checking to save any unsent comment drafts first. It's like viewing a document on a library tablet and pressing a button that instantly transfers the file to your personal laptop, along with the half-written sticky notes you had placed on it.

FEATURE

Auto-retry on network glitches or busy servers, keeping your code sessions flowing

Response generation is now more resilient.

When the AI model runs into transient errors (transient errors, temporary failures caused by unstable Wi-Fi disconnects or brief cloud server overloads), the app automatically handles client-side retries behind the scenes, rather than aborting and making you resubmit your prompt. It's like being on a support call when your signal drops; instead of hanging up and making you dial and queue again, the phone system automatically redials in the background and reconnects you to the same agent.

BUGFIX

Executing background commands with zero text output (like sleep) no longer crashes the app

Background executors now handle silent processes properly.

Previously, if background tasks (tasks sent to run silently in the background, like a sleep command that pauses for a few seconds) yielded empty outputs (empty outputs, console command outputs containing absolutely no text), the internal reader panicked and crashed; this is now fixed so silent finishes close cleanly. It's like hiring a messenger and panicking that he was kidnapped because he came back with no letters; now you understand that returning empty-handed is a perfectly normal result.

BUGFIX

Fixed custom, dynamically created helper agents failing to wake up due to format bugs

Custom agent creations are now fully functional.

Spawning custom helper agents on the fly via define_subagent (dynamically defined subagents, custom AIs created on the fly with specialized prompts and tool permissions for unique tasks) used to fail due to fragile JSON format checks; the app now maps these in Markdown, allowing custom helpers to wake up and run immediately. It's like filling out a complex, poorly designed form (JSON) to hire a temp worker where one wrong checkmark rejects the request; now you just write a simple sticky note (Markdown) that they read and start working from immediately.
