Antigravity 1.5.3

發布日期：2026-11-07

繁體中文

新功能

子代理列出運作模型，詳細畫面可查思考力度

當你在對話中啟用多個子代理分工時，能一眼看清每位助理背後運作的模型。現在輸入框上方的子代理清單與 /agents 列表中，代理名稱旁會直接標註所使用的模型，遇到寬度較窄的終端機則會自動隱藏。

就像瀏覽球隊的出賽名單，以前名牌上只印球員名字，看不出誰是主力；現在名字旁直接列出階級，點開詳情還能掌握每位選手的投入程度。

進入子代理詳細檢視畫面，還能查看完整模型名稱與思考力度設定。如果你透過 status line（顯示在終端機最底下的狀態列）讀取 JSON 資料，每筆 subagents 項目也補上了 model 欄位。/agents 列表不再每行重複顯示 [view details]，改在下方顯示單行 Tip: Press enter on a subagent to view details. 提示。

新功能

外掛掛鉤支援專屬目錄，驗證工具接納分類欄位

開發或客製化外掛時，掛鉤程式現在能精準存取自身檔案並取得運作資訊。來自外掛的掛鉤（hook，特定事件發生時被觸發的小程式）指令，現在新增了 PLUGIN_ROOT 與 PLUGIN_DATA 兩個環境變數，分別指向外掛所在的目錄與會保留資料的目錄，方便掛鉤使用隨附檔案並在多次執行間保留狀態。執行 agy plugin validate 時，不會再針對掛鉤未設定這兩個變數發出警告。 執行 agy plugin validate 檢查時，plugin.json 設定檔內的 category 分類欄位已被正式接納，不再誤報為未知欄位，僅在內容不是非空字串時提出警告。在工作階段使用自訂模型時，過去掛鉤常收到預留位置或空名稱，現在會確實取得當前運作的模型名稱。

新功能

外掛管理支援符號連結，登入畫面與提示排版整齊

在終端機安裝、停用或登入各類外掛時，介面排版與特殊路徑的支援都補齊了。如果外掛以符號連結（symlink，指向另一個位置的捷徑檔）方式安裝，或名稱含有空格與符號，過去執行 agy plugin uninstall、agy plugin enable、agy plugin disable 或從 /plugin 移除時常會失敗，現在均已修復，且 agy plugin list 能重新列出符號連結外掛。 在 /plugin 登入畫面中，登入連結會正常縮排並以空行隔開，折行不再替結尾空白加底線，名稱也會改採 plugin.json 的顯示名稱。當外掛需要登入時，請求不會再從對話消失，終端機會提示 ⚠ The <plugin> plugin needs you to sign in. Open /plugin to sign in.。

問題修復

企業模型閘道修復路徑錯誤，模型逾時自動重試

連線至雲端模型或企業內部閘道時，網路延遲與路徑設定常影響對話能否順利展開。

宛如撥打跨國總機電話，以前只要線路忙線超過一分鐘就被直接切斷，分機號碼多帶斜線還會轉到空號；現在遇上線路延遲會自動重撥，轉接號碼多打尾碼也會自動校正接通。

當模型超過 60 秒才開始回傳標頭時，代理不會再以 http2: timeout awaiting response headers 中斷失敗，而是會主動重試。若企業模型閘道（gateway）網址結尾帶有 /v1beta，系統會自動忽略該後綴，避免請求全數回傳 404 錯誤。透過 Vertex AI 呼叫模型時，若模型不存在或專案無權限，錯誤訊息改以 The requested model was not found, or your project does not have access to it. 取代原始 API 報錯。

新功能

對話標題保留英文縮寫，送出排隊訊息不再閃爍消失

日常使用對話視窗交辦任務時，文字顯示與歷史紀錄保存變得更為可靠。現在自動產生的對話標題，會依你在提問中輸入的原樣保留英文簡寫與首字母縮寫，不再自行猜測並展開全名。 當你使用立即送出（Send Immediately）排隊訊息模式時，若在上一輪剛好結束的瞬間送出訊息，過去常在對話中短暫消失又重新出現，這個問題已經修好。 如果你透過 agy acp 連線工作階段，過去當用戶端切斷連線時，常在代理後端關閉前過早退出，容易打斷對話紀錄的儲存；這個問題已經修好，對話資料不會再因此在儲存途中被打斷。

問題修復

檔案工具支援舊版編碼頁，遠端讀取上限放寬至 20 MiB

當代理在不同系統間讀取程式碼或路徑時，非標準編碼與長路徑常引發解析異常。在 Windows 環境下，檔案工具讀取 UTF-16 與傳統編碼頁文字時不再誤判為二進位檔，編輯時也會保留 UTF-16 編碼或既有的 UTF-8 位元組順序記號（BOM）。寫入含非 ASCII 字元的 PowerShell 腳本時也會加上 UTF-8 BOM，讓 Windows PowerShell 5.1 能正確讀取。 使用 --remote-agent 遠端工作階段時，超過讀取限制的檔案不再被悄悄截斷，最高可完整讀取 20 MiB，超過上限則明確報錯。此外，工具呼叫摘要縮短非 ASCII 路徑時已修正亂碼，路徑與家目錄前綴重疊時也不再於 /context 清單顯示損壞的 ~ 符號。

問題修復

隔離終端機沙盒環境狀態，強化連線識別碼安全性

當你在終端機沙盒中執行不受信任的指令時，本機環境的隔離防護變得更為嚴密。

如同在密閉防護艙內試驗原料，以前艙內殘留的氣體可能滲漏到外部常態作業區，控制台識別碼也缺乏防護；現在內部操作徹底阻斷外洩，終端編號也強化防禦以防止越區穿透。

過去在終端機沙盒（sandbox，隔離執行指令的受限環境）內執行的指令，曾可能改動環境狀態，導致沙盒外部執行的常駐終端機指令載入受污染的設定。這個安全問題已經修好，沙盒內的狀態變更不會再影響外部終端機。常駐終端機的連線識別碼也針對路徑遍歷（path traversal）加強了防護。

English

FEATURE

Subagents List Their Running Models, and Detail Views Show Thinking Effort

When delegating tasks to multiple subagents in a conversation, you can immediately see the model running behind each assistant. In the subagent rows above the prompt and in /agents, the model in use is now marked directly next to each agent's name, and it is automatically hidden on narrow terminals.

Think of checking a team roster where placards previously showed only player names without revealing starters; now each name displays their tier, and opening details reveals each player's level of effort.

Entering a subagent's detail view also lets you see the full model name and effort setting. If you read JSON data through the status line (the status bar displayed at the bottom of the terminal), a model field has also been added to each subagents entry. The /agents list no longer repeats [view details] on every row, instead displaying a single Tip: Press enter on a subagent to view details. line below.

FEATURE

Plugin Hooks Gain Dedicated Directories, and Validation Accepts Category Field

When developing or customizing plugins, hook programs can now accurately access their own files and retrieve runtime information. Hook commands coming from a plugin now add the PLUGIN_ROOT and PLUGIN_DATA environment variables, pointing respectively to the plugin's folder and its persistent data folder. This allows hooks (small programs triggered by specific events) to use bundled files and preserve state across runs. Running agy plugin validate no longer warns that these variables are not set for hooks. When running agy plugin validate, the category field in the plugin.json configuration file is now officially accepted instead of reported as an unknown field, with a warning issued only when it is not a non-empty string. When using a custom model in a session, hooks previously often received a placeholder or empty name, but they now reliably receive the name of the model actually in use.

FEATURE

Plugin Management Supports Symlinks, Tidying Sign-In Screens and Prompts

When installing, disabling, or signing in to plugins in the terminal, interface layouts and support for special paths are now fully rounded out. If a plugin was installed as a symbolic link (a shortcut pointing to another location) or has a name containing spaces or symbols, running agy plugin uninstall, agy plugin enable, agy plugin disable, or uninstalling from /plugin previously often failed; these issues are now fixed, and agy plugin list displays symlinked plugins again. In the /plugin sign-in screen, sign-in links are now properly indented and set apart with a blank line, wrapped links no longer underline trailing blank space, and names use the display name from plugin.json. When a plugin requires a sign-in, requests are no longer dropped from the conversation, and the terminal displays a line such as ⚠ The <plugin> plugin needs you to sign in. Open /plugin to sign in..

BUGFIX

Enterprise Model Gateways Fix Path Errors, and Model Timeouts Auto-Retry

When connecting to cloud models or enterprise internal gateways, network latency and path configurations often affect whether conversations start smoothly.

Picture dialing an international switchboard where lines busy for over a minute were abruptly disconnected and an extra slash in the extension forwarded to a dead line; now line delays trigger an automatic redial, and accidental trailing suffixes in the extension are corrected to connect.

When a model takes more than 60 seconds to begin returning response headers, agent turns no longer fail with http2: timeout awaiting response headers and are retried instead. If an enterprise model gateway URL ends in /v1beta, the system automatically ignores that suffix to prevent every request from failing with a 404 error. When calling models through Vertex AI, if the requested model does not exist or your project lacks permissions, the error message now displays The requested model was not found, or your project does not have access to it. instead of the raw API error.

FEATURE

Conversation Titles Keep Abbreviations, and Queued Messages No Longer Flicker Away

When assigning tasks in daily conversation windows, text display and history retention have become more reliable. Auto-generated conversation titles now preserve abbreviations and acronyms as originally written in your request, without guessing and expanding their full names. When using the Send Immediately queued-messages mode, sending a message right as the previous turn ended previously caused it to briefly disappear and reappear in the conversation; this issue is now resolved. If you connect to sessions via agy acp, client disconnections previously caused sessions to exit prematurely before the agent backend finished shutting down, which could easily interrupt saving conversation history; this issue is now fixed so conversation data is no longer cut short during saving.

BUGFIX

File Tools Support Legacy Code Pages, and Remote Read Limit Expands to 20 MiB

When the agent reads code or paths across different systems, non-standard encodings and long paths often trigger parsing anomalies. On Windows, file tools reading UTF-16 and legacy code-page text no longer misidentify files as binary, and edits preserve UTF-16 encoding or existing UTF-8 byte order marks (BOMs). Writing PowerShell scripts containing non-ASCII characters also attaches a UTF-8 BOM so that Windows PowerShell 5.1 can read them properly. In --remote-agent remote sessions, files exceeding the read limit are no longer silently truncated, loading fully up to 20 MiB and reporting a clear error above that limit. In addition, garbled characters have been fixed when tool-call summaries shorten paths containing non-ASCII characters, and paths sharing a prefix with your home directory no longer show a broken ~ symbol in the /context list.

BUGFIX

Terminal Sandbox State Is Isolated, Hardening Connection ID Security

When running untrusted commands in a terminal sandbox, local environment isolation becomes significantly tighter.

Like testing raw materials inside a sealed containment chamber where residual gases once leaked into routine work areas outside while console IDs lacked protection, internal operations now thoroughly block leaks and terminal numbers are fortified against cross-zone traversal.

Commands run inside the terminal sandbox (an isolated, restricted environment for running commands) previously could alter environment state, causing persistent terminal commands run outside the sandbox to load contaminated configurations. This security issue has been resolved, so state changes inside the sandbox no longer affect external terminals. Connection IDs for persistent terminals have also been hardened against path traversal.
