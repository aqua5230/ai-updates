Antigravity 1.5.0

發布日期：2026-11-04

繁體中文

新功能

支援 ACP 協定，讓編輯器直接調用 agy 擔任代理

在慣用的程式碼編輯器中撰寫專案時，若想讓 AI 代理深度融入編輯流程，現在指令列新增了 agy acp。

好比請一位專屬秘書直接坐進辦公室，以前需要在不同視窗來回複製截圖與檔案，現在編輯器能透過標準輸入輸出直接交代任務。

它以 Agent Client Protocol（ACP，讓編輯器連接代理的協定）運作，支援在提問中附帶圖片與檔案內文。你甚至能在回答中途再次送出提示來即時修正方向。每個工作階段都支援獨立的模型與思考深度，並提供 default、accept-edits 與 plan 三種模式。透過 session/resume 能直接恢復工作階段而無須重播歷史紀錄。若編輯器運行在沒有瀏覽器的遠端主機，只要執行 agy acp --login 即可在終端機完成 Google 登入。

新功能

新增 `--remote-agent` 參數，將對話交由遠端代理執行

當本機電腦效能吃緊或需要專用運算環境時，你可以把任務分派到雲端主機。

如同把手頭工作委派給遠端辦公室的同事，以前所有檔案與流程都綁在自己的桌機上，現在工作改由遠端環境執行。

啟動時加上 --remote-agent 即可將工作階段的對話移至遠端代理執行，搭配 --project 能指定遠端專案名稱或識別碼，未指定時則進入預設專案。在這類工作階段中，鍵入 @ 補齊會搜尋遠端檔案，終端機無法顯示的產出物會提供 Open in browser 連結。介面頂端會改為顯示 remote workspace，斜線選單不再提供本機技能，在 /config 的 Remote 分頁也會顯示該對話專屬的權限預設。

新功能

`/projects` 支援本機專案，自由建立並快速切換工作區

在日常開發中頻繁切換不同專案目錄時，反覆尋找路徑往往令人手忙腳亂。

跟工作桌上的專案資料夾一樣，以前每次切換任務都要手動重新挑選相關文件，現在只要抽換整份收納夾，所有目錄便整組就位並開啟全新筆記。

現在本機工作階段的 /projects 指令支援完整的本機專案管理。你能列出專案清單並查看目前項目標記，也能依名稱與一組資料夾建立專案。資料夾路徑支援絕對路徑、波浪號 ~ 或工作區相對路徑。專案隨時可重新命名或修改資料夾；切換專案時，終端機會將其資料夾加入工作區並開啟新對話。

新功能

外掛與 MCP 設定體驗升級：引導登入、家目錄路徑與清楚的缺少指令提示

在終端機透過外掛連接各類服務時，授權與環境設定現在更直覺。從 /plugin 安裝合作夥伴外掛時，若包含 MCP（Model Context Protocol，讓 AI 連接外部工具的協定）伺服器，會跳出 Connect <外掛名稱> 畫面引導登入，按 Esc 可略過。已安裝分頁也會標示 ⚠ needs sign-in。Discover 清單與安裝後也會顯示第三方開發者工具提醒。 外掛的 sidecar.json 範本新增內建 ${HOME} 變數，方便在 workspaceUris 與 accessGrants 指定家目錄路徑，同名參數優先採用。 啟動 stdio MCP 伺服器若找不到指令，錯誤訊息會明確提示如 uvx 未安裝或不在 PATH 中，提醒安裝或指定完整路徑，不再只丟出找不到執行檔代碼。

新功能

無頭模式完整等待背景工作，逾時明確退出並回報錯誤

編寫自動化腳本以無頭模式（沒有視覺介面的執行模式）透過 -p 執行任務時，背景工作不再被暗中掐斷。

就像貨運站處理包裹，以前即使後台還有貨物在裝箱，時間一到就當作全部送達並提早收工；現在會確實等待所有背景工作做完才結束，若因倒數截止而中途喊停，也會留下錯誤紀錄並標明未完成的任務。

在未指定 --print-timeout 的情況下，執行時不再有隱藏的 30 分鐘限制並自動視為成功，而是會持續等待背景工作全部做完。若設定了 --print-timeout 且中途切斷，程式會改以退出碼 3 結束。它會印出標明終止任務名稱的 AGY_ERROR 行，並在標準錯誤輸出寫入 [agy] print timeout after ... 紀錄。

新功能

`/btw` 支援調用工具，查檔搜尋即時顯示並自動略過權限詢問

在長篇對話中想插話向 AI 打聽某個檔案細節時，直接輸入 /btw 就能發問而不打斷主線。

彷彿在開會中向身旁的速記員咬耳朵，以前他只能憑腦中印象悄聲回答，想翻閱文件就會卡住；現在他能快速查閱檔案再給出答覆，但只要動作需要額外簽核就會主動放棄。

現在 /btw 插話提問具備調用工具的能力，能直接讀取檔案或搜尋資訊。執行的每個動作都會即時呈現在卡片中，回答完成後會顯示 Called N tools 的調用次數摘要。凡是需要向你請求權限的工具操作一律會被自動拒絕。這項修正解決了先前模型想調用工具時，因無法處理而跳出空白回應錯誤的問題。

新功能

Auto 模式放寬安全指令審查，減少不必要的授權確認

啟用 Auto 模式讓代理自主執行多步驟任務時，原本頻繁跳出的確認詢問常打斷工作節奏。

有如經驗豐富的辦公室警衛，以前即使是倒垃圾或收發已登記的常規包裹，每隔一會兒都要敲門請你簽字；現在面對常態且安全的動作，他給自己設了時限，也少來敲你的門。

針對即將離開終端機沙盒的指令，Auto 模式的審查現在會逾時，對安全指令也更少跳出詢問。這些被認可的安全動作包含：未要求審查的上傳作業、終止代理自行啟動的任務、從套件庫安裝或移除套件，以及刪除後續可透過版本控制復原的檔案。這讓你能在確保安全的前提下，更順暢地讓代理獨立完成任務。

問題修復

終端機介面調整：選單選項更名為全螢幕，修復 diff 摺疊線與復原鍵錯誤

在終端機檢視檔案差異或切換輸入模式時，幾處顯示與按鍵操作細節獲得了修正。在 /config 的 Rendering Mode 中，原本名為 no flickering (altscreen) 的選項已更名為 full screen (altscreen)，已儲存設定維持不變。 修復 /diff 在新檔案或從第 1 行修改時，會在最上方繪製多餘且無摺疊內容的 ↕ ··· 空白摺疊線。另外修復在輸入框按復原鍵會喚回已送出訊息，以及在 ! Shell 或 : 搜尋模式按復原會叫回文字並在按 Enter 後誤跑指令或搜尋的問題。

就像在通訊軟體打草稿，按復原鍵只會抹掉剛打的字，絕不會把你五分鐘前早就發出去的舊訊息又撈回來重傳。
問題修復

修復模型連線與外掛更新問題：安全過濾死循環、錯誤重試與更新路徑

使用外部金鑰連接模型或讓外掛自動升級時，先前幾處例外處理的缺陷已獲得修正。使用 GEMINI_API_KEY 連線時，若觸發 API 安全過濾機制，過去會陷入無限重送提示的死循環，現在會顯示內容過濾訊息並結束該輪對話；該連線下的 pro 與 flash 子代理先前誤用落後兩代的老模型，現已修正為 Gemini 4 Argon 與 Gemini 3.8 Flash。 特定模型遇到速率限制（429）與伺服器 5xx 錯誤時不再直接失敗，現在會依據伺服器的 Retry-After 標頭自動重試。 若外掛安裝於不同名稱的資料夾（例如重新命名後），過去每次啟動都會寫入新目錄並重試更新，現在已修正為在現有資料夾就地更新。

跟整修老房子一樣，施工隊會認準原址就地翻新，不再因為招牌換了就每次都跑到空地另外蓋一間新屋。

English

FEATURE

Support ACP so editors can use agy directly as an agent

When writing code in your everyday editor, the command line now adds agy acp to weave AI agents deeper into your editing workflow.

Picture hiring a dedicated assistant to sit right inside your office. Where you once had to copy screenshots and files back and forth between windows, the editor now assigns tasks directly over standard input and output.

It runs on the Agent Client Protocol (ACP, a protocol for connecting editors to agents), supporting images and embedded file context in prompts. You can even steer a running turn by sending another prompt mid-answer to adjust course on the fly. Each session supports an independent model and thinking level, providing three modes: default, accept-edits, and plan. Through session/resume, you can restore a session directly without replaying its history. If your editor runs on a remote host without a browser, simply running agy acp --login lets you complete Google sign-in from the terminal.

FEATURE

Add `--remote-agent` flag to run conversations on remote agents

When your local machine runs short on power or demands a dedicated computing environment, you can offload tasks to a cloud host.

Think of delegating tasks to a coworker in a remote office. Where every file and process was once tied to your local desktop, the work now runs inside a remote environment.

Adding --remote-agent at startup runs the session's conversations on remote agents, while --project lets you specify a remote project name or ID, defaulting to your primary project when omitted. In these sessions, @-mention completion searches the remote files, and artifacts that cannot be displayed in the terminal provide an Open in browser link. The header changes to display remote workspace, the slash menu no longer offers local skills, and the Remote tab in /config displays the conversation's own permission preset.

FEATURE

`/projects` adds local project support to create and switch workspaces

When constantly switching between project directories during daily development, hunting down paths over and over can easily get chaotic.

Consider how project binders work on an office desk. Where switching tasks once meant hand-picking related documents each time, swapping out the entire binder puts all directories in place at once and opens a brand-new notepad.

The /projects command in local sessions now supports full local project management. You can list your projects with the current one marked, or create one from a name and a set of folders. Folder paths accept absolute paths, tildes ~, or workspace-relative paths. Projects can be renamed or have their folders modified at any time; switching projects adds their folders to the workspace and starts a new conversation.

FEATURE

Enhanced plugin and MCP setup: guided sign-in, home directory paths, and clearer missing command errors

When connecting to services through plugins in the terminal, authorization and environment configuration are now much more intuitive. Installing a partner plugin from /plugin that includes an MCP (Model Context Protocol, a protocol for connecting AI to external tools) server now brings up a Connect <plugin> screen to guide sign-in, which Esc can skip. The Installed tab also displays a ⚠ needs sign-in marker. Third-party developer tools notices now appear at the end of the Discover list and after installation. Plugin sidecar.json templates add a built-in ${HOME} variable, making it easy to name paths under the home directory in workspaceUris and accessGrants, while arguments with the same name take precedence. When launching a stdio MCP server fails because its command is missing, the error message now clearly points out that, for instance, uvx is not installed or not on PATH, reminding you to install it or set a full path instead of just reporting a raw missing executable error.

FEATURE

Headless mode waits fully for background tasks, exiting with explicit errors on timeout

When writing automation scripts to run tasks via -p in headless mode (an execution mode without a visual interface), background tasks are no longer quietly cut off.

Imagine a shipping depot processing parcels. Where workers previously called it a day and assumed all deliveries succeeded the moment the clock ran out even with items still being packed in the back, the system now genuinely waits for every background task to wrap up, leaving an error log that flags incomplete tasks if cut short by a countdown.

Without --print-timeout specified, runs no longer enforce a hidden 30-minute limit and exit with success, but instead keep waiting for all background tasks to finish. If --print-timeout is set and cuts a turn short, the program now exits with code 3. It prints an AGY_ERROR line naming the terminated tasks and writes a [agy] print timeout after ... record to standard error.

FEATURE

`/btw` gains tool calling to search and read files live while auto-denying permission prompts

When you want to interject and ask the AI about a file detail during a long conversation, entering /btw lets you ask without interrupting the main thread.

The experience mirrors whispering to a stenographer beside you in a meeting. Where they previously could only whisper back from memory and froze whenever checking documents was required, they can now quickly consult files before replying, automatically stepping back if an action demands extra sign-off.

Asking side questions with /btw now has the ability to call tools, letting it directly read files or search for information. Each executed action appears live inside the card, followed by a Called N tools summary once the answer finishes. Any tool operation that would ask you for permission is denied automatically. This fix resolves an issue where the model threw an empty-response error when trying to use tools it could not handle.

FEATURE

Auto mode relaxes review for safe commands to reduce unnecessary confirmations

When enabling Auto mode to let the agent independently run multi-step tasks, frequent confirmation prompts used to break your workflow.

An experienced office security guard illustrates the shift well. Where he previously knocked on your door for signatures every few minutes even for taking out trash or logging routine deliveries, he now sets a time limit for standard, safe tasks and knocks far less often.

For commands that would leave the terminal sandbox, Auto mode review now times out and prompts less often for safe commands. These approved safe actions include uploads that do not request review, stopping tasks the agent started itself, installing or removing packages from a registry, and deleting files that can later be restored through version control. This lets you allow the agent to complete tasks independently and smoothly while preserving safety.

BUGFIX

Terminal UI adjustments: full screen menu rename, diff fold divider fixes, and undo key fixes

When inspecting file differences or switching input modes in the terminal, several display and keystroke details have been refined. In /config under Rendering Mode, the previous no flickering (altscreen) option has been renamed. It is now called full screen (altscreen), while saved settings remain unchanged. Fixed /diff drawing an empty ↕ ··· fold divider at the top of new files and edits starting at line 1, where nothing was folded away. In addition, fixed pressing undo in the prompt bringing back already-sent messages, as well as undo in ! Shell or : search mode restoring text that Enter would then accidentally run as a command or search.

Drafting a message in a chat app follows the same principle: pressing undo should only erase the words you just typed, never resurrecting an old message you already sent five minutes ago to transmit again.
BUGFIX

Fix model connection and plugin update bugs: safety filter loops, error retries, and upgrade paths

When connecting to models with external keys or letting plugins upgrade automatically, several previous exception-handling flaws have been resolved. When connecting with a GEMINI_API_KEY, triggering API safety filters previously caused an endless loop of re-sending prompts. The turn now ends with a content-filter message. On that same connection, pro and flash subagents previously ran models two generations older, which has now been corrected to Gemini 4 Argon and Gemini 3.8 Flash. Instead of failing outright on rate-limit (429) and server 5xx errors, certain models now retry automatically based on the server's Retry-After header. For plugins installed under a different folder name, such as after a rename, startup previously wrote to a new directory and retried upgrading every time. This has now been fixed to update the existing folder in place.

Renovating an old house works the same way. The construction crew commits to renovating right on the original site, rather than running off to an empty lot to build an entirely new house every time the sign changes.
