Antigravity 1.4.3

發布日期：2026-10-20

繁體中文

新功能

/diff 與產物檢視器新增搜尋功能，支援跨檔案逐筆跳轉

比對大批修改內容時，要在冗長的變更清單中精準定位某個函式或變數往往相當費時。在 /diff 的檔案清單與檔案檢視中，按下 / 即可啟動搜尋。輸入關鍵字時會即時反白相符字串，提示列還會列出整份差異比對與各檔案分別包含多少筆相符項目。按下 Enter 會跳到第一筆結果，接著按 n 或 N 就能跨檔案逐筆來回巡覽，頁首也會顯示如 match A/B 的進度指示。

尋訪長篇族譜名冊時，以前只能逐頁掃描而容易看漏同行的重複名字；現在輸入字根便立刻標記全冊，提示列載明各章節出現次數，還能依序巡禮每個相符人名。

在產物檢視器（artifact viewer，用來預覽生成文件的面板）中按 n 與 N，現在也會逐筆跳過同一行內的多個項目，不再整行跳躍。

問題修復

外掛驗證新增結構檢查，修正 Windows 覆寫防護與顏色輸出

外掛設定疏漏或檔案被佔用以往容易導致異常。agy plugin validate 新增結構檢查：無法解析 hooks.json、sidecar.json 或元件清單時報錯；遇未知掛鉤、無效正規表達式（用符號比對字串）、未讀取的 hooks/hooks.json、遺漏路徑、不載入的 commands/ 與 workflows/ 或頂層 "hooks" 鍵名則警告。 在 Windows 更新或重裝外掛時，若被其他工作階段佔用，以前會留下半刪除毀損目錄；新版就位前舊版維持完整，替換失敗也會還原。 agy plugin install 與 agy plugin import 修正了導向輸出夾帶色碼的問題，現在只在終端機著色，並遵循 NO_COLOR、CLICOLOR 與 CLICOLOR_FORCE。

新功能

/tasks 計時器改以天時分秒顯示，清楚掌握剩餘時間

當你在背景啟動了長時間排程，隨時掌握任務的等待時間是安排後續工作的關鍵。在終端機查看進行中的排程計時器時，時間標示方式直接影響你掌握進度的速度。在 /tasks 任務清單與作用中任務清單中，計時器標籤現在改以天、小時、分鐘與秒數來顯示時間長度，例如呈現為 1d 2h timer 或 5m timer。以前這裡只會顯示原始秒數，像是 93784s timer，讓人難以一眼看出到底還要等多久。

盯著大樓停車場的繳費機螢幕，以前停留時間只顯示幾萬秒讓人摸不著頭緒；現在直接換算成幾天幾小時幾分幾秒，一眼就能看清車輛停放了多久。

當你設定了排程任務時，只要在對話中輸入 /tasks，就能立刻從清單看到以天或分鐘標示的計時器，不必再自行拿計算機換算秒數。

問題修復

修復以金鑰連線時未顯示 Gemini 4 Argon 的問題

習慣使用個人 API 金鑰切換模型時，可用清單若漏列特定選項會影響工作調度。當你透過環境變數 GEMINI_API_KEY（Gemini 服務的存取金鑰）連線時，先前在切換模型的 /model 指令選單以及 --model 啟動參數中，都沒有列出 Gemini 4 Argon 模型。現在這個問題已經修好，以金鑰連線時也能正常在選單與參數中指定該模型。

問題修復

不支援沙盒的作業系統不再列出終端機沙盒選項

在不支援終端機沙盒（隔離執行指令的受限環境）的電腦上打開 CLI，本來就用不了的選項不該出現在選單裡。這類系統包括阻擋非特權使用者命名空間的 Linux 系統，以及 Windows 11 24H2 之前的舊版 Windows，以前命令列介面仍會提供需要沙盒支援的選項。這個問題已經修好，不支援沙盒的系統上不會再看到需要沙盒的選項。

問題修復

自動模式子代理指令改由獨立代理審核，安全操作免手動核准

讓代理在背景自動排解複雜任務時，頻繁跳出確認提示會打斷原本流暢的工作流程。在自動模式下，子代理（subagent，負責分流特定任務的輔助代理）與自訂代理以往只要執行脫離終端機沙盒的指令，每次都會停下來要求你手動核准。現在比照主代理的處理機制，它們的指令會先由另一個獨立代理負責審核。安全指令會直接執行，只有具備潛在風險的操作才會跳出提示向你確認。

問題修復

對話壓縮保留子代理編號，精簡摘要不再丟失背景任務

長時間對話進行壓縮整理時，歷史任務資訊若被截斷，會讓代理遺忘先前派出的幫手。以前對話摘要會塞入每個子代理完整的初始提示詞，往往因為長度超限而在記錄對話編號（conversation ID）前就被截斷，導致代理失去對近期子代理的追蹤。現在壓縮摘要只保留各子代理的類型、角色與執行結果，確保識別資訊完整留存，並為語境視窗（context window，模型一次能讀取的記憶上限）留出更多空間。

問題修復

PostToolUse 掛鉤失敗改為記錄日誌，不再將工具誤判為失敗

設定工具執行的後續連動時，附加檢查腳本若發生異常，不應影響主要操作的成敗判定。在工具呼叫後觸發的 PostToolUse 掛鉤（特定事件發生時被觸發的小程式）若執行失敗，例如指令不存在、執行逾時、退出回傳錯誤或輸出無效的 JSON，以前會將原本成功的工具呼叫直接標記為失敗。現在這類失敗只會記錄在日誌中，工具會完整保留原本的執行成果。

問題修復

修復空白檔案建立失敗，以及專案寫入誤報產物路徑的問題

讓代理建立新模組或初始化目錄時，建立標記檔案與修改專案內容是常見的操作。以前代理在建立如 __init__.py 或 .gitkeep 等空白檔案時會執行失敗，而且當模型送出空白的產物資訊時，寫入或編輯一般專案檔案也會跳出 ... is not a valid artifact path 的報錯。現在這個問題已經修好，建立零內容檔案與正常編輯專案檔案都能順利完成。

問題修復

iPhone 與 iPad 遠端控制支援狀態記憶，不再重複提示條款與通知

在行動裝置上透過遠端功能查看進度時，每次開啟都必須手動關閉重複的提示視窗相當不便。在 iPhone 與 iPad 上使用 Remote Control（遠端控制功能）時，以前每次重新開啟，都會重複要求同意 Security Notice & Data Use 安全與資料使用條款，並再次彈出 Enable Notifications 啟用通知提示。現在應用程式會記住你的回覆，連同主題、排版設定以及已關閉的提示一併儲存。

問題修復

修復終端機游標錯位與換行，完善表情符號與多語字元排版

在終端機處理多國文字與圖示時，字寬計算誤差常導致游標跑位或排版錯亂。 調整視窗（停在 ↑ N more lines 或框外）、提示過高、按上下鍵移至中日韓或表情符號，以及進入 Vim 視覺模式時游標不再錯位，過長的補全提示也會自動縮短。 在支援圖素叢集寬度的終端機中，從外部編輯器（Ctrl+G）或 Ctrl+Z 返回後及在 tmux 3.6+ 下，含 👩💻、👍🏽、⚠️ 的行不再漂移。在日中韓語系（如 LANG=ja_JP.UTF-8）下含 →、…、─、• 時的漂移與提早折行也一併修復。 按方向鍵、Backspace 或 Delete 不再只刪改半個表情符號、旗幟或變音字母，行末寬字元也會正確折行。在 /diff 與 /artifact 預覽中，結合符號或零寬字元導致提早折行、空白列或過早以 … 截斷也已修好。

English

FEATURE

/diff and Artifact Viewer Add Search with Cross-File Match Navigation

When reviewing large sets of changes, pinpointing a specific function or variable across a lengthy change list is often time-consuming. In the file list and file view of /diff, pressing / starts a search. Typing keywords highlights matching strings in real time, while the prompt bar lists total matches across the diff and per file. Pressing Enter jumps to the first result, and pressing n or N navigates back and forth between matches across files, with the header showing progress indicators like match A/B.

When searching through a lengthy genealogy registry, people previously had to scan page by page and easily missed duplicate names on the same line; now, typing a root immediately highlights the entire registry, with a prompt bar showing the number of occurrences per chapter, and lets you browse each matching name in sequence.

In the artifact viewer (a panel used to preview generated documents), pressing n and N now also steps through multiple matches on the same line rather than skipping entire lines.

BUGFIX

Plugin Validation Adds Structural Checks, Fixing Windows Overwrite Protection and Color Output

Oversights in plugin configuration or occupied files previously caused errors. agy plugin validate adds structural checks, reporting errors if hooks.json, sidecar.json, or component manifests cannot be parsed. It warns on unknown hooks, unread hooks/hooks.json, missing paths, unloaded commands/ and workflows/, or top-level "hooks" keys. It also warns on invalid regular expressions (patterns used to match strings). When updating or reinstalling plugins on Windows, if files were locked by another session, a half-deleted corrupted directory was previously left behind. The old version now remains intact until the new version is in place, and rolls back if replacement fails. agy plugin install and agy plugin import fix an issue where redirected output included color escape codes. Output is now colored only in the terminal, respecting NO_COLOR, CLICOLOR, and CLICOLOR_FORCE.

FEATURE

/tasks Timers Switch to Days, Hours, Minutes, and Seconds for Clearer Remaining Time

When running long-running schedules in the background, keeping track of task waiting time is key to planning subsequent work. When checking active scheduled timers in the terminal, the time display format directly affects how quickly you grasp progress. In the /tasks task list and active tasks list, timer labels now display durations in days, hours, minutes, and seconds, appearing as 1d 2h timer or 5m timer. Previously, this displayed only raw seconds like 93784s timer, making it hard to tell at a glance how much waiting time remained.

Picture the screen of a parking payment machine, where parking duration previously showed only tens of thousands of seconds and left drivers baffled; now it directly converts into days, hours, minutes, and seconds, making it obvious at a glance how long a vehicle has been parked.

When you configure scheduled tasks, simply typing /tasks in a conversation lets you immediately see timers labeled in days or minutes from the list, without needing a calculator to convert seconds yourself.

BUGFIX

Fix Missing Gemini 4 Argon When Connecting with an API Key

When you are accustomed to switching models using a personal API key, missing options from the available list disrupt workflow planning. When connecting through the GEMINI_API_KEY environment variable (the access key for Gemini services), the Gemini 4 Argon model was previously omitted from the /model command selection menu and the --model launch flag. This issue is now resolved, and you can properly select the model from the menu and specify it via the flag when connecting with an API key.

BUGFIX

Terminal Sandbox Options Omitted on Operating Systems Lacking Sandbox Support

When opening the CLI on a machine that does not support a terminal sandbox (a restricted environment that isolates command execution), unusable options should not appear in the menu. Such systems include Linux systems blocking unprivileged user namespaces and versions of Windows prior to Windows 11 24H2, where the command-line interface previously still offered options requiring sandbox support. This issue has been resolved, and systems without sandbox support will no longer display options requiring a sandbox.

BUGFIX

Auto-Mode Subagent Commands Reviewed by Independent Agent, Allowing Safe Operations Without Manual Approval

When letting agents automatically handle complex tasks in the background, frequent confirmation prompts interrupt an otherwise smooth workflow. In auto mode, subagents (auxiliary agents that handle specific tasks) and custom agents previously paused to require manual approval every time they executed a command outside the terminal sandbox. Matching the behavior of the main agent, their commands are now reviewed first by an independent agent. Safe commands run directly, and only potentially risky operations prompt you for confirmation.

BUGFIX

Conversation Compaction Preserves Subagent IDs, Preventing Compacted Summaries from Losing Background Tasks

When compacting and summarizing long conversations, truncated historical task information causes the agent to forget previously delegated helpers. Previously, conversation summaries included the full initial prompts for each subagent, which frequently exceeded length limits and were truncated before recording conversation IDs, causing the agent to lose track of recent subagents. Compacted summaries now retain only the type, role, and execution results of each subagent, ensuring identifiers are preserved while freeing up space for the context window (the maximum memory a model can read at one time).

BUGFIX

PostToolUse Hook Failures Now Logged Rather Than Misreporting Tool Failures

When configuring post-execution actions for tools, errors in supplemental check scripts should not affect the outcome of the primary operation. If PostToolUse hooks (small programs triggered when specific events occur) failed after a tool call—such as from a missing command, execution timeout, non-zero exit code, or invalid JSON output—the system previously marked an otherwise successful tool call as failed. Such failures are now recorded only in logs, leaving the original tool results fully intact.

BUGFIX

Fix Empty File Creation Failures and Erroneous Artifact Path Errors on Project Writes

When having an agent create new modules or initialize directories, generating marker files and modifying project contents are common operations. Previously, agents failed when creating empty files such as __init__.py or .gitkeep. In addition, writing or editing normal project files threw a ... is not a valid artifact path error whenever the model sent blank artifact information. This issue is now resolved, allowing both zero-content file creation and standard project file editing to complete smoothly.

BUGFIX

Remote Control on iPhone and iPad Adds State Persistence, Ending Repeated Terms and Notification Prompts

When monitoring progress remotely on mobile devices, having to manually dismiss repetitive modal dialogs upon every launch is frustrating. When using Remote Control on iPhone and iPad, reopening previously prompted users to accept the Security Notice & Data Use terms again and popped up the Enable Notifications prompt each time. The application now remembers your responses, saving them alongside your theme, layout preferences, and dismissed prompts.

BUGFIX

Fix terminal cursor misalignment and line wrapping, improving emoji and multilingual character layouts

When handling multilingual text and symbols in the terminal, character width calculation errors often lead to cursor displacement or layout glitches. The cursor no longer misaligns when resizing the window (resting on ↑ N more lines or outside the frame), when prompts are excessively tall, when pressing Up or Down keys across CJK characters or emojis, or when entering Vim visual mode. Excessively long completion hints will also automatically shrink. In terminals supporting grapheme cluster widths, lines containing 👩💻, 👍🏽, or ⚠️ no longer drift after returning from an external editor (Ctrl+G) or Ctrl+Z, or under tmux 3.6+. Drifting and premature line wraps when containing →, …, ─, or • under CJK locales (such as LANG=ja_JP.UTF-8) have also been fixed. Pressing arrow keys, Backspace, or Delete no longer modifies or deletes half of an emoji, flag, or accented letter, and wide characters at line ends now wrap correctly. In /diff and /artifact previews, premature line wrapping, blank lines, or early truncation with … caused by combining characters or zero-width characters have also been fixed.
