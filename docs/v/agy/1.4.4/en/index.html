Antigravity 1.4.4

Released: 2026-10-21

Release notes

FEATURE

Auto Mode Arrives on Windows 11 with Stricter Out-of-Sandbox Command Review

When running on Windows 11 24H2 or later with a personal Google account, you can now experience Auto mode, which decides tool calls on its own.

Picture a car cruise control system with active safety: where it once only held a preset speed and struggled with sudden shifts, it now slows down on hazardous roads and prompts the driver to take over.

You can switch modes via the --mode auto flag, by selecting Agent Mode in the /config settings menu, by pressing Shift+Tab, or by enabling Remote Control settings, while Agent mode remains the default. When Auto mode reviews commands about to leave the terminal sandbox (an isolated security environment for command execution), safeguards are significantly stricter. For pipeline commands, it inspects every sub-command individually; for short replies like yes, it evaluates them alongside the assistant's preceding question, prompting for confirmation before running destructive Git or file operations.

BUGFIX

/diff Adds Hunk Folding and Full File Toggle, Fixing List Wrapping and Title Truncation

When typing /diff in the terminal to inspect code changes, Commit Tree and Per Turn views add several reading controls.

Like consulting a bound set of engineering blueprints where you previously had to spread out entire pages to search for details, you can now collapse secondary sections at will and consolidate edits from the same job into a single list.

Pressing f now toggles the full file view, while Ctrl+O folds an individual hunk (a contiguous section of code changes in version control). In Per Turn view, multiple edits made to the same file within a single turn merge directly into a unified diff screen instead of being scattered. List formatting issues are also fixed: lines exceeding terminal width now truncate cleanly rather than wrapping forcefully, and Per Turn headers no longer truncate prompts at 50 characters.

FEATURE

MCP Tool Calls Support Root Conversation Tracing, Fixing Server Connection Leaks

When connecting custom servers with MCP (Model Context Protocol, a protocol that connects AI to external tools), tracking tool calls made by subagents is substantially improved.

Think of shipping a package through an international courier: previously, handoffs to regional delivery agents obscured the origin, but now every dispatch record stamps a master tracking number so the initial request remains traceable across any number of transfers.

Even when tools are invoked by deeply nested subagents, outgoing tools/call requests now automatically include the _meta["antigravity.google/root_conversation_id"] field so external servers can identify the top-level conversation ID. In terms of server connections and resource cleanup, background connection routines and client sessions previously lingered if tools/list failed during startup or if the CLI closed before the connection finished. Leaks of client sessions and background connection routines caused by both scenarios are now resolved.

BUGFIX

Plugin Validation Enforces Stricter Checks, Fixing Subagent Inheritance and Skill Duplication

When developing or installing custom extensions, plugin validation mechanisms and execution environments received multiple fixes. The agy plugin validate command introduces stricter checks that thoroughly inspect plugin.json, MCP server configurations, hooks.json, and sidecar manifests, guarding against invalid JSON syntax, unknown fields, malformed variable placeholders, unrecognized tool matchers for hooks (automated scripts triggered by specific events), and missing scripts. For subagents, an issue where subagents lost plugins inherited from parent sessions has been resolved. If a packaged plugin subagent sets plugins.inherit_user: false and restricts MCP tools, the startup error throwing mcp spec not found for provider is also fixed. When custom rules or SKILL.md skills exist simultaneously in standalone customization folders and enabled plugins, the system no longer loads them twice.

FEATURE

Stream Response Caching Cuts Resource Overhead, Compaction Retains Tool Declarations

When asking models to generate lengthy responses or modify extensive code, caching mechanisms for response streaming and conversation compaction reduce computing overhead.

Imagine keeping prepped ingredients ready by the kitchen counter, where washed and chopped items drop straight into the pot without re-cutting, while standard menus stay on the chalkboard during cleanup to save time re-copying.

During streamed text output, the terminal now caches code-block syntax tokens (structural analysis units for code) across frames, along with rendered Markdown blocks and inline file edit confirmation diffs, lowering CPU and memory usage. When running /compact or when the system triggers automatic compaction, conversation summary requests preserve tool declarations intact, allowing model APIs to smoothly reuse previously cached prompt prefixes.

BUGFIX

Remote Control Adds Multi-Column Layout on Tablets, Fixing Mobile UI and Rendering Bugs

When using Remote Control on tablets and mobile devices, large-screen layouts and various operational experiences received an overall upgrade. Tablets and foldable devices are no longer forced into a single-column phone view; instead, they enable a multi-column layout with touch-sized controls, and popover panels remain open while dragging scrollbars. Mobile interface details have also been refined. Issues where titles and dialogs truncated on phones, tapping input fields in iOS Safari triggered automatic zoom, the Enable Telemetry and Marketing Emails toggles flipped back while settings loaded, and dragging URLs lost query parameters or hashes (#) are all resolved. Output rendering and file exports are likewise more stable. Prior issues with broken nested code block layouts, Shell variables ($VAR) being misidentified as LaTeX formulas, media previews failing to load, blurry or blank charts when copying images or exporting PDFs, and background tab timer drift have all been fixed.

BUGFIX

Terminal Input Box Re-Anchors to Bottom, Fixing Ctrl+Z Undo and Emoji Truncation

When chatting with models in the terminal, the input box layout position and text undo behavior received major fixes.

A writer sketching and erasing drafts on paper once risked smudging extra marks or wrinkling the sheet, but now each undo step accurately retracts the previous entry.

Previously, closing panels, dropdown menus, or inline prompts could leave the input box stuck midway up the screen, and a blank gap appeared above the input box in Medium verbosity mode; these layout anomalies are now resolved, keeping the input bar securely anchored to the bottom. For text editing, the Ctrl+Z undo mechanism has been retuned. Pasting text previously scrambled undo history, sometimes incorrectly merging newly typed content with older history. Ineffective Backspace and Delete keystrokes are no longer recorded as extra steps, and deleting or undoing next to emojis (pictographic symbols) no longer causes characters to be truncated.

BUGFIX

Clarify Rule Precedence Phrasing to Explicitly Cover Earlier Built-In Instructions

When writing custom rules in project roots, note the updated system prompt phrasing for rule precedence. Phrasing in the system prompt (core instructions guiding AI behavior) previously only stated that user rules in GEMINI.md and AGENTS.md could override instructions placed after them. The system prompt now explicitly clarifies that GEMINI.md and AGENTS.md rules can override earlier built-in instructions.

BUGFIX

Support Media Attachments with Codec Parameters, Preventing Erroneous Audio Rejections

When uploading audio or multimedia files in terminal conversations, attachment format compatibility has been fixed. Previously, if a media attachment's MIME type (a label identifying attachment content formats) included extra parameters, such as the common audio format audio/webm; codecs=opus, it was incorrectly flagged as unsupported and rejected. Such natively supported attachments are no longer falsely rejected due to parameterized MIME types.
