Antigravity 1.1.27

Released: 2026-09-05

Release notes

BUGFIX

`/model` Supports Single-Prompt Model Switching with Comprehensive Fixes to Input Hints and Startup Menus

You no longer need to change your global settings when you want to switch models for a single question mid-conversation.

It is like consulting your primary physician and having a specialist step into the examination room just to review a single scan, immediately returning to your primary physician once done without undergoing hospital transfer procedures.

The new /model <name> <prompt> command lets you run a single prompt on another model, automatically returning the session to its original model afterward without affecting your saved defaults. If you finish writing code and want to run /model gemini-3.8-flash check for security vulnerabilities to consult another perspective, this is the exact use case. In addition, typing /model now displays a real-time [model] argument hint so you know how to use it without opening help. If the session is already using that model, the command now reports Model already set to <name> instead of falsely reporting a switch. Running /model without arguments before the session finishes starting up also now properly opens the model picker.

FEATURE

Custom Markdown Agents Support `agents` List to Directly Declare Dependent Subagent Paths

When designing multi-agent collaboration for a project, custom agents can now directly declare their own subordinate helpers.

The Markdown frontmatter at the beginning of an agent definition file has added an agents list. You can directly list the subagents this agent depends on, using workspace-relative paths, absolute paths, or agent-relative paths just like skills:

---
agents:
  - ./researcher.md       # Agent-relative path
  - subagents/verifier.md # Workspace-relative path
  - /global/audit.md      # Absolute path
---

When creating a security audit agent that needs to automatically invoke a dedicated code inspection helper, simply declaring this list at the top of the definition file ensures the system accurately loads the dependencies.

Like a head chef listing dedicated prep assistants and cold-dish apprentices at the top of a banquet menu so the kitchen can staff up before work begins, rather than scrambling to dispatch helpers after guests are seated.
FEATURE

Status Line and Window Title Scripts Add `conversation_title` to Synchronize Renamed Conversations in Real Time

Custom scripts can now retrieve richer information to help you track active conversations at the screen edge at any time.

Like a digital nameplate outside a conference room that instantly updates when the organizer renames the project, giving anyone walking in immediate clarity.

The JSON payload passed to custom status line and window title scripts now includes a conversation_title field. Your scripts can directly read this field to display the active conversation's name, picking up renames immediately rather than staying stuck on old names or default identifiers:

{
  "conversation_title": "Refactor login module"
}

When running multiple terminal windows across different projects, having your script read this new field makes it easy to identify the task topic in each window.

BUGFIX

Hardened Execution for Headless and Print Mode `-p`: Unauthorized Actions Explicitly Listed and Records Flushed to Disk

When running AI in background automated schedules, the worst issues are silent tool rejections or dropped records due to premature disconnections.

Like an autonomous sampling rover that, when encountering an unauthorized restricted zone, no longer skips past it silently but clearly logs the refused location in writing, and always waits for all telemetry to flush to storage before powering off on its return.

When running headless with -p, the system previously skipped unauthorized tool actions silently; it now ends with a notice naming the refused actions and reports them as denied_actions in the JSON output. In addition, print mode previously exited before the session finished shutting down, which could drop trailing conversation history before it reached disk; it now properly waits for the session to finish writing to disk before exiting.

BUGFIX

MCP Tool Calls Strictly Validate Schemas, Actively Rejecting and Correcting Invented Parameters

Validation standards for passing arguments have become much stricter when connecting AI to external servers for dedicated tools.

When calling MCP (Model Context Protocol) servers in the past, if the AI invented extra arguments never declared in the server's schema, the system often silently dropped them without notice, causing unexpected behavior. The underlying validation mechanism is now fixed to actively reject and correct invented parameters outside the schema, ensuring every tool call strictly matches definitions.

Like filling out a bank transfer slip where, if the applicant checks custom options never printed on the form, the teller will not silently cross them out, but will reject the slip on the spot and guide you to fill out valid fields.
FEATURE

Settings Panel Details Verbosity Levels, and Onboarding Key Hints Are Fully Standardized

On-screen guidance fits your habits much better when tweaking settings in the terminal or logging in for the first time.

Like browsing a touchscreen kiosk in a tech showroom where highlighting different options prompts a dynamic billboard to explain functional differences, button backlights adapt to showroom colors, and navigation arrows hide when only a single path exists.

When opening the /settings panel, highlighting each Verbosity option now expands explanatory text in real time. It describes in detail whether tool calls, terminal commands, and thoughts are shown in full or collapsed into a token metrics table. In addition, sign-in and Google Cloud setup screens now use standard styled CLI key hints that follow your terminal color scheme and custom keybindings, dropping navigation hints when only one option is available.

BUGFIX

Vim Normal Mode Resolves `?` Key Conflict, Restoring Inline Search and Replace Operators

Engineers used to Vim keybindings in the terminal will no longer accidentally trigger popup panels during inline navigation in the prompt.

Previously in Vim Normal mode, pressing ? while the prompt already contained text incorrectly opened the shortcuts panel, breaking character-search and replace operators such as f?, t?, and df?. This key intercept issue is now fixed so that search and replace commands work smoothly when the prompt has text; pressing ? only opens shortcut help when the prompt is completely empty.

Like editing on a typewriter where pressing a punctuation key performs precise inline character search, jumping, and replacement while paper is loaded, and only acts as a service bell summoning the manual when the roller is completely empty.
BUGFIX

Reading and Writing Cross-Conversation Artifacts No Longer Prompts for Redundant Approval When Workspace Access Is Granted

Retrieving past analysis documents across conversations no longer interrupts your workflow with repeated confirmation popups.

Once you explicitly allow an agent access to file paths outside your workspace, the system previously still prompted repeatedly for approval whenever the agent read or wrote artifact files created by another conversation; this redundant prompt is now fixed so the agent smoothly accesses artifacts from other conversations once external paths have been permitted.

Like staying at an all-inclusive resort where wearing an all-access wristband means the front desk should not ask for your passport and signature again when you borrow board games from the recreation center next door.
