Antigravity 1.1.22

Released: 2026-08-27

Release notes

FEATURE

Switch and save default models by name with inline ghost text completion

Like a regular customer ordering a favorite dish by name and making it their standing order, with the waiter guessing the dish from the first syllable while the full menu remains available on request.

When switching your underlying language model, you can now run /model <name> with a model name, slug (a short identifier), or label to switch and save it as your default in one step.

While you type, the rest of the first matching name appears as ghost text (a faint inline preview of the suggested completion). Running /model by itself still opens the interactive picker, and typing an unrecognized name prints the full list of valid choices.

FEATURE

The /effort prompt dynamically completes what you type instead of showing a static placeholder

When adjusting reasoning effort (the computational depth the model uses before answering), the command hint is now much more responsive.

After typing /effort, the inline completion dynamically fills in based on the characters you have actually typed, adapting seamlessly as you type each letter. Previously, the prompt strictly displayed the static [low|medium|high] placeholder regardless of what you entered.

Like a search bar that dynamically suggests matching queries based on the letters you type rather than always displaying a generic static hint.
FEATURE

Artifact handling coalesces filesystem event bursts into a single rescan

Like a mailroom receiving a large batch of packages at once, cataloging the entire bundle in a single pass rather than making a full delivery run for every individual envelope.

Handling artifacts (code or document files generated during conversations) is now much faster in workflows that output multiple files.

Previously, when a burst of files was created in quick succession, repeated filesystem events triggered multiple redundant rescans; the system now coalesces bursts of filesystem events into a single efficient rescan.

BUGFIX

Selectable reasoning effort enabled for Gemini 3.1 Pro and 3.5 Flash with Gemini API keys

When authenticating with a Gemini API key (a private key granting access to model services), model configuration is now fully unlocked.

Previously, when using Gemini 3.1 Pro and Gemini 3.5 Flash with an API key, selecting reasoning effort (the computational depth used to think before answering) was broken; this has been fixed so you can freely adjust reasoning depth to match the complexity of your task.

Like bringing your own VIP pass to an attraction and finding all adjustable gear dials fully operational rather than locked in a single fixed mode.
BUGFIX

Idle tasks and subagent panels stop redrawing continuously, reducing CPU usage

Like an unattended lobby screen that stops frantically refreshing a blank page dozens of times a second so the hardware can finally rest.

When keeping the tasks panel or a subagent (a helper agent assigned to a subtask) detail panel open with nothing running, the user interface used to redraw continuously.

This bug held CPU usage near 32% even while completely idle; the redraw loop has been fixed so the process now settles at roughly 10% CPU.

BUGFIX

Subagent elapsed timers no longer freeze when the parent agent is waiting

When monitoring background jobs, on-screen timers now reflect progress accurately.

Previously, when a subagent (an auxiliary agent executing a separate task) was running, its elapsed timer on screen would freeze whenever the parent agent was waiting; the timing loop has now been decoupled so the running subagent's timer continues ticking smoothly regardless of the parent agent's state.

Like field workers whose stopwatches keep running while the manager in the office pauses to wait for paperwork, rather than having all clocks frozen in place.
BUGFIX

HTTP 502 Bad Gateway errors from model endpoints are automatically retried

Like a phone system that automatically redials when a line experiences momentary static rather than hanging up and abruptly canceling the entire conference call.

Transient network hiccups from AI servers no longer derail your ongoing workflow.

Previously, receiving an HTTP 502 error (Bad Gateway, a temporary server connection failure) from the model endpoint immediately terminated the entire run; the client now recognizes these errors as temporary outages and retries the request automatically.

BUGFIX

Self subagents properly inherit parent configurations and preserve autonomous mode

When spawning a self subagent from a session that lacks explicit agent configuration records, the new subagent now faithfully inherits its parent's setup.

Previously, such subagents would re-resolve their settings from scratch and drift from the parent agent; most noticeably, they would run interactively and prompt for input even when the parent was running in autonomous mode (a hands-off mode executing tasks without manual confirmation). The inheritance behavior has been corrected to keep subagents fully aligned with their parent.

Like an apprentice stepping out on an errand and adhering to their mentor's current rules of engagement rather than reverting to trainee mode just because no written handbook was in sight.
BUGFIX

Windows file deletions retry with backoff to prevent sharing violations

Deleting files on Windows no longer fails immediately when another program temporarily holds the file open.

Previously, attempting to delete a file that was still opened by another process would trigger a sharing violation error (a conflict where a file is locked by an active process) and immediately abort the action. The delete operation now automatically retries with backoff for about a second before reporting a failure, smoothly handling transient file locks.

Like a cleaner stepping back for a moment when someone is reading a document rather than immediately logging a cleaning failure the second they encounter a busy desk.
BUGFIX

Headless daemon removes unsupported browser URL from startup logs

Startup logs for the headless daemon (a background process running without a graphical terminal interface) are now much cleaner.

Previously, the daemon's startup banner printed Open in your browser: http://localhost:<port>, which was never a supported connection method; when managed by a service manager, this spurious line cluttered logs on every single restart. The misleading line has been removed to keep background logs focused and accurate.

Like an unmanned server rack that boots silently without broadcasting unneeded visitor desk directions, keeping the system event log pristine.
BUGFIX

The migrate-workflows skill supports Windows paths and home directories

Migrating workflows on Windows now handles paths smoothly without cross-platform errors.

The built-in migrate-workflows skill (a specialized tool package extending agent capabilities) previously suffered from compatibility issues. It assumed POSIX (Unix-like operating system standards) home directories and forward slash path separators, breaking path resolution on Windows. It now resolves and reports file paths using the appropriate Windows directory format.

Like a navigation system learning the local street numbering rules of different cities so it gives accurate directions anywhere in the world.
