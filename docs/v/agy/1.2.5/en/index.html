Antigravity 1.2.5

Released: 2026-09-17

Release notes

FEATURE

Automatic Subagent Guidance and Roster Injection for Markdown Custom Agents

When customizing project AI agents in Markdown files, agents can now collaborate and divide work more intelligently.

Just like an onboarding handbook prepared by a chain restaurant for a new store manager, where as long as their duties include scheduling staff, the first page automatically includes the on-duty staff roster and station assignment workflows, allowing the manager to accurately dispatch work to dedicated front-of-house staff or kitchen assistants upon receiving orders.

When you define custom agents in Markdown format and include the invoke_subagent tool in their tool list, this new mechanism automatically injects the currently available subagent roster and detailed usage guidance into that agent's system prompt. Custom agents can now reliably delegate to their declared subagents based on the roster, rather than failing to divide work due to missing instructions.

FEATURE

Background Tasks Retain Original Names in Notifications and Lists Instead of Displaying Generic Identifiers

Keeping track of progress is now much more intuitive when sending long-running, heavy commands to run in the background.

Previously, when assigning work to run in the background, the system often replaced the task name with an auto-generated generic identifier, making it hard to tell at a glance which job had finished running. The background task naming mechanism has now been improved so that tasks fully retain their originally given custom names when moved to the background. Whether in completion notifications popping up in the terminal or in queryable background task lists, the original task name is now clearly displayed, allowing you to accurately cross-reference each operation.

Just like dropping off dry cleaning at the counter, where the garment bag always keeps the handwritten laundry tag you wrote, and both the pickup notification and pending laundry list clearly specify which outfit it is, rather than only labeling an impersonal, random receipt serial number.
BUGFIX

Automatic Sign-Out and Cleanup on Rejected Credentials While Preserving Sessions During Transient Network Failures

Managing sign-in status during account permission changes or network fluctuations is now significantly more accurate and reliable.

Much like room key card management at a hotel front desk, where the card reader proactively clears old keys from the card chip for re-issuance once the front desk confirms a guest has officially checked out and settled their bill, but the system never arbitrarily cancels the access of an actively staying guest if the sensor line is briefly busy or the card reader responds slowly.

Previously, when situations like enterprise account revocations or invalidations occurred and the sign-in server definitively rejected the identity, stale sign-in credentials could still linger locally. The CLI tool now automatically signs you out and clears stale tokens so you can sign in again cleanly. Meanwhile, if transient network connection failures, server errors, or request rate limits occur, the system will never accidentally drop your session, ensuring operations remain uninterrupted.

BUGFIX

Commands Terminated by External Signals Correctly Marked as Canceled with Remote Sessions Syncing Interruption Hints

Recording cancellation and interruption states is now more accurate when running commands in the terminal or operating across connected sessions.

Previously, when a running command was terminated by an external signal (such as when the entire session shut down mid-run), the system erroneously recorded it as a successful execution with exit code 0. Such commands are now properly marked as canceled while fully preserving the output logs collected before the interruption. In addition, whereas the Interrupted hint previously only appeared when pressing the Esc key locally in the terminal, it now faithfully displays on screen whenever the current turn is actually canceled, including when stopped from a connected remote session.

This is like a high-speed train stopping mid-route due to an external emergency signal: the on-board computer accurately marks that trip as canceled mid-way and preserves prior driving logs, while prominent interruption warning lights illuminate synchronously across both the driver's console and the remote dispatch screen.
BUGFIX

Terminal Resizing Automatically Re-wraps Text and Resolves Frozen In-Progress Thinking Frames

Layout and status presentation are now much smoother when freely resizing the terminal window or reloading conversations.

Previously, after resizing the terminal window, Markdown text in the artifact viewer remained stuck at its original width without re-wrapping automatically. Furthermore, in-progress thinking frames in conversation history would sometimes freeze permanently—such as staying stuck forever at Thinking... (31s)—without recovering even after resizing the window or reloading the session. Both interface display issues are now resolved: text content automatically re-wraps to fit the new window dimensions, and thinking frames update progress normally.

Just as when switching screen widths on an e-reader, where article pages instantly reflow and re-wrap to match the new layout, and loading progress spinners do not freeze on screen due to screen resizing.
