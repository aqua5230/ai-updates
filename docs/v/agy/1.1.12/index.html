繁體中文

長文件有目錄，Markdown 警示也會正常顯示

讀到很長的 Markdown 文件時，現在按 t 就能打開標題大綱，直接跳到要看的段落，不必一直捲動找位置。Markdown（用符號排版的純文字格式）裡的提醒框也終於會畫成提醒框：[!NOTE]、[!WARNING] 等標記不再原樣露在畫面上，輪播區塊也能顯示。像一本原本只有密密麻麻文字的說明書，補上目錄和醒目的注意貼紙；找章節與辨認警告都快得多。

列印模式可直接查指令，結果也能交給程式讀

想在腳本裡查權限、掛鉤或設定時，現在可用 print mode（列印模式，只輸出答案就結束）執行 -p "/permissions"、/hooks、/help、/changelog、/config。它不會啟動代理、不花額度，也不留下對話；每行是一筆以 Tab 分隔的資料，改用 --output-format json 或 stream-json 則會給結構化結果。models 與 agents 子指令也同樣能輸出 JSON，錯誤訊息和轉圈提示搬離標準輸出，接收清單的程式不會混到雜訊。像市場的秤貨單：品項整齊列出，攤販的招呼聲留在一旁。

技能可退出斜線選單，工具很多也不再被拒絕

技能庫越裝越多，/ 選單不必跟著塞滿。只要在技能的 SKILL.md 前置資料加上 disable-slash-command: true，它會從選單與 /名稱 查找中隱藏，但模型仍找得到、也能呼叫它。SKILL.md（技能說明檔）像工具箱上的標籤：先把不需手動拿的工具收進抽屜，不等於丟掉。另一邊，單一工作階段允許宣告的工具數量提高；MCP、外掛與技能都裝很重的環境，不會因為工具太多而被拒在門外。工具呼叫標頭也改成短摘要，背景任務、子代理和權限詢問會顯示正在做什麼，而非只丟名稱或一串參數。

終端機連結能跨 SSH 點開，換行也不斷

你在 SSH（遠端登入另一台電腦的連線方式）裡看到網址，現在也能直接點開；支援超連結的 tmux 終端機同樣適用。網址折到下一行時，整段仍是一個可點的連結，不再只剩第一行有效。Markdown 沒自動連結的網址，包括程式碼區塊裡的網址，也會補上連結；滑過去不會連無關網址一起反白，含連結的行也能正常橫向捲動和選取文字。像跨行寫下的樂譜，換到下一行仍是同一段旋律。

登入少填一步，巢狀 Git 專案也找對根目錄

用 Application Default Credentials（雲端服務帳號的預設登入憑證）登入時，現在會自動找出 quota project（用來計算用量的雲端專案），服務帳號不必再額外補設定才用得起來。另一項改善發生在把多個 Git 專案放進大資料夾的人身上：工具會辨認內層的儲存庫才是目標，不會誤把外層目錄當根目錄；子模組和工作樹也算進去。像機場分揀行李：認出最終航廈，行李才會送到正確轉盤，不會只停在第一站。

無頭執行會自己判斷，模式錯了也看得到警告

把 -p 放進排程或自動流程時，沒人能回覆追問，現在它遇到本來會問你的選項會自行做決定，不再停在原地等人。無頭模式（沒有互動視窗的執行方式）也終於會套用 --mode accept-edits 或 --mode plan；傳入不認得的模式則會警告，不再悄悄忽略。啟動時的崩潰通知、找不到 --conversation、--print 與 --prompt-interactive 衝突、載入對話失敗，以及 mode 或 agent 警告，也會印到終端機，不再只藏在日誌。像夜間值班的機器，遇到岔路能照規則走，規則寫錯時還會亮起警示燈。

排程結束時少一條廢通知，原因和來信者寫清楚

設定一次性的 schedule（排程工具）在收到某個訊息後提早結束時，以前還會再跳一則沒有幫助的 Timer Cancelled 通知；現在那則重複訊息拿掉了。步驟結果則會寫出是哪個條件成立，以及哪位傳訊者剛好滿足它。像社團活動提早結束，公告只留一張，並註明哪個規則與哪位成員的訊息觸發，不會再多貼一張內容完全相同的公告。

長路徑看得到尾端，引用和送出文字也不再少字

工具步驟顯示很長的檔案路徑時，現在會把家目錄縮成 ~，保留真正有辨識力的尾端，不再從前面硬截到看不出是哪個檔案。回答裡的檔案引用也會恢復行號，範圍能正確顯示成 path:10-25。另一個更隱密的錯誤也修好了：你送出的提示詞剛好在終端機最右邊換行時，回顯文字不會因縮排而少掉一個字。像校稿室整理長篇手稿：封面縮短前綴仍留住章節末段，引用標明行號，排到行尾也不漏字。

多選自填不會清掉勾選，背景任務也不擋輸入框

回答多選題時，先勾好的方塊不會因為填入自訂答案就被清空；你回頭改選預設選項，也不會把舊的自訂文字一起送出。這讓同時選幾項再補一句的人不必重來。背景任務很多時，輸入框下方每個進行中項目則限制為一行，不會把你要打字的位置擠到看不見。像活動報名表：補填其他選項不會抹掉已勾的場次，工作人員的處理清單也一行顯示，不會蓋住下一格讓人填寫。

設定寫入更安全，登入不再因慢鑰匙圈被迫重試

config.json 現在採原子寫入（先寫好完整新檔，再一次替換舊檔），程式崩潰或同時有別的程式寫入時，不會留下半截設定檔，害設定悄悄失效。OS keyring（作業系統保存登入密碼的保管庫）若反應慢，也從等一秒就當成空白改為等五秒，避免被迫重新登入。對話預覽標題則只取第一行、最多 500 個字元；大量貼上的提示詞不會變成數 MB 的標題。像辦公室歸檔：先完成整份文件再替換舊檔，查保管櫃較慢時多等一下，索引標籤只取首行並限字數。

Windows 路徑不再當機，子代理也會把結果送回來

Windows 上處理對話逐字稿路徑時，會尊重路徑中的磁碟機代號，轉換軌跡日誌成產物時不再因此崩潰。另一個修正在代理協作：子代理自己的訊息送不出去時，以前可能對父代理安靜消失；子代理閒置卻沒有最終回答時，父代理又會收到空通知。現在兩種狀況都補好了。像劇場控台：燈光表上的舞台代號不被換掉，燈光師傳訊失敗會回報控台；未交最後回覆就離開，也不會留下一張空白訊號紙。

讀網址不再慢慢耗光連線，額度顯示也跟得上

反覆使用 read_url_content 讀網址時，每次呼叫原本都會漏掉一條網路連線；累積久了可能耗盡電腦可用的連接埠，現在會正確關閉。連接埠（讓電腦程式進出網路的編號）像飯店房間鑰匙：客人走了就得交回，否則後來的人沒房可住。狀態列顯示的模型 quota（本次可用額度）也不再慢一輪更新，會對上你實際剩下多少。讀很多網址或盯著剩餘額度工作時，畫面終於不會給你過期數字。

English

Long documents get an outline, and Markdown alerts render properly

When a Markdown document runs long, press t to open its heading outline and jump straight to a section instead of scrolling for it. Markdown is plain text marked up with simple symbols. Alert blocks such as [!NOTE] and [!WARNING], plus carousel blocks, now render instead of showing their raw markers. It is like adding a table of contents and visible warning stickers to a dense manual.

Print mode answers more commands, with output scripts can read

When a script needs permissions, hooks, help, release notes, or config, print mode can answer -p "/permissions", /hooks, /help, /changelog, and /config without starting an agent, using quota, or leaving a conversation. It emits tab-separated rows, or structured JSON with --output-format json or stream-json. The models and agents subcommands now do the same, while errors and spinners stay off stdout. Like a market receipt: items are listed cleanly, while vendor chatter stays aside.

Skills can leave slash menu while larger toolsets still load

A growing skill library no longer has to flood the / menu. Add disable-slash-command: true to a skill's SKILL.md frontmatter and it disappears from the menu and /name lookup, while the model can still discover and invoke it. Think of moving rarely hand-picked tools into a drawer, not throwing them away. Sessions also accept more tool declarations, so heavy MCP, plugin, and skill setups are not rejected. Tool-call headers now state a short action summary for activity lists and permission prompts instead of a bare name or argument blob.

Terminal links stay clickable over SSH and across wrapped lines

URLs in an SSH session can now be opened directly, including in hyperlink-capable tmux. A URL that wraps onto another line remains one clickable link rather than losing everything after line one. URLs the Markdown renderer missed, including URLs inside code blocks, also become links. Hovering no longer highlights unrelated links, and linked lines still scroll sideways and select text correctly. Like sheet music continuing onto another line: it is still one melody.

Sign-in needs less setup, and nested Git repositories find right root

Application Default Credentials, the default cloud-account sign-in credentials, now resolve the quota project automatically, so service-account logins do not need extra setup. Repository detection also recognizes when the intended Git repository sits inside a larger multi-repository checkout. Submodules and worktrees are included. It is like airport baggage sorting: once the final terminal is identified, the bag reaches the right carousel instead of stopping at the first one.

Headless runs decide when needed and report mode mistakes

Put -p into a scheduled or automated flow and nobody is there to answer questions. It now settles a choice itself rather than waiting forever. Headless mode, meaning execution without an interactive window, also honors --mode accept-edits and --mode plan; unknown values produce a warning instead of being silently ignored. Startup crashes, missing conversations, conflicting print flags, load errors, and mode or agent warnings now reach the terminal instead of hiding in a log. Like an overnight attendant that can take a marked route and turns on a light when the instructions are wrong.

Schedules skip redundant notices and name what ended them

When a one-shot schedule ends early after receiving a qualifying message, it used to add an unhelpful Timer Cancelled notice. That duplicate notice is gone. The step result now names both the condition that was met and the sender whose message met it. Scheduling behavior has not changed; the receipt is clearer, like a club posting one notice when an event ends early and naming the rule and member message that triggered it.

Long paths, citations, and submitted prompts keep their missing pieces

Long paths in tool steps now collapse your home directory to ~, preserving the informative ending instead of chopping it off from the front. File citations regain their line numbers, so ranges render as path:10-25. A subtler issue is fixed too: if a submitted prompt wrapped at the terminal's right edge, its echoed text no longer loses one character because of indentation. Like an editor preparing a long manuscript: the cover shortens its prefix but keeps the chapter ending, citations retain line numbers, and no letter drops at a line end.

Write-ins keep multi-select choices, and tasks stop crowding prompt

In a multi-select question, adding a write-in answer no longer clears boxes you already ticked. If you go back to a predefined option, stale write-in text is not submitted either. That matters when you choose several items and add one note. With many background tasks, each active item below the prompt is now limited to one line, so the list does not push the input box away. Like an event sign-up form: adding “other” does not erase checked sessions, and a one-line staff list does not cover the next field.

Config saves safely, and slow keyrings no longer log you out

config.json now uses atomic writes: it prepares a complete new file, then replaces the old one in one move. A crash or concurrent writer cannot leave a truncated config that silently breaks settings. If the OS keyring, the store for login secrets, responds slowly, the CLI now waits five seconds rather than treating it as empty after one and forcing a login. Conversation preview titles also stop at first line and 500 characters, so a large pasted prompt cannot create a multi-megabyte title. Like office filing: complete the whole document before replacing the old file, wait a little longer for a slow records cabinet, and keep an index label to its first line and set length.

Windows paths stop crashing, and subagents report back reliably

On Windows, converting a trajectory log into a transcript artifact now honors the drive letter in its path, avoiding a crash. Agent collaboration gets two fixes too: a subagent whose own message failed to send no longer falls silent to its parent, and a subagent that goes idle without a final response no longer leaves the parent an empty notice. Like a theater control booth: a stage code stays intact, a lighting technician reports a failed message, and leaving without a final response does not leave a blank signal slip.

Reading URLs stops leaking connections, and quota display catches up

Repeated calls to read_url_content used to leak one network connection each time, eventually risking exhaustion of available machine ports; connections now close correctly. A port is a numbered network doorway for a program, like a hotel key that must be returned after checkout. The status line's model quota, the quota remaining, also no longer lags one fetch behind and now matches what remains. Heavy URL reading and quota watching no longer rely on stale numbers.
