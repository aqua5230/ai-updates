看程式碼與留言不再破圖，行號終於對準了

現在在終端機裡看程式碼產出（artifact）變得舒服多了。以前如果你寫了單行留言，或是遇到太長的程式碼自動換行、甚至折疊了複雜的圖表（像 Mermaid 圖）時，旁邊的行號就會跟著大亂，完全對不上原始檔的行數；現在行號系統整個打掉重練，保證每一行都精準對齊。如果你在程式碼裡留了一堆註解，以前捲動畫面時文字可能會爆出邊界或捲出畫面外，現在這些破圖的問題也都修好了。就像看一本有大量眉批的書，以前字太多排版就會跑掉，現在不管你加多少筆記，版面都穩如泰山。

模型能力解放，外掛與連線設定更自由

Gemini 單回合現在最多可呼叫 512 次工具。Gemini 模型（背後運作的 AI 引擎）現在一次對話最多可以連續使用 512 次工具，讓它可以一口氣幫你做完非常複雜的連環任務，不會做一半就卡住。連線外部工具（MCP 伺服器）的等待時間現在也開放讓你自訂了，如果你有啟動超級慢的工具，甚至可以設定成「無限期等待」，不再被強制中斷。安裝擴充外掛（plugin）時也更方便，現在可以直接指定 GitHub 專案底下的某個子資料夾來安裝；而且外掛裡用的特殊路徑變數（例如 ${extensionPath}），現在也終於能正確指到安裝好的位置了。就像請了個能力更強的管家，以前他跑腿只能跑三家店就會忘記，現在可以一次幫你跑五百家店；而且你也可以授權他為了買特定東西排隊等一整天，不會再被系統硬性規定趕回來。

解決當機、卡轉圈圈與設定檔被洗掉的毛病

送出訊息後不再卡在處理中。以前送出訊息後，畫面有時會卡在「處理中」的轉圈圈動畫停不下來；或者在開新對話前遇到錯誤時，系統會因為不斷跳警告而直接崩潰當機，現在這些死當問題都解決了。當你切換不同版本的 CLI 軟體時，系統不會再偷偷洗掉它看不懂的未知設定，保護你的設定檔（settings.json）原汁原味。使用 Linux 的人現在也能順利在最新的 Wayland 介面環境裡貼上剪貼簿的內容了，而且複製檔案會比複製純圖片優先處理。此外，像「存檔時間沒寫入」、「工作區路徑顯示錯誤」以及 Windows 沙盒網路卡住等問題也都一併修好了。就像老爺車進廠大修，以前油門有時會卡住、儀表板會指錯方向，連換個音響還會把你原本的冷氣設定洗掉，現在全換上了最新的零件，開起來順暢又安心。

English

Accurate line numbers and flawless layouts in the artifact viewer

Viewing generated code (artifacts) in the terminal is now a much more pleasant experience. Previously, if you left inline comments, encountered long wrapped lines of code, or collapsed complex diagrams (like Mermaid charts), the line numbers on the side would get completely misaligned with the actual source file; the gutter numbering system has been completely revamped to ensure every single line aligns perfectly. If you left a bunch of comments throughout the code, scrolling used to cause the text to bleed past boundaries or scroll entirely out of bounds; these layout-breaking bugs have all been squashed. Like reading a book heavily annotated in the margins: the layout used to warp when there were too many words, but now no matter how many notes you add, the pages stay perfectly structured.

Unleashed model capabilities, flexible MCP timeouts, and easy GitHub subpath plugins

We've removed several restrictions holding the system back. Gemini models (the AI engine powering the tool) can now make up to 512 tool calls in a single turn, allowing them to complete incredibly complex, multi-step tasks in one breath without stalling halfway. The timeout for connecting to external tools (MCP servers) is now entirely configurable; if you have a ridiculously slow-starting tool, you can even set it to wait indefinitely (-1) instead of being forcefully disconnected. Installing plugins has also become easier: you can now install them directly from a specific subfolder within a GitHub repository. Additionally, special path variables used in plugins (like ${extensionPath}) will finally resolve to the correct installed directory. Like hiring a much more capable butler: they used to forget your list after visiting three stores, but now they can visit five hundred in one go; you can also authorize them to wait in line all day for a specific item, rather than the system arbitrarily forcing them to return empty-handed.

Fixes transient spinners, crashes, lost settings, and clipboard bugs

A slew of maddening system bugs have been cured. Previously, after sending a message, the screen would sometimes get permanently stuck showing a "processing" spinner animation; or if an error occurred before starting a conversation, the system would crash itself with a stack overflow of warnings—these fatal hangs are now gone. When switching between different CLI versions, the system will no longer silently wipe out unknown fields in your settings.json, preserving your configuration exactly as is. Linux users on modern Wayland setups can now properly paste from the clipboard, with copied files being correctly prioritized over raw image data. Minor annoyances like "archived time not saving," "wrong workspace path displaying," and Windows sandbox network proxies hanging have all been fixed. Like taking an old clunker to the mechanic: the gas pedal used to get stuck, the dashboard pointed the wrong way, and simply changing the radio would somehow erase your AC settings; now it's completely overhauled with brand-new parts, driving smoothly and reliably.
