Antigravity 1.2.16

發布日期：2026-10-03

繁體中文

新功能

設定選單支援左右方向鍵，切換選項立即儲存

當你想調整工具偏好卻不想在一層層下拉選單裡反覆按確認時，現在有更快的改法。

在終端機輸入 /config 開啟設定頁面，將游標停在想要修改的項目上，直接按鍵盤的 ← 或 → 鍵，就能立刻切換到上一個或下一個選項數值並直接儲存，不需要再按 Enter 展開下拉清單。畫面最下方的頁尾也會顯示 ←/→ Change 的提示字樣。

像在電視選單按左右鍵切換訊號源或音效模式，不用每次都展開整排下拉選單再按確定，手指一撥設定就立刻生效。
新功能

全螢幕對話不再卡頓，滑鼠選取與重繪更流暢

當你在長對話中調整終端機視窗大小或用滑鼠選取文字時，畫面反應現在更加敏捷。

在無閃爍的 altscreen（終端機全螢幕顯示模式）與產出物檢視器中，拉動視窗不會再讓介面卡死，系統會優先重繪目前畫面上的訊息，不再卡在舊寬度等待整段對話重繪完畢。按 Esc 中斷代理人或恢復對話時，也不會把螢幕上的所有步驟全部重新繪製一次。使用滑鼠拖曳反白超過頂端或底端時會自動捲動，滾動滾輪或在代理人串流輸出時選取範圍都不會跑位。複製文字還能完整包含捲出畫面的行數，並自動濾除產出物檢視器中的行號與註解預覽。

彷彿閱讀排版精美的長卷軸電子書，拉大視窗時眼前文字立刻依新寬度排好，反白選取整段內容往下拉也能順暢捲動，複製時更不會把旁邊的頁碼與輔助備忘一起剪進去。
新功能

Go 指令授權更省事，編譯與檢查可永久放行

當你頻繁讓代理人編譯或檢查 Go 專案程式碼時，授權流程變得更加省心。

批准 go vet 或 go build 等安全指令時，系統現在會提供直接放行該子指令（主指令底下負責特定功能的附屬指令）所有後續參數的選項，日後帶不同參數都不必再次手動按確認。但針對會執行或安裝程式碼的 go run、go test、go generate、go install 與 go tool，這些子指令仍須以完整指令為放行範圍。

跟廚房領用食材一樣，拿取安全調味料只要登記一次就能自由取用不同份量，但遇到動用瓦斯爐或刀具等高風險操作，放行時仍須寫明完整操作內容。
新功能

排隊訊息支援合併即時送出，Vim 快捷鍵不再誤送

當你在代理人忙碌時連續輸入多條指令，訊息的排隊與召回機制現在更為可靠。

在 /config 設定中開啟排隊訊息的 Send Immediately（立即發送）時，若前面已有訊息在排隊，新送出的內容會依照先後順序連同排隊訊息一起交給代理人，不再單獨落後排隊。若訊息在回合中途發送失敗，也會自動退回佇列（排隊等候處理的清單）而不會憑空遺失。在 Vim 常規模式的最頂行按下 k 鍵時，現在會如同向上方向鍵一樣將排隊訊息抽回編輯區，修復了以前誤抓歷史紀錄導致排隊訊息重複送出的問題。

宛若在郵局櫃台寄信，臨時追加的急件能直接併入當前的包裹一起秤重寄出，如果櫃台忙碌沒收下也會退回你手上，不必重新排隊重填一張單據。
新功能

圖片生成改由專屬子代理負責，自動重試並存入產出物

當你請代理人繪製插圖或設計素材時，產圖的工作流程變得更有條理。

主代理人現在會將生圖需求轉交給內建的 image-generator 子代理（在背景協助處理特定專門任務的輔助助理）。它會負責撰寫提示詞（引導 AI 生成具體內容的描述句）、檢查每次產生的圖片，且最多會自動嘗試三次直到成功，最後將完成的圖片儲存至對話的產出物中。整個產圖過程也會在對話紀錄中明確呈現為獨立的子代理執行階段。

猶如把設計海報的工作交給專門的美編助理，他會自己琢磨提示詞並反覆微調，最多嘗試三次，最後把滿意的圖檔規矩收進專案資料夾，不再需要總指導親自逐筆摸索。
問題修復

背景指令中斷不再卡死，無頭模式精確等待結果

當代理人在背景執行的耗時指令遭遇系統強制中止或記憶體不足時，處理流程不再停滯。

以前代理人等待背景指令時，若指令當機或因記憶體耗盡遭系統終止，代理人會卡在原地等待。現在系統能正確辨識如 137 或 134 等結束代碼（程式執行完畢後回傳給系統的狀態數字）並繼續後續工作。在以無頭模式（沒有終端機視窗或視覺介面的執行模式）使用 -p 參數執行時，也修復了背景指令於第一回合後完成時代理人尚未回應程式就提前結束的問題。

就如外送平台派單給外勤騎士，就算路上機車拋錨或意外中斷，系統收到騎士回傳的異常代碼後也能立刻轉派或繼續流程，不會傻等在原地直到整家店打烊。
問題修復

子目錄可正常載入上層技能，斜線選單不再列出停用工具

當你在專案深層的子資料夾開啟工作階段時，專案層級的自訂擴充現在能完整生效。

以前若從子目錄啟動工作階段（使用者與 AI 進行的一連串連續互動對話），上層目錄 .agents/ 裡的 skills.json 與 rules.json 等自訂清單會被忽略。現在系統會從目前工作目錄一路向上至專案根目錄，完整載入各層級的設定檔。輸入 / 開啟的選單也修復了會列出當前代理人未啟用的內建技能之問題，避免選取後注入代理人無法使用的工具指令。

如同翻閱總公司與各分部的工作手冊，在分店工作也能一路向上查找總部規章，且目錄索引裡只會列出當前分店真正具備的工具清單。
問題修復

支援含 UTF-8 簽章的設定檔，Windows 儲存不再報錯

在 Windows 環境下使用記事本或 PowerShell 的 Set-Content 編輯設定檔時，檔案開頭常會自動加入 UTF-8 位元組順序記號（標記檔案文字編碼的隱藏字元）。

以前這會導致 ~/.gemini/config/config.json 無法正常載入設定，現在這個問題已經修好，能順暢讀取各類編輯器儲存的設定檔。

問題修復

修復終端機剛好滿行時的文字折行與縮排異常

當斜線指令的輸出或系統警示訊息剛好與終端機視窗等寬時，以前最後一個單字會被直接擠到下一行開頭且失去縮排，破壞閱讀版面。

現在版面排版邏輯已經修正，即便字元長度剛好貼齊邊界也能保持整齊換行與原有縮排。

English

FEATURE

Settings menu supports left and right arrow keys to switch options and save instantly

When you want to adjust tool preferences without repeatedly pressing confirm across dropdown menus, there is now a faster way.

Typing /config in the terminal opens the settings page. Highlight the setting you want to change and press ← or → on your keyboard to instantly switch to the previous or next value and save immediately, without needing to press Enter to expand the dropdown list. The footer at the very bottom of the screen also displays a ←/→ Change prompt.

Like toggling input sources or sound modes with the arrow keys on a TV menu, settings apply instantly with a flick of a finger instead of expanding an entire dropdown list and confirming every time.
FEATURE

Fullscreen chats no longer freeze, with smoother mouse selection and repainting

When you resize terminal windows or select text with a mouse during long chats, the display responds much more quickly.

In the flicker-free altscreen (terminal fullscreen display mode) and artifact viewer, dragging the window will no longer freeze the interface. The system prioritizes repainting the messages currently on screen instead of getting stuck at the old width waiting for the entire conversation to finish repainting. Pressing Esc to interrupt the agent or resume the conversation also avoids repainting all steps on screen from scratch. Dragging to highlight past the top or bottom with the mouse now auto-scrolls, and scrolling the mouse wheel or selecting text while the agent streams output will not cause selections to drift. Copying text also captures lines scrolled off screen and automatically strips line numbers and annotation previews in the artifact viewer.

Picture reading a beautifully formatted long-scroll e-book: resizing the window instantly wraps the text before you to the new width, dragging the selection downward scrolls smoothly, and copying omits side page numbers and helper notes.
FEATURE

Simpler Go command approvals allow permanent authorization for builds and checks

When you frequently have the agent compile or check Go project code, the authorization process is much easier.

When approving safe commands like go vet or go build, the system now provides an option to allow all future arguments for that subcommand, so passing different arguments later will not require manual confirmation again. However, for subcommands that execute or install code—such as go run, go test, go generate, go install, and go tool—approvals must still cover the exact full command.

Much like requisitioning ingredients in a kitchen, signing out safe seasonings once allows you to freely take different quantities later, whereas high-risk tasks like using the stove or knives still require explicit approval for each full action.
BUGFIX

Queued messages support merged immediate delivery, fixing Vim shortcut mishandling

When you enter multiple commands while the agent is busy, message queuing and recall are now more reliable.

When enabling Send Immediately in /config, if messages are already queued, newly submitted input is delivered to the agent in order along with the existing queued messages rather than falling behind in a separate queue. If message delivery fails mid-turn, the message automatically returns to the queue instead of vanishing. Pressing k on the top line in Vim normal mode now pulls queued messages back into the editor like the Up arrow key, fixing an issue where pulling history mistakenly caused duplicate submissions of queued messages.

Think of mailing items at a post office counter: an urgent addition merges directly into your current parcel to be weighed and shipped together, and if the counter fails to process it, it is returned directly to your hands without waiting in line to fill out a new slip.
FEATURE

Image generation moves to a dedicated subagent with automatic retries and artifact saving

When you ask the agent to draw illustrations or design assets, the image generation workflow is now better organized.

The primary agent delegates image creation to the built-in image-generator subagent. It handles prompt writing, inspects each generated image, and makes up to three attempts automatically until successful before saving the completed images to the conversation artifacts. The entire generation process is clearly recorded in the conversation transcript as an independent subagent execution stage.

A design lead delegates poster design to a dedicated graphic assistant, who crafts prompts, iterates up to three times, and files the finished image into the project folder without requiring the lead to tweak every detail manually.
BUGFIX

Interrupted background commands no longer hang, with accurate waiting in headless mode

When long-running background commands executed by the agent are terminated by the system or run out of memory, execution no longer stalls.

Previously, if a background command crashed or was killed by the system due to out-of-memory errors, the agent remained stuck waiting. The system now correctly recognizes exit codes like 137 or 134 and proceeds with subsequent tasks. When running in headless mode with the -p flag, it also fixes an issue where the process exited prematurely if a background command finished after the first turn before the agent responded.

A delivery platform dispatches orders to couriers: if a scooter breaks down along the route, the system receives the abnormal status code and immediately reroutes or proceeds, rather than waiting idly until the store closes.
BUGFIX

Subdirectories properly load parent skills, and slash menus omit disabled tools

When you launch a session from deep within a project subdirectory, project-level customizations now take full effect.

Previously, starting a session from a subdirectory ignored custom definitions like skills.json and rules.json in parent .agents/ folders. The system now traverses upward from the current working directory to the project root, loading configuration files across all levels. The menu opened by typing / also fixes an issue where it listed built-in skills disabled for the current agent, preventing selection from injecting instructions for tools the agent cannot use.

Consulting employee handbooks across headquarters and branches: working at a branch lets you look up company-wide policies upward, while the table of contents only lists tools actually available at that location.
BUGFIX

Configuration files with UTF-8 BOM now supported without Windows saving errors

When editing configuration files on Windows using Notepad or PowerShell's Set-Content, editors often prepend a UTF-8 byte order mark (a hidden character indicating text encoding).

Previously, this prevented ~/.gemini/config/config.json from loading settings properly. This issue has now been resolved, ensuring smooth parsing across various editors.

BUGFIX

Fixed word wrapping and indentation glitches when terminal lines are exactly full

When slash command output or system warnings match the exact width of the terminal window, the final word previously wrapped to the start of the next line while losing indentation and disrupting the layout.

The rendering logic is now fixed, maintaining clean wrapping and consistent indentation even when text reaches the exact window boundary.
