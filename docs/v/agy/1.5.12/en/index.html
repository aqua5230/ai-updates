Antigravity 1.5.12

Released: 2026-11-19

Release notes

FEATURE

Add Gemini 4 Neon with your own key

Want to test a different response style while running a project with your own Gemini key? When you connect with a GEMINI_API_KEY, Gemini 4 Neon now appears in the model list. Type /model in a conversation or pass --model at launch to pick Low, Medium, High, or XHigh.

Think of bringing your own battery to power a new tool: instead of a single mode, you get four switchable settings to adjust whenever the task calls for it.
BUGFIX

Hide unsupported features and credit warnings on your own key

Working with a GEMINI_API_KEY used to surface options and warnings on screen that could not actually be used. With this key, Remote Control, --remote-agent, and voice dictation would always fail—for example, producing a Remote Control link that never connected. Launching --remote-control or --remote-agent now exits right away with code 2. /remote-control, /voice, and /record are also left out of autocomplete and /help, and explain that they are not available with a Gemini API key. Previously, if AI credits were turned on in your settings, the status line at the bottom would also show a red AI: Out of credits warning. Because API keys do not use AI credits, that status notice and the Use AI Credits option in /config no longer appear.

FEATURE

Add split view to Remote Control browser view

Want to keep an eye on a long presentation's edits while looking up notes on the side? Previously, you could only view one conversation at a time in the browser. Now you can open several conversations side by side in the Remote Control browser view. Open the Split submenu from a conversation's menu in the sidebar or the ⋮ menu in its title bar, then choose Split Right or Split Down to split the view. This feature is not available on phones.

Picture comparing two reference books: before, you had to close one to open the other, whereas now both pages lie open side by side for a quick glance back and forth.
FEATURE

Smoother loading and typing in Remote Control browser view

Scrolling through history or typing messages in the Remote Control browser view used to run into unresponsive screens, crashes, or drafts sending too early. When scrolling up through a long conversation, Loading older messages… now appears while earlier messages load. If loading fails, Couldn't load older messages · Retry lets you retry manually instead of silently retrying every time you scroll up. Pasting @ mentions back from a Markdown export (such as Google Docs' Copy as Markdown) used to crash the browser view. Those mentions now paste as plain text, and affected conversations open normally again. Before an attachment finished uploading or while a conversation was still loading, pressing Enter used to send your message even though the send button was disabled. Now Enter waits until you can send, and your draft stays in the message box.

FEATURE

Scroll progress indicator for altscreen full screen

When scrolling way back in a long conversation to find earlier work, it is easy to lose track of how far you are from the latest reply. In full screen (altscreen) mode, scrolling up to read older messages now shows a progress line above the prompt. It displays how much of the conversation sits below your current spot, such as ↓ 25 lines · 2 turns.

Like scrolling up through an old group chat, it is easy to forget how many new replies are waiting below; this reminder line lets you see at a glance how far down you still need to go.
BUGFIX

Fix extra line breaks when copying long prompts in altscreen

Copying a multi-line prompt off the screen to revise it used to paste back fragmented, with every line cut off. That happened because selecting and copying with the mouse in full screen (altscreen) mode inserted line breaks wherever text wrapped on screen. This issue is fixed, so copying either a sent prompt or text in the prompt box now preserves it exactly as you typed it.

FEATURE

/fork now points to large artifact folders instead of copying

Midway through a conversation, if its folder is packed with project code or build files left in scratch/, running /fork to start a new branch used to mean a long wait. Now, when /fork encounters a large artifact folder, it leaves those files in the original conversation and points the forked AI agent directly to them instead of copying every file. This lets forking finish in seconds rather than waiting up to an hour, though deleting the original conversation also deletes those files.

Opening a new branch store no longer means buying a duplicate set of every sample in headquarters' warehouse: the new shop just keeps a forwarding address to inspect the original stock, though closing that main warehouse clears out those samples too.
PERF

Faster, quieter Auto mode reviews outside the sandbox

Letting the tool run tasks on its own only to get stalled on a permission prompt for a safe command quickly breaks your flow. Previously, when Auto mode reviewed commands that would leave the terminal sandbox (an isolated environment that restricts where programs can act), it took a long time and often popped up approval prompts. Now, whenever that review runs on Gemini 4 Hydrogen, it uses medium instead of high thinking, deciding faster, timing out less often, and asking you to approve safe commands less often.

A bank teller checking transfer slips used to examine every line with a magnifying glass; now they verify the key fields and stamp it right away, clearing transfers faster and asking for an in-person signature far less often.
FEATURE

Markdown headings and bold text no longer show raw markers

Reading notes or long drafts written by AI only to see unconverted hash marks or asterisks pop up makes the layout look broken. Markdown headings in AI responses and artifacts used to print ## to ###### markers at the start, looking like syntax that failed to render. Now headings show only their text, using bold, italic, or underline to set levels apart. Next to Chinese, Japanese, or Korean text, bold text that started or ended with punctuation—such as **注意：**这里—used to display the ** markers as raw text. That display bug is now fixed, and bold formatting applies properly.

Just like a manuscript after a typesetter finishes proofing, all the leftover markup symbols and guidelines vanish from the page, leaving only clean, properly weighted text.
BUGFIX

Fix turn errors on brief disconnects or wake from sleep

Flipping open your laptop to continue a conversation or hitting a brief network blip mid-response used to put your progress at risk. Previously, when your computer had just woken from sleep and the network was not ready yet, the server reset the connection, or a model response broke off partway through, the current turn stopped with an error. That is fixed—the CLI now retries these requests automatically.
