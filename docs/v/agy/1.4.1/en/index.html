Antigravity 1.4.1

Released: 2026-10-18

Release notes

FEATURE

agy plugin validate Expands Check Coverage to Guard Skills, Subagents, and Rule Configurations

Nothing is worse when packaging plugins than missing configuration settings. Now agy plugin validate guards skills, subagents, and rules.

Like a travel checklist, it previously only inspected luggage exteriors, but now it verifies document expiration dates item by item and flags any oversight immediately.

A missing SKILL.md frontmatter triggers an error. Missing name or description, folder name mismatches, exceeding 24 KB, or skipped duplicate names trigger warnings. Subagent frontmatter errors, missing fields, agent.json parsing failures, or using reserved names trigger errors. Duplicate names, files without frontmatter, or ignored agent.json files trigger warnings. Invalid rule frontmatter or a missing trigger triggers an error (skipping README.md). Missing descriptions, missing globs, exceeding 24 KB, or mistakenly placing AGENTS.md or GEMINI.md in the root directory triggers a warning.

FEATURE

Inline File Diff Previews Align with Inspection Styling, Supporting Syntax Highlighting and Tinted Changes

When you receive confirmation prompts from agents requesting to edit or create files, you can now see every modification detail directly in the conversation. Inline diff previews (screens showing file modifications directly in the conversation) now align with the /diff inspection style and support syntax highlighting for the active color scheme.

Picture annotating a contract draft with two-color highlighters: confirming changes previously relied on monotonous black-and-white plain text, but added and deleted lines are now clearly marked with dedicated tints, while the line number column stays clean and free from distracting color.

The new rendering method adds background tints to added and deleted code lines. If the Terminal color scheme is selected, the interface selects the most suitable contrast tint based on whether the terminal background is light or dark. The line number column on the left side of the screen remains untinted, preventing colored blocks from bleeding into the margin and distracting your gaze, making it easier to track line numbers during code reviews.

PERF

Terminal Rendering Adjustments Reduce CPU Consumption During Typing and Execution

When frequently typing long passages into the terminal or waiting on background computations, your computer will no longer endure spinning cooling fans from thermal strain. The prompt area now renders only once per frame and reuses measured widths of unchanged text rows across frames.

Think of flipping through an animation flipbook: previously, every page turn wiped the entire chalkboard clean to remeasure and rewrite character by character, but unchanged sections are now retained directly, and dynamic banners are styled as entire spans rather than drawn slowly glyph by glyph.

The dynamic status line (the bar at the bottom of the terminal displaying execution progress) previously rendered one character at a time, but now batches rendering by identically styled segments. Layout optimizations reduce redundant computations during redraws, noticeably lowering CPU usage while typing in the terminal or waiting for responses.

BUGFIX

Enterprise Accounts Lock Telemetry Off, Removing Consumer Telemetry Checkbox from Initial Setup

If you routinely log in using an enterprise account or a Google Cloud project, the settings interface now explicitly reflects data privacy policies. Enterprise accounts and environments authenticated via AGY_ADC_AUTH never collect prompts, file contents, or model responses in the first place, yet the telemetry toggle (a mechanism transmitting diagnostic and usage metrics) remained switchable inside the /config settings menu.

Consider an official fleet vehicle equipped with non-toggleable security standards: previously, the dashboard switch could be toggled at will to everyone's confusion, but it is now locked in the off position with an explanation attached, and delivery no longer includes an optional consumer survey form.

The Enable Telemetry row in /config now displays off (disabled) accompanied by text explaining the reason for the lock. During initial launch and configuration setup via AGY_ADC_AUTH, the screen displays only the Google Cloud Platform Terms of Service, outright removing the standard consumer telemetry consent checkbox.

BUGFIX

Older Windows Falls Back to Pre-Execution Prompts Under Sandbox Limits, Hiding Incompatible Settings

When operating on Windows 10 or Windows 11 PCs not yet upgraded to 24H2, command execution will no longer stall because the operating system lacks sandbox support. Previously, selecting sandbox permission mode on such systems caused terminal sandboxing (a secure environment confining commands within controlled boundaries) to fail during agent command startup due to lack of environment support.

Just as an amusement park ride manages safety gates, older turnstiles with incompatible sensors previously locked up completely, but the attraction now falls back to a manual ticket gate and removes unsupported wristband options from the ticket kiosk.

The command line now automatically disables the terminal sandbox and activates a fallback, prompting for confirmation before executing each command instead. The Remote Control settings popover in the browser also hides the sandbox permission option on such systems, preventing accidental selection of invalid settings.

BUGFIX

Network Disconnections Trigger Automatic Retries, Keeping Work Intact Across Laptop Sleep and Network Switches

When moving a laptop between conference rooms or waking it after closing the lid, tasks handed off to the agent will no longer easily abort midstream. Previously, when the system encountered network socket disconnections (interfaces establishing connections to transfer data between programs)—such as broken pipe, software caused connection abort, network is down, or http2: client connection lost triggered after laptop sleep or switching Wi-Fi—the conversation terminated outright with an error.

During an unstable long-distance phone call, passing through a tunnel previously dropped the line the moment the signal cut out, but calling software now redials automatically in the background to reconnect, displaying a call failure alert only when connection truly fails.

When tools encounter these disconnection errors now, they automatically initiate reconnection retries in the background. Only if retries still fail to establish a connection will the agent report a network error, no longer discarding an entire round of progress over momentary network fluctuations.

BUGFIX

Fix MCP Tool Pipeline: Immediate Crash Errors and Enforced Limits on Large Payloads

Connecting services or querying large datasets now features sturdier connection protection and memory management. When using MCP tools (Model Context Protocol, a protocol connecting AI to external tools), unexpected server process terminations previously left /mcp displaying Ready, causing subsequent tool calls to fail with client is closing: EOF. The interface now marks them as Error and cleans up closed sessions.

Much as external factory instruments behave, the control board illuminates a fault indicator and disconnects the line during a power trip instead of pretending normal operation, and it truncates oversized data streams by rule instead of overflowing the buffer.

For structured data such as large JSON payloads, requests previously bypassed single-step token limits (text units for AI processing and billing) even when marked as truncated, overflowing the model context window before auto-compaction could trigger. The pipeline now strictly enforces single-step limits.

BUGFIX

Hyperlinks with Semicolons in Responses No Longer Truncate, Opening Complete URLs on Click

When clicking web hyperlinks in terminal responses, URL parameters are no longer lost to special characters. In certain terminals or terminal multiplexers (tools dividing and managing multiple sessions in a single window), URLs provided by the agent that contained a semicolon ; were previously cut short at the first semicolon when clicked, causing browsers to open invalid pages. This issue has been fixed, and complete URLs containing semicolons now open properly.

BUGFIX

/title and /remote-control Support Uppercase Toggles, No Longer Erroring on ON

When typing slash commands into the terminal to adjust settings, you no longer need to double-check Caps Lock. Previously, when using /title to set titles or /remote-control to enable remote control, entering uppercase toggle arguments (such as /title ON or /remote-control Off) caused commands to be flagged as invalid and rejected outright. This issue has been resolved, and commands now correctly recognize and toggle settings regardless of whether uppercase or lowercase text is supplied.

Original changelogagy plugin validate Expands Check Coverage to Guard Skills, Subagents, and Rule Configurations
Improved `agy plugin validate` to also check a plugin's skills, subagents, and rules: for skills, it errors on a `SKILL.md` with missing or invalid frontmatter and warns when `name` or `description` is missing, when `name` doesn't match its folder, when the body is over the 24 KB limit, or when a skill in `skills/` is skipped because an earlier skill has the same name; for subagents, it errors on an `agents/` Markdown file with invalid frontmatter or a missing `name` or `description`, an unparseable `agent.json`, or a name reserved for a built-in agent, and warns on duplicate agent names, Markdown files in `agents/` without frontmatter, and `agent.json` files, which the CLI ignores; and for rules, it errors on a rule with invalid frontmatter or without a valid `trigger` (skipping a `README.md` in `rules/` without frontmatter), and warns on a `model_decision` rule without a `description`, a `glob` rule without `globs`, content cut to fit the 24 KB limit, or an `AGENTS.md` or `GEMINI.md` at the plugin root instead of in `rules/`.
Original changelogInline File Diff Previews Align with Inspection Styling, Supporting Syntax Highlighting and Tinted Changes
Improved the inline diff preview when the agent asks to edit or create a file so it renders like the `/diff` file view, with syntax highlighting for your color scheme, background tints on added and removed lines (picked from your terminal's light or dark background when using the `Terminal` color scheme), and an untinted line-number gutter.

Fixed agent commands failing to start on Windows versions that don't support the terminal sandbox (Windows 10 and Windows 11 before version 24H2) when a sandboxed permission mode was selected: the CLI now turns off the terminal sandbox and falls back to asking before running commands, and the Remote Control browser Settings modal hides sandboxed permission options on those systems.

Fixed an MCP server continuing to show as `Ready` in `/mcp` after its process exited unexpectedly, which left later tool calls failing with `client is closing: EOF`; the server is now marked as `Error` and its closed session is removed.
Fixed large structured tool outputs (such as JSON results from MCP tools) bypassing the per-step token limit while still being counted as truncated, which could push long conversations past the model's context window before automatic compaction ran.
Original changelogHyperlinks with Semicolons in Responses No Longer Truncate, Opening Complete URLs on Click
Fixed clickable links in agent responses whose URL contains `;` opening a URL cut off at the first `;` in terminals and multiplexers that split link sequences on semicolons.
Original changelog/title and /remote-control Support Uppercase Toggles, No Longer Erroring on ON
