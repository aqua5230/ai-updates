Antigravity 1.4.12

發布日期：2026-10-31

繁體中文

新功能

外掛的 API 金鑰可以設成選填

你剛裝好一個串接網路服務的外掛，想先試試基本功能，手邊卻還沒申請帳號。現在外掛作者可以在外掛的 auth.json 裡，把某個 API 金鑰（向線上服務證明身分的存取密碼）提供者標記成選填，做法是在那一項加上 "optional": true。它適用於不用金鑰也能用、但附上金鑰能提高限流（服務限制單位時間內請求次數的機制）門檻的服務。 標成選填後，你還沒設定金鑰時，外掛指令會把存放金鑰的那個變數當成未設定，直接以免費的限流額度發出未驗證請求。以前同樣的情況會出現 401 錯誤，或跳出要你登入的畫面。

跟逛公立展覽館一樣，以前入口一律要看會員證，沒帶就被擋在門外；現在沒登記的訪客也能領普通號碼牌入場，出示會員卡則能換到更多參觀名額。
問題修復

串流中的長表格完成後才進捲動紀錄，邊框不再歪斜

在終端機收到很長的回覆時，如果裡面有 Markdown 表格，往上翻常會看到版面亂掉。以前在串流（模型一邊生成一邊即時顯示）輸出時，表格列太早被推進捲動紀錄，也就是往上翻看得到的舊畫面，結果留下歪斜的邊框和重複的文字。現在表格各列會先留在即時畫面，等整張表格完成，才用最終欄寬推進捲動紀錄，往上翻就不會再看到錯位。

English

FEATURE

Plugin API Keys Can Now Be Optional

You've just installed a plugin that connects to an online service and want to try the basics, but you haven't signed up for an account yet. Plugin authors can now mark an API key (an access password that proves your identity to an online service) provider as optional in the plugin's auth.json by adding "optional": true to that entry. It is meant for services that work without a key but raise rate limits (caps on how many requests you can send per unit of time) when you have one. Once a key is optional and you haven't set it, the plugin's commands see the variable holding the key as unset and make unauthenticated requests at the free rate limit. Before, the same situation failed with 401 errors or asked you to sign in.

Think of a public exhibition hall: the entrance used to demand a membership card and turned away anyone without one; now walk-in visitors can take a regular ticket and enter, while members who show their card get a larger visiting allowance.
BUGFIX

Streamed Tables Now Reach Scrollback Only When Complete

When you get a long reply in the terminal that contains a Markdown table, scrolling up often showed a broken layout. Before, while streaming (showing output in real time as the model generates it), table rows reached your terminal scrollback too early, leaving misaligned borders and repeated text. Now a table's rows stay in the live view until the table is complete, then reach scrollback with their final column widths, so scrolling up no longer shows the misalignment.
