Antigravity 1.0.8

發布日期：2026-07-13

繁體中文

「模型與額度」頁面重新設計

終端機介面變得更實用也更美觀了。現在你可以像一般打指令一樣，按方向鍵「上」來找回之前打過的快捷指令（slash commands，像 /plan 這些），不用每次都重打，而且在選單裡打字時，也不會再發生「打 /conv 結果系統硬是幫你補全成 /conv-switch 並關掉選單」這種自作聰明的毛病。「模型與額度」頁面重新設計，畫面最底下的狀態列也會隨時告訴你現在用了多少額度和處於什麼執行模式。當你在看歷史對話或任務清單時，如果你的視窗太窄，系統會自動隱藏不重要的欄位以免版面擠爆，而且時間和狀態也會對齊得清清楚楚。就像你常去的咖啡廳重新裝潢，不但點單機終於會記住你常點的隱藏菜單，而且就算用小桌子，服務生也會幫你把餐盤排得整整齊齊。

解決貼上大量文字與舊電腦當機的問題

大量單行貼上不再拖慢輸入框。以前如果你一次貼上超級長（例如好幾萬字）的一行文字，輸入框會因為來不及處理而卡住很久；現在它會聰明地把它折疊成一個小圖示，不再拖垮效能。用 /btw 更省 token，並支援串流回覆，也改用一邊生成一邊印字的方式，不再斷尾。如果你用的是很舊的電腦（沒有支援硬體加速的 CPU），以前一開程式就會直接崩潰，現在也能正常打開了。另外，Windows 與部分 Linux 系統（Wayland）的剪貼簿讀取也修好了，而且系統現在會檢查剪貼簿裡的檔案大小，防止你貼上超大檔案時把記憶體整個吃光。就像換了更強的抽水馬達，以前如果一次倒太多水進去水管就會塞住甚至爆管，現在它會先幫你打包分流，連舊房子的老水管也能撐得住，而且還順便把幾個地方漏水的問題修好了。

設定檔終於寫對位置，拒絕權限後不再卡死

系統裡的設定與狀態同步現在變得更精準了。以前你用 /hooks 幫系統掛上自動執行腳本時，它會傻傻地把設定檔寫錯資料夾，導致你設定半天背後的程式卻讀不到；現在終於會乖乖寫進共用的設定檔目錄裡了。當你切換專案或加入新目錄時，你自己寫的快捷指令和技能也會立刻在自動補齊選單裡現身，不用再重開程式。如果你儲存設定失敗，狀態列現在會立刻閃紅燈警告你。另外，以前如果你拒絕了代理的某個執行權限，然後馬上又傳訊息給它，它會因為還沒從被拒絕的錯愕中回過神來而當機；現在這個「反應慢半拍」的毛病也治好了。就像你去辦公所，以前你在櫃檯填的申請單會被收進錯的檔案櫃，而且就算你剛加入新部門的通訊錄，也要等隔天大家才查得到你；現在這些資料都即時連線了，而且如果你剛拒絕推銷員，他也不會再擋在門口不讓你跟下一個客人講話。

English

Smarter UI layout and slash command history support

The terminal interface is now much more practical and better looking. You can finally press the "Up" arrow key to recall previously entered slash commands (like /plan), saving you from retyping them every time. When typing in the autocomplete menu, it will no longer mistakenly "help" you by forcefully auto-completing /conv into /conv-switch and then abruptly closing the menu. The completely redesigned "Models & Quota" page is now live, and the status bar at the very bottom will always keep you informed of your current quota usage and execution mode. When viewing your conversation history or task lists, if your terminal window is too narrow, the system will automatically drop less important columns to prevent layout chaos, while ensuring times and statuses align perfectly. Like your favorite cafe getting a remodel: the register finally remembers your secret menu orders, and even if you sit at a tiny table, the waiter still manages to arrange your plates perfectly.

Fixes performance on large text pastes, legacy CPUs, and clipboard issues

A slew of performance issues that could freeze or crash the program have been resolved. Previously, if you pasted a ridiculously long single line of text (like tens of thousands of characters), the input box would choke and freeze for ages; now, it smartly collapses it into a little placeholder icon, keeping performance smooth. When you use /btw to ask the agent for a quick favor, its replies are now faster and stream in word by word instead of getting prematurely truncated. If you're on a very old computer (with a CPU that lacks hardware acceleration), the program used to instantly crash on startup, but now it opens perfectly. In addition, clipboard reading on Windows and certain Linux setups (Wayland) has been fixed, and the system now checks the file size before reading the clipboard so pasting massive files won't devour all your RAM. Like installing a much stronger water pump: previously, dumping too much water at once would clog or burst the pipes, but now it automatically bundles and reroutes the flow so even the old plumbing in an aging house can handle it, while fixing a few leaks along the way.

Hooks save to the correct path, and denying permissions no longer causes hangs

Settings and state synchronization within the system are now much more precise. Previously, when you used /hooks to attach automated scripts, the system would foolishly write the config file into the wrong folder, meaning your backend wouldn't read anything despite all your setup work; it now correctly writes to the shared configuration directory. When you switch projects or add a new directory, any custom slash commands or skills you wrote will instantly appear in the autocomplete menu without you needing to restart the program. If saving a configuration fails, the status bar will now immediately flash a red warning alert. Additionally, if you denied an agent's permission request and then immediately sent it a new message, the backend used to hang because it hadn't finished cleaning up after the denial; this "slow reaction" bug is now cured. Like visiting a government office: the application forms you filled out at the counter used to be filed in the wrong cabinet, and if you just joined a new department, it took a whole day before anyone could find you in the directory; now everything is instantly synced, and if you turn away a salesperson, they no longer block the doorway preventing you from talking to the next person.
