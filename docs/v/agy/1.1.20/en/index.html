Antigravity 1.1.20

Released: 2026-08-25

Release notes

FEATURE

Skills gain icons without throwing terminal lists out of line

When you open /skills to find a familiar skill (a reusable set of work instructions), each one can now show the emoji icon it declares.

The icon lives in metadata.icon at the top of its SKILL.md file. It appears in the /skills catalog, detail headers, and slash-command autocomplete popups.

It is like putting a small picture on every drawer in a toolbox, so your eyes find the right one first.

The terminal also calculates the display width of multi-byte Unicode characters correctly, keeping the columns aligned after icons arrive.

FEATURE

@ path completion can now find empty folders too

Typing @ to name a file path but remembering only its empty folder used to leave you stranded.

Path autocomplete now indexes empty directories too, instead of seeing only places where search results already contain files. This includes workspace structures made up solely of folders with no contents yet, so you can find the directory in the completion list and keep navigating.

It is like a mall map that labels vacant units as well as open shops, so the route does not vanish halfway there.
FEATURE

Default review mode stops repeatedly asking to read workspace files

Repeated approval prompts can break up a simple inspection when a tool only needs to read or list files under the workspace root.

Default review mode (a mode for examining content) now automatically grants workspace-scoped read access, so those two actions no longer need repeated confirmation.

It is like getting a library reading pass before checking the catalog and turning the pages inside.

The boundary remains: changing files or accessing anything outside the workspace still asks for confirmation.

PERF

Git status checks avoid an extra sweep through submodule worktrees

In a Git repository with submodules (nested projects that keep their own version history), a status check can spend its time recursively scanning each submodule worktree.

Repository inspection now skips that sweep to remove status latency, while still tracking updates to the commit pointer each submodule uses.

It is like checking an apartment building's mailboxes by seeing whether each door label changed, without entering every apartment on every visit.
BUGFIX

Print mode no longer marks a run failed over benign tool errors

When you put the CLI into an automated flow, print mode with -p or --print used to mark the whole run as failed and return a non-zero exit code for benign tool errors or permission denials.

That is now fixed for --output-format json and stream-json too. A non-interactive run reports failure only for a cascade-level failure (one that reaches the overall run), matching an interactive session.

A delivery should not be marked undelivered merely because one napkin is missing.

Local trouble no longer mislabels the whole result.

BUGFIX

Startup no longer truncates settings it cannot parse

If you maintain settings.json yourself, an unrecognized setting value or syntax mistake should not make startup overwrite what was already there.

On encountering either one, the CLI now preserves the existing file on disk instead of saving a truncated version.

It is like a cashier who cannot read one note in a ledger leaving the original ledger on the desk, rather than tearing out every page except the puzzling one.

You can return to fix that entry without first rescuing the rest of your settings from a damaged file.

BUGFIX

Built-in customizations appear even without an explicit agent config

Without an explicit agent configuration (the data that configures an agent), /skills, /plugins, /agents, and /hooks could say no customizations were found, making built-in content seem absent.

Their listing views now mount built-in customizations before showing the list, so they appear even with no agent configuration specified.

It is like a gallery desk turning on the lights for the permanent collection first, so you can see what was already in the building.

This changes the listing view; it does not require you to create an agent config.

BUGFIX

Streaming CJK drafts stop gaining stray spaces

While a CJK draft (Chinese, Japanese, or Korean text) streams into the main prompt, stray spaces could appear between characters and make the sentence look pulled apart.

Streaming transcript updates now normalize whitespace at their boundaries, preventing those unwanted inserts.

It is as though a typesetter smooths the join before attaching the next strip of paper, so the letters do not suddenly spread apart.

The fix applies to streaming updates in the main prompt and keeps the draft at its intended spacing.

BUGFIX

The conversation spinner stops waking the CPU after a turn ends

After a conversation turn had already finished, the spinner (the rotating animation that signals processing) could keep ticking in the background.

That loop now stops when the turn completes, so an idle CLI no longer causes unnecessary CPU wakeups from it.

It is like a shop's queue light going dark after closing instead of glowing pointlessly and repeatedly starting equipment inside.

No setting is required; the fix is for the background animation that kept running after completion.
