Antigravity 1.5.4

Released: 2026-11-10

Release notes

FEATURE

agy acp adds Auto mode, speeding up out-of-sandbox command reviews with a lightweight model

If you are used to co-editing code in your editor through agy acp, you can now enjoy the convenience of automatic execution. As long as the command line interface offers Auto mode, the editor can switch the current session to auto. Once enabled, the tool automatically approves edits inside the workspace and runs commands in the terminal sandbox. If a command intends to leave the sandbox, it still pauses to ask for your permission unless the review clears it.

Think of hiring an on-site secretary to handle official paperwork: previously every invoice required a handwritten signature, whereas routine in-office expenses are now approved directly and only special cross-department payments are passed to a manager for quick review.

For reviewing commands that leave the terminal sandbox, a lighter-thinking Gemini Flash model now handles the review, making review decisions faster and reducing the chances of timeouts.

FEATURE

Hook input data expands to let a single command identify events, directories, and tool calls

When you write custom scripts to listen to various AI operations, you can now directly obtain richer contextual details. In the JSON input received by hooks (small programs triggered by specific events), three new fields have been added: hookEventName, cwd, and toolCall.id. This allows a single hook command to handle multiple different events while knowing the agent's current working directory at any time. When a PostToolUse call is emitted after tool execution finishes, it can also accurately match the PreToolUse call prior to execution using the identifier.

Picture a courier mailroom log sheet: previously the receipt slip carried only a single stamp and could not identify which building received the delivery, but now the slip prints the event type, office location, and tracking code so the same clerk can tie the sign-offs before and after dispatch together.
BUGFIX

agy acp session fixes: reloads preserve custom modes and second authorizations no longer hang

When reconnecting or resuming an existing conversation through an editor, operating modes and authorization prompts now continue smoothly. Previously, when an editor reloaded or resumed an open session, it dropped back to the default mode. Even if you had previously switched to accept-edits mode to automatically accept modifications, file writes still asked for permission confirmation again. Sessions now fully retain their original settings without asking repeatedly. When a tool call needed a second permission approval (such as a command asking for confirmation again after its first approval), conversation turns previously hung and waited indefinitely. Editors now properly receive the new permission request, allowing you to complete authorization smoothly.

BUGFIX

Subagent window and interaction fixes: narrow terminal prompts no longer crash or freeze the display

When you delegate tasks to subagents (auxiliary agents that run divided work independently in the background), window interactions are now more stable. Previously, if the terminal window was overly narrow or its dimensions had not yet been detected, drawing a subagent's question or approval prompt caused the tool to crash. While you were answering a question, the prompt box could also close on its own, and switching the view could occasionally freeze the terminal. These issues have now all been resolved, preventing unexpected workflow disruptions.

BUGFIX

Conversation browsing and expanded view fixes: paging no longer skips lines and thinking blocks align properly

When scrolling up and down through long conversations in the terminal, the display no longer unexpectedly skips lines or misaligns formatting. Previously, when paging with PgUp and PgDn, scrolling down could jump past an entire message if a page ended right on a message boundary. In full screen (altscreen) rendering mode, text lines hidden under the pinned prompt header were also skipped during scrolling without ever being shown on screen. Additionally, when pressing Ctrl+O to switch to the expanded view, a thinking block immediately following a tool result line (such as Read 22 lines) was previously indented further, making it look like part of that tool call. Layout and scrolling have now both been repaired, ensuring you won't miss messages when reviewing complete history.

BUGFIX

Remote connection and sign-in credential fixes: resolving boot disconnections, key size limits, and permission update prompts

When connecting across devices or managing account credentials, various issues with boot connections and authorization updates have been resolved. If the remote-control background service started before the network was ready (such as right after booting), it previously disconnected permanently and printed an invalid sign-in link, which has now been fixed. When data stored in credential stores (places that store login proofs) such as Windows Credential Manager or macOS Keychain grew too large, the Gemini Enterprise plan was previously lost and caused permission errors, and affected data is automatically repaired the next time it loads. The Sign-in update needed warning that prompts running /logout to sign in again was previously omitted in --remote-agent sessions, and is now properly displayed.
