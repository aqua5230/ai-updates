Antigravity 1.4.8

發布日期：2026-10-27

繁體中文

新功能

/diff 支援按鍵跨輪次跳轉，大專案變更即時開啟並在背景載入

當你在大型專案或多輪對話中打開 /diff 查看變更時，介面不再需要等全部檔案掃描完才顯示。

就像餐廳出餐，招牌熱菜先上桌讓客人享用，慢燉的湯品則在後廚繼續準備，不必整桌乾等。

現在已追蹤變更與 Commit Tree 會立即出現，未追蹤檔案改在背景載入；Per Turn 則先顯示最新輪次並快取（把算過的結果暫存起來直接用），舊輪次於背景載入。在 Per Turn 中可按 [ 與 ] 循環跳至相鄰輪次首個檔案，狹窄終端機的按鍵提示也會折成兩列。超過 1 MB 與二進位檔案改以附註標記而不載入記憶體，未追蹤檔案中以 ++ 加空格開頭的行，也不再被錯誤顯示，載入中途刪除檔案也不再讓清單失敗。

效能優化

Auto 模式沙盒指令審查放寬至 10 秒，減少安全指令手動確認

如果你平時習慣開啟 Auto 模式讓代理自動執行指令，遇到需要跳出終端機沙盒的操作時常會被打斷。

跟高速公路的電子收費車道一樣，感應系統有多一點時間辨識車牌，十秒內確認正常就直接抬桿，不再動輒把駕駛轉去人工收費亭。

例如當你請代理下載專案依賴或檢查遠端環境時，審查機制現在有更充裕的時間做出判定。只要單一緩慢檢查達到 10 秒就會及時停止，避免無謂等待。這有效降低了審查逾時的機率，遇到安全無虞的指令時，介面不再動不動就跳出手動確認詢問你。

問題修復

外掛安裝輸出與格式驗證改進，並修復邊車常駐程序記憶體洩漏

管理或開發擴充外掛時，更詳細的終端機回饋能讓你迅速掌握安裝與驗證狀態。執行 agy plugin install 會明確列出安裝的技能、代理、規則、指令與掛鉤（特定事件發生時被觸發的小程式）。清單也會列出安裝的 MCP（Model Context Protocol，讓 AI 連接外部工具的協定）伺服器，不再把未包含的元件型別列為略過，並印出安裝資料夾與覆寫提示。agy plugin validate 會檢查 plugin.json 的 author、homepage 與 repository，若網址非 https:// 或格式不合便提出警告，物件格式的作者名也能在清單正常顯示。以前在長時間工作階段執行邊車（sidecar）外掛會殘留背景任務導致記憶體外洩，這個問題也已修好。

問題修復

對話與子代理生命週期修復，恢復對話降低 10% 處理器負擔

當你接續先前的對話紀錄、或從現有討論中分岔出額外任務時，往往涉及多個背景處理程序。

如同施工工班的調度日誌，接續進度時不重複念出已完工的項目，分派支援小組時切斷總工程的死線牽制，撤場時則徹底拆除臨時搭建的工寮。

現在恢復對話時不再重複渲染已經完成的工具呼叫，可省下約 10% 的處理器運算資源。從帶有 /goal 目標的對話分岔出新討論、/btw 旁支提問或衍生子代理時，繼承的目標會在分岔點自動取消，避免新工作階段停不下來。同時，自訂代理的名稱若含有冒號，過去導致子代理無法啟動的錯誤已獲修正。而當你刪除對話時，執行中的子代理、已存歷史紀錄與共享或分支工作區都會一併停止並清除。

問題修復

工具呼叫失敗明確回傳錯誤狀態，代理能接續自行復原

當代理呼叫外部工具時，執行結果是它決定下一步動作的依據。以前呼叫不存在的工具、或是呼叫被取消與中斷時，這些失敗會被當成一般正常結果傳回給代理，導致它無法察覺異常。現在這類失敗都會被明確視為錯誤回傳，代理能在下一步辨識問題並接續自我復原。

問題修復

Windows 貼上圖片支援常見格式，剪貼簿被佔用時自動重試

在 Windows 系統中，從其他應用程式複製圖片貼進終端機時常會遇到阻礙。以前如果圖片是從瀏覽器、剪取工具（Snipping Tool）或其他將 PNG 或 V5 點陣圖資料放入剪貼簿的程式複製，貼上動作無法順利讀取。現在這些格式已能正常支援，且當剪貼簿被其他程式短暫佔用時，貼上功能會自動重試。

English

FEATURE

/diff supports key-based turn jumping, opening large repository changes instantly with background loading

When you open /diff to inspect changes in large repositories or long conversations, the interface no longer waits for all files to finish scanning before displaying.

Just like restaurant service where signature hot dishes are brought out immediately for diners while slow-simmered soups keep cooking in the kitchen, nobody has to wait idly for the entire meal.

Tracked changes and Commit Tree now appear immediately while untracked files load in the background, and Per Turn displays the newest turns first and caches them while older turns load in the background. In Per Turn, you can press [ and ] to jump cyclically to the first file of adjacent turns, and key hints now wrap onto two rows on narrow terminals. Files over 1 MB and binary files are noted instead of being read into memory, lines starting with ++ followed by a space in untracked files are no longer displayed incorrectly, and deleting a file mid-load no longer causes the entire list to fail.

PERF

Auto mode sandbox command review extended to 10 seconds, reducing manual approvals for safe commands

If you regularly use Auto mode to let the agent run commands automatically, operations that need to leave the terminal sandbox often interrupt you.

Much like an electronic highway toll lane where sensors get extra time to read license plates and lift the gate directly once verified normal within ten seconds, drivers are no longer routinely diverted to manual toll booths.

For example, when you ask the agent to download project dependencies or inspect remote environments, the review mechanism now has more time to decide. Any single slow check stops promptly after reaching 10 seconds to avoid unnecessary waiting. This effectively reduces the chance of review timeouts, so the interface no longer constantly prompts you for manual approval on safe commands.

BUGFIX

Plugin installation output and format validation improved, with sidecar memory leak fixed

When managing or developing extensions, more detailed terminal feedback helps you quickly grasp installation and validation status. Running agy plugin install now explicitly names installed skills, agents, rules, commands, and hooks (small programs triggered by specific events). The list also names installed MCP (Model Context Protocol, a protocol connecting AI to external tools) servers, stops listing unincluded component types as skipped, and prints the installation folder along with an overwrite notice. agy plugin validate now checks the author, homepage, and repository fields in plugin.json, warning if a URL is not https:// or has an invalid format, while author names in object format now display properly in plugin listings. Previously, running sidecar plugins during long sessions left behind background tasks that led to memory leaks, which has now been fixed.

BUGFIX

Conversation and subagent lifecycles fixed, with resuming reducing CPU load by 10%

When you resume an earlier conversation history or fork additional tasks from an existing discussion, multiple background processes are often involved.

A construction crew dispatch log works the same way: resuming progress avoids reading off already finished items, dispatching a support squad cuts ties to the master project's deadline, and clearing the site thoroughly dismantles temporary work sheds.

Resuming a conversation now avoids rendering already finished tool calls a second time, saving about 10% in CPU computing resources. When forking a new discussion, /btw side question, or subagent from a conversation with an active /goal, the inherited goal is automatically canceled at the fork point, preventing the new session from being unable to stop. Meanwhile, an issue where custom agent names containing a colon prevented subagents from starting has been fixed. When you delete a conversation, running subagents, saved histories, and shared or branched workspaces are now stopped and cleaned up together.

BUGFIX

Failed tool calls explicitly return error status, enabling agents to self-recover

When an agent calls external tools, execution results serve as the basis for deciding its next move. Previously, calls to nonexistent tools or calls that were canceled or interrupted were passed back to the agent as ordinary normal results, leaving it unaware of any issues. Such failures are now explicitly returned as errors, allowing the agent to recognize the problem on its next step and proceed with self-recovery.

BUGFIX

Image pasting on Windows supports common formats, retrying automatically when clipboard is busy

In Windows, pasting images copied from other applications into the terminal often ran into obstacles. Previously, if images were copied from a browser, Snipping Tool, or another app that placed PNG or V5 bitmap data on the clipboard, pasting failed to read them properly. These formats are now supported normally, and pasting automatically retries when the clipboard is briefly held by another program.
