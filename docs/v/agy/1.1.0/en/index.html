Antigravity 1.1.0

Released: 2026-07-13

Release notes

FEATURE

Previews diffs before editing files by default, and lets you cycle agent modes directly from the panel

Before writing or modifying files, the system now defaults to pausing and clearly showing the differences.

Previously, the program might silently change files; now, it pops up an interactive line-level diff preview so you can review and decide whether to accept the edits. New file creations also get their own dedicated preview, and if you try to close the diff view with unsent comments, the system will politely warn you. You also no longer need to edit config files or pass startup arguments to switch execution modes (like accept-edits for direct writing or plan for just planning) — you can now cycle through them directly by pressing shift+tab, or instantly apply them via the Agent Mode option in the /settings panel. The old /planning and /fast slash commands have also been consolidated into a cleaner /plan. Like getting a haircut: the barber used to just start snipping right after you spoke, but now they default to holding up a mirror and pointing out exactly what they're going to cut before you nod, and if you want to switch to a "just cut it" mode, you just tap a button next to your chair.

FEATURE

Smarter UI layouts, with accurate keybinding hints and correctly localized timestamps

The interface layout is now much tidier when you view tasks or rename conversations, and the hints no longer confidently give you the wrong instructions.

Previously, the keybinding hints at the bottom of the screen were hardcoded; even if you modified your custom keybindings file (keybindings.json), the screen would still display the default keys. Now, it accurately reflects your custom bindings. When renaming a conversation in the /resume picker, the input box dynamically adjusts its width, and metadata columns properly align to the right, preventing the screen from jumping around while you type. Full-screen panels (like settings or changelogs) will also stop flashing redundant "Press ? for shortcuts" or "Esc to cancel" messages that clutter the view. Moreover, background task timestamps no longer blindly display UTC; they now correctly convert to your local timezone. Like walking through a museum: the old entrance maps used to be outdated and plastered with irrelevant "Walk Up" arrows, but now every signpost perfectly syncs with the latest map in your hand, and the operating hours are finally shown in your local time.

BUGFIX

Fixes path and directory misjudgments, stopping innocent file creations from being blocked

Creating or reading files inside your own workspace will no longer inexplicably trigger system warnings.

Previously, due to a flaw in path resolution, the tool confirmation dialog would misjudge perfectly valid in-workspace actions and throw an "outside workspace" warning; this is now fixed. If you kept your project inside a parent directory that started with a dot (like .parent_dir/project), the system used to fail to start because its exclusion filters were overly broad; it now correctly limits its checks to paths within the workspace. When creating a new agent, the panel now points to the correct global config directory (~/.gemini/config/), and the header no longer mistakenly lists the extension as agent.json when it should be agent.md. Like entering your own office building: the security guard used to ban you from working just because the road you took was named ".dark_alley", or warned you for "trespassing" while you were sitting at your own desk; now the guard finally recognizes you and knows the actual boundaries of the company.

Added a dedicated `"Create file"` confirmation preview for new file creations (`write_to_file` without overwrite): renders new content as an addition-only diff preview.

Improved file-edit diff preview rendering: computed accurate line-level diffs with context lines (`3` lines) and hunk separators, capped inline preview height with truncation hints, and added a comment confirmation prompt when exiting the diff view with unsent comments.
