Antigravity 1.1.0

發布日期：2026-07-13

繁體中文

預設改檔前先讓你看差異，還能直接用面板切換代理模式

改檔前你會先看到差異，可決定是否接受。，會預設先暫停並清楚秀出修改前後的差異。以前程式可能不作聲就把檔案改了，現在它會跳出精細到每一行的差異預覽（diff preview），讓你能先檢查並決定要不要接受；如果是建立新檔案，也會有專屬的預覽畫面，而且如果你在看差異時留了註解還沒送出就想關掉，系統也會貼心提醒你。你也不用再為了切換這些執行模式（像是不問就直接改的 accept-edits 或只規劃的 plan）而去改設定檔或加啟動參數，現在按 shift+tab 就能直接輪替切換，或到 /settings 面板裡用「代理模式」選項點一下就立刻生效。舊版的 /planning 與 /fast 快捷指令也一併整併成更簡潔的 /plan。就像去剪頭髮，以前理髮師可能聽完就直接動刀，現在他預設會先拿鏡子比劃給你看要剪哪裡，你點頭了他才剪，而且你想換成「不廢話直接剪」模式，只要在座位旁的面板點一下就行。

介面排版更聰明，快捷鍵提示與時間顯示不再錯亂

你在各個面板看任務或改名時，畫面變得更整齊，提示也不會再牛頭不對馬嘴了。以前底部的快捷鍵提示是寫死的，就算你自己改了快捷鍵設定檔（keybindings.json），畫面上還是教你舊的按法；現在它會乖乖照你改的顯示。在 /resume 裡幫對話改名時，輸入框會自動調整寬度，旁邊的資訊也會好好靠右對齊，不會因為你打字就讓整個畫面亂跳。全螢幕面板（像設定或更新日誌）裡也不會再跑出多餘的「按 ? 看快捷鍵」或「按 Esc 取消」來干擾視線。另外，背景任務的時間戳（timestamp）也不會再傻傻顯示格林威治標準時間（UTC），現在都會自動換算成你所在地的時間。就像看展覽，以前每個展區門口的導覽圖都是舊版的，有些地方還貼著不相干的「往上走」箭頭，現在所有告示牌都跟你手上的最新地圖同步，而且營業時間也終於換成你熟悉的本地時間了。

修好各種路徑與目錄誤判，建新檔案不再被無辜阻擋

你在自己的工作目錄裡建立或讀取檔案，不會再莫名其妙被系統警告了。以前因為路徑判斷的瑕疵，就算你明明在正確的資料夾裡做事，工具確認對話框還是會誤判並跳出「超出工作目錄外」的警告；現在這個問題修好了。如果你把專案放在名稱有加點的前置目錄（像是 .parent_dir/project），以前系統會因為過濾規則太廣而啟動失敗，現在也懂得只管目錄裡面的事而不會亂擋。建立新代理時，面板上的路徑終於指向正確的設定檔總目錄（~/.gemini/config/），標題也不會再把應該是 agent.md 的附檔名錯寫成 agent.json。就像進自己公司辦公室，以前警衛會因為你走過的路名叫「.暗巷」就不准你上班，或者明明在自己座位上辦公卻被警告「擅闖禁區」，現在警衛終於認得你而且認得公司的範圍了。

English

Previews diffs before editing files by default, and lets you cycle agent modes directly from the panel

Before writing or modifying files, the system now defaults to pausing and clearly showing the differences. Previously, the program might silently change files; now, it pops up an interactive line-level diff preview so you can review and decide whether to accept the edits. New file creations also get their own dedicated preview, and if you try to close the diff view with unsent comments, the system will politely warn you. You also no longer need to edit config files or pass startup arguments to switch execution modes (like accept-edits for direct writing or plan for just planning) — you can now cycle through them directly by pressing shift+tab, or instantly apply them via the Agent Mode option in the /settings panel. The old /planning and /fast slash commands have also been consolidated into a cleaner /plan. Like getting a haircut: the barber used to just start snipping right after you spoke, but now they default to holding up a mirror and pointing out exactly what they're going to cut before you nod, and if you want to switch to a "just cut it" mode, you just tap a button next to your chair.

Smarter UI layouts, with accurate keybinding hints and correctly localized timestamps

The interface layout is now much tidier when you view tasks or rename conversations, and the hints no longer confidently give you the wrong instructions. Previously, the keybinding hints at the bottom of the screen were hardcoded; even if you modified your custom keybindings file (keybindings.json), the screen would still display the default keys. Now, it accurately reflects your custom bindings. When renaming a conversation in the /resume picker, the input box dynamically adjusts its width, and metadata columns properly align to the right, preventing the screen from jumping around while you type. Full-screen panels (like settings or changelogs) will also stop flashing redundant "Press ? for shortcuts" or "Esc to cancel" messages that clutter the view. Moreover, background task timestamps no longer blindly display UTC; they now correctly convert to your local timezone. Like walking through a museum: the old entrance maps used to be outdated and plastered with irrelevant "Walk Up" arrows, but now every signpost perfectly syncs with the latest map in your hand, and the operating hours are finally shown in your local time.

Fixes path and directory misjudgments, stopping innocent file creations from being blocked

Creating or reading files inside your own workspace will no longer inexplicably trigger system warnings. Previously, due to a flaw in path resolution, the tool confirmation dialog would misjudge perfectly valid in-workspace actions and throw an "outside workspace" warning; this is now fixed. If you kept your project inside a parent directory that started with a dot (like .parent_dir/project), the system used to fail to start because its exclusion filters were overly broad; it now correctly limits its checks to paths within the workspace. When creating a new agent, the panel now points to the correct global config directory (~/.gemini/config/), and the header no longer mistakenly lists the extension as agent.json when it should be agent.md. Like entering your own office building: the security guard used to ban you from working just because the road you took was named ".dark_alley", or warned you for "trespassing" while you were sitting at your own desk; now the guard finally recognizes you and knows the actual boundaries of the company.
