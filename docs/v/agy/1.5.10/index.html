Antigravity 1.5.10

發布日期：2026-11-17

繁體中文

新功能

--remote-agent 新增編輯自動放行模式

開啟遠端代理工作階段後，現在每改動工作區裡的檔案前都會跳出詢問，跟以前直接改完不太一樣。覺得逐一確認太繁瑣，按 Shift+Tab 就能在預設模式與 accept-edits 模式之間切換，不再沒反應。 新開啟的工作階段依然從預設模式開始，切到 accept-edits 後，代理改檔案就會直接進行、不再每次發問。

交給剪輯師修影片時，預設改成他每剪一刀都先給你看過才動手；確認方向對了，再切到直接放行模式讓他順順改下去。
新功能

/model 新增 Orchestrator 模型

以 Gemini Enterprise 帳號或 AGY_ADC_AUTH 應用程式預設憑證登入，若帳號能選取 Carbon 與 Hydrogen 這兩個模型，/model 就會出現 Orchestrator。它會先讓 Gemini 4 Carbon (High) 擬定計畫。接著交由 Gemini 4 Hydrogen (High) 接手執行。 方案若含多種規劃者，Orchestrator (Carbon) 會整併進單一 Orchestrator 列。另一列 Orchestrator (Argon) 也收進來，可用 ←、→ 或 Tab 切換 Planner。至於 --model 指令參數與已存設定，仍使用原本的完整名稱。

裝潢房子時，一位建築師先畫好整套藍圖，再交給工班主任按圖施工，你也能在同一窗口直接指定建築師。
新功能

遠端控制網頁新增對話導覽軌道

在長對話裡來回翻找先前的指令，滑鼠滾輪常要捲老半天。遠端控制網頁版新增了對話導覽軌道，你送出的每則提問都會在軌道上留下一道標記。 把游標停在標記上就能預覽該則提問，點一下直接跳過去；習慣用鍵盤的話，按 [ 或 ] 也能跳到上一則或下一則提問。

聽長篇廣播節目時，以前想找前面某段得一路盲拉進度條，現在軸線上直接標出每個段落，停上去預覽、點一下就能直達。
新功能

遠端控制網頁新增 Quote 引用按鈕

想針對代理長篇回覆裡的某一段繼續追問，現在不必自己手動複製再整理。在遠端控制網頁版選取代理回覆中的任意文字，點擊 Quote 按鈕，這段話就會以引用格式放進你的下一則訊息。

新功能

遠端控制網頁的網址可按鍵直接開啟

訊息裡貼了網址想順手點開，過去還得反白複製到新分頁。輸入框裡打好的網址，以及你已送出的訊息裡的網址，現在都能直接點開。 在 Mac 按 Cmd+click、Windows 與 Linux 按 Ctrl+click，或按滑鼠中鍵就能開啟連結，單純左鍵點擊依然只會放置游標。

新功能

遠端控制網頁計時器顯示剩餘倒數

代理在背景設定計時器後，你不用自己推算還要等多久。遠端控制網頁版的 Background Tasks 清單裡，每個運作中的計時器都會顯示像 59m left 這樣的剩餘倒數。 若是當下只有計時器在跑，狀態列也會跟著顯示例如 Waiting for 1h timer · 59m left 的進度。

新功能

遠端控制網頁側邊欄保留分頁並增設總覽

遠端控制網頁版把頁面重整後，原本打開的檔案或檢視畫面不再跟著消失。側邊欄裡開啟的檔案與檢視內容現在會以分頁保留，重新整理網頁後照樣會恢復。 側邊欄也新增了 Overview Panel，可從標題列點開，或按 Cmd+Option+O 叫出。Windows 與 Linux 快捷鍵則是 Ctrl+Alt+O，裡面會列出對話的產物、修改過的檔案、子代理與背景任務。

辦活動時，以前重整場地就把各組資料夾全收掉，現在攤開的分頁都留在原位，旁邊還多了張總表一次看清誰在忙什麼。
新功能

限流等待重試上限放寬至 4 分鐘

模型暫時塞車，這一輪對話不會動不動就被迫中斷。當模型介面要求稍候再試，指令列工具現在會等到最多 4 分鐘並自動重試，不再像過去只要等待超過 30 秒就直接結束這一輪。 因此每分鐘頻率限制與容量上限不會再打斷你的進度；不過一旦遇到消費上限、預付餘額不足或每週額度用盡的錯誤，則會立刻停止該輪。

排熱門餐廳一樣，以前等超過半分鐘沒位子就直接走人，現在只要還會翻桌就願意多等一會；但要是折價券或額度用光，就立刻改天再來。
效能優化

長工作階段切換對話更快也更省記憶體

對話開久了之後來回切換，常會卡頓又佔記憶體。現在用 /resume <id> 切回已開啟的對話，或用 /fork 分岔後切換，都不再先把整份歷史載入，因此不再停頓一秒以上。/btw 和 /help 這類旁白提問也啟動得更快。 記憶體管理也跟著調整：工作階段開啟期間，指令列工具只保留最近用到的對話步驟，舊步驟等需要時再從硬碟重讀。每輪開始時也不再載入先前所有子代理的完整紀錄，跑過大量子代理時原本可能吃掉數 GiB 的空間。

在廚房備料時，以前把整週食材全攤在流理台差點沒位子切菜，現在只留當下要用的，其餘先收進儲藏室隨用隨拿。
新功能

全螢幕模式可點擊項目懸停會發亮

使用 full screen (altscreen) 全螢幕模式，游標移過去常分不清哪裡能點開。現在只要把游標停在可點擊的項目上，畫面就會高亮標示。 這些項目包含 (ctrl+o to expand) 展開提示、思考內容、展開後的工具群組，以及釘選在畫面的提問。

新功能

終端機沙盒預設封鎖讀取設定目錄

許多軟體會把帳號設定與 token（授權令牌）存在系統資料夾，過去受限指令也能直接查看。現在終端機沙盒預設會擋下 ~/.config 或 XDG_CONFIG_HOME，在 Windows 也會擋下 AppData\Roaming。 不過 Git、Go、npm 與 Python 等常見開發工具的設定依然可以讀取，而 ~/.git-credentials 則改為預設封鎖。如果確實需要讓指令讀取其他路徑，你還是能在沙盒規則裡明確放行。

請人來家裡修家電時，以前連臥室抽屜都沒關任他查看，現在先把放存摺和印章的抽屜鎖好，只留維修需要的工具箱。
問題修復

修正 Auto 模式忽略工作區外存取設定

明明已在 /config 開啟 Non-Workspace Access，讓工具讀取工作區以外的檔案，以前在 Auto 模式下卻還是會跳出核准詢問。這個問題已經修好，Auto 模式現在會依照這項設定放行。

問題修復

高思考強度長回覆靜默上限延至 10 分鐘

請模型進行高思考強度的長篇處理時，以前只要它在思考過程中超過 5 分鐘沒有回傳任何內容，就會被判定卡住而整段取消重來。這個問題已經修好，指令列工具現在最多會等待 10 分鐘。

問題修復

修正讀取超大檔案後報錯或過早壓縮

對話還沒壓縮過，就讓代理讀取動輒好幾 MB 的 PDF 等超大檔案，過去很容易出狀況。這一輪可能會報錯 model output must contain either output text or tool calls，或是遠早於需要時就提前壓縮，現在這個問題已經修好。

問題修復

修正特定時機新建對話失效問題

指令列工具剛啟動，或透過 agy acp 連線的編輯器正在重整已存工作階段清單的瞬間建立新對話，過去偶爾會發生順序衝突。這會讓新對話每則訊息都報錯 trajectory not found，連重開都救不回，現在這個問題已經修好。

問題修復

修正 agy acp 背景任務回報與停止時機

透過 agy acp 把代理接進編輯器後，該輪結束時若背景任務或子代理完成並喚醒代理，過去回覆、工具呼叫和權限請求會被扣住，等到你送出下一句才看得到。現在這些訊息會即時送到編輯器，代理不再卡在編輯器根本沒顯示的權限詢問上。 當編輯器取消提示詞或關閉工作階段後，屬於該工作階段的子代理與開發伺服器等背景任務，過去會繼續留在背景運作、甚至重新喚醒對話。現在取消或關閉都會把它們停下來，而且關閉工作階段時，就算沒有提示詞在執行也照樣停止。

問題修復

外掛啟停登入與技能命名修復

從 /plugin 裝完外掛立刻登入並貼上代碼，過去可能會失敗。畫面會顯示 "The sign-in link changed. Open the new one above, then paste its code."。這個登入問題現在已經修好。 若管理員在受管設定以 pluginsDisabled 停用外掛，外掛的 MCP（讓 AI 連接外部工具的協定）伺服器與程序不會再於登入前啟動。工作階段途中一旦被管理員關閉，它們也會立刻停止。 當技能的 SKILL.md 開頭欄位沒寫 name，過去全都叫 SKILL，只載入第一個而略過其餘。現在會改用所屬資料夾命名，agy plugin validate 也會回報該名稱。

問題修復

修正尾端追加文字混雜換行格式錯誤

在 Windows 開啟慣用 CRLF 結尾的檔案並從最後一行接續寫入，代理以前會寫成 LF。這會讓同一份檔案夾雜兩種斷行，後續多行修改就會跳出 target content not found。這個問題已經修好，現在追加的文字會沿用檔案原本的換行格式。

問題修復

修正終端機等待背景工作時誤顯完成

你把子代理或任務放去背後跑、代理正停下來等結果，以前 OSC 7501 狀態列會先把這個工作階段標示為結束。這個問題已經修好，現在分頁或視窗會保持在執行中直到工作完成，不過像開發伺服器這類常駐任務不計算在內。

問題修復

遠端控制網頁操作與選單問題修復

用手機或電腦瀏覽器連回來發訊息、滑動長對話或挑選項時，畫面原本有幾處會卡住或亂跳。 在 Android 的 Chrome 用螢幕鍵盤打字時，Backspace 不再突然刪不動、後續文字也不會插進單字中間。使用輸入法或手機選字建議後按 Enter，會直接送出訊息而不是換行。 代理回覆特別長時，往上捲動想回到自己的提問，畫面不會再莫名跳回底下。 若你設定了 ask 規則或 hook（特定事件發生時會觸發的小程式）要求每次確認，權限提示裡不可用的「一律允許」選項，現在用數字鍵或方向鍵也會跳過，跟滑鼠點擊一樣。 連線或伺服器短暫出錯時，模型選單不會再跳成 No Model Selected，而是保留你原本的帳號與模型清單直到下次更新成功。

English

FEATURE

--remote-agent adds accept-edits mode

After starting a remote agent session, it now prompts before changing any file in the workspace, unlike before when it edited directly. If confirming each change feels tedious, pressing Shift+Tab toggles between the default mode and accept-edits mode instead of doing nothing. New sessions still start in the default mode, and switching to accept-edits lets the agent edit files directly without asking each time.

When handing a video to a film editor, the default now has them check with you before every cut; once you are sure the direction is right, switch to direct approval mode so they can keep editing smoothly.
FEATURE

/model adds the Orchestrator model

When signed in with a Gemini Enterprise account or AGY_ADC_AUTH Application Default Credentials, Orchestrator appears in /model if your account can select both Carbon and Hydrogen. It first has Gemini 4 Carbon (High) draft a plan. Then it hands execution off to Gemini 4 Hydrogen (High). If your plan includes multiple planners, Orchestrator (Carbon) is merged into a single Orchestrator row. The Orchestrator (Argon) row is folded in too, and you can switch Planner using ←, →, or Tab. Meanwhile, --model flags and saved settings still use the original full names.

During a home renovation, one architect draws up the full blueprint and then hands it to a site foreman to build from, and you can pick the architect right from the same contact.
FEATURE

Remote Control browser view adds conversation navigator rail

Scrolling back through a long conversation to find earlier prompts often takes ages with a mouse wheel. The Remote Control browser view now includes a conversation navigator rail that leaves a mark on the track for every prompt you send. Hover over a mark to preview that prompt and click to jump straight to it; if you prefer the keyboard, press [ or ] to jump to the previous or next prompt.

Listening to a long radio show used to mean blindly dragging the progress bar to find an earlier segment, whereas now every segment is marked right on the timeline so you can hover to preview and click to jump straight there.
FEATURE

Remote Control browser view adds Quote button

When you want to follow up on one part of a long agent response, you no longer have to copy and format it by hand. Select any text in an agent response in the Remote Control browser view and click the Quote button to insert that passage as a quote into your next message.

FEATURE

Links in Remote Control browser view open directly on click

Opening a URL pasted into a message used to mean highlighting it and copying it into a new tab. Web addresses typed in the message box and those in your sent messages can now be opened directly. On Mac, use Cmd+click, on Windows and Linux use Ctrl+click, or middle-click to open the link, while a plain left-click still just places the cursor.

FEATURE

Timers show remaining countdown in Remote Control browser view

Once the agent sets a timer in the background, you no longer have to calculate how much longer to wait. In the Remote Control browser view's Background Tasks list, each running timer shows a remaining countdown like 59m left. If a timer is the only thing running at that moment, the status line also shows progress such as Waiting for 1h timer · 59m left.

FEATURE

Remote Control browser view side panel keeps tabs and adds Overview

Reloading the Remote Control browser view no longer wipes out the files or reviews you had open. Files and views opened in the side panel are now kept as tabs and are restored after a page reload. The side panel also adds an Overview Panel, which you can open from the title bar or by pressing Cmd+Option+O. On Windows and Linux, the shortcut is Ctrl+Alt+O, and it lists the conversation's artifacts, modified files, subagents, and background tasks.

Think of running an event: tidying up the venue used to mean packing away every team's folder, whereas now the open tabs stay right where they are, with a summary sheet beside them showing who is working on what at a glance.
FEATURE

Rate-limit retry wait raised to 4 minutes

Temporary model congestion no longer cuts your turn short so easily. When the model API asks to wait before retrying, the CLI now waits up to 4 minutes and retries automatically, instead of ending the turn as soon as the wait exceeded 30 seconds. As a result, per-minute rate limits and capacity limits no longer interrupt your progress; however, spend-cap, insufficient prepaid-balance, or weekly quota exhaustion errors will stop the turn right away.

Picture waiting in line at a popular restaurant: you used to walk away if there was no table within half a minute, and now you are willing to wait a bit longer as long as tables are turning over, though if your vouchers or balance run out, you immediately come back another day.
PERF

Faster conversation switching and lower memory use in long sessions

Switching back and forth in long-running conversations often lags and eats up memory. Now, switching back to an open conversation with /resume <id> or switching after /fork no longer loads the entire history first, eliminating pauses of a second or more. Side questions like /btw and /help also start faster. Memory management has been adjusted as well: while a session is open, the CLI keeps only recently used conversation steps in memory and reloads older ones from disk when needed. It also no longer loads the full history of all previous subagents at the start of each turn, which could otherwise consume several GiB when many subagents had run.

Prepping ingredients in a kitchen used to mean spreading a whole week's groceries across the counter until there was barely room to chop, whereas now only what you need right away stays out and the rest waits in the pantry to be grabbed on demand.
FEATURE

Clickable items highlight on hover in full screen mode

In full screen (altscreen) mode, it was often hard to tell what could be clicked when moving the cursor around. Now, hovering over any clickable item highlights it on screen. These items include (ctrl+o to expand) hints, thoughts, expanded tool groups, and the pinned prompt.

FEATURE

Terminal Sandbox Blocks Reading Config Directories by Default

Many programs store account settings and tokens (authentication credentials) in system folders, which restricted commands could previously read directly. Now, the terminal sandbox blocks ~/.config or XDG_CONFIG_HOME by default, and also blocks AppData\Roaming on Windows. However, settings for common developer tools such as Git, Go, npm, and Python remain readable, while ~/.git-credentials is now blocked by default. If you genuinely need a command to read other paths, you can still allow them explicitly in your sandbox rules.

Inviting a technician to repair an appliance at home used to mean leaving bedroom drawers open for them to look through; now you lock the drawer holding your bankbook and stamps first, leaving out only the toolbox needed for the repair.
BUGFIX

Fix Auto Mode Ignoring Non-Workspace Access Setting

Even when Non-Workspace Access was turned on in /config so tools could read files outside the workspace, Auto mode still prompted for approval. This issue is fixed, and Auto mode now honors that setting.

BUGFIX

Extend Silent Timeout to 10 Minutes for High-Effort Responses

When asking the model for long, high-effort processing, any pause of more than 5 minutes without returning content while thinking previously caused it to be treated as stalled and canceled from scratch. This issue is fixed, and the CLI now waits up to 10 minutes.

BUGFIX

Fix Errors or Early Compaction After Reading Large Files

If the agent read very large files, such as multi-megabyte PDFs, before the conversation was compacted, things could easily go wrong. That turn could fail with model output must contain either output text or tool calls, or compact far earlier than needed, and this issue is now fixed.

BUGFIX

Fix New Conversations Failing at Specific Timing

Starting a new conversation right as the CLI launched or while an editor connected through agy acp was refreshing its saved session list could occasionally hit a race condition. That left every message in the new conversation failing with trajectory not found, unrecoverable even after a restart, and this issue is now fixed.

BUGFIX

Fix agy acp Background Task Reporting and Stop Timing

After connecting the agent to an editor via agy acp, if a background task or subagent finished after a turn ended and woke the agent, replies, tool calls, and permission requests were previously held back until you sent your next message. Now those messages reach the editor right away, so the agent no longer stalls on a permission prompt the editor never showed. Previously, when the editor canceled a prompt or closed a session, subagents and background tasks belonging to that session, such as dev servers, kept running in the background and could even wake the conversation again. Now canceling or closing stops them, and closing a session stops them even when no prompt is running.

BUGFIX

Fix Plugin Sign-In, Admin Toggling, and Skill Naming

Signing in and pasting the code right after installing a plugin from /plugin could previously fail. The screen displayed "The sign-in link changed. Open the new one above, then paste its code.". This sign-in issue is now fixed. When an administrator disables plugins in managed settings using pluginsDisabled, plugin MCP (a protocol that connects AI to external tools) servers and processes no longer start before sign-in. If an administrator turns them off mid-session, they also stop immediately. When a skill's SKILL.md frontmatter omitted name, all of them were previously named SKILL, so only the first loaded and the rest were skipped. Now each is named after its folder, and agy plugin validate reports that name.

BUGFIX

Fix Mixed Line Endings When Appending to Files

On Windows, when opening a file that uses CRLF endings and appending to the last line, the agent previously wrote LF. That left the file with mixed line endings, causing later multi-line edits to fail with target content not found. This issue is fixed, and appended text now uses the file's original line endings.

BUGFIX

Fix Terminal Showing Done While Waiting on Background Work

When you sent a subagent or task to the background and the agent paused to wait for results, the OSC 7501 status bar previously marked the session as done. This issue is fixed, so the tab or window now stays in the working state until that work finishes, though daemon tasks such as dev servers do not count.

BUGFIX

Fix Remote Control Browser Input and Menu Issues

When connecting from a phone or desktop browser to send messages, scroll through long conversations, or pick options, several parts of the interface could previously freeze or jump. When typing with the on-screen keyboard in Chrome on Android, Backspace no longer stops deleting characters, and subsequent text no longer lands in the middle of a word. Pressing Enter after using an input method or phone keyboard suggestions now sends the message instead of adding a new line. When the agent's reply is especially long, scrolling up to return to your own prompt no longer unexpectedly jumps back to the bottom. If you configured an ask rule or a hook (a small program triggered by specific events) requiring confirmation each time, the unavailable "always allow" option in the permission prompt is now skipped by number and arrow keys, matching mouse clicks. During a brief connection or server error, the model menu no longer switches to No Model Selected, keeping your existing account and model list until the next successful refresh.

Added a conversation navigator to the Remote Control browser view: a rail with a mark for each of your prompts previews the prompt when you hover over it and jumps to it when you click, and `[` and `]` jump to the previous or next prompt.
Original changelog遠端控制網頁新增 Quote 引用按鈕
Added a `Quote` button to the Remote Control browser view: select text in an agent response and click `Quote` to add it to your next message as a quote.
Original changelog遠端控制網頁的網址可按鍵直接開啟
Added clickable links to the message box and your sent messages in the Remote Control browser view: a web address you type or paste opens with `Cmd+click` (`Ctrl+click` on Windows and Linux) or a middle-click, while a plain click still places the cursor.
Original changelog遠端控制網頁計時器顯示剩餘倒數
Added the time left to timers the agent sets, in the Remote Control browser view: each running timer in `Background Tasks` shows a countdown such as `59m left`, and when a timer is all that's running, the status line reads, for example, `Waiting for 1h timer · 59m left`.
Original changelog遠端控制網頁側邊欄保留分頁並增設總覽
Improved the side panel in the Remote Control browser view: files and reviews open in tabs that come back when you reload the page, and a new Overview Panel, opened from the title bar or with `Cmd+Option+O` (`Ctrl+Alt+O` on Windows and Linux), lists the conversation's artifacts, modified files, subagents, and background tasks.
Original changelog限流等待重試上限放寬至 4 分鐘
Improved rate-limit handling: when the model API asks the CLI to wait before retrying, the CLI now waits and retries for delays of up to 4 minutes instead of stopping the turn when the delay is longer than 30 seconds, so per-minute rate and capacity limits no longer end your turn, while spend-cap, prepaid-balance, and weekly quota errors now stop the turn right away.
Original changelog長工作階段切換對話更快也更省記憶體
Improved switching to a conversation that's already open in long sessions: `/resume <id>` back to it and the switch after `/fork` no longer load the conversation's whole history first, so they no longer pause for a second or more, and `/btw` and `/help` side questions start faster too.
Improved memory use in long sessions: the CLI now keeps only recently used conversation steps in memory and reloads older ones from disk when it needs them, instead of holding every step for as long as the conversation is open, and it no longer loads every earlier subagent's full history at the start of each turn, which could take several GiB in sessions that ran many subagents.
Original changelog全螢幕模式可點擊項目懸停會發亮
Improved click-to-expand in the `full screen (altscreen)` rendering mode: items you can click, such as `(ctrl+o to expand)` hints, thoughts, expanded tool groups, and the pinned prompt, now highlight when you hover over them.
Original changelog終端機沙盒預設封鎖讀取設定目錄
Changed the terminal sandbox to block sandboxed commands from reading `~/.config` (or your `XDG_CONFIG_HOME`) and, on Windows, `AppData\Roaming` by default, since other programs keep settings and tokens there; previously they were readable. The settings of common developer tools such as Git, Go, npm, and Python stay readable, `~/.git-credentials` is now blocked, and you can still allow other paths explicitly in your sandbox rules.
Original changelog修正 Auto 模式忽略工作區外存取設定
Fixed Auto mode asking for approval to read files outside the workspace even when `Non-Workspace Access` is turned on in `/config`; Auto mode now honors that setting.
Original changelog高思考強度長回覆靜默上限延至 10 分鐘
Fixed long, high-effort model responses being canceled and restarted from scratch when the model went more than 5 minutes without sending anything while it was still thinking; the CLI now waits up to 10 minutes before it treats a silent response as stalled.
Original changelog修正讀取超大檔案後報錯或過早壓縮
Fixed turns failing with `model output must contain either output text or tool calls`, or the conversation compacting far earlier than needed, after the agent read very large files, such as multi-megabyte PDFs, before the conversation's first compaction.
Original changelog修正特定時機新建對話失效問題
Fixed a rare race that could leave a new conversation unusable, with every message failing with `trajectory not found` even after a restart, when the conversation was created while the CLI was listing saved conversations, such as at startup or when an editor connected through `agy acp` refreshed its session list.
Original changelog修正 agy acp 背景任務回報與停止時機
Fixed `agy acp` holding back what the agent did after a turn ended: when a background task or subagent finishes and wakes the agent, its replies, tool calls, and permission requests now reach the editor right away instead of at your next prompt, so the agent no longer waits on a permission request the editor never showed.
Fixed `agy acp` leaving a session's subagents and background tasks, such as dev servers, running after the editor canceled a prompt or closed the session, where they could keep working and wake the conversation again; canceling or closing now stops them, and closing does so even when no prompt is running.
Original changelog外掛啟停登入與技能命名修復
Fixed signing in to a plugin right after installing it from `/plugin`, where pasting the code from its sign-in page could fail with "The sign-in link changed. Open the new one above, then paste its code."
Fixed plugins running while your organization turns them off with `pluginsDisabled` in managed admin settings: plugin MCP servers and other plugin processes no longer start before sign-in finishes, and they now stop as soon as an administrator turns plugins off during a session.
Fixed skills whose `SKILL.md` has no `name` in its frontmatter: they were all named `SKILL`, so only the first one loaded and the rest were silently dropped; each is now named after its folder, and `agy plugin validate` reports that name.
Original changelog修正尾端追加文字混雜換行格式錯誤
Fixed the agent writing LF line endings when it appends to a file that uses CRLF line endings, as is common on Windows, which left the file with mixed line endings and made later multi-line edits to it fail with `target content not found`; appended text now uses the file's own line endings.
Original changelog修正終端機等待背景工作時誤顯完成
Fixed OSC 7501 terminal status showing the session as done while the agent was paused waiting for background subagents or tasks to finish; the terminal's tab or window now shows it as working until that work ends, and daemon tasks such as dev servers don't count.
Original changelog遠端控制網頁操作與選單問題修復
Fixed typing in the Remote Control browser view: with Chrome on Android, `Backspace` on the on-screen keyboard could stop deleting characters and later text could land in the middle of a word, and after typing with an input method or a phone keyboard's suggestions, `Enter` could add a new line instead of sending your message.
Fixed scrolling up through a long agent turn in the Remote Control browser view, where the view could jump back down instead of reaching your prompt.
Fixed the permission prompt in the Remote Control browser view letting the number or arrow keys select and submit an unavailable "always allow" option when one of your ask rules or a hook requires you to confirm each time; the keyboard now skips those options, as clicking already did.
Fixed the model selector in the Remote Control browser view switching to `No Model Selected` after a brief connection or server error; it now keeps your account and model list until the next successful refresh.
