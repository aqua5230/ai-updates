Antigravity 1.0.1

發布日期：2026-07-13

zh-TW

歡迎畫面直接搞定免費帳號，黑白風格成預設首選

新玩家加入變得更容易了。現在你剛打開軟體時，可以直接在終端機裡順暢完成免費帳號的註冊與綁定（onboarding），不用再四處找教學。在挑選顏色主題時，最經典、和系統環境最搭的「terminal（黑白終端機）」風格現在被移到了最上面，成為預設首選。以前如果你在註冊畫面上手癢拉了一下視窗大小，畫面可能會因為來不及反應而變成一片空白當機，現在這個脆弱的問題也修好了。就像搬進新家，以前要自己去不同部門辦水電，現在大廳就有專人幫你辦到好，而且預設附贈的傢俱就已經是最百搭的款式，不用怕選錯，而且調整擺設時房子也不會再突然停電了。

排版不走鐘，表格、長檔名與刪除紀錄的按鍵都調整好了

畫面排版變得更加堅固且順眼。以前貼上超級長的文章時，行數計算會出錯，導致畫面又被撐爆；現在系統會精準把它折疊成短短一行「貼上的文字」提示框。當 AI 正在讀取某個資料夾深處的檔案時，如果路徑太長，現在它會聰明地把中間省略成「/foo/.../bar」，確保不會把原本的排版擠歪。用 Markdown 畫表格時，裡面很長的字現在終於會自動換行，不會再硬生生被切斷了。在看程式碼差異時，被刪除的檔案也不會再跟上一個檔案的內容詭異地黏在一起。另外，在 /resume 歷史清單裡刪除對話的快捷鍵，從容易誤按的 ctrl+d 改成了 ctrl+delete，這樣就不會跟你平常想刪字或退出程式的習慣打架了。就像排版一本雜誌，以前字太長就會凸出格子、被刪除的圖會殘留在上一頁，現在所有文字跟圖片都完美待在它們該待的格子裡。

沙盒指令自動放行，查詢額度不再慢半拍

沙盒內指令可少按同意。我們推出了一種全新的「在沙盒中繼續執行」的權限模式：只要指令是在安全的沙盒（sandbox，隔離的安全區）裡面跑，系統就會自動幫你點頭放行，只有遇到想越界逃出沙盒的危險指令才會停下來問你，讓你少按很多次「同意」。用 /usage 查額度時，系統現在會強制即時向伺服器更新，讓你立刻看到最準確的消耗量，不用再等它慢慢同步。外掛系統也升級了，現在會自動掃描你安裝的外掛目錄，一裝好就能直接在終端機裡呼叫自訂的技能跟代理。對於 Windows 系統的使用者，以前日誌（log）沒寫好會導致視窗大小卡住而且關閉超慢，現在也順利解決了，就像有了個聰明的門禁系統，以後在安全區裡活動的員工都不用再查證件，而且你的點數卡餘額一刷就會立刻更新，不用等到隔天才扣款。

en

Built-in free-tier onboarding and stable terminal themes

Getting started as a new user is now much easier. When you open the software for the first time, you can now smoothly complete the free-tier account registration and onboarding directly within the terminal, without needing to hunt down tutorials elsewhere. When picking a color theme, the classic, environment-matching "terminal" (black & white) style has been moved to the very top, making it the default choice. Previously, if you resized your window while on the onboarding screen, the UI would fail to react in time and crash into a blank screen; this fragility has been fixed. Like moving into a new apartment: you used to have to visit different municipal offices to set up your utilities, but now the lobby concierge handles it all for you; plus, the default furniture provided is the most versatile style, so you can't go wrong, and rearranging it won't suddenly cause a power outage anymore.

Flawless layouts for tables and paths, plus safe session deletion

The interface layout is now much more robust and pleasing to the eye. Previously, pasting an incredibly long article would mess up the line counting and blow up the screen; now, the system accurately folds it into a short "[Pasted text]" placeholder. When the AI is reading a file buried deep in a folder, if the path is too long, it now smartly truncates the middle into "/foo/.../bar" to ensure the layout doesn't shift. Long text inside Markdown tables will now automatically wrap instead of being abruptly cut off. When viewing code differences, deleted files will no longer bizarrely merge their content into the previous file's diff block. Additionally, the shortcut for deleting a conversation in the /resume history list has been changed from the accident-prone ctrl+d to ctrl+delete, so it won't clash with your muscle memory for forward-deleting text or exiting the program. Like typesetting a magazine: text used to spill out of its boxes and deleted images would leave ghost traces on the previous page, but now every word and picture stays perfectly inside its designated bounds.

Auto-approve sandbox commands, real-time quotas, and instant plugin discovery

Permission management and the underlying system are much smarter now. We've introduced a brand-new "proceed-in-sandbox" permission mode: as long as a command is running safely isolated inside the sandbox, the system will auto-approve it for you, only stopping to ask for your permission if a dangerous command attempts to break out, saving you from clicking "Approve" constantly. When you use /usage to check your quota, the system now forcefully reloads data from the server in real-time, giving you immediately accurate consumption stats instead of making you wait for a slow sync. The plugin system has also been upgraded: it automatically scans your installed plugin directories, meaning you can call your custom skills and agents directly in the terminal the moment they are installed. For Windows users, a critical bug where poorly handled logs caused window resizing to freeze and made the app shut down excruciatingly slowly has been fixed. Like installing a smart security gate: employees moving within the designated safe zone no longer have to show ID at every corner, and when you swipe your prepaid card, the balance updates instantly instead of taking until the next day to process.

Fixed pasted text line counting. Corrected line counting for user inputs to ensure extremely long inputs are correctly folded into a `[Pasted text #X +Y lines]` placeholder to keep the viewport clean.
Improved step rendering layout. Calculates available terminal width dynamically and uses middle-truncation (`/foo/.../bar`) for file path tools to prevent layout shifting on narrow screens.
Improved session deletion keybinding in `/resume`. Changed the shortcut from `ctrl+d` to `ctrl+delete` to resolve conflicts with the global exit keybinding (`ctrl+d` `ctrl+d`) and preserve Emacs-style forward-delete in search input fields.
Restored automatic table wrapping, preventing long cells inside markdown tables from being truncated.
Resolved an issue where deleted files (represented by `+++ /dev/null`) had their deletion lines incorrectly merged into the previous file's diff.
Original changelog
Added `proceed-in-sandbox` tool permission mode. Auto-approves terminal commands that run inside the secure sandbox, requesting manual approval only when a command attempts to bypass the sandbox.
Improved `/usage` and `/quota` commands. Forces a real-time reload of model configuration and remaining quotas, allowing you to see updated real-time consumption statistics immediately.
Added plugin discovery for skills and agents. Automatically scans installed plugin directories to make custom skills and specialized agents available for execution in the CLI.
Fixed Windows log redirection and resizing issues. Resolved a critical bug where logs were not redirected correctly on Windows, which previously caused the terminal to swallow window resize events and shut down slowly.
