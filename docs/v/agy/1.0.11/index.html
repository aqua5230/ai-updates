繁體中文

快捷鍵與中斷操作更直覺，設定防呆不卡死

現在鍵盤快捷鍵的行為更符合你的直覺了。按 ctrl+c 第一下會中斷代理正在做的事（例如打斷它還在碎碎唸的回覆），連按兩下則會退出程式，而且這是一道防死當的安全閥，就算你自己在設定裡把 ctrl+c 綁成別的功能，它依然會強制攔截以防你卡死，並會給你明確的修改建議。按 ctrl+d 時，如果你正在打字，它會正常把游標後面的字刪掉，只有在輸入框全空時才會退出程式，不會再因為想刪字就不小心關掉整個軟體了。自訂快捷鍵時，系統也變聰明了：如果你打錯按鍵名稱，它會直接挑錯並推薦正確寫法，不會再讓你設定出根本按不出來的「死鍵」；而且錯誤提示也會用人話（像是 cli.escape）告訴你，還改成彈出式警告，不再霸佔畫面底部的寶貴空間。就像搭電梯，以前你可能按了開門鍵結果電梯卻關機，或者設定保全時不小心把自己反鎖，現在不但緊急停止鈕絕對有效，設定時如果密碼格式不對也會當場糾正你。

歷史對話載入神速，搜尋與改名更順利

你現在打開 /resume 查看歷史對話時會發現順暢無比。以前如果你的歷史紀錄太多，打開這個畫面會卡很久，背後還會狂印載入日誌；現在系統加了快取機制和同步載入，點開瞬間就能看到清單。在這畫面裡搜尋或改名時，現在終於支援直接從剪貼簿貼上文字了。幫對話改名時，輸入框也升級成可以多行顯示的版本，再長的名字都不會被卡掉一半，而且選單游標也不會再莫名其妙消失了。就像去圖書館找書，以前圖書館員要一本本翻找還會一直碎碎唸，現在有了最新的電子目錄，一秒就能找到，而且要幫借閱清單加備註時，終於可以直接貼上整段字，不會再被限制只能打一行字了。

排版更漂亮，全螢幕審查指令與更清晰的版本紀錄

現在終端機裡的文字與畫面排版更友善了。當系統跳出工具確認對話框問你要不要執行指令時，你可以按 ctrl+g 切換到全螢幕模式，舒舒服服地查看並編輯完整指令和權限，不再只能擠在原本小小的單行修改框裡。指令輸出的高度現在會自動調整，你甚至可以用 AGY_CLI_CMD_OUTPUT_PERCENTAGE 這個環境變數（設定程式環境的參數）來控制它最多能佔畫面的幾成。文字排版時也不會再發生「網址裡有連字號就被硬生生切成兩半」的糗事。在看版本控制（VCS，像是 Git 紀錄）的樹狀圖時，代表當前位置的 @ 符號現在會精準標示在你真正所在的版本上，不會再跑去標記「還沒存檔的工作區」，讓你一眼看出自己到底在哪裡。就像看電影時，以前字幕遇到長網址會被隨便切斷，重點片段只能在小視窗看，現在不但字幕排版完美，遇到重要確認還能按 ctrl+g 放大到全螢幕看個仔細。

English

Intuitive shortcuts and interrupt operations with foolproof keybinding settings

Keyboard shortcuts now behave much more intuitively. Pressing ctrl+c once interrupts whatever the agent is currently doing (like stopping a rambling, streaming response), and pressing it twice exits the program. Furthermore, this acts as a fail-safe safety valve: even if you mapped ctrl+c to another function in your settings, the system forcibly intercepts it to prevent you from getting permanently locked up, offering clear suggestions on how to fix your config. When pressing ctrl+d while typing, it now correctly forward-deletes text, and only exits the app if the input box is completely empty — no more accidentally closing the whole program just because you tried to delete a typo. The custom keybinding system is also smarter now: if you misspell a key name, it will outright reject it and suggest the correct spelling, ensuring you don't register "dead keys" that can never be pressed; the error messages also use human-readable names (like cli.escape) and appear as transient alerts instead of permanently hogging valuable space at the bottom of the screen. Like riding an elevator: you used to press the "open door" button and the elevator might shut down, or you might accidentally lock yourself out while setting up the security system; now, the emergency stop button is guaranteed to work, and if you punch in the wrong passcode format, it corrects you on the spot.

Blazing fast history loading with improved search and rename features

Opening /resume to view your conversation history is now blazingly fast and smooth. Previously, if you had a massive chat history, loading this screen would freeze for a long time while spamming loading logs in the background; now, thanks to a new caching mechanism and parallel loader, the list pops up instantly. When searching or renaming conversations in this view, you can finally paste text directly from your clipboard. The rename input box has also been upgraded to a multiline editor, so long titles won't get chopped off halfway, and the menu cursor will no longer mysteriously vanish. Like searching for a book at the library: the librarian used to flip through cards one by one while mumbling non-stop, but now there's an electronic catalog that finds it in a second, and when you want to add a note to your reading list, you can finally paste an entire paragraph instead of being restricted to a single line.

Better formatting, full-screen command review, and clearer version history

The text and layout in the terminal are now much friendlier. When the tool confirmation dialog pops up asking if you want to run a command, you can press ctrl+g to switch to a full-screen view, allowing you to comfortably inspect and edit the entire command and its permissions rather than cramming into a tiny single-line box. Command output heights now adjust dynamically, and you can even set a maximum terminal height percentage using the AGY_CLI_CMD_OUTPUT_PERCENTAGE environment variable (a parameter used to configure the program's environment). Text formatting has also been improved to stop awkwardly splitting URLs in half just because they contain a hyphen. When viewing the version control system (VCS, like Git) tree history, the @ marker representing your current position now accurately highlights your actual committed state, rather than pointing to the uncommitted "Working Copy", letting you see exactly where you stand. Like watching a movie: the subtitles used to awkwardly chop long URLs in half, and crucial scenes were forced into a tiny window; now the subtitles are perfectly formatted, and you can instantly expand important prompts to full-screen to read every detail clearly.

Improved keybinding validation warning messages to use user-facing names (e.g., `cli.escape`) instead of internal representation names.
Improved startup behavior by only creating the `keybindings.json` configuration file when the user explicitly runs the `/keybindings` customization command, rather than automatically generating it on every startup.
Fixed the `ctrl+c` exit safety valve to ensure it always works as an interrupt or exit key, regardless of how it is mapped in the user's custom keybindings configuration.
