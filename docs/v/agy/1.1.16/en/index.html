Antigravity 1.1.16

Released: 2026-08-20

Release notes

FEATURE

Manage MCP servers with subcommands

When you connect AI to outside tools, MCP (a protocol for connecting AI to external tools) server settings no longer require hand-editing mcp_config.json.

Use mcp add, mcp remove, mcp list, mcp enable, and mcp disable for user-level servers; --type, --env, and --header cover stdio and HTTP.

It is like labelling every breaker in a panel: add, remove, inspect, enable, or disable a connection at its switch rather than opening a wall to rewire it.
FEATURE

`/mcp` retains configuration fields when toggling servers

When you toggle a server in the /mcp panel, it previously could drop enabledTools, timeoutSeconds, url, and tools.eager from mcp_config.json.

The panel now retains them during an edit and also keeps fields written by a newer client that it does not recognize.

It is like a clerk updating a form by changing only the box you named, not erasing other completed fields; even a new field the clerk cannot yet read stays untouched.

Settings written by a newer client therefore survive a toggle in the panel.

FEATURE

File search is faster in large workspaces and respects ignore rules

In a large project, typing @ to find a file no longer means watching results struggle to catch up.

Lookup now uses bundled ripgrep and waits for your keystrokes to pause; an exact filename ranks above a directory or generated artifact that merely contains the query.

It is like calling an item name in a warehouse: the clerk waits until you finish speaking, then brings the exactly labelled box to the front.

Files listed in .antigravityignore also stop appearing in @ path completion.

FEATURE

Gemini API keys can tune reasoning effort, without cramped picker text

After signing in with a Gemini API key, Gemini 3.

6 Flash and Gemini 3.7 Flash can finally have their reasoning effort adjusted with /effort—how much thought a model uses before answering. That sign-in route had wrongly called them unadjustable while other routes allowed it. In narrow terminals, the reasoning-effort description beneath the timeline gauge in /effort and /model is now omitted when it would overflow, keeping the gauge readable.

A dial that was locked and crowded by its label can now turn, and its reading remains visible.
BUGFIX

Unsupported OSC 8 terminals no longer print raw link controls

If your terminal lacks OSC 8 hyperlinks, such as Terminal.

app, control sequences no longer print as literal text. Such terminals originally could not interpret control sequences and displayed them literally; the program now checks support first to avoid sending them. Detection now also covers command output and alert bodies, which had still emitted hyperlinks regardless of support.

It is like a printer finding that readers lack an invisible-ink viewer, then using readable ink instead of leaving markings on the page.

All three places now check whether OSC 8 can be handled first.

BUGFIX

Unsupported Kitty keyboard protocol no longer adds equals signs to prompts

On a terminal without the Kitty keyboard protocol—the way a terminal interprets keyboard input—the prompt no longer gains a = every couple of seconds.

The renderer, the part that draws the display, periodically re-armed the protocol, but the terminal printed that control signal as text instead of interpreting it.

It is like resetting a classroom projector every few seconds when its control signal is not received and is written onto the whiteboard instead.

Re-arming no longer leaves equals signs on unsupported terminals.

BUGFIX

Artifact names with spaces now match in list, preview, and header

When an artifact name contains a space, its list row, inline preview, and detail header now spell it the same way.

It could previously appear as quarterly%20plan.md, replacing the space with a percent-escape and making it look like another file.

It is like one film using its real title in the opening credits, poster, and programme.

Moving from list to preview or detail no longer makes you wonder whether it is the same artifact.

BUGFIX

Prompt cursor stays aligned after text wraps

After long text wraps in the prompt editor, the cursor now stays in the right place.

The editor had miscalculated positions after a wrap, so the cursor could point at one spot while inserted text landed elsewhere.

It is like measuring a folded sheet with a ruler: the fold once broke the scale, but now the ruler continues along the paper.

When you move, add, or delete text in a long prompt, the visible position matches the edit position.

BUGFIX

MCP can now keep PDFs, audio, and other binary resources

When an MCP server returns a PDF, audio file, or other non-image binary content, read_resource no longer silently drops it.

Every blob is now offloaded to disk, while only small text and image resources are inlined in the response.

It is like a museum placing every object in storage, while its display board embeds only small text and images; larger pieces are not discarded.

Large PDFs, audio, and other binary resources remain usable instead of disappearing during reading.

BUGFIX

Workforce Identity Federation sign-in stops expiring unexpectedly

With Workforce Identity Federation sign-in, refreshing a token—the credential that keeps a login valid—no longer sends you out through the wrong endpoint.

The refresh had gone to the standard sign-in endpoint instead of the federated one, repeatedly invalidating the session roughly every hour.

It is like sending a badge for its scheduled validity stamp to the issuing machine in another building; now it returns to the matching machine.

Token refresh remains in the correct federated sign-in flow.

BUGFIX

Built-in skills are now labelled and grouped correctly

In /skills, skills shipped with the CLI are now correctly identified as built in.

They had been reported as not built in, making the builtin flag in --output-format json wrong and placing them in the wrong /skills panel group.

It is like a store's own-brand goods being labelled as consignment stock, then shelved in the wrong aisle; labels and shelves now match.

JSON output for other tools and the panel view now agree.

BUGFIX

Custom and SDK agents can use /btw, with real failure messages

When a small side question occurs to you mid-conversation, /btw no longer fails with a planner configuration error because you are using a custom or SDK-defined agent—an AI setup that performs a particular task for you.

Side questions work with whichever agent is running. If one fails, the card no longer blindly says model returned an empty response; when there is its own error, that error is shown.

It is like a medical form being handled by doctors in different specialties without being returned for its identity field; if an examination fails, its report gives the real abnormality.
BUGFIX

Finished background tasks no longer linger as active

After a background task finishes, the status line, active-items list, and /tasks panel no longer keep calling it active.

A task could already be done while all three views failed to remove it, making you think you still had to wait.

It is like a train reaching its station while the platform board still says in transit; now all three boards update together.

These views show tasks that are still running in the background.

BUGFIX

An unreadable settings.json is no longer overwritten with defaults

If settings.json cannot be parsed because its format is broken, the CLI now refuses to save without overwriting it with default settings.

Previously, saving anything later could silently revert every existing setting. On a refused save, the file remains byte-for-byte identical and the status line names it.

It is like a counter finding an unreadable page in a contract and returning the original for repair instead of replacing the whole document with a blank template.
BUGFIX

An inherit subagent starts even when its parent has no model

When a subagent leaves model as inherit, it now starts even if its parent has no model of its own.

The old behavior failed because there was nothing to inherit. It now falls back to the default fast tier.

A relay team that cannot find the baton from the previous runner does not remain at the start; it picks up a spare baton and keeps running.

inherit still prefers the parent model, falling back only when that model is absent.
