Antigravity 1.4.7

發布日期：2026-10-24

繁體中文

新功能

掛鉤指令接收使用者最新輸入，可在代理動作前過濾提示詞

你在編寫自訂安全規範或自動流程時，常希望在 AI 真正開始動手前先確認剛送出的內容。現在傳遞給掛鉤（特定事件發生時被觸發的小程式）指令的標準輸入 JSON 資料中，正式加入了 lastUserInput 欄位。

郵件收發室的分揀員拿到的清冊上，現在多了一欄最新信件內容，可以在送交專員處理前先檢查這封信。

這個欄位記錄了你剛發送的最新訊息。掛鉤可直接讀取 lastUserInput，檢查最新訊息並在代理處理前篩選提示詞。

新功能

推出萬聖節限定主題，開機橫幅與月相動畫換上應景外觀

萬聖節主題開放期間，你也能為日常開發環境換上濃厚的節慶氛圍。只要在終端機輸入 /config，就能在設定清單中看見僅在節慶期間出現的 Seasonal Themes 選項。

如同街角咖啡館限時換上南瓜燈飾與限定杯套，原本的迎賓招牌與隨行杯身，也暫時換上應景的特殊圖樣。

開啟這項功能後，工具啟動時會顯示萬聖節開機橫幅，等待回應時的旋轉指示燈會變換為月相週期動畫，同時還會點綴主題跑馬燈與專屬的提示框邊框。這項外觀純屬季節限定的選用項目，節慶檔期結束後設定選項就會自動隱藏，平時完全不影響簡潔的介面風格。

新功能

自動模式減少例行確認，無頭執行與介面反應更流暢

在讓 AI 自動處理專案或透過背景腳本批次執行時，你往往希望工具能安靜執行，不要頻繁被瑣碎中斷或耗盡電腦資源。 在 Auto 模式下，工具現在會減少針對例行指令的授權確認次數，包含清理暫存檔、結束本機行程，或是執行程式碼排版工具，都不會再頻繁跳出視窗要你逐一確認。 以 -p 參數執行無頭模式（沒有視覺介面的執行模式）時，處理器佔用顯著降低，在輸出長篇回覆或累積大量歷史紀錄時特別明顯。由於列印模式無需顯示畫面，因此不再建置搜尋索引與螢幕逐字稿，也不會再觸發自訂狀態列（終端機底部的即時資訊列）與視窗標題指令。 在日常互動介面中，無論是模型正在串流輸出文字、畫面跳出權限請求，或是手動縮放視窗大小，畫面更新速度都更快。以前跑背景批次常遇到處理器過載，現在資源消耗明顯降低，操作過程也少了不必要的打擾。

問題修復

單一內容超出容量上限時，不再陷入反覆壓縮對話的迴圈

當你讓代理處理超大檔案或工具輸出巨量文字時，可能會遇到對話停滯。以前只要單一訊息、工具輸出或附加文件大到無法放進上下文（模型一次能讀取的對話範圍），對話就會陷入反覆壓縮的無限迴圈。這個問題現在已經修好，遇到超長內容時不會再卡在連續壓縮的狀態。

問題修復

外掛與 MCP 擴充功能修復憑證儲存，隨選工具回傳上限放寬至 10 KB

串接外部工具與外掛時，你可能遇過登入狀態沒存下來，或切換帳號後連線沒跟著換。 隨選載入的 MCP（讓 AI 連接外部工具的協定）工具可直接向代理回傳最多 10 KB 結果；以前超過 4 KB 就得寫入檔案再額外讀取一次。 使用應用程式預設憑證（AGY_ADC_AUTH）登入時，技能、規則、自訂代理、外掛、外掛 MCP 伺服器與掛鉤無法載入的錯誤已修復。 在 macOS 與 Windows 上，外掛與 MCP 伺服器的權杖（授權令牌）過大、無法存入系統金鑰鏈時，會改存到本機私密檔案以保留登入狀態。 透過 OAuth 登入的外掛 MCP 伺服器權杖改為綁定登入者，修好了共用電腦帳號時誤用他人權杖的問題。先前切換帳號或登出後，仍可能保留前一位使用者的連線，這個問題也已修好。伺服器在切換帳號時會自動重連，可能需重新登入。

問題修復

終端機排版與文字複製多項修復，說明清單精簡常用快速鍵

在終端機內瀏覽輸出結果、複製程式碼或編輯文字時，細節排版直接左右閱讀與操作的流暢度。 輸入 /help 查看快速鍵分頁時，清單移除了方向鍵等基礎導覽鍵，方便你更快找到真正實用的進階快速鍵。 在表格呈現上，預設的 Terminal 配色改用框線繪製字元取代 ASCII 直線符號。儲存格內折行的長網址先前只有第一行附帶截斷的超連結，現在整段網址都能完整點擊與複製。 複製程式碼區塊或行內程式碼中折行的長指令時，貼上會合併為單行，不會在折行處夾帶多餘換行。程式碼區塊內的長行也會在單字之間折行，並保留區塊縮排。 在 Vim 模式的 Normal 與 Visual 模式下使用 r 替換文字時，先前會殘留部分摺疊的貼上標記，現在會乾淨取代整個預留位置。

English

FEATURE

Hook Commands Receive Latest User Input to Screen Prompts Before Agent Acts

When writing custom safety rules or automated workflows, you often want to verify what was just sent before the AI actually begins acting. Now, the lastUserInput field has been officially added to the JSON data that hook (small programs triggered by specific events) commands receive on stdin.

A mailroom sorter now receives a manifest with an extra column showing the latest letter's contents, allowing them to inspect the letter before delivering it to the specialist.

This field records the latest message you just sent. Hooks can directly read lastUserInput to inspect the latest message and screen prompts before the agent acts on them.

FEATURE

Halloween Theme Launches for a Limited Time with Seasonal Startup Banner and Moon-Phase Animation

While the Halloween theme is active, you can bring a festive atmosphere to your everyday development environment. Just enter /config in the terminal, and you will see the Seasonal Themes option in the settings list, which appears only while the theme is in season.

Much like a corner cafe temporarily putting up pumpkin decorations and limited-edition cup sleeves, the welcome sign and takeaway cups temporarily switch to festive designs.

Turning on this feature displays a Halloween startup banner when the tool launches, changes the waiting spinner into a moon-phase animation, and adds a themed running light along with dedicated prompt box borders. This visual appearance is a strictly seasonal opt-in item; the setting row is automatically hidden after the holiday season ends, leaving the clean interface untouched during normal times.

FEATURE

Auto Mode Reduces Routine Confirmations, Making Headless Execution and UI Response Smoother

When letting AI automatically handle projects or executing batch runs via background scripts, you often want the tool to run quietly without frequent interruptions or draining computer resources. In Auto mode, the tool now asks for approval less often on routine commands; cleaning up temporary files, stopping local processes, or running code formatters will no longer frequently pop up windows asking for confirmation one by one. When running in headless mode (an execution mode without a visual interface) with the -p flag, CPU usage is significantly reduced, which is especially noticeable when outputting long answers or accumulating many saved conversations. Because print mode does not need to display a visual interface, it no longer builds the search index or conversation transcripts for display, and it no longer starts custom status line (a real-time information bar at the bottom of the terminal) and window title commands. In the everyday interactive interface, rendering speed is faster whether the model is streaming response text, a permission prompt appears, or you manually resize the window. While background batch runs previously ran into CPU overloads, resource consumption is now noticeably reduced, and the operating experience has fewer unnecessary interruptions.

BUGFIX

Conversations No Longer Loop Compacting When a Single Item Exceeds Context Capacity

When you have the agent handle oversized files or tools output huge amounts of text, conversations could stall. Previously, whenever a single message, tool output, or attached document was too large to fit in the context (the conversation range a model can read at once), the conversation would fall into an infinite loop of repeated compaction. This issue has now been fixed, so encounters with extra-long content will no longer get stuck in continuous compaction.

BUGFIX

Plugins and MCP Extensions Fix Credential Storage, Relaxing On-Demand Tool Return Limit to 10 KB

When connecting external tools and plugins, you might have experienced login states failing to save or connections not updating after switching accounts. MCP (a protocol allowing AI to connect to external tools) tools that are loaded on demand can now return results of up to 10 KB directly to the agent; previously, anything over 4 KB had to be written to a file and read again in an extra step. When signing in with Application Default Credentials (AGY_ADC_AUTH), errors where skills, rules, custom agents, plugins, plugin MCP servers, and hooks failed to load have now been fixed. On macOS and Windows, when a token (authorization credential) for plugins and MCP servers is too large to fit in the system keychain, it is now saved to a local private file to preserve the login state. Tokens for plugin MCP servers signed in via OAuth are now bound to the signed-in user, fixing an issue where users sharing the same computer account could mistakenly use someone else's token. The previous issue where the prior user's connection might still be retained after switching accounts or signing out has also been fixed. These servers automatically reconnect when switching accounts, so you may need to sign in again.

BUGFIX

Terminal Formatting and Text Copying Receive Multiple Fixes, Streamlining Help Shortcuts

When browsing output, copying code, or editing text in the terminal, layout details directly dictate the smoothness of reading and operations. When typing /help to view the shortcuts tab, the list removes basic navigation keys such as the arrow keys, making it easier to quickly find truly useful advanced shortcuts. For table display, the default Terminal color scheme now uses box-drawing characters instead of ASCII vertical line symbols. Long links that wrap inside a cell were previously linked only on their first line to a truncated URL, but now the full URL can be clicked and copied. When copying a long command that wraps across rows in a code block or inline code, pasting now merges it into a single line without extra line breaks at each wrap point. Long lines within code blocks also now break between words and retain the block indentation. When using r to replace text in Vim mode's Normal and Visual modes, which previously left behind part of a collapsed paste marker, the entire placeholder is now cleanly replaced.
