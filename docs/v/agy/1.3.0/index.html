Antigravity 1.3.0

發布日期：2026-10-06

繁體中文

新功能

對話畫面預設精簡，思考與工具呼叫自動收攏

當你打開終端機與 AI 對話時，眼前不再被連篇累牘的內部推導塞滿。

系統將詳細程度（Verbosity，控制終端機顯示資訊多寡的選項）預設值從 high 改為 medium。現在對話檢視畫面會把相關的工具呼叫與思考過程收攏成精簡摘要，同時完整保留執行的指令與回覆內容。

好比翻閱會議紀錄，以前攤開來是滿紙的討論推導與喃喃自語，現在秘書預先將過程收整成條列摘要，只留下關鍵結論與執行動作，需要對帳時再翻開完整逐字稿。

這項調整適用於從未設定過詳細程度的人，以及過去在 high 還是預設值時選取過 high 的使用者。若你想重新看見完整的工具呼叫、指令與思考過程，隨時能在 /config 設定中把 Verbosity 切換回 high。

新功能

版本比對按鍵調整，改用上下鍵與 jk 逐行瀏覽

你在終端機裡用 /diff 檢查程式碼更動時，鍵盤操作手感現在更加直覺統一。

檔案檢視畫面中的 j 與 k 鍵改為移動行游標，操作方式如同鍵盤上的上下方向鍵。這樣能完全對齊檔案清單以及 Vim（常見的終端機文字編輯器）的操作習慣，不再按一下就直接跳到上一個或下一個檔案。

彷彿翻閱附有頁籤的活頁文件夾，以前按上下鍵會突然抽換整份文件，現在上下翻動只在當前頁面逐行游移，切換整份文件則改用左右撥動頁籤。

如果想在不同檔案之間切換，改用左右方向鍵即可平順跳轉。

問題修復

對話畫面捲動修復，遠端連線不再前後亂跳

當你透過觸控板或滑鼠滾輪瀏覽長篇對話時，畫面滾動變得穩定滑順。

以前在 SSH（遠端連線協定）或 tmux 終端環境下，斜向滑動容易造成畫面忽前忽後跳動。現在系統會忽略對角滑動時的水平分量，並限制單次快速滾動的最大距離，徹底解決畫面抖動問題；按 Page Up 與 Page Down 鍵則依舊維持移動一整頁。

問題修復

特殊字元路徑修復，空格與特殊符號皆能正確開啟

當專案路徑包含空格、#、% 等特殊字元，或是存放在 Windows 磁碟機時，各項命令行功能現在都能正常運作。

以前在此類路徑下，CLI（終端機介面）常會解析錯誤或找不到檔案。現在不管是 @ 檔案標註、/codesearch 搜尋結果，還是代理回覆裡的檔案連結，都能準確開啟目標檔案；工作區信任機制與專案專屬自訂代理，也能正確辨識在這些資料夾中透過 Antigravity 桌面應用程式建立的專案。

English

FEATURE

Compact conversation view by default, collapsing thought processes and tool calls

When you open the terminal to chat with the AI, your screen is no longer flooded with endless internal reasoning.

The system changes the default Verbosity from high to medium. The conversation view now collapses related tool calls and thought processes into compact summaries, while fully preserving executed commands and response content.

Picture reading meeting minutes where, instead of pages of sprawling deliberations and stream-of-consciousness notes, an assistant has neatly condensed the discussion into bullet points, surfacing only key conclusions and action items while keeping the verbatim transcript available if you need to check details.

This change applies to users who have never configured verbosity, as well as those who selected high when high was the default. If you want to see the full tool calls, commands, and thought processes again, you can switch Verbosity back to high at any time in /config.

FEATURE

Diff view navigation update, using Up/Down and jk to browse line by line

When inspecting code changes with /diff in the terminal, keyboard navigation is now more intuitive and consistent.

The j and k keys in the file view now move the line cursor, behaving just like the up and down arrow keys. This aligns with the file list and standard Vim navigation habits, preventing accidental jumps to the previous or next file with a single keystroke.

Think of browsing a tabbed binder where pressing the up and down keys previously swapped out the entire document, whereas now moving up and down simply navigates line by line within the current page, leaving document switching to flipping tabs left and right.

To switch between different files, simply use the left and right arrow keys to jump smoothly.

BUGFIX

Conversation view scrolling fix, eliminating erratic jumps over remote connections

Scrolling long conversations with a trackpad or mouse wheel is now stable and smooth.

Previously under SSH or tmux terminal environments, diagonal swipes could cause the screen to jump erratically back and forth. The system now ignores the horizontal component of diagonal swipes and caps the maximum distance of a single rapid scroll, completely resolving jitter issues; pressing Page Up and Page Down continues to scroll by a full page as before.

BUGFIX

Special character path fixes, correctly opening files with spaces and symbols

When project paths contain spaces, special characters such as # and %, or reside on Windows drives, all command-line features now function properly.

Previously with such paths, the CLI often encountered parsing errors or failed to find files. Now, whether using @ file mentions, /codesearch results, or file links in agent responses, target files open accurately; workspace trust mechanisms and project-specific custom agents also correctly recognize projects created in these folders via the Antigravity desktop application.
