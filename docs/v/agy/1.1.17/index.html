Antigravity 1.1.17

發布日期：2026-08-21

zh-TW

代理程式改走同一路，工具行為更一致

同一件事交給代理程式（agent，能代你執行工作的程式）處理時，最怕換個入口就得到不同結果。這次把它的執行架構收斂成單一路徑，不論從哪裡啟動，都會經過同一套流程。這像車站把分散月台的列車導回同一條主線，調度規則終於一致。工具（讓它執行動作的功能）的行為會更一致。hook（掛鉤，特定事件發生時被觸發的小程式）也走這條路。提示（prompt，交代給它的工作說明）同樣如此。當你在不同操作中安排同樣的工作，入口不同帶來的差異會減少。

斜線指令不再憑空消失

想開啟團隊協作預覽時，指令卻從清單消失，會讓人以為功能根本不存在。這像常用的遙控器按鍵突然從面板上掉下來，設備還在，卻找不到叫它動的方法。現在 /teamwork-preview 與部分其他斜線指令（slash command，輸入 / 後可直接叫出的功能）不會再對某些使用者消失。需要用這些指令時，清單應能保留它們，讓你照原本的方式叫出對應功能。

Vim 輸入時按 Enter，也能開啟進行中的任務

你正用 Vim 插入模式（直接把文字輸入提示列的狀態）寫指令，想查看仍在執行的工作時，按 Enter 原本不會帶你進去。這像你正在記事本上寫字，卻按不開旁邊亮著的待辦事項；按鈕明明在眼前，手卻碰不到。現在提示列處於 Vim 插入模式時，Enter 能開啟進行中的背景任務（不佔著眼前操作、在後方持續執行的工作）。也能開啟子代理（subagent，由主代理分派工作的代理程式）。你不用先離開正在輸入的狀態，便能查看已啟動的工作。

Ogg 音訊與影片檔可正常附加

要把錄好的音訊或影片交給模型（讀取檔案並回應的 AI）時，副檔名明明是支援的格式，卻被拒收，特別讓人摸不著頭緒。這像寄件人把不同內容的包裹都貼成同一張過於籠統的標籤，收件處只好退回。現在可附加 .ogg、.opus 與 .ogv 檔案。先前它們都被當成通用的 application/ogg 類型送出，因此遭模型拒絕；這個附加問題已修正。下次你有這些 Ogg 音訊或影片，不必再因為送出時的檔案類型標記而卡住。

en

One execution route makes agent behavior more consistent

When an agent handles the same job through different entry points, differing results are a nuisance. Its execution harness now follows one path, so every starting point goes through the same process. It is like routing trains from scattered platforms onto one main line, where the dispatch rules finally match. Tool behavior is therefore more consistent. Hooks, small programs triggered by particular events, use that route too. Prompts, the instructions you give the agent, do as well. The same work should vary less just because you began it differently.

Slash commands no longer vanish

When you want the teamwork preview but its command has vanished from the list, it can seem as though the feature does not exist. It is like a familiar button falling off a remote: the device remains, but you cannot tell it what to do. /teamwork-preview and some other slash commands, commands you call by typing /, no longer disappear for some users. When you need them, they should remain in the list so you can call their features as before.

Enter opens active work even while typing in Vim mode

While typing a command in Vim insert mode, the state where text goes directly into the prompt, you might want to inspect work that is still running. Enter previously would not open it. It was like writing in a notebook while the lit-up to-do item beside it could not be opened; the button was visible but out of reach. Now Enter opens an active background task, work that keeps running behind your current action. It also opens a subagent, an agent assigned work by another agent. You can inspect that work without first leaving insert mode.

Ogg audio and video files can now be attached

When you give a recorded audio or video file to the model, the AI that reads files and responds, it is baffling to have a supported extension rejected. It was like putting the same overly general shipping label on packages with different contents, leaving the receiving desk to send them back. You can now attach .ogg, .opus, and .ogv files. They had all been sent as the generic application/ogg type, which made the model reject them; that attachment problem is fixed. Your Ogg audio and video no longer get stopped by that file-type label on the way in.
