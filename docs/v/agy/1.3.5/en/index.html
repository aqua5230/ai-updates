Antigravity 1.3.5

Released: 2026-10-14

Release notes

FEATURE

Auto Mode Arrives, Allowing Routine Changes Directly Without Repeated Confirmations

When asking AI to write code or edit files in the terminal, having to pause and press Enter for every single line often shatters your workflow.

Picture hiring an empowered executive assistant who handles editing notes or archiving files directly, knocking on your door only to shred critical records or sign major contracts.

The newly added auto mode (an execution mode that automatically approves safe operations) automatically allows file edits and safe commands, yet it still prompts before executing irreversible actions. If a command might escape the terminal sandbox (an isolated environment restricting program execution scope), an independent agent reviews it first. You can enter --mode auto, select Agent Mode in /config, or press Shift+Tab to cycle through modes. This feature is currently supported on Linux and macOS, with Windows support arriving in a future release.

FEATURE

New /compact Command Compresses Conversations Anytime to Free Up Memory

After multiple rounds of project discussions with AI, accumulating conversation logs often crowd the model's reading limit to capacity.

Think of organizing a bulky meeting notebook where reaching the bottom of a page once required archiving the entire binder for a fresh one, but now an assistant condenses prior discussions into a concise summary on the spot, freeing up clean pages for you to keep writing.

You can now enter /compact at any time to compress conversations and free up the context window (the maximum range of text an AI can read and retain at once). Running /compact by itself summarizes the current conversation and ends the turn. If you enter /compact <message>, it answers your new question right after finishing the summary. During compression, the terminal displays a Compacting conversation... progress indicator, and pressing Esc cancels at any time. Once finished, it clearly lists the total number of dialogue steps organized and how much context was reduced.

FEATURE

/diff Adds Syntax Highlighting and Folding, Ending Scrolling Freezes on Large Files

When reviewing code changes in the terminal, long stretches of unchanged text are often tedious to read, and unusually large files can even freeze the display.

Like reading a folded map with color-coded sticky notes, unfolding the entire sheet once made navigation cumbersome, but now key markers carry prominent background tints and repetitive routes fold away conveniently.

The /diff command now adds syntax highlighting, with tinted backgrounds for added and deleted lines, and each color scheme displays dedicated colors based on tokens (syntax units in code). Selecting the Terminal theme automatically detects terminal background tones to match colors, and /config as well as initial installation offer direct previews of /diff. Block headers now indicate the number of hidden unchanged lines above them. Pressing Ctrl+O expands or collapses the fold at the cursor, while pressing f toggles between changes-only and full text. These operations work as long as uncommitted files match the diff, and the footer explains when they are unavailable. Currently, only lines visible on screen are rendered, so scrolling, expanding, or opening full text no longer freezes. Files exceeding 100,000 lines or 10 MB disable expansion and full text while showing a footer notice.

BUGFIX

Remote iTerm2 Color Degradation Fixed, Restoring Full Color Over SSH

When using iTerm2 over an SSH connection, terminal display previously degraded to 256 colors if COLORTERM was not forwarded. Setting LC_TERMINAL=iTerm2 now directly enables full 24-bit color unless COLORTERM or NO_COLOR specifies otherwise. This color degradation issue has been resolved, allowing vivid color schemes to display normally during remote logins.
