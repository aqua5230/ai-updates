Antigravity 1.0.5

Released: 2026-07-13

Release notes

FEATURE

Unified permissions management with in-app editing and model launch flags

Managing system permissions is now a breeze.

The terminal intelligently merges your "project-specific permissions," "settings shared with the rest of Antigravity," and the "CLI's own config file" into one unified rule set, saving you from hunting down various config files. We've also added a brand-new /permissions command, allowing you to easily add, edit, or remove these rules directly inside the terminal. When launching the software, you can now instantly select your preferred AI model by adding the --model flag, or use the new models subcommand to see a list of all available options. Like a building's security system: you used to have to visit three different desks to set up an access card, but now everything is synchronized, and you can just tap the lobby's touchscreen a few times to let a guest in.

FEATURE

Uninterrupted code review, cleaner status lines, and smarter autocomplete

Your workflow is about to become much smoother.

Previously, if the system asked you to approve a command or was waiting for you to answer a question, you were blocked from opening the "Artifact Review" panel to look at the code; now, you can press ctrl+r at any time to switch over and check, and when you switch back, your progress is perfectly preserved so you never have to blindly guess. The status line at the bottom of the screen has also been redesigned: active tips and artifact statuses now merge into a single line, and if your window is narrow, the text gracefully truncates with an ellipsis (...) instead of crushing the layout into a mess. When using slash commands, if you type an abbreviation (like /se), hitting Tab will obediently autocomplete it to the alias you wanted (/settings), rather than obnoxiously replacing it with its underlying primary name (/config). Like filling out a questionnaire: you used to be forbidden from leaving your seat to double-check a book for the answer, but now you can get up to do research anytime, and when you return, your half-written answers are exactly where you left them—and the waiter will no longer rudely "correct" your pronunciation.

BUGFIX

SQLite support for history, fixed cache locations, and direct MCP URLs

We've exorcised a few details where the devil was hiding.

When opening /resume to browse your history, the list now filters out entirely empty conversations that used to clutter the view, loads details much faster, and even learned how to scan SQLite database files (.db and .db-wal) to give you a more comprehensive view. If you run the tool in text-only headless mode (-p), it now obediently writes its temporary cache data into the dedicated ~/.gemini/antigravity-cli/cache folder instead of treating your current working directory like a litter box. When configuring external MCP server tools, you can now connect directly by placing a URL in the config file, skipping unnecessary detours. Finally, if you manage custom tool directories, they can now properly be treated as functional workspace directories. Like buying a smarter vacuum cleaner: it used to collect empty wrappers while dumping the dust it sucked up all over your living room rug; now, it filters out the useless wrappers perfectly, plugs directly into your network pipe, and dumps the dirt precisely into its designated trash bin.
