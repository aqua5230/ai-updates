Antigravity 1.5.14

發布日期：2026-11-21

繁體中文

新功能

/thinking 即時展開思考過程

好奇 AI 給出答案前是怎麼一步步推理出來的嗎？現在只要輸入 /thinking on，對話紀錄就會在模型思考的當下即時串流顯示完整思考過程，想關閉就輸入 /thinking off。思考結束後，這段內容也會維持展開，不用另外按 Ctrl+O 打開。相關設定會以 "showThinking" 記在 settings.json 裡，預設為關閉。

就像上數學課看老師在黑板推算，以前他只把最終答案寫出來，想看過程還得自己翻筆記；現在每一步推導都直接留在黑板上，隨時抬頭就看得到。
新功能

/swarm board 新增 Overview 總覽

同時派出一批代理分頭處理專案，只要終端機視窗至少有 28 列高，打開 /swarm board 就能看到即時更新的 Overview 區塊。這個區塊會列出整體目標與總進度，格式像 Overview · N of M tasks done，若有卡住的項目也會標出受阻數量。 下面還會顯示最多六條工作線，各自用狀態燈號標明每個背景工作單元目前是在執行、審核中、等待同伴、已失敗還是已完成。

跟看車站大廳的列車動態看板一樣，以前得一節一節車廂去問進度，現在抬頭就有總表，幾班準點、幾班誤點或卡在路上全在一眼之內。
新功能

--remote-agent 新增 plan 模式

派遠端代理動手改檔案或跑指令前，如果想先看過它的規劃，現在可以在 --remote-agent 工作階段使用新加入的 plan 模式。代理可以先調查並寫出計畫，供你在改檔或執行指令前審核。 按 Shift+Tab 可在目前工作階段切換模式而不改預設值；啟動時加 --mode plan 會直接進入規劃模式，接續舊對話也能用 --mode 覆寫原設定。 到 /config 的 Remote Agent 分頁調整 Agent Mode（default、accept-edits、plan），會立即套用到目前對話並存成新遠端工作階段的預設值。

找裁縫師傅改衣服時，你可以先請他用粉筆畫好修改記號，看看他打算怎麼改。
新功能

Remote Control 檔案分頁新增方向鈕

用 Remote Control 網頁版看筆記或純文字檔，若內容是由右向左書寫且段落開頭夾帶英文單字，過去整段常會莫名跳回靠左對齊。現在 .md、.markdown 與 .txt 分頁的標題列多了 Switch to RTL text direction 按鈕，點下去就能順暢顯示右向文字。裡面的程式碼區塊與行號仍會維持由左向右。

在由右往左寫的信紙上夾帶英文地址時，以前整行字會跟著英文被拉去左邊；現在按下切換鍵，信件正文穩穩靠右排好，只有地址與編號照舊從左讀。
新功能

/model 可調 Orchestrator 雙模型

消費者方案在本地工作階段打開 /model，現在能在 Orchestrator 這一列同時指定 Planner 與 Executor 兩套模型，並各自調整思考 Effort。操作時用 Tab 或 Shift+Tab 在 Planner、Executor 與兩者的 Effort 滑桿之間移動，再用 ← 與 → 調整目前選中的項目。 選好的組合會以 "orchestrator" 儲存在 settings.json 與 --settings 裡。終端機底下的 status line（顯示在底部的即時狀態列）也會在 Orchestrator 旁標出目前啟用的規劃模型。

雙人划船比賽要發揮戰力，以前只能照大會配好的組合硬划；現在你能自己挑誰當舵手看方向、誰當槳手出全力，連兩個人各自出幾分力都調得出來。
新功能

medium 模式展開工具群組保留色彩與縮排

在 medium 詳細程度下按 Ctrl+O 或點擊檢視折疊項目，以前摘要標題會整條變灰，連失敗的紅色狀態標記也不例外。現在摘要標題列會保留原本的色彩，展開後的工具呼叫則會往內縮排，放在一條 │ 邊線之後。

新功能

網頁版工作區外授權改建議專案資料夾

用 Remote Control 網頁版請代理在工作區外新增或編輯檔案，權限提示現在會提供更寬的「永遠允許」建議。它會優先建議授權所屬儲存庫或專案資料夾，若沒有所屬專案則建議上一層資料夾，不必每次只放行單一檔案。 不過，像 .env 或 SSH 金鑰這類敏感檔案，以及家目錄或 /tmp 這類大範圍資料夾，選項仍會限制在該單一檔案。如果在提示框裡手動修改目標路徑，也會蓋掉原本的建議範圍。

向學校借教室辦活動時，以前每拿一隻麥克風都要單獨寫一張借條，現在會建議你一次借整個社團器材室，唯有保險箱裡的貴重器材還是要逐件簽領。
新功能

網頁版連續啟動子代理改為收合顯示

打開 Remote Control 瀏覽器畫面看對話，如果單一回合接連派出好幾個子代理，相鄰的啟動紀錄現在不再逐條攤開。相鄰的啟動項目會縮成單一列 Started N subagents，啟動進行中則顯示 Starting N subagents，點開就能查看並開啟每個子代理。

新功能

Auto 模式放寬免詢問直接讀取工作區外檔案

用預設的 Agent Mode（Auto 模式）跑任務，過去只要需要查看目前專案資料夾以外的檔案，都會先跳出確認視窗，除非你特地到 /config 開啟 Non-Workspace Access。現在 Auto 模式改為可以直接讀取工作區外的檔案，不再另外請示。 不過限制並沒有全部放開，在工作區外寫入或修改檔案仍須經你同意。你設定的 ask 與 deny 權限規則、像 mcp_config.json 這類受保護的設定檔、其他專案的對話紀錄，以及組織要求審查工作區外檔案的政策都照樣有效。

去鄰居書房借參考資料時，以前連翻開書看兩眼都要先問過主人，現在只要是純看書就能直接翻閱，但想拿筆改裡面的字，還是得先開口取得同意。
問題修復

修正 Windows 特殊路徑外洩憑證漏洞

Windows 版先前在工作區權限規則、@ 檔案提及、外掛、sidecars.json 與自訂代理中，遇到 UNC 網路、裝置或 NT 物件路徑時會有安全風險。這類路徑可能觸發查詢並把 Windows 登入憑證送到遠端主機，現在會直接拒絕而不存取。

問題修復

修正中斷回覆誤跑工具並導致驗證失敗

模型回覆如果中途出錯、被取消或被截斷，過去不完整的內容裡若帶有半套工具呼叫仍可能被執行。重試時也可能把那次壞掉的嘗試再送出去，導致後續對話出現思考簽章驗證錯誤，現在這些問題都已經修好。

問題修復

修正窄終端機寬表格標題截斷與斷字問題

在較窄的終端機觀看代理回覆的寬版 Markdown 表格，以前欄位標題會被截成 …，文字欄也擠到把單字從中間拆斷。這個排版問題已經修好，現在標題會正常換行，欄寬調整後能保住完整單字，只折斷長路徑與網址。

問題修復

修正外掛 $schema 清單解析與名稱截斷

外掛的 plugin.json 若宣告了 Agent Plugins $schema，過去用 /plugin、agy plugin list、agy plugin enable 與 agy plugin install 查看或操作時會列錯項目。技能、子代理、MCP（讓 AI 連接外部工具的協定）伺服器與掛鉤清單都會出錯，例如錯讀 mcp_config.json 而非 mcp.json。 把 hooks.json 誤報成名為 $schema 與 hooks 的 hook（掛鉤，特定事件發生時被觸發的小程式）這項錯誤已經修好。agy plugin install 摘要在 . 處截斷子代理名稱的問題也一併解決。

問題修復

修正外掛市集安裝失敗與錯誤登入提示

改用 GEMINI_API_KEY 連線而不靠已儲存的登入帳號，過去執行 agy plugin install <plugin>@<marketplace> 會跳出 unknown marketplace 錯誤。這個安裝失敗的問題已經修好。 代理在回覆中推薦外掛時，即使該外掛還沒安裝，以前也會附上原始市集編號顯示 The <id> plugin needs you to sign in. Open /plugin to sign in.。現在這句提示改為 Open /plugin to install or sign in to this plugin.。

問題修復

修正點數歸零卻一直亮出紅色餘額警告

啟用 AI 點數且點數餘額為 0 時，就算你還有一般模型額度可用，狀態列過去仍會一直掛著紅色的 AI: Out of credits 警告。這個問題已經修好，現在狀態列只有在點數餘額大於 0 時才會顯示 AI 點數。

問題修復

修正遠端代理列出不支援的本機模型

在 --remote-agent 工作階段下 /model 挑選項時，過去清單裡仍看得到實際跑不動的項目，選了也只會跳出一段令人一頭霧水的錯誤。現在 /model 會把遠端代理不支援的模型標上 not available for remote agents，並省略本機自訂模型。 若改用不支援的模型送出請求，則會明確回報這則錯誤訊息：

<model> isn't available for remote conversations yet. Choose another model and try again.
問題修復

修正按 Esc 取消送出與續發訊息異常

送出訊息後、畫面上明明已經顯示 esc to cancel 正在做送前檢查，這時按下 Esc 過去卻攔不住訊息送出，反而照樣跑完一整輪代理回應。現在在這個空檔按 Esc 會直接中止發送，並顯示 Message not sent: canceled before it was sent。 上一輪還在收尾清理時若按 Esc 取消，過去會清掉 Interrupted 狀態提示。緊接著送出的下一則訊息，還會被以 executor has not processed the previous input yet 擋下。現在 Interrupted 提示會繼續留著，後續訊息也會排隊等到取消完成再處理。

問題修復

修正逾時取消的命令掛鉤殘留背景行程

在 Linux 與 macOS 透過 hooks.json 觸發外部指令時，過去執行到一半被中斷或等太久停掉後，它衍生的子任務仍會留在背後繼續跑。這個問題已經修好，現在停止命令型掛鉤時會一併結束它的整個行程群組。

問題修復

修正工作流腳本末尾寫 return 會報錯

run_workflow 執行結尾帶有頂層 return 的 Python 工作流腳本，過去會跳出 workflow syntax error: 'return' outside function 而失敗。現在腳本末尾的 return 會直接被評估為這個工作流的執行結果。

問題修復

修正網頁版停止或插隊送出時弄丟草稿

在 Remote Control 網頁版剛送出追問訊息、還沒傳送完成就立刻按下 Stop，過去整則訊息會直接消失。現在它會連同 @ 提及、附件與審查留言一起退回輸入框，接在你後來新打的文字後面。 對排隊中的訊息點 Send Now 時，以前輸入框裡打到一半的草稿、附件或審查留言會被清空覆寫。現在這些內容都會保留下來，連續點擊多次 Send Now 也會依序送出。

問題修復

修正非 Markdown 產出物留言計數異常

在 Remote Control 網頁版側邊欄對程式碼或其他非 Markdown 產出物加上行內留言，過去顯示與送出都會出錯。Review 按鈕上的留言數會停在零，側邊欄與 Overview Panel 也漏掉計數徽章，按下 Proceed 還會拆成多個獨立膠囊。現在這些問題都已經修好。

問題修復

修正 iPhone 網頁版輸入框與鍵盤錯位

拿 iPhone 打開 Remote Control 瀏覽器介面傳訊息時，打字區過去不是滑到螢幕下方被蓋住，就是浮在半空中留出一塊空白。不論是對話頁、首頁，還是子代理分頁這類側邊欄抽屜裡，這個與螢幕鍵盤對不齊的問題現在都已經修好。

English

FEATURE

Stream /thinking live in real time

Curious how the AI reasons step by step before giving an answer? Run /thinking on to stream the model's full thinking live in the transcript while it thinks, or /thinking off to turn it off. Finished thoughts stay expanded without pressing Ctrl+O. This setting is saved as "showThinking" in settings.json and is off by default.

Picture a math class watching a teacher work on the blackboard: previously only the final answer was written up and you had to check your notes for the steps, but now every step stays right on the board whenever you look up.
FEATURE

Add Overview section to /swarm board

When dispatching a group of agents to work on a project in parallel, opening /swarm board in a terminal at least 28 rows tall now shows a live Overview section. It displays the overall goal and task progress in the format Overview · N of M tasks done, along with any blocked count. Below that, up to six workstream threads use status indicators to show whether each background worker is working, in review, waiting on a peer, failed, or done.

A departure board in a train station concourse works the same way: instead of checking progress car by car, you can look up at one summary table to see how many trains are on time, delayed, or stuck on the tracks.
FEATURE

Add plan mode to --remote-agent

If you want to review a remote agent's plan before it edits files or runs commands, --remote-agent sessions now include plan mode. The agent can research and write a plan for your review before making changes or running commands. Press Shift+Tab to switch modes for the current session without changing your saved default, start with --mode plan to enter plan mode right away, or pass --mode when resuming a conversation to override its saved setting. Adjusting Agent Mode (default, accept-edits, plan) on the Remote Agent tab of /config updates the current conversation immediately and saves it as the default for new remote sessions.

Think of taking clothes to a tailor: you can ask them to mark the alterations in chalk first so you can see how they plan to change the fit.
FEATURE

Add RTL direction button to Remote Control file tabs

When viewing notes or plain text files in the Remote Control browser view, right-to-left prose starting with an English word used to snap unexpectedly to left alignment. Now the header of .md, .markdown, and .txt tabs includes a Switch to RTL text direction button so right-to-left text renders cleanly, while code blocks and line numbers stay left-to-right.

Suppose you write a right-to-left letter that includes an English address: previously the whole line got pulled to the left with the English text, whereas pressing the toggle keeps the body aligned cleanly on the right while only the address and numbers read from the left.
FEATURE

Configure both Orchestrator models in /model

On consumer plans in local sessions, opening /model lets you pick both the Planner and Executor models on the Orchestrator row and adjust each one's thinking Effort. Press Tab or Shift+Tab to move between Planner, Executor, and their Effort sliders, then use ← and → to change the selected choice. Your selection is saved under "orchestrator" in settings.json and --settings. The status line (the live bar at the bottom of the terminal) also shows the active planner model next to Orchestrator.

To get the most out of a two-person rowing race, you previously had to row with whatever pairing the organizers assigned; now you can pick who steers the course and who pulls the oars, and even tune how much power each one puts in.
FEATURE

Keep colors and indentation in expanded medium tool groups

When expanding collapsed items in medium verbosity with Ctrl+O or by clicking, the summary header previously dimmed to gray—even red status markers on failed runs. Now the summary header row keeps its original colors, and expanded tool calls are indented behind a │ gutter.

FEATURE

Suggest project folders for outside-workspace prompts on web

When asking an agent to create or edit a file outside the workspace in the Remote Control browser view, permission prompts now offer a broader "always allow" suggestion. They suggest the enclosing repository or project folder first, or the parent folder when there is none, instead of approving only one file at a time. However, sensitive files such as .env or SSH keys and broad folders such as your home directory or /tmp remain limited to that single file. Editing the target path in the prompt also overrides the suggested scope.

When borrowing a room at school for an event, you previously had to sign a separate slip for every microphone; now you are offered the whole club equipment room at once, except for valuables in the safe that still require individual sign-off.
FEATURE

Collapse consecutive subagent launches in browser view

When viewing a conversation in the Remote Control browser view, consecutive subagent launches within a single turn are no longer listed one by one. Adjacent launches collapse into a single Started N subagents row—or Starting N subagents while launching—that you can expand to view and open each subagent.

FEATURE

Allow Auto mode to read outside workspace without asking

When running tasks in the default Agent Mode (Auto mode), viewing files outside the current project folder previously triggered a confirmation prompt unless you enabled Non-Workspace Access in /config. Auto mode now reads files outside the workspace directly without asking. Not all restrictions are lifted, though—writing or editing files outside the workspace still requires your approval. Your ask and deny permission rules, protected config files such as mcp_config.json, other projects' conversations, and organization policies requiring outside-workspace file review all still apply.

Consider borrowing reference books from a neighbor's study: previously you had to ask the owner just to open a book and glance at it, whereas now you can read freely, though picking up a pen to edit the text still requires asking first.
BUGFIX

Fix Windows credential leak via special paths

On Windows, UNC network, device, and NT object paths in workspace permission rules, @ file mentions, plugins, sidecars.json, and custom agents previously posed a security risk. Those paths could trigger a lookup that sent Windows login credentials to a remote host, and are now rejected without being accessed.

BUGFIX

Fix interrupted responses running partial tools and failing validation

When a model response errored out, was canceled, or got cut off partway through, partial tool calls in the incomplete response could still run. Retrying could also resend that broken attempt, causing thinking-signature validation errors in later turns; both issues are now fixed.

BUGFIX

Fix wide table headers and mid-word breaks on narrow terminals

When viewing wide Markdown tables from agent responses on narrow terminals, column headers used to get cut off with … and text columns were squeezed until words broke mid-word. This layout issue is fixed: headers now wrap properly, and column widths keep whole words intact while only breaking long paths and URLs.

BUGFIX

Fix plugin $schema listing errors and name truncation

When a plugin's plugin.json declared an Agent Plugins $schema, /plugin, agy plugin list, agy plugin enable, and agy plugin install used to list the wrong items. Skills, subagents, MCP (a protocol that lets AI connect to external tools) servers, and hooks were all listed incorrectly, such as reading mcp_config.json instead of mcp.json. The bug that misreported hooks.json as hooks (small programs triggered by specific events) named $schema and hooks is now fixed. The agy plugin install summary cutting off subagent names at . is also resolved.

BUGFIX

Fix marketplace plugin install failures and sign-in prompts

When connecting with GEMINI_API_KEY instead of a saved sign-in, running agy plugin install <plugin>@<marketplace> used to fail with an unknown marketplace error. This installation failure is now fixed. When an agent suggested a plugin in its response, it used to include a raw marketplace ID and say The <id> plugin needs you to sign in. Open /plugin to sign in. even if the plugin was not installed. That prompt now reads Open /plugin to install or sign in to this plugin..

BUGFIX

Fix persistent red out-of-credits warning at zero balance

When AI credits were enabled and your credit balance was 0, the status line used to keep showing a red AI: Out of credits warning even while normal model quota was still available. This is now fixed, and the status line only shows AI credits when your balance is greater than 0.

BUGFIX

Fix remote agents listing unsupported local models

When choosing a model with /model in a --remote-agent session, the list used to include options that could not actually run, and picking one threw a confusing error. Now /model labels models unsupported by remote agents as not available for remote agents and omits local custom models. If you send a request with an unsupported model, it now clearly reports this error message:

<model> isn't available for remote conversations yet. Choose another model and try again.
BUGFIX

Fix Esc failing to cancel sends and breaking follow-up messages

Right after submitting a message, while esc to cancel was already shown during pre-send checks, pressing Esc used to fail to stop the send and still ran a full agent turn. Pressing Esc in that window now aborts the send and displays Message not sent: canceled before it was sent. Pressing Esc to cancel while the previous turn was still tearing down used to clear the Interrupted status hint, and an immediate follow-up message would be rejected with executor has not processed the previous input yet. The Interrupted hint now stays visible, and follow-up messages queue until cancellation finishes.

BUGFIX

Fix timed-out or canceled command hooks leaving background processes

When external commands were triggered via hooks.json on Linux and macOS, child processes used to keep running in the background if the hook was canceled mid-run or timed out. This is now fixed, and stopping a command hook terminates its entire process group.

BUGFIX

Fix workflow scripts failing on trailing return statements

When run_workflow ran a Python workflow script ending with a top-level return, it used to fail with workflow syntax error: 'return' outside function. Now a trailing return is evaluated directly as the workflow's result.

BUGFIX

Fix browser Stop and Send Now losing message drafts

In the Remote Control browser view, pressing Stop right after submitting a follow-up message before it finished sending used to drop the entire message. It is now returned to the message box along with its @ mentions, attachments, and review comments, placed after any new text you started typing. Clicking Send Now on a queued message used to clear or overwrite any in-progress draft, attachments, or review comments in the message box. All of those are now preserved, and multiple Send Now clicks are sent in order.

BUGFIX

Fix Comment Count Bugs on Non-Markdown Artifacts

Adding inline comments to code or other non-Markdown artifacts in the side panel of the Remote Control browser view previously caused display and submission errors. The comment count on the Review button stayed at zero, the sidebar and Overview Panel were also missing comment-count badges, and clicking Proceed split them into separate pills. These issues are now fixed.

BUGFIX

Fix iPhone Browser Message Box Alignment

When sending messages in the Remote Control browser view on an iPhone, the message box previously either slid behind the on-screen keyboard or floated in mid-air with a blank gap. This misalignment with the on-screen keyboard is now fixed in conversations, on the home screen, and in side-panel drawers such as subagent tabs.

Added `/thinking` (`/thinking [on|off]`, saved as `"showThinking"` in `settings.json` and off by default) to stream the model's full thinking live in the transcript while it thinks and keep finished thoughts expanded without pressing `Ctrl+O`.
Original changelog/swarm board 新增 Overview 總覽
Added a live `Overview` section to `/swarm board` on terminals at least 28 rows tall, showing the swarm's goal, overall task progress (`Overview · N of M tasks done` and any blocked count), and up to six workstream threads with status indicators for which workers are working, in review, waiting on a peer, failed, or done.
Original changelog--remote-agent 新增 plan 模式
Added `plan` mode to `--remote-agent` sessions, so a remote agent can research and write a plan for your review before editing files or running commands: switch to it with `Shift+Tab`, start in it with `--mode plan`, or choose `plan` under `Agent Mode` on the `Remote Agent` tab of `/config`.
Added an `Agent Mode` setting (`default`, `accept-edits`, and `plan`) to the `Remote Agent` tab of `/config` in `--remote-agent` sessions: choosing a mode saves it as your default for new remote sessions and updates the current conversation, while `Shift+Tab` switches modes for the session without changing your saved default and `--mode` overrides a resumed conversation's saved mode.
Original changelogRemote Control 檔案分頁新增方向鈕
Added a `Switch to RTL text direction` button to the header of Markdown (`.md`, `.markdown`) and `.txt` file tabs in the side panel of the Remote Control browser view, so right-to-left prose renders cleanly without paragraphs that start with English words snapping left, while code blocks and line numbers stay left-to-right.
Original changelog/model 可調 Orchestrator 雙模型
Improved the `Orchestrator` row in `/model` on consumer plans in local sessions so you can pick both its `Planner` and `Executor` models and each one's thinking `Effort` (saved under `"orchestrator"` in `settings.json` and `--settings`): press `Tab` or `Shift+Tab` to move between `Planner`, `Executor`, and their `Effort` sliders, use `←` and `→` to change the focused choice, and see the active planner next to `Orchestrator` in the status line.
Original changelogmedium 模式展開工具群組保留色彩與縮排
Improved expanded tool groups in `medium` verbosity: expanding a group with `Ctrl+O` or by clicking now keeps the summary header's colors, including red status markers on failed runs, instead of dimming it to gray, and indents the expanded tool calls behind a `│` gutter.
Original changelog網頁版工作區外授權改建議專案資料夾
Improved permission prompts for creating or editing a file outside the workspace in the Remote Control browser view: the "always allow" options now suggest the enclosing repository or project folder (or the parent folder when there is none) instead of only that single file, while sensitive files such as `.env` or SSH keys and broad folders such as your home directory or `/tmp` stay limited to the exact file, and editing the target path in the prompt overrides the suggestion.
Original changelog網頁版連續啟動子代理改為收合顯示
Improved turns that launch several subagents in a row in the Remote Control browser view: consecutive subagent launches now collapse into a single `Started N subagents` row (`Starting N subagents` while launching) that you can expand to see and open each subagent.
Original changelogAuto 模式放寬免詢問直接讀取工作區外檔案
Changed Auto mode (the default `Agent Mode`) to allow reading files outside the workspace without asking for approval; previously Auto mode prompted before reading outside the workspace unless `Non-Workspace Access` was turned on in `/config`. Writing or editing files outside the workspace still asks for approval, and your `ask` and `deny` permission rules, protected configuration files such as `mcp_config.json`, other projects' conversations, and organization policies requiring outside-workspace file review still apply.
Original changelog修正 Windows 特殊路徑外洩憑證漏洞
Fixed a security issue on Windows where network (UNC), device, and NT object paths in workspace permission rules, `@` file mentions, plugins, `sidecars.json`, and custom agents could trigger a lookup that sent Windows credentials to a remote host; those paths are now rejected without being accessed.
Original changelog修正中斷回覆誤跑工具並導致驗證失敗
Fixed model responses that error out, are canceled, or are cut off partway through running partial tool calls from the incomplete response or resending that broken attempt on retry, which could make later turns fail with thinking-signature validation errors.
Original changelog修正窄終端機寬表格標題截斷與斷字問題
Fixed wide Markdown tables in agent responses cutting off column headers with `…` and squeezing text columns until words broke mid-word on narrow terminals; headers now wrap and columns are sized to keep words intact while breaking long paths and URLs.
Original changelog修正外掛 $schema 清單解析與名稱截斷
Fixed `/plugin`, `agy plugin list`, `agy plugin enable`, and `agy plugin install` listing the wrong skills, subagents, MCP servers, and hooks for plugins whose `plugin.json` declares an Agent Plugins `$schema` (such as reading `mcp_config.json` instead of `mcp.json` or reporting `hooks.json` as hooks named `$schema` and `hooks`), and fixed the `agy plugin install` summary cutting off subagent names at a `.`.
Original changelog修正外掛市集安裝失敗與錯誤登入提示
Fixed `agy plugin install <plugin>@<marketplace>` failing with `unknown marketplace` when you connect with a `GEMINI_API_KEY` instead of a saved sign-in.
Fixed plugin suggestions in agent responses telling you `The <id> plugin needs you to sign in. Open /plugin to sign in.` with a raw marketplace catalog ID even when the plugin was not installed; they now say `Open /plugin to install or sign in to this plugin.`
Original changelog修正點數歸零卻一直亮出紅色餘額警告
Fixed the status line permanently showing a red `AI: Out of credits` warning when AI credits are enabled and your credit balance is `0`, even while normal model quota is still available; the status line now shows AI credits only when you have a positive balance.
Original changelog修正遠端代理列出不支援的本機模型
Fixed `--remote-agent` sessions offering local-only and custom models that remote agents cannot run, and showing an unexplained error when a model is unavailable remotely: `/model` now marks models that remote agents don't support as `not available for remote agents` and omits local custom models, and requests with an unsupported model report `<model> isn't available for remote conversations yet. Choose another model and try again.`
Original changelog修正按 Esc 取消送出與續發訊息異常
Fixed pressing `Esc` right after submitting a message — while the CLI already showed `esc to cancel` during pre-send checks — failing to stop the message from being sent and running a full agent turn; canceling in that window now aborts the send and shows `Message not sent: canceled before it was sent`.
Fixed pressing `Esc` to cancel a turn while it is still tearing down clearing the `Interrupted` status hint and rejecting an immediate follow-up message with `executor has not processed the previous input yet`; the `Interrupted` hint now stays visible and follow-up messages queue until cancellation finishes.
Original changelog修正逾時取消的命令掛鉤殘留背景行程
Fixed command hooks in `hooks.json` on Linux and macOS leaving child processes running in the background after a hook times out or is canceled; stopping a hook now terminates its entire process group.
Original changelog修正工作流腳本末尾寫 return 會報錯
Fixed `run_workflow` failing with `workflow syntax error: 'return' outside function` when a Python workflow script ends with a top-level `return` statement; a trailing `return` is now evaluated as the workflow's result.
Original changelog修正網頁版停止或插隊送出時弄丟草稿
Fixed pressing `Stop` right after submitting a follow-up message in the Remote Control browser view, before the message finished sending, dropping your message; it is now put back in the message box with its `@` mentions, attachments, and review comments, after anything new you've started typing.
Fixed clicking `Send Now` on a queued message in the Remote Control browser view clearing or overwriting a draft, attachments, or review comments you were typing in the message box, and kept multiple `Send Now` clicks in order.
Original changelog修正非 Markdown 產出物留言計數異常
Fixed inline comments added to code and other non-Markdown artifacts in the side panel of the Remote Control browser view leaving the `Review` button at zero comments, missing comment-count badges in the sidebar and Overview Panel, and splitting into separate pills when you click `Proceed`.
Original changelog修正 iPhone 網頁版輸入框與鍵盤錯位
Fixed the message box in the Remote Control browser view on iPhone either sliding behind the on-screen keyboard or floating with a blank gap above it in conversations, on the home screen, and in side-panel drawers such as subagent tabs.
