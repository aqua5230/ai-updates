Antigravity 1.0.14

Released: 2026-06-25 ~ 06-30

Release notes

FEATURE

Pasting clipboard images now works inside tmux panes too

Tmux (a tool that lets you run multiple panes inside a terminal session that keeps running in the background) users previously couldn't paste clipboard images directly while using Antigravity inside it, and had to work around it some other way to get a screenshot into the chat.

Now you can just paste it, exactly as easily as in a regular terminal.

FEATURE

`/goal` no longer cuts long tasks short — the AI can run until it's actually done

/goal (the command that sets a long-term objective and lets the AI plan its own steps to get there) used to be capped at a maximum runtime — the system would force it to stop even if the task wasn't done.

That cap is now removed: the AI keeps working until the task is genuinely complete or you cancel it yourself, with no mid-task interruption from the system.

FEATURE

Picking a skill command from autocomplete now actually runs it, instead of doing nothing

Skill (skill, a pre-packaged set of command templates invoked with a leading /) commands used to occasionally clear the input box without actually submitting, when you picked them from the autocomplete (autocomplete, the suggestion list that pops up partway through typing) list — selecting it had no effect.

Now it's fixed: picking from the list reliably submits and runs.

FEATURE

"Always Approve" rules now default to exact matching, far less likely to wave through a dangerous lookalike command

'Always Approve' rules (Always Approve, settings that let matching commands skip asking for your consent every time) used to default to matching with loose regular expressions (regex, a pattern-matching syntax that's flexible but can accidentally let through things that look similar but aren't), which now default to strict literal matching instead — much less likely to wave through a dangerous command that merely resembles an approved one.

If you really need the flexibility of fuzzy matching, you can opt in by prefixing a rule with regex:. It's like an access card reader that used to accept cards that 'looked close enough'; now it requires an exact match unless you specifically tell it to relax.

FEATURE

Safe output-redirection commands no longer get blocked for re-approval every single time

Genuinely safe, common patterns like tool > file (redirecting a command's output into a file, where > is a redirection symbol) used to often get flagged as 'not quite the same' as a previously approved command, forcing you to re-approve every time, because the matching rules were too strict.

These checks are now relaxed — safe output-redirection commands can apply your existing approval rules directly, without being asked again every time.

FEATURE

Links in the terminal are now clickable, and you can press shift+n to step backward through a diff

Terminals that support it can now render URLs as genuinely clickable links (OSC8, a technical standard for clickable hyperlinks inside terminal text), while older unsupported terminals automatically fall back to plain text instead of garbled output.

Also, the unified diff review screen (diff review, the view that compares code before and after a change) now has a shift+n shortcut to cycle backward through changes, instead of only being able to move forward.

BUGFIX

Makefile syntax inside code blocks no longer gets mistaken for math formulas and garbled

Antigravity supports LaTeX (a markup syntax dedicated to typesetting math formulas) math rendering, but it used to misread Makefile (a config syntax for writing build instructions) patterns like $(call ...) inside code blocks as math formula syntax, garbling the output.

A new state machine now restricts math-formula parsing to plain prose paragraphs only, so code block contents no longer get caught in the crossfire.
