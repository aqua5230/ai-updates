Usage 0.30.23

發布日期：2026-09-26

繁體中文

新功能

Antigravity 卡片支援切換兩組額度

如果你在 Antigravity 裡習慣呼叫 Claude 或 GPT 模型，以前工具卡片上永遠只顯示 Gemini 的消耗量。

現在標題旁多了一個常駐標籤顯示目前的模型組別，點擊 Gemini ⇄ 就能切換成 Claude / GPT ⇄，系統會記住你的選擇。切換時會直接以最近一次抓取的快照重繪畫面，完全不需再次發送網路請求，並重新啟動消耗速度預測，避免兩組額度混合計算。這項功能支援全數 13 款包含 Antigravity 卡片的主題，且在 macOS 與 Windows 上都能運作。

跟雙幣帳戶在手機上翻頁查帳一樣，以前只顯示台幣餘額，現在按一下就能查看外幣，切換時直接讀取剛剛的紀錄而不必重打網路，兩邊的扣款預測也不會混在一起。
新功能

Muse Code 呼叫花費納入統計與報表

當你在專案中使用 Muse Code 輔助寫程式時，現在它產生的每筆費用都能被完整追蹤。

工具會讀取 ~/.local/share/muse/sessions/**/session.jsonl 中的工作階段紀錄，依據紀錄 ID 排除重複項目，並以每次請求消耗的 token（AI 處理與計費的文字單位）對照 LiteLLM 的 meta/muse-* 模型價格計算金額。這些花費會計入今日開銷、專案累積總計、HTML 報表與 usage 命令列工具。即使在斷網環境下，離線備援價目表也已補上 muse-spark-1.3 的計費依據。由於 Muse 本身沒有存放本機額度資料，因此不會額外提供 Muse 額度卡片。

好比總務人員定期整理出差單據，以前分散在各處的零星開銷無人清查，現在按紀錄編號剔除重複並對照標準價目，即便離線也有備用表可查，全數彙整到當日帳本中。
新功能

開發工具版本更新

你在檢查專案的自動化工作流程時，想確認底層換了什麼，清單列出三項：ruff 更新到 0.16.8，astral-sh/setup-uv 更新到 10.2.0，CodeQL actions 也更新了；原文沒有提供 CodeQL actions 的新版本號。

這份紀錄只列更新項目，沒有交代這次換版後的實際效果。

像核對器材更換單，前兩件寫出新型號，第三件只註明已更換；拿到這張單，你知道哪些器材換過，卻不知道換後用起來有何不同。

English

FEATURE

Antigravity Cards Support Switching Between Two Quota Sets

If you regularly use Claude or GPT models in Antigravity, tool cards previously only displayed Gemini usage.

A persistent badge next to the title now shows the current model group, allowing you to click Gemini ⇄ to switch to Claude / GPT ⇄, and the system remembers your choice. Switching immediately redraws the interface using the most recent snapshot without making another network request, while restarting burn rate predictions to keep both quota calculations separate. This feature supports all 13 themes containing Antigravity cards and runs on both macOS and Windows.

Think of checking a mobile dual-currency account: it previously showed only the local balance, but now a single tap reveals foreign currency, directly loading recent records without new network requests and keeping deduction forecasts from mixing together.
FEATURE

Muse Code Usage Costs Included in Statistics and Reports

When you use Muse Code to assist with coding in your projects, every expense it generates is now fully tracked.

The tool reads session records in ~/.local/share/muse/sessions/**/session.jsonl, deduplicates entries by record ID, and calculates costs by matching tokens consumed per request against LiteLLM meta/muse-* model pricing. These expenses are included in today's spending, project cumulative totals, HTML reports, and the usage command-line tool. Even when disconnected, the offline fallback price list includes billing rates for muse-spark-1.3. Because Muse does not store local quota data, no additional Muse quota card is provided.

Picture an administrative clerk sorting travel receipts: previously scattered expenses went unchecked, but now duplicates are removed by record ID and matched against standard rates—with an offline backup table on hand—fully compiling everything into the daily ledger.
FEATURE

Development Tool Version Updates

When checking your project's automated workflow to see what changed underneath, the list outlines three items: ruff was updated to 0.

16.8, astral-sh/setup-uv was updated to 10.2.0, and CodeQL actions was also updated, though the source provided no new version number for CodeQL actions. This log only lists updated items without explaining the actual effects of the version bump.

Checking an equipment replacement form works similarly: the first two items list new model numbers while the third only notes it was replaced; holding this slip, you know which equipment was swapped, but not how it feels to use afterward.
