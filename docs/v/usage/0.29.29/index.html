墨刷貓成為 usage 的新圖示

想在選單列一眼認出 usage 時，墨刷貓也會出現在應用程式圖示上，讓你能沿著同一個標記找到它。這是 usage 的新圖示，選單列的符號和應用程式圖示都改用它。

像店家把門口招牌與名片換成同一枚手繪印記：兩個入口雖在不同地方，認得的都是同一家店。

不只應用程式圖示，選單列的符號也採用這隻貓；無論從哪一處看到 usage，使用的都是同一個新標記，兩處設計保持一致。

Matrix 與 Cloud Observation 讓背景穿過卡片

卡片幾乎遮住背景時，Matrix 落下的字元只像難以看清的紋理，Cloud Observation 的雲也容易把面板洗成白色。

這像在玻璃舞台前掛上半透明布幕：後面的動態仍看得見，前方的內容則留在自己的位置。

Matrix 的卡片變得更透明，讓落下的字元讀起來像在移動的背景，不再只是難以看見的紋理。Cloud Observation 的天空更深、卡片更淺，飄動的雲會從額度列後方通過，而不會把整個面板洗成白色。

Origami 的重設時間重新看得清

想看 Origami 何時重設，卻得在深藍折角上找同色文字時，原本幾乎都辨認不出來。以前深藍折角上的同色文字幾乎融進紙面，幾乎沒有對比，難以辨認。

像在深色摺紙上寫字，筆畫太接近紙色便看不出來；換成較深的筆觸，再加一圈淡淡光暈，字就能跨過每道摺線被讀到。

現在重設那一行改用較深的字重和淡淡光暈，無論落在折頁哪一處都看得清楚。

Claude 卡片第二行不再被底部裁掉

Claude 卡片裡的內容排到第二行時，最後一截曾在閱讀時被卡片底部遮住而看不見。原本顯示到第二行的內容，會在卡片下緣被截斷，讀到一半就少了一截。

像把紙條塞進有透明窗的名牌套：窗框不該蓋住最後一行，內容應完整落在可見範圍內。

現在卡片底部不會再壓住第二行，讓顯示在第二行的文字都能從頭到尾完整看清楚，不再有任何部分在底部被裁掉。

更新通知不再露出 Markdown 格式記號

打開更新通知想看版本說明，卻先遇到 ** 和 ` `` 這些格式記號。Markdown（用符號標示粗體或程式碼的文字格式）原本應先被轉成可讀文字，但更新對話框裡的 release notes 曾把它們直接顯示出來。

這像餐廳把廚房的備料標籤連同菜一起端上桌；現在端出的版本說明只留下讀者要看的內容。

你在更新對話框讀 release notes 時，不必再把那些格式符號當成正文的一部分。

English

An ink-brush cat becomes usage's new icon

Spot usage at a glance in the menu bar, then find the same ink-brush cat again on its app icon. It is usage's new icon, used both for the menu-bar glyph and the app icon.

It is like a shop giving its front sign and business card the same hand-drawn mark: the entrances differ, but both point to the same shop.

The cat is not limited to the app icon; the menu-bar glyph uses it too, so both places carry the same new mark.

Matrix and Cloud Observation let their backdrops show through

When cards almost hide the backdrop, Matrix's falling glyphs are only a hard-to-see texture and Cloud Observation's clouds can wash the panel white.

It is like hanging a translucent curtain in front of a glass stage: movement behind it remains visible while the material in front stays in place.

Matrix cards are more translucent, making the falling glyphs read as a moving backdrop rather than a barely visible texture. Cloud Observation has a deeper sky and lighter cards, so drifting clouds pass behind the quota rows instead of washing the whole panel white.

Origami reset times are readable again

Trying to see when Origami resets meant hunting for same-blue text on a dark-blue folded corner, where it was almost impossible to make out. The same-blue text on a dark-blue folded corner used to nearly disappear into the paper.

It was like writing on dark origami with ink too close to the paper's color; a darker stroke and a faint halo let the words cross every fold and remain readable.

The reset line now has a darker weight and faint halo, so it can be read on any part of the fold.

The second row on the Claude card stays clear of the bottom edge.

When content on a Claude card reached the second row, its last part used to vanish behind the card's bottom edge. Previously, content reaching that row could be cut off at the lower boundary, leaving part of the line out of sight.

It is like sliding a label into a badge holder with a clear window: the frame should not cover the last line, and the whole message belongs inside the visible area.

The bottom of the card no longer covers the second row, so its text can be read from beginning to end.

Update notifications stop exposing raw Markdown markers

You open an update notification to read the release notes, only to meet raw ** and ` `` markers first. Markdown is a text format that uses symbols for such things as bold text and code, but the update dialog had been displaying those symbols literally.

It was like serving a dish with the kitchen's prep labels still attached; the release notes now present the content meant for the reader.

You no longer need to treat those formatting symbols as part of the release notes in the update dialog.
