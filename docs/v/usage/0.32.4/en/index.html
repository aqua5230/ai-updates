Usage 0.32.4

Released: 2026-10-05

Release notes

FEATURE

Windows tray allows switching quota sources, taskbar adds transparent remaining balance

While coding on Windows, you can always check the remaining quota of major AI tools at a glance.

You can now specify whether to display quota for Claude Code or Codex directly in the system tray or popover menu, and this preference persists after restarting the app. If Codex has not yet reported session information, it automatically falls back to the weekly quota. A transparent quota label can also be enabled next to the notification area at the bottom of the desktop, supporting display scaling as well as light and dark themes while hiding automatically in full-screen mode. The label sits to the left of taskbar buttons and the News and Interests weather widget, moves to an outer position when space is tight, and clicking to toggle the panel does not cause interface jank.

Picture a desk meter with selectable channels: instead of staring at a single fixed number, you can now switch which expense you track, and it automatically shifts position when desk space gets tight so it never blocks your way.
FEATURE

Background process checks for updates hourly, failures clearly explain causes

During long working sessions, you can receive new release notifications promptly without having to restart the application.

On macOS and Windows, usage now re-evaluates automatic checks hourly instead of checking only at launch, while preserving the original 24-hour check interval, grace periods, and skipped version rules. If a check fails, it retries after intervals of 1, 1, 2, 4, and 6 hours, popping up an update dialog once a new version is found. Users who previously disabled auto-checks via an old setting removed in June will also have automatic checks re-enabled. When clicking Check for Updates manually fails on Windows, the dialog explains causes such as being offline, server errors, or unreadable responses. In situations such as rate-limited GitHub requests (HTTP 403 or 429 status codes), the dialog provides Retry and Cancel buttons to try again or dismiss.

Like a building manager checking mailboxes on a regular schedule, instead of only notifying you about registered mail when you first step out the door, patrols run periodically, retrying sequentially if the courier is delayed while explaining why delivery stalled.
FEATURE

Menu bar displays warning icons when auto-start or Token Saver is blocked

When background automation or token-saving mechanisms cannot run, you can quickly spot the issue right on the menu bar.

On macOS and Windows, Auto-start 5-hour Session records every outcome and retries after 10 minutes when the window is idle. A final failure adds a ⚠ icon to the menu bar where hovering displays the cause, and a notification is sent if reminders are enabled. The same error does not trigger duplicate notifications, and a single success clears the warning. Starting with Codex 0.129, only trusted hooks are executed. If the startup hook of usage is not trusted, the Token Saver item also displays a ⚠ symbol, prompting you to enter /hooks in Codex to enable it. usage only reads trust settings without granting permissions on its own, which usage doctor also reports.

Think of warning lights on factory machinery: instead of silently grinding to a halt when something fails, the console now flashes an amber light with an explanatory note.
FEATURE

Antigravity alerts on expired sign-ins, auto-start switches to updated model

When tracking usage with Antigravity, the interface provides clear next steps if account authentication lapses or background connections fail.

When login credentials expire, the quota card directly displays Sign-in expired and prompts you to log in again. The terminal command usage status --json and the side popover report not_signed_in, automatically clearing the warning after the next successful quota check. In addition, background keepalive previously ran into continuous connection errors by requesting the deprecated Gemini 3.5 Flash (Low) model. It has now been updated to Gemini 3.8 Flash (Low), restoring the auto-start mechanism to normal operation.

A building access gate handles credential renewals cleanly: instead of silently locking the turnstile when an access pass expires, the screen displays a tap-again prompt while the backend updates to the latest frequency band to keep traffic moving.
FEATURE

Foreground app still displays notification banners, terminated background jobs marked correctly

When switching between desktop windows, task progress and system alert statuses are now more accurate.

On macOS, notification banners display normally even while usage is running in the foreground, and denied notification permissions are recorded in the log file. The side popover also corrects background job statuses: when receiving killed, stopped, or cancelled notifications, the panel marks them as stopped. The interface no longer mislabels prematurely terminated jobs as completed, preventing misinterpretations of execution results.

Package tracking systems handle status milestones with precision: instead of stamping an interrupted return as successfully delivered, notifications pop up right in front of you and halted shipments are clearly marked as stopped.
