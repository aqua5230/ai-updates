Usage 0.32.4

發布日期：2026-10-05

繁體中文

新功能

Windows 系統匣可切換額度來源，工作列支援透明剩餘數字

在 Windows 上寫程式時，你隨時都能一眼掌握主要 AI 工具的剩餘額度。現在你可以直接在系統匣或面板選單中，指定要顯示 Claude Code 或 Codex 的額度（quota，可用額度上限），重開軟體後也會記住這項偏好。若 Codex 尚未回報工作階段（session，單次對話視窗）資訊，則會自動改用每週額度備援。桌面底端也能在通知區域旁開啟透明的額度標籤，支援螢幕縮放與深淺色主題，遇到全螢幕時會自動隱藏。標籤會排在工作列按鈕與「新聞和興趣」天氣元件左側，空間不足時改放外側位置，點擊切換面板時也不會卡住介面。

如同在辦公桌角擺放可自選頻道的微型跳表，以前只能看固定數字，現在能自由切換要盯哪項開銷，位置不夠還會自動挪位避免擋路。
新功能

常駐背景每小時檢查新版本，更新失敗清楚說明原因

長時間開著電腦工作時，不用特地重開程式也能即時收到新版發布通知。macOS 與 Windows 上的 usage 現在每小時都會重新評估自動檢查，不再只於啟動時檢查，並維持原本 24 小時檢查間隔、忽略期與略過版本的規則。若檢查失敗，會依序等 1、1、2、4、6 小時重試，發現新版就會跳出更新視窗。過去曾在 6 月已移除的舊設定中關閉自動檢查的人，也會重新恢復自動檢查。在 Windows 上手動點擊 Check for Updates（檢查更新）若失敗，對話方塊會說明離線、伺服器報錯或回應無法讀取等原因。面對 GitHub 請求受限（HTTP 403 或 429 代碼）等狀況，視窗會提供 Retry 與 Cancel 按鈕讓你重試或取消。

像大樓管理員定期巡視信箱，以前只有你剛出門才會告知有掛號信，現在每隔一陣子主動巡檢，信差延遲時還會依序重試並說明卡關原因。
新功能

自動啟動與精簡模式遇阻時，選單列直接標註警告符號

當背景自動排程或省流機制無法運作時，你能在選單列上迅速掌握問題。在 macOS 與 Windows 上，Auto-start 5-hour Session（自動啟動 5 小時工作階段）會記錄每次結果，視窗閒置時 10 分鐘後重試。最終失敗會在選單列旁加上 ⚠ 符號，停留可看原因，開啟提醒時亦會發送通知；同錯誤不重複通知，成功一次即清掉警告。Codex 0.129 起只執行已信任的 hook（掛鉤，特定事件觸發的小程式）。若 usage 的啟動掛鉤未獲信任，Token Saver（精簡模式）項目也會標註 ⚠，提示到 Codex 輸入 /hooks 啟用。usage 只讀取信任設定而不自行授權，usage doctor 也會回報。

彷彿工廠機台的警報燈，以前失效只會默默停工，現在會亮黃燈並附上說明。
新功能

Antigravity 登入過期即時提醒，自動啟動改用新模型

使用 Antigravity 追蹤用量時，若帳號驗證失效或背景連線中斷，介面會清楚指引下一步。當登入憑證失效時，額度卡片會直接標示 Sign-in expired（登入已過期）並提示重新登入。終端機指令 usage status --json 與側邊面板會回報 not_signed_in，待下次成功查詢額度後即自動清除警告。另外，背景保活程式原本因請求已下架的舊版 Gemini 3.5 Flash (Low) 模型，導致連線不斷出錯。現在已更新為 Gemini 3.8 Flash (Low)，讓自動啟動機制恢復正常。

恰似門禁刷卡系統換發新卡，以前通行證過期只會無聲卡住閘門，現在螢幕會跳出重新感應提示，主機也同步對齊最新頻段確保暢通。
新功能

前景執行仍能接收通知橫幅，已終止背景工作正確標記

在桌面上切換不同視窗操作時，各項工作進度與系統提醒的狀態現在更加精確。在 macOS 上，即使 usage 正位於前景使用中，系統仍會正常顯示通知橫幅，若通知權限遭拒也會記錄至日誌檔。此外側邊面板也修正了背景工作狀態，當收到 killed、stopped 或 cancelled 通知時，面板會標示為 stopped（已停止）。畫面不再將中途終止的工作誤植為 completed（已完成），避免誤判執行結果。

跟包裹追蹤系統的進度更新一樣，以前中途退件會被誤蓋上順利送達印章，現在視窗開在眼前照樣跳出快訊，配送中斷也會確實標記為已停止。

English

FEATURE

Windows tray allows switching quota sources, taskbar adds transparent remaining balance

While coding on Windows, you can always check the remaining quota of major AI tools at a glance. You can now specify whether to display quota for Claude Code or Codex directly in the system tray or popover menu, and this preference persists after restarting the app. If Codex has not yet reported session information, it automatically falls back to the weekly quota. A transparent quota label can also be enabled next to the notification area at the bottom of the desktop, supporting display scaling as well as light and dark themes while hiding automatically in full-screen mode. The label sits to the left of taskbar buttons and the News and Interests weather widget, moves to an outer position when space is tight, and clicking to toggle the panel does not cause interface jank.

Picture a desk meter with selectable channels: instead of staring at a single fixed number, you can now switch which expense you track, and it automatically shifts position when desk space gets tight so it never blocks your way.
FEATURE

Background process checks for updates hourly, failures clearly explain causes

During long working sessions, you can receive new release notifications promptly without having to restart the application. On macOS and Windows, usage now re-evaluates automatic checks hourly instead of checking only at launch, while preserving the original 24-hour check interval, grace periods, and skipped version rules. If a check fails, it retries after intervals of 1, 1, 2, 4, and 6 hours, popping up an update dialog once a new version is found. Users who previously disabled auto-checks via an old setting removed in June will also have automatic checks re-enabled. When clicking Check for Updates manually fails on Windows, the dialog explains causes such as being offline, server errors, or unreadable responses. In situations such as rate-limited GitHub requests (HTTP 403 or 429 status codes), the dialog provides Retry and Cancel buttons to try again or dismiss.

Like a building manager checking mailboxes on a regular schedule, instead of only notifying you about registered mail when you first step out the door, patrols run periodically, retrying sequentially if the courier is delayed while explaining why delivery stalled.
FEATURE

Menu bar displays warning icons when auto-start or Token Saver is blocked

When background automation or token-saving mechanisms cannot run, you can quickly spot the issue right on the menu bar. On macOS and Windows, Auto-start 5-hour Session records every outcome and retries after 10 minutes when the window is idle. A final failure adds a ⚠ icon to the menu bar where hovering displays the cause, and a notification is sent if reminders are enabled. The same error does not trigger duplicate notifications, and a single success clears the warning. Starting with Codex 0.129, only trusted hooks are executed. If the startup hook of usage is not trusted, the Token Saver item also displays a ⚠ symbol, prompting you to enter /hooks in Codex to enable it. usage only reads trust settings without granting permissions on its own, which usage doctor also reports.

Think of warning lights on factory machinery: instead of silently grinding to a halt when something fails, the console now flashes an amber light with an explanatory note.
FEATURE

Antigravity alerts on expired sign-ins, auto-start switches to updated model

When tracking usage with Antigravity, the interface provides clear next steps if account authentication lapses or background connections fail. When login credentials expire, the quota card directly displays Sign-in expired and prompts you to log in again. The terminal command usage status --json and the side popover report not_signed_in, automatically clearing the warning after the next successful quota check. In addition, background keepalive previously ran into continuous connection errors by requesting the deprecated Gemini 3.5 Flash (Low) model. It has now been updated to Gemini 3.8 Flash (Low), restoring the auto-start mechanism to normal operation.

A building access gate handles credential renewals cleanly: instead of silently locking the turnstile when an access pass expires, the screen displays a tap-again prompt while the backend updates to the latest frequency band to keep traffic moving.
FEATURE

Foreground app still displays notification banners, terminated background jobs marked correctly

When switching between desktop windows, task progress and system alert statuses are now more accurate. On macOS, notification banners display normally even while usage is running in the foreground, and denied notification permissions are recorded in the log file. The side popover also corrects background job statuses: when receiving killed, stopped, or cancelled notifications, the panel marks them as stopped. The interface no longer mislabels prematurely terminated jobs as completed, preventing misinterpretations of execution results.

Package tracking systems handle status milestones with precision: instead of stamping an interrupted return as successfully delivered, notifications pop up right in front of you and halted shipments are clearly marked as stopped.
