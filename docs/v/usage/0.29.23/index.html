兩款新面板，像彩繪玻璃或摺紙般看用量

想換個心情看額度卡嗎？「Switch Panel」現在多了 Stained Glass 與 Origami 兩種面板（顯示用量卡片的外觀）。前者把卡片放在不規則彩色多邊形與鉛條分隔裡，光影會緩緩掃過；後者用單色三角摺面呈現，載入時展開一次便停住，不像其他面板持續循環。兩者都可在 macOS 和 Windows 系統匣選用，因為結構相同，沿用 Classic 的固定高度。像把同一份帳單放進彩繪玻璃窗或折好的紙雕裡：內容沒變，看的感覺換了。另有測試會核對 Windows 清單與高度表是否和 macOS 面板名冊一致，避免只加到其中一邊。

連點熱圖標題，貪食蛇會來吃格子

貢獻熱圖（用格子顯示每天活動量的圖）標題藏了一個小遊戲：1.5 秒內連按三下，貪食蛇就會沿著格子來回穿梭，最後自行還原。蛇從第一週有資料的位置起步，所以整年空白時不會白跑；若裝置設為 prefers-reduced-motion（要求網站少用動態效果的偏好），遊戲會略過。要把熱圖匯出成 HTML、CSV 或 PNG 前，蛇也會先停止並重設，因此輸出的網頁、表格或圖片不會拍到蛇吃到一半。這像筆記本角落的翻頁動畫：想看時才叫它出來，交出去的正式副本仍是原本那頁。

九種面板改共用同一套骨架，警示不再漏顯示

原本挑不同面板看用量，看到的資訊可能不一樣：八個面板漏了 Codex 過期、額度或歷史資料載入失敗的警示，五個也沒有 Install Hook 按鈕；Win95 還有一個過期狀態清除問題。原因像九間各自抄同一份作業的分店，每份腳本平均超過兩百行，久了改到各走各的。現在 classic、matrix、win95 等九種卡片面板都接到同一支 panel_core.js 核心腳本（共用處理邏輯的檔案），所以綁定資訊的規則一致。進度條材質、專案列排法、切換按鈕和裝飾動畫仍各自保留；測試也會攔下日後再複製整份腳本的新面板。

網站互動更細緻，說明內容同步校正

逛公開網站時，游標聚光、捲動後淡入、帶彈性的滑過效果與完整鍵盤操作等九項細修，讓頁面回應更豐富；它們參考 Framer Motion、GSAP 等常見做法，卻以原生 CSS 和 JavaScript 重寫，沒有新增相依套件。網站也把容易誤會的說明補正：World Cup 2026 面板其實沒有 Antigravity 卡或拖曳排序；五語說明改為「CLI 會保留紀錄，但不會自動重新附回」。主題圖庫加入 Classic、Cloud Observation、Prism Arcade、Lepidoptera 截圖，README 加快速跳轉清單，DEVELOPMENT 補寫 Antigravity。導覽列換成手繪 SVG 腳印與官方 GitHub 圖示，並移除四張過時功能卡和翻譯鍵。像展場重新掛好指示牌：燈光更會跟著人走，地圖也不再標出不存在的展品。

en

Two new ways to view usage: stained glass and origami

Want a different mood while checking your quota cards? Switch Panel now includes Stained Glass and Origami, two panel themes (the visual treatment around those cards). Stained Glass places them behind irregular colored polygons and leaded dividers, with light slowly sweeping over them. Origami uses monochrome triangular folds that open once on load, then stop rather than looping. Both are available on macOS and from the Windows tray, and reuse Classic's measured height because their structure is the same. It is like putting the same bill in a stained-glass window or a folded paper sculpture: the contents stay put, but the view changes. A test also checks that Windows' panel list and height table match macOS' registry, so a theme cannot quietly be added to only one side.

Triple-click the heatmap title to summon a snake

The contribution heatmap (a grid showing activity by day) hides a tiny game. Triple-click its title within 1.5 seconds and a snake winds back and forth through the grid, then restores it on its own. It starts at the first week with data, so it does not run pointlessly across an empty year. If your device uses prefers-reduced-motion (a setting that asks websites to limit motion), the game is skipped. Before an HTML, CSV, or PNG export, the snake also stops and resets, so your exported webpage, spreadsheet, or image never catches it mid-bite. Think of it as a flip-book animation in a notebook corner: call it up when you want it, while the copy you hand over remains the original page.

Nine panels now share one backbone, so warnings stop going missing

Choosing a different usage panel used to change which information you saw: eight panels omitted Codex stale, quota, or history-load warnings; five had no Install Hook button; and Win95 had a small stale-state clearing bug. It was like nine branches copying the same homework: each script had grown past 200 lines on average, then drifted apart. Now all nine card panels, including classic, matrix, and win95, feed into panel_core.js, a core script (a file holding shared handling rules), so their bindings are consistent. Their real visual differences remain: progress-bar materials, project-row layouts, theme-switch buttons, and decorative animation. A test also blocks future panels from being made by copying the whole script again.

Website interactions get polish, while its copy catches up

While you browse the public website, nine polish passes now add things such as cursor spotlights, fade-ins after scrolling, springy hover states, and full keyboard navigation. They draw on familiar patterns from Framer Motion and GSAP, but were rewritten in plain CSS and JavaScript, with no new dependency added. The copy has caught up too: the World Cup 2026 panel does not have an Antigravity card or drag-to-reorder, and the five-language explanation now says the CLI keeps a record but does not automatically reattach it. The gallery adds screenshots for Classic, Cloud Observation, Prism Arcade, and Lepidoptera; READMEs gain jump lists; DEVELOPMENT mentions Antigravity. Navigation now uses a hand-drawn SVG paw and official GitHub icon, while four outdated feature cards and their translation keys are gone. Like rehanging a museum's signs: lighting responds more gracefully, and the map no longer points to exhibits that are not there.

ja

利用状況を彩色ガラスや折り紙のように見る二つの新パネル

使用量カードの見た目を変えたいとき、Switch Panel に Stained Glass と Origami が加わった。どちらもパネル（使用量カードを表示する外観）のテーマである。Stained Glass は不規則な色付き多角形と鉛の仕切りの奥にカードを置き、光がゆっくり横切る。Origami は単色の三角形の折り目で表し、読み込み時に一度だけ開いて止まる。他のパネルのように繰り返し動かない。macOS と Windows のトレイから選べ、構造が Classic と同じなので高さも引き継ぐ。同じ請求書をステンドグラスか折り紙の作品に入れるようなものだ。内容は変わらず、眺め方だけが変わる。Windows の一覧と高さ表が macOS の登録内容と一致するかをテストし、片方だけに追加されるのも防ぐ。

ヒートマップの題名を3回押すとヘビが現れる

日ごとの活動をマス目で示す貢献ヒートマップの題名には、小さな遊びが隠れている。1.5 秒以内に3回クリックすると、ヘビがマス目を蛇行して進み、最後には自動で元に戻る。データのある最初の週から始めるので、1年分が空でも無駄に動かない。prefers-reduced-motion（サイトに動きを減らすよう求める端末設定）が有効なら、この遊びは表示しない。HTML、CSV、PNG に書き出す前にもヘビを止めてリセットするため、ウェブページ、表計算、画像の出力に途中の姿が残らない。ノートの隅にあるパラパラ漫画のようなものだ。見たいときだけ動かし、提出するコピーは元のページのままである。

9種類のパネルが同じ骨組みを共有し、警告の表示漏れを防ぐ

利用状況を見るパネルを変えると、表示される情報まで変わっていた。8個のパネルでは Codex の古い状態、利用枠、履歴読み込み失敗の警告が抜け、5個には Install Hook ボタンもなかった。Win95 には古い状態を消す小さな不具合もあった。9店舗が同じ宿題を別々に写したようなもので、各スクリプトは平均200行以上に膨らみ、次第に別の内容になったためである。今は classic、matrix、win95 など9種類のカードパネルが panel_core.js というコアスクリプト（共通の処理規則を入れたファイル）を通るので、情報を結び付ける規則がそろう。進行バーの素材、プロジェクト行、切替ボタン、装飾アニメーションは各テーマに残る。テストは今後、スクリプト全体の複製で新パネルを作ることも防ぐ。

サイトの操作感を磨き、説明も現状に合わせて修正

公開サイトを眺めると、カーソルを追うスポットライト、スクロール後のフェードイン、ばねのようなホバー、完全なキーボード操作など、9項目の磨き込みが加わっている。Framer Motion や GSAP のよくあるパターンを参考にしつつ、CSS と JavaScript だけで書き直し、新たな依存関係は加えていない。説明も現状に合わせた。World Cup 2026 のパネルには Antigravity カードもドラッグ並べ替えもなく、5言語の説明は「CLI は記録を残すが自動で再び紐付けない」と修正された。ギャラリーには Classic、Cloud Observation、Prism Arcade、Lepidoptera の画像を追加し、README にはジャンプ一覧、DEVELOPMENT には Antigravity の記述を加えた。ナビゲーションは手描き SVG の足跡と公式 GitHub アイコンに替え、古い機能カード4枚と翻訳キーも削除した。展示会の案内板を掛け直すようなものだ。照明は人の動きに合わせ、地図は存在しない展示を指さない。

ko

스테인드글라스와 종이접기처럼 사용량을 보는 두 새 패널

할당량 카드를 보는 기분을 바꾸고 싶다면 Switch Panel에 Stained Glass와 Origami가 추가됐다. 둘은 패널(사용량 카드를 보여 주는 겉모양) 테마다. Stained Glass는 불규칙한 색 다각형과 납선 칸막이 뒤에 카드를 놓고 빛이 천천히 훑고 지나간다. Origami는 단색 삼각 접힌 면으로 나타내며, 불러올 때 한 번 펼쳐진 뒤 멈춘다. 다른 패널처럼 계속 반복하지 않는다. 둘 다 macOS와 Windows 트레이에서 고를 수 있고 구조가 Classic과 같아 높이도 그대로 쓴다. 같은 청구서를 스테인드글라스 창이나 접은 종이 조각 안에 넣는 셈이다. 내용은 같고 보는 느낌만 달라진다. Windows의 패널 목록과 높이 표가 macOS 등록 목록과 맞는지도 테스트해 한쪽에만 테마가 추가되는 일을 막는다.

히트맵 제목을 세 번 누르면 뱀이 나타난다

하루별 활동을 칸으로 보여 주는 기여 히트맵 제목에는 작은 놀이가 숨어 있다. 1.5초 안에 세 번 누르면 뱀이 칸을 지그재그로 지나가고 마지막에는 저절로 원래 모습으로 돌아온다. 데이터가 있는 첫 주에서 출발하므로 1년 전체가 비어 있으면 쓸데없이 움직이지 않는다. prefers-reduced-motion(웹사이트에 움직임을 줄여 달라고 요청하는 기기 설정)이 켜져 있으면 이 놀이는 건너뛴다. HTML, CSV, PNG로 내보내기 전에도 뱀을 멈추고 초기화해 웹페이지, 표, 이미지에 먹는 도중 모습이 찍히지 않는다. 공책 귀퉁이의 플립북 애니메이션과 같다. 보고 싶을 때만 움직이고, 건네는 사본은 원래 페이지 그대로다.

아홉 패널이 한 뼈대를 공유해 경고가 빠지지 않는다

사용량 패널을 바꾸면 보이는 정보까지 달랐었다. 여덟 패널에는 Codex 오래된 상태, 할당량, 기록 불러오기 실패 경고가 빠졌고 다섯 패널에는 Install Hook 버튼도 없었다. Win95에는 오래된 상태를 지우는 작은 문제도 있었다. 아홉 지점이 같은 숙제를 따로 베낀 꼴이었다. 각 스크립트는 평균 200줄 넘게 자라면서 서로 다른 길로 흩어졌다. 이제 classic, matrix, win95 등을 포함한 아홉 카드 패널은 panel_core.js 코어 스크립트(공통 처리 규칙을 담은 파일)를 거치므로 정보를 연결하는 규칙이 같다. 진행 막대 재질, 프로젝트 행 배치, 테마 전환 버튼, 장식 애니메이션은 각 테마에 남는다. 테스트는 앞으로 스크립트 전체를 복사해 새 패널을 만드는 일도 막는다.

웹사이트 움직임을 다듬고 설명도 현재에 맞췄다

공개 웹사이트를 둘러볼 때 커서를 따라가는 조명, 스크롤 뒤 서서히 나타나는 효과, 탄성 있는 마우스 올림 반응, 완전한 키보드 탐색 등을 포함한 아홉 가지 다듬기가 더해졌다. Framer Motion과 GSAP의 익숙한 방식을 참고했지만 CSS와 JavaScript만으로 다시 써 새 의존성은 넣지 않았다. 설명도 현재 모습에 맞췄다. World Cup 2026 패널에는 Antigravity 카드나 끌어서 순서 바꾸기 기능이 없으며, 다섯 언어 설명은 CLI가 기록은 남기지만 자동으로 다시 붙이지는 않는다고 고쳤다. 갤러리에는 Classic, Cloud Observation, Prism Arcade, Lepidoptera 화면을 더했고 README에는 빠른 이동 목록, DEVELOPMENT에는 Antigravity 설명을 넣었다. 탐색 막대는 손그림 SVG 발자국과 공식 GitHub 아이콘으로 바꾸고, 오래된 기능 카드 넉 장과 번역 키는 없앴다. 전시장 안내판을 다시 거는 일과 같다. 조명은 사람 움직임에 반응하고 지도는 없는 전시품을 가리키지 않는다.
