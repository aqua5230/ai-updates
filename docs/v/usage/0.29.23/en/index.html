Usage 0.29.23

Released: 2026-08-10

Release notes

FEATURE

Two new ways to view usage: stained glass and origami

Want a different mood while checking your quota cards? Switch Panel now includes Stained Glass and Origami, two panel themes (the visual treatment around those cards).

Stained Glass places them behind irregular colored polygons and leaded dividers, with light slowly sweeping over them. Origami uses monochrome triangular folds that open once on load, then stop rather than looping. Both are available on macOS and from the Windows tray, and reuse Classic's measured height because their structure is the same. It is like putting the same bill in a stained-glass window or a folded paper sculpture: the contents stay put, but the view changes. A test also checks that Windows' panel list and height table match macOS' registry, so a theme cannot quietly be added to only one side.

FEATURE

Triple-click the heatmap title to summon a snake

The contribution heatmap (a grid showing activity by day) hides a tiny game.

Triple-click its title within 1.5 seconds and a snake winds back and forth through the grid, then restores it on its own. It starts at the first week with data, so it does not run pointlessly across an empty year. If your device uses prefers-reduced-motion (a setting that asks websites to limit motion), the game is skipped. Before an HTML, CSV, or PNG export, the snake also stops and resets, so your exported webpage, spreadsheet, or image never catches it mid-bite. Think of it as a flip-book animation in a notebook corner: call it up when you want it, while the copy you hand over remains the original page.

FEATURE

Nine panels now share one backbone, so warnings stop going missing

Choosing a different usage panel used to change which information you saw: eight panels omitted Codex stale, quota, or history-load warnings; five had no Install Hook button; and Win95 had a small stale-state clearing bug.

It was like nine branches copying the same homework: each script had grown past 200 lines on average, then drifted apart. Now all nine card panels, including classic, matrix, and win95, feed into panel_core.js, a core script (a file holding shared handling rules), so their bindings are consistent. Their real visual differences remain: progress-bar materials, project-row layouts, theme-switch buttons, and decorative animation. A test also blocks future panels from being made by copying the whole script again.

FEATURE

Website interactions get polish, while its copy catches up

While you browse the public website, nine polish passes now add things such as cursor spotlights, fade-ins after scrolling, springy hover states, and full keyboard navigation.

They draw on familiar patterns from Framer Motion and GSAP, but were rewritten in plain CSS and JavaScript, with no new dependency added. The copy has caught up too: the World Cup 2026 panel does not have an Antigravity card or drag-to-reorder, and the five-language explanation now says the CLI keeps a record but does not automatically reattach it. The gallery adds screenshots for Classic, Cloud Observation, Prism Arcade, and Lepidoptera; READMEs gain jump lists; DEVELOPMENT mentions Antigravity. Navigation now uses a hand-drawn SVG paw and official GitHub icon, while four outdated feature cards and their translation keys are gone. Like rehanging a museum's signs: lighting responds more gracefully, and the map no longer points to exhibits that are not there.
