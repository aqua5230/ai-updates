Usage 0.33.1

發布日期：2026-10-07

繁體中文

新功能

沒裝 Claude Code，只靠桌面版也能查額度

平常習慣直接打開桌面版軟體跟 AI 聊天，現在不用另外裝命令列工具也能隨時盯緊用量。

找不到 Claude Code 的額度檔時，程式會改去讀取 Claude 桌面版的本機歷史紀錄，連 Windows 的微軟商店安裝版也支援。畫面上能直接看見工作階段與每週的使用百分比。要是本機 HTTP 快取（暫存查過資料的地方）剛好留有近期一致的回應，還會附上準確的重置時間。整趟過程不使用登入憑證，也不發送額度 API（查詢額度的介面）請求，遇到沒把握的時間絕不瞎猜，還會清楚標示資料是多久以前記下的，也會處理過期資料。

像在辦公桌瞄一眼牆上的出勤打卡白板，以前沒領到專屬通行證就完全看不到剩餘天數，現在直接幫你把公佈欄的現成紀錄抄過來，既不用額外跑去人資櫃檯重問，也不會偷翻你的私人抽屜。
新功能

Windows 工作列右鍵點額度標籤，立刻跳出選單

在 Windows 桌面緊盯剩餘額度時，不必特地把滑鼠移到角落找小圖示。

現在只要直接在工作列的額度文字上按滑鼠右鍵，就能叫出跟系統匣（螢幕角落放背景小圖示的區域）一模一樣的功能選單。彈出的選單會自動顯示在工作列外側，不管你把工作列釘在螢幕的上下左右哪一邊都不會被遮蔽。至於原本用滑鼠左鍵點擊的習慣依然保留，按一下同樣會打開完整的額度面板。

宛如在電視邊框摸到快捷鍵，以前要調模式非得跑回主機面板按選單，現在隨手一按就跳出懸浮視窗，還會自動閃開邊框不擋住螢幕。
新功能

Windows 版加入新手與額度感知開關，跨工具用量一覽無遺

在 Windows 上找 Claude Code 的模式開關時，現在可以直接到系統匣選單操作。

系統匣選單裡的「Claude Code」子選單現在補齊了新手模式與額度感知模式這兩項開關，跟側邊面板放在同一個群組，操作體驗直接對齊 macOS。開啟額度感知模式後，系統在 Windows 上也能跨界讀取 Codex 與 Antigravity 的額度狀況，幫你一手掌握不同助理的消耗進度。

彷彿在多功能儀表板上裝了整合切換鈕，以前要看各家工具的用量得自己逐一開分頁對照，現在打開同一個抽屜就能直接切換模式，連其他幫手的剩餘油量也能順便讀到。

English

FEATURE

Check your quota from the desktop app alone, no Claude Code install needed

If you usually just open the desktop app to chat with the AI, you can now keep an eye on usage anytime without installing a separate command-line tool.

When the program can't find Claude Code's quota file, it falls back to reading the Claude desktop app's local history, and it even supports the Microsoft Store install on Windows. The screen shows your session and weekly usage percentages directly. If the local HTTP cache (where previously fetched data is temporarily stored) happens to hold a recent matching response, it also includes the accurate reset time. The whole process uses no login credentials and sends no quota API (the interface for querying quota) requests; it never guesses at times it isn't sure about, clearly marks how long ago the data was recorded, and handles stale data.

Picture glancing at the attendance whiteboard on the office wall from your desk: before, without your own access pass you couldn't see the remaining days at all, but now the existing records on the bulletin board are simply copied over for you—no extra trip to the HR counter to ask again, and no peeking into your private drawer.
FEATURE

Right-click the quota label on the Windows taskbar and a menu pops up instantly

When watching your remaining quota on the Windows desktop, you no longer have to move the mouse to a corner hunting for a tiny icon.

Now just right-click directly on the quota text in the taskbar to summon the exact same function menu as the system tray (the area in the screen corner that holds background icons). The pop-up menu automatically appears outside the taskbar, so it never gets covered no matter which edge of the screen—top, bottom, left, or right—you pin the taskbar to. The original left-click habit is kept too: one click still opens the full quota panel.

Like finding a shortcut button on the TV frame: before, switching modes meant walking back to the main unit's panel to press the menu, but now a casual press pops up a floating window that automatically moves clear of the frame so it doesn't block the screen.
FEATURE

Windows gains newcomer and quota-aware toggles, with cross-tool usage at a glance

When looking for Claude Code's mode switches on Windows, you can now operate them straight from the system tray menu.

The "Claude Code" submenu in the system tray menu now includes both the newcomer mode and quota-aware mode toggles, grouped together with the side panel so the experience matches macOS directly. Once quota-aware mode is on, the system can also read the quota status of Codex and Antigravity across tools on Windows, helping you track the consumption progress of different assistants in one place.

Think of a unified toggle added to a multi-function dashboard: before, checking each tool's usage meant opening tabs one by one to compare them yourself, but now you open a single drawer to switch modes directly, and even the remaining fuel of the other helpers gets read along the way.
