Usage 0.30.2

Released: 2026-08-28

Release notes

FEATURE

Oversized panels scale down to fit screen instead of clipping

Like a camera automatically zooming out to wide-angle when capturing a tall skyscraper, fitting the entire building proportionally into the viewfinder instead of slicing off the roof.

When a popover grows too tall for the screen, it now scales down proportionally rather than getting clipped.

Previously, clamp_content_height() capped height strictly to the visible screen frame, leaving any lower rows unreachable and invisible. The new panels/panel_scale.py module computes a fit scale that stays above MIN_PANEL_SCALE, and macOS's PopoverViewController.applyPanelScale() together with Windows's _WindowsTrayController._apply_panel_zoom() apply it across the entire panel using window.usageApplyPanelZoom().

FEATURE

Codex status lines install cleanly on dotted and subtable configs

Codex status lines now install and remove reliably even when config.toml lacks a bare [tui] header.

Configurations declaring tui solely through [tui.*] subtables or top-level dotted keys previously caused setup and removal routines to write nothing while falsely claiming success. Helper functions _insert_table_line(), _remove_table_line(), and _replace_table_line() now support both config structures, parse and validate every proposed edit with tomllib.loads, and raise a clear failure when no change can be made safely.

It is like an electrician inspecting a breaker box: wiring connections correctly whether the label sits on the main switch or individual branch circuits, testing voltages before power-up, and flagging faults instead of pretending everything is installed.
FEATURE

Windows builds point hidden imports to current installer modules

Windows build scripts now direct their hidden import flags to the current installer module paths.

The v0.29.37 update restored the missing wintray.app and tui.app entry points; after a separate code refactor, scripts/build_windows.ps1 still pointed to session_hooks and setup_hook as obsolete top-level modules. The packaged executable was never broken because main.py imports both statically, but the outdated flags were dead configuration of the exact kind that previously caused broken v0.29.34–36 builds. They now properly specify installer.session_hooks and installer.setup_hook, enabling PyInstaller to diagnose any future omissions.

It is like updating warehouse addresses on a shipping checklist: keeping the registry accurate ensures the system catches a missing crate before trucks leave the dock.
FEATURE

Double-clicked macOS app toggles login items safely with UTF-8

Like a customs inspector who once defaulted to English-only and rejected any foreign package, now equipped with a universal dictionary to replace unreadable symbols and keep shipments moving.

Toggling login items on macOS no longer fails when the app is launched via double-click.

Without the LANG environment variable, subprocess.run(..., text=True) defaulted to ASCII, causing a UnicodeDecodeError whenever launchctl or gh outputs contained non-ASCII characters. These process outputs are now explicitly parsed using UTF-8 encoding, safely substituting replacement characters for any invalid byte sequences.

FEATURE

Claude cost totals add advisor iterations and one-hour cache writes

Claude cost totals now accurately capture advisor iterations and one-hour cache write expenses.

Claude usage parsers now inspect usage.iterations and usage.cache_creation.ephemeral_1h_input_tokens, creating separate breakdown rows solely for advisor_message iterations to avoid double-counting regular turns. One-hour cache writes are priced at twice the base input token rate, and the history cache schema version has been bumped so past sessions are reparsed automatically.

It is like an accounting firm updating its audit ledgers: billing special advisor consults and short-term secure storage at double rates, while auditing archived receipts to guarantee nothing is missed or duplicated.
FEATURE

Dragging Grok card on Windows moves panel consistently with others

Dragging the Grok card in the Windows tray now moves the entire panel smoothly, just like the other three provider cards.

The tray's WebKit shim converts empty space on quota cards into native pywebview drag handles, but its element selector previously named only Claude, Codex, and Antigravity. As a result, dragging Grok fell through to the shared card-reordering logic, causing the fourth card to reorder itself rather than moving the window. The drag selector now includes all four providers, matching behavior already established in panel_core.js on macOS.

It is like a control board with four grab handles: three shifted the entire deck while the fourth slipped because it missed a grip pad; outfitting all four ensures consistent handling everywhere.
FEATURE

Contribution guides and localized docs move to dedicated folders

Like a library tidying its lobby: filing reader policies into administrative offices and shelving multilingual guides in study rooms so the entrance stays clutter-free with clear signposts.

The repository root has been cleaned up and reorganized.

Public contribution guidelines and security policies have been relocated into .github/. Multilingual README documentation and changelog history files are now consolidated under docs/. This housekeeping cleans up the root directory and updates all internal navigation links across the project.

FEATURE

Simplified Chinese, Japanese, and Korean READMEs backfill Grok CLI

Readers consulting localized documentation will now find complete coverage for the Grok CLI card.

The Simplified Chinese, Japanese, and Korean README files previously missed mentions of the Grok card in their feature lists, the Hide Sections toggle documentation, and the provider comparison tables. This update backfills all three missing entries across all three translations, ensuring readers across every supported language have access to the exact same feature overviews and settings details.

It is like updating international product catalogs: reprinting feature summaries, accessory switches, and comparison charts for localized editions so every market receives identical documentation.
FEATURE

Bump PyObjC to 12.2.2 and ruff to 0.16.4 across dependency updates

Project dependencies and linting toolchains have been upgraded to their latest releases.

This update bumps the macOS system bridge PyObjC to 12.2.2 and the static analysis linter ruff to 0.16.4. By consolidating these version bumps into a single lockfile commit, the release cleanly resolves five separate dependency update requests at once, keeping the development environment and automated checks current.

It is like factory maintenance consolidating five separate work orders into one shift, upgrading control circuits and calibrating measurement tools in a single scheduled pass without recurring downtime.
