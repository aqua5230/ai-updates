Oversized panels scale down to fit screen instead of clipping

Like a camera automatically zooming out to wide-angle when capturing a tall skyscraper, fitting the entire building proportionally into the viewfinder instead of slicing off the roof. When a popover grows too tall for the screen, it now scales down proportionally rather than getting clipped. Previously, clamp_content_height() capped height strictly to the visible screen frame, leaving any lower rows unreachable and invisible. The new panels/panel_scale.py module computes a fit scale that stays above MIN_PANEL_SCALE, and macOS's PopoverViewController.applyPanelScale() together with Windows's _WindowsTrayController._apply_panel_zoom() apply it across the entire panel using window.usageApplyPanelZoom().

Helper functions _insert_table_line(), _remove_table_line(), and _replace_table_line() now support both config structures, parse and validate every proposed edit with tomllib.loads, and raise a clear failure when no change can be made safely. It is like an electrician inspecting a breaker box: wiring connections correctly whether the label sits on the main switch or individual branch circuits, testing voltages before power-up, and flagging faults instead of pretending everything is installed.

Codex の設定ファイル config.toml に単独の [tui] ヘッダーがない場合でも、ステータス行の追加と削除が正常に行えるようになった。以前は [tui.*] サブテーブルや最上位のドット区切りキーのみで tui が宣言されていると、セットアップや解除の処理が何も書き込まずに成功と偽って報告していた。現在は _insert_table_line()、_remove_table_line()、_replace_table_line() が両方の記法に対応し、変更候補を tomllib.loads で構文検証したうえで安全に変更できない場合は明確に失敗を報告する。これは配電盤の工事で、メインスイッチにラベルがあっても個別ブレーカーにあっても正しく配線し、通電前にテスターで確認して安全に工事できない時は作業完了と偽らず報告するようなものだ。

Windows ビルドの隠蔽インポートを現行モジュールへ修正、無効設定を排除

macOS でダブルクリック起動しても UTF-8 読み込みでログイン項目が正しく動作

Codex 상태 표시줄이 점 표기법 설정을 지원하여 설치와 제거가 실패하지 않는다
