zh-TW

「Cloud Observation」主題修正 Grok 過期提示，標題不再被擠壓至寬度歸零

切換至「Cloud Observation」面板主題查看 Grok 額度時，卡片標題不再被過期提示擠壓消失。該主題範本 cloud_observation.html 貼入 Grok 過期提示列時誤帶了 codex-stale、codex-stale-info 與 codex-stale-tooltip，但該面板定義的是 .stale、.stale-info 與 .stale-tooltip。因名稱不符，懸停提示掉成一般內文，未排版的列失去 flex: none 與 white-space: nowrap，將「Grok」標題擠成零寬度。修正後該主題已恢復正常，其餘 12 款主題先前早已正確對應。這好比標籤貼錯代碼致使樣式失效，隱藏說明攤在門面把「Grok」招牌擠到看不見；更正後版面即恢復整齊。

en

Cloud Observation theme fixes Grok staleness notice without squeezing the header

When viewing Grok usage under the Cloud Observation panel theme, the card heading will no longer be squeezed out of sight by the staleness notice. The Grok stale row was previously pasted into cloud_observation.html carrying codex-stale, codex-stale-info, and codex-stale-tooltip, but that panel defines .stale, .stale-info, and .stale-tooltip. Because nothing matched, the hover tooltip rendered as plain inline body text, and the unstyled row lost its flex: none and white-space: nowrap layout properties, squeezing the Grok heading down to zero width. This release updates the template's class names, bringing Cloud Observation in line with the other twelve themes that already resolved their classes. It is like pasting an inventory label with the wrong department code onto a display plaque, causing the styling rules to miss it so that the hidden note sprawled across the front and crushed the "Grok" store sign down to nothing; aligning the class names restores the neat layout and floating popup.

zh-CN

“Cloud Observation”主题修正 Grok 过期提示，标题不再被挤压至宽度归零

切换至“Cloud Observation”面板主题查看 Grok 额度时，卡片标题不再被过期提示挤压消失。该主题模板 cloud_observation.html 贴入 Grok 过期提示行时误带了 codex-stale、codex-stale-info 与 codex-stale-tooltip，但该面板定义的是 .stale、.stale-info 与 .stale-tooltip。因名称不符，悬停提示掉成一般正文，未排版的行失去 flex: none 与 white-space: nowrap，将“Grok”标题挤成零宽度。修正后该主题已恢复正常，其余 12 款主题先前早已正确对应。这好比标签贴错代码致使样式失效，隐藏说明摊在门面把“Grok”招牌挤到看不见；更正后版面即恢复整齐。

ja

Cloud Observation テーマで Grok の更新遅延通知を修正、見出しが非表示にならない

Cloud Observation パネルテーマで Grok の利用枠を確認する際、更新遅延の通知によってカードの見出しが押し潰される問題が解消された。以前は cloud_observation.html に Grok の遅延通知行を貼り付けた際、codex-stale、codex-stale-info、codex-stale-tooltip というクラス名が残っていたが、このパネルでは .stale、.stale-info、.stale-tooltip と定義されていた。クラス名が一致しなかったため、マウスを重ねた際のツールチップが通常の本文テキストとして展開され、未適用の行から flex: none や white-space: nowrap の指定が外れて Grok の見出し幅が 0 に縮んでいた。今回クラス名が修正され、すでに正しく定義されていた他の 12 テーマと同様に正常な表示へ揃えられた。これは展示プレートに別部門のコード付きラベルを貼ったせいで装飾ルールが当たらず、隠れるはずの注記が表に溢れて「Grok」の店名看板を完全に押し潰したようなものだ。名前を揃えたことで、他の 12 テーマと同様に整った表示に戻った。

ko

Cloud Observation 테마에서 Grok 지연 알림을 수정하여 제목이 사라지지 않는다

Cloud Observation 패널 테마에서 Grok 사용량을 확인할 때, 데이터 지연 알림 때문에 카드 제목이 찌그러져 사라지는 문제가 해결되었다. 이전에는 cloud_observation.html에 Grok 지연 알림 행을 붙여넣으면서 codex-stale, codex-stale-info, codex-stale-tooltip 클래스명이 그대로 남았으나, 해당 패널에는 .stale, .stale-info, .stale-tooltip으로 정의되어 있었다. 이름이 맞지 않아 마우스를 올렸을 때 떠야 할 툴팁이 일반 본문 텍스트로 펼쳐졌고, 스타일이 빠진 행에서 flex: none 및 white-space: nowrap 속성이 누락되어 Grok 제목 너비가 0으로 압축되었다. 이번 수정으로 클래스명이 정상 반영되어, 이미 올바르게 지정되어 있던 다른 12개 테마와 동일하게 깔끔한 화면을 보여준다. 전시 팻말에 다른 부서의 식별 코드가 붙은 라벨을 붙여 스타일 규칙이 적용되지 않는 바람에, 숨겨져 있어야 할 설명 메모가 겉으로 튀어나와 'Grok' 간판을 완전히 찌그러뜨린 것과 같다. 클래스 이름을 일치시키면서 다른 12개 테마처럼 깔끔한 레이아웃과 도움말 안내로 정상 복구되었다.
