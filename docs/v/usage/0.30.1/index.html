繁體中文

「Cloud Observation」主題修正 Grok 過期提示，標題不再被擠壓至寬度歸零

切換至「Cloud Observation」面板主題查看 Grok 額度時，卡片標題不再被過期提示擠壓消失。該主題範本 cloud_observation.html 貼入 Grok 過期提示列時誤帶了 codex-stale、codex-stale-info 與 codex-stale-tooltip，但該面板定義的是 .stale、.stale-info 與 .stale-tooltip。因名稱不符，懸停提示掉成一般內文，未排版的列失去 flex: none 與 white-space: nowrap，將「Grok」標題擠成零寬度。修正後該主題已恢復正常，其餘 12 款主題先前早已正確對應。

這好比標籤貼錯代碼致使樣式失效，隱藏說明攤在門面把「Grok」招牌擠到看不見；更正後版面即恢復整齊。

English

Cloud Observation theme fixes Grok staleness notice without squeezing the header

When viewing Grok usage under the Cloud Observation panel theme, the card heading will no longer be squeezed out of sight by the staleness notice. The Grok stale row was previously pasted into cloud_observation.html carrying codex-stale, codex-stale-info, and codex-stale-tooltip, but that panel defines .stale, .stale-info, and .stale-tooltip. Because nothing matched, the hover tooltip rendered as plain inline body text, and the unstyled row lost its flex: none and white-space: nowrap layout properties, squeezing the Grok heading down to zero width. This release updates the template's class names, bringing Cloud Observation in line with the other twelve themes that already resolved their classes.

It is like pasting an inventory label with the wrong department code onto a display plaque, causing the styling rules to miss it so that the hidden note sprawled across the front and crushed the "Grok" store sign down to nothing; aligning the class names restores the neat layout and floating popup.
