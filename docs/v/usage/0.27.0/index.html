en

Dedicated update website is live, keeping the HTML report uncluttered

Clicking "AI Update Daily" in the menu bar now takes you straight to a dedicated public web page, instead of making you hunt through the HTML deep report (the page showing your full data analysis). This new page auto-updates daily with the complete history for Claude Code, Codex, and Antigravity; reviewed versions show plain-language summaries in all five UI languages, while unreviewed ones display the official source text. Because this dedicated page now exists, the old update digest section has been removed from the HTML deep report to keep it uncluttered. It's like a restaurant moving the "new dishes" section from the corner of the order sheet into a beautifully printed full-color menu—the order sheet stays clean, and those looking for new dishes get a much better reading experience.
