繁體中文

按鈕改名又會回應了，報告語言與開啟也修順

面板上的按鈕變得更好懂、也更會回應你了。首先是名字改直白：「分析」改成「報告」、「CLI」（命令列介面的縮寫，工程師才懂的詞）改成「終端」，五種語言同步更新，不再只有工程師看得懂。再來，以前只有「立即更新」這顆按鈕滑鼠移上去會變色，其他像是「結束」「更換面板」「今日」「報告」「終端」全部沒反應、看起來像壞掉的；現在每顆按鈕移上去都有視覺回饋。而「終端」這顆開關（用來開關狀態列 hook 的——狀態列 hook 是一種讓程式在終端機提示列上常駐顯示一小段資訊的設定）以前只有一個小勾勾表示開著，現在按鈕底色也會跟著變，一眼分得出開還是關。另外兩個跟「報告」有關的問題也修好了：按「報告」產生的 HTML 報告，現在會跟著選單列目前的語言，不會再因為系統環境沒設好就退回英文；而開啟報告時，如果路徑裡有空白或中文字（以前會讓某些瀏覽器打不開），現在改用系統的 open 指令更穩定。就像一個店面把原本只有店員才看得懂的編號標籤，換成客人也懂的名字，每個按鈕按下去也都會亮一下告訴你「有反應喔」，而且不管你的資料夾取什麼名字都能順利結帳。

面板視覺全面翻新，標題不再斷、數字不再對不上

你的面板畫面整個整理過，看起來更像一套 macOS 系統工具，也修掉一堆排版與數字的小毛病。預設的 classic 面板大幅翻新：卡片圓角變小、間距收緊、進度條多了凹陷與光暈、專案排行榜多了相對佔比的比例條（前 3 名強調）、底部狀態改成圓角標籤、左邊加上品牌色細條。其他七款主題面板（駭客任務、視窗 95、報紙、水族箱、雲圖、稜鏡街機、黑洞）都跟進終端開啟變色與按鈕 hover（滑鼠移上去的變色反應）效果；不過比例條只有駭客任務、視窗 95、報紙這三款跟 classic 一樣保留，水族箱、雲圖、稜鏡街機、黑洞這四款因為版面結構衝突而拆掉。各面板仍保留原本的主題視覺（綠字、像素、油墨等）。同時修掉一堆惱人的排版問題：九款面板的「專案用量」標題以前常被三顆按鈕擠到斷行（尤其英文和日韓較長的字串），現在改成兩列版型不再被裁掉；駭客任務面板的底部按鈕、視窗 95 與報紙面板的「重置倒數」文字以前會被邊框切掉，現在都調高了；切換面板時彈窗也不再出現短暫的排版錯亂。另外，同一份 Codex 對話紀錄以前在面板和報告裡可能算出不一樣的數字，現在兩邊走同一套算法，app 和報告不再對不上。官網與說明文件的展示截圖也一併補齊到九款面板。就像一間老店面重新裝潢：招牌字不再被遮、櫃子不再塞到溢出來，而且各分店統一用同一套陳列方式，客人不管走進哪一家都看得順眼。

English

Buttons get friendlier names and real feedback, and reports open in the right language

The buttons on the panel are friendlier and more responsive now. First, the names got plainer: "Analyze" became "Report", and "CLI" (an abbreviation for command-line interface, jargon only engineers understand) became "Terminal", updated across all five languages so it's no longer just engineers who can read them. Second, previously only the "Refresh Now" button changed color when you hovered; the others — "Quit", "Switch Panel", "Today", "Report", "Terminal" — gave no reaction and looked broken; now every button gives visual feedback on hover. And the "Terminal" toggle (which turns the status-line hook on and off — a status-line hook is a small setup that pins a program's info in your terminal's prompt line) used to show only a tiny check mark when on, but now its background tints too, so you can tell at a glance whether it's on or off. Two report-related bugs are also fixed: the HTML report generated by clicking "Report" now follows the menu bar's current language instead of falling back to English when the system environment isn't set up; and when opening the report, paths with spaces or CJK characters (which used to break some browsers) now work reliably via the system's open command. It's like a shop swapping clerk-only numeric labels for names customers actually understand, with every button lighting up to say "I heard you" when pressed, and checkout working no matter what you named your folders.

Panels get a full visual refresh — titles stop clipping and numbers stop disagreeing

Your panel has been cleaned up top to bottom — it reads more like a proper macOS system tool, and a pile of layout and number glitches got fixed. The default classic panel got a major refresh: smaller card corners, tighter spacing, progress bars with inset shadows and glow, a relative-share comparison bar on the project rankings (emphasizing the top 3), footer status turned into rounded chips, and a brand-color stripe down the left side. Seven other themed panels (Matrix, Windows 95, newspaper, aquarium, cloud, prism arcade, black hole) all picked up the Terminal active-state coloring and button hover effects; the comparison bars, though, are kept only on Matrix, Windows 95, and newspaper (same as classic) — aquarium, cloud, prism arcade, and black hole had theirs removed over a layout conflict. Each panel still keeps its original theme art (green text, pixels, ink, and so on). A batch of annoying layout bugs are fixed too: the "Project Usage" title across all nine panels used to get squeezed into a broken line by the three buttons (especially the longer English, Japanese, and Korean strings), now rebuilt into a two-row layout that no longer clips; the Matrix panel's bottom buttons and the Windows 95 / newspaper panels' "resets in" text used to get cut off by the frame, now raised to fit; switching panels no longer causes a brief layout glitch in the popover. And the same Codex session used to be counted differently in the panel versus the report — now both sides share one counting path, so the app and the report no longer disagree. The website and documentation gallery screenshots were also refreshed to cover all nine panels. It's like an old shop getting renovated: the sign isn't blocked anymore, the shelves don't overflow, and every branch uses the same display so customers see a tidy store no matter which one they walk into.

**Terminal toggle button now changes background when enabled**: previously only the `✓` check mark indicated that the statusLine hook was active; now the button background tints with each panel's accent color too, so the on/off state is obvious at a glance.
**Friendlier button labels for non-developers**: "Analyze" → "Report", "CLI" → "Terminal" (with per-language translations: 終端 / ターミナル / 터미널 / 终端). All five languages updated together.
**All buttons now have hover feedback**: previously only "Refresh Now" reacted to mouse hover; "Quit", "Switch Panel", "Today", "Report", "Terminal" looked disabled. Hover now produces visual feedback at a graded intensity (primary > secondary > switch).
**Analysis reports now follow the menu bar popover language**: clicking Report (formerly Analyze) now passes the menu bar's current language into HTML report generation instead of redetecting from environment variables only, avoiding English fallback when LaunchAgent does not set `LANG`.
**macOS now opens analysis reports with `/usr/bin/open`**: previously `webbrowser.open()` constructed a `file://` URI, which some browsers refused for paths containing spaces or CJK characters. Switching to `/usr/bin/open` with the resolved path is more reliable. Thanks to @ericweichun (#9).
