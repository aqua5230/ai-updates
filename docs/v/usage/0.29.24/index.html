面板換上 Catppuccin 四色主題，格線設計照舊

眼前的面板想換個色調，現在可以選 Catppuccin 的四套官方配色。草稿紙般的藍圖格線、尺刻度進度條和角落記號仍在，只是換上 Latte、Frappé、Macchiato 或 Mocha；在面板底部按四個色票就能選。這像同一張製圖桌換四種墨水，尺線與格紙不動，整張圖卻能依喜好改色。選擇會存進偏好設定（記住你選項的地方），而非 localStorage（瀏覽器暫存網站資料的地方）；面板在 WebKit 以 null origin 載入時，後者會被擋住。macOS 與 Windows 系統匣的面板都會套用這個選擇。

en

Catppuccin brings four color themes to the panel without changing its blueprint look

Want the panel in a different mood? It now offers Catppuccin's four official palettes. The drafting-paper grid, ruler-tick progress bars, and corner marks stay put; choose Latte, Frappé, Macchiato, or Mocha from four swatches along the panel's bottom edge. It is like using four inks on one drafting table: the rulers and paper do not move, but the drawing takes on your chosen color. Your pick is saved in preferences, rather than localStorage (browser storage for website data), because WebKit blocks localStorage when the panel loads with a null origin. The choice appears in both the macOS and Windows tray panels.

パネルに Catppuccin の4色テーマが登場、設計図風の見た目はそのまま

目の前のパネルの色合いを変えたいなら、Catppuccin の公式4色パレットを選べるようになった。製図用紙のようなグリッド、定規の目盛り風の進行バー、角の印は残したまま、下部の4つの色見本から Latte、Frappé、Macchiato、Mocha を選ぶ。これは同じ製図台で4色のインクを使い分けるようなものだ。定規と紙は動かず、図面だけが好みの色になる。選択は preferences に保存され、localStorage（ブラウザーがウェブサイトのデータを一時保存する場所）は使わない。パネルが WebKit で null origin として読み込まれると、localStorage がブロックされるためである。この選択は macOS と Windows のトレイのパネルにも反映される。

패널에 Catppuccin 네 가지 색 테마가 들어오고, 설계도풍 모습은 그대로다

눈앞의 패널 색감을 바꾸고 싶다면 이제 Catppuccin의 공식 네 가지 팔레트를 고를 수 있다. 제도 용지 같은 격자, 자 눈금 모양 진행 막대, 모서리 표시는 그대로 두고 패널 아래의 네 색 견본에서 Latte, Frappé, Macchiato, Mocha를 고른다. 같은 제도대에서 네 가지 잉크를 바꿔 쓰는 것과 같다. 자와 종이는 움직이지 않고 도면만 원하는 색을 입는다. 선택은 preferences에 저장되며 localStorage(브라우저가 웹사이트 데이터를 잠시 저장하는 곳)는 쓰지 않는다. 패널이 WebKit에서 null origin으로 불러와질 때 localStorage가 막히기 때문이다. 이 선택은 macOS와 Windows 시스템 트레이의 패널에도 적용된다.
