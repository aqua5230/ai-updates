Usage 0.30.17

發布日期：2026-09-17

繁體中文

新功能

洞察結論移至摘要卡正下方，日期篩選列隨管轄區塊動態吸頂

檢視用量報表時，最關鍵的洞察結論不再需要滑到頁面底部。

過去長達 4,660px 的頁面中，洞察排在熱力圖、使用習慣與最近在做什麼之後，要捲動到約 3,600px 處才看得見。現在洞察移至數字卡片正下方並標上「固定區間」，表示它統計整份報告期間、不跟日期篩選連動。「數字怎麼算的」附錄移到「以下區塊不受上方日期篩選影響」上方，因附錄數據會隨篩選改變（選「最近 7 天」後快取讀取量由 5.29B 變成 1.88B）。日期篩選列改為只在管轄區塊在畫面時固定在頂端，捲到熱力圖、使用習慣、最近在做什麼與年度 Wrapped 時會跟著離開，不再留下一排按了沒反應的按鈕。

這好比商場將導覽指引立在手扶梯旁，促銷標籤只在特賣區懸浮，走進常設專櫃便自動收起。
新功能

高消耗工作階段改依 tokens 排序，專案改採中性色並調整指標排版

想掌握各個模型與專案的消耗排行，圖表與數據呈現現在更加直覺一致。

過去「最燒的 5 段工作階段」依花費排序，但長條圖與報表各處的燃燒皆代表 token（AI 處理與計費的文字單位），導致第二名長條可能比第一名還長。現在全面改依 token 排序，用量相同時才比花費。專案長條改用單一中性色，不再借用工具的綠、紫、橘色，避免專案看起來像屬於 Claude Code、Antigravity 或 Codex；工具列中 Grok 的長條也改為與圖表相同的粉紅色。活躍日寫成「17 / 17 天」，避免在尖峰日旁被誤認成日期。展開專案後「佔本專案」只標示一次不再每列重複，快取命中率說明也移至專屬小標題底下。

這有如整理多重幣別的計量儀表，將耗電長條全數照度數多寡排序，不同團隊採用一致中立色塊，讓讀表者一眼看清真實消耗。
問題修復

手機版工作階段改為三行卡片，放大觸控按鈕並修正斷行排版

在手機螢幕上瀏覽用量明細時，窄版面的排版與觸控操作體驗更加順手。

過去熱門工作階段常將 tokens 與花費擠出手機畫面外，現在改為三行卡片：首行列出專案、tokens 與花費，次行標註開始時間和時長，第三行顯示模型。寬度 780px 以下時，日期按鈕、輸入框、主題與分享鍵、Tokens 與花費切換及頁尾連結高度從原本 16 至 32px 提升到至少 44px，確保觸控容易點按。手機上日期與模型名稱不再從連字號處斷行，避免 2026-05- 與 04 拆成兩行。空白報表提示在五種語言補上 Antigravity 與 Grok（與 Claude Code 及 Codex 並列），頁尾 Ko-fi 連結減為一個，並重拍對齊新版面的報表截圖。

這彷彿將橫幅通訊錄重新剪裁為隨身便條，把重要資料分行排好，並將每顆按鈕放大到手指能從容點擊的友善間距。
新功能

官網推出獨立多語系網頁強化搜尋收錄，功能區改為圖示卡片格

搜尋或瀏覽 usage 官網時，多語系讀者能直接造訪專屬母語頁面。

過去透過 ?lang= 切換語言時，一律回傳英文 HTML 與英文 canonical（告知搜尋引擎代表性頁面的標準網址標記），導致其他四種語言無法被收錄。現在由 scripts/build_site_pages.py 從 docs/index.html 產生各語系獨立網頁（含 /zh-TW/、/zh-CN/、/ja/、/ko/），具備在地化標題、html lang 與專屬 canonical，CI 用 --check 把關。網站地圖與 hreflang 列出五語網址，舊 ?lang= 連結仍可用。功能區改為附圖示卡片格，標題補上 Grok。

這如同觀光局為旅客印製專屬母語手冊與獨立展架，讓各語言讀者與搜尋引擎都能精準找到正確版本，不再全擠在英文櫃台前。
效能優化

官網遵循無障礙與介面規範，改善鍵盤操作、手機圖檔與文字排版

點開 usage 官網閱讀說明時，頁面的無障礙操作體驗與排版細節更加完善。

網站依循 Lighthouse、axe 與 Vercel Web Interface Guidelines 規範進行多項調整：手機上的章節選單在點擊後會自動收合，頁面內所有可捲動區塊也能完整透過鍵盤操作。首頁主視覺圖提供 800w 與 1200w 尺寸規格，在手機載入時能減少約 230KB 下載量，安裝指令亦加上 translate="no" 標記。在文字排版方面，標題會自動跨行平衡長度，段落結尾避免留下單字孤行；日文與韓文標題不再從詞彙中間拆斷，行內指令也不再從連字號處斷開。

這種細緻度恰似印刷出版品在交付裝訂前的全面校準，既壓縮大圖減輕手冊重量，又微調每行字距與斷詞，讓閱讀翻頁體驗順暢舒適。

English

FEATURE

Insights Move Right Under the Summary Cards, Date Filter Now Only Pins Above Sections It Actually Controls

The most actionable line in your usage report no longer requires scrolling to the bottom of the page.

On the old 4,660px page, Insights came after the heatmap, habits, and recent work, around 3,600px down. Insights now sits directly under the summary cards, tagged "Fixed range" to show it covers the whole report period and doesn't follow the date filter. The "How these numbers are calculated" appendix has moved above the note that says sections below don't follow the date filter above, since the appendix actually does follow it (cache reads went from 5.29B to 1.88B after picking Last 7 days). The date filter now only stays pinned while the sections it controls are on screen; scrolling into the heatmap, habits, recent work, or Wrapped lets it scroll away instead of leaving a row of buttons that do nothing there.

It's like a mall putting directional signage next to the escalator, with promo tags floating only over the sale section and folding away once you walk into the permanent stores.
FEATURE

Top Burn Sessions Now Rank by Tokens, Projects Get a Neutral Colour and Metrics Get Tidier

Reading model and project consumption rankings is now more consistent and intuitive.

The Top 5 burn sessions used to be ranked by cost, while their bars — and every other "burn" in the report — measure tokens, so the second row could carry a longer bar than the first. Everything now ranks by tokens, with cost only breaking ties. Project bars now use one neutral colour instead of borrowing the tools' green, purple, and orange, so a project no longer looks like it belongs to Claude Code, Antigravity, or Codex; Grok's bar in the tools list is now the same pink as the chart instead of teal. Active days now reads "17 / 17 days" instead of looking like a date next to the peak-day card. "Share of project" is shown once per expanded project instead of on every model row, and the cache hit rate explanation now sits under its own heading.

It's like tidying up a multi-currency meter panel: every burn bar gets sorted purely by its reading, different teams get the same neutral colour block, and the reader can tell real consumption at a glance.
BUGFIX

Top Sessions Become Three-Line Cards on Phones, Buttons Get Bigger and Line Breaks Get Fixed

Browsing usage details on a phone screen is now easier to read and tap through.

Top sessions used to push tokens and cost off-screen on phones; each session is now a card with project, tokens, and cost on the first line, start time and duration on the second, and model on the third. On screens 780px wide or narrower, the range buttons, date inputs, theme and share buttons, the Tokens/Cost toggle, and the footer links now stand at least 44px tall instead of their old 16 to 32px. Dates and model names on phones no longer break at a hyphen, so 2026-05- and 04 no longer split apart. The empty report now names Antigravity and Grok alongside Claude Code and Codex in all five languages, the footer has one Ko-fi link instead of two, and report screenshots have been retaken for the new layout.

It's like recutting a wide address book into a pocket notecard: the key fields line up row by row, and every button gets sized up to a friendly width your thumb can hit without missing.
FEATURE

The Website Gets Standalone Pages Per Language for Better Search Indexing, Feature Section Becomes an Icon Grid

Multilingual readers can now land directly on a page in their own language when they search or browse the usage website.

Every ?lang= URL used to serve the English HTML with an English canonical (the standard URL tag that tells search engines which page is authoritative), so the other four languages couldn't be indexed. scripts/build_site_pages.py now generates a standalone page per language (/zh-TW/, /zh-CN/, /ja/, /ko/) from docs/index.html, each with its own localized title, html lang, and canonical, checked by CI with --check. The sitemap and hreflang tags now list all five language URLs, and old ?lang= links still work. The feature section is now a card grid with icons, and the headline includes Grok.

It's like a tourism board printing a dedicated language brochure and display stand for each nationality of visitor, so readers and search engines alike can find the right version instead of everyone crowding the English-only counter.
FEATURE

The Website Follows Accessibility and Interface Guidelines, Improving Keyboard Use, Mobile Images and Typography

Reading through the usage website is now more polished in its accessibility and typographic details.

The site picked up several fixes from Lighthouse, axe, and the Vercel Web Interface Guidelines: the mobile section menu now closes after a tap, and every scrollable region on the page is fully keyboard-reachable. Hero images now ship 800w and 1200w variants, cutting about 230KB off phone loads, and install commands are now marked translate="no". On the typography side, headings now balance their length across lines and paragraphs avoid leaving a single word on the last line; Japanese and Korean headings no longer break mid-word, and inline commands no longer split at a hyphen.

It's the kind of finish a print publication gets before binding: shrinking oversized images to lighten the load, tightening every line's spacing and word breaks, so flipping through it reads smoothly.
