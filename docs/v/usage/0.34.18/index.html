Usage 0.34.18

發布日期：2026-11-14

繁體中文

新功能

額度感知模式在對話中通報新模型與新額度池

換上剛推出的 AI 模型趕報告，你可能會納悶 Claude 到底知不知道這個新選項。

就像電信公司剛推出新的漫遊方案，以前專員沒收到通報只能自己猜，現在總機會在每通來電提示一次新名稱與費率表有沒有列。

現在只要最近七天內出現新模型或新的 Antigravity 額度池（共用同一個用量上限的分組），額度感知模式就會在每個對話告訴 Claude 一次，並附上 usage 的價目表認不認得它。其中 Codex 的新模型會從 Codex 自己的模型清單抓到，其他工具的新模型則在你使用過一次後才會出現。當你剛試過一款新模型、接著開新對話問 Claude 目前有哪些可用額度時，它就能立刻知道這個新成員已經進來了。

問題修復

修正 Antigravity 登出閘門與 Gemini 週額度歸類

背景執行額度檢查遇到暫時驗證錯誤或開窗逾時，Antigravity 過去容易反覆彈出登入頁或錯記數字。 背景執行 CLI（指令列工具）檢查若因暫時性驗證錯誤而鎖住閘門，六小時後只要備援管道用同一份憑證仍抓得到額度，usage 就會清掉標記並恢復使用 CLI。 自動開窗送訊號若因等待驗證而逾時，usage 現在會跟額度檢查一樣記下未登入狀態，不再重複啟動 CLI 在背景開出登入頁。未登入標記也改為原子寫入（寫完整才算數、不讓讀檔看到半成品），自動開窗同時讀檔時不會再誤開閘門。 先前透過 CLI 記下 Gemini 週額度重置時間後，改走備援管道若看到重置時間相差在十分鐘內，會直接更新週額度，不再把同一個數字重複填進 5 小時那一列。以前驗證偶爾卡住就得面對背景冒出的登入頁或錯位的額度欄，現在這些狀態都會自動對正。

問題修復

修正 Antigravity token 讀取並重算年度歷史

過去在年度檢視裡看到的 Antigravity 每日用量，常常偏高卻降不下來。

宛如發現以前錯把箱號當貨數、又把進貨與退貨抄反，現在只要原始單據還在，先前虛胖的舊日報表也跟著一起更正。

usage 以前每次回應都把約 1,300 到 1,500 的內部模型編號算進 input token（AI 計費的文字單位），還把 output 和 thinking 讀反。現在 input 只讀 input 欄位、output 與 thinking 不再對調、只帶模型編號的回應也不計入，更新後還會重算一次 Antigravity 的快取（暫存結果）。年度檢視的每日歷史以前只在新總量不小於舊紀錄時才替換，現在只要當天所有對話紀錄與工作階段都還留在本機，偏高的舊日子就會改成正確數值，紀錄缺漏的日子則保留原總量。

新功能

HTML 報表重認 Antigravity 模型並計入思考花費

想在 HTML 報表查看 Antigravity 用量帳單，明細上卻整排列成「沒有價格」。

好比核對工程報價單，以前型號多了尾碼就整項留白、還少算一欄工時，現在先裁掉尾碼對上牌價，再把漏計的工時補進帳單。

Antigravity 記下的 gemini-4-argon-s 等型號原本對不到價目表，現在會先去掉 -n、-s、-medium 等尾碼並找 gemini/ 開頭的價格，Gemini 4 Hydrogen 也算得出花費。報表分開讀取輸出與思考欄位後，原本漏掉 Antigravity 的思考 token（AI 計費的文字單位）。現在比照 Codex 把思考 token 計入輸出並以輸出單價計費，花費會明顯變高，這只是補算漏掉的部分，不是漲價。

新功能

價目表下載等待重試、換表清快取並補上 Muse 定價

離線環境或長時間開著選單列程式算費用，價目表有時會卡在重複下載、舊表沒清或模型缺價。 離線或連不上網且沒有未過期價目快取（暫存查詢資料）時，以前每次算費都重開連線下載，現在失敗後會等 10 分鐘再試。 選單列程式長時間執行並多次更新價目表時，啟用新表會順手清掉記憶體裡的舊表查詢快取，不再一直留著。 離線表原本只有 Muse Spark，下載表又缺 Meta 條目時，Muse Wonder 的 muse-wonder-1.0 與 Muse Ember 的 muse-ember-1.0 token（AI 計費單位）全被列成「沒有價格」。現在兩款都用 Meta 公布的標準價，但 Ember 單次輸入逾 200K token 的長文價位因工作階段紀錄沒記，一律採標準價。 以前斷網每算一次就重連、用這兩款模型也算不出費用，現在都已修好。

新功能

額度感知模式相容同帳號多對話與 Windows 中文

你開著好幾個視窗同時跑 Claude Code，或在 Windows 終端機裡輸入字句，有時會漏掉警示或突然沒反應。現在同帳號別的對話更新狀態檔時，其他對話仍收得到額度警告，新對話也能直接拿到起始總覽；用 /login 換帳號後，閒置對話隨後切換也不再誤記成舊帳號額度。讀寫標準輸入與輸出改固定用 UTF-8（跨語言通用文字編碼），遇中日韓文不再靜默或不同步，寫入狀態失敗也會清掉暫存檔。「Other agy model groups still have quota」現在只會在該回合實際通報 Antigravity 模型組跨過門檻時才附上。

跟辦公室共用交接白板一樣，以前換人簽收或寫進外文就容易漏看、還常附帶不相干備註，現在照統一格式交接，沒過線就不亂貼。
新功能

Antigravity 狀態列改用在地語言顯示 xhigh 強度

Gemini 4 Hydrogen 切到 xhigh 思考強度後，畫面上的狀態列（顯示即時設定資訊的文字欄）以前只會印出英文原名。現在這個顯示問題已經修好，狀態列會像其他思考強度一樣顯示在地化標籤，例如英文介面顯示為 Extended。

彷彿洗衣機面板原本只有幾段行程翻成中文、某個檔位卻硬生生留著英文代號，現在把最後那顆標籤也換成中文，瞄一眼就知道切到哪一檔。

English

FEATURE

Quota-aware mode announces new models and quota pools in conversations

When you switch to a newly released AI model to rush a report, you might wonder whether Claude even knows about this new option.

Picture a telecom carrier rolling out a new roaming plan: agents used to guess without any notice, whereas now the switchboard announces the new name and whether it is on the rate sheet once on every call.

Now, whenever a new model or a new Antigravity quota pool (a group sharing the same usage limit) appears within the last seven days, quota-aware mode informs Claude once per conversation and notes whether usage's price table recognizes it. New Codex models are pulled from Codex's own model list, while new models from other tools show up after you use them once. When you have just tried a new model and then open a new conversation to ask Claude what quotas are available, it will immediately know this newcomer has arrived.

BUGFIX

Fix Antigravity sign-out gate and Gemini weekly quota classification

When background quota checks hit a temporary authentication error or a window-opening timeout, Antigravity used to repeatedly pop up sign-in pages or misrecord numbers. If a background CLI (command-line tool) check locks the gate due to a temporary authentication error, usage clears the marker and resumes using the CLI after six hours as long as the fallback path can still fetch quotas with the same credential. If the auto-start window ping times out waiting for authentication, usage now records a signed-out state just like the quota check does, instead of repeatedly launching the CLI to open sign-in pages in the background. The signed-out marker is also written atomically (only counted once complete so readers never see a half-written file), so concurrent reads by the window keeper no longer reopen the gate by mistake. After a CLI check records the Gemini weekly quota reset time, a fallback check whose reset time falls within ten minutes of it now updates the weekly quota directly instead of duplicating the same number into the 5-hour row. Previously, an occasional authentication hiccup meant dealing with background sign-in pages or misplaced quota rows, and now those states align automatically.

BUGFIX

Fix Antigravity token reading and recalculate yearly history

In the year view, past Antigravity daily usage often looked inflated and refused to drop.

Like realizing you used to count box numbers as stock and mix up incoming deliveries with returns, those inflated old daily reports now get corrected whenever the original slips are still on hand.

usage previously added Antigravity's internal model ID of around 1,300 to 1,500 into input tokens (text units AI models bill by) on every response, and also swapped output and thinking. Now input reads only the input field, output and thinking are no longer swapped, responses carrying only the model ID are not counted, and the Antigravity cache is rebuilt once after updating. Previously, the year view's daily history replaced a day only when the new total was no smaller than the old record; now, as long as all conversation logs and sessions from that day remain on disk, inflated past days switch to the corrected values, while days with missing logs keep their saved totals.

FEATURE

HTML report recognizes Antigravity models again and includes thinking cost

When checking your Antigravity usage bill in the HTML report, every line item used to show up as unpriced.

Think of auditing a contractor quote: extra model suffixes used to leave an item blank while a whole column of labor hours was missed, and now you strip the suffixes to match the rate card and add the missing hours back onto the bill.

Model IDs recorded by Antigravity such as gemini-4-argon-s previously matched nothing in the price table; now usage strips suffixes like -n, -s, and -medium and also looks up gemini/-prefixed prices, so Gemini 4 Hydrogen can be priced as well. After the report separated output and thinking fields, Antigravity's thinking tokens (text units AI models bill by) were left out. Matching Codex, thinking tokens are now counted into output and billed at the output rate, so costs will look noticeably higher—that only makes up for the missing share, not a price hike.

FEATURE

Price table downloads wait before retrying, clear cache on refresh, and add Muse pricing

When calculating costs offline or with the menu bar app running for long stretches, the price table could get stuck retrying downloads, holding onto old tables, or missing model prices. When offline or unreachable without an unexpired price cache, each cost calculation used to start a new download; now usage waits 10 minutes after a failure before trying again. When the menu bar app runs for a long time and refreshes the price table multiple times, activating a new table now clears old lookup cache entries from memory instead of keeping them around. When the offline table only had Muse Spark and the downloaded table lacked Meta entries, tokens (AI billing units) from Muse Wonder's muse-wonder-1.0 and Muse Ember's muse-ember-1.0 were all listed as unpriced. Both now use Meta's published standard prices, though Ember's long-context tier for over 200K input tokens per request falls back to standard pricing because session logs do not record it. Previously, offline runs retried the network on every calculation and these two models could not be priced; both issues are now fixed.

FEATURE

Quota-aware mode supports multi-conversation accounts and Windows Chinese text

Running Claude Code across several windows at once or typing in a Windows terminal used to drop warnings or suddenly stop responding. Now, when another conversation on the same account updates the state file, other conversations still receive quota warnings and new ones get their starting overview right away; after switching accounts with /login, idle conversations that switch later no longer mistake the limits for the old account. Standard input and output are now always read and written as UTF-8 (a universal text encoding across languages), so CJK text no longer causes silent failures or state desync, and failed state writes clean up their temporary file. "Other agy model groups still have quota" now appears only on turns that actually report an Antigravity model group crossing a threshold.

A shared office handoff whiteboard works the same way: changing who signs off or writing in another language used to cause missed notes and unrelated remarks, whereas now everyone follows one format and nothing gets posted unless a line is crossed.
FEATURE

Antigravity status line localizes the `xhigh` effort level

When switching Gemini 4 Hydrogen to the xhigh thinking effort, the status line (the text bar showing live settings) on screen used to print only the raw English name. That display bug is now fixed, and the status line shows a localized label like the other effort levels, such as Extended in English.

An old washing machine panel had most cycles translated into Chinese while one setting stubbornly kept its English code, and now swapping out that last label lets you tell which gear you are on at a glance.
