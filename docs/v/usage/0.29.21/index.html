zh-TW

Windows 額度面板不再高出一截

Windows 使用者打開額度面板時，畫面不會再像穿了大一號外套。面板（popover，浮在原畫面上的小視窗）曾沿用舊的高度數字；在網頁內容回報實際高度前，八個面板會高出 17 到 24 點。現在 Windows 的備援高度表已對齊 Mac 的重新校準結果，程式也留下數字來源註記，之後調整不易漏改。就像先拿錯尺寸的相框，照片尺寸一量到才換掉；現在相框一開始就合身。

新增額度卡，原本排序照樣保留

你排好額度卡片的順序後，新增來源不會把整份排序洗回預設。額度卡（quota card，顯示各項使用額度的卡片）原先要求已儲存順序的長度和預設清單完全一致；多一張新卡時，舊順序就被當成無效。現在只拒絕重複或不存在的識別碼（id，用來辨認項目的代號）；少掉的新卡會接在原順序最後。像書架多買一本書，不必把整櫃重排，只把新書放到最後。

命令列狀態列換上青綠與藍色

看命令列（CLI，用文字指令操作的介面）時，專案名稱、分支和數值標籤換成青綠與藍的配色。使用百分比依嚴重程度顯示的顏色沒有改。這不是功能或判斷方式改了，而是同一張儀表板換了表面：你讀到的資訊與警示顏色都照舊，只有原本綠、藍、洋紅混用的幾個標籤改成了新的色調。因此看見青綠與藍時，不代表數值的嚴重程度跟著改變；百分比的顏色規則仍和之前相同。

en

Windows quota panels no longer stand too tall

On Windows, quota panels no longer look like they put on a coat one size too big. The popovers — small panels that float above the main screen — still used old height values, so eight of them stood 17 to 24 points too tall until their web content reported its real height. Their Windows defaults now match Mac's recalibrated values, and a comment records where those numbers came from so a later recalibration is less likely to miss them. It is like starting with the right-sized picture frame instead of swapping it after measuring the photo.

A new quota card no longer resets your order

After you arrange your quota cards, adding another source will not wash the whole order back to the default. A quota card is a card showing one usage allowance. Previously, the saved order had to be exactly as long as the default list, so one new card made the old order look invalid. Now only duplicate or unknown ids — identifiers for the cards — are rejected; a newly missing card joins the end of your order. It is like buying one more book for a shelf: you add it at the end instead of rearranging the whole bookcase.

CLI status line gets a teal-and-blue palette

When you look at the command-line interface, or CLI — the text-based place where you enter commands — project names, branches, and metric labels now use teal and blue. The colors for usage percentages at different severity levels have not changed. This is not a new feature or a new way of judging usage; it is the same dashboard with a different face. Its information and warning colors stay put, while the labels that once mixed green, blue, and magenta take on the new shades.

It now only rejects duplicate or unknown ids; an order that's missing a newer card gets that card appended instead of the whole preference being discarded.
