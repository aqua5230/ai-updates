工具更新快訊不再離奇消失，舊版快取也能順利更新

你的「AI 工具更新快訊」不會再因為升級版本而莫名其妙變成一片空白了。以前當你從舊版本（0.24.9 以前）升級上來時，系統在讀取你電腦裡舊格式的暫存檔（cache）時會產生誤判，以為「空空的」就是最新鮮的資料，結果就是一整天（直到暫存過期）都不會去 GitHub 抓新資料，導致整個快訊區塊不見。現在系統學會了正確辨認這些舊格式的檔案，一看到就會立刻去網路抓一份新的回來。就像是你訂閱的早報改版了，以前送報生看到你信箱裡有舊版報紙的包裝袋，就以為你已經收過新報紙而直接跳過；現在他懂得分辨那只是舊袋子，會乖乖把今天熱騰騰的新報紙塞進去。

English

AI Tool Update Digest stops disappearing on upgrades from older versions

Your AI Tool Update Digest will no longer turn entirely blank simply because you updated the app. Previously, when you upgraded from an older version (0.24.9 or earlier), the system misinterpreted your machine's old-format cache file, mistakenly believing that an "empty" result was fresh data. This caused it to refuse to fetch new updates from GitHub for up to 24 hours until the cache expired, completely hiding the digest section. The system now correctly recognizes these legacy cache schemas and immediately fetches fresh data. It's like your morning newspaper subscription redesigning its layout: previously, the delivery person saw an old-style plastic wrapper in your mailbox, mistakenly thought you already got today's paper, and walked past your house; now, they recognize the old bag for what it is and correctly slide a fresh, hot-off-the-press newspaper inside.

Original changelog工具更新快訊不再離奇消失，舊版快取也能順利更新
**AI Tool Update Digest went blank after upgrading from 0.24.9 or earlier**: the new versions-array schema introduced in 0.24.10 caused `_normalize_payload` to return an empty list (not `None`) when reading a pre-0.24.10 cache file, which `load_ai_updates` then treated as a valid "fresh" empty result instead of refetching from GitHub — hiding the section for up to 24h (the cache TTL) on every machine that had used an older version. Legacy-schema caches now correctly trigger a refetch.
