發布日期：2026-05-21

zh-TW

專案用量新增「月」切換，費用也不再顯示為零

現在你可以查看各個專案近 30 天的用量了。專案用量（Project usage）面板新增了「月」的切換選項（與「今日」、「7 日」循環），而且之前因為 Claude Code 沒有記錄花費（costUSD）導致所有專案費用都顯示為 $0.00 的問題也修好了，現在會幫你算出正確的花費。另外，專案用量的圖示也調整成跟 Claude Code 與 Codex 的圖示一樣大。就像記帳本以前只能看這禮拜，現在可以翻看整個月，而且每筆帳目終於有寫金額了。

離線時 Opus 模型的備援定價更準確了

離線時，系統為 Opus 模型估算花費的備援定價（fallback price，斷網時用來墊檔的預設價格）從 $15/M 修正成了 $5/M。這讓它跟 LiteLLM 的實際數值保持一致。就像是你常去的商店網路斷線查不到售價時，老闆憑記憶算給你的價格變得更接近真實售價了。

面板底層架構全面翻新，舊有原生面板與 Antigravity 追蹤暫時退役

為了替接下來的新設計鋪路，所有面板的底層架構都改成了 HTML/CSS（用網頁技術來畫介面）。因此，我們移除了 Taiwan、Matrix、ECG、Minimal 和 Sketch 這五個用舊有原生程式碼寫的面板；同時，為了不把憑證寫死在程式碼裡，也暫時移除了 Antigravity 的用量追蹤功能，這些都會等架構調整好後重新設計。就像是把老房子的管線全部打掉重練，雖然有些舊傢俱暫時不能用，但這是為了迎接之後更棒的新裝潢。

en

Project usage gains a 'Month' toggle, and costs are no longer zero

You can now view token usage across your projects for the last 30 days. The project usage panel has added a "Month" toggle (cycling through "Today" and "7 days"). Also, because Claude Code doesn't record the cost (costUSD), all projects previously showed $0.00; this is now fixed, and it calculates the correct cost. Additionally, the project usage icon has been resized to match the Claude Code and Codex icons. It's like an accounting book that used to only show this week's expenses, but now you can flip through the whole month, and every entry finally has a price tag.

Fallback pricing for the Opus model is more accurate when offline

When offline, the fallback price (the default rate used to estimate costs when the network is disconnected) for the Opus model has been corrected from $15/M to $5/M. This aligns it with LiteLLM's actual value. It's like going to your regular store when their network is down, and the owner quoting you a price from memory that's now much closer to the real cost.

Panel architecture completely overhauled, temporarily retiring old native panels and Antigravity tracking

To pave the way for upcoming new designs, the underlying architecture for all panels has been switched to HTML/CSS (drawing the interface using web technologies). Consequently, we've removed the Taiwan, Matrix, ECG, Minimal, and Sketch panels, which were written in legacy native code. At the same time, to avoid hardcoding credentials into the source code, Antigravity quota tracking has been temporarily removed until the feature can be redesigned. It's like gutting an old house to replace all the plumbing — some old furniture is temporarily unusable, but it's to make way for a much better renovation later.
