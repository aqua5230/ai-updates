AI Council 少帶一箱工具，Claude 額度更省

AI Council 裡的 Claude 成員明明被要求只討論，卻每回合還背著一整箱用不到的工具，會白佔你的 Claude 額度。先前在沒有附上專案資料夾時，claude -p 沒有傳入 --tools，Claude Code 仍會把 Bash、Edit、Write 等內建工具（讓 AI 能執行終端機、編輯與寫入檔案的能力）整套塞進每回合的輸入。現在此情況會明確傳入 --tools ""，把工具箱留在門外。每次 Claude 呼叫也會加上 --exclude-dynamic-system-prompt-sections，讓系統提示詞（AI 每回合先讀的固定規則）開頭在各回合維持位元組完全一致，較有機會命中 Anthropic 的自動提示詞快取（把已處理內容暫存直接沿用），少花重複額度。這只影響 Claude；Codex 和 Antigravity 成員不變。

English

AI Council stops hauling unused tools into every Claude turn

In AI Council, Claude participants are told to discuss rather than use tools, yet they used to carry a whole unused toolbox into every turn, consuming Claude quota. When claude -p ran without an attached project folder, it omitted --tools, so Claude Code still packed its built-in tools—Bash, Edit, Write, and more—into each turn's input. It now explicitly sends --tools "" in that case, leaving the toolbox outside. Every Claude call also adds --exclude-dynamic-system-prompt-sections, keeping the system-prompt prefix byte-for-byte stable across turns and giving Anthropic's automatic prompt cache a better chance to reuse it. Codex and Antigravity participants are unchanged.
