zh-TW

AI Council 少帶一箱工具，Claude 額度更省

AI Council 裡的 Claude 成員明明被要求只討論，卻每回合還背著一整箱用不到的工具，會白佔你的 Claude 額度。先前在沒有附上專案資料夾時，claude -p 沒有傳入 --tools，Claude Code 仍會把 Bash、Edit、Write 等內建工具（讓 AI 能執行終端機、編輯與寫入檔案的能力）整套塞進每回合的輸入。現在此情況會明確傳入 --tools ""，把工具箱留在門外。每次 Claude 呼叫也會加上 --exclude-dynamic-system-prompt-sections，讓系統提示詞（AI 每回合先讀的固定規則）開頭在各回合維持位元組完全一致，較有機會命中 Anthropic 的自動提示詞快取（把已處理內容暫存直接沿用），少花重複額度。這只影響 Claude；Codex 和 Antigravity 成員不變。

en

AI Council stops hauling unused tools into every Claude turn

In AI Council, Claude participants are told to discuss rather than use tools, yet they used to carry a whole unused toolbox into every turn, consuming Claude quota. When claude -p ran without an attached project folder, it omitted --tools, so Claude Code still packed its built-in tools—Bash, Edit, Write, and more—into each turn's input. It now explicitly sends --tools "" in that case, leaving the toolbox outside. Every Claude call also adds --exclude-dynamic-system-prompt-sections, keeping the system-prompt prefix byte-for-byte stable across turns and giving Anthropic's automatic prompt cache a better chance to reuse it. Codex and Antigravity participants are unchanged.

AI Council が不要な道具箱を持ち込まず、Claude の利用枠を節約

AI Council の Claude 参加者は議論だけをするよう指示されているのに、毎ターン使わない道具箱まで抱え、Claude の利用枠を余計に使っていた。プロジェクトフォルダを付けずに claude -p を実行すると、以前は --tools が渡されず、Claude Code が Bash、Edit、Write などの内蔵ツール（AI が端末操作やファイル編集・書き込みを行うための機能）を毎ターンの入力に丸ごと入れていた。今はこの場合に --tools "" を明示し、道具箱を外に置く。さらに全 Claude 呼び出しで --exclude-dynamic-system-prompt-sections を加え、システムプロンプト（AI が各ターンの前に読む固定ルール）の先頭をターン間でバイト単位まで同一に保つ。これにより Anthropic の自動プロンプトキャッシュが再利用できる可能性が高まる。Codex と Antigravity の参加者は変わらない。

ko

AI Council이 매 차례 쓸데없는 도구 상자를 빼고 Claude 사용량을 아낀다

AI Council의 Claude 참여자는 토론만 하라는 지시를 받는데도, 매 차례 쓰지도 않을 도구 상자를 들고 와 Claude 사용량을 괜히 차지하곤 했다. 프로젝트 폴더를 붙이지 않고 claude -p를 실행하면 예전에는 --tools가 빠져, Claude Code가 Bash, Edit, Write 등 내장 도구(AI가 터미널을 실행하고 파일을 편집·작성하는 기능)를 매 차례 입력에 통째로 넣었다. 이제 이 경우 --tools ""를 명시해 도구 상자를 문밖에 둔다. 모든 Claude 호출에는 --exclude-dynamic-system-prompt-sections도 추가한다. 이로써 시스템 프롬프트(AI가 매 차례 먼저 읽는 고정 규칙)의 앞부분이 차례마다 바이트 단위까지 같아져 Anthropic의 자동 프롬프트 캐시가 다시 쓸 가능성이 커진다. Codex와 Antigravity 참여자는 영향이 없다.

Calls now pass `--tools ""` when no project folder is attached, and every Claude call adds `--exclude-dynamic-system-prompt-sections` to keep the system prompt prefix byte-stable across turns for a better shot at Anthropic's automatic prompt caching. Codex and Antigravity participants are unaffected.
