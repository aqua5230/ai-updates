Usage 0.30.0

Released: 2026-08-26

Release notes

FEATURE

Grok CLI joins as a fourth local quota card with zero network calls

When checking your Grok CLI usage, you can now see a weekly progress bar right inside the popover.

It is like glancing at the gas meter on the outside wall: you know this week's total at a glance without calling the utility company.

The card directly reads the weekly credit percentage Grok CLI already writes to its local debug log (~/.grok/logs/unified.jsonl), requiring zero network requests and spawning no extra background processes. Because this log file contains no session or burn-rate information, the card displays a single weekly bar unlike Claude, Codex, and Antigravity. This new card is fully integrated into the macOS popover and Windows tray. It supports all five languages, and its icon styling across all 13 panel themes strictly follows each theme's badge conventions.

FEATURE

Grok CLI token usage now feeds today's cost totals and project attribution

Developers frequently using Grok CLI will now see every call reflected in the daily spend panel.

Grok CLI already writes prompt, completion, cached, and reasoning token counts to its local debug log as shell.turn.inference_done events. A new loader converts these events into UsageEntry rows, correlating them by session id with model-changed and session-created events for model and project attribution. This allows Grok activity to feed into the popover's "today" cost, token total, and project rows just like Claude and Codex, while maintaining zero network calls. Grok's log has also been added to the history fingerprint's always-restat file sources, ensuring Grok-only sessions do not go stale between refreshes.

It is like a cashier importing receipt slips from a new register directly into the daily ledger, tracking project costs clearly without external bank inquiries.
FEATURE

Codex CLI auto-starts a 5-hour session keeper for $20 plans

It is like a smart parking timer that only beeps if your ticket has a time limit, staying completely silent for unlimited day passes.

Subscribers on Codex CLI's $20 plan face a 5-hour rate limit window, while $100 and $200 plans do not.

The app now automatically starts a 5-hour session keeper for eligible accounts. To keep things clean, the keeper only pings when local rate-limit data has actually reported a five_hour_window_minutes value, leaving unlimited plans completely untouched.

FEATURE

Grok icon no longer vanishes in WebKit across five themes

In the five panel themes classic, catppuccin, origami, stained_glass, and prism_arcade, Grok's icon no longer vanishes in the real app while Chromium tests appear normal.

The sizing and color rules for SVG icons previously applied only to the Antigravity card. Grok's icon container was outside those rules, so WebKit rendered it at its default intrinsic size of zero and the icon became invisible. The same rules now also cover Grok's icon container in all five themes.

It is like a print shop that had a size template for an older logo but none for the new one, leaving it off the finished page until the same template was added.
FEATURE

Grok joins Hide Sections for manual hiding on desktop

When a Grok card has data but you want to put it away temporarily, the "Hide Sections" menu on macOS and Windows now lets you choose it manually.

Grok previously auto-hidden only when no data was available. The menu already controlled the other three providers, but not Grok. It is now an option too, so you can choose whether it is shown or hidden like the other three.

It is like an exhibition with curtains for only three display cases: the fourth switched off by itself only when empty, and now it has its own curtain for you to open or close.
FEATURE

Grok gets its own monochrome theme accent, ending purple color clash

Grok now uses its own per-theme monochrome accent, matched to its black-and-white brand and each theme.

Grok's official branding is strictly black and white, but its cards initially shipped with hardcoded purple hex values across all 13 themes, looking close enough to Antigravity's blue that the two appeared related. This release replaces the hardcoded values with a per-theme --grok token, mirroring Antigravity's theme structure and matching the visual language of each design.

It is like outfitting a new department with its own tailored black-and-white insignia instead of borrowing a purple label from the neighboring rack.
FEATURE

Demo panels add Grok row, updating all README screenshots

When browsing project documentation and previews, readers will now see all four providers displayed together.

The panel demo generator was not updated with a Grok row when the card originally shipped, meaning theme screenshots in the README mistakenly showed three providers instead of four. This update adds the missing demo row and regenerates every theme screenshot, ensuring all visuals accurately represent the four-card layout.

It is like a product catalog photographer reshooting the entire collection to include the newly launched fourth model, showing customers the complete lineup at a glance.
FEATURE

Yearly Wrapped card receives visual polish with glows and badges

It is like refining a commemorative plaque: casting a soft glow behind the mascot, adding layered highlights to the emblem, and letting the illustration gently break outside its frame for a richer look.

The exported HTML report received a pure CSS styling refresh in its "年度 Wrapped" section.

A radial-gradient glow now illuminates the background behind the beast illustration, while the WRAPPED badge features a layered gradient with an inset highlight. The artwork is also allowed to overflow past its grid column, preventing awkward empty margins. These changes are entirely visual and introduce no functional modifications.
