zh-TW

Grok CLI 支援本機額度卡片，讀取每週進度零網路請求

想掌握 Grok CLI 的使用額度，現在打開面板就能直接看見每週進度條。這就像看自家牆外的瓦斯表指針，不必打電話給瓦斯公司詢問，瞄一眼就知道本週用了多少。 系統直接讀取 Grok CLI 寫在本機記錄檔（~/.grok/logs/unified.jsonl）中的每週信用額度百分比，全程不需要任何網路請求，也不會啟動任何背景行程。由於該記錄檔未提供工作階段或消耗速率數據，因此不同於 Claude、Codex 與 Antigravity，本卡片只顯示單一每週進度條。這項功能已完整整合至 macOS 面板與 Windows 系統匣（tray，工作列右下角常駐圖示區）。介面同時支援五種語言，且全部 13 款主題的圖示風格皆比照既有徽章規範。

Grok CLI 每次請求納入今日花費，專案與模型歸屬精準核算

頻繁使用 Grok CLI 產出內容的開發者，今日花費面板現在能如實反映你的每一次呼叫。Grok CLI 原先就會在本地記錄檔寫入每輪提示、完成、快取與推論的 token（AI 處理與計費的文字單位）計數事件 shell.turn.inference_done。系統新增載入器將這些事件轉換為 UsageEntry 資料列，並透過工作階段識別碼串接模型變更與建立事件，精準歸屬模型與專案。這讓 Grok 的活動與 Claude、Codex 一樣計入面板的「今日」總花費、token 總量與專案明細，全程維持零網路請求。此外，該記錄檔已加入歷史指紋的重算清單，避免兩次重新整理之間純用 Grok 的工作階段數據過期。這有如會計櫃檯將新收銀機的每筆明細單直接匯入當日帳冊，各專案開銷一清二楚，無須額外向銀行查帳。

Codex 20 美元方案自動啟動保活器，無限制方案不受影響

這好比隨身攜帶的定時鬧鐘：只在停車單註記了限時停車規則時才會輕聲提醒，若是全天暢停的通行證則保持靜默。 使用 Codex CLI 的 20 美元方案訂閱者，常會遇上 5 小時限流時間窗，而 100 美元與 200 美元方案則不受此限制。現在系統會為 20 美元方案自動啟動 5 小時工作階段（session，單次持續連線的工作週期）保活器。該保活機制極為謹慎，只有在本機限流資料曾回報過 five_hour_window_minutes 數值時才會發送探測訊號，確保無限制方案完全不被干擾。

五款主題修正 Grok 圖示，WebKit 不再隱形

在 classic、catppuccin、origami、stained_glass 與 prism_arcade 五款面板主題查看 Grok 時，實際 App 不會再出現圖示缺席、Chromium 測試卻看似正常的落差。原本 SVG 圖示（可縮放的向量圖）的尺寸與色彩規則只套用於 Antigravity 卡片。Grok 圖示容器不在範圍內，WebKit（App 繪製畫面的引擎）便以預設原生尺寸零繪製，於是圖示隱形。現在五款主題都將同一套規則延伸到 Grok 圖示容器。像印刷廠替舊版標誌備妥尺寸版型，新標誌漏了版型而印不出來；補上同一規格後，它也能正常出現在成品上。

Grok 加入隱藏區塊選單，可在桌面版手動收起

當面板上已有資料，卻想暫時收起 Grok 卡片時，macOS 與 Windows 的「隱藏區塊」選單現在也可手動選它。以前 Grok 只會在沒有資料時自動隱藏；選單已能控制其他三家服務商，卻沒有 Grok。它現已列入選項，因此能像其他三家一樣自行決定顯示或隱藏。像展場原本只有三個展櫃的遮簾可拉，第四個展櫃只會在空著時自動關燈；現在也有自己的遮簾，展示與收起都由你安排。

Grok 換上專屬黑白單色強調色，不再與 Antigravity 混淆

Grok 現在改用符合其黑白品牌、依主題調整的專屬單色強調色。Grok 官方品牌一向採用黑白單色風格，但先前版本在全部 13 款主題中皆寫死了紫色十六進位色碼；這與 Antigravity 的藍色過於接近，容易讓使用者誤以為兩者是同一品牌的系列變體。本次更新比照 Antigravity 現有的主題強調色結構，改用各主題專屬的 --grok 變數標記，讓每款主題下的 Grok 卡片都能呈現與該主題視覺語言高度融合的單色強調效果。這宛如為新品牌換上原廠訂製的黑白徽章，不再借用隔壁專櫃的紫色標籤，界線分明且和諧一致。

範本產生器加入 Grok，說明文件截圖完整展示四卡

查閱說明文件與預覽主題效果時，讀者能看見四家服務商齊聚的完整畫面。面板範本產生器在先前 Grok 卡片釋出時未同步加入 Grok 範本列，導致專案說明文件（README，專案首頁的介紹文件）裡展示的所有主題截圖都只出現三家服務商而非完整的四家。這次更新補齊了 Grok 範本資料列，並重新產生了全部主題的面板展示截圖，確保每張截圖都能忠實呈現包含 Grok 在內的四卡版面。這恰似型錄攝影師重拍全系列商品宣傳照，補上新發表的第四款產品，讓買家翻開目錄就能看清所有陣容。

年度 Wrapped 卡片樣式升級，光暈與徽章更精緻且改善留白

這有如為紀念證書重新打光：在神獸主角身後打上柔和光環，搭配多層次高光徽章，並讓畫作邊緣自然延伸破格，整體氣勢更為生動。 匯出的 HTML 報表在「年度 Wrapped」視覺區塊獲得了純 CSS 樣式升級。怪獸插圖背後新增了放射狀漸層（radial-gradient，由中心向外發散的漸層光暈）背景光；WRAPPED 徽章採用多層漸層搭配內陰影高光效果；同時放寬版面限制，讓怪獸插圖能自然溢出其網格欄位邊界，避免留白處顯得生硬空曠。本次調整全為純樣式優化，未改動任何功能邏輯。

en

Grok CLI joins as a fourth local quota card with zero network calls

When checking your Grok CLI usage, you can now see a weekly progress bar right inside the popover. It is like glancing at the gas meter on the outside wall: you know this week's total at a glance without calling the utility company. The card directly reads the weekly credit percentage Grok CLI already writes to its local debug log (~/.grok/logs/unified.jsonl), requiring zero network requests and spawning no extra background processes. Because this log file contains no session or burn-rate information, the card displays a single weekly bar unlike Claude, Codex, and Antigravity. This new card is fully integrated into the macOS popover and Windows tray. It supports all five languages, and its icon styling across all 13 panel themes strictly follows each theme's badge conventions.

Grok CLI token usage now feeds today's cost totals and project attribution

Developers frequently using Grok CLI will now see every call reflected in the daily spend panel. Grok CLI already writes prompt, completion, cached, and reasoning token counts to its local debug log as shell.turn.inference_done events. A new loader converts these events into UsageEntry rows, correlating them by session id with model-changed and session-created events for model and project attribution. This allows Grok activity to feed into the popover's "today" cost, token total, and project rows just like Claude and Codex, while maintaining zero network calls. Grok's log has also been added to the history fingerprint's always-restat file sources, ensuring Grok-only sessions do not go stale between refreshes. It is like a cashier importing receipt slips from a new register directly into the daily ledger, tracking project costs clearly without external bank inquiries.

Codex CLI auto-starts a 5-hour session keeper for $20 plans

It is like a smart parking timer that only beeps if your ticket has a time limit, staying completely silent for unlimited day passes. Subscribers on Codex CLI's $20 plan face a 5-hour rate limit window, while $100 and $200 plans do not. The app now automatically starts a 5-hour session keeper for eligible accounts. To keep things clean, the keeper only pings when local rate-limit data has actually reported a five_hour_window_minutes value, leaving unlimited plans completely untouched.

Grok icon no longer vanishes in WebKit across five themes

In the five panel themes classic, catppuccin, origami, stained_glass, and prism_arcade, Grok's icon no longer vanishes in the real app while Chromium tests appear normal. The sizing and color rules for SVG icons previously applied only to the Antigravity card. Grok's icon container was outside those rules, so WebKit rendered it at its default intrinsic size of zero and the icon became invisible. The same rules now also cover Grok's icon container in all five themes. It is like a print shop that had a size template for an older logo but none for the new one, leaving it off the finished page until the same template was added.

Grok joins Hide Sections for manual hiding on desktop

When a Grok card has data but you want to put it away temporarily, the "Hide Sections" menu on macOS and Windows now lets you choose it manually. Grok previously auto-hidden only when no data was available. The menu already controlled the other three providers, but not Grok. It is now an option too, so you can choose whether it is shown or hidden like the other three. It is like an exhibition with curtains for only three display cases: the fourth switched off by itself only when empty, and now it has its own curtain for you to open or close.

Grok gets its own monochrome theme accent, ending purple color clash

Grok now uses its own per-theme monochrome accent, matched to its black-and-white brand and each theme. Grok's official branding is strictly black and white, but its cards initially shipped with hardcoded purple hex values across all 13 themes, looking close enough to Antigravity's blue that the two appeared related. This release replaces the hardcoded values with a per-theme --grok token, mirroring Antigravity's theme structure and matching the visual language of each design. It is like outfitting a new department with its own tailored black-and-white insignia instead of borrowing a purple label from the neighboring rack.

Demo panels add Grok row, updating all README screenshots

When browsing project documentation and previews, readers will now see all four providers displayed together. The panel demo generator was not updated with a Grok row when the card originally shipped, meaning theme screenshots in the README mistakenly showed three providers instead of four. This update adds the missing demo row and regenerates every theme screenshot, ensuring all visuals accurately represent the four-card layout. It is like a product catalog photographer reshooting the entire collection to include the newly launched fourth model, showing customers the complete lineup at a glance.

Yearly Wrapped card receives visual polish with glows and badges

It is like refining a commemorative plaque: casting a soft glow behind the mascot, adding layered highlights to the emblem, and letting the illustration gently break outside its frame for a richer look. The exported HTML report received a pure CSS styling refresh in its "年度 Wrapped" section. A radial-gradient glow now illuminates the background behind the beast illustration, while the WRAPPED badge features a layered gradient with an inset highlight. The artwork is also allowed to overflow past its grid column, preventing awkward empty margins. These changes are entirely visual and introduce no functional modifications.
