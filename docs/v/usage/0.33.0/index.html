Usage 0.33.0

發布日期：2026-10-07

繁體中文

新功能

新手模式帶你看懂專有名詞，搭配隨堂測驗加深記憶

剛開始接觸指令列工具時，終端機跳出的艱澀字詞常讓人看得一頭霧水。

macOS 版現在新增預設關閉的新手模式，在 Claude Code 回答完後，會在輸入框上方挑出最多 3 個專有名詞，並附上一行與介面相同語言的白話解釋。你可以按 9 標記為懂了，略過的名詞會在 1、3、7 天後再次出現。隨時輸入 /terms 就能翻閱名詞紀錄。開啟新對話時，可以針對你已標記懂了的名詞，在 7、21、60 天後出一題選擇題，一天最多一題，答錯的名詞則會重新回到提示清單。挑選名詞會透過你的 Claude Code 請 Claude Haiku 協助並消耗少量額度，當 5 小時額度達到 90% 以上時會自動暫停。

跟用單字卡箱複習生字一樣，以前看過的名詞容易轉頭就忘，現在標記懂了後按既定間隔複習，答錯的卡片則回到提示清單。
新功能

額度快用完時主動通報，讓 AI 開大任務前先跟你商量

當你準備把一整份複雜專案交給 AI 處理時，最怕做到一半突然撞上限額而中斷。

macOS 版新增預設關閉的額度感知模式，當 5 小時額度超過 80%、90%、95%，或週額度超過 95% 時，Claude Code 就會收到一行提示，寫明剩餘額度與重置時間。在展開大型任務前，Claude 會先提醒你額度吃緊，由你選擇先做局部小任務或等待重置。這項功能支援 Claude Code、Codex 與 Antigravity，每個額度門檻在同一個對話中只會通報一次，且不會產生額外的模型呼叫。

彷彿開車上高速公路時儀表板主動亮燈，以前油箱見底你可能還毫不知情，現在副駕駛會提早報出剩餘油量與下個加油站距離，好決定先換小路或等補給。
新功能

Claude Code 開關收進專屬子選單，選單列更清爽

想在選單列中快速調整工具設定時，若所有開關都堆在同一層，容易讓人眼花撩亂。

現在側邊面板、新手模式與額度感知模式這三項開關，集中在選單列選單中的「Claude Code」專屬子選單，就像面板主題一樣集中管理。現在歸類後不僅讓主選單畫面更為清爽，找尋相關功能也更直覺。

如同工具箱用專用隔層收納同系列工具，現在要查看這三項開關，就打開標著 Claude Code 的那一格，能一起看到它們。
新功能

速率標籤改跟自己比，不再動輒誤報高負載

平時透過介面觀察自己的用量速率時，很容易發現指標動不動就亮起高負載。

現在閒置、正常、活躍與高負載四種速率標籤，改用你過去 30 天的個人用量紀錄來劃分。用量排在最低 25% 的時段算閒置，只有衝進你最忙碌的前 5% 時才會標記為高負載。以往固定的統計門檻，會讓平常的 Opus 工作階段幾乎全程顯示高負載。在歷史紀錄累積滿 24 小時之前，則會暫時沿用舊門檻。

像運動手錶按你自己的體能設定心率區間，以前拿運動員的標準來套，稍微慢跑就整路狂響高負荷警報，現在改對齊你平時的心跳分佈，真正衝刺時才亮紅燈。

FEATURE

Beginner mode explains technical terms and reinforces memory with quick quizzes

When first using command-line tools, obscure terms appearing in the terminal often feel confusing.

The macOS version adds a beginner mode that is off by default. After Claude Code finishes responding, it picks up to 3 technical terms above the input box and provides a one-line plain-language explanation in the same language as your interface. You can press 9 to mark a term as understood, while skipped terms reappear after 1, 3, and 7 days. Entering /terms at any time lets you browse your term history. When starting a new conversation, it can present one multiple-choice question on terms you marked as understood after 7, 21, and 60 days, up to one question per day, and incorrectly answered terms return to the hint list. Selecting terms asks Claude Haiku for assistance through your Claude Code and consumes a small amount of quota, automatically pausing when the 5-hour quota reaches 90% or higher.

Like reviewing vocabulary with a flashcard box, terms seen before were once easy to forget quickly, but now marking them as understood reviews them at set intervals, with missed cards returning to the hint list.
FEATURE

Proactive quota notifications let AI consult you before starting large tasks

When handing an entire complex project to AI, the biggest worry is being interrupted halfway through by hitting limits.

The macOS version adds a quota-aware mode that is disabled by default. When the 5-hour quota exceeds 80%, 90%, or 95%, or the weekly quota exceeds 95%, Claude Code receives a one-line prompt specifying remaining quota and reset time. Before starting large tasks, Claude warns you that quota is tight, leaving you to choose between tackling smaller subtasks first or waiting for a reset. This feature supports Claude Code, Codex, and Antigravity, reporting each quota threshold only once per conversation without generating extra model calls.

Picture a dashboard lighting up while driving on the highway; previously you might not notice an empty tank, but now a co-pilot announces remaining fuel and distance to the next station early so you can choose side roads or wait for refueling.
FEATURE

Claude Code toggles move into a dedicated submenu for a cleaner menu bar

When adjusting tool settings quickly from the menu bar, stacking all switches on the same level easily causes clutter.

The side panel, beginner mode, and quota-aware mode toggles are now gathered into a dedicated "Claude Code" submenu within the menu bar menu, managed centrally just like popover themes. Organizing them makes the main menu cleaner and locating related features more intuitive.

Think of a toolbox using dedicated compartments for related tools; checking these three toggles now means opening the section labeled Claude Code to see them all together.
FEATURE

Rate labels benchmark against your history to reduce false high load warnings

When monitoring your usage rate through the interface, indicators frequently trigger high load warnings unnecessarily.

The four rate labels—idle, normal, active, and high load—are now classified using your personal usage history over the past 30 days. Periods in your lowest 25% of usage count as idle, while only spikes reaching your busiest top 5% are marked as high load. Previously, fixed statistical thresholds caused regular Opus sessions to display high load almost the entire time. Before 24 hours of history accumulate, the old thresholds are temporarily used.

A sports watch customizes heart rate zones to your fitness; applying an athlete's standard once caused heavy load alarms during light jogs, but calibrating to your normal heart rate distribution lights up red only when truly sprinting.
