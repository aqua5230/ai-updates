Usage 0.34.8

發布日期：2026-10-30

繁體中文

問題修復

匯出報表徹底遮蓋專案名稱，CSV 檔案防止符號觸發試算表公式

需要把專案用量匯出給外部團隊或主管審閱時，檔案本身的隱私與安全性現在有了更周全的防護。以往隱藏專案名稱並下載 HTML 報表，每一列資料其實還把真名藏在給輔助工具讀取的標籤裡，打開檔案原始碼就看得到。現在遮罩連同這些標籤、滑鼠提示與圖片說明一起蓋掉。若是匯出 CSV 檔案，專案名或模型名以 =、+、-、@ 開頭時，舊版會原樣寫出，Excel 可能把它當成公式執行。現在這類名稱開頭會自動加上一個單引號，維持純文字呈現。

處理公文寄送時，以前若只用奇異筆塗黑紙面，背後的複寫痕跡仍會透光看見，特殊符號甚至會被自動掃描機誤當操作指令；現在底層複寫與附註會同步塗銷，開頭也加註標記維持純文字讀取。
問題修復

進度管家在對話檢查時停用檔案監控，防止外部專案擅自執行程式

從網路下載開源專案來進行分析，最怕專案自帶的設定檔趁著背景檢查偷偷啟動惡意程式。

走進大樓櫃檯登記入內時，以前訪客繳交的證件若夾帶自動呼叫裝置，保全一翻開封面就會不知不覺觸發它運作；現在安檢只核對身分並切斷隨附的連動線路，杜絕未經許可的額外動作。

每當工作階段開始，進度管家會在專案目錄裡執行 git status 檢查目前狀態。然而專案自身的 .git/config 設定檔，原本可以指示 Git 同步啟動一支檔案監控程式，下載來的陌生專案便可能藉此暗中執行有害程式。現在 usage 執行這項檢查時會關閉檔案系統監控，防止下載的專案透過這項設定啟動程式。

新功能

macOS 程式簽章執行後維持有效，發版流程鎖定建置工具防禦供應鏈攻擊

在使用桌面應用程式或更新軟體時，程式本身的完整性有了明確把關。

檢驗精密儀器的出廠包裝時，以前開機運作就會破壞防偽封條，組裝工具遭竄改更可能混入瑕疵；現在封條在出廠前已妥善固化，產線也只採用驗證過規格的專用設備。

macOS app 第一次啟動時，以前 Python 會把編譯快取（把編譯結果暫存起來直接使用的檔案）寫進 app 裡，導致簽章失效且難以辨識竄改。現在快取在簽章前就先編好，執行時內部不再變動，簽章持續有效，app 大約多 2 MB。發布流程也防堵供應鏈攻擊。PyPI 套件改在無發布權限的步驟建置，工具版本鎖定並驗證雜湊；Windows 版的 PyInstaller 同樣鎖定，防範 10 月出現的劫持風險。打包 macOS app 用的 setuptools 亦升至 84.2.1，修補 GHSA-xmj3-9gf7-h52w。

問題修復

開啟省 token 模式不再損毀 Codex 設定檔，離線時為 GPT-6.1 Terra 補齊計價

平時若習慣為 Codex 開啟省 token（AI 處理與計費的文字單位）模式，或常在離線環境工作，現在能更穩妥維護設定與統計開銷。若 ~/.codex/config.toml 寫成 features = { hooks = false } 或 features.hooks = false，舊版多加 [features] 會讓 Codex 無法載入；現在會先檢查修改後的內容能否解析；若修改會讓檔案無法解析，就保留原檔。若價目表下載失敗，GPT-6.1 Terra 原本算為 $0；現在內建備援收錄價格，每百萬 token 輸入 $1、輸出 $5。

諮詢秘書整理帳冊時，以前見到特殊格式就硬加欄位導致整本報廢，離線時更把新服務當成免費招待；現在會先驗證改好的版本，確認格式沒壞才替換原本帳冊，斷網時也能查閱隨身底冊如實計價。
問題修復

面板標題保留英文字尾完整顯示，並移除已下架的 AI 圓桌頁面

換上不同主題面板瀏覽專案用量，標題文字不再因為邊框過矮而出現破版截斷。在預設、摺紙、彩繪玻璃、手繪筆記、心電圖和視窗 95 面板裡，「Antigravity」與「Project Usage」等標題中的 g 與 y，字尾以往會被切掉下半截。這是因為裁切長標題的外框比字體還矮，現在外框替字尾留出空間，維持版面位置不變。應用程式也不再夾帶已下架的 AI 圓桌視窗。v0.30.11 下架該功能時漏刪了頁面，由於沒有任何程式會載入它，本版已將其清理移除。

挑選展覽相框時，以前邊框尺寸比照片還小導致邊緣文字被壓扁，倉庫角落甚至還留著前年撤展的空展牌；現在相框預留足夠邊界完整襯托字樣，閒置已久的展板也一併清空撤離。

BUGFIX

Exported reports thoroughly mask project names, and CSV files prevent symbols from triggering spreadsheet formulas

When you need to export project usage for external teams or managers to review, the privacy and security of the files themselves now have more comprehensive protection. Previously, when hiding project names and downloading an HTML report, each row of data actually still hid the real name inside a label read by assistive tools, visible to anyone opening the file's source code. Masking now covers those labels along with tooltips and image descriptions. If exporting a CSV file, when a project name or model name started with =, +, -, or @, the older version wrote it as-is, so Excel could execute it as a formula. Such names now automatically start with a single quote to remain plain text.

Think of dispatching official documents: in the past, blacking out paper with a marker still left carbon-copy traces visible against the light, and special symbols could even be mistaken for operational commands by automatic scanners; now underlying copies and notes are erased at the same time, with a prefix mark added to keep them read as plain text.
BUGFIX

Progress Concierge disables file monitoring during session checks to prevent external projects from running programs without permission

When downloading open-source projects from the internet for analysis, the biggest worry is that bundled configuration files might sneakily launch malicious programs during background checks.

Picture signing in at a building front desk: in the past, if a visitor's badge carried an automated pager, a security guard opening the cover would trigger it without knowing; now security checks only verify identity and cut off any accompanying trigger lines, stopping unauthorized actions entirely.

Whenever a session begins, Progress Concierge runs git status in the project directory to check current status. However, a repository's own .git/config configuration file could originally instruct Git to launch a file-system monitor program at the same time, allowing an unfamiliar downloaded project to covertly execute harmful programs. usage now disables file-system monitoring when performing this check, preventing downloaded projects from launching programs through this setting.

FEATURE

macOS code signatures remain valid after execution, and release pipelines lock build tools against supply-chain attacks

When using desktop applications or updating software, the integrity of the program itself now has clear safeguards.

Inspecting factory packaging for precision instruments offers a comparison: previously, turning on the machine broke the tamper-evident seal, and altered assembly tools could introduce flaws; now seals are properly cured before shipping, and production lines use only dedicated equipment with verified specifications.

On first launch of the macOS app, Python previously wrote its compiled caches into the app, which broke the signature and made any later tampering impossible to identify. Caches are now built before signing, so nothing inside changes during execution, keeping the signature valid and making the app about 2 MB larger. The release workflow also defends against supply-chain attacks. The PyPI package is now built in a step without publishing permissions, with tool versions locked and hashes verified; the Windows version of PyInstaller is locked the same way to prevent hijacking risks that emerged in October. The setuptools used to package the macOS app is also upgraded to 84.2.1 to patch GHSA-xmj3-9gf7-h52w.

BUGFIX

Turning on Token Saver no longer corrupts Codex configs, and pricing is filled in for GPT-6.1 Terra while offline

If you regularly enable Token Saver mode for Codex to conserve tokens (text units processed and billed by AI), or often work in offline environments, you can now maintain settings and track spending more reliably. If ~/.codex/config.toml was written as features = { hooks = false } or features.hooks = false, older versions added an extra [features] section that prevented Codex from loading; it now checks whether the modified content parses first, leaving the original file untouched if the edit would fail to parse. If downloading the price table failed, GPT-6.1 Terra originally counted as $0; the built-in fallback now includes its pricing, at $1 for input and $5 for output per million tokens.

A secretary organizing account ledgers faced similar challenges: previously, forcing extra columns into an unfamiliar format ruined the entire book, and working offline led to treating new services as complimentary; now the revised version is verified first, replacing the original ledger only after confirming the format remains intact, while a pocket ledger is consulted to price services accurately during network outages.
BUGFIX

Panel titles fully display English letter descenders, and the retired AI Council page is removed

When switching between themed panels to browse project usage, title text is no longer cut off due to overly short bounding boxes. In the Default, Origami, Stained Glass, Sketchbook, Heart Monitor, and Windows 95 panels, titles such as "Antigravity" and "Project Usage" previously had the lower halves of descenders on letters g and y cut off. This happened because the frame trimming long titles was shorter than the font; the frame now leaves room for descenders while keeping layout positioning unchanged. The application also no longer bundles the retired AI Council window. When v0.30.11 retired this feature, its page was left behind, and because no program loaded it, this version cleans up and removes it.

Framing artwork for an exhibition works the same way: previously, frames smaller than the photos squashed marginal lettering, and warehouse corners still held empty signboards from displays dismantled two years ago; now frames preserve ample borders to display lettering fully, while long-idle boards are cleared away together.
