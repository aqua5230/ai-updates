Usage 0.32.3

發布日期：2026-10-05

繁體中文

新功能

額度重置立即歸零，面板更新即時顯示狀態

每當你等待用量重置或手動點擊更新時，畫面上的數值與按鈕狀態現在都能即時反映最新進度。

像手機上網流量在每月結算日重新計費，以前帳單週期剛換時螢幕還停留在上個月的滿額警告，現在時間一到就直接歸零並標記重置，查帳時不必再盯著舊數據反覆猜測。

5 小時或每週額度（quota，固定時間內能使用的 AI 運算量上限）重置時間一到，選單列、彈出面板、Windows 系統匣與 Claude Code 側邊面板都會立即顯示 0% 與「已重置」，直到新資料載入，不再卡在上一週期的百分比。系統通知與歷史紀錄則會繼續維持實際讀到的數值，確保用量軌跡不受影響。在 macOS 與 Windows 上按下「立即更新」按鈕後，彈出面板的狀態標籤也會顯示「↻ 更新中…」，直到整個更新流程順利完成。

新功能

側邊面板完整列出背景工作，任務未跑完不再誤報完成

交給 Claude Code 處理耗時任務時，側邊面板現在能清楚掌握每一項背景工作的即時進度。

跟搬家公司清點物件一樣，以前工作人員搬完客廳桌椅就急著宣布完工，把還在裝箱的廚房物品全拋在腦後；現在總指揮會盯著所有搬運項目陸續上車，等每件家具確實定位才通知你簽收。

主對話輪次結束但背景工作還在跑時，側邊面板會持續顯示轉圈圖示，直到所有工作結束才跳出完成提示，不再提早宣告對話完成。面板內的背景工作區以前只保留最後四列，現在所有執行中的工作都會完整顯示，已結束的工作則收進「+N 個」按鈕供點擊展開。追蹤項目也不再只限於派發給 codex、agy、grok、muse 與子代理（subagent，替主要對話分頭處理任務的輔助程式），一般的背景指令、監控程序和工作流程現在都會列入清單，並讓對話正確維持在工作中。

English

FEATURE

Quotas Reset to Zero Instantly, and Panels Display Live Status During Refresh

Whenever you wait for usage to reset or click refresh manually, the numbers and button states on your screen now reflect the latest progress in real time.

Think of mobile data resetting on billing day: where screens previously stayed stuck on the prior month's limit warning right as a new billing cycle began, the display now immediately drops to zero and marks the reset the moment time arrives, saving you from guessing over stale numbers.

When the 5-hour or weekly quota reset time arrives, the menu bar, popover panel, Windows system tray, and Claude Code side panel immediately display 0% and "Reset" until fresh data loads, instead of remaining stuck on the previous cycle's percentage. System notifications and history logs continue to maintain the actual retrieved values, ensuring usage history remains unaffected. After clicking the "Refresh Now" button on macOS and Windows, the popover panel's status label also displays "↻ Updating..." until the entire update process completes smoothly.

FEATURE

Side Panel Lists Background Tasks in Full, Ending Premature Completion Alerts While Jobs Run

When handing off time-consuming tasks to Claude Code, the side panel now clearly tracks the real-time progress of every background job.

Picture a moving crew inventorying household items: workers previously rushed to announce the job was finished right after moving living room tables and chairs, leaving packed kitchen boxes completely behind; now the supervisor tracks every item onto the truck and waits until each piece of furniture is in place before asking for your sign-off.

When the main conversation turn finishes while background tasks are still running, the side panel continues displaying a spinner icon and only presents a completion notice once all jobs finish, no longer declaring the conversation complete prematurely. The background tasks section in the panel previously retained only the last four rows, but now all running jobs are fully displayed, while finished jobs are collapsed into a "+N more" button that you can click to expand. Tracked items are also no longer limited to delegations to codex, agy, grok, muse, and subagents (helper programs handling tasks in parallel for the main conversation); standard background commands, monitoring processes, and workflows are now included in the list, keeping the conversation properly marked as working.
