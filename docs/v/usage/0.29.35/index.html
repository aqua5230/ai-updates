웹사이트의 테마 벽은 정적 스크린샷 열 장에서 직접 볼 수 있는 실제 패널 열세 개로 바뀐다. 역의 실시간 안내판처럼 실제 열차 상태는 볼 수 있지만, 안내판의 버튼을 눌러도 열차가 다른 선로로 바뀌지는 않는다.origami와 stained_glass에는 이미지가 없었고 catppuccin은 중국어만 보였으므로, 열세 테마라는 말과 달리 보이는 것은 열 개였다. 이제 웹사이트는 실제 패널 HTML을 손으로 쓴 데모 데이터와 함께 프레임에 넣고, 테마 목록은 panels.all_panels()에서 가져온다. 열네 번째 패널은 scripts/make_panel_demo.py를 실행하면 사이트에 나타나므로 사진 두 장을 더 찍을 일을 기억할 필요가 없다. 기존 applyLang()도 사이트의 언어 선택을 패널에 넘겨 다섯 언어가 함께 바뀐다. 패널은 표시 전용이며 웹페이지에는 Switch Panel과 Quit 버튼에 응답할 네이티브 쪽이 없다. 옛 스크린샷은 docs/에 남고 README도 계속 그것을 연결한다.

Stained Glass에 만화경 같은 반대 회전이 더해진다

Stained Glass 패널은 기존 빛 훑기 효과를 남기면서 화면에 움직임 한 겹을 더한다. 만화경을 돌리면 유리 조각은 반대 방향으로 돌고 빛은 굴절의 리듬을 따라 움직이는데, 이번 업데이트가 패널에 더한 변화가 바로 이것이다.겹친 조각은 kaleidoscopeTurn으로 반대 회전하고 빛 훑기는 kaleidoscopeSweep가 이어 간다. 기존 sunlightSweep와 패널 식별자 및 이름은 그대로이므로, 새 테마가 아니라 기존 Stained Glass의 시각적 개선이다.

일곱 모듈을 나누고 패키징 때 `setup` 이름 충돌을 피한다

프로젝트 루트에서 모듈 일곱 개를 더 옮겨 Python 파일은 이제 스물여덟 개만 남는다. 영화 촬영 전 역할을 나누듯 창 관련 일은 미술팀에, 메뉴 막대 일은 소품팀에, 설치 일은 지원팀에 맡긴다.panel_window와 panel_window_state는 panels/로, critter_frames는 menubar/로 들어간다. setup_hook, session_hooks, statusline_settings, login_item 네 모듈은 usage를 사용자 시스템에 설치하고 새 installer/ 패키지로 간다. 이것은 setup이라 부를 수 없다. 저장소 루트는 Python의 sys.path(Python이 모듈을 찾는 장소 목록)에 있고, 같은 이름의 최상위 패키지가 있으면 setuptools와 py2app이 패키징 때 실행하는 import setup을 가리기 때문이다. 이 실패는 테스트가 아니라 패키징할 때만 나타난다. 네 모듈은 __file__에서 위로 올라가 훅 스크립트를 찾았는데, 스크립트는 시스템 Python에서 실행하려고 루트에 남으므로 이제 한 단계 더 위로 올라간다.
