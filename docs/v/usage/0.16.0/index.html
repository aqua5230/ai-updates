開新對話自動列出未存檔改動，估算耗盡時間更神準

現在開新對話不用再自己回想改過什麼，估算用量也更準了。首先，當你開啟全新的對話時，「進度管家」不但會告訴你上次做到哪，現在還會貼心地幫你列出上一個工作階段裡「改了卻還沒提交（commit）」的檔案，讓你不用自己痛苦回想。再來，預測你「額度還有多久燒光」的演算法升級了。以前它只用頭尾兩點去拉直線，現在改用平滑的近期加權平均，這代表當你突然發狂丟大檔給 AI 時，它能立刻警覺並縮短預估時間，而不會被偶爾的一筆小雜訊騙倒。另外，如果你是雙擊打開打包好的 App，以前在開面板或跳通知時會直接閃退，現在這問題也修好了；額度暫時抓不到時，也不會再亂跳「額度用完」的幽靈通知。最後，萬一翻譯字串的佔位符跟呼叫端參數不符時，它會自動退回英文、再退回原始鍵，避免整個介面崩潰。就像是一位貼心秘書，不但會在你出門開會前遞上上一場會議還沒簽完的文件，而且幫你估算油錢時不再只拿剛買車跟現在的油表相減，而是看你這幾天的飆車習慣來精準預報，遇到下雨油表短暫失靈時也不會再大驚小怪喊沒油。

警示訊息瘦身不再爆版，順手補齊開源合規文件

你的警示畫面現在變得乾淨不爆版，開源合規文件也都幫你打點好了。額度快燒光時跳出的紅字警告，以前後面會多貼一句「(比平均快／慢 N 倍)」，字一多常常擠出面板外框；現在拿掉這句，只留下「還剩多久」跟「重置倒數」兩個重點，版面終於不會爆開。另外也把開源合規的門面補齊：新增雙語的 SECURITY.md（安全漏洞回報信箱，不是公開 Issue，避免漏洞被公開利用前就曝光）、每個 Python 檔案頂端加上 AGPL-3.0-only 授權標頭、LICENSE 版權欄也補上維護者的 GitHub 帳號。就像把公佈欄上貼得歪七扭八、字都溢出邊框的告示重新排版，順便把消防逃生圖、安檢合格證這些該貼的文件也補齊。

English

New sessions auto-list uncommitted changes, and time-to-empty estimates are dead-on

Starting a new session now automatically lists what you forgot to commit, and your quota estimates are much sharper. First, when you start a fresh conversation, the Progress Concierge's "where we left off" summary will now explicitly list any files you modified in the previous session but forgot to commit, saving you the headache of remembering them yourself. Second, the algorithm predicting "how long until you run out of quota" is completely overhauled. It used to blindly draw a straight line between your first and last usage points; now it uses a weighted rolling average, meaning if you suddenly start throwing massive files at the AI, it immediately reacts and shortens the estimate, while gracefully ignoring single-point hiccups. Finally, launching the packed App via double-click no longer instantly crashes when opening panels or requesting notifications, and temporarily missing quota data will no longer falsely trigger a "Quota Empty" ghost alarm. Finally, if a translated string's placeholder doesn't match the caller's arguments, it safely falls back to English and then to the raw key, preventing the entire UI from crashing. It's like a brilliant assistant who not only hands you the unsigned contracts from your last meeting before you head out, but also predicts your road trip's remaining mileage based on how hard you've been slamming the gas pedal today, rather than just doing a simple math problem from when you bought the car—and they stop screaming that the tank is empty just because the fuel gauge flickered, and even if they grab the wrong translated script, they just calmly read the original text instead of freezing up completely.

The burn-rate warning got shorter so it stops overflowing, and open-source paperwork is now in order

Your warning screens are now cleaner without overflowing, and all open-source compliance paperwork is fully sorted. The red warning that pops up when your quota is about to run out used to tack on a "(N× faster/slower than average pace)" suffix, and the extra text often pushed past the panel's edge. That suffix is gone now — the warning just shows time-to-empty and the reset countdown, so it fits cleanly. Separately, the project tidied up its open-source paperwork: a bilingual SECURITY.md now routes vulnerability reports to a private email instead of public Issues (so a bug isn't exposed before it's fixed), every Python file got an AGPL-3.0-only license header, and the maintainer's GitHub handle was added to the LICENSE copyright line. It's like re-laying-out a bulletin board notice that had been spilling past its frame, and while at it, finally pinning up the fire-exit map and safety inspection certificate that were supposed to be there all along.

**Progress Concierge now surfaces last session's uncommitted changes**: the "where you left off" handoff on a new conversation also lists the file changes the previous session hadn't committed yet, so you don't have to recall them.
**EMA-smoothed burn-rate forecast**: the "time until empty" estimate now uses an exponential moving average over recent interval rates instead of a single first-to-last slope, making it more responsive to sudden acceleration and steadier against single-point noise.
**Packaged .app no longer crashes on a non-terminal launch**: double-clicking the .app or launching it in the background could crash the moment it opened the panel or requested notification permission (`Argument 3 is a block, but no signature available`), because py2app shipped the bare WebKit/UserNotifications modules without their full wrapper metadata. The required block signatures are now registered unconditionally and the wrappers are bundled.
**Missing quota data no longer triggers a false "quota empty" alert**: when a quota window temporarily has no reading (e.g. an expired Codex 5-hour window), it was treated as depleted — firing a notification with a broken "back after --" body. Depletion now requires an actual 100%.
**A malformed locale string can no longer crash the UI**: if a translated string's placeholder doesn't match the call site's arguments, the lookup now falls back to English, then to the raw key, instead of raising.
