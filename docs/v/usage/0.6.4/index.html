新增復古報紙面板，繁體中文系統不再誤判成簡體

現在多了一款「復古報紙（Newspaper）」面板可以選了！它重現了舊報紙頭版的風格，有著泛黃的紙張底色、明體油墨字和傳統報紙的排版，裡面的資料邏輯則跟預設面板一模一樣。另外，以前系統在偵測語言時，只看到你用的是「中文」，就擅自把你當成簡體中文使用者；現在系統學會看更完整的地區資訊，繁體中文的系統終於能正確顯示繁體中文了。就像是寄信時只寫了「某某路」，郵差總是不小心投錯鄰居的信箱，現在補上了完整的門牌號碼，信件終於能精準送達你家了。

en

Newspaper panel added, and Traditional Chinese systems are no longer misidentified as Simplified

You can now choose the new "Newspaper" panel! It recreates the look of a vintage newspaper front page, featuring an aged newsprint background, serif ink type, and traditional newspaper layouts, while keeping the data logic exactly the same as the default panel. Also, when detecting your language previously, the system only saw "Chinese" and presumed you were a Simplified Chinese user; it has now learned to read the full region info, so Traditional Chinese systems finally display in Traditional Chinese correctly. It's like addressing a letter with only the street name, making the postman constantly drop it in the neighbor's mailbox — now that the full house number is added, the mail finally reaches your door accurately.

原始 CHANGELOG

Original changelog
**Newspaper panel**: a fourth built-in panel recreating a vintage newspaper front page — aged newsprint background, serif ink type, double-rule page border, newspaper-style section headings, hairline row dividers, solid ink progress bars. Card layout and data logic match the Classic panel; only the CSS styling differs.
**Traditional Chinese systems detected as Simplified Chinese**: `_detect_language()` read `NSLocale.languageCode`, which returns a bare `"zh"` with no region, so Traditional Chinese systems were normalized to Simplified. It now reads `localeIdentifier` (e.g. `zh_TW`), which keeps the region, so Traditional Chinese systems display Traditional Chinese correctly.
README panel section updated to show all four panels side-by-side (Traditional Chinese / English).
