Usage 0.30.24

發布日期：2026-09-26

繁體中文

新功能

HTML 報表新增派工帳本，清楚看懂跨工具額度消耗

當你讓 Claude 呼叫其他工具一起分工寫程式時，往往很難算清一項任務到底扣了哪一邊的用量。

像工程主管核對跨包商工單，以前只見到月底整筆總支出，現在能清清楚楚拆解出每個專案各自攤提了哪家廠商的工時。

現在 HTML 報表的最耗用對話清單新增了「約佔週額度」欄位，並加入「派工帳本（最近 7 天）」區塊。它會將對話中的 codex exec 與 agy -p 呼叫，對應回 Codex 與 Antigravity 的紀錄。消耗估算是以對話消耗的 token（AI 處理與計費的文字單位）佔比，乘以各平台已使用的週額度。計算時會自動排除快取（把查過的資料暫存起來直接用）讀取的份額。歸屬依序比對對話識別碼、負五至一百二十秒的時間窗與工作目錄；若仍無法確認，就保持未歸屬。全程只讀取本機檔案與既有快取，不發送額外網路請求，沒有派工時也不會顯示此區塊。

新功能

發行版本自動上傳套件庫，免存認證金鑰更安全

想要把維護好的工具打包發布，現在只要為專案建立版本標籤，流程就會透過受信任發布機制（Trusted Publishing，透過平台互信驗證身分的安全機制）自動將 usage-cli 送上 Python 套件庫 PyPI。

好比大樓改用身分認證自動辨識進出，以前必須在管理室押一把實體備用鑰匙，現在通過驗證就直接放行，櫃子裡不必保存任何密碼鑰匙。

整個自動化發布流程完全不需要在設定中存放任何 token（授權令牌），只要打上標籤發版就能安全完成發布，不必擔心金鑰外洩。

新功能

面板底部按鈕不再被裁切，窄版介面完整顯示操作文字

當你在使用較窄的面板主題或是切換到文字較長的語言介面時，可能會發現底部的操作按鈕被切掉半截。

如同排版軟體依照實際縮放比例重新測量元件，以前視窗縮放後，邊界文字會被擠出畫面；現在文字可就地換行，按鈕高度也會自然調整，字樣不再被切掉。

這次修正解決了十款面板主題在顯示狀態列（顯示在終端機最底部的即時資訊列）設定按鈕時，底部標籤與按鈕溢出的問題。介面現在會依實際縮放比例精確測量內容，避免 WebKit 引擎縮放後的字體差異造成底部被截斷，同時保留各主題原本的外觀風格。

FEATURE

HTML Reports Add Delegation Ledger to Track Multi-Tool Quota Consumption

When you have Claude delegate coding tasks to external tools, tracking which platform consumed quota for a specific task can be difficult.

Think of an engineering manager auditing contractor invoices: where they once saw only a lump-sum bill at month-end, they can now clearly break down which vendor's hours were billed to each project.

The top-spending conversations list in the HTML report now adds an "Est. % of Weekly Quota" column and introduces a "Delegation Ledger (Last 7 Days)" section. It maps codex exec and agy -p invocations within conversations back to Codex and Antigravity records. Usage estimation multiplies the conversation's token consumption share by each platform's used weekly quota. The calculation automatically excludes cached reads. Attribution matches sequentially by conversation ID, a time window of -5 to 120 seconds, and working directory; if it still cannot be confirmed, it remains unassigned. The entire process reads only local files and existing caches without making additional network requests, and the section is hidden when no delegation occurred.

FEATURE

Automated Releases Upload to Package Index Without Storing Authentication Keys

When publishing maintained tools, creating a version tag on the project will now automatically upload usage-cli to the Python package index PyPI via Trusted Publishing, a mechanism that verifies identity through trust between platforms.

Picture a secure building switching to automated identity verification: instead of leaving a physical spare key with the front desk, visitors are granted entry directly upon authentication without storing any keys or combinations in a locker.

The entire automated release workflow eliminates the need to store authorization tokens in settings. Tagging a release safely completes deployment without the risk of credential leakage.

FEATURE

Popover Bottom Buttons No Longer Clipped Across Narrow Layouts

When using a narrow popover theme or switching to a language with longer text strings, you might find the bottom action buttons cut off.

Like publishing software remeasuring elements against the actual zoom scale, where window resizing previously pushed edge text off-screen, text now wraps in place while button heights adjust naturally so labels are never clipped.

This fix resolves bottom label and button overflow across 10 popover themes when displaying status line settings buttons. The interface now accurately measures content based on the actual scale factor, preventing font rendering discrepancies in the WebKit engine from truncating the bottom while preserving each theme's original visual styling.
