Usage 0.30.19

發布日期：2026-09-23

繁體中文

新功能

App 圖示換成水墨貓，各平台標誌統一由腳本產出

在 Mac 或 Windows 桌面上啟動 usage，現在會看見俐落的扁平水墨貓圖示。

以前在 macOS 26 與 27 上，圖示會被系統關進灰框；現在依 Apple 格線畫成圓角方塊，不再出現灰框。所有圖示改由 assets/brand/ 內同一套向量原檔（彩色、全黑、反白、字標、App 圖示）經 scripts/make_app_icon.py 產出：涵蓋 Mac 與 Windows 的 App 圖示、README 頭像、官網 favicon、apple-touch-icon 與 logo 橫幅。頁首小圖、社群預覽圖與區段標籤也換上新圖示並簡化版面，未使用的管家貓 docs/avatar.png 則已刪除。

鑄幣廠用同一套母模壓製不同面額的硬幣與印記，各處標誌都維持一致神韻。
新功能

Opus 5.5 補齊離線備援價格，用量表改標簡短名稱

平時使用 Claude Code 呼叫最新的預設模型，現在離線也能算出正確花費。

從 Claude Code 2.1.280 開始，Opus 5.5（claude-opus-5-5）已成為預設的 Opus 模型。然而先前的離線備援價目表遺漏了這筆資料，導致價格快取（把算過的結果暫存起來直接用）一旦過期，該模型的花費就會被錯誤算成 $0。現在價目表已補上每百萬 token（AI 處理與計費的文字單位）輸入 $4、輸出 $20、快取寫入 $5 與快取讀取 $0.20 的定價，標準與 LiteLLM 完全一致。用量報表中的欄位也改為直接顯示「Opus 5.5」，不再印出冗長的原始識別碼。

計程車跳表機預載了最新的夜間加成費率表，就算開進收不到訊號的地下道，也能照常按新費率精準計費。
新功能

Grok 缺少總紀錄檔時，各工作階段花費照常自動補回

查詢 Grok 的使用花費時，就算總紀錄檔尚未建立也不必擔心資料遺失。

在先前的機制中，當總彙整檔 unified.jsonl 不存在時，系統會直接回傳空清單，導致個別工作階段在 updates.jsonl 裡記錄的花費跟著全部丟失。現在程式會將「檔案不存在」比照「檔案內容為空」來處理，照常從各工作階段的日誌中將花費完整補回，確保統計數據不會漏算。

抄表員發現社區總電表尚未安裝，便逐一抄下各分戶的獨立電表，依然能把整棟樓的用電度數完整拼湊回來。
新功能

官網新增首次安裝指引，校正中日韓文字排版與動態細節

造訪 usage 官網時，現在能看到更清晰的指引與細緻動態。

安裝區說明 macOS 15 起無法以右鍵打開繞過 Gatekeeper，需至「系統設定」→「隱私權與安全性」點選「強制打開」，首頁下載鈕下方與五份 README 同步附上說明。GitHub 按鈕顯示即時星星數，抓取失敗時自動隱藏，標題補上 Grok。主題截圖改 WebP（英文頁 647KB 降至 95KB），非英文頁的 JSON-LD 帶入專屬網址、語言與描述。中日韓頁依 W3C clreq 校正：標題字距歸零、中文標題僅在詞間斷行、破折號不落行首，安裝卡文字與行距放大，首屏說明改回一般斷行以消除兩端對齊拉出的過大空隙，英文頁不變。頁首紅圈載入時一筆畫出並隨閱讀縮短，複製成功補滿小紅圈，首屏標題後方有淡紅圈旋轉，並新增五語 404 頁；prefers-reduced-motion 下所有動畫關閉。

English

FEATURE

App icon switched to ink-wash cat, all platform logos generated by a script

Launching usage on a Mac or Windows desktop now shows a clean, flat ink-wash cat icon.

On macOS 26 and 27, the system previously trapped the icon inside a gray frame; it is now drawn as a rounded square following Apple's grid, eliminating the gray frame. All icons are now generated from the same set of vector source files in assets/brand/ (color, black, reversed, wordmark, app icon) via scripts/make_app_icon.py: covering Mac and Windows app icons, the README avatar, website favicon, apple-touch-icon, and logo banner. The header mark, social preview image, and section tabs also adopt the new icon with a simplified layout, while the unused butler-cat docs/avatar.png has been removed.

A mint presses coins and stamps of different denominations from a single master die, keeping the exact same character everywhere.
FEATURE

Opus 5.5 adds offline fallback pricing, usage table switches to short name

Calling the latest default model in Claude Code now computes accurate costs even offline.

Since Claude Code 2.1.280, Opus 5.5 (claude-opus-5-5) has been the default Opus model. However, the previous offline fallback price table omitted this entry, causing the model's cost to be wrongly calculated as $0 whenever the price cache expired. The price table now includes pricing of $4 input, $20 output, $5 cache writes, and $0.20 cache reads per million tokens, matching LiteLLM exactly. Columns in usage reports also directly display "Opus 5.5" instead of printing the lengthy raw identifier.

Like a taxi meter preloaded with the latest night-surcharge rates, pricing remains accurate even when driving into an underpass with no signal.
FEATURE

Grok per-session spending is recovered automatically when combined log is missing

Checking Grok spending no longer risks losing data even if the combined log has not been created yet.

Under the previous mechanism, when the combined log file unified.jsonl did not exist, the system returned an empty list, causing all spending recorded by individual sessions in updates.jsonl to be lost. The program now treats a non-existent file the same as an empty file, fully recovering spending from individual session logs as usual and ensuring statistics are never undercounted.

Picture a meter reader who discovers the building's master electric meter is not yet installed and reads each individual apartment meter instead, completely piecing together the power usage.
BUGFIX

Website adds first-launch guide, CJK typography fixes, and animated details

Visiting the usage website now presents clearer guidance and refined animations.

The install section explains that from macOS 15 onward, right-click Open no longer bypasses Gatekeeper, requiring users to go to System Settings → Privacy & Security and click Open Anyway; these instructions are linked below the hero download button and across all five READMEs. The GitHub button shows a live star count and automatically hides if fetching fails, with Grok added to titles. Theme screenshots switch to WebP (dropping from 647KB to 95KB on the English page), and non-English pages populate their own URL, language, and description in JSON-LD. CJK pages follow W3C clreq corrections: heading letter-spacing is zeroed, Chinese headings break only between words, em dashes never start a line, install card text and line height are enlarged, and hero text reverts to standard line breaks to eliminate oversized gaps caused by justified alignment, leaving English pages unchanged. The header's red circle draws in on load and shrinks as you scroll down, the copy button fills in a small red circle on success, a faint red circle rotates behind the hero title, and new 404 pages cover five languages; all animations are disabled under prefers-reduced-motion.
