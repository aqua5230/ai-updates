Usage 0.11.6

發布日期：2026-05-27

繁體中文

底部清楚標示 Codex 模型，日韓介面也不會一片空白

你現在可以直接在介面底部看到目前正在使用的 Codex 模型。以前如果剛好沒有模型資料，畫面會空一塊讓你以為壞掉了，現在它會老實印出「unknown」。同時，日文與韓文介面的模型標籤也補齊了，切換語系一樣看得到。就像去餐廳點無菜單料理，以前主廚不說話你會以為沒菜了，現在菜單底部會確實寫上今日食材或是「主廚特製」，而且各國語言的菜單都印得清清楚楚。

分析報告時間範圍跟著專案走，累積再多對話也秒開

你現在按出分析報告時，它的時間區間會自動對齊你正在看的專案範圍（Project Usage），切換 1d 就看今天、7d 就看本週，不用另外找按鈕設定。對於重度使用者來說，現在按出今日報告的時間從 7 秒大幅縮短到只要 0.03 秒。因為系統學會了「從尾巴往前掃描」，不再傻傻從盤古開天闢地第一筆對話開始讀。就像去圖書館查昨天的報紙，以前館員會從十年前的舊報紙一路翻到今天，現在他直接從最新的一疊拿給你，而且你說要找體育版，他拿出來的就直接是體育版。

English

The popover footer clearly displays the Codex model, and Japanese/Korean UIs are no longer blank

You can now see exactly which Codex model is currently active right at the bottom of the interface. Previously, if no model data was available, the space was left completely blank, making you wonder if the app broke; it now honestly prints "unknown". Additionally, the missing Japanese and Korean model labels have been filled in, so you get the same clear info regardless of language. Like a mysterious chef's tasting menu—instead of leaving the dish name blank and making you guess if the kitchen closed, the menu now explicitly says "Chef's Secret" or prints the actual ingredients, fully translated for every guest.

Analysis reports sync with your project range and open instantly regardless of history size

When you generate an analysis report, its time period now automatically matches the project range (Project Usage) you're currently viewing—selecting 1d shows today, 7d shows this week, without needing a separate toggle. For heavy users, generating today's report has plummeted from a sluggish 7 seconds down to lightning-fast 0.03 seconds. The system now smartly scans backwards from the newest entries instead of mindlessly reading your entire history from the dawn of time. Like asking a librarian for yesterday's newspaper—instead of flipping through a decade of archives from page one, they now grab right from the top of the freshest pile, already opened to the section you requested.
