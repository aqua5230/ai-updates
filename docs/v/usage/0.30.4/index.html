zh-TW

Windows 面板縮放完整呈現，消弭底部空白且防範死結

就像裁縫師在布料縮水前先預留延伸長度，量測尺寸時暫時扣除這段預留值，處理完後版型恰好合身，既不緊繃也不拖地。 Windows 上的經過縮放的面板能完整顯示所有內容，頁尾下方不再殘留空白條帶。控制器 _WindowsTrayController._apply_panel_zoom() 改由背景執行緒呼叫 window.usageApplyPanelZoom()，隨後僅將調整大小與位移交給 UI 執行緒，避開了 WebView2 的死結（deadlock，處理序互相等待而卡住）。函式 usageApplyPanelZoom() 接收自然高度並在套用 CSS zoom 前擴展 body，而 naturalContentHeight() 量測時會暫時移除該補償，確保縮放版面有足夠空間而不裁切卡片。

Windows 納入 Grok CLI 用量統計，日誌讀取失敗不影響既有紀錄

在 Windows 開啟今日用量面板查看費用、token（AI 計費與文字計量單位）總數與專案清單時，Grok CLI 紀錄會一併出現。控制器 _WindowsTrayController._load_entries() 在載入既有的 Claude 與 Codex 資料時，會一併呼叫 grok_loader.load_entries() 讀取記錄。若 Grok 日誌讀取失敗，對應的錯誤處理機制會保留已收集的 Claude 與 Codex 項目。像三條獨立水管流進同一個水槽，第三條堵住時，前兩條已流入的水仍留在槽裡。

Token Saver 導入三項白話寫作規則，版號升級免除重複重寫

你請 Token Saver 把一段回覆縮短時，這 3 條規則會套用。在 i18n.json 的 terse_mode_instruction，以及其在 _DEFAULT_INSTRUCTION 中的獨立副本裡，5 種語言皆要求將名詞化還原為動詞、刪除只報幕不提供資訊的句子，並先放已知資訊，再放新資訊。同時 installer/session_hooks.py 的 TERSE_HOOK_VERSION 與 usage_terse_mode.py 的 __version__ 皆升至 1.3，讓 _installed_terse_version() 維持已安裝 sidecar（隨附輔助檔）最新，免於每個工作階段重寫。像一台有三個調整鈕的機器，三種寫法依設定一起運作；標記升至 1.3 時，只替已裝好的小模組換新版。

en

Scaled Windows panels show full content without footer gaps or deadlocks

Like a tailor allowing extra length for fabric shrinkage and temporarily deducting that allowance during measurements, ensuring the finished garment fits neatly without being cropped or dragging. Scaled Windows panels now display all their content completely, eliminating the blank strip below the footer. _WindowsTrayController._apply_panel_zoom() now invokes window.usageApplyPanelZoom() from a background thread before delegating only resize and move work to the UI thread, avoiding a WebView2 deadlock. The usageApplyPanelZoom() function receives natural height and expands body before applying CSS zoom, while naturalContentHeight() temporarily removes that compensation during measurements so the scaled layout preserves ample space instead of clipping cards.

Windows tracks Grok CLI activity with fault-isolated log loaders

When you open today's usage panel on Windows to check costs, token totals, and the project list, Grok CLI records now appear too. Inside _WindowsTrayController._load_entries(), the controller calls grok_loader.load_entries() alongside the existing Claude and Codex loaders. If reading the Grok log fails, dedicated error handling preserves the Claude and Codex entries already collected. Like three separate pipes feeding one tank, a blockage in the third pipe leaves the water from the first two in place.

Token Saver enforces three plain-language rules with versioned sidecars

When you ask Token Saver to shorten a reply, these three rules apply. Across all five languages, terse_mode_instruction in i18n.json and its standalone copies in usage_terse_mode.py's _DEFAULT_INSTRUCTION turn nominalizations back into verbs, cut sentences that announce without informing, and put known information before new information. Meanwhile, TERSE_HOOK_VERSION in installer/session_hooks.py and __version__ in usage_terse_mode.py both move to 1.3, so _installed_terse_version() keeps installed sidecars current instead of rewriting them on every session. Like a machine with three adjustment knobs, the three writing rules work together; when its marker reaches 1.3, only the installed small module is swapped for the new version.

Windows のスケールされたパネルが完全表示、余白とデッドロックを解消

洗濯による縮みを想定してあらかじめ生地を広めに裁断し、採寸時はその余白を一時的に差し引くことで、仕上がりが切り詰められず余計な余白も出ないように合わせる仕立て直しのようなものだ。 Windows でスケールされたパネルにおいて、すべての内容が表示されフッター下の空白帯も解消された。_WindowsTrayController._apply_panel_zoom() はサイズ変更と移動の処理のみを UI スレッドへ渡す前にバックグラウンドスレッドから window.usageApplyPanelZoom() を呼び出し、WebView2 のデッドロック（deadlock、処理同士が互いを待ち合って停止する状態）を回避する。usageApplyPanelZoom() は元の高さを受け取って CSS の zoom を適用する前に body を拡張し、naturalContentHeight() が測定時にその補正を一時的に外すことで、スケール後の配置に十分な領域を確保してカードの端が切り取られるのを防ぐ。

Windows で Grok CLI の利用実績を集計、ログ読み込み失敗時も既存データを保護

Windows で今日の利用量パネルを開き、費用、トークン合計、プロジェクト一覧を確認すると、Grok CLI の記録も一緒に表示される。_WindowsTrayController._load_entries() は既存の Claude と Codex のローダーと並んで grok_loader.load_entries() を呼び出す。Grok のログ読み込みに失敗しても、対応するエラー処理によってすでに収集された Claude と Codex の記録はそのまま保持される。3 本の独立した水路が一つの水槽に注がれ、3 本目の流れが止まっても、先に入った 2 本分の水は残るようなものだ。

Token Saver が 3 つの平易化規則を導入、版数管理で再書き込みを防止

Token Saver に返信の一部を短くするよう頼むと、この 3 つの規則が適用される。i18n.json の terse_mode_instruction と、usage_terse_mode.py の _DEFAULT_INSTRUCTION 内にあるその独立したコピーでは、全 5 言語で名詞化を動詞へ戻し、情報を伝えない告知文を削り、既知の情報を新しい情報より前に置く。また installer/session_hooks.py の TERSE_HOOK_VERSION と usage_terse_mode.py の __version__ がともに 1.3 に進み、_installed_terse_version() がセッションごとに書き直さず、導入済みサイドカー設定ファイルを最新に保つ。3 つの調整つまみを備えた機械のように、3 種類の書き方の規則がそろって働く。印が 1.3 になると、取り付け済みの小さな部品だけを新版へ差し替える。

ko

크기가 조정된 Windows 패널이 온전히 표시되고 하단 여백과 교착 상태를 해소

세탁 후 수축을 감안하여 천을 미리 넉넉하게 재단하고 치수를 잴 때는 여유분을 잠시 제외하여, 완성된 옷이 잘려 나가지도 않고 밑단이 남지도 않도록 맞추는 재단 작업과 같다. Windows에서 크기가 조정된 패널이 모든 내용을 온전히 보여주며 바닥글 아래의 빈 띠가 사라졌다. _WindowsTrayController._apply_panel_zoom 메서드는 크기 조정과 이동 작업만 UI 스레드로 넘기기 전에 백그라운드 스레드에서 window.usageApplyPanelZoom 함수를 먼저 호출하여 WebView2의 교착 상태(deadlock, 스레드들이 서로 대기하며 멈추는 현상)를 방지한다. usageApplyPanelZoom 함수는 본래 높이를 전달받아 CSS zoom 속성을 적용하기 전에 body 영역을 확장하며, naturalContentHeight 함수가 측정 중에 해당 보정치를 일시적으로 제거하여 크기가 조정된 레이아웃이 카드를 자르지 않고 충분한 공간을 확보하도록 한다.

Windows에서 Grok CLI 사용량을 집계하고 로그 오류 시 기존 기록을 보존

Windows에서 오늘 사용량 패널을 열어 비용, 토큰 총합, 프로젝트 목록을 확인하면 Grok CLI 기록도 함께 표시된다. _WindowsTrayController._load_entries 메서드는 기존 Claude 및 Codex 로더와 함께 grok_loader.load_entries 메서드를 호출한다. Grok 로그를 읽지 못해도 전용 오류 처리가 이미 수집한 Claude와 Codex 항목을 그대로 보존한다. 세 개의 독립된 물관이 하나의 물통으로 이어져 있어 세 번째 물관이 막혀도 앞의 두 물관에서 들어온 물은 남아 있는 것과 같다.

Token Saver에 3가지 일상어 작성 규칙 도입 및 판올림으로 재작성 방지

Token Saver에게 답변 일부를 짧게 해 달라고 하면 이 3가지 규칙이 적용된다. i18n.json의 terse_mode_instruction 문자열과 usage_terse_mode.py의 _DEFAULT_INSTRUCTION에 있는 별도 사본은 5개 언어 모두에서 명사화를 동사로 되돌리고, 정보 없이 알림만 하는 문장을 삭제하며, 아는 정보를 새로운 정보 앞에 배치한다. 아울러 installer/session_hooks.py의 TERSE_HOOK_VERSION과 usage_terse_mode.py의 __version__이 모두 1.3으로 올라가, _installed_terse_version 함수가 매 세션마다 파일을 다시 쓰지 않고 설치된 사이드카 설정 파일을 최신 상태로 유지한다. 세 개의 조절 손잡이가 있는 기계처럼 세 가지 작성 규칙이 함께 작동하며, 표시가 1.3이 되면 설치된 작은 모듈만 새 판으로 교체한다.
