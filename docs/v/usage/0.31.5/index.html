Usage 0.31.5

發布日期：2026-10-03

繁體中文

新功能

狀態列排版精簡，重置時間與快取命中一目了然

在終端機專心配對程式碼時，螢幕最底部的即時資訊現在變得更短。

好比汽車儀表板精簡了多餘的指針，以前塞滿次要數據容易讓人分心，現在只留關鍵油量與里程，一眼就能看清現況。

第一行現在只保留專案名稱與兩個額度，上下文視窗（對話可容納的內容範圍）資訊則移至第二行末尾。兩個額度改用較暗的顏色顯示，並在剩餘時間前標出重置時刻，例如 22:00(剩 3h45m)。快取（把算過或查過的結果暫存起來直接用）區塊移除了進度條與倒數，改為僅顯示命中率，例如快取:93%。因為 Claude Code 每送出一則訊息就會重新計時，加上閒置時不會重畫畫面，導致倒數幾乎永遠停在約 59 分鐘，所以不再顯示。先前在 0.31.4 加入的「快取已冷、下輪重寫 N token（AI 處理與計費的文字單位）」提示文字也一併從狀態列移除。

新功能

離線備援價目表補上新模型，過期時不再誤算為零元

當下載的價目表過期，你查看 gpt-6.1-sol 的 Codex 用量時，以前可能會看到 $0。

就像手上的商品價目表過期，店員改查備用表；以前備用表漏了新商品，價格被記成 0 元，現在備用表補上了這項商品。

內建的離線備援價目表正式補上 gpt-6.1-sol。以往只要下載的價目表過期，它的 Codex 用量就會被算成 $0；現在補齊清單後，這種情況下不會再被誤算。

English

FEATURE

Status Line Layout Streamlined for At-a-Glance Reset Times and Cache Hits

While pair programming in the terminal, the real-time information at the very bottom of the screen is now more concise.

Think of a car dashboard stripping away unnecessary gauges: where cluttered secondary dials once caused distraction, only key fuel and mileage remain to check status at a glance.

The first line now keeps only the project name and two quotas, while context window information moves to the end of the second line. The two quotas are displayed in a dimmer color, labeling the reset time before the remaining time, such as 22:00 (3h45m left). The cache section removes the progress bar and countdown, showing only the hit rate instead, such as cache:93%. Because Claude Code resets the timer every time a message is sent and does not redraw the screen when idle, the countdown almost permanently hovered around 59 minutes and is no longer shown. The hint text added in 0.31.4 noting that the cache has cooled down and N tokens will be rewritten next round has also been removed from the status line.

FEATURE

Offline Fallback Price List Adds New Model to Prevent Zero-Dollar Miscalculations Upon Expiration

When the downloaded price list expired and you checked Codex usage for gpt-6.

1-sol, you might have previously seen $0.

Picture a clerk consulting a backup catalog when the printed price list expires; where the backup sheet previously omitted new items and recorded their prices as $0, it now includes the missing listing.

The built-in offline fallback price list officially adds gpt-6.1-sol. Previously, whenever the downloaded price list expired, Codex usage for this model was calculated as $0; with the list completed, it will no longer be miscalculated under these conditions.
