Usage 0.34.14

發布日期：2026-11-07

繁體中文

新功能

Windows 工作列額度標籤顯示恢復倒數，滿額即時掌握剩餘時間

當你在 Windows 上專注編寫專案，把 AI 額度用到上限時，不必再反覆點開面板確認何時能繼續。以前系統匣選定的服務在 5 小時或本週額度達到 100% 時，工作列上的標籤只會停留在 100%。現在達到滿額後，標籤會改用滿額代表色直接顯示剩餘恢復時間（例如 Claude: 2h55m），與 macOS 選單列的顯示方式一致。

停車場門口的車位看板以前只亮著客滿紅燈，駕駛得搖下車窗詢問才知何時有空位；現在滿額時直接切換為預估等待時間，即使閘門關著也持續倒數。

在時間倒數期間，就算面板處於關閉狀態，標籤也會在每個輪詢週期照常更新。

問題修復

Antigravity 睡眠喚醒不再狂開登入頁，切換模型組也各自記錄通知

如果常讓 Mac 進入睡眠，或是經常在面板切換模型組，兩處惱人的誤判提示現在都不會再跳出。剛喚醒時網路常常尚未就緒，以前 Antigravity CLI（終端機指令列工具）更新授權令牌失敗就當成未登入，每次刷新都多開一個登入分頁。現在連不上 Google 登入伺服器時先略過 CLI；檢查失敗後等 30 分鐘再啟動，登入過期或 Wi-Fi 需先開網頁登入時也適用，額度卡則沿用上次的數字。切換模型組也不再共用狀態。以前從用完的 Gemini 切到 Argon 會誤發額度恢復，切回又通知已用完；現在 macOS 與 Windows 都各自記錄。

進出管制實驗室時，門禁系統以前在主機離線時會狂響補登警報，換用不同門禁卡也把舊紀錄拿來亂按鈴；現在離線時先安靜等待，不同清單也各自記錄。
新功能

報表補齊 Codex 歷史細項，八月以前對話紀錄重現卡片分布

翻閱用量報表追蹤歷史消耗時，八月以前的詳細分佈現在也能正常查閱。以前較舊的帳本只儲存每日總量，導致卡片與工具分佈只能從 2026-08-01 開始顯示，即使熱度圖有更早的紀錄也無法查看細項。現在這些日子會從 Codex 本機的對話資料庫補齊一次，按照日期、模型與專案進行整理。無法歸屬的 token（AI 處理與計費的文字單位）會直接顯示為「unknown」，不會任意猜成 Claude。補回的資料不含金額，統一計入「沒有價格資料」。

氣象觀測站補建歷史圖表時，以前老檔案只記下每日總雨量，分類圖只能從八月畫起；現在從儀器本機日誌單次補齊數據，無法辨識的數值直接記為未註明，絕不隨意猜成其他測站。
問題修復

上游檢查腳本不再把內部狀態欄位誤報為上游新欄位

平時透過本機腳本追蹤上游服務的變更時，欄位檢查的提示現在更乾淨。以前執行 scripts/check_upstream.py 檢查上游狀態時，usage 內部的 _rate_limits_session_id 狀態欄位，會被檢查工具誤當成上游服務新推出的欄位而跳出警示。現在不再將它誤報為上游新欄位。

圖書館採購組核對新書目錄時，以前常把館員寫在頁邊的借閱註記當成出版社推出的全新書目；現在不再把那筆註記當成新書目。

English

FEATURE

Windows taskbar quota label displays recovery countdown to track remaining time when full

When you are focused on writing a project on Windows and reach your AI quota limit, you no longer need to repeatedly open the panel to check when you can continue. Previously, when the tray's selected service hit 100% of its 5-hour or weekly quota, the label on the taskbar simply stayed at 100%. Now once the quota is reached, the label switches to the full-quota color to directly show the remaining recovery time (for example Claude: 2h55m), matching how the macOS menu bar displays it.

A parking lot display sign previously only stayed lit with a red full light, forcing drivers to roll down their windows to ask when a spot would open; now it switches directly to an estimated wait time when full, continuing to count down even while the gate remains closed.

During the countdown, the label still updates every polling cycle even when the panel is closed.

BUGFIX

Antigravity sleep wake no longer opens repeated sign-in pages, while switching model groups tracks notifications separately

If you frequently put your Mac to sleep or often switch model groups in the panel, two annoying false-positive prompts will no longer appear. Right after waking, the network is often not yet ready, and previously the Antigravity CLI (a terminal command-line tool) treated a failed token refresh as being not logged in, opening an extra sign-in tab on every refresh. Now it skips the CLI when unable to reach Google's sign-in server; after a failed check, it waits 30 minutes before launching again, which also applies to expired sign-ins or Wi-Fi requiring web login, while the quota card continues to use the previous numbers. Switching model groups also no longer shares state. Previously, switching from a depleted Gemini group to Argon would falsely notify that quota had recovered, and switching back would notify again that it was used up; now macOS and Windows each track them separately.

When accessing a restricted lab, the access control system previously blared re-registration alarms whenever the host was offline, and rang false bells with old records when switching access cards; now it waits quietly while offline, and records different lists separately.
FEATURE

Reports backfill Codex historical details to restore card distributions for conversations before August

When browsing usage reports to track historical consumption, detailed breakdowns prior to August can now also be viewed normally. Previously, older ledger days stored only daily totals, causing card and tool breakdowns to display only from 2026-08-01, even though the heatmap had earlier records. Now these days are backfilled once from Codex's local thread database, organized by date, model, and project. Unattributable tokens (the text units AI processes and bills for) are displayed directly as "unknown" rather than arbitrarily guessed as Claude. Backfilled data carries no monetary cost and is uniformly counted under "no pricing data".

Think of a weather station reconstructing historical charts: old archives previously only recorded daily total rainfall, leaving breakdown charts able to start only from August; now data is backfilled once from local instrument logs, with unidentifiable readings directly recorded as unspecified and never casually guessed as other stations.
BUGFIX

Upstream check script no longer falsely reports internal status field as new upstream field

When tracking upstream service changes through local scripts, field check alerts are now cleaner. Previously, when running scripts/check_upstream.py to inspect upstream status, usage's internal _rate_limits_session_id status field was mistaken by the check tool for a newly introduced upstream field, triggering a warning. It is now no longer falsely reported as a new upstream field.

Picture a library acquisitions team checking a new book catalog: previously, borrowing notes scribbled in page margins by staff were often mistaken for brand-new titles released by publishers; now that annotation is no longer treated as a new entry.
