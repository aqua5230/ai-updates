Usage 0.30.22

發布日期：2026-09-25

繁體中文

問題修復

Claude Code 新增外掛，對話中直接查額度

你跟 Claude Code 對話到一半想確認還能問幾題，不必再特地跳出視窗開終端機查帳。

像在辦公桌邊裝了計量表，瞄一眼就知道剩餘額度，以前得特地跑去機房看總表，現在坐在位子上就能掌握。

只要先後安裝市集與外掛，就能依序在 Claude Code 對話介面輸入以下指令查詢：

/plugin marketplace add aqua5230/usage
/plugin install usage@usage
/usage:quota

執行後會列出 Claude Code 與 Codex 的 5 小時及每週額度（quota，模型使用上限）用了多少與何時重置。

外掛只呼叫 usage-cli status --json，未安裝時會透過 uvx 執行。指令使用 usage-cli 是為避免與其他工具同名衝突，而且只有你主動輸入才會執行，Claude 絕不會在背景自行觸發。

新功能

狀態查詢回傳倒數秒數，免去手動換算時間

打算寫腳本抓取帳號狀態時，串接程式再也不必為了計算剩餘時間而大費周章。

好比公車站牌直接標示進站倒數三分鐘，以前只印發車時刻讓乘客自己看手錶心算，現在抬頭就能直接看懂還要等多久。

現在執行 usage status --json 時，輸出格式直接替你算好倒數時間。每個統計視窗新增了 resets_in_seconds 欄位回傳額度重置倒數，每個代理人（agent，負責執行特定任務的 AI 程式）也多了 age_seconds 記錄已運作秒數。兩項數值都以報表產生的 generated_at 時間點為準計算完成，接收資料的下游工具不用再自己拿兩個時間戳記相減。

新功能

精簡模式移除過度施壓指令，交接語氣更自然

使用精簡模式讓 AI 長話短說時，換班交接的開場訊息不再生硬冰冷。

像指導實習生寫工作日誌，以前規定字字精簡且嚴禁任何問候，導致交班留言生硬冰冷，現在拿掉死板禁令，既維持精準也能在交接時保有溫暖問候。

系統在精簡模式（terse mode，指示 AI 保持回答簡短的設定）中移除了兩行提示詞。首先是刪去「不准淡忘」的嚴格施壓要求，因為每則訊息發送時的提醒機制本來就能穩定簡潔語氣。其次是拿掉「不要為了親切多寫」的禁令，避免它與每位使用者必讀的進度交接摘要互相衝突。

新功能

HTML 報表卡片等高對齊，手機排版補上邊界留白

打開瀏覽器或手機查看用量報表時，畫面中的統計數據不再排列得歪歪斜斜。

恰似將畫廊展覽牆上的說明牌統一裁成相同尺寸，以前字數多的卡牌排版混亂且緊貼外框，現在將補充細節縮小分行並留出邊距，整面展示牆看起來整齊一致。

在 HTML 報表裡，四張關鍵指標卡的高度現在保持完全一致。記錄 token（AI 處理與計費的文字單位）消耗的卡片大字只放約略值，精確數值與漲跌幅度則改以小字分行顯示，解決了過去卡片文字換行不一的問題。手機版各區塊也在兩側補上 16px 的留白，內容不再緊貼著卡片邊界。

English

FEATURE

Claude Code Gets a Plugin for Checking Quotas Right in the Conversation

When you're mid-conversation with Claude Code and want to check how many questions you have left, you no longer need to jump out of the window and open a terminal to check your account.

It's like having a meter installed right at your desk: one glance tells you the remaining quota. Before, you had to make a special trip to the server room to read the master gauge; now you can keep track without leaving your seat.

Just install the marketplace and the plugin in order, then enter the following commands in the Claude Code conversation interface:

/plugin marketplace add aqua5230/usage
/plugin install usage@usage
/usage:quota

After running, it lists how much of the 5-hour and weekly quotas (the model usage limits) for Claude Code and Codex have been used and when they reset.

The plugin only calls usage-cli status --json, and runs it via uvx if it isn't installed. The command uses usage-cli to avoid name clashes with other tools, and it only runs when you type it yourself—Claude will never trigger it on its own in the background.

FEATURE

Status Queries Return Countdown Seconds, No More Manual Time Conversion

When you plan to write a script to pull account status, the integrating program no longer has to go to great lengths just to calculate remaining time.

Think of a bus stop sign that directly shows "arriving in 3 minutes": before, it only printed departure times and passengers had to check their watches and do the math; now you just look up and immediately see how long the wait is.

Now when you run usage status --json, the output format calculates the countdown for you. Each statistics window gains a resets_in_seconds field returning the countdown until the quota resets, and each agent (an AI program responsible for a specific task) also gets an age_seconds field recording how many seconds it has been running. Both values are computed against the report's generated_at timestamp, so downstream tools receiving the data no longer need to subtract two timestamps themselves.

FEATURE

Terse Mode Drops Overly Pressuring Instructions, Making Handoffs Sound More Natural

When using terse mode to make the AI keep things short, the shift-handoff opening message no longer sounds stiff and cold.

Picture coaching an intern on writing a work log: the old rules demanded every word be terse and strictly banned any greeting, which made handoff notes stiff and cold. Now the rigid bans are removed, keeping things precise while still allowing a warm greeting at handoff.

The system removed two lines from the prompt in terse mode (the setting that tells the AI to keep answers short). First, it deleted the strict pressuring demand to "never let it fade," because the reminder mechanism attached to every message already keeps the tone consistently concise. Second, it removed the ban on "writing extra just to be friendly," to avoid conflicting with the progress handoff summary that every user must read.

FEATURE

HTML Report Cards Aligned to Equal Height, Mobile Layout Gains Edge Padding

When you open the usage report in a browser or on your phone, the statistics on screen no longer line up crookedly.

Like trimming every caption plaque on a gallery wall to the same size: before, cards with more text were laid out messily and pressed against the frame; now the supplementary details are shrunk onto separate lines with margins added, and the whole display wall looks neat and consistent.

In the HTML report, the four key metric cards now all keep exactly the same height. The card tracking token (the unit of text the AI processes and bills by) consumption shows only an approximate value in large type, while the exact figure and the change move to smaller text on separate lines, fixing the old problem of inconsistent line wrapping across cards. On mobile, each section also gains 16px of padding on both sides, so content no longer hugs the card edges.
