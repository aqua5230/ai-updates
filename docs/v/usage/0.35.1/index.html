Usage 0.35.1

發布日期：2026-11-23

繁體中文

新功能

回報問題會自動填好環境資訊

用 usage 碰到錯誤想找開發者反映，卻懶得自己查電腦規格嗎？macOS 的面板選單與 Windows 的系統匣選單現在都加入了「回報問題」（英文介面為 Report an Issue）。 點下去會在程式碼平台 GitHub 開啟一份新問題單，裡頭已套好錯誤回報範本的各個段落並填妥環境區塊。區塊包含 usage 版本、安裝方式、作業系統、CPU、Python、語言、面板主題，以及顯示哪些 AI 卡片，且不含任何檔案路徑、使用者名稱、額度數字或紀錄檔。

如同把家電送回原廠維修，以前得自己抄下機型與序號填表，現在櫃檯先幫你印好規格欄，你只需寫上哪裡故障。
新功能

絨毛小夥伴多了六隻並輪流登場

打開面板看各家 AI 額度的空檔，卡片底下那排隊伍又添了新面孔。這次先多了刺蝟「Prickle」與水獺「Shelly」使總數來到 13 隻。接著再加入蝸牛「Swirl」、螃蟹「Pinch」、河豚「Puff」和鳳頭鸚鵡「Tuft」，現在一共有 17 隻。每隻都一樣有五種姿勢，每次面板載入時誰先上場都是隨機決定的。 雖然數量變多，卡片下方的這一排不會因此擠得更近。站不下的小夥伴會先在畫面外等待，每隔幾分鐘，排在最後的那隻會跳出去，等最久的那隻跳進來輪流上場。

就像長椅寬度固定，來聚會的朋友變多了也不用硬擠，坐不下的先在旁邊等，時間到再讓等最久的補上空位。
新功能

歷史紀錄更省記憶體並放大檔案快取上限

長期累積大量 Codex 對話檔後，usage 現在會把相同資料合併共用，重新整理也免去反覆重算的功夫。從磁碟快取（把讀過的資料暫存起來直接用）載入相同數值時，現在只保留一份共用。拿真實資料重新整理三次後，記憶體用量約從 174 MiB 降到 162 MiB。 每個檔案快取的上限也從 4,096 提高到 16,384。Codex 紀錄檔數量超過舊上限時，不會每次重新整理都重新解析其中一部分。

跟把辦公室裡一模一樣的表單改成只留一份共用、再把檔案櫃換成四倍大一樣，空間既省下來，舊資料也不必一直被擠出去重抄。
新功能

IDE 與 Cowork 用 Claude 也能更新額度

明明已經切進編輯器繼續跟 AI 對話，選單列上的數字卻好幾個小時一動也不動，也沒半點提醒。過去 usage 只從終端機底下的狀態列讀取 Claude 額度。但是 IDE（寫程式用的編輯器）外掛與 Cowork 不會畫出狀態列，選單列就只能停在最後一次終端機工作階段的數字。 現在只要狀態列超過 15 分鐘沒回報新額度，而 Claude Code 自己的快取有同帳號的較新數字，usage 就會改顯示快取數值並標出資料是多久前的。這份數字可能會落後 20 到 30 分鐘。 切換帳號後也不再顯示另一個帳號的額度。額度通知改按帳號分開記錄，從額度用完的帳號切到另一個帳號時，usage 不會把它當成額度重置。

過去只盯著玄關溫度計，沒更新就一直停在舊度數；現在它久沒動會改看氣象站紀錄並標出時間，不同房間的數值也分開記不再混在一起。

English

FEATURE

Reporting an issue now prefills your environment info

Run into a bug in usage and want to report it to the developers without looking up your computer specs yourself? Both the macOS panel menu and the Windows tray menu now include "Report an Issue". Clicking it opens a new issue on GitHub with the bug report template's sections and a prefilled Environment block. The block includes your usage version, install method, OS, CPU, Python, language, panel theme, and which AI cards are shown, and it contains no file paths, usernames, quota numbers, or logs.

Think of bringing an appliance back to the manufacturer for repair: before, you had to copy down the model and serial number onto the form yourself, whereas now the counter prints the specs section for you and you only need to write what broke.
FEATURE

Six more Plush Pals join and take turns onstage

While you open the panel to check your AI quotas, the lineup under the cards has gained new faces. First came Prickle the hedgehog and Shelly the otter, bringing the total to 13. Then Swirl the snail, Pinch the crab, Puff the pufferfish, and Tuft the cockatoo joined in, making 17 in all. Each one still has five poses, and who starts onstage is chosen at random each time the panel loads. Even with more pals, the row under the cards does not squeeze any closer together. Pals that do not fit wait offstage, and every few minutes, the last one in line hops out while the one that has waited longest hops in to take its turn.

Picture a bench of fixed width: when more friends show up to the gathering, nobody has to squeeze in—those who cannot fit wait on the side, and when time is up, the friend who has waited longest steps into the open spot.
FEATURE

History uses less memory with a larger file cache limit

When large amounts of Codex conversation files build up over time, usage now merges and shares identical data, saving refreshes from repeating the work. When loading equal values from disk caches, it now keeps only one shared copy. After refreshing three times on real data, memory usage dropped from about 174 MiB to 162 MiB. The per-file cache limit also rose from 4,096 to 16,384. When the number of Codex log files exceeds the old limit, usage no longer reparses part of them on every refresh.

An office keeps one shared copy of identical forms and swaps in a filing cabinet four times the size, saving space while keeping old records from getting pushed out and recopied.
FEATURE

Claude quota updates in IDEs and Cowork too

You switch into your editor and keep chatting with AI, yet the number in the menu bar sits unchanged for hours with no warning at all. Previously, usage read Claude quota only from the status line at the bottom of the terminal. However, IDE (code editor) extensions and Cowork never draw a status line, so the menu bar stayed stuck on the number from your last terminal session. Now, whenever the status line has reported no new quota for more than 15 minutes and Claude Code's own cache has a newer number for the same account, usage shows the cached value instead and notes how old the data is. This figure can lag by 20 to 30 minutes. Quota from another account is also no longer shown after you switch accounts. Quota notifications are now tracked per account, so switching from an exhausted account to another one no longer reads as a quota reset.

Before, you only watched the entryway thermometer and stayed stuck on an old reading when it stopped updating; now, if it sits still too long, you check the weather station record with its timestamp instead, and readings from different rooms are logged separately so they never mix.
