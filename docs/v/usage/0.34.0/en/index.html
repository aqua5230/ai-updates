Usage 0.34.0

Released: 2026-10-21

Release notes

FEATURE

Muse Code gets its own quota card

Anyone juggling several AI coding tools dreads finding out mid-task that one of them has run dry. Say you just used Muse to revise a report and wonder whether there is room for another pass: open the usage panel and the Muse quota card is there, with the 5-hour Session (the usage window counted from when you start) and the weekly quota, reset countdowns, and support in all 15 quota themes. The menu bar gains a Muse item and a hide toggle, plus the same near-limit, used-up and restored notifications as Antigravity. Muse keeps no quota file on your machine, so usage asks Muse directly with one small background request, saving no conversation log and running from an empty folder.

Phoning the bank for your balance costs a little each time, so you would not call every minute: it asks once when there is no reading yet, then only after the reading is over 30 minutes old and you have used Muse since.

Each check uses a little of your Muse quota, and a failed check waits for new Muse activity before retrying. Hiding the Muse card stops the checks, and the card hides itself when Muse is not installed.

FEATURE

Muse quota appears in the side pane, terminal dashboard and Windows tray

You are halfway through work in Claude Code and want a quick look at how much Muse quota is left, without switching back to the main usage panel. The Claude Code side pane, the usage status --json command, the multi-agent terminal dashboard and Quota-Aware Mode now all list Muse. The Windows tray does too, with Muse in its card, hover tooltip, hide toggle and notifications.

Muse's numbers used to sit only in the flagship store; now every branch window displays them, but the branches only show the last batch the flagship sent over and never restock on their own.

These places read only the last saved reading and never start a Muse check themselves, so looking in more places does not spend any extra Muse quota.

FEATURE

Quota cards shrink when there are many, and the menu bar shows at most three tools

If you use several AI tools at once, too many quota cards no longer fit on a laptop screen. Now, once there are four or more quota cards, they all switch to a compact layout together: a smaller header, Session and weekly side by side, and shorter percent and reset text, with the Projects title shrinking to match. Three cards or fewer look the same as before. The menu bar at the top of the screen had the same crowding: with Claude Code, Codex, Antigravity, Grok and Muse all on, it got so wide it could slide behind the notch.

A subway platform sign only cycles through the next three trains; the menu bar used to cram in all five tools until the tail vanished behind the notch, and now it keeps the three with the highest Session usage, in the usual order.

Open the panel and every card is still listed.

FEATURE

Stale-data warnings are readable in two themes, and Windows remembers card order

A flashy theme can end up hiding the one warning you most need to see. In the Windows 95 theme, the red stale-data warning (a reminder that the numbers have not updated in a while) sat right on the blue title bar, and in Cloud Observation the pale amber one sat on sky-blue cards; both now have enough contrast. In World Cup 2026, the English MATCH STATS heading is no longer cut off by the buttons beside it. On Windows, the tray accepted a new card order only when it listed exactly the Claude, Codex and Antigravity cards.

Picture a cloakroom that only recognizes three ticket numbers, so hanging one extra Grok coat voids the whole row: once a Grok card was in the panel, your dragged order was not saved, and now Windows uses the same check as macOS so the order sticks.
BUGFIX

Auto-start 5-hour Session no longer fires your own hooks

If you have set up hooks (small programs that run automatically at certain moments), you may have been getting a pile of unexplained notifications or extra saved conversations. The cause: Auto-start 5-hour Session sends small background pings through claude -p and codex exec, and every ping fired every hook you had set up, such as SessionStart, UserPromptSubmit and Stop hooks, Codex's hooks.json, and the notify program in Codex's config.toml.

Imagine hiring a cleaner who sets off your doorbell, camera alerts and auto-recording every time they open the front door; now they use a side door that trips no sensors.

Claude Code pings now load a settings file with disableAllHooks turned on, and Codex pings turn off features.hooks and notify. Antigravity pings are unchanged.
