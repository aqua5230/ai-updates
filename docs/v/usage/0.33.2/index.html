Usage 0.33.2

發布日期：2026-10-08

繁體中文

新功能

特殊符號與中文資料夾，專案清單正確顯示原始名稱

當你的專案資料夾名稱包含點號、底線、中文或表情符號（emoji）時，打開 usage 就能一眼認出它是誰。

Claude Code 會把路徑裡的所有符號都換成減號 -。過去遇到這類專案，畫面往往只會顯示一長串編碼後的名稱，甚至直接顯示上一層資料夾的名字。若是路徑太長被 Claude Code 截短，對照也會直接失效。現在 usage 會拿編碼後的名稱回頭比對真實資料夾，就算長路徑被截短也能精準對上。

跟機場行李託運掛牌一樣，以前行李條碼若被縮寫成代號，地勤人員只能念出一整串編碼，現在系統會自動拿代號反查原始旅客姓名，把正確名牌亮出來。
新功能

額度感知模式智慧判定，只在用到的額度耗盡時提醒

當你在 Antigravity 裡耗盡了某個模型組的額度時，切換到 Claude 執行完全無關的工作不會再被無端打斷。

以前額度感知模式只要發現任一模型組用完，即使當前任務完全用不到它，Claude 也會先詢問你要不要等待。現在提醒訊息會明確說明每份額度與模型組各自獨立，只會在任務確實會動用到該額度時才發問。這項改動隨額度感知掛鉤（hook，事件發生時自動攔截並處理的小程式）升級至 1.1 版推出，電腦中已安裝的副本會在下次啟動應用程式時自動更新。

像在美食街各家櫃位點餐，以前只要有一家拉麵店賣光，不管你點的是漢堡還是飲料，店員都會跑來問你要不要等拉麵，現在各家櫃位分開叫號，只在你想買的餐點售完時才會確認。
新功能

側邊面板對話完成通知，開頭標註所屬專案名稱

當你桌面上一口氣開了好幾個視窗平行趕工時，螢幕角落跳出的提醒往往讓人摸不著頭緒。

側邊面板跳出的工作階段完成通知，現在開頭會直接標明專案名稱。以前通知只會顯示對話已經完成，在多工處理時根本分不清是哪一個視窗跑完；現在看一眼通知標題就能立刻知道是哪個專案搞定，切換視窗不再手忙腳亂。

就像快遞櫃發送取件通知，以前簡訊只寫『包裹已送達』讓人分不清寄來的是哪一件，現在開頭直接標明商品名稱，一眼就能確認哪批貨到手。

English

FEATURE

Project list correctly displays original names for folders with special symbols and Chinese characters

When your project folder name contains dots, underscores, Chinese characters, or emoji, you can instantly recognize it upon opening usage.

Claude Code replaces all symbols in a path with hyphens -. In the past, the screen often showed only a long encoded name or even the parent folder's name for such projects. If a path was too long and truncated by Claude Code, the matching broke completely. Now, usage compares the encoded name back against real folders, matching them accurately even if long paths get truncated.

Picture airport baggage tags: in the past, if a baggage barcode was abbreviated into a code, ground staff could only read out a long encoded string; now the system automatically cross-references the code to find the traveler's original name and display the correct luggage tag.
FEATURE

Quota-aware mode intelligently alerts only when the relevant quota is exhausted

When you exhaust a model group's quota in Antigravity, switching to Claude for completely unrelated tasks will no longer be interrupted unnecessarily.

Previously, whenever quota-aware mode detected that any model group was depleted, Claude would ask if you wanted to wait, even if the current task did not use it at all. Alert messages now clarify that each quota and model group operates independently, prompting you only when a task actually requires that quota. This update is released alongside version 1.1 of the quota-aware hook (a lightweight script triggered on specific events), and local installations will update automatically the next time the app starts.

Think of ordering food across different stalls in a food court: in the past, if a ramen stall ran out of food, the staff would ask whether you wanted to wait for ramen even if you ordered a burger or drink; now each stall calls numbers independently and only checks with you when the item you want is sold out.
FEATURE

Side panel completion notifications prefix the corresponding project name

When working across multiple open windows in parallel on your desktop, alerts popping up in the corner of your screen can easily be confusing.

Session completion notifications from the side panel now directly include the project name at the beginning. In the past, notifications only stated that a conversation had finished, making it difficult to tell which window completed during multitasking; now a single glance at the notification title tells you exactly which project is done, eliminating the hassle of switching between windows.

Like parcel locker pickup notifications: previously, SMS alerts only said "Package delivered," leaving you unsure which item had arrived; now the product name is clearly labeled at the beginning, letting you instantly confirm which package is ready.
