工程人才多 25 位，啟動角色少一步

網站缺前端、後台缺 API（讓軟體互相傳資料的介面）專長時，AI Talent Market 新增七組、共 25 個工程角色。角色涵蓋前端、後端、雲端維運、品質、AI、程式維護與應用程式開發；React、Next.js、SQL、Python、Docker、DevOps、Swift、Electron、重構、相依套件與提示詞工程也各有專家。既有的行銷包加入 SEO 角色，電商包加入付款整合角色；每位都有繁中、簡中、英文、日文、韓文人設。挑好角色後，卡片直接顯示「Launch」：未安裝才會先把一個 .md 檔寫進 ~/.claude/agents/，接著啟動；安裝失敗便停下並報錯，不會開空終端機。手動改過的角色仍可按「Restore」還原。像人才仲介先把專長排好，帶你選到人便直接牽線。

en

25 more engineering roles, with fewer steps to launch one

Need someone to build a page, design an API, or untangle a dependency? The AI Talent Market adds 25 engineering roles across seven new packs. They cover frontend, backend, cloud operations, quality, AI, code maintenance, and app development, with specialists in React, Next.js, SQL, Python, Docker, DevOps, Swift, Electron, refactoring, dependencies, and prompt engineering. Marketing also gains SEO, while ecommerce gains payment integration; every role comes with zh-TW, zh-CN, English, Japanese, and Korean personas. After choosing one, its card now says "Launch". If needed, it first writes one .md file to ~/.claude/agents/, then starts; a failed install stops and reports its error instead of opening an empty terminal. Hand-edited roles still keep their "Restore" button. Think of a recruiter who sorts the specialties first, then introduces you straight to the right person.

原始 CHANGELOG

Original changelog
**The AI Talent Market gained 25 engineering roles across seven new packs.** Frontend, backend, cloud ops, quality, AI, code maintenance and app development — React and Next.js specialists, API designers, SQL and Python pros, cloud architects, Docker and DevOps engineers, Swift and Electron experts, refactoring and dependency specialists, prompt engineers, and more. Every role ships the full zh-TW/zh-CN/en/ja/ko persona set. Two existing packs also absorbed a role each: SEO into marketing, payment integration into ecommerce.
**Hiring a role is now one click instead of two.** A role card used to show "Install", and only after that did it turn into "Launch" — but installing is an implementation detail (writing one `.md` file into `~/.claude/agents/`) that no one needed to see. Every card now shows "Launch" directly; if the role isn't installed yet, it gets installed first and then starts. A failed install stops there and reports the error rather than opening an empty terminal. The "Restore" button for hand-edited roles is unchanged.
