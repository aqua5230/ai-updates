en

The system instantly looks up prices for unknown models instead of pretending they're free

Run into a model it's never seen before, and it now looks up the real price right away instead of quietly showing $0.00. Previously, to save network calls, it cached the master price list for 7 days. This meant that newly-released AI models wouldn't have a price, causing them to temporarily show up as completely free ($0.00) for days. Now, the moment it spots an unknown model, it triggers a debounced (debouncing delays the action and groups repeated rapid requests into a single one) background refresh to fetch the latest prices, and it even carries a built-in fallback price specifically for Claude Sonnet 5 so it can estimate costs even when you are fully offline. It's like a cashier who used to give away items for free if the barcode wouldn't scan; now they immediately call the manager to check the price, and keep a backup clipboard for the most popular new item just in case the phone lines are down.
