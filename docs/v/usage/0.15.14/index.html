進入新資料夾時，Claude Code 額度不再閃退變空白

現在進新資料夾開新對話，不用再擔心配額畫面突然白掉嚇你一跳了。以前當你剛進入一個新資料夾、開啟全新的 Claude Code 對話時，第一次傳回來的狀態資料可能還來不及帶上額度數字。這時候，負責更新狀態的程式會傻傻地把這份「缺件」的資料直接蓋過去，把你畫面上本來好好的配額洗白，變成空蕩蕩的「--」和一句「請發送一句訊息以同步配額」，直到你講下一句話才會恢復。現在它變聰明了，如果發現新來的資料少了額度，它會把舊的、完好的額度數字保留下來，不會再隨便洗掉。就像是訂閱報紙，以前如果今天的報紙漏印了股市版，送報生會把你昨天保留的股市版也直接抽走丟掉，害你無圖可看；現在他懂得把舊的那張留著，直到拿到今天完整的報紙再幫你換掉。

en

Entering a new folder no longer briefly drops Claude Code quota to a blank screen

You can now enter a new folder and start a fresh session without worrying about your quota screen suddenly blanking out and startling you. Previously, when you jumped into a new folder and started a fresh Claude Code session, the very first status update might not have the quota numbers ready yet. The update hook used to blindly overwrite your app state with this incomplete data, wiping out your perfectly valid quota and forcing the menu bar to flash a blank "--" along with a "Send a message to sync" prompt until you spoke again. Now it's smarter: if the new payload arrives missing its quota, it carefully preserves your existing valid numbers instead of blindly wiping them. It's like a newspaper delivery; previously, if today's paper was missing the financial section due to a printing error, the delivery driver would also confiscate yesterday's financial page from your desk, leaving you with nothing. Now they let you keep the old page until a complete edition arrives.

原始 CHANGELOG

Original changelog
**Claude Code quota no longer briefly drops to "--" when entering a new folder**: on the first status-line refresh of a new session, the data Claude Code sends may not yet include rate limits; the hook used to overwrite the status file wholesale with this incomplete data, wiping out the previously valid quota and briefly showing "--" plus "send a message to sync your quota" until you sent another message. The hook now preserves the existing complete quota when the incoming data is incomplete.
