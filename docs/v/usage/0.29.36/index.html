Antigravity 額度會提醒，也能提早預警

把 Antigravity 額度想成油表：油用完才亮燈已經太晚，舊讀值更不能冒充油箱已空。 現在 agy_session 和 agy_weekly 兩列會發通知，不再因為漏列在通知允許清單而一路耗盡卻沒消息。它們也接上各自的用量追蹤器，會在額度歸零前顯示警告，而不是等到底才沉默。Antigravity 的資料來自經過快取（把查過的結果暫存起來直接用）的網路端點；快取過期時，快照會標成不可用，因而不會誤報額度已用完。預測採用快照自己的 fetched_at 時間，而非輪詢當下的時鐘，避免同一份每五分鐘才變動的資料被重複讀取後憑空算出趨勢。兩列使用 3600 秒視窗；原本十分鐘的預設視窗湊不齊 MIN_FORECAST_SAMPLES，等同根本無法預測。過期快照也會完全停用預測，與 agy_window_keeper 一致。

usage doctor 能抓出 Codex 歷史搬遷後的歸零

這像記帳員同時翻閱收據盒與總帳；收據盒空了、總帳卻有交易，便知道資料沒有真的消失。 usage doctor（用來檢查使用資料異常的指令）現在會檢查 Codex 的歷史搬遷。Codex 開始寫入 rollout_migration_state 這類資料表後，若搬遷完成、工作階段的 .jsonl 檔不再寫入，loaders/codex_loader.py 會毫無錯誤地回傳零 token（AI 計費與計量的文字單位）數。現在只要 .jsonl 在最近七天沒有任何項目，但 thread_history_1.sqlite 裡的 thread_turns 卻有同一時段資料，檢查便會警告你。這能指出原本悄悄把計數歸零的落差。

usage doctor 會核對 Claude 費用是否偏離官方數字

帳單對不上時，問題可能不在你，而在離線價目表已經過時。這次的 usage doctor 像把兩把尺靠在同一塊木板上，讀數差距超過門檻就亮起警示燈。 它會把 usage-status.json 的 cost.total_cost_usd 與 usage 自行算出的金額相比。差距同時超過 20% 與 $1 時便會警告。撰寫這項功能的那台機器上，兩者相差 46.4%，原因是價目表把 claude-opus-5 標成真實費率的一半。這正是離線備援價目表可能掩蓋的價格漂移。

WIN95 與 Newspaper 的專案用量卡不再截掉資料列

Antigravity quota now notifies and warns ahead

Think of Antigravity quota as a fuel gauge: a light that comes on after the tank is empty is too late, and an old reading must not pretend the tank is empty. The agy_session and agy_weekly rows now send notifications instead of being omitted from the notification allow-list and running down silently. Each row also has its own usage tracker, so it can warn before quota reaches zero rather than stay quiet until then. Antigravity data comes from a network endpoint behind a local cache, which stores a previously fetched result for reuse. When that cache is stale, its snapshot is marked unavailable, so it cannot announce that quota has run out. Forecasting uses the snapshot's fetched_at time instead of the polling clock, preventing repeated reads of a payload that changes only every five minutes from inventing a trend. Both rows use a 3600-second window because the default ten-minute window cannot gather MIN_FORECAST_SAMPLES. A stale snapshot also suppresses forecasting, matching agy_window_keeper.

usage doctor catches Codex history migrations that zero counts

It is like an accountant opening both the receipt box and the ledger: if the box is empty but the ledger has transactions, the records have not truly vanished. usage doctor, a command that checks for problems in usage data, now looks for a Codex history migration. After Codex began writing tables such as rollout_migration_state, a completed migration could stop the session .jsonl files from being written while loaders/codex_loader.py silently returned zero token counts. It now warns when .jsonl files contain no entry from the last seven days while thread_history_1.sqlite has thread_turns from that same window. That exposes a mismatch that used to zero counts without an error.

usage doctor compares Claude costs with the official figure

When a bill does not match, the problem may be an outdated offline price table rather than you. Here usage doctor is like placing two rulers against the same board and lighting a warning when their readings exceed a threshold. It compares cost.total_cost_usd in usage-status.json with the amount usage calculates itself, then warns when the gap is both over 20% and over $1. On the machine where this feature was written, the figures differed by 46.4% because the price table listed claude-opus-5 at half its real rate. That is the kind of price drift an offline fallback table can hide.

WIN95 and Newspaper project cards no longer clip rows

Project usage cards on the WIN95 and Newspaper panels no longer show only their title bar while clipping the rows below. To measure natural height, a panel temporarily releases the height: 100% chain to auto. Yet both panels write the project card as flex: 1, whose flex basis is zero, while the card's overflow: hidden, needed by retro window chrome, suppresses the automatic content-based minimum size that would keep it open. During measurement the card therefore collapsed to its title bar: WIN95 reported 877 pixels and Newspaper 876, versus 923 for structurally identical Classic. It is like loosening a stretched elastic before measuring cloth, so the whole garment is not measured too short. Measurement now temporarily pins stretching children to flex: 0 0 auto and restores them afterward, leaving each panel's visual design unchanged.

Eight modules move into packages, clearing repository root

The repository root has eight fewer loose modules, while behavior stays unchanged. burn_rate, usage_rate, window_keeper, and agy_window_keeper moved into quota/; time_utils, usage_logging, usage_lang, and usage_dir_sweeper moved into usage_common/. It is like putting eight loose parts from a workbench into two clearly labeled drawers: the parts are unchanged, but no longer scattered across the surface. The shared utility package is called usage_common, not common, because the uvx usage-cli entry point installs top-level packages into shared site-packages, where common can easily collide with another package. No compatibility shims remain: every repository import was updated in one pass, pyproject.toml dropped eight py-modules entries and added the two packages, and setup_app.py followed.

Antigravity の利用枠が通知し、事前にも警告する

Antigravity の利用枠は燃料計のようなものだ。燃料が尽きてからランプが点いても遅く、古い読み取り値が空の燃料タンクを名乗ってはいけない。 agy_session と agy_weekly の行は、通知の許可リストから漏れて黙ったまま使い切ることがなくなり、通知を出す。各行は専用の使用量トラッカーも持つため、利用枠がゼロになる前に警告する。Antigravity のデータは、取得済みの結果を一時保存して再利用するキャッシュを挟んだネットワーク端点から来る。キャッシュが古いときはスナップショットを利用不可とし、利用枠切れを誤って知らせない。予測はポーリング時の時計ではなく、スナップショット自身の fetched_at を使う。五分ごとにしか変わらない同一データを繰り返し読んで、存在しない傾きを作らないためである。両行は 3600 秒の窓を使う。既定の十分の窓では MIN_FORECAST_SAMPLES が集まらず、予測できないからである。古いスナップショットでは予測を完全に止め、agy_window_keeper とそろえる。

usage doctor が Codex 履歴移行による計数ゼロを見つける

これは帳簿係が領収書箱と元帳を同時に開くようなものだ。箱が空でも元帳に取引があれば、記録が本当に消えたわけではない。 使用データの異常を調べるコマンドである usage doctor は、Codex の履歴移行を検査するようになった。Codex が rollout_migration_state のような表を書き始めた後、移行が完了してセッションの .jsonl ファイルへの書き込みが止まると、loaders/codex_loader.py はエラーなしに token 数をゼロで返していた。今は .jsonl に直近七日間の項目がなく、thread_history_1.sqlite の thread_turns には同じ期間のデータがある場合、警告を出す。これにより、以前は黙って計数をゼロにした食い違いが分かる。

usage doctor が Claude の費用を公式額と照合する

請求額が合わないとき、原因はあなたではなく、古くなったオフライン価格表かもしれない。ここでの usage doctor は、同じ板に二本の物差しを当て、目盛りの差がしきい値を超えると警告灯を点ける役である。 usage-status.json の cost.total_cost_usd と usage 自身が計算した金額を比べ、差が 20% を超え、かつ $1 も超えると警告する。この機能を書いた機械では両者の差は 46.4% だった。価格表が claude-opus-5 を実際の料金の半分としていたためである。これはオフラインのフォールバック価格表が隠しうる料金のずれである。

WIN95 と Newspaper のプロジェクト使用量カードが行を切らない

WIN95 と Newspaper のパネルにあるプロジェクト使用量カードは、タイトル行だけを残して下の行を切り取らなくなった。パネルが自然な高さを測る際、height: 100% の連鎖を一時的に auto にする。しかし両パネルのプロジェクトカードは flex: 1 であり、そのフレックス基準はゼロである。さらにレトロな窓枠に必要なカード自身の overflow: hidden が、内容で開くための自動最小サイズを抑える。測定中にカードはタイトル行まで縮み、WIN95 は 877 ピクセル、Newspaper は 876 ピクセルとなった。構造が同じ Classic は 923 ピクセルである。布を測る前に引き伸ばされたゴムを緩め、服全体を短く測らないようにするのに似ている。 今は測定中だけ伸びる子要素を flex: 0 0 auto に固定し、その後で戻すため、パネルの見た目は変わらない。

八つのモジュールをパッケージへ移し、リポジトリ直下を整理した

リポジトリ直下から散在していた八つのモジュールが減ったが、動作は変わらない。burn_rate、usage_rate、window_keeper、agy_window_keeper は quota/ へ移し、time_utils、usage_logging、usage_lang、usage_dir_sweeper は usage_common/ へ移した。作業台に散った八つの部品を、表示の明確な二つの引き出しへ入れるようなものだ。部品は同じでも、台の上に散らばらない。 共用ユーティリティパッケージを common ではなく usage_common としたのは、uvx usage-cli の入口が最上位パッケージを共用の site-packages に入れ、common は別のパッケージと衝突しやすいためである。互換用の代替物は残していない。リポジトリ中の全 import を一度に更新し、pyproject.toml は八つの py-modules 項目を削除して二つのパッケージを追加し、setup_app.py も更新した。

Antigravity 할당량이 알림을 보내고 미리 경고한다

Antigravity 할당량은 연료 게이지와 같다. 연료가 바닥난 뒤에 불이 켜지면 늦고, 오래된 수치가 빈 연료통인 척해서도 안 된다. agy_session과 agy_weekly 행은 이제 알림 허용 목록에서 빠져 소리 없이 바닥까지 내려가지 않고 알림을 보낸다. 각 행에는 자체 사용량 추적기도 붙어 할당량이 0이 되기 전에 경고한다. Antigravity 데이터는 이미 가져온 결과를 잠시 저장해 다시 쓰는 캐시를 거친 네트워크 끝점에서 온다. 캐시가 오래되면 스냅샷을 사용할 수 없다고 표시하므로 할당량이 소진됐다고 잘못 알리지 않는다. 예측은 폴링할 때의 시계 대신 스냅샷 자체의 fetched_at 시간을 쓴다. 오 분마다만 바뀌는 같은 데이터를 반복해서 읽고 없는 추세를 만들어 내지 않기 위해서다. 두 행은 3600초 창을 쓴다. 기본 십 분 창으로는 MIN_FORECAST_SAMPLES를 모을 수 없어 예측할 수 없기 때문이다. 오래된 스냅샷은 예측도 완전히 막으며 agy_window_keeper와 맞춘다.

usage doctor가 Codex 기록 이전으로 인한 집계 0을 찾아낸다

장부 담당자가 영수증 상자와 원장을 함께 펼쳐 보는 것과 같다. 상자는 비었는데 원장에 거래가 있으면 기록이 정말 사라진 것은 아니다. 사용 데이터 이상을 확인하는 명령인 usage doctor가 이제 Codex 기록 이전을 검사한다. Codex가 rollout_migration_state 같은 표를 쓰기 시작한 뒤 이전이 끝나고 세션 .jsonl 파일 작성을 멈추면, loaders/codex_loader.py는 오류 없이 token 수를 0으로 돌려주고 있었다. 이제 .jsonl에 최근 칠 일의 항목이 없는데 thread_history_1.sqlite의 thread_turns에는 같은 기간 데이터가 있으면 경고한다. 이로써 예전에는 조용히 집계를 0으로 만들던 불일치를 알 수 있다.

usage doctor가 Claude 비용을 공식 금액과 대조한다

청구 금액이 맞지 않을 때 원인은 당신이 아니라 오래된 오프라인 가격표일 수 있다. 여기서 usage doctor는 같은 판자에 자 두 개를 대고 눈금 차이가 기준을 넘으면 경고등을 켜는 역할이다. usage-status.json의 cost.total_cost_usd와 usage가 직접 계산한 금액을 비교하고, 차이가 20%를 넘으면서 $1도 넘으면 경고한다. 이 기능을 작성한 기기에서는 두 수치가 46.4% 차이 났다. 가격표가 claude-opus-5를 실제 요금의 절반으로 적었기 때문이다. 이는 오프라인 대체 가격표가 숨길 수 있는 가격 변동이다.

WIN95와 Newspaper 프로젝트 사용량 카드가 행을 자르지 않는다

WIN95와 Newspaper 패널의 프로젝트 사용량 카드는 이제 제목 줄만 남기고 아래 데이터 행을 잘라 내지 않는다. 패널이 자연 높이를 잴 때는 height: 100% 연결을 잠시 auto로 푼다. 그러나 두 패널의 프로젝트 카드는 flex: 1로 쓰였고 그 플렉스 기준은 0이다. 복고 창 테두리에 필요한 카드 자체의 overflow: hidden은 내용을 바탕으로 카드를 열어 두는 자동 최소 크기도 막는다. 그래서 측정 중 카드는 제목 줄까지 줄어들었고 WIN95는 877픽셀, Newspaper는 876픽셀을 보고했다. 구조가 같은 Classic은 923픽셀이었다. 천을 재기 전에 팽팽한 고무줄을 풀어 옷 전체를 짧게 재지 않는 것과 같다. 이제 측정할 때만 늘어나는 자식 요소를 flex: 0 0 auto로 고정하고 끝나면 되돌리므로 패널의 시각 디자인은 바뀌지 않는다.

여덟 모듈을 패키지로 옮겨 저장소 루트를 정리했다

저장소 루트에 흩어져 있던 모듈이 여덟 개 줄었지만 동작은 바뀌지 않는다. burn_rate, usage_rate, window_keeper, agy_window_keeper는 quota/로 옮겼고 time_utils, usage_logging, usage_lang, usage_dir_sweeper는 usage_common/으로 옮겼다. 작업대에 흩어진 여덟 부품을 이름표가 분명한 두 서랍에 넣는 것과 같다. 부품은 그대로지만 더는 작업대에 흩어지지 않는다. 공용 도구 패키지 이름은 common이 아니라 usage_common이다. uvx usage-cli 진입점이 최상위 패키지를 함께 쓰는 site-packages에 설치하고, common은 다른 패키지와 이름이 부딪히기 쉽기 때문이다. 호환용 연결 장치는 남기지 않았다. 저장소의 모든 import를 한 번에 고쳤고, pyproject.toml에서 여덟 py-modules 항목을 빼고 두 패키지를 추가했으며 setup_app.py도 바꿨다.

Original changelog
**Antigravity quota now raises notifications, the way Claude Code and Codex already did.** The `agy_session` and `agy_weekly` channels were missing from the notification allow-list, so the two Antigravity rows could run to the floor without ever saying so. Antigravity quota is the one source that comes from a network endpoint behind a local cache rather than a file on disk, so `QuotaRowState.available` is hard-coded to `True`; a stale snapshot now passes `available=False` instead, so an expired cache can no longer announce that the quota has run out.
**The Antigravity rows now warn before the quota is gone, not after.** They had never been wired to the burn-rate forecast, so their `warning` flag was permanently `False` — Claude and Codex warned ahead of a reset and Antigravity stayed silent until it hit the floor. Both rows now register their own tracker. Samples are timestamped with the snapshot's own `fetched_at` rather than the wall clock, because the Antigravity snapshot only changes every five minutes and polling would otherwise read the same payload again and invent a slope out of it. Both rows use a 3600-second window: at one sample per five minutes the default ten-minute window never collects `MIN_FORECAST_SAMPLES`, which is the same as not forecasting at all. A stale snapshot suppresses the forecast entirely, matching what `agy_window_keeper` already does.
Original changelog
**`usage doctor` now catches a Codex history migration that would silently zero the token counts.** Codex has begun writing tables such as `rollout_migration_state`, and if that migration lands and the `.jsonl` files stop being written, `loaders/codex_loader.py` returns zero without an error anywhere. The check warns when the session `.jsonl` files hold no entry from the last seven days while `thread_history_1.sqlite` does hold `thread_turns` from that window.
Original changelog
**`usage doctor` now reconciles its own Claude cost against the official one.** It compares `cost.total_cost_usd` from `usage-status.json` with the figure usage calculates itself and warns when they differ by more than 20% and more than $1. On the machine this was written on they differed by 46.4%, because the price table listed `claude-opus-5` at half its real rate — exactly the kind of drift the offline fallback table is known to hide.
Original changelog
**The project usage card no longer clips its rows on the WIN95 and Newspaper panels.** A panel measures its own natural height by releasing the whole `height: 100%` chain to `auto`. Both panels write their project card as `flex: 1`, which means a flex basis of zero, and the card's own `overflow: hidden` — the retro window chrome depends on it — suppresses the automatic content-based minimum size that would otherwise hold the card open. The card therefore collapsed to its title bar during the measurement, and the reported height was short by exactly the project rows: 877 pixels for WIN95 and 876 for Newspaper against 923 for the structurally identical Classic. The measurement now pins such stretching children to `flex: 0 0 auto` while it measures and restores them afterwards, so no panel's visual design changes.
Original changelog
**Eight more modules moved out of the repository root.** `quota/` took `burn_rate`, `usage_rate`, `window_keeper`, and `agy_window_keeper`; `usage_common/` took `time_utils`, `usage_logging`, `usage_lang`, and `usage_dir_sweeper`. The shared-utility package is named `usage_common` rather than `common` because the `uvx usage-cli` entry point installs top-level packages into a shared `site-packages`, where `common` is about the most collision-prone name available. No compatibility shims were left behind — every import in the repository was updated in one pass, `pyproject.toml` dropped the eight `py-modules` entries and added the two packages, and `setup_app.py` followed. Behavior is unchanged.
