Token Saver 簡短回覆兼顧好懂，技術術語加註白話並提示下一步

像主管交代交接事項：話要精練且說白話，遇到行話加句白話註釋，結尾交代成果與下一步，並換掉舊指引便條。 Token Saver 讓簡短回覆兼顧好懂。模組 usage_terse_mode.py 的 _DEFAULT_INSTRUCTION 將白話風格與精簡並列，規定不可避免的技術術語加一次性白話註釋，並要求回覆以結果與下一步收尾；usage_terse_reminder.py 的 _DEFAULT_REMINDER 也強化此規則。installer/session_hooks.py 提高 TERSE_HOOK_VERSION，使自我修復函式 _self_heal_terse_mode() 主動替換既有 sidecar（隨附設定檔），不再停留在舊措辭。

Token Saver 指引自我一致，放行問候表情並依語言載入提示

Token Saver 提示指引消除矛盾，並自動以在地語言開啟。模組 usage_terse_mode.py 的 _DEFAULT_INSTRUCTION 允許開頭問候 emoji 與單行工具意圖，但仍排除在回覆正文之外。在 installer/session_hooks.py 中，_write_terse_sidecar() 將 detect_lang() 記錄於 lang，兩組 hook（事件發生時觸發的小程式）腳本內的 _read_sidecar() 與 _detect_lang() 會在環境變數覆蓋後讀取。未設語言變數的工作階段不再預設載入較長英文提示詞；若 sidecar 隨附檔遺失或損毀依然安全備援至英文。宛如多語接待櫃台：服務員可開頭致意並亮出名牌，正文維持精練，依訪客母語遞上簡章而非預設長篇英文，簡章遺失時以英語備援。

既有提醒掛鉤支援版本比對，過期腳本主動換新不留舊版

升級 usage 後，既有的 Token Saver 提醒掛鉤（hook，事件發生時觸發的小程式）現在會自動同步最新版。過去 installer/session_hooks.py 裡的自我修復函式 _self_heal_terse_reminder() 僅在腳本或註冊遺失時重新補上，已安裝的舊版腳本則原樣保留。現在系統透過 TERSE_REMINDER_HOOK_VERSION 與 _installed_terse_reminder_version() 比對版號並主動替換過期副本，記錄 update_terse_reminder_hook 供診斷。恰似大樓巡檢廣播設備：以前檢查員只在設備遺失時才補裝，裝好的舊款從不更換；現在會核對型號主動換新，並在檢修日誌登記換裝明細以供備查。

en

Token Saver keeps short replies plain and clear with term glosses and next steps

Like a manager briefing a team handoff: keeping updates brief while speaking plain language, adding a quick plain-words gloss whenever technical jargon is unavoidable, closing with the result and next action, and immediately swapping out obsolete guidelines. Token Saver now keeps concise replies easy to understand. In usage_terse_mode.py, _DEFAULT_INSTRUCTION pairs plain language directly alongside brevity, adds a one-time explanation for unavoidable technical terms, and instructs responses to conclude with the concrete result and next step; usage_terse_reminder.py's _DEFAULT_REMINDER reinforces this exact requirement. Furthermore, TERSE_HOOK_VERSION in installer/session_hooks.py was bumped so _self_heal_terse_mode() actively replaces existing sidecar config files instead of leaving them on outdated prompt phrasing.

Token Saver guidance reconciles rules and loads prompt in your language

Token Saver's prompt instructions now reconcile internal rules and launch directly in your local language. In usage_terse_mode.py, _DEFAULT_INSTRUCTION now permits an opening greeting emoji and a one-line tool intent while keeping them strictly outside the reply body. Inside installer/session_hooks.py, _write_terse_sidecar() writes the output of detect_lang() under lang, and _read_sidecar() / _detect_lang() in both hook scripts parse it after checking environment overrides. Consequently, sessions lacking explicit language environment variables no longer fall back to the longer English prompt; missing or corrupted sidecar files still safely default to English. It is like a multilingual reception desk: permitting the greeter to wave and display a one-line badge while keeping the response brief, handing visitors brochures in their native language instead of defaulting to a bulky English manual, and using English only as a safe fallback when records are lost.

Existing reminder hooks upgrade automatically instead of staying stale

After upgrading usage, existing Token Saver reminder hooks now update themselves to the latest version automatically. Previously, _self_heal_terse_reminder() in installer/session_hooks.py only intervened when a script file or its registration was entirely missing, leaving older installed scripts untouched on stale wording. The system now uses TERSE_REMINDER_HOOK_VERSION and _installed_terse_reminder_version() to compare version numbers and actively replace outdated script copies, logging an update_terse_reminder_hook event for future diagnostics. It is like a building inspector checking public address speakers: previously only replacing a unit if it was missing while leaving obsolete speakers in place, but now verifying serial numbers, actively replacing aged hardware, and logging the maintenance in service records.

ja

Token Saver の簡潔な応答が平易になり、専門用語の解説と次の手順を案内

業務の引き継ぎメモを作成する際、要点を簡潔にまとめつつ専門用語には平易な注釈を添え、作業結果と次の手順で締めくくって古い手引きを新しい版に差し替えるようなものだ。 Token Saver において、簡潔な応答が平易で理解しやすくなった。モジュール usage_terse_mode.py の _DEFAULT_INSTRUCTION は簡潔さに加えて平易な表現を基本方針に据え、回避できない技術用語には一度限りの平易な注釈を加え、応答の末尾を実行結果と次の手順で締めくくるよう求めている。また usage_terse_reminder.py の _DEFAULT_REMINDER も同様の規則を強化する。さらに installer/session_hooks.py の TERSE_HOOK_VERSION が引き上げられたため、自己修復関数 _self_heal_terse_mode() は古い文言のまま放置せず既存のサイドカー設定ファイルを新しい記述へ置き換える。

Token Saver の指示が整合され、挨拶の絵文字を許容しユーザーの言語で起動

Token Saver の指示内容が自己矛盾なく整理され、ユーザーの言語で自動起動するようになった。モジュール usage_terse_mode.py の _DEFAULT_INSTRUCTION は、冒頭の挨拶絵文字や 1 行のツール意図の出力を認めつつ、それらを応答本文から除外する。installer/session_hooks.py の _write_terse_sidecar() は detect_lang() で検知した言語を lang に記録し、両フックスクリプトの _read_sidecar() および _detect_lang() が環境変数の上書き確認後にそれを読み出す。これにより言語環境変数のないセッションでも冗長な英語プロンプトへ不用意にフォールバックしなくなった。なおサイドカーファイルが見つからない場合や壊れている場合は安全に英語へフォールバックする。多言語の総合案内窓口のようなもので、係員が冒頭で会釈して名札を提示することを認めつつ本文は簡潔に保ち、来訪者の母国語に応じた案内書を渡して不要な長文英語を避け、案内書を紛失した場合のみ英語で対応するようなものだ。

既存のリマインダーフックが版数を比較し、古いスクリプトを自動更新

usage の更新後、既存の Token Saver リマインダーフックが自動的に最新版へ同期されるようになった。以前は installer/session_hooks.py の自己修復関数 _self_heal_terse_reminder() は、スクリプトや登録設定が完全に失われた場合のみ復元を行い、すでにインストールされていた古いスクリプトはそのまま放置されていた。現在は TERSE_REMINDER_HOOK_VERSION と _installed_terse_reminder_version() が版数を比較し、古い複製を検知すると自動で新しいスクリプトに置き換えたうえで、診断用に update_terse_reminder_hook を記録する。ビルの館内放送スピーカーを点検するようなもので、以前はスピーカー自体が紛失した時だけ補充して古い機材はそのまま放置していたのを、現在は型番を確認して旧型機を積極的に新品へ交換し、点検日誌に交換記録を残すようなものだ。

ko

Token Saver의 간결한 응답이 쉬워지고 전문 용어 설명과 다음 단계를 안내

업무 인수인계 시 간결하면서도 쉬운 일상어로 설명하고, 피할 수 없는 전문 용어에는 쉬운 해설을 덧붙이며, 결과와 다음 단계를 명시하고 오래된 지침서를 새것으로 교체하는 것과 같다. Token Saver 모드에서 짧은 응답이 한층 더 이해하기 쉬워졌다. usage_terse_mode.py 모듈의 _DEFAULT_INSTRUCTION은 간결함과 더불어 쉬운 일상어 작성을 기본 방침으로 삼고, 불가피한 기술 용어에 일회성 설명을 추가하며, 실행 결과와 다음 단계로 답변을 마무리하도록 요구한다. usage_terse_reminder.py의 _DEFAULT_REMINDER 역시 같은 규칙을 강화한다. 아울러 installer/session_hooks.py의 TERSE_HOOK_VERSION 판번호가 올라가면서, 자가 복구 함수인 _self_heal_terse_mode가 기존 사이드카 설정 파일을 이전 문구로 방치하지 않고 새로운 프롬프트로 교체한다.

Token Saver 안내가 일관성을 갖추고 인사말 이모티콘을 허용하며 모국어로 시작

Token Saver의 지침이 자체 모순을 해소하고 사용자의 기본 언어로 올바르게 시작된다. usage_terse_mode.py의 _DEFAULT_INSTRUCTION은 첫머리 인사 이모티콘과 한 줄짜리 도구 의도 표시를 허용하면서도 이들을 답변 본문에서 제외한다. installer/session_hooks.py의 _write_terse_sidecar 함수는 detect_lang으로 감지한 언어를 lang 항목에 기록하며, 두 훅 스크립트의 _read_sidecar와 _detect_lang이 환경 변수 우선순위를 확인한 뒤 이를 읽어 들인다. 따라서 언어 환경 변수가 없는 세션에서도 더 이상 불필요하게 긴 영문 프롬프트로 기본 설정되지 않는다. 사이드카 파일이 없거나 손상된 경우에는 안전하게 영문으로 대체 동작한다. 다국어 안내 데스크와 같아서, 직원이 첫인사를 건네고 한 줄 명찰을 보여주는 것을 허용하되 본문은 간결함을 유지하고, 방문객의 모국어에 맞춘 안내서를 건네어 긴 영문 안내를 피하며, 안내서가 유실되었을 때만 안전하게 영문으로 대응하는 것과 같다.

기존 리마인더 훅이 버전을 비교하여 오래된 스크립트를 자동 갱신

usage를 업그레이드한 후, 기존 Token Saver 리마인더 훅이 최신 버전으로 자동 동기화된다. 이전에는 installer/session_hooks.py의 자가 복구 함수인 _self_heal_terse_reminder가 스크립트나 등록 정보가 완전히 누락된 경우에만 복원하여, 이미 설치된 구버전 스크립트는 그대로 방치되었다. 이제 시스템이 TERSE_REMINDER_HOOK_VERSION과 _installed_terse_reminder_version으로 버전을 대조하여 오래된 사본을 최신 스크립트로 능동 교체하고 진단용으로 update_terse_reminder_hook을 기록한다. 건물의 안내 방송 스피커를 점검할 때, 예전에는 장비가 완전히 사라졌을 때만 새로 달아주고 낡은 기기는 그대로 두었던 반면, 이제는 모델 번호를 확인하여 구형 기기를 새것으로 교체하고 점검 일지에 교체 명세를 남기는 것과 같다.
