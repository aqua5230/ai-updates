Windows 檔案變更即時更新，重疊重整不漏接

你在 Windows 上剛讓 Claude Code 或 Codex 跑完大量工作，想立刻確認最新額度，以前系統匣（工作列右下角的小圖示區）的數字可能慢半拍、落後長達五分鐘。現在新增的原生檔案監聽器會在底層檔案一變動時，立刻更新系統匣百分比、面板、額度通知與 Window Keeper。如果你在背景重新整理時手動點擊重整或打開面板，重疊的請求會自動合併，並在當前進度跑完後立即再補刷一次，不再遺失任何操作。這如同大樓的包裹收發台，快遞一送件就立刻廣播通知住戶，不再等固定巡邏；若清點包裹時又有人按鈴催件，管理員會先記下來並在點完後馬上再查一次。

Windows 支援 Antigravity 狀態列，安裝路徑更穩固

習慣在 Windows 終端機使用 Antigravity 開發的人，現在只要打開狀態列（status line，顯示在終端機最底下的資訊欄）開關，終端機底端就能同步顯示即時額度，即使使用打包後的獨立執行檔也能正常維護。過去安裝時可能會悄悄寫入無法執行的指令，現在會主動為 cmd.exe 挑選不帶引號的安全 Python 路徑、妥善處理特殊路徑字元，遇到不支援的路徑更會給出明確的處理提示；macOS 上原有的設定則維持不變。這好比水電師傅替工廠機台配線，自備符合新規格的專用接頭，遇到特殊牆面做好絕緣包覆，遇到不相容的插座更會當場附上接線指引，確保通電後指示燈穩定運作。

Windows 補齊每日診斷與更新檢查，通知與工作列掌握度更高

你在 Windows 上使用 usage 管理多個 AI 工具時，日常的健康檢查與提醒變得像 macOS 一樣全面且貼心。系統匣啟動後會排程每日額度浪費診斷、面板可接收 Claude 與 Codex 服務狀態，背景自動更新也遵循每日快取（cache，把查過的結果暫存起來直接用）與冷卻設定，但手動檢查仍會立即執行。額度警示改用帶有操作按鈕的互動式快訊，可保留在重要訊息中心直接點擊打開面板，不支援時則在不中斷重新整理的情況下自動切換為備援氣泡；面板開啟時，工作列按鈕還會顯示同色系的額度進度條，面板關閉即消失。這好比診所秘書每天定時彙整健康報告並留意門診公告，提醒信附有掛號按鈕且收在待辦匣，門口燈號更會隨進度變色並在離開時自動熄滅。

Windows 介面清晰防模糊，多螢幕排版與選單更清晰

桌上接了高解析度螢幕或多台不同縮放比例顯示器的 Windows 使用者，現在打開面板不再遇到字體模糊或視窗飄出螢幕外的困擾。獨立執行檔換上了專屬貓爪圖示，並具備 Per-Monitor-v2 高解析度感知能力，避免面板被點陣圖粗暴拉伸；視窗定位統一採用 WebView2 邏輯座標並經由主執行緒調整，徹底解決面板出現在錯誤螢幕或跨出邊界的問題。同時選單結構也重新整理，右鍵點擊系統匣僅保留重設位置與結束等救援選項，面板切換、重新整理、開機自動啟動與通知設定等控制項全移至面板專屬選單，且兩處共用定義不再脫節。這如同畫廊重新布展，每幅畫作依展廳標準精準縮放，由專人依精確標尺掛在正確展牆，並將大門總開關與展台操作盤分開管理。

用量預測依時間加權，短暫尖峰不再觸發見底警報

當你一口氣讓 Claude 讀入一份厚重檔案，看著預測面板可能曾被「額度即將在短時間內用光」的警報嚇了一跳。現在 macOS 與 Windows 上的預測演算法已改良，會依據近期每個輪詢區間的實際持續時間進行加權計算；就算某個短短數秒的區間內剛好碰上大量 token（AI 處理與計費的文字單位）更新，系統也不會再把瞬間爆發誤當成長期常態，進而做出額度即將耗盡的不合理預測。這如同家用水錶評估水費，如果洗手剛好開了五秒大水，計算機現在會把這五秒與平時一整天的靜止時間一起平均加權，知道這只是短暫用水，不會再發出誇張的缺水預報。

服務中斷橫幅準確復原，停機警示抑制回歸正常

遇到 AI 服務端短暫故障時，你既想及時看到故障橫幅，又不希望在已知停機期間被不斷跳出的錯誤警報轟炸。macOS 與 Windows 上的狀態監控現在已修正：讀取 Codex API 狀態時改採完整的元件清單，不再讀取容易遺漏細節的截斷摘要；而警示抑制機制只會在受影響的元件確實需要時，才去抓取事故狀態，修復了 Claude 之前的退化問題，並讓 Codex 的通知抑制功能首次正式生效。這好比機場航班調度看板，地勤人員改查閱完整的全航線班表，確認只有受天候影響的特定航班延誤時才精準靜音重複警報，既不漏報班機狀態，也不會在已知檢修期間連續發出廣播吵醒候機旅客。

en

Windows updates usage in real time on file changes without dropping refresh requests

When you finish a heavy run with Claude Code or Codex on Windows and want to check your quota, the tray readings used to lag behind by up to five minutes. A native file watcher now updates the tray percentage, panel, quota notifications, and Window Keeper right after underlying files change. If you click Refresh Now or open the panel while a background refresh is already underway, overlapping requests are merged and executed once more as soon as the active refresh completes, ensuring no request is lost. It is like an apartment mail desk that broadcasts an arrival notice the moment a courier delivers a parcel rather than waiting for scheduled rounds, and notes down any resident checking in during an active inventory to re-check right after.

Windows supports Antigravity status line with safe executable paths

Developers running Antigravity on Windows can now turn on the existing status line (the readout displayed at the bottom of a terminal) switch to install and maintain live quota stats, even when using the packaged standalone binary. The setup process previously risked silently writing unrunnable commands, but now selects an unquoted, safe Python path for cmd.exe, handles special characters securely, and provides clear action steps if an unsupported path is encountered, leaving macOS paths unaffected. It is like an electrician wiring industrial machinery with custom connectors suited for the specific panel, insulating cables around awkward corners, and leaving clear diagrams if a socket is incompatible, ensuring the status light turns on reliably.

Windows gains daily diagnostic checks, Action Center toast alerts, and taskbar progress

Managing AI tools on Windows now offers the same comprehensive health checks and alerts as macOS. The app schedules a daily quota-waste diagnosis after startup, feeds Claude and Codex service statuses into the panel, and respects daily cache (saving fetched results temporarily for direct reuse) cooldowns during background update checks, while manual checks still run immediately. Quota alerts now use interactive Windows toasts with action buttons that stay in the Action Center to open the panel, falling back gracefully to tray balloons without interrupting refreshes if unsupported. When the panel is open, its taskbar button displays a color-coded progress bar that vanishes on close without cluttering your bar. It is like a clinic receptionist compiling daily health summaries, sending actionable reminders directly to your inbox, and displaying a color-coded queue light that turns off when you leave.

Windows interface stays sharp on high-DPI setups with polished menus and positioning

Windows users with high-DPI displays or mixed multi-monitor setups will no longer encounter blurry text or off-screen panels. The executable now sports the custom paw icon and enables Per-Monitor-v2 DPI awareness to prevent ugly bitmap stretching; panel placement consistently applies logical coordinates via WebView2 on the UI thread, eliminating misplacement across monitors or edges. Furthermore, menu layouts have been cleaned up: right-clicking the tray icon keeps only emergency recovery options like Reset Panel Position and Quit, while panel switching, refresh, launch at login, notification settings, and update checks are available from the panel's own menu, with both surfaces sharing the same definition. It is like an art gallery scaling paintings cleanly to every gallery wall, hanging frames precisely with accurate rulers, and separating main circuit breakers from individual podium switches.

Quota forecasts weight intervals by duration to ignore brief token spikes

When feeding Claude a massive document, you might have been startled by a forecast warning that your quota would dry up in minutes. On both macOS and Windows, the forecasting algorithm now weights each recent polling interval by its actual duration. A short interval carrying a heavy token (units of AI text processing and billing) jump from a single Claude update is no longer extrapolated as continuous consumption, preventing implausibly pessimistic depletion estimates. It is like estimating a home water bill: opening the faucet full blast for five seconds is weighted alongside hours of inactivity, recognizing a brief surge rather than predicting the reservoir will run dry by nightfall.

Outage banners restore correctly and suppress noisy alerts during downtime

When an AI upstream hiccups, you want to see the status banner immediately without getting bombarded by repetitive error popups during a known outage. Status monitoring across macOS and Windows has been overhauled: Codex API health is now parsed from the complete component list rather than a truncated summary, and alert suppression only fetches incident details when an affected component truly requires it. This fixes a recent regression for Claude and brings effective alert suppression to Codex for the first time. It is like an airport flight status board where ground staff cross-reference the full master flight schedule, muting repetitive alarm bells specifically for flights already marked as delayed by bad weather without spamming the public address system during scheduled maintenance.
