Usage 0.29.27

Released: 2026-08-13

Release notes

FEATURE

Windows updates usage in real time on file changes without dropping refresh requests

When you finish a heavy run with Claude Code or Codex on Windows and want to check your quota, the tray readings used to lag behind by up to five minutes.

A native file watcher now updates the tray percentage, panel, quota notifications, and Window Keeper right after underlying files change. If you click Refresh Now or open the panel while a background refresh is already underway, overlapping requests are merged and executed once more as soon as the active refresh completes, ensuring no request is lost. It is like an apartment mail desk that broadcasts an arrival notice the moment a courier delivers a parcel rather than waiting for scheduled rounds, and notes down any resident checking in during an active inventory to re-check right after.

FEATURE

Windows supports Antigravity status line with safe executable paths

Developers running Antigravity on Windows can now turn on the existing status line (the readout displayed at the bottom of a terminal) switch to install and maintain live quota stats, even when using the packaged standalone binary.

The setup process previously risked silently writing unrunnable commands, but now selects an unquoted, safe Python path for cmd.exe, handles special characters securely, and provides clear action steps if an unsupported path is encountered, leaving macOS paths unaffected. It is like an electrician wiring industrial machinery with custom connectors suited for the specific panel, insulating cables around awkward corners, and leaving clear diagrams if a socket is incompatible, ensuring the status light turns on reliably.

FEATURE

Windows gains daily diagnostic checks, Action Center toast alerts, and taskbar progress

Managing AI tools on Windows now offers the same comprehensive health checks and alerts as macOS.

The app schedules a daily quota-waste diagnosis after startup, feeds Claude and Codex service statuses into the panel, and respects daily cache (saving fetched results temporarily for direct reuse) cooldowns during background update checks, while manual checks still run immediately. Quota alerts now use interactive Windows toasts with action buttons that stay in the Action Center to open the panel, falling back gracefully to tray balloons without interrupting refreshes if unsupported. When the panel is open, its taskbar button displays a color-coded progress bar that vanishes on close without cluttering your bar. It is like a clinic receptionist compiling daily health summaries, sending actionable reminders directly to your inbox, and displaying a color-coded queue light that turns off when you leave.

FEATURE

Windows interface stays sharp on high-DPI setups with polished menus and positioning

Windows users with high-DPI displays or mixed multi-monitor setups will no longer encounter blurry text or off-screen panels.

The executable now sports the custom paw icon and enables Per-Monitor-v2 DPI awareness to prevent ugly bitmap stretching; panel placement consistently applies logical coordinates via WebView2 on the UI thread, eliminating misplacement across monitors or edges. Furthermore, menu layouts have been cleaned up: right-clicking the tray icon keeps only emergency recovery options like Reset Panel Position and Quit, while panel switching, refresh, launch at login, notification settings, and update checks are available from the panel's own menu, with both surfaces sharing the same definition. It is like an art gallery scaling paintings cleanly to every gallery wall, hanging frames precisely with accurate rulers, and separating main circuit breakers from individual podium switches.

FEATURE

Quota forecasts weight intervals by duration to ignore brief token spikes

When feeding Claude a massive document, you might have been startled by a forecast warning that your quota would dry up in minutes.

On both macOS and Windows, the forecasting algorithm now weights each recent polling interval by its actual duration. A short interval carrying a heavy token (units of AI text processing and billing) jump from a single Claude update is no longer extrapolated as continuous consumption, preventing implausibly pessimistic depletion estimates. It is like estimating a home water bill: opening the faucet full blast for five seconds is weighted alongside hours of inactivity, recognizing a brief surge rather than predicting the reservoir will run dry by nightfall.

FEATURE

Outage banners restore correctly and suppress noisy alerts during downtime

When an AI upstream hiccups, you want to see the status banner immediately without getting bombarded by repetitive error popups during a known outage.

Status monitoring across macOS and Windows has been overhauled: Codex API health is now parsed from the complete component list rather than a truncated summary, and alert suppression only fetches incident details when an affected component truly requires it. This fixes a recent regression for Claude and brings effective alert suppression to Codex for the first time. It is like an airport flight status board where ground staff cross-reference the full master flight schedule, muting repetitive alarm bells specifically for flights already marked as delayed by bad weather without spamming the public address system during scheduled maintenance.
