zh-TW

超過九成亮起外框紅光，Default 面板警戒更直觀

Default 面板的卡片外框會亮起紅色動態警示，標出超過 90% 的工作階段（session，單次對話或任務的連續使用期間）或每週用量。如同精密儀器在警戒線邊界亮起環形跑馬燈，紅光沿著邊緣繞行，提醒操作者留意殘量。一條紅色弧線每 2.6 秒會繞著卡片邊緣跑動一圈，在 Claude、Codex 與 Antigravity 卡片上皆有一致的視覺效果。目前這項警戒光效果由 Default 面板提供，其餘面板則維持不變。

進度條標出八成門檻刻度，剩餘額度一眼看清

上限前還剩多少額度，現在能從進度條一眼看出。進度軌道在 80% 門檻處新增了刻度標記，位置正好落在進度條轉為紅色的交界點。這讓你能一眼看出達到上限前還剩下多少可用餘裕（headroom，額度耗盡前的剩餘緩衝空間），不必再依賴純文字數字進行推算。這好比在透明量筒的八成高度標上一道分界刻度，液面一逼近紅線，不必細讀數字刻度也能立刻掌握剩餘容量。

休息時消耗速率自動回落，計入閒置時間更貼近真實

密集使用 10 分鐘後休息 40 分鐘，消耗速率標籤會開始回落，不再一直釘在「Heavy」。過去計算速率時，只除以第一筆到最後一筆紀錄之間的間隔，分母漏掉了閒置時間；這導致密集使用 10 分鐘後休息 40 分鐘，標籤仍會被釘在「Heavy」狀態，直到滿 1 小時視窗過期。現在分母改以第一筆紀錄起算經過的總時間計算，離開時速率就會逐漸衰減。各級門檻與快取讀取（cache-read，讀取暫存資料）排除規則皆維持不變。這如同計算長途旅行的平均時速，把停靠休息站的空檔也算入時間分母，車子熄火後儀表板均速便會自然往下降。

專案讀數改用等寬數字，排版欄位不再左右晃動

數字跳動時，專案用量清單的欄位不再左右晃動或錯位了。這有如機械翻牌式時刻表，每個數字格子寬度完全相同，任一欄位跳動都不會推擠到鄰近文字。專案 token（AI 處理與計費的文字單位）計數、花費金額與百分比全面改用等寬數字，每個數字字元佔據相同寬度。當數值隨用量即時跳動時，縱向欄位不再左右晃動或錯位，版面閱讀體驗更加穩定。

Default 面板看清鍵盤焦點，按鈕平滑過渡並遵循動態偏好

Default 面板會清楚亮出鍵盤焦點（focus，鍵盤目前選中並可接收按鍵指令的介面位置）。面板上的按鈕在滑鼠懸停（hover）狀態之間，也改以平滑動畫過渡，不再生硬地瞬間切換。這兩項視覺改進都會自動遵循系統的「減少動態效果」設定，若使用者偏好靜態介面，系統會關閉動態過渡。宛如舞台上的聚光燈與調光燈具，鍵盤移動時焦點清晰可辨，游標滑過時按鈕柔和漸變，遇到調暗需求時也能維持靜止。

en

Card borders trace warning lights at 90% in Default panel

The Default panel now traces a red active warning light around the border of any session or weekly row above 90%. It is like a precision instrument activating a perimeter warning beacon at critical capacity, running a red glow along the edge to alert the operator. A red arc travels around the card's edge once every 2.6 seconds, appearing consistently across Claude, Codex, and Antigravity cards. The Default panel carries this warning light today, while other panels remain unchanged.

Progress tracks mark the 80% threshold for at-a-glance headroom

Remaining headroom is now visible at a glance instead of requiring you to read percentage text. Progress tracks now display a tick mark at the 80% threshold, positioned precisely where the bar turns red. This allows you to assess how much headroom (the buffer remaining before hitting limits) is left at a glance instead of reading raw percentage text. It is like marking a boundary line at the eighty percent level on a measuring cylinder, letting you gauge remaining capacity the moment fluid nears the line without inspecting numbers.

Burn rate decays after stopping work as idle time enters the denominator

A ten-minute burst followed by a forty-minute break no longer leaves the rate label pinned at "Heavy". Previously, burn rate was calculated by dividing only by the span between the first and last usage entry, excluding idle time from the denominator; a ten-minute burst followed by a forty-minute break stayed pinned at "Heavy" until those entries aged out of the one-hour window. The rate now divides by the total time elapsed since the first entry, allowing it to decay while you are away. Threshold levels and the cache-read exclusion remain unchanged. It is like calculating trip speed by including time spent parked at a rest stop in the denominator, so average speed steadily drops while the engine is off.

Tabular figures align project readouts and stop column shifts

As digits change, columns in project usage lists no longer shift side to side. It is like a mechanical flip-board schedule where every digit occupies an identical slot width, preventing changes in one column from shoving neighboring text. Project token (the unit for AI processing and billing) counts, costs, and percentages now use tabular figures with uniform widths. As digits change with live activity, columns stop shifting or jittering horizontally, creating a steady visual layout.

Default panel shows keyboard focus and animates hover states smoothly

The Default panel now clearly shows keyboard focus (the interface element currently selected to receive keystrokes). Buttons on the panel also animate smoothly between hover states rather than snapping abruptly. Both visual improvements respect the system's reduced-motion setting, falling back to static states if the user prefers reduced motion. It is like stage spotlights paired with dimmer switches: the focus is immediately clear as you step through, buttons glow smoothly as the cursor passes, and transitions remain static whenever calm lighting is requested.

超过九成亮起外框红光，Default 面板预警更直观

Default 面板的卡片外框会亮起红色动态预警，标出超过 90% 的会话（session，单次对话或任务的连续使用期间）或每周用量。如同精密仪器在警戒线边界亮起环形跑马灯，红光沿着边缘绕行，提醒操作者留意残量。一条红色弧线每 2.6 秒会绕着卡片边缘跑动一圈，在 Claude、Codex 与 Antigravity 卡片上均有一致的视觉效果。目前这项预警光效果由 Default 面板提供，其余面板则维持不变。

进度条标出八成门槛刻度，剩余额度一眼看清

上限前还剩多少额度，现在能从进度条一眼看出。进度轨道在 80% 门槛处新增了刻度标记，位置正好落在进度条转为红色的交界点。这让你可以一眼看出达到上限前还剩下多少可用余量（headroom，额度耗尽前的剩余缓冲空间），不必再依赖纯文本数字进行推算。这好比在透明量筒的八成高度标上一道分界刻度，液面一逼近红线，不必细读数字刻度也能立刻掌握剩余容量。

休息时消耗速率自动回落，计入闲置时间更贴近真实

密集使用 10 分钟后休息 40 分钟，消耗速率标签会开始回落，不再一直钉在「Heavy」。过去计算速率时，只除以第一条到最后一条记录之间的间隔，分母漏掉了闲置时间；这导致密集使用 10 分钟后休息 40 分钟，标签仍会被钉在「Heavy」状态，直到满 1 小时窗口过期。现在分母改以第一条记录起算经过的总时间计算，离开时速率就会逐渐衰减。各级门槛与缓存读取（cache-read，读取暂存数据）排除规则均维持不变。这如同计算长途旅行的平均时速，把停靠休息站的空档也算入时间分母，车子熄火后仪表板均速便会自然往下降。

项目读数改用等宽数字，排版列不再左右晃动

数字跳动时，项目用量清单的列不再左右晃动。这有如机械翻牌式时刻表，每个数字格子宽度完全相同，任一列跳动都不会推挤到邻近文本。项目 token（AI 处理与计费的文本单位）计数、花费金额与百分比全面改用等宽数字，每个数字字符占据相同宽度。当数值随用量即时跳动时，纵向列不再左右晃动或错位，版面阅读体验更加稳定。

Default 面板看清键盘焦点，按钮平滑过渡并遵循动效偏好

Default 面板会清楚亮出键盘焦点（focus，键盘当前选中并可接收按键指令的界面位置）。面板上的按钮在鼠标悬停（hover）状态之间，也改以平滑动画过渡，不再生硬地瞬间切换。这两项视觉改进都会自动遵循系统的「减少动态效果」设置，若用户偏好静态界面，系统会关闭动态过渡。宛如舞台上的聚光灯与调光灯具，键盘移动时焦点清晰可辨，光标划过时按钮柔和渐变，遇到调暗需求时也能维持静止。

ja

90% 超過でカード枠に警告灯が走り、Default パネルの警戒が直感的に

Default パネルでは、90% を超えたセッション（session、1 回の対話やタスクの継続期間）や週ごとの行のカード外枠に、赤い動的な警告が現れるようになった。精密機器が限界値に達した際に外枠のシグナルを巡回させ、操作者に残量を知らせるようなものだ。赤い弧が 2.6 秒ごとにカードの縁を一周し、Claude、Codex、Antigravity の各カードで同様に点灯する。この表示は現在 Default パネルで導入されており、他のパネルは変更されていない。

進捗バーに 80% の目盛りが付き、残り枠が一目で分かる

上限までの残り枠は、数字テキストを読み込まなくても一目で分かるようになった。進捗トラックの 80% の位置に目盛りが配置され、バーが赤く変わる境界が一目で分かるようになった。これにより、上限までの残余余力（headroom、制限に達するまでの残り枠）を数字テキストに頼らず直感的に把握できる。計量カップの 8 割の位置に境界線が引かれ、液面が赤線に近づくだけで目盛りを読まずとも残量を把握できるようなものだ。

作業停止後に消費レートが自然減衰し、待機時間の加味で実態に近づく

10 分間集中的に使った後に 40 分間休んでも、消費レート表示は「Heavy」に固定されず下がり始める。以前は最初と最後の使用記録の間隔だけで割っていたため分母から待機時間が抜け落ちており、10 分間集中的に使った後に 40 分間休んでも、1 時間の集計枠から外れるまで「Heavy」のまま固定されていた。現在は最初の記録からの経過時間全体で割るようになり、離席中にレートが減衰する。閾値やキャッシュ読み取り（cache-read、一時保存されたデータを読み出す処理）の除外ルールは変更されていない。長距離ドライブの平均速度を計算する際、サービスエリアでの休憩時間も分母に含めることで、停車中に平均速度が自然と落ちていくようなものだ。

プロジェクト表示が等幅数字になり、列の横揺れが収まる

数字が変わっても、プロジェクトの使用量一覧の列は左右に揺れなくなった。反転フラップ式案内表示機のように、各数字のマス目の幅が均一で、桁が動いても隣の文字を押し出さない仕掛けだ。プロジェクトの token（AI がテキストを処理・課金する際の文字単位）数、利用料金、パーセンテージに等幅数字が採用され、文字幅が一定になった。数字が変化しても列が左右にガタつくことがなくなり、視認性が大幅に向上した。

Default パネルでキーボードフォーカスが見え、ボタンも滑らかに変化する

Default パネルでは、キーボードフォーカス（focus、キー入力を受け付ける選択位置）が明確に見えるようになった。パネル上のボタンもマウスホバー時に即座に切り替わるのではなく、滑らかなアニメーションで遷移する。これら 2 つの視覚的改善はシステムの「視覚効果を減らす」設定を尊重し、不要な動きを避ける環境では過度な演出を控える。舞台のスポットライトと調光器のように、移動先が明るく照らされ、カーソルが触れると光が柔らかく変化し、演出を抑える場面では静止を保つようなものだ。

ko

90% 넘기면 카드 테두리에 경고등이 돌고 Default 패널 경고가 직관적으로 바뀐다

Default 패널은 90%를 넘긴 세션(session, 단일 대화나 작업이 이어지는 기간)이나 주간 사용량 카드 테두리에 빨간색 움직이는 경고를 표시한다. 정밀 기기가 한계치에 다다랐을 때 외곽 표시등을 돌려 남은 양을 알리는 것과 같다. 빨간색 호가 2.6초마다 카드 가장자리를 한 바퀴 돌며, Claude, Codex, Antigravity 카드 모두에 똑같이 표시된다. 이 기능은 현재 Default 패널에 적용되었으며 다른 패널은 변경되지 않았다.

진행률 막대에 80% 눈금이 생겨 남은 여유가 한눈에 보인다

한도까지 남은 여유는 이제 백분율 텍스트를 읽지 않아도 한눈에 보인다. 진행률 트랙의 80% 임계값 위치에 눈금이 추가되었으며, 막대가 빨간색으로 변하는 지점에 정확히 놓인다. 이를 통해 한도까지 남은 여유 공간(headroom, 상한에 도달하기 전 남은 완충량)이 얼마나 되는지 텍스트 숫자에만 기대지 않고 한눈에 파악할 수 있다. 계량컵의 80% 높이에 눈금선이 그어져 있어 눈금을 일일이 읽지 않아도 수위가 다가오는 순간 남은 용량을 알아채는 것과 같다.

작업 중단 후 소모율이 자연스럽게 내려가고 유휴 시간 반영으로 현실에 가까워진다

10분간 몰아서 쓴 뒤 40분을 쉬면 소모율 표시는 더 이상 'Heavy'에 고정되지 않고 내려가기 시작한다. 예전에는 처음과 마지막 사용 기록 사이의 간격으로만 나누어 분모에서 유휴 시간이 빠져 있었다. 그 결과 10분간 몰아서 쓴 뒤 40분을 쉬어도 1시간 집계 범위에서 빠질 때까지 'Heavy' 상태로 고정되어 있었다. 이제는 첫 기록 이후 흐른 전체 시간으로 나누어 자리를 비운 동안 소모율이 줄어든다. 임계값 기준과 캐시 읽기(cache-read, 임시 저장된 데이터를 읽는 동작) 제외 규칙은 그대로 유지된다. 휴게소에서 쉰 시간까지 분모에 넣어 장거리 주행의 평균 속도를 계산함으로써 시동을 끄고 쉬는 동안 계기판 평균 속도가 자연스럽게 떨어지는 것과 같다.

프로젝트 수치에 고정폭 숫자를 적용해 열이 좌우로 흔들리지 않는다

숫자가 바뀌어도 프로젝트 사용량 목록의 열은 더 이상 좌우로 흔들리지 않는다. 플랩식 전광판처럼 모든 숫자 칸의 폭이 같아서 숫자가 바뀌어도 옆 칸의 글자를 밀어내지 않는 것과 같다. 프로젝트의 token(AI가 글을 처리하고 요금을 매기는 글자 단위) 수와 비용, 백분율 표시에 고정폭 숫자가 쓰여 글자 너비가 일정해졌다. 수치가 실시간으로 바뀌어도 열이 좌우로 흔들리지 않아 화면을 훨씬 편하게 볼 수 있다.

Default 패널에서 키보드 포커스가 보이고 버튼 전환이 부드러워진다

Default 패널은 키보드 포커스(focus, 키 입력을 받을 수 있도록 선택된 화면 위치)를 또렷하게 보여 준다. 패널의 버튼 역시 마우스를 올렸을 때 딱딱하게 끊기며 바뀌는 대신 부드러운 애니메이션으로 전환된다. 두 시각적 개선 사항은 모두 시스템의 동작 줄이기 설정을 따르므로 정적인 화면을 선호하는 환경에서는 전환 애니메이션이 꺼진다. 무대의 스포트라이트와 조광기처럼 이동할 때마다 위치가 선명하게 드러나고 커서가 닿으면 빛이 부드럽게 바뀌며 연출을 줄여야 할 때는 정지 상태를 유지하는 것과 같다.
