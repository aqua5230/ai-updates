Usage 0.29.30

發布日期：2026-08-15

繁體中文

問題修復

超過九成亮起外框紅光，Default 面板警戒更直觀

Default 面板的卡片外框會亮起紅色動態警示，標出超過 90% 的工作階段（session，單次對話或任務的連續使用期間）或每週用量。

如同精密儀器在警戒線邊界亮起環形跑馬燈，紅光沿著邊緣繞行，提醒操作者留意殘量。

一條紅色弧線每 2.6 秒會繞著卡片邊緣跑動一圈，在 Claude、Codex 與 Antigravity 卡片上皆有一致的視覺效果。目前這項警戒光效果由 Default 面板提供，其餘面板則維持不變。

新功能

進度條標出八成門檻刻度，剩餘額度一眼看清

上限前還剩多少額度，現在能從進度條一眼看出。

進度軌道在 80% 門檻處新增了刻度標記，位置正好落在進度條轉為紅色的交界點。這讓你能一眼看出達到上限前還剩下多少可用餘裕（headroom，額度耗盡前的剩餘緩衝空間），不必再依賴純文字數字進行推算。

這好比在透明量筒的八成高度標上一道分界刻度，液面一逼近紅線，不必細讀數字刻度也能立刻掌握剩餘容量。
新功能

休息時消耗速率自動回落，計入閒置時間更貼近真實

密集使用 10 分鐘後休息 40 分鐘，消耗速率標籤會開始回落，不再一直釘在「Heavy」。

過去計算速率時，只除以第一筆到最後一筆紀錄之間的間隔，分母漏掉了閒置時間；這導致密集使用 10 分鐘後休息 40 分鐘，標籤仍會被釘在「Heavy」狀態，直到滿 1 小時視窗過期。現在分母改以第一筆紀錄起算經過的總時間計算，離開時速率就會逐漸衰減。各級門檻與快取讀取（cache-read，讀取暫存資料）排除規則皆維持不變。

這如同計算長途旅行的平均時速，把停靠休息站的空檔也算入時間分母，車子熄火後儀表板均速便會自然往下降。
新功能

專案讀數改用等寬數字，排版欄位不再左右晃動

數字跳動時，專案用量清單的欄位不再左右晃動或錯位了。

這有如機械翻牌式時刻表，每個數字格子寬度完全相同，任一欄位跳動都不會推擠到鄰近文字。

專案 token（AI 處理與計費的文字單位）計數、花費金額與百分比全面改用等寬數字，每個數字字元佔據相同寬度。當數值隨用量即時跳動時，縱向欄位不再左右晃動或錯位，版面閱讀體驗更加穩定。

新功能

Default 面板看清鍵盤焦點，按鈕平滑過渡並遵循動態偏好

Default 面板會清楚亮出鍵盤焦點（focus，鍵盤目前選中並可接收按鍵指令的介面位置）。

面板上的按鈕在滑鼠懸停（hover）狀態之間，也改以平滑動畫過渡，不再生硬地瞬間切換。這兩項視覺改進都會自動遵循系統的「減少動態效果」設定，若使用者偏好靜態介面，系統會關閉動態過渡。

宛如舞台上的聚光燈與調光燈具，鍵盤移動時焦點清晰可辨，游標滑過時按鈕柔和漸變，遇到調暗需求時也能維持靜止。

English

FEATURE

Card borders trace warning lights at 90% in Default panel

The Default panel now traces a red active warning light around the border of any session or weekly row above 90%.

It is like a precision instrument activating a perimeter warning beacon at critical capacity, running a red glow along the edge to alert the operator.

A red arc travels around the card's edge once every 2.6 seconds, appearing consistently across Claude, Codex, and Antigravity cards. The Default panel carries this warning light today, while other panels remain unchanged.

FEATURE

Progress tracks mark the 80% threshold for at-a-glance headroom

Remaining headroom is now visible at a glance instead of requiring you to read percentage text.

Progress tracks now display a tick mark at the 80% threshold, positioned precisely where the bar turns red. This allows you to assess how much headroom (the buffer remaining before hitting limits) is left at a glance instead of reading raw percentage text.

It is like marking a boundary line at the eighty percent level on a measuring cylinder, letting you gauge remaining capacity the moment fluid nears the line without inspecting numbers.
FEATURE

Burn rate decays after stopping work as idle time enters the denominator

A ten-minute burst followed by a forty-minute break no longer leaves the rate label pinned at "Heavy".

Previously, burn rate was calculated by dividing only by the span between the first and last usage entry, excluding idle time from the denominator; a ten-minute burst followed by a forty-minute break stayed pinned at "Heavy" until those entries aged out of the one-hour window. The rate now divides by the total time elapsed since the first entry, allowing it to decay while you are away. Threshold levels and the cache-read exclusion remain unchanged.

It is like calculating trip speed by including time spent parked at a rest stop in the denominator, so average speed steadily drops while the engine is off.
FEATURE

Tabular figures align project readouts and stop column shifts

As digits change, columns in project usage lists no longer shift side to side.

It is like a mechanical flip-board schedule where every digit occupies an identical slot width, preventing changes in one column from shoving neighboring text.

Project token (the unit for AI processing and billing) counts, costs, and percentages now use tabular figures with uniform widths. As digits change with live activity, columns stop shifting or jittering horizontally, creating a steady visual layout.

FEATURE

Default panel shows keyboard focus and animates hover states smoothly

The Default panel now clearly shows keyboard focus (the interface element currently selected to receive keystrokes).

Buttons on the panel also animate smoothly between hover states rather than snapping abruptly. Both visual improvements respect the system's reduced-motion setting, falling back to static states if the user prefers reduced motion.

It is like stage spotlights paired with dimmer switches: the focus is immediately clear as you step through, buttons glow smoothly as the cursor passes, and transitions remain static whenever calm lighting is requested.
