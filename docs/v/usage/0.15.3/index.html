zh-TW

資料刷新偶爾出錯時，Codex 額度不再閃成空白

你的 Codex 額度顯示現在更穩定了，不會再時不時消失一瞬間。以前如果系統在背景讀取歷史用量時剛好遇到錯誤，它會連帶把已經順利讀好的 Codex 額度清空，讓你看到畫面閃一下變成空白；現在它懂得在出錯時保留已經抓到的好資料。就像看電視遇到訊號稍微不穩，以前會直接切成黑畫面，現在它會先凍結在最後一個清楚的畫面，等你沒察覺時訊號就恢復了。

en

Codex quota no longer flashes blank when background refreshes hiccup

Your Codex quota display is much steadier now and won't randomly disappear for a split second. Previously, if the system hit a bump while reading your historical usage in the background, it would mistakenly wipe out the Codex quota it had already successfully fetched, making those rows flash blank; it now knows to hold onto the good data it already has when an error occurs. Like watching a streaming video that encounters a slight network hiccup — it used to just cut to a black screen, but now it freezes on the last clear frame until the signal quietly catches up.

原始 CHANGELOG

Original changelog
**Codex quota no longer blanks out on refresh errors (#25)**: follow-up to #24. When the later refresh stage (history parsing) failed, the error state reset the Codex session/weekly rows to blank, overwriting the quota that had already been loaded at the start of the refresh. The error path now preserves those already-loaded Codex rows, so they no longer flash empty.
