zh-TW

自動接棒改用同一開關，Antigravity 不再被假倒數騙住

你替 Claude 或 Antigravity 開過自動接棒，現在不用記得兩個開關在哪裡：它們合成同一個選項，打開後兩位視窗守護者會一起啟動；先前只開其中一項的人，也會自動視為兩項都開啟。Antigravity 的額度 API（程式用來取得額度資料的介面）在額度還有 100% 時，仍會回報「約五小時後重設」。這只是尚未使用的滑動視窗（從第一次使用才開始計時的五小時時段）預留時間，不是已在倒數。舊版誤認工作階段正在跑，讓自動接棒從不觸發；現在會把 100% 視為沒有進行中的時段，符合條件就可自動接棒，五小時防連續觸發仍保留。額度卡也會顯示「Quota full」，不再拿假倒數嚇你。

en

One switch now runs both keepers, without Antigravity's fake countdown

If you enabled automatic handoff for either Claude or Antigravity, you no longer need to hunt for two switches. They are now one shared toggle: turn it on and both keepers start; anyone who had enabled either old switch is automatically treated as having enabled both. This also fixes Antigravity's phantom countdown. Its quota API (the program connection used to retrieve quota data) reported “in about five hours” even with 100% remaining. That is reserved time for a sliding window (a five-hour period whose clock starts only with first use), not a running countdown. The old gate mistook it for an active session, so it never launched. At 100% remaining, it treats the window as inactive and can launch, while its five-hour self-throttle remains. The card shows “Quota full” until then. Like one relay-race switch: both runners get ready together, but the clock counts down only after the race begins.

Original changelog
**Auto-start is now one shared switch for Claude and Antigravity.** It starts both keepers together; users who previously enabled either individual switch are automatically treated as having both enabled.
**Antigravity auto-start never fired, and the card showed a phantom countdown.** The Antigravity quota API reports a *sliding* reset time (always "in ~5 hours") while a 5-hour window is still untouched at 100% remaining. The 0.28.14 auto-start gate treated any reported countdown as "a window is already running", so it never pinged; it now treats 100% remaining itself as "no active window" (the 5-hour self-throttle still applies). The card likewise stopped rendering that placeholder as a live countdown — at 100% remaining it now shows "Quota full" until a real window starts.
