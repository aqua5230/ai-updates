新功能

蝶類圖鑑面板在沒有專案時不再亂跳

新增的蝶類圖鑑面板現在不管有沒有專案資料，版面都會穩如泰山。

以前這個面板的內容是垂直置中的，當你還沒有任何專案資料時，面板上的卡片會直接飄到視窗正中間，等專案一出現又會突然跳回原本的位置；現在它已經改成跟其他面板一樣靠上對齊，多出來的空間會被專案卡片自然填滿。就像原本掛在牆上的畫因為沒釘好而滑到中間，現在把它牢牢釘在頂部，不管底下多掛幾幅畫都不會走位。

English

FEATURE

The Lepidoptera panel no longer jumps around when the project list is empty

The new Lepidoptera panel will now stay rock solid regardless of whether you have project data.

Previously, this panel was vertically centered, meaning if you had no projects listed, the cards would float to the exact middle of the popover and then suddenly jump back when projects appeared; it now top-aligns exactly like the other panels, with the project card naturally absorbing any extra space. Like a framed picture that used to slide to the middle of a wall because it wasn't nailed properly, it's now firmly anchored at the top and won't shift no matter how many other pictures you hang below it.
