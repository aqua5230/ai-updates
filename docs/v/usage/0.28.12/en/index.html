Release notes

FEATURE

Start your next 5-hour window while you're away

Heading out for lunch or errands and don't want your next Claude allowance window to start only when you return? usage now has an opt-in Auto-start 5-hour Session toggle.

When it sees that a 5-hour quota window has reset and no session is running, it sends one background claude -p ok --model haiku command to start the next window immediately. Think of it like scheduling a washing machine: the countdown can begin while you're away, but it runs at most once per window rather than repeatedly nudging the machine. It is off by default, never calls Anthropic's quota API, and quietly does nothing if the claude CLI is unavailable. On setup, it explains that usage and your Mac need to stay awake; closing the lid still puts your Mac to sleep as usual.

Original changelog

Original changelogStart your next 5-hour window while you're away
**New opt-in menu toggle: Auto-start 5-hour Session.** When enabled, usage detects that your Claude 5-hour quota window has just reset and no session is currently running, then fires a single `claude -p ok --model haiku` in the background to immediately start the next window — useful if you're stepping away and want the next 5 hours counting down before you're back. Off by default; sends at most once per 5-hour window (self-throttled), never touches the Anthropic quota API, and silently no-ops if the `claude` CLI can't be found. Enabling it shows a one-time dialog explaining that it needs usage (and the Mac) to stay awake to fire — closing the lid always sleeps the Mac regardless of this setting.
