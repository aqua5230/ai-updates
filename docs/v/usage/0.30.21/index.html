Usage 0.30.21

發布日期：2026-09-23

繁體中文

新功能

離線價目表補齊 GPT-6 模型，斷網也能精準記帳

當你在沒有網路的環境下使用 Codex 寫程式，工具依然能準確計算最新模型的花費。

線上的 LiteLLM 價目表原本就包含 GPT-6-Sol 與 GPT-6-Luna 這兩款新模型，但過去程式內建的備援（fallback，下載線上資料失敗時才會啟用的備用方案）價目表尚未更新。一旦網路斷線或是連線下載失敗，這兩個新模型的消耗金額就會漏算。現在內建備援表已經同步補上相同的價格資訊。

就像水電師傅隨身帶著備用紙本報價單，就算在地下室收不到訊號，翻開來照樣查得到新進特殊零件的工料費，算帳時不會漏掉任何項目。
新功能

Grok 狀態列支援 Windows，舊設定不再誤當備份還原

在 Windows 上使用 Grok 搭配 usage 時，狀態列（status line，顯示在終端機最底下的狀態列）現在能正常運作。

過去 Grok 會把 [ui.status_line] command 視為單一程式路徑而觸發 os error 123 錯誤。現在 usage 會寫入 ~/.grok/usage-statusline-grok.cmd 包裝檔並指向它，既有安裝由自我修復自動切換，macOS 維持不變。過去若 Python 路徑不同，安裝程式會把舊指令誤存為使用者設定並在移除時還原；現在只要指向 usage 腳本或包裝檔，解除安裝便會直接捨棄備份。

如同將工序封裝成專用料理包避免出錯，退租點交時也能認出外加包裝直接丟棄，不再誤當成原本餐具放回抽屜。
新功能

Windows 首次啟動說明，教你放行 SmartScreen 警告

第一次在 Windows 電腦上下載並打開 usage 時，如果遇到系統安全提示擋下，現在有明確步驟可依循。

官方說明文件（README，專案隨附的說明檔案）與網站正式補上操作教學：當 Windows Defender SmartScreen 跳出「Windows 已保護您的電腦」提示時，只要先點擊「其他資訊」，再按下「仍要執行」即可正常啟動程式，不必擔心被系統防護卡住。

跟大樓門禁初次攔下訪客一樣，只要依提示點擊確認，就能順利放行進門。

English

FEATURE

Offline pricing table now covers GPT-6 models, so billing stays accurate without a network

When you use Codex to write code in an environment without internet access, the tool can still accurately calculate the cost of the latest models.

The online LiteLLM pricing table already included the two new models GPT-6-Sol and GPT-6-Luna, but the program's built-in fallback pricing table (the backup that only kicks in when downloading online data fails) had not been updated. Once the network dropped or the download failed, the spending on these two new models would be missed. The built-in fallback table has now been synced with the same pricing information.

It is like a plumber who carries a paper backup price list: even in a basement with no signal, they can still look up the labor and material cost of newly stocked specialty parts, so nothing gets left off the bill.
FEATURE

Grok status line now supports Windows, and old settings are no longer mistakenly restored as backups

When using Grok with usage on Windows, the status line (the status bar shown at the very bottom of the terminal) now works properly.

Previously, Grok treated the [ui.status_line] command as a single program path, which triggered os error 123. Now usage writes a wrapper file at ~/.grok/usage-statusline-grok.cmd and points to it; existing installs switch over automatically via self-repair, while macOS stays unchanged. In the past, if the Python path differed, the installer would mistakenly save the old command as a user setting and restore it on removal; now, as long as it points to the usage script or wrapper file, uninstalling simply discards the backup.

Think of it like sealing a procedure into a dedicated meal kit to avoid mistakes: at move-out inspection, the added packaging is recognized and thrown away directly, instead of being mistaken for the original tableware and put back in the drawer.
FEATURE

First-launch instructions for Windows show you how to allow the SmartScreen warning

The first time you download and open usage on a Windows computer, if a system security prompt blocks it, there are now clear steps to follow.

The official documentation (the README, the instruction file shipped with the project) and the website now include a walkthrough: when Windows Defender SmartScreen pops up the "Windows protected your PC" prompt, just click "More info" first, then press "Run anyway" to start the program normally, without worrying about being stuck at the system protection screen.

Just like a building's access control stopping a visitor for the first time, you only need to follow the prompts to confirm, and you are let through the door smoothly.
