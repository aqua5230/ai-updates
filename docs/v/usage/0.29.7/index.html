額度面板會自己收好高度，不留底部空白

你打開 Usage 面板（跳出來顯示額度的小視窗）查看 Codex 的每週額度時，底部不會再莫名多出一條空白帶。以前畫面高度照每張面板預設的固定值算；若 Codex 只回報每週時段、沒有 5 小時資料，額度卡少了一列，底下就留下死白。現在每次更新後，面板會量自己的實際高度，視窗隨著內容縮放，且不會超出可用螢幕範圍；量不出來時仍用原本數值當備援。這像量身裁衣：少一行內容就收短一點。只有 World Cup 的球場主題刻意預留滿版背景，會標記那塊空間，保留原本設計高度。

en

Quota panels now fit their content instead of leaving a blank strip

When you open the Usage panel to check Codex's weekly quota, an odd blank strip will no longer linger below it. The panel height used to come from a fixed preset. If Codex reported only a weekly window and no 5-hour data, the quota card lost one row but kept the extra height. Now, after each refresh, the panel measures its natural height and the window follows it without exceeding usable screen space; the old value remains a fallback if measuring fails. Think of a tailored hem: one less line of content, one less line of fabric. The World Cup pitch theme is the exception: it marks its intentional full-window backdrop so its designed height remains intact.

原始 CHANGELOG

Original changelog
**The panel no longer leaves an empty strip at the bottom**: panel height came from a fixed per-panel constant, so any layout that rendered shorter than the registered value left dead space below the footer. The common trigger is Codex reporting only a weekly window with no 5-hour data, which drops a quota row from the card. The panel now measures its own natural height after each refresh and the window resizes to match, clamped to the usable screen area; the registered constants stay as the pre-measurement default and as the fallback when a measurement is unusable. A panel that deliberately leaves room for a full-window backdrop — World Cup's pitch is the only one — marks that region so it keeps its designed height instead of collapsing while the measurement releases the layout's height constraints.
