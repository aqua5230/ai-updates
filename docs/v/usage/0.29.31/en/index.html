Usage 0.29.31

Released: 2026-08-18

Release notes

FEATURE

usage status removes floating-point noise from percentage outputs

Running usage status to inspect your quotas will no longer spit out messy floating-point noise in session and weekly percentages.

The tool previously interpolated raw numerical values directly into output strings, producing cluttered readouts like 42.30000000000001 instead of a clean 42.3.

It is like a digital scale rounding off jittery multi-digit fractions to show a single steady decimal on its display.

Both session and weekly metrics are now strictly formatted to one decimal place, keeping terminal output predictable and tidy.

FEATURE

Windows tray tooltip aligns with panel values and includes Antigravity

Hovering over the Windows system tray icon now reveals tooltip figures that perfectly match what you see inside the main panel, while no longer skipping Antigravity.

The tooltip previously showed the *remaining* percentage (calculated as 100 minus used) while every panel displays the *used* percentage, creating unnecessary confusion.

It is like giving every line on a noticeboard one used-amount standard, restoring the missing Antigravity line, and setting the Claude entry in the same one-line format as the rest.

The tooltip now reports used percentages across the board, adds an Antigravity row whenever that card is visible, and reformats the Claude entry to match Codex and Antigravity's single-line "Session · Weekly" layout.

FEATURE

Windows update notifications strip raw Markdown markers

Update dialogs on Windows will no longer greet you with unformatted Markdown markup when a new version drops.

Release descriptions pulled from GitHub previously rendered literal ##, **, and ` `` tokens directly inside the notification window. While macOS resolved this display glitch in version 0.29.28, the corresponding fix had not made its way to Windows until now. Both platforms now route release text through the shared formatter.

It is like a printing press stripping proofreading marks before handing books to readers across every branch store.
BUGFIX

Website fixes mobile navigation and shareable anchors

On the public website, a narrow mobile screen will no longer leave you without a way to navigate.

Below 640px, the navigation bar that previously disappeared entirely is replaced by a labeled, expandable Sections menu.

It is like a narrow trailhead gaining an expandable route board that keeps your marked location when you switch to another language route.

Switching languages also no longer rewrites shared anchors such as #install to #<lang>, so links copied before a language switch still open at their original location.

FEATURE

Website improves footer readability, image loading, and tap targets

On mobile, the public website now also covers readability and interaction details that are easy to overlook.

Footer text meets AA contrast requirements, making foreground and background easier to distinguish, while images lazy-load only when needed.

It is like making station information readable to everyone, lighting up platform displays only as you approach, and leaving enough room for the clickable areas of buttons and links.

Every tap target measures at least 24px, with the primary mobile navigation reaching 44px to make finger input less error-prone.

FEATURE

Website theme count updated from 12 to 13 to include Catppuccin

The theme counter across all five language versions of the public website has been updated from 12 to 13.

The Catppuccin color scheme introduced in version 0.29.23 had been left out of the site's tally, causing the displayed figure to lag behind reality.

This is like a showroom featuring 13 distinct models while the printed catalog mistakenly tallies 12 until an update fixes the count.

Every localized version of the website now accurately showcases the full lineup of 13 themes.

FEATURE

Social preview image reflects Windows support and shrinks in size

Sharing website links on social platforms now generates an updated preview card that reflects Windows availability alongside macOS.

The old image labeled the project strictly as a "macOS Menu Bar App", whereas the new 1200×630 visual pairs the brand and title with an authentic panel screenshot (featuring Claude, Codex, and Antigravity) rendered in the site's distinct color palette. File size dropped dramatically from 573KB down to 96KB, with the smaller preview file size.

It is like a station sign that previously listed only macOS, now adding Windows and an authentic service-panel image on lighter material.
FEATURE

README status-line screenshots upgraded to localized animations

Viewing the status-line previews in the README now presents fully recorded animations tailored to each language.

Non-English translations previously borrowed static screenshots from the English README.

It is like a fitness class no longer showing every learner the same English posture photo, but playing a dedicated moving demonstration for each language.

Every supported language now features its own animated recording, scaled to stay sharp and legible within the standard README reading width.

FEATURE

Status-line setup becomes a dedicated README section with platform terms

Finding setup instructions for terminal status-lines in the README is now immediate and straightforward.

The guide was formerly tucked away as a sub-topic under Windows Support, causing macOS users to overlook it entirely. It now commands its own dedicated section, complete with terminology aligned for both platforms and Traditional Chinese.

As if moving a popular information desk from a remote corner annex to the main lobby so visitors on every path spot it right away.

Users across operating systems can now easily locate relevant setup steps and terminology.
