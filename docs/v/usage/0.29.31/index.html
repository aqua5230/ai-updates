usage status 消除百分比雜訊，統一保留一位小數

在終端機執行 usage status 查詢額度時，工作階段（session，單次使用的時間區段）與每週百分比數值不再出現多餘的小數雜訊。過去程式將數值直接拼進字串，導致畫面上可能出現如 42.30000000000001 這類冗長的小數。這就像電子磅秤把原本因感應過敏而跳出的一長串零碎小數抹平，在螢幕上整齊收攏到小數點後一位。現在這兩項百分比都統一格式化為一位小數（例如 42.3），讓輸出的資訊乾淨俐落。

Windows 系統匣提示對齊面板數值，納入 Antigravity

把游標移到 Windows 系統匣（tray，工作列右側的常駐圖示區）圖示上方時，浮動提示文字顯示的數值現在與面板完全一致，而且不再漏掉 Antigravity。過去提示文字顯示的是「剩餘」百分比（以 100 減去已用量），而各個面板顯示的都是「已使用」百分比，兩邊數字對不起來。這如同把公告欄的各項用量改用同一個已使用標準，補上漏列的 Antigravity，並把 Claude 條目整理成和其餘項目相同的一行格式。現在提示文字統一改為已使用百分比，並在 Antigravity 卡片未隱藏時補上專屬一行；Claude 的顯示行也同步重構為與 Codex 和 Antigravity 一致的單行「工作階段 · 每週」排版。

Windows 更新通知去除原始 Markdown 標記

SNS で公式サイトのリンクを共有した際に表示されるプレビュー画像が刷新された。以前の画像には「macOS Menu Bar App」と記載されていたが、新しい 1200×630 の画像ではブランドロゴやタイトルとともに、サイトの配色に合わせた実際のパネル画面（Claude、Codex、Antigravity）が並び、Windows 対応が明示されるようになった。ファイルサイズも 573KB から 96KB へと大幅に削減された。macOS 対応だけを示す駅の案内板に Windows を加え、実際のサービスパネルを載せ、より軽い素材へ替えるようなものだ。

README の解説を読む際、ステータス行のプレビューが録画されたアニメーションへと更新された。以前は英語以外の言語版でも英語の静止画が流用されていたが、現在は各言語ごとに個別の録画アニメーションが用意されている。フィットネス教室が全員に同じ英語の姿勢写真を見せるのをやめ、言語ごとに専用の動く実演を流すようなものだ。すべてのアニメーションは README の表示幅に合わせて調整され、どの言語でも文字が鮮明に読める。

ステータス行の設定が README の独立セクションへ昇格

端末でステータス行を設定したい利用者が、README 内で専用の解説セクションをすぐ見つけられるようになった。これまでは Windows Support（Windows サポート）の下層に埋もれていたため、macOS の利用者が設定手順を見落とす原因となっていた。現在は独立したセクションへ昇格し、両プラットフォームおよび繁体中国語の用語対応も補完された。人気の案内窓口を特定フロアの奥から中央ロビーへ移設し、各言語の案内標識を整えて誰もが見つけられるようにしたような改善である。どの環境の利用者でも迷わず設定手順を参照できる。

usage status 백분율 출력에서 부동 소수점 잡음 제거

터미널에서 usage status 명령으로 잔여량을 확인할 때 세션(session, 한 번의 작업 구간) 및 주간 사용률에서 지저분한 소수점 잡음이 사라졌다. 예전에는 계산된 숫자를 문자열에 그대로 끼워 넣어 42.3 대신 42.30000000000001 같은 긴 소수가 화면에 찍히곤 했다. 전자저울이 미세한 센서 떨림으로 튀던 긴 자릿수를 정리해 화면에 소수점 아래 한 자리로 깔끔하게 띄워 주는 것과 같다. 이제 두 항목 모두 소수점 첫째 자리까지 깔끔하게 정리되어 출력된다.

Windows 트레이 툴팁 수치가 패널과 일치하고 Antigravity 항목 추가

Windows 시스템 트레이 아이콘 위에 마우스를 올렸을 때 나타나는 툴팁 수치가 이제 패널 화면과 정확히 일치하며 Antigravity 항목도 빠지지 않는다. 이전에는 모든 패널이 '사용량' 백분율을 보여주는 반면 툴팁은 '남은 양'(100에서 사용량을 뺀 값)을 표시해 혼란을 주었다. 게시판의 모든 항목을 같은 사용량 기준으로 맞추고, 빠졌던 Antigravity 줄을 보태며, Claude 항목도 다른 항목과 같은 한 줄 형식으로 정리한 셈이다. 이제 툴팁도 사용량 기준으로 통일되었고 Antigravity 카드가 숨겨져 있지 않으면 해당 줄도 표시된다. Claude 표시 줄 또한 Codex 및 Antigravity와 동일하게 한 줄짜리 'Session · Weekly' 배치로 정리되었다.

Windows 업데이트 알림에서 가공되지 않은 Markdown 기호 제거

Windows에서 새 버전 업데이트 알림이 뜰 때 대화상자에 Markdown(특수 기호로 굵은 글씨나 제목을 지정하는 서식) 기호가 그대로 노출되지 않는다. 이전에는 GitHub Release 본문에 적힌 ##, **, ` `` 같은 서식 기호가 업데이트 창에 글자 그대로 나타났다. macOS에서는 0.29.28 버전에서 이미 수정되었으나 Windows에는 반영되지 않았던 부분으로, 이제 두 플랫폼 모두 같은 서식 처리기를 공유한다. 서적을 배포하기 전에 교정 부호를 말끔히 지우고 정돈된 본문만을 보여 주는 것과 다름없다.

웹사이트 모바일 내비게이션과 공유 앵커 수정

모바일 기기로 usage 공식 웹사이트를 볼 때 좁은 화면에서 내비게이션을 잃지 않게 되었다. 화면 너비가 640px 미만이면 이전에는 완전히 사라지던 내비게이션 바 대신 Sections라고 표시된 펼침 메뉴가 나타난다. 좁은 등산로 입구에 펼칠 수 있는 경로 안내판을 두고 다른 언어 경로로 바꿔도 기존 위치 표시는 남겨 두는 것과 같다. 언어를 바꿔도 #install 같은 공유 앵커가 #<lang>으로 다시 쓰이지 않아, 전환 전에 복사한 링크도 원래 위치를 계속 연다.

웹사이트가 바닥글 가독성, 이미지 로딩, 터치 영역을 개선

모바일에서 공식 웹사이트를 볼 때 놓치기 쉬운 가독성과 조작 세부 사항도 함께 보완되었다. 바닥글 글자는 AA 대비 기준을 충족해 전경과 배경을 구분하기 쉬워졌으며, 이미지는 필요할 때 지연 로딩된다. 역 안내 정보를 누구나 읽기 쉬운 글자로 바꾸고, 승강장 화면은 가까이 갈 때만 켜며, 버튼과 링크의 클릭 영역에도 충분한 공간을 두는 것과 같다. 모든 터치 영역은 최소 24px이고 모바일 주 내비게이션은 44px이다.

웹사이트 테마 수를 12개에서 13개로 수정하여 Catppuccin 반영

공식 웹사이트 5개 언어 전체에서 안내되던 테마 총수가 12개에서 13개로 바로잡혔다. 0.29.23 버전에서 추가되었던 Catppuccin 테마가 웹사이트의 집계에서 누락되어 있었는데, 이번 변경을 통해 모든 언어 페이지에서 누락이 해결되었다. 진열대에는 13개 제품이 놓여 있는데 카탈로그의 숫자 표기만 하나 빠져 있던 것을 정상적으로 맞춘 조치와 같다. 이제 어느 언어로 접속하든 현재 지원되는 13가지 테마가 올바르게 표시된다.

소셜 미리보기 이미지에 Windows 지원을 반영하고 용량 경량화

소셜 플랫폼에서 공식 웹사이트 링크를 공유할 때 나타나는 미리보기 카드가 새롭게 개편되었다. 이전 이미지에는 'macOS Menu Bar App'이라는 문구만 적혀 있었으나, 새로운 1200×630 이미지는 브랜드 및 제목과 함께 사이트 고유 색상의 실제 패널 스크린샷(Claude, Codex, Antigravity)을 담아 Windows 지원을 명확히 보여준다. 이미지 용량 또한 573KB에서 96KB로 크게 줄었다. macOS 지원만 적힌 역 안내판에 Windows와 실제 서비스 패널을 더하고 더 가벼운 소재로 바꾸는 것과 같다.

README 상태 줄 미리보기가 언어별 맞춤 애니메이션으로 개편

README 문서를 확인할 때 상태 줄 미리보기가 움직이는 녹화 애니메이션으로 업그레이드되었다. 이전에는 영어가 아닌 다른 언어 문서에서도 영어 스크린샷을 그대로 빌려와 사용했으나, 이제 각 언어마다 맞춤 녹화된 전용 애니메이션이 제공된다. 운동 교실이 모든 수강생에게 같은 영어 자세 사진을 보여 주는 대신 언어별 전용 동작 시연을 재생하는 것과 같다. 모든 애니메이션은 README 본문 너비에 맞춰 조정되어 어떤 언어에서도 글씨를 또렷하게 읽을 수 있다.

상태 줄 설정 가이드가 README 독립 섹션으로 분리되고 용어 보강

터미널 상태 줄을 설정하려는 사용자가 README에서 전용 안내 단락을 바로 찾을 수 있게 되었다. 이전에는 해당 설명이 Windows Support(Windows 지원) 하위 항목에 묻혀 있어 macOS 사용자가 그냥 지나치기 쉬웠다. 이제 독립된 최상위 섹션으로 승격되었으며, 두 운영체제 플랫폼 및 번체 중국어에 맞춘 용어 대조도 함께 채워졌다. 인기 안내 데스크를 구석진 부속 건물에서 중앙 로비로 옮겨 누구나 쉽게 발견할 수 있도록 개선한 변화와 같다. 어떤 운영체제를 쓰든 필요한 설정 정보를 한눈에 찾아볼 수 있다.
