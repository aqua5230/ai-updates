zh-TW

usage status 消除百分比雜訊，統一保留一位小數

在終端機執行 usage status 查詢額度時，工作階段（session，單次使用的時間區段）與每週百分比數值不再出現多餘的小數雜訊。過去程式將數值直接拼進字串，導致畫面上可能出現如 42.30000000000001 這類冗長的小數。這就像電子磅秤把原本因感應過敏而跳出的一長串零碎小數抹平，在螢幕上整齊收攏到小數點後一位。現在這兩項百分比都統一格式化為一位小數（例如 42.3），讓輸出的資訊乾淨俐落。

Windows 系統匣提示對齊面板數值，納入 Antigravity

把游標移到 Windows 系統匣（tray，工作列右側的常駐圖示區）圖示上方時，浮動提示文字顯示的數值現在與面板完全一致，而且不再漏掉 Antigravity。過去提示文字顯示的是「剩餘」百分比（以 100 減去已用量），而各個面板顯示的都是「已使用」百分比，兩邊數字對不起來。這如同把公告欄的各項用量改用同一個已使用標準，補上漏列的 Antigravity，並把 Claude 條目整理成和其餘項目相同的一行格式。現在提示文字統一改為已使用百分比，並在 Antigravity 卡片未隱藏時補上專屬一行；Claude 的顯示行也同步重構為與 Codex 和 Antigravity 一致的單行「工作階段 · 每週」排版。

Windows 更新通知去除原始 Markdown 標記

當 Windows 跳出新版本更新通知時，說明視窗不再直接印出未解析的 Markdown（以特殊符號標示粗體或標題的排版語法）原始標記。先前來自 GitHub Release 內文的 ## 標題、** 粗體與 ` `` 程式碼符號，在更新對話框中都會被原樣渲染出來。這項問題在 macOS 平台已於 0.29.28 版解決，但修復一直未同步至 Windows 平台；現在兩個系統已共用同一套格式化處理器。這好比印刷廠在樣品書送達各分店前先將排版標記擦拭乾淨，讓讀者看見精緻排版而非編輯痕跡。

官網修復行動版導覽與分享錨點

用手機瀏覽 usage 官方網站時，窄螢幕不會再失去導覽方向。在螢幕寬度低於 640px 時，原本整條消失的導覽列現在改由標示 Sections 的展開選單替代。好比登山步道的窄入口設有可展開路線牌，改走其他語言路線時，原本標記的位置仍保留下來。切換語言也不再把 #install 等分享錨點改寫為 #<lang>，因此在切換前複製的連結仍能開啟原先位置。

官網補強頁尾可讀性、圖片載入與點擊操作

網站在手機上顯示時，容易被忽略的可讀性與操作細節也一併補齊。頁尾文字現在符合 AA 級對比要求，前景與背景的差異足以辨識；圖片改為需要顯示時才讀取。這像候車資訊換成人人看得清楚的字，月台畫面接近時才亮起，按鈕與連結的可點擊區域也留出足夠空間。各個點擊目標至少為 24px，行動版主導覽則為 44px，手指操作更不容易按偏。

官網主題總數校正為 13 款，補齊 Catppuccin 計數

瀏覽官方網站的主題清單時，頁面上標示的主題總數已在全部五種語言版本中統一由 12 款修正為 13 款。先前在 0.29.23 版推出的 Catppuccin 主題配色一直未被計入網站的統計數字中，這次更新在所有語系頁面中如實補上了這項遺漏。這像展示櫃明明陳列了 13 款特色商品，外頭目錄清單卻少算了一款，如今目錄將漏掉的款式如實補上，讓各語系型錄的標示與架上款式完全一致。現在造訪官網不同語言版本，所見的主題統計都能正確反映當前完整的 13 種配色。

社群預覽圖反映 Windows 支援，體積縮小更輕量

在社群平台分享官方網站連結時，縮圖卡片（social preview image，社群預覽圖片）已全面翻新。過去圖片標題寫著「macOS Menu Bar App」，現在全新的 1200×630 圖片將品牌與標題結合網站原生配色的實際面板截圖（涵蓋 Claude、Codex 與 Antigravity），清楚展現對 Windows 的支援。此外，圖片檔案大小也從原本的 573KB 大幅縮減至 96KB，讓分享預覽圖檔案更輕量。像車站指示牌原本只標示 macOS，現加入 Windows、放上實際服務面板，並換成更輕薄的材質。

README 狀態列截圖升級為多語言動態展示

查閱 README 說明文件時，狀態列（status line，顯示在終端機底部的即時資訊列）展示畫面已升級為動態錄製的動畫。過去非英文語系都是借用英文版的靜態截圖，現在每一種語言版本都配備了專屬的錄製動圖。如同健身教室不再讓所有學員看同一張英文姿勢照片，而是依各語言播放專屬的動態示範。所有動圖都針對 README 的版面寬度進行了最佳化調整，確保文字在各語言環境下都能清晰易讀。

狀態列設定升格為 README 獨立章節，補齊平台術語

想在終端機配置狀態列的讀者，現在能在 README 中直接找到專屬的設定章節。過去這段教學作為子章節被埋在 Windows Support（Windows 支援）底下，導致 macOS 使用者容易直接錯過；現在它被獨立成頂層章節，並完整補齊了兩大平台與繁體中文的專業術語對照。彷彿將熱門服務台從特定附錄搬到大廳正中央，並補齊多系統與繁體中文標籤，讓所有訪客一進門就能找到指引。無論你在哪種作業系統上使用 usage，都能順暢依照母語術語完成狀態列設定。

en

usage status removes floating-point noise from percentage outputs

Running usage status to inspect your quotas will no longer spit out messy floating-point noise in session and weekly percentages. The tool previously interpolated raw numerical values directly into output strings, producing cluttered readouts like 42.30000000000001 instead of a clean 42.3. It is like a digital scale rounding off jittery multi-digit fractions to show a single steady decimal on its display. Both session and weekly metrics are now strictly formatted to one decimal place, keeping terminal output predictable and tidy.

Windows tray tooltip aligns with panel values and includes Antigravity

Hovering over the Windows system tray icon now reveals tooltip figures that perfectly match what you see inside the main panel, while no longer skipping Antigravity. The tooltip previously showed the *remaining* percentage (calculated as 100 minus used) while every panel displays the *used* percentage, creating unnecessary confusion. It is like giving every line on a noticeboard one used-amount standard, restoring the missing Antigravity line, and setting the Claude entry in the same one-line format as the rest. The tooltip now reports used percentages across the board, adds an Antigravity row whenever that card is visible, and reformats the Claude entry to match Codex and Antigravity's single-line "Session · Weekly" layout.

Windows update notifications strip raw Markdown markers

Update dialogs on Windows will no longer greet you with unformatted Markdown markup when a new version drops. Release descriptions pulled from GitHub previously rendered literal ##, **, and ` `` tokens directly inside the notification window. While macOS resolved this display glitch in version 0.29.28, the corresponding fix had not made its way to Windows until now. Both platforms now route release text through the shared formatter. It is like a printing press stripping proofreading marks before handing books to readers across every branch store.

Website fixes mobile navigation and shareable anchors

On the public website, a narrow mobile screen will no longer leave you without a way to navigate. Below 640px, the navigation bar that previously disappeared entirely is replaced by a labeled, expandable Sections menu. It is like a narrow trailhead gaining an expandable route board that keeps your marked location when you switch to another language route. Switching languages also no longer rewrites shared anchors such as #install to #<lang>, so links copied before a language switch still open at their original location.

Website improves footer readability, image loading, and tap targets

On mobile, the public website now also covers readability and interaction details that are easy to overlook. Footer text meets AA contrast requirements, making foreground and background easier to distinguish, while images lazy-load only when needed. It is like making station information readable to everyone, lighting up platform displays only as you approach, and leaving enough room for the clickable areas of buttons and links. Every tap target measures at least 24px, with the primary mobile navigation reaching 44px to make finger input less error-prone.

Website theme count updated from 12 to 13 to include Catppuccin

The theme counter across all five language versions of the public website has been updated from 12 to 13. The Catppuccin color scheme introduced in version 0.29.23 had been left out of the site's tally, causing the displayed figure to lag behind reality. This is like a showroom featuring 13 distinct models while the printed catalog mistakenly tallies 12 until an update fixes the count. Every localized version of the website now accurately showcases the full lineup of 13 themes.

Social preview image reflects Windows support and shrinks in size

Sharing website links on social platforms now generates an updated preview card that reflects Windows availability alongside macOS. The old image labeled the project strictly as a "macOS Menu Bar App", whereas the new 1200×630 visual pairs the brand and title with an authentic panel screenshot (featuring Claude, Codex, and Antigravity) rendered in the site's distinct color palette. File size dropped dramatically from 573KB down to 96KB, with the smaller preview file size. It is like a station sign that previously listed only macOS, now adding Windows and an authentic service-panel image on lighter material.

README status-line screenshots upgraded to localized animations

Viewing the status-line previews in the README now presents fully recorded animations tailored to each language. Non-English translations previously borrowed static screenshots from the English README. It is like a fitness class no longer showing every learner the same English posture photo, but playing a dedicated moving demonstration for each language. Every supported language now features its own animated recording, scaled to stay sharp and legible within the standard README reading width.

Status-line setup becomes a dedicated README section with platform terms

Finding setup instructions for terminal status-lines in the README is now immediate and straightforward. The guide was formerly tucked away as a sub-topic under Windows Support, causing macOS users to overlook it entirely. It now commands its own dedicated section, complete with terminology aligned for both platforms and Traditional Chinese. As if moving a popular information desk from a remote corner annex to the main lobby so visitors on every path spot it right away. Users across operating systems can now easily locate relevant setup steps and terminology.
