Grok Build 1.0.48

發布日期：2026-10-02

繁體中文

新功能

/rewind 倒轉對話時只列出你親手輸入的指令

當你請 AI 寫程式寫到一半想推翻重來、想跳回先前的步驟時，終端機裡的歷史清單現在不會再被雜訊淹沒。

好比翻閱會議紀錄時，以前每一頁中間都夾雜設備檢查與換電池的雜記，現在只保留與會者真正說過的話，讓你一眼就能翻回想重來的那一刻。

以前打 /rewind（倒轉對話的指令）準備挑選要退回的時間點，清單裡常會混雜系統在背景自動產生的過渡紀錄。現在這項指令只會列出你親手敲進去的提示詞（prompt，向 AI 發出的指令），自動產生的執行輪次通通直接跳過。

新功能

config.toml 設定自訂模型時保留原始公告橫幅

如果你在專案設定檔裡切換或掛載自己慣用的模型，現在終端機依然能完整看見官方的重要提示。

在 config.toml（管理設定選項的檔案）中設定自訂模型表格時，有時需要指定不同的模型來源。以前只要填入這些自訂內容，終端機原本會顯示的公告橫幅（notice banner，說明模型條款或使用須知的提示區塊）就會莫名失蹤。現在無論你怎麼自訂模型表格，原始公告都會安然保留在畫面上。

如同改裝車輛儀表板時，以前換上自選配件會把原廠的警示標籤蓋掉，現在換了儀表之後，關鍵的原廠提醒依然老老實實貼在上方。
新功能

檔案讀取、搜尋與替換工具更能應對超大與特殊檔案

請 AI 幫忙翻找或修改程式碼時，最怕遇到專案裡夾雜非純文字檔案導致工具直接卡死。

現在 read_file、search_replace 與 grep 遇到特殊檔案（例如系統管道或裝置捷徑）時更為穩定。面對超大檔案或二進位內容（binary content，非一般純文字的圖檔或編譯檔）時，也不容易突然當掉。就算真的無法讀取，工具也會直接給出清楚具體的錯誤訊息，不再丟出令人困惑的故障代碼。

彷彿圖書館的掃描機升級了感應器，以前塞進厚重字典或夾著相片的冊子會直接卡紙死機，現在不僅能順暢處理，遇到真的無法判讀的裝訂也會清楚顯示原因。
問題修復

工具呼叫更守規矩，取消單一操作不影響其他平行指令

放手讓 AI 查詢網路或同時執行多個動作時，你對背後工具的掌控度現在變得更加穩固。

就像派幾位助理分頭跑腿，需要額外花費的事項會停下來打電話請示你，而且你中途叫停其中一人，其他人依然會照常把各自手上的工作辦完。

現在只要替 WebSearch 與 WebFetch（負責搜尋與抓取網頁的工具）設定了詢問規則，它們一定會先跳出確認提示，不再擅自直接連網。當多個工具同時平行執行時，中途取消其中一項工具呼叫，其他平行呼叫所啟動的指令也不會跟著一起被殺掉。

新功能

登入後不再自動重試指令，遭拒絕的提示詞需手動重發

在終端機輸入問題卻因為尚未登入而被擋下時，完成驗證後的下一步現在完全交由你決定。

以前只要碰上需要登入的限制，被拒絕的提示詞（prompt，向 AI 發出的指令）在登入完成後常會自動重試。現在登入成功後它不會再擅自重新發送，只會把被擋下的登入區塊留著，需要你手動再次送出。

跟在辦公大樓換證一樣，剛才因為沒證件被保全擋下的人，換好證件後櫃檯不會擅自把你推進電梯，而是讓你確認好目的地後再自行前往。

English

FEATURE

/rewind only lists prompts you typed when rewinding conversations

When you want to scrap code changes halfway through and jump back to a previous step while pairing with AI, the history list in your terminal is no longer flooded with noise.

Think of flipping through meeting minutes: in the past, every page was cluttered with notes on equipment checks and battery swaps, but now only words attendees actually spoke remain, letting you spot the exact moment you want to revisit at a glance.

Previously, running /rewind to select a rollback point often displayed a list mixed with intermediate records that the system generated automatically in the background. Now, this command only lists prompts you typed yourself, skipping automatically generated execution turns entirely.

FEATURE

config.toml preserves original notice banners when configuring custom models

If you switch to or mount preferred models in your project configuration file, your terminal still displays official notices in full.

When configuring a custom model table in config.toml, you sometimes need to specify different model sources. Previously, filling in these custom details caused the terminal's notice banner to mysteriously disappear. Now, no matter how you customize the model table, the original announcement remains safely on screen.

Picture modifying a vehicle dashboard: previously, swapping in aftermarket accessories covered up factory warning labels, but now key manufacturer reminders stay firmly in place after changing the instruments.
FEATURE

File reading, search, and replacement tools better handle oversized and special files

When asking AI to search or modify code, the biggest fear is running into non-plain-text files in a project that freeze tools completely.

Now, read_file, search_replace, and grep are significantly more stable when encountering special files such as system pipes or device links. When facing oversized files or binary content, they are also far less likely to crash unexpectedly. Even if a file cannot be read, the tools now provide clear, specific error messages instead of throwing confusing failure codes.

A library scanner upgrades its sensors: previously, feeding in a thick dictionary or a booklet with photos caused paper jams and system crashes, but now it processes them smoothly and clearly shows the reason whenever a binding truly cannot be scanned.
BUGFIX

Tool calls follow rules more reliably, and canceling a single operation leaves other parallel commands unaffected

When letting AI search the web or run multiple actions simultaneously, your control over the underlying tools is now much firmer.

Imagine sending several assistants on separate errands: any task requiring extra expenses pauses to call you for approval, and stopping one assistant midway leaves the others to finish their respective jobs as usual.

Now, whenever you set prompt rules for WebSearch and WebFetch, they always show a confirmation prompt first instead of accessing the internet on their own. When multiple tools run in parallel, canceling one tool call midway will not kill the commands spawned by other parallel calls.

FEATURE

Commands no longer auto-retry after login, leaving rejected prompts to be resent manually

When a question entered in the terminal is blocked because you are not logged in, the next step after completing authentication is now entirely up to you.

Previously, whenever you hit a login requirement, rejected prompts often retried automatically once authentication finished. Now, it no longer resends anything automatically after a successful login; instead, it retains the blocked login prompt block, requiring you to submit it again manually.

Security badge exchanges at an office building follow the same logic: after someone stopped by security for lack of ID gets their visitor badge, the front desk does not shove them into an elevator, but lets them confirm their destination and head up on their own.
