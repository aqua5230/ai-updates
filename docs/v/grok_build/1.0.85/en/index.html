Grok Build 1.0.85

Released: 2026-11-13

Release notes

FEATURE

Terminal notifications now fire for questions and plan approvals

When running tasks in the background in your terminal, Grok sometimes pauses to wait for your answer or confirmation on the next step. Previously, permission requests sent terminal notifications; now question cards, MCP (a protocol that connects AI to external tools) input cards, and plan-approval cards send the same notification.

Think of waiting at a clinic: previously only the pharmacy counter called your number, and now the exam and checkup desks ring a bell to call you over too.
FEATURE

Search session contents as you type with /resume

When you want to pick up a conversation from a few days ago but forget its title, scanning the list alone can make it hard to find. Now, after opening the /resume picker, typing directly searches session conversation contents in real time, and you can open a match right away.

Picture flipping through an old notebook: instead of scanning page by page for a heading, you look up keywords inside the text and immediately pick up writing on that page.
FEATURE

Skills now expand passed argument variables in the body

You may have written a handy Skill (a reusable instruction template you can invoke) to help check files, yet each run needs a different target. Now, simply place ${ARGUMENTS} or ${ARGUMENTS[N]} in the skill body, and any arguments passed when invoking it will automatically expand into the text.

Sending out event invitations used to mean editing the name and time by hand on every card, whereas now you leave those blanks open and the matching details fill in automatically when sent.
FEATURE

Subagents hitting their turn limit now return work and wake the parent

When you hand a tedious task to a subagent (an assistant dispatched to handle work separately), the worst part is having it hit its limit halfway through with no word back. Now, once a subagent hits its turn limit, it returns the work it has done so far and wakes the parent agent that dispatched it.

Ask a coworker to look up some info: previously, when time ran out without them checking back in, you were left waiting at your desk, whereas now as soon as time is up they hand over what they gathered and wake you up.
FEATURE

Plugin counts and security hiding updates for grok inspect

Running grok inspect to inventory your project settings now includes hooks (small programs triggered by specific events) and MCP servers from inline plugins in the total count. When running grok inspect inside an untrusted folder, it now hides plugin hooks and LSP servers (language services that provide code hints and checks), matching a regular session.

FEATURE

Updates to slash command hints, selection, and error replies

Typing / in the input box to call a built-in command or Skill now brings new behavior for hints, selection, and typos. Slash command autocomplete now shows each command's argument hint after its name. Typing a full Skill name in the slash menu now reliably selects the exact match. Entering an unknown or disabled slash command now gets a direct reply instead of being sent to the model.

BUGFIX

Improvements to /skills list controls and Skill name display

To quickly pull up a specific tool in a conversation or tell at a glance in the terminal which one was just loaded, these usability details have been tuned. Adding a name after /skills now opens the Skills tab filtered to that name. Pressing Space in the /skills list now folds groups, and the filter label is no longer clipped. When reading a Skill, the terminal scrollback and shell titles now display its advertised name instead of its folder name. Skill-read titles keep this advertised name after a reload.

BUGFIX

Fixes for queuing, cancelling, and panel cleanup mid-turn

Sending a follow-up message, queuing a compaction, or hitting interrupt before the AI finished the current turn previously risked accidental drops or getting stuck. Follow-ups sent while the previous turn is still running are no longer dropped, even when that turn stops at its cap or on repeated tool calls. Pressing Ctrl+C a second time within one second now arms quit instead of cancelling the next queued prompt. A /compact queued while the previous turn was still running can now be cancelled directly with Ctrl+C. Running /rewind to step back the conversation now also cancels a compaction that is still summarizing. The stop panel now closes after the turn it belongs to finishes.

BUGFIX

Fixes for session titles and history preview display

Browsing past conversation logs or naming a session could occasionally run into gibberish symbols or fail to generate a title. Session titles no longer include raw color codes or control characters. The rename input and history previews also strip out raw color codes. Models that count reasoning against the output limit now finish generating session titles.

BUGFIX

Clearer line breaks and paragraphs in replies and headless output

When reading AI reply text or passing headless mode (an execution mode with no terminal window) output to another program, paragraphs used to clump into one big block. When using plain or json format in headless mode, output now starts a new paragraph after tool calls. Regular replies also preserve single newlines as line breaks instead of joining everything into one paragraph.

BUGFIX

Using --fork-session alone now starts a new session

When starting Grok in the terminal, passing only the --fork-session flag previously failed outright. Now using --fork-session on its own starts a new session.

BUGFIX

Double-clicking a thinking block selects text instead of collapsing

When trying to copy a word from the AI's thinking process, double-clicking often caused the entire block to suddenly collapse or expand. Double-clicking a thinking block now selects text instead of toggling its collapsed state.

FEATURE

Network-restricted sandbox profiles start on Mac with OrbStack

People running both container tools and a sandbox (an isolated execution environment) on the same computer may have previously seen certain sandbox profiles fail to start. Now, even with the container tool OrbStack installed on a Mac, network-restricted sandbox profiles can start normally.

BUGFIX

Fix dashboard dispatch box label for Enter key action

After selecting a row on screen, the adjacent hint text could previously mislead you as you prepared to submit it. Now, after selecting an item in the dashboard, the dispatch box accurately labels what pressing Enter will do.

BUGFIX

Unchanged plan-revision drafts no longer reappear after sending

If no text was edited before sending a plan-revision draft, that draft would pop back onto the screen afterward. This bug is fixed, and unchanged drafts no longer appear again after being sent.

BUGFIX

Clicking a hidden question-card answer no longer moves the caret

Accidentally clicking a collapsed section on screen previously caused the typing position to jump away. This issue is fixed, and clicking a hidden question-card answer no longer moves the caret.

BUGFIX

Dictation no longer starts a new recording while processing the last clip

Right after finishing a sentence, while the screen was still processing the previous audio clip, accidentally triggering recording again used to start capturing immediately. This issue is fixed, and dictation no longer starts a new recording while the previous clip is still processing.

BUGFIX

Fix grok update hanging while cleaning up old downloads

When running grok update in the terminal to update versions, the step that cleans up old downloaded files could occasionally stall. This issue is fixed, and cleaning up old downloads no longer hangs.

BUGFIX

Home-screen search no longer gets stuck on Searching after opening dashboard

After opening the dashboard from the home screen, the home-screen session search bar previously stayed stuck in the "Searching" state. This issue is fixed, and the search status no longer gets stuck on Searching.

BUGFIX

Tabs with failed session restores now refuse new prompts

After restarting the app, if a window failed to reconnect to its previous conversation, any message you typed and sent there used to vanish without a trace. Now, on a tab whose session failed to restore, the new prompt is explicitly refused rather than silently dropped.

FEATURE

Tool search rows now start with Search

When you see the AI looking up information in the conversation history, the lines for finding files and finding external features used to look inconsistent. Now tool search rows also start with Search, keeping the same format as file-search rows.

BUGFIX

Fix Grok pane repainting issues in tmux

When running Grok in a split screen using tmux (a tool that splits a terminal into multiple panes), the display previously failed to update properly after resizing in certain sequences. Now the panes repaint correctly under those operation sequences.
