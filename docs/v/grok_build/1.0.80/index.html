Grok Build 1.0.80

發布日期：2026-11-09

繁體中文

新功能

窄版終端機不再裁切按鈕與資訊

在筆電分割視窗或小窗格裡開 Grok Build，再也不用為了看全畫面一直拉寬視窗。 用量視窗不再把額度條和帳單網址切掉。 Read 標頭和影片疊加層面對窄版終端機與中日韓文字時，都能正常顯示。 Dashboard 預覽面板現在會秀出全部選項並留住輸入框，寬度在 40 到 43 欄時會改用精簡的工作階段列。 計畫審查的按鈕也能維持看得到、點得到。

就像小尺寸海報重新排版一樣，以前字句和聯絡方式常在邊緣被裁掉半截，現在把版面收緊，該有的資訊和按鍵都留在框裡。
新功能

按 Ctrl+E 後思考區塊會維持展開

寫企劃盯著 AI 一步步推論的過程，看到關鍵處最怕展開的畫面突然自己收起來。 現在按下 Ctrl+E 展開全部後，思考區塊（模型在正式回答前顯示推理步驟的區域）在串流輸出期間都會維持展開狀態。

打開白板旁的演算筆記看老師解題，以前剛掀開看兩眼，筆記本就自己闔回去，現在攤開後會一路平放到底。
新功能

網頁抓取失敗展開後會顯示實際原因

請 AI 幫忙查一份線上報價單，結果卻沒讀到東西，最想知道的就是到底哪裡卡住。 現在網頁抓取失敗後，只要把該筆紀錄展開，畫面上就會列出實際的錯誤原因。

好比寄掛號信被退件，以前信封上只蓋個「投遞失敗」的章，現在翻開背面附條，就能看清是因為地址寫錯還是沒人簽收。
問題修復

Shift 拖曳複製不再多帶行尾方塊字元

把終端機裡的幾段分析複製貼到筆記本，偶爾會發現每行尾巴都黏著多餘的東西。 在捲軸旁邊按住 Shift 拖曳選取文字並複製時，現在每行結尾不會再多帶一個方塊字元。

撕下牆面膠帶時，以前邊緣總會勾著一絲殘膠一起掀起來，得另外用手摳掉，現在從頭拉到尾都是平整的一條。
問題修復

終端機貼上大段文字不再停頓好幾秒

整份會議記錄或長篇文章貼進對話框準備請 AI 處理，畫面卻突然停住沒辦法繼續操作。 現在就算用的是不支援 bracketed-paste（讓終端機分辨整段貼上與手動打字的功能）的終端機，貼上大段文字也不會再卡住好幾秒。

把整疊發票放進點鈔機時，以前沒有分批標記就得一張張慢吞吞重算，現在即使少了那道標記，機器也能順暢吞進去。
新功能

Linux 在匯流排慢或 Kitty 無回應時啟動更快

Linux 使用者打開 Grok Build，有時還沒看見輸入畫面就得停在原地等著啟動。 現在遇到 system bus（Linux 系統內部傳遞訊息的通道）反應慢或沒有回應時，啟動速度會變得更快。 換成支援 Kitty 規格的終端機時，就算它一直沒回應鍵盤協定查詢（用來確認進階按鍵支援的詢問），啟動同樣變得更快。

搭電梯上班時，以前大廳感應器慢半拍或門禁機沒應聲，整台車就停著不動，現在這兩種狀況下開門起步都會快上不少。
新功能

Grep 與 10 項以上編號清單排版對齊

對照終端機裡的長清單或表格欄位，只要多縮進一格，整排字就會跟著錯位。 Grep（在檔案裡搜尋文字的工具）的結果現在會把 Tab 字元顯示成空白格，讓直欄能正確對齊。 工作流程階段和工具搜尋裡的編號清單，在項目達到 10 項以上時也能正常對齊。

排電影院座位表時，以前只要中間空位寬度沒算準，後面的號碼就跟著歪掉，現在每一格都按固定寬度留白，從頭到尾都能對成一直線。
新功能

舊版 Windows 主控台待辦與捲動字元正常顯示

仍在使用舊版 Windows 主控台的人，現在看操作進度與歷史紀錄不用再擔心畫面出狀況。 還沒處理完的待辦事項，在舊版主控台上已經能正確顯示。 往回捲動查看舊輸出時，畫面上的字元符號也都能正常繪製出來。

拿舊款印表機印新表格時，以前欄框和字跡常有漏印，現在整張紙上的項目與符號都能清楚印出來。

English

FEATURE

Narrow terminals no longer clip buttons and info

When opening Grok Build in a split laptop window or a small pane, you no longer have to keep widening the window just to see the whole screen. The Usage modal no longer clips the credit bar or billing URL. Read headers and video overlays now display properly on narrow terminals and with Chinese, Japanese, and Korean text. Dashboard peek now shows all options and keeps the input box visible, switching to compact session rows at 40 to 43 columns. Plan review buttons also stay visible and clickable.

Picture re-laying out a small poster: words and contact details used to get cut off at the edges, but tightening the layout keeps all the info and buttons inside the frame.
FEATURE

Thinking blocks stay expanded after pressing Ctrl+E

When writing a proposal and watching the AI reason step by step, the last thing you want at a key moment is for the expanded view to collapse on its own. Now, after pressing Ctrl+E to expand all, thinking blocks (the area where the model shows its reasoning steps before the final answer) stay expanded while streaming.

You open a scratchpad next to the whiteboard to watch a teacher solve a problem—before, the notebook would snap shut after a quick glance, and now it stays flat open all the way through.
FEATURE

Failed web fetches show the actual reason when expanded

When you ask the AI to check an online quote and it reads nothing back, what you want to know most is where it got stuck. Now, when a web fetch fails, expanding that entry lists the actual error reason on screen.

A returned registered letter used to bear only a "Delivery failed" stamp on the envelope, whereas flipping to the slip on the back now shows whether the address was wrong or nobody signed for it.
BUGFIX

Shift-drag copy no longer adds a trailing block character

When you copy a few paragraphs of analysis from the terminal into your notes, you occasionally find extra clutter stuck to the end of every line. When you hold Shift and drag to select and copy text beside the scrollbar, each row no longer carries an extra block character at the end.

Peeling tape off a wall used to snag a stray bit of residue along the edge that you had to pick off by hand, while now it pulls off in one clean strip from start to finish.
BUGFIX

Large terminal pastes no longer stall for seconds

You paste a full meeting transcript or long article into the chat box for the AI to process, and the screen suddenly freezes so you cannot keep working. Now, even if you use a terminal that lacks bracketed-paste (a feature that lets terminals tell a whole-block paste apart from manual typing), pasting large text no longer stalls for many seconds.

Feeding a stack of receipts into a counter without a batch marker used to force it to recount them slowly one by one, and now it takes the whole stack smoothly even without that marker.
FEATURE

Faster Linux startup when system bus is slow or Kitty is unresponsive

Linux users opening Grok Build sometimes have to sit and wait for startup before even seeing the input screen. Now, startup is faster when the system bus (the internal channel Linux uses to pass messages) is slow or unresponsive. On a Kitty-capable terminal, startup is also faster even when it never answers the keyboard protocol query (a check for advanced key support).

Taking an elevator to work used to leave the cab sitting still whenever the lobby sensor lagged or the badge reader stayed silent, whereas now it opens and gets moving much faster in both cases.
FEATURE

Grep and 10+ numbered lists align properly

When scanning a long list or table columns in the terminal, a single extra indent throws the whole row out of alignment. Results from Grep (a tool for searching text in files) now display tab characters as spaces so columns line up correctly. Numbered lists in workflow phases and tool search also align properly when there are 10 or more items.

Laying out a movie theater seating chart used to skew every number behind a miscalculated aisle gap, and now each slot reserves a fixed width so the whole row stays in a straight line.
FEATURE

Pending todos and scrollback glyphs render on legacy Windows consoles

Anyone still using a legacy Windows console no longer has to worry about display glitches when checking progress and history. Pending todos now render correctly on legacy Windows consoles. Scrollback glyphs also render properly when scrolling back through earlier output.

Printing a new form on an older printer used to leave missing borders and faint marks, but now every item and symbol on the page prints out clearly.
