Grok Build 1.0.64

發布日期：2026-10-19

繁體中文

新功能

未受信任資料夾限制執行掛鉤，無頭模式預設信任個人設定

從網路下載開源專案或開啟陌生目錄時，潛在的腳本可能藉由自動化流程悄悄啟動。在未受信任的資料夾中，只會執行所屬組織集中管理的掛鉤（特定事件發生時觸發的小程式）。

進駐管制嚴密的企業園區，以前未經認證的訪客攜帶自備隨身碟就能隨意運作，現在櫃台只允許使用公司統一配發的儲存設備，個人的自訂工具一律扣留，直到取得正式擔保才准啟用。

專案、外掛、代理人與使用者自訂的掛鉤都會暫停，直到你手動確認信任該資料夾。若是在無頭模式（沒有終端機視覺介面的執行模式）下啟動工作階段，使用者個人掛鉤則會預設為受信任，兼顧自動化腳本的執行彈性。

新功能

自動模式指令完全比對允許清單，常用編譯版本查詢免確認

開啟自動模式讓 AI 自主執行終端機指令時，安全邊界有了更嚴密的審查機制。

穿過海關的快速查驗通道，以前整批行李貼著免檢標籤便直接放行，現在查驗員逐件核對包裝清單，只要夾帶一項未申報物件就必須停下開箱，只有附帶原廠說明的標準樣品才能直接過關。

在自動模式（Auto mode）下，只有當整段指令中的每一個指令都符合允許清單時才會直接執行，其餘任何指令都會先向你確認。權限規則在解析時，會比照 bash 傳遞參數給程式的方式逐字讀取每個單詞，確保指令拆分與實際執行完全一致。為了不打斷工作節奏，查詢編譯工具版本的 make --version、cmake --version 與 just --version 已預設允許直接執行，不必手動確認。

新功能

沙盒禁用工作樹時預先隱藏選項，指令操作直接回絕

身處受限的沙盒環境開發專案，不符權限的進階功能現在會更早被辨識並阻擋。

走進主題樂園的遊樂設施，以前限制身高的項目依然排在推薦看板上，排到入口才被工作人員勸退；現在導覽螢幕會先隱藏不符規定的項目，若直接持通行證感應，閘門也會當場顯示限制說明。

當沙盒設定檔不允許建立工作樹（Git 讓同一專案平行開多份副本的功能）時，介面與指令會同步連動。在 /fork、/new 與歡迎畫面中，建立工作樹的選項會隱藏。如果你手動執行 grok -w、grok worktree create，或是發起工作樹分叉與子代理工作樹，指令會在第一時間直接回絕，並明確顯示沙盒拒絕訊息。

問題修復

工作樹命名支援萬國碼字元，防範重名並修正檔案排除規則

利用工作樹（Git 平行開多份專案副本的功能）切換任務時，命名檢驗與檔案追蹤邏輯迎來一系列完善。

檢索檔案室裡的分類公文夾，以前標籤上的外文重音符號常被系統抹除，遇上重名還會自動亂加尾綴編號；現在系統忠實保留外文字元，一旦重名便立刻提醒，手動清空的舊編號也能重新指派。

使用 Ctrl+W 輸入工作樹名稱時，現在會完整保留如 café 這類萬國碼字元；若名稱或參照以減號 - 開頭，或是名稱已被占用，系統會直接拒絕建立，不再擅自附加數字後綴。先前若手動刪除了工作樹資料夾，其名稱現在也能重新使用。 新工作樹納入檔案時，只要檔案已受版本追蹤，即使符合 .gitignore 規則依然會保留；若檔案僅被 .git/info/exclude 或全域 core.excludesFile 排除，則會排除。

問題修復

恢復指令支援自動載入更多對話，啟動失敗保留已輸入文字

在不同工作階段（session，指與 AI 互動的獨立對話流程）之間切換或開啟新任務，操作體驗有了更貼心的防護。

查閱檔案櫃中的活頁備忘錄，以前翻到夾層底部就無法再看更早的紀錄，抽換新活頁時若卡住，剛寫下的文字還會整頁遺失；現在翻到底端會自動接續附上舊紀錄並註明已展開數量，抽換新頁失敗時也會把原稿完整退回。

以往輸入 /resume 挑選歷史對話時，畫面只會列出固定筆數；現在只要捲動到選單最後一列，系統便會自動載入更早以前的工作階段，並清楚顯示目前已載入的總數量。如果你嘗試開啟新工作階段卻不幸啟動失敗，先前在輸入框中打好的一長串文字不會遺失，而是會如實還原到返回後的輸入提示列中，方便你直接重試或修改。

新功能

HTTP 連線與遠端 MCP 伺服器可接受四種壓縮回應

AI 藉由網路呼叫遠端伺服器或外部擴充時，對方回傳的資料可能採用壓縮格式。

收發跨國快遞包裹，寄件方可以用不同方式壓縮包裹體積，收件窗口則需要備有對應的拆包工具；現在窗口能接收四種指定包裝，不必要求寄件方一律使用同一種。

現在所有的 HTTP（網路傳送請求與回應的通訊規則）連線，都能接收 gzip、brotli、zstd 與 deflate 這四種格式的壓縮回應。這也包含遠端 MCP（Model Context Protocol，讓 AI 連接外部工具的協定）伺服器在內。

新功能

停用外掛設定生效時，輸入框上方不再顯示安裝推薦

專注在終端機中編寫程式碼時，輸入框上方不時跳出的擴充推薦容易打斷輸入視線。

租用專注工作的獨立隔音艙，以前牆面上總貼滿各類器材租借與升級服務的推銷傳單；現在只要登記免打擾模式，艙內便只保留工作檯燈，任何周邊服務的宣傳單一律清空。

當你指定 disable_plugins = true 後，輸入提示列上方就不會再主動跳出任何外掛安裝建議，讓終端機視野始終保持乾淨集中。

新功能

網路搜尋支援外部登入首輪查詢，自訂模型對話不再中斷

請 AI 透過網路搜尋即時資料時，外部帳號驗證與模型介面的穩定性獲得了重要修正。

撥打專業機構的諮詢專線，以前透過外部機構代為驗證身分時，第一通電話或交由助理轉接都會連線失敗，總機遇到查詢空檔還會直接切斷；現在系統一撥通就能立刻聯網查詢，即使訊號暫時沒有動作也會保持通話繼續進行。

當搜尋模型使用外部驗證提供者登入時，現在從工作階段（指與 AI 互動的獨立對話流程）的第一輪對話開始，以及在指派的子代理中，網路搜尋功能都能正常運作。在 Responses API 上呼叫自訂模型時，若網路搜尋呼叫在啟動時未帶有任何動作，對話輪次現在會保持繼續進行，避免流程意外中斷。

問題修復

修復遠端連線按鍵檢查卡死，相容 zsh 啟動設定別名

透過遠端終端機連線或使用自訂 Shell 配置，特殊執行環境的相容度迎來關鍵修復。

調度偏遠觀測站的自動望遠鏡，以前透過純文字終端遠端連線時，只要一偵測控制面板按鍵狀態就會無預警停擺，自訂的輔助快速鍵更會干擾觀測指令；現在控制程式能正確適應無螢幕的遠距連線，即使技術員設定了專用簡稱，所有排程指令也能準確執行。

在沒有圖形介面工作階段（例如透過 SSH 登入）的 macOS 上執行 Grok 時，系統不再於第一次檢查輔助按鍵時卡死。若你的 zsh 啟動設定檔為 grep 建立了別名，或是替換了系統內建的 run-help 說明函式，終端機執行各項 shell 指令時現在都能正確執行，確保個人化工作環境不受干擾。

新功能

語音聽寫預覽隨說話動態展開，最新字詞始終保持在視野內

習慣對著麥克風用說話方式指派工作，語音輸入的文字呈現迎來了全新調整。

速記員在長捲軸打字機上記錄發言，以前紙捲卡在固定窗口，打字員得頻繁手動拉紙才能確認剛剛打出的段落；現在紙捲會隨著敲擊即時平順延伸，剛印出的文字始終落在最醒目的對焦線中央。

現在使用語音聽寫（Voice dictation）時，輸入框內的預覽文字會隨著你開口說話即時增長展開，並始終將最新辨識出的單詞保持在可視範圍內。當你正在整理複雜思路、連續說出一長串需求時，目光再也不必在輸入欄位中來回搜尋，只要盯著最新出現的語句，就能確認語音辨識是否精確，省去手動向下捲動查看的麻煩。

FEATURE

Untrusted Folders Restrict Hook Execution, While Headless Mode Trusts Personal Settings by Default

When downloading open-source projects from the internet or opening unfamiliar directories, potential scripts might trigger quietly through automated workflows. In untrusted folders, only managed hooks (small programs triggered by specific events) from your organization will run.

Entering a tightly guarded corporate campus, unverified visitors once operated freely with personal flash drives, but now the front desk only permits company-issued storage devices, holding all personal custom tools until formal clearance is granted.

Project, plugin, agent, and user custom hooks wait until you manually confirm that you trust the folder. If you start a session in headless mode (an execution mode without a terminal visual interface), personal user hooks are treated as trusted by default, preserving execution flexibility for automated scripts.

FEATURE

Auto Mode Matches Commands Strictly Against Allowlists, Skipping Confirmation for Common Compiler Version Checks

When enabling Auto mode for AI to run terminal commands autonomously, the security boundary gains a stricter review mechanism.

Picture an express customs inspection lane: entire batches of luggage once cleared directly with inspection-exempt tags, but now inspectors verify every item against the packing list, stopping to open any box carrying an undeclared item, while waving through only standard samples backed by manufacturer documentation.

In Auto mode, a shell command runs without review only when every command in it matches an allowlist entry, and anything else asks you first. Permission rules read each word the way bash passes arguments to a program during parsing, ensuring that command splitting matches actual execution exactly. To avoid interrupting workflow, querying compiler versions with make --version, cmake --version, and just --version is now allowed to run directly by default without manual confirmation.

FEATURE

Options Are Hidden When Sandboxes Disallow Worktrees, with Commands Refused Up Front

When developing projects inside a restricted sandbox environment, advanced features that exceed permissions are now identified and blocked earlier.

At a theme park attraction, height-restricted rides once remained on the recommendation board, turning guests away only after they queued to the entrance; now guide screens hide ineligible rides in advance, and tapping a pass at the turnstile immediately displays the restriction notice.

When a sandbox profile does not allow creating a worktree (a Git feature that lets a single project run multiple copies in parallel), the interface and commands respond in tandem. Worktree options are hidden in /fork, /new, and the Welcome screen. If you manually run grok -w or grok worktree create, or initiate worktree forks and subagent worktrees, the commands refuse up front and clearly display the sandbox refusal message.

BUGFIX

Worktree Naming Supports Unicode Characters, Prevents Duplicates, and Fixes File Exclusion Rules

When switching tasks using a worktree (a Git feature that lets a project run multiple copies in parallel), naming validation and file tracking logic receive a series of refinements.

Think of searching through categorized document folders in an archive: foreign accent marks on labels were once stripped away and duplicate names triggered random numbered suffixes; now the system faithfully retains foreign characters, alerts you immediately upon a naming conflict, and lets you reassign previously discarded numbers.

Worktree names typed with Ctrl+W now fully keep Unicode letters such as café; if a name or ref starts with a minus sign -, or if the name is already taken, the system refuses creation directly instead of attaching a numbered suffix. If you previously deleted a worktree folder by hand, its name can now be used again. When a new worktree brings in files, tracked files that match .gitignore rules are still kept; files excluded only by .git/info/exclude or global core.excludesFile are left out.

BUGFIX

Resume Command Automatically Loads Older Sessions, and Preserves Typed Input on Launch Failure

Switching between different sessions (independent conversation flows for interacting with AI) or launching new tasks now comes with more thoughtful safeguards.

Inside a filing cabinet of loose-leaf memos, flipping to the bottom previously prevented viewing older records, and a snag while inserting a new page would lose everything just written; now reaching the bottom automatically appends earlier records with a count of loaded entries, and a failed page insertion returns the original draft intact.

Previously, entering /resume to pick from past conversations listed only a fixed number of entries; now, reaching the last row of the menu automatically loads older sessions and clearly shows how many sessions are currently loaded. If you attempt to start a new session and it fails to launch, what you typed in the input box is not lost, but returned to the prompt you return to so you can easily retry or make edits.

FEATURE

HTTP Connections and Remote MCP Servers Accept Four Compressed Response Formats

When an AI calls remote servers or external extensions over the network, incoming data may arrive in compressed formats.

When handling international courier parcels, senders could compress package volume using various techniques while the receiving desk needed matching unpacking tools; now the counter accepts four designated packaging types without forcing every sender to use the exact same one.

Now all HTTP (communication rules for sending network requests and responses) connections can accept compressed responses in gzip, brotli, zstd, and deflate formats. This includes remote MCP (Model Context Protocol, a protocol that lets AI connect to external tools) servers as well.

FEATURE

Setting Plugin Disabling Turns Off Installation Suggestions Above the Prompt

When focusing on writing code in the terminal, extension recommendations that pop up above the prompt can easily break your concentration.

Imagine a rented soundproof focus booth: walls were once plastered with flyers advertising equipment rentals and service upgrades; now registering for do-not-disturb mode leaves only the desk lamp lit, clearing away all promotional flyers for peripheral services.

Once you set disable_plugins = true, plugin install suggestions will no longer appear above the prompt, keeping your terminal view clean and focused.

FEATURE

Web Search Supports First-Turn Queries with External Logins, and Custom Model Turns Keep Going

When asking AI to search the web for real-time information, the reliability of external account authentication and model interfaces receives key fixes.

Dialing a specialized consultation hotline, authenticating through an outside agency previously failed on the first call or when forwarded to an assistant, and the switchboard hung up during query pauses; now dialing connects instantly to online lookup, and the call stays active even when a signal is temporarily idle.

When the search model signs in through an external auth provider, web search works from the first turn of a session (an independent conversation flow for interacting with AI), as well as in assigned subagents. When calling custom models on the Responses API, if a web search call starts without an action, the conversation turn now keeps going to avoid unexpected interruptions.

BUGFIX

Remote Key Check Freezes Are Fixed, with Support for zsh Startup File Aliases

Connecting over a remote terminal or using custom Shell configurations brings critical compatibility fixes for specialized environments.

Managing an automated telescope at a remote observatory, connecting over a text-only terminal previously froze without warning during control-panel key detection, while custom shortcut keys disrupted observation commands; now the control software smoothly handles display-free remote links, executing all scheduled instructions accurately even with technician-defined shorthand.

Running Grok on macOS without a GUI session (such as when logging in over SSH) no longer hangs on its first modifier-key check. If your zsh startup files alias grep or replace the built-in run-help helper function, terminal execution of shell commands now runs correctly, ensuring personalized work environments remain uninterrupted.

FEATURE

Voice Dictation Preview Expands Dynamically as You Speak, Keeping Newest Words in View

For those accustomed to assigning tasks by speaking into a microphone, the text display for speech input receives a brand-new update.

A stenographer recording remarks on a continuous scroll typewriter was once constrained by a fixed window, requiring constant manual paper pulling to review typed passages; now the scroll unrolls smoothly in real time with each keystroke, keeping newly printed words centered on the primary focus line.

When using Voice dictation, the preview text inside the prompt grows dynamically as you speak, keeping the newest recognized words continuously in view. As you organize complex thoughts and dictate a long series of requests, you no longer have to scan back and forth across the input field; tracking the newest incoming phrases lets you verify speech recognition accuracy without the hassle of manually scrolling down.
