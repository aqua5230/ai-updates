Grok Build 1.0.90

發布日期：2026-11-18

繁體中文

新功能

/mcps 會顯示雲端連接器區且能重選權限

還沒接上任何雲端服務，打開 /mcps（設定讓 AI 連接外部工具的協定介面）現在就看得到雲端連接器區塊。想替已經連上的雲端連接器重新驗證並挑一組新權限，只要先按 i 再按 y 就能重跑授權。

就像還沒裝任何外掛前，手機設定裡就先把空位留給你看；之後想改開放的權限，也不必刪掉重綁，直接重選就好。
問題修復

沙盒設定失敗改明確回報且支援 ~ 路徑

設定沙盒（隔離程式執行範圍的安全區）如果出錯，過去會安靜失敗，讓人無從查起。現在這些失敗都會直接顯示在歡迎畫面、標準錯誤輸出 stderr，還有 /doctor 檢查結果裡。 寫在允許路徑設定裡的 ~ 符號，現在會自動展開成你的家目錄路徑。要是在 sandbox.toml 寫了工具不認得的設定鍵，也會直接當成錯誤回報。

開長途時引擎燈以前壞了都不會亮，等於蒙眼開上路；現在只要零件異常或填錯規格，儀表板立刻亮燈提醒你哪裡有問題。
新功能

Grok Build 儲存與清除設定更乾淨

在設定畫面改好選項並儲存，現在只會把你改過的欄位寫進 config.toml。要是把某個設定清空，config.toml 裡對應的設定鍵也會跟著刪掉。

跟批改考卷一樣，老師只用紅筆修改寫錯的那兩題，不會把整張考卷重新抄一遍；確定不要的條目就用立可白擦乾淨，不留空白格。
問題修復

無頭模式 --continue 的清單缺漏提示更明確

在無頭模式（沒有終端機視窗或視覺介面的執行模式）跑 --continue，過去本機工作階段清單確定缺漏時，畫面總會叫你重試。現在它會給出更清楚的錯誤說明，不再一律建議你重複嘗試。

包裹確認已經遺失時，過去查詢頁面還是照樣叫你稍後再試；現在客服會老實說明哪裡缺了資料，不再讓你一直重按查詢。
新功能

worktree 分岔保留原本的工作階段標題

你拉一條 worktree（Git 讓同一專案平行開多份副本的功能）出來做實驗時，來源工作階段可能剛好被改了名稱。現在就算來源工作階段在建立途中被改了名稱，新分岔出來的副本仍會保留原本的標題。

拿雙胞胎登記名字來比方，哥哥在報戶口中途臨時改了小名，弟弟的證件上還是會印著原本取好的名字。
新功能

目標模式連 3 輪無進展會說明暫停原因

把任務交給 Goal 自動執行，有時它會因為連續 3 個回合推不動而自己停下來。現在目標模式暫停後，畫面上會直接說明它自己停下來的原因。

以前洗衣機轉到一半突然停機，面板只亮一個靜止符號；現在停下來會順便顯示「排水孔卡住」，不必自己拆開猜。
新功能

模型被移除時工作階段自動改用其他模型

挑好一個 AI 聊到一半，手邊的可用清單偶爾會突然把你正在用的選項拿掉。遇到這種情況，這個工作階段（正在進行的一輪對話任務）現在會自動切換成其他模型。

本來約好使用的會議室臨時撤銷，大樓櫃檯直接幫這場會議換進另一間還能用的房間。
新功能

登入與帳號識別後自動套用權限並收起條款提示

遇到登入反應比較慢的情況，帳號、方案等級與存取權限就算在啟動完成後才送達，現在依然會完整套用。 等辨識出對應的帳號後，原本顯示在畫面上的服務條款提示也會自動消失。

去醫院掛號如果資料慢一步才連線成功，櫃檯人員現在收到健保卡資訊就會直接更新你的看診資格，不會因為開診時沒讀到就作廢。
新功能

舊對話與 /compact 結果先於新提示顯示

恢復較長的工作階段，先把提問放進排隊佇列裡，畫面上現在會先把較早之前的歷史紀錄顯示出來，接著才送出排隊中的提示。 執行 /compact 壓縮對話期間如果已經接著打下一句提示，壓縮完成的那一行結果現在也會排在你新打的提示前面，不會倒過來插在後面。

寫筆記時還沒翻回上一頁確認內容，新寫的備忘卻先插到前面會讓人看混；現在先把前文或總結墊在前面，後寫的話才接在底下。
問題修復

子代理回覆顯示與訊息送出規則修正

在主畫面與子代理（協助分擔任務的分身代理）來回傳訊，回覆位置、標記寫法與斜線文字的處理方式都做了調整。 在子代理卡片上選 No 並附上文字回覆後，子代理的回應現在會顯示在主聊天室裡。 排隊等待送給子代理的訊息，過去會帶著排隊標籤和前後引號，現在這些多餘標示都拿掉了，標記文字改成顯示 read-only。 在子代理檢視畫面輸入長得像斜線指令的備註文字，以前會被拒絕送出，現在會當成一般純文字照常傳送。

問題修復

已停止的背景任務與 Shell 狀態顯示更準確

因為離開工作階段而中斷的背景任務，現在在狀態上都會明確標記為 cancelled。 對於已經停止運作的 Shell，任務窗格以前還會繼續顯示一個憑空生出的執行時間。這個錯誤已經修好，Shell 結束後不會再出現假時長。

問題修復

終端機輸入末行游標與 Tab 選中項不再消失

在提示輸入列一直打字直到填滿最後一行，輸入游標以前會突然不見，打字時找不到落點。這個問題已經修好，填滿最後一行時游標依然會正常顯示。 把終端機視窗縮得很矮時，按 Tab 叫出的補全清單以前會把目前選中的那一項遮住。現在即使在很矮的終端機視窗裡，選中的項目也不會再被藏起來。

問題修復

修正 LaTeX 數學公式括號與直線符號顯示錯誤

在對話裡讀寫數學算式，過去碰到部分特殊排版語法常會渲染失敗。現在這類 LaTeX 數學公式已經修好，成對的直線符號、\middle 分隔指令以及角括號都會正常顯示。

問題修復

移除本機提問卡片上多餘的自由輸入框

互動過程跳出問題要你回覆，畫面裡以前會附帶一格根本派不上用場的打字欄。現在這張本機提問卡片已經拿掉這個多餘的自由輸入框，畫面上不會再看到它。

新功能

Dashboard 彈窗鎖定焦點且擋下 Ctrl+\

打開 Dashboard 的彈跳視窗或挑選器後，鍵盤焦點現在會一直留在視窗內，直到視窗關閉為止。在關閉前如果按下 Ctrl+\，彈窗和挑選器也會直接攔截這個按鍵，不會傳到外層畫面。

問題修復

修正 Apple Terminal 的 Dashboard 列反白

在 Apple Terminal 裡開啟 Dashboard 瀏覽清單，每一列的反白高亮以前無法正常顯示出來。這個問題已經修好，現在在 Apple Terminal 裡看 Dashboard，列反白都能正常繪製。

English

FEATURE

/mcps shows hosted connectors section and lets you re-select permissions

Even before you connect any cloud services, opening /mcps (the interface for configuring the protocol that lets AI connect to external tools) now shows the hosted connectors section. To re-authenticate a connected hosted connector and pick a fresh set of permissions, just press i and then y to run authorization again.

Picture your phone settings leaving a placeholder slot visible before you install any plugins, and letting you change granted permissions later by re-selecting them directly instead of deleting and re-linking.
BUGFIX

Sandbox setup failures are reported clearly and support ~ paths

When configuring a sandbox (a safe zone that isolates where programs run) went wrong, it used to fail silently and leave you with no way to investigate. Now these failures appear directly on the welcome screen, in stderr, and in /doctor check results. A ~ symbol written in allow path settings now automatically expands to your home directory path. If you write an unrecognized setting key in sandbox.toml, it is also reported directly as an error.

On a long drive, a broken check-engine light used to leave you driving blind, whereas now the dashboard lights up right away to tell you where the problem is whenever a part acts up or a spec is entered wrong.
FEATURE

Grok Build saves and clears settings more cleanly

After changing options on the settings screen and saving, only the fields you modified are now written to config.toml. If you clear a setting, its corresponding key in config.toml is deleted as well.

Like a teacher grading an exam, the red pen only corrects the two wrong answers instead of rewriting the whole sheet, and unwanted entries are whited out cleanly without leaving blank boxes.
BUGFIX

Headless --continue gives clearer messages for incomplete lists

When running --continue in headless mode (running without a terminal window or visual interface), the screen used to always tell you to retry when the local session list was confirmed incomplete. Now it gives a clearer error explanation instead of always suggesting you try again.

When a package was confirmed lost, the tracking page used to still tell you to try again later, whereas customer support now honestly explains what information is missing instead of making you keep hitting search.
FEATURE

Worktree forks preserve the original session title

When you spin up a worktree (a Git feature for opening multiple parallel copies of the same project) to run an experiment, the source session might happen to be renamed. Now even if the source session is renamed while being created, the newly forked copy still keeps the original title.

Think of registering twins: even if the older brother switches to a new nickname halfway through the paperwork, the younger brother's documents still print the name chosen originally.
FEATURE

Goal mode explains why it paused after 3 rounds without progress

When you hand a task to Goal for automatic execution, it can sometimes stop on its own after 3 consecutive rounds without progress. Now when Goal mode pauses, the screen directly explains why it stopped itself.

A washing machine used to stop mid-cycle with only a pause symbol on the panel, but now it also displays "drain clogged" when it stops so you do not have to take it apart to guess.
FEATURE

Sessions switch to another model when theirs is removed

Midway through chatting with a chosen AI, the available list can occasionally drop the option you are using. When this happens, the session (an ongoing round of conversation) now automatically switches to another model.

Suppose a booked meeting room is suddenly canceled, and the building front desk moves the meeting straight into another available room.
FEATURE

Permissions apply and terms notice hides after sign-in and account match

When sign-in responds slowly, your account, plan tier, and access permissions are now still fully applied even if they arrive after startup finishes. Once the matching account is identified, the terms of service notice shown on screen also disappears automatically.

At a hospital check-in, if the connection is slow and your records arrive a step late, the front desk staff now update your visit eligibility as soon as your health card info comes through instead of voiding it because it was not read at opening time.
FEATURE

Older history and /compact outcome appear before new prompts

When resuming a longer session with prompts already placed in the queue, the screen now displays the older history first before sending the queued prompts. If you already typed the next prompt while running /compact to compress the conversation, the outcome line from the compaction now also appears ahead of your newly typed prompt instead of getting inserted after it.

Imagine taking notes where a new memo gets inserted ahead of the previous page before you have checked it, which confuses the reader; now the earlier context or summary is placed first, and what you wrote later follows underneath.
BUGFIX

Subagent reply display and message sending rules fixed

When exchanging messages between the main screen and a subagent (a helper agent that shares the workload), the reply location, marker wording, and handling of slash text have all been adjusted. After selecting No with a text reply on a subagent card, the subagent's response now appears in the main chat. Messages queued for a subagent used to carry a queued label and surrounding quotes, which have now been removed, and the marker text now reads read-only. Entering note text that looks like a slash command in a subagent view used to be refused, but it is now sent as ordinary plain text as usual.

BUGFIX

More accurate status for stopped background tasks and Shells

Background tasks interrupted by leaving a session are now explicitly marked as cancelled in their status. For a Shell that has already stopped running, the tasks pane previously continued to show an invented duration. This bug is fixed, so a fake duration no longer appears after a Shell ends.

BUGFIX

Terminal input last-row caret and Tab selection no longer disappear

When typing in the prompt input line until the last row is full, the input caret previously vanished suddenly, leaving no visible spot while typing. This issue is fixed, so the caret still displays normally when the last row is filled. When the terminal window is shrunk very short, the completion list opened with Tab previously covered the currently selected item. Now, even in a very short terminal window, the selected item is no longer hidden.

BUGFIX

Fix LaTeX math bracket and vertical bar rendering errors

When reading or writing math expressions in a conversation, certain special formatting syntax previously often failed to render. These LaTeX math formulas are now fixed, so paired vertical bars, the \middle delimiter command, and angle brackets all display properly.

BUGFIX

Remove extra free-text input on local question cards

When a question popped up for your reply during an interaction, the screen previously included a typing field that served no purpose. This local question card has now removed that extra free-text input, so it no longer appears on screen.

FEATURE

Dashboard modals lock focus and block Ctrl+\

After opening a Dashboard modal or picker, keyboard focus now stays inside the window until it is closed. If Ctrl+\ is pressed before closing, the modal and picker also intercept that key directly so it does not pass through to the outer screen.

BUGFIX

Fix Dashboard row highlights in Apple Terminal

When opening Dashboard to browse lists in Apple Terminal, the highlight for each row previously failed to display properly. This issue is fixed, so row highlights render normally when viewing Dashboard in Apple Terminal.
