Grok Build 1.0.78

發布日期：2026-11-06

繁體中文

新功能

`@` 檔案標籤能原地修改並支援新寫法

想請 AI 讀某個檔案卻不小心選錯，現在不用急著刪掉重來。用 @ 插入的檔案標籤（輸入框裡那塊標示目標的小方塊）可以直接在原地修改，手動打 @~/ 開頭的路徑也會自動對應到你的家目錄。 想指明特定行數或帶入隱藏檔，現在也支援在結尾加上 :N 行號後綴，以及用 @!hidden 語法點名隱藏檔。

就像在手機地圖設定目的地，以前打錯字得整格清空，現在能直接在欄位裡改字，還聽得懂捷徑、樓層和暗門。
新功能

依安裝方式改善 `grok update` 更新指引

想幫手上的 Grok 升級或切換更新頻道，結果常取決於你當初怎麼安裝它。如果你的 bin/grok 是透過 npm（JavaScript 套件管理工具）裝的，現在執行 grok update --channel 會直接跳出清楚的錯誤訊息與後續步驟。 改用 Homebrew cask（macOS 常用的軟體安裝工具）安裝的話，grok update 和切換頻道功能現在都能正常運作，畫面上也會顯示正確的指令。

好比在賣場辦退貨，以前不管從門市還是網購下單，櫃檯都只給同一張表單，現在會依你的購買管道，給出對得上的步驟和指示。
問題修復

對話紀錄可跨區塊選取並複製彩色文字

在對話紀錄裡想抄幾句回答，以前用滑鼠拖曳往往只能一整塊訊息全選，無法精準挑出要的片段。現在直接拖曳滑鼠，就能跨過不同訊息區塊反白選取，連帶有顏色的文字都能一起複製下來。

把報紙文章剪下來保存時，以前得把整版帶走，現在拿剪刀沿著需要的段落跨欄剪下，連彩色標題都能保留。
新功能

`grok export` 匯出對話加速又省記憶體

工作階段裡只要累積了大段終端機指令輸出，想把整段對話存成檔案就得靠 grok export（匯出對話紀錄的指令）。這類包含大量終端機輸出的工作階段，現在執行匯出時速度更快，佔用的記憶體也更少。

搬運一整箱厚重報表時，以前得來回扛好幾趟又佔滿走廊，現在換成輕巧推車，一下就運完還不佔空間。
新功能

Always-approve 說明更正會存進設定檔

設定 Always-approve（永遠允許的權限選項）前想確認它會不會被記下來，過去的說明文字寫得並不正確。現在這段說明已經更正，會清楚寫明這項設定會存進設定檔。

問題修復

圖片被略過的提示不再混進你的訊息裡

打開對話紀錄或歷史紀錄想回顧先前內容，以前在自己送出的內容中會看到圖片遭略過的通知。現在這個問題已經修好，這則提示不會再混進使用者的訊息中。

English

FEATURE

`@` file chips can be edited in place and support new syntax

If you want the AI to read a file but pick the wrong one, you no longer need to delete it and start over. File chips inserted with @ (the small blocks in the input box that mark a target) can now be edited in place, and paths typed starting with @~/ automatically resolve to your home folder. To point to specific line numbers or include hidden files, you can now append a :N line suffix at the end or use @!hidden syntax to name hidden files.

Think of setting a destination in a phone map: previously a typo meant clearing the whole field, whereas now you can edit right inside the box, and it understands shortcuts, floors, and hidden doors.
FEATURE

`grok update` guidance improved by installation method

When you try to upgrade Grok or switch update channels, the outcome often depends on how you originally installed it. If your bin/grok was installed via npm (a JavaScript package manager), running grok update --channel now shows a clear error message and next steps. For installations done through Homebrew cask (a common macOS software installer), grok update and channel switching now work properly, and the screen displays the right commands.

Picture returning an item at a store: previously the counter handed out the same form whether you bought in person or online, but now it gives you steps and instructions that match how you purchased.
BUGFIX

Transcripts now support cross-block selection and copying colored text

When you wanted to copy a few lines from a reply in the transcript, dragging with the mouse used to select an entire message block instead of letting you pick just the snippet you needed. Now dragging the mouse highlights across different message blocks and lets you copy colored text along with it.

When clipping a newspaper article to save, you used to have to take the whole page, whereas now you can cut across columns along just the paragraphs you want and even keep the colored headlines.
FEATURE

`grok export` gets faster and uses less memory

Whenever a session builds up large terminal command output, saving the whole conversation to a file relies on grok export (the command for exporting conversation transcripts). Exporting sessions with heavy terminal output is now faster and uses less memory.

Moving a heavy crate of reports used to take multiple trips and clog the hallway, but switching to a light cart gets the job done quickly without taking up space.
FEATURE

Always-approve help text corrected to note it saves to config

If you wanted to check whether Always-approve (the permission option for permanent approval) would be remembered before enabling it, the previous help text was inaccurate. That help text has now been corrected to clearly state that this setting is saved to the config file.

BUGFIX

Dropped-image notice no longer mixes into your message

When opening a transcript or history to review earlier messages, you used to see a notice about dropped images inside the content you sent. This issue is now fixed, and the notice no longer appears inside the user's message.
