Grok Build 1.0.67

Released: 2026-10-21

Release notes

FEATURE

Worktrees Automatically Inherit Approvals from Main Checkout, Removing Repeated Prompts

When switching between branches to fix code in parallel across large projects, recurring tool authorization popups often break your focus. Worktrees (a Git feature that opens multiple copies of the same project in parallel) now automatically reuse the "always allow" choices you saved in the main checkout, eliminating the need to reconfirm the same tool in every copy.

Holding an access badge issued by headquarters, you walk into local branches: previously, every office switch meant filling out access logs again, but now security scanners directly recognize clearance records from headquarters; however, if you are flagged as barred at headquarters, all branches strictly block you as well.

If you want each worktree to maintain independent authorization, you can write [features] worktree_inherits_main_approvals = false into your configuration file to turn off inheritance. Regardless, the "never allow" settings saved in the main checkout still apply either way, ensuring blocking rules are never missed.

BUGFIX

Prompt Suggestions Support Vim Mode, Switching Tab to Navigate Scrollback History

Developers accustomed to Vim keybindings often struggle with helper features clashing with shortcuts when typing in the terminal.

When switching a professional camera to manual focus mode, half-pressing the shutter previously triggered autofocus directly; now the shutter button toggles a magnified view instead, leaving confirmation and cancellation to the dial and back button.

After you enable the [ui].vim_mode setting, prompt suggestions adjust their key behavior to follow Vim logic completely. Pressing Tab no longer directly accepts the recommended text, instead moving focus to the scrollback history for inspection. To accept a suggestion, press → or Ctrl+→ instead; pressing Esc dismisses the prompt directly.

BUGFIX

Headless Mode Exits Cleanly After Reading Background Task Output Instead of Hanging

In automated workflows or continuous integration environments, scheduled scripts often rely on tools running quietly in the background to handle heavy analytical tasks.

Picture a courier returning a signed delivery slip to the counter: previously, whenever that same desk collected the receipt, the courier stood frozen on the spot and refused to leave; now, as soon as the work is handed over, they cleanly clock out and head home.

When running grok -p in headless mode (an execution mode without a terminal window), the program previously hung whenever a background task or subagent finished and its output was read in the same turn. Headless runs now exit normally after their work is done, ensuring automated pipelines wrap up smoothly.

FEATURE

Theme Picker in Settings Restores Previous Theme When Leaving Without Pressing Enter

When previewing different interface styles one by one in the settings menu, changing your mind halfway through often makes you want your familiar palette back immediately.

Think of flipping through wallpaper patterns on a sample rack: previously, merely holding a new sample against the wall led the clerk to assume you were redecorating; now, as long as you do not confirm the order, walking away instantly restores your original wall color.

When browsing color schemes in the Settings theme picker, leaving in any way other than pressing Enter now automatically restores your previous theme. This change brings the settings exit behavior in line with what the /theme command already does, so you never have to worry about accidentally overwriting your look while browsing.

FEATURE

Quitting a Session with Hooks Configured Is Faster, Making Exits Snappier

For users who routinely run cleanup scripts when a conversation ends, waiting through a pause every time they shut down the tool can feel sluggish.

Leaving a smart home configured with departure automations previously required waiting longer by the door, but the delay before stepping out is now shorter.

When you had configured hooks (small programs triggered by specific events) to handle session events, entering the quit command previously caused a noticeable stutter. Quitting a session with hooks configured is now faster, making exits much smoother.
