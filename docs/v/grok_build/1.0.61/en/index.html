Grok Build 1.0.61

Released: 2026-10-16

Release notes

BUGFIX

/resume Directly Resumes an Exact Single-Session Match and Supports Any-Word-Order Search in the Picker

When you have accumulated a large conversation history and want to resume progress, you no longer have to endure rigid keyword ordering or redundant confirmation steps.

Picture someone searching for a project folder in an office drawer. Previously, if the word order on the cover was reversed, it could not be found, and reciting a unique number still required opening the entire list. Now, entering all keywords matches regardless of sequence, and matching exactly one code lets you pull the folder straight out.

Now when you enter /resume <id or name> in the terminal, as long as the specified ID or title matches exactly one session, Grok Build directly enters that session instead of forcing a picker popup every time for an extra click. If you bring up the picker to search manually, the picker accurately lists matching sessions as long as your input includes every word in the title, regardless of their order.

FEATURE

Dashboard Preview Text Supports Mouse Dragging, Automatically Copying to the Clipboard on Release

When you want to quickly grab preview content from the dashboard to paste for a colleague, you no longer need to press any keyboard shortcuts.

Imagine marking highlights on a document with a highlighter. Previously, after finishing the mark, you still had to press a camera shutter manually to keep a record; now, as the pen tip glides across the text and releases, the content is transmitted automatically to a pocket notebook.

While viewing preview text on the dashboard, you can click and drag the mouse cursor to select the desired string. As soon as you release the mouse button after completing the selection, the marked text snippet is automatically copied to the clipboard. Whether you need to extract error details or compare execution results, you can paste directly into another chat window right after dragging to select, saving the tedious step of pressing keys to copy after highlighting.

BUGFIX

Workflow View Smoothly Advances Toward Newer Agents When Scrolling Down the Roster

When tracking a workflow where multiple agents collaborate, the biggest frustration when checking progress is an uncooperative viewport.

Think of tracking an inspection camera forward along a queue corridor. Previously, whenever the scroll wheel moved downward, the view was abruptly pulled back to the starting point like a spring; now, the frame follows the action, smoothly advancing toward newly joined members at the rear.

In the workflow execution view, when you scroll down on the agent roster with the mouse wheel, the view now continuously scrolls toward newer agents in the direction of your movement, rather than snapping back to the origin. This allows your line of sight to smoothly follow along as you inspect each agent's latest execution progress in sequence, without having to repeatedly hunt for focus.

BUGFIX

Windows Identifies Unstarted Programs When Hook Execution Fails, Rather Than Blaming the Script

When debugging automated workflows on Windows using hooks (small programs triggered by specific events), the worst experience is seeing ambiguous error messages.

Dispatching a field fleet for a mission previously meant that whenever an outsourced truck failed to start at the gate, the control center only reported an error in the work order; now, the alert clearly names which vehicle failed to start without falsely blaming the original task list.

If a hook fails to spawn a process on Windows, the terminal now directly names which external program failed to start, such as specifically indicating an error in PowerShell or Git Bash, rather than blaming the hook script itself. When confronting such issues, you can immediately tell whether the environment lacks an execution tool or is missing a path configuration, saving time spent inspecting the script line by line.
