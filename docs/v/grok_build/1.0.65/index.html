Grok Build 1.0.65

發布日期：2026-10-20

繁體中文

問題修復

/resume 搜尋支援跨資料夾與對話全文，字首匹配更精確

當你想接續先前的對話進度，卻只依稀記得幾句回覆或執行過的指令時。

跟請唱片行店員尋找舊專輯一樣，以前只要打錯字母就找不到，也查不到內頁歌詞裡的片語；現在能跨架檢索整張唱片收錄的曲目與備註，還會嚴格對齊單字開頭，不再把不相干的黑膠混在一起。

現在輸入 /resume 搜尋時，工具能直接找出其他資料夾的工作階段，並能容忍打錯字。比對範圍更擴及工作階段內的指令、檔案路徑與回覆內容。輸入單一字元時會維持字面意義，搜尋詞則會各自對齊單字開頭比對，因此輸入 log fix 不會再配對到「Blog prefix cleanup」。

問題修復

指令列指定 `--permission-mode plan`，依約進入計畫模式

準備著手梳理大型架構時，你可能會先指定 Grok 的起始模式。

請建築顧問入場，以前明明約好從規劃會議開始，顧問卻仍照預設流程開場；現在他會依約從規劃會議開始。

先前在指令列加上 --permission-mode plan 參數，啟動的工作階段卻仍會停留在預設模式。現在這項問題已經修好，會依文件所述，以計畫模式啟動工作階段。

問題修復

儀表板 `Ctrl+L` 資料夾清單擴充，最近記錄上限增至 50 個

在儀表板頻繁切換多個專案，想快速跳轉到不久前開啟過的目錄時。

拉開工作檯旁的工具收納格，以前抽屜容量狹窄，最多只能保留 10 種最近拿取的工具，稍微切換幾樣舊工具就得重新翻找；現在收納上限擴增至 50 格，找回剛用過的器具不再撲空。

過去在儀表板按下快速鍵 Ctrl+L 開啟資料夾挑選器時，清單只會列出 10 個最近開啟的項目，切換頻繁時舊路徑很快就會被擠掉。現在選單能列出最多 50 個最近資料夾，翻找過去的專案路徑時不必再重複輸入。

問題修復

`grok --help` 提供單行摘要，查詢說明指令不再報錯

面對陌生的指令列想查詢參數用法，快速掌握功能全貌時。

站在綜合賣場的入口指示看板前，以前看板沒有簡短說明，想按鈕查詢導覽機自身的用法還會亮起故障紅燈；現在各個專區都附有一行清爽簡介，點選服務台說明也能順利拿到導覽指南。

現在執行 grok --help 時，畫面會替每個指令與選項附上一行簡短摘要，方便在同一個畫面瀏覽完整功能。若輸入 grok help -h 或 grok help --help 查詢說明指令自身，終端機會正常印出 help 指令的說明資訊，不再跳出錯誤訊息。

新功能

停用遙測與當機回報，環境變數設為任何值皆生效

管理重視隱私的內部專案，需要停用各類背景數據傳輸時。

在住家大門掛上拒收宣傳品的告示牌，以前只要標籤上寫了文字，郵差常誤以為在備註投遞細節而繼續塞入廣告；現在只要門前掛有告示牌，不論上頭填寫什麼內容，外送員都會確實停止投遞所有文宣。

現在只要設定環境變數 DISABLE_TELEMETRY 或 DISABLE_ERROR_REPORTING，無論賦予它們任何值，包含字面上的 0 與 false，工具都會確實將遙測與當機回報功能關閉。這避免了過去因填寫非預期數值，導致停用設定未能如期生效的情況。

English

BUGFIX

`/resume` search supports other folders and full session text, with more accurate prefix matching

When you want to continue previous conversation progress, but only vaguely remember a few replies or executed commands.

Think of asking a record store clerk to find an old record: previously, a single mistyped letter meant you could not find it, nor could you search for phrases in the liner notes; now they can search across shelves through the tracks and notes on an entire record, while strictly matching word beginnings so unrelated vinyl is no longer mixed in.

Now when searching with /resume, the tool can directly find sessions from other folders and tolerate typos. The matching scope also extends to commands, file paths, and reply content within a session. A single typed character keeps its literal meaning, and search terms match individually at the start of words, so typing log fix no longer matches "Blog prefix cleanup".

BUGFIX

Specifying `--permission-mode plan` on the command line enters plan mode as documented

When preparing to untangle a large architecture, you might specify Grok's starting mode in advance.

Picture hiring a building consultant: previously, despite agreeing to start with a planning meeting, the consultant still opened with the default process; now they start from the planning meeting as agreed.

Previously, adding the --permission-mode plan option on the command line still left the started session in the default mode. Now this issue has been fixed, and it starts the session in plan mode as documented.

BUGFIX

Dashboard `Ctrl+L` folder list expanded, increasing recent history limit to 50

When frequently switching between multiple projects in the dashboard and wanting to quickly jump to a recently opened directory.

A craftsperson opens a tool organizer beside a workbench: previously, drawer capacity was narrow and could only keep 10 recently grabbed tools, so switching tools forced you to search around again; now the storage limit expands to 50 slots, so reaching back for recently used tools no longer comes up empty.

Previously, pressing the shortcut Ctrl+L in the dashboard to open the folder picker only listed 10 recently opened items, so older paths were quickly pushed out during frequent switching. Now the menu can list up to 50 recent folders, eliminating the need to retype past project paths when browsing for them.

BUGFIX

`grok --help` provides one-line summaries, and inspecting the help command no longer errors

When facing an unfamiliar command line and wanting to look up option usage to quickly grasp the full picture of features.

Imagine standing before an entrance directory board in a department store: previously, the board had no brief descriptions, and pressing a button to look up how to use the directory itself would light up a red malfunction light; now each section comes with a clean one-line overview, and selecting the help desk guide successfully delivers the directory guide.

Now when running grok --help, the screen provides each command and option with a one-line summary, making it easy to browse the complete feature set on a single screen. If you enter grok help -h or grok help --help to look up the help command itself, the terminal prints help information for the help command normally instead of throwing an error message.

FEATURE

Disabling telemetry and crash reports takes effect when environment variables are set to any value

When managing privacy-sensitive internal projects and needing to disable various types of background data transmission.

A homeowner hangs a sign refusing promotional mail on the front door: previously, whenever text was written on the label, mail carriers often mistook it for delivery notes and kept stuffing flyers in; now as long as a sign hangs on the door, regardless of what is written on it, delivery couriers reliably stop dropping off all promotional material.

Now simply setting the environment variable DISABLE_TELEMETRY or DISABLE_ERROR_REPORTING to any value, including the literal 0 and false, ensures the tool turns telemetry and crash reports off. This avoids the past situation where entering unexpected values prevented the disable setting from taking effect as expected.
