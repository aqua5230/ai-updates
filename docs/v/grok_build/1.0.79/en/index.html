Grok Build 1.0.79

Released: 2026-11-08

Release notes

FEATURE

/rewind works in place for paged sessions

When a conversation grows long and splits across multiple pages, stepping back to an earlier point often meant waiting for the entire history to reload. Entering /rewind now rewinds in place within paged sessions without reloading every turn.

Picture rewinding a long movie to rewatch a scene: dragging the slider back used to reload the whole film, whereas now the frame jumps straight to that second.
FEATURE

/vim-mode all enables full Vim editing

Those used to moving the cursor and editing text with Vim keybindings can now use them all the way through the agent input area. Entering /vim-mode all turns on full Vim editing inside the agent prompt. When enabled, Vim Normal mode (the state where single keys move the cursor and edit text) also appears as its own section in the keyboard shortcuts cheatsheet.

Driving a stick shift used to mean switching back to automatic in city traffic, but now you can shift gears the whole trip with a gear chart taped right beside you.
FEATURE

Auto-review mode tints the entire prompt bar blue

When switching back and forth between conversation modes, color lets you tell at a glance which one is active. Auto-review mode now tints the entire prompt bar blue, matching how plan and ask modes appear.

FEATURE

Prompt queue adds WSL toggle and editing label

Lining up unsent prompts to run in order now comes with both a toggle shortcut and an edit indicator. When running in WSL (the Linux subsystem on Windows) inside Windows Terminal, pressing Ctrl+Y toggles the prompt queue. Editing a queued prompt dims the row and shows an "editing" label.

Taking a numbered ticket at a counter lets you pull up the waitlist with one button, and updating a ticket grays it out so it never gets mixed up with the rest.
FEATURE

Smoother input shortcuts and startup completion

Editing drafts, triggering completion, or pasting images in the input box gets a few updated key behaviors and docs. When editing a draft in minimal mode, Ctrl+E now moves the cursor to the end of the line. Right after startup, Tab completion works immediately even before skills (prewritten extension commands) finish loading. For macOS users, the official documentation now recommends Ctrl+V to paste screenshots.

FEATURE

Cleaner reply rendering and clickable copy buttons

Viewing AI output that mixes URLs, code, diagrams, and math formulas gets cleaner rendering and smoother interactions. Link cards now appear by default for links that cannot be opened. Copy buttons under code blocks remain clickable while slash or other menus are open. Mermaid (a tool for drawing flowcharts from text syntax) diagrams now break lines properly on \n and <br> instead of printing the literal characters. Markdown links containing LaTeX (syntax built for typesetting math formulas) now render as links instead of mistakenly entering math mode.

BUGFIX

Background task counts stay visible and safe on close

Leaving commands or subagents (helpers that split off work in the background) running makes it easy to lose track of progress or stop them by mistake. The end-of-turn marker now shows how many background commands are still running. Double-clicking to close a view no longer accidentally stops a background task or subagent.

Think of several pots simmering on a stove: a timer tells you how many are still bubbling, and hitting the range hood switch twice by mistake will not shut off the burners.
BUGFIX

Deleted sessions stay hidden and feedback drafts open

Whether cleaning up past conversations or returning to a draft, session lists and records now line up properly. Deleted sessions no longer appear in resume lists or title searches. Saved feedback drafts now open properly from the full session view.

BUGFIX

Clearer delete and sign-in authentication messages

When a delete action fails or sign-in hits an authentication snag, the on-screen prompts and status feedback are no longer confusing. Delete error messages now show their full text instead of being cut off. Authentication error messages during sign-in no longer repeat the underlying cause. Feedback after copying an MCP (a protocol that connects AI to external tools) sign-in URL now correctly indicates verification status.

BUGFIX

tmux delay warning and terminal display fixes

Running multiple panes with tmux (a terminal multiplexer for managing multiple panes) or shrinking the terminal window very short gets both key-check and display fixes. /doctor now warns when tmux holds Esc for more than 50 ms. Text remains visible when running through an 8-color tmux session. Showing the cancel-turn prompt no longer crashes the TUI (text-based user interface inside the terminal) on very short terminals.
