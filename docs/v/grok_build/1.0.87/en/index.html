Grok Build 1.0.87

Released: 2026-11-14

Release notes

FEATURE

Minimal mode /mcps adds search and action hints

If you prefer working in minimal mode, managing MCP (a protocol that lets AI connect to external tools) connections is no longer cut short. Opening /mcps now shows the same loading state, error messages, and layout style as the full view. It also adds a search bar and the full set of action hints. When you spot an item you want to act on, pressing its key opens the form directly.

Think of a pocket remote now matching the main living room unit: it used to fit only a few switches, and now both the search button and settings menu work right from it.
BUGFIX

Typing on permission cards sends feedback to the model

When a tool prompts for permission and you want to suggest changes to that step, you can reply just by typing. Previously, typing on the permission card only moved the selected row. Now your text goes straight to the model as feedback instead of switching options.

When signing off on an engineering draft card, pressing keys used to only move up and down between options, whereas now whatever you type goes straight to the drafter as feedback.
BUGFIX

/voice saves clipped errors and names the app missing permission

When you turn on /voice on macOS and it cannot capture audio, the screen now points out that your terminal app is missing Microphone permission and shows how to fix it. If a voice error message gets cut off by the toast notification, the full text is now saved to your terminal scrollback. Toast text also no longer shows stray spaces or double ellipses.

BUGFIX

/resume keeps search matches visible and confirms before delete

When browsing past session records, search result snippets often showed only the start or end and cut off the words you were looking for. Now /resume search snippets fit the list width and keep the matching text visible. Before deleting a session through /resume in minimal mode, the screen now shows the "y confirm delete · n cancel" prompt.

BUGFIX

/agents modal text no longer overflows or gets clipped

Dialogs often break their layout when text mixes in wide characters like Chinese or full-width symbols. In the agents modal, persona names and descriptions no longer overflow the window even when they contain wide characters. When expanding agent details in /agents, content that exceeds the available space used to be clipped at the modal edge and now ends with an ellipsis instead.

FEATURE

Clearer text copying and status display in conversation view

Copying from conversation history, clicking links, and checking tool output now all give clearer visual feedback. Dragging the mouse to select and copy conversation text now skips collapsed tool calls and the turn summary line, copying only the actual conversation. When a reply contains links, hovering over them highlights them to show they can be clicked. When a tool returns nothing, Use Tool blocks now display (no output).

BUGFIX

Text labels and hints fixed for narrow terminals and dialogs

Setting names and key hints are now easier to read when your window is narrow or when you switch to a fullscreen dialog. Key hints in fullscreen dialogs now use consistent capitalization. When the terminal window is very narrow, settings rows now show their name label instead of a cut-off restart tag. Footer hints in minimal mode no longer get cut off mid-word on narrow terminals.

FEATURE

Leftover text from other programs in the terminal clears automatically

When you switch between different tools in the same command-line window, output printed by another program can sometimes linger on screen. That leftover text is now cleared automatically when a tool call ends, a turn ends, or you switch back to the window and it regains focus.

FEATURE

Cmd+A selects all prompt text in the Rex terminal

When you wanted to rewrite or copy your whole prompt in the input box, certain terminals used to prevent selecting it all at once. In the Rex terminal, pressing Cmd+A now selects the entire prompt text.
