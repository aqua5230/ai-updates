Grok Build 1.0.88

Released: 2026-11-16

Release notes

FEATURE

MCP servers support dynamic request headers

When connecting to external tools, you can let a command provide request headers dynamically instead of hardcoding them in the config. When configuring an MCP (a protocol for connecting AI to external tools) server, you can now specify a headers_helper command to supply dynamic request headers.

FEATURE

Only Tab returns to parked cards and approvals

Other keys no longer respond when you want to pull back a card you set aside or return to a plan approval screen you were reviewing. Now only the Tab key returns to a parked card or plan approval.

Previously, several buttons by the desk could call a held folder back to the tabletop, but now only one dedicated call button remains for pulling up set-aside files.
FEATURE

Windows voice dictation points to microphone access

When speaking to enter text gets no response, the operating system has often blocked audio permissions. Previously you had to hunt through settings on your own when blocked by the system, but now the screen tells you directly where to turn on microphone access.

FEATURE

Parallel startup queries speed up the first frame

Opening Grok Build now takes less time before the first frame appears. Startup now sends terminal protocol queries at the same time as it establishes the agent connection, so the first frame shows up faster without waiting for the prior step to finish. When starting in inline or minimal mode, terminals that answer cursor position queries slowly no longer delay the first frame from appearing.

Think of ordering at a restaurant: before, the kitchen would not fire up until the waiter finished writing down the table number, whereas now taking the order and prepping the food happen in parallel so the first dish arrives sooner.
FEATURE

Limit-hit model switches show and apply exact settings

When a usage limit notice pops up mid-conversation and you follow the prompt to switch models, the option used to hide which parameters would apply and switching did not always match the suggested values. Now when switching models at a limit hit, the button spells out the exact settings it will select, such as Switch to Auto (Standard, Terse). After confirming the switch from the limit box, it also directly applies the exact settings suggested by the backend.

Picture taking a taxi during a road detour: before, the driver only said to take another way without naming the route, whereas now the navigation shows the full new route name upfront and follows it once you confirm.
FEATURE

Empty hook files load cleanly and keep initial rows

When you just created a hook (a small program triggered by specific events) config file with no rules yet and only whitespace, loading it used to throw an error. Now empty or whitespace-only hook files load without error. When entering the first prompt screen, earlier rows such as hook notes stay visible as long as they fit on the page, instead of disappearing as soon as you start entering input.

BUGFIX

Loaded sessions keep model settings and no longer wait on ended turns

When you open a previously saved session to continue working, you no longer have to worry about losing settings if the list cannot be fetched right away. Even if the first model list fetch fails, loaded sessions still keep their saved model and effort. When encountering a saved turn that has already ended, the terminal interface no longer waits idly on it.

FEATURE

MCP form and URL rejection cards show full content

The MCP form card in minimal mode now fits the width it draws, keeping every input field visible on screen. Even when the error reason for a rejected URL wraps to two rows, the MCP URL rejection card still displays the full rejected URL.

BUGFIX

Persona multi-line highlights and badge display fixes

When you open the /agents modal to adjust persona settings, it is now clear at a glance which row is selected and how many instruction lines remain collapsed. Selecting a multi-line field in a persona now highlights every row. The collapsed-instructions hint also displays the true remaining line count. After switching to the Personas tab in the /agents modal, badges are colored by scope. If tool or prompt-extension fields have no content, the screen reads (empty).

Like tidying up a folder by highlighting a whole stack of pages evenly and adding color-coded tabs, you no longer have to guess how many pages are left or whether a section is blank.
FEATURE

Narrow terminals preserve folder names and truncate long model or mode names

When the terminal window is narrowed or a model or mode has an especially long name, the top of the screen and the prompt box can easily overflow. Now the prompt border and mode banner truncate overly long model or mode names with an ellipsis. When opening the welcome bar on narrow terminals, the branch name is shortened first to keep the current folder name visible.

FEATURE

Steady Link Hand Pointer and Loading Indicator

Hovering over a link while pressing Cmd, or waiting for file search and image previews to load, now gives you clear cursor and status feedback. Links keep showing the hand pointer when Cmd is pressed or released while the pointer rests on them. File search, history, and image preview now show an animated Loading… indicator.

BUGFIX

Text Fixes for /doctor and /usage

When running diagnostics on your keyboard setup or checking how many tokens (the text units AI processes and bills by) each model used, the text output for both common commands is now fixed. When you run /doctor to check your environment, it now correctly says when a confirmed keyboard protocol is not actually in use. When viewing the /usage by-model breakdown, each row now uses lowercase tokens for consistency with the rest of the interface.

A reconciled utility bill works the same way: before, it failed to admit when a meter was idle and mixed up unit capitalization, whereas now both the status and the wording are accurate and consistent.
BUGFIX

Tasks Pane Layout and Selection Fixes

Opening the Tasks pane on a narrow terminal to pick a task used to cause layout misalignment, and keyboard or mouse actions often hit the wrong item. Buttons and timers no longer paint over the status icon. After filtering, each row's icon, time, and buttons stay on their own row without breaking layout. Keyboard actions now apply directly to the highlighted row. Clicking after scrolling the pane down also accurately selects the task under the pointer. The search bar no longer disappears unexpectedly, and updating a filter no longer leaves stale rows behind. Clicking the search bar or filter status row no longer selects a hidden task either.

Realigning a crooked elevator button panel captures this fix: buttons once overlapped and pressing one slot sent you to a different floor, but now wherever you point, it reliably hits the right spot.
FEATURE

/tasks and /queue Output and Pane Navigation Updates

When checking scheduled tasks, to-dos, or the command queue, display formatting across blocks and keyboard navigation after hiding a pane are now consistent. The /tasks block now displays scheduled loops with the same next-fire suffix and empty-state message as the Tasks pane. Even if the todo, tasks, and queue panes change while hidden, arrow-key navigation works properly once you switch back. /queue output now prefixes bash commands with ! and uses the same line-count suffix as the pane.

BUGFIX

Scrollback and Block Viewer Display and Selection Fixes

When scrolling back through earlier task records or searching inside the block viewer, every line is now clearly visible. Scrollback now applies the same selection highlight to Task, Subagent, and Workflow rows. Scrollback on narrow terminals no longer drops wrapped text or group headers. When searching inside the block viewer, the search bar and status bar no longer overlap the bottom lines of content.

FEATURE

Theme Border and Hint Text Color Adjustments

Whether you prefer a dark or light terminal palette, borders, hint text, and highlight backgrounds now match cleanly. The Tokyo Night theme now dims the unfocused input border correctly. Tips and answered-question text now dim to match the terminal theme. On light themes, welcome screen rows now use lighter selection and hover colors.

FEATURE

Dashboard Command Support and Interaction Updates

While the dashboard is open, opening help commands, spotting selected options, and pasting images are all more direct. When the dashboard is active, entering /release-notes, /docs, and /help now opens their corresponding content. The dashboard peek pane now highlights the selected permission or question option with the same caret and band used elsewhere. Dashboard action buttons are now labeled Resume Session and Enable Worktree. The free-text row now says Type your answer here. Pasted images on the dashboard now attach directly to the correct input field without waiting for other fields.

BUGFIX

/resume and Session Picker Layout and Accidental-Input Fixes

Searching for and switching back to a previous session on narrow terminals or in minimal mode often ran into obscured text or wrong-row selection. On narrow terminals, the /resume search bar no longer lets the filter chip cover your query text, and it shows which source filter is active when width permits. In minimal mode, /resume now lets arrow keys and Enter act only on rows that are actually shown, and uses the same loading spinner and empty states as the full picker. It keeps message-text matches visible using the same query the keys use, and draws a flat list when session grouping is off so selection lines up with key presses. The /resume panel now shows all fields even when a session's current folder path wraps at narrow widths. If a long working directory path contains an early space, /resume and full-screen pickers no longer truncate cards. While the list is still reloading, the session picker no longer lets key presses or clicks trigger a selection. Keys also do nothing until the next frame actually draws the list rows.

BUGFIX

Minimal Mode Sign-In and Prompt Screen Fixes

Signing in, confirming trust, or refusing a plan revision in minimal mode used to leave messages stuck or misaligned, and those are now cleaned up. Media rows no longer show the [Open] button that cannot be clicked in minimal mode, status and info rows now end with an ellipsis, and transcript progress uses sentence case. When refusing a plan revision, minimal mode now displays the refusal message directly instead of leaving the review stuck in a blank state. On sign-in failure in minimal mode, only the error message appears in red; the device code is shown on its own with the caption underneath, Connecting… is shown until the flow type is known, and text wraps cleanly on narrow terminals. In the trust prompt, y/n is now followed by single spacing.

BUGFIX

Permission and Question Card Arrow and Scrollbar Fixes

On permission and question cards, key direction indicators, long typed text, and the right-hand scrollbar now line up properly. On narrow terminals, permission and question cards now end long typed answers and form values with an ellipsis. Permission cards now show only the scope arrows that can still move the scope. The shortcuts bar below also aligns precisely with the scope arrows listed on the permission card above it. In question cards, scrollbar size is now calculated accurately after option descriptions wrap to the card width. When every option fits on one page, the option list no longer shows a scrollbar or allows overscroll.
