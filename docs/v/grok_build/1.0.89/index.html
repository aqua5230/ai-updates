Grok Build 1.0.89

發布日期：2026-11-17

繁體中文

新功能

儀表板新增 /rename 幫工作階段改名

列表中同時留著好幾條舊紀錄，想替其中一條換個好認的標記，卻不想一一打開。現在選好目標後輸入 /rename，就能直接把那個工作階段改名，不用先打開它。

就像站在書架前替書換書腰，以前得先把整本書抽出來翻過才能改名，現在不用打開內頁就能直接寫上新名字。
新功能

新增 /models 指令從伺服器重抓模型清單

不確定畫面上顯示的模型還是不是最新一批，卻不想靠猜的。輸入 /models，就會直接向伺服器重新抓取目前可用的模型清單。

跟走到自動販賣機前按下更新鍵一樣，不用憑印象猜測，直接向倉庫抓回最新上架的品項清單。
問題修復

/hooks 清單改用清楚欄位顯示檔名與設定

查看自動化設定不用再對著原始指令硬猜用途。/hooks 清單每一列現在都會顯示 hook（掛鉤，特定事件發生時被觸發的小程式）的檔案名稱。各項設定也改成在易讀的欄位裡列出，不再直接傾倒原始指令。

配電箱打開來，以前裡面只塞著一長串難懂的原始線路代號，現在每個開關旁都印好檔名跟設定項目。
新功能

MCP 伺服器檢視與開關設定更準確

調整或檢查 MCP（Model Context Protocol，讓 AI 連接外部工具的協定）伺服器時，現在能看到更清楚的狀態與路徑。 在 /mcps 裡，除非裡頭超過十台伺服器，否則代管區塊預設會直接展開。 在已經執行的終端機介面工作階段裡，grok mcp disable 與 grok mcp enable 現在能正確停止對應的伺服器。 執行 grok inspect 檢查專案自訂的 MCP 伺服器時，回報的設定檔位置現在能正確對應到 .grok/config.toml 或 .mcp.json。 這樣一來，清單展開範圍、進行中工作階段的伺服器停用，以及設定檔路徑都跟實際狀態一致。

新功能

/workflows 清單按 Enter 可直接開檔並搜尋

平時對照工作流程定義，總得確認裡面的步驟寫法。現在游標停在 /workflows 清單的項目上按下 Enter，就會直接開啟該流程的檔案，方便你瀏覽與搜尋內容。

新功能

全展開模式重複收合思考時會提示關閉快捷鍵

每次回答一長串思考過程，你可能忍不住一塊一塊手動把它們摺起來，卻忘了全部展開模式還開著。在全部展開開啟的狀態下，只要你持續把思考段落一個個收起來，畫面就會跳出提示，列出用來關掉全部展開的組合鍵。

你一盞一盞手動關掉小燈，旁邊的人看你連按好幾顆，就會順手指給你看總開關的位置在哪。
問題修復

問答卡打字與貼上回答不再誤觸快捷鍵或捲過頭

在問答卡上想填寫自己的回答，以前操作常出狀況。現在打字或貼上回答內容，都不會再被誤認成快捷鍵。 打字輸入回答的過程中，問答卡清單也不會再捲超過最後一個選項。

新功能

儀表板派送與快速檢視回覆框操作改進

打字打一半想一口氣清掉剛敲錯的字詞，不用再連按倒退鍵。現在在儀表板的派送與快速檢視回覆框裡按 Ctrl+W，就能刪掉前一個單字。 當派送訊息正在等待圖片傳送時，快速檢視回覆框依然可以正常接收按鍵輸入與貼上內容。

問題修復

接續工作階段後背景任務與工作流程位置修正

事情做到一半暫停，回頭重開紀錄繼續進行，裡頭有些項目常會插錯順序。這個問題已經修好，現在重開工作階段後，背景任務與工作流程都會出現在對話紀錄裡正確的順序位置。

問題修復

搜尋與篩選列的選取錯位與語法錯誤提示修正

在區塊檢視器裡用搜尋列找內容，以前容易點選到被搜尋列蓋住的那一行。現在搜尋列不會再誤選被它擋在底下的那行文字。 當輸入的 regex（正規表達式，用符號匹配字串的語法）格式無效時，搜尋列與篩選列現在會直接顯示 bad pattern。

新功能

回覆中的無效連結改顯示為純文字

回覆裡有時會夾帶已經失效的連結，過去畫面還是把它畫成可點擊的超連結。現在回覆中的無效連結只會以純文字呈現，不會再顯示為可點擊的連結。

問題修復

/goal pause 後的階段計時器改從零起算

使用 /goal pause 之後查看階段計時，過去畫面上會留著過時的舊時間。現在 /goal pause 後的階段計時器會從零開始計時，不再顯示殘留的舊時間。

問題修復

grok update 輸出不再夾帶內部代號與設定檔

更新完工具想確認畫面訊息，以前總會混進幾行給研發端看的編號和檔名。現在 grok update 的輸出已經移除這些內部項目，不再顯示實驗 ID 或設定檔名稱。

問題修復

登入畫面貼上金鑰時不再點名環境變數

把存好的通行憑證複製進帳號驗證框，以前頁面還會順帶寫出一個系統參數的名字。現在當你可能貼上了已儲存的金鑰，登入畫面不再顯示環境變數名稱。

問題修復

服務端連上卻不回傳時對話與壓縮不再卡死

進行對話輪次或壓縮對話內容，萬一供應商雖然建立連線卻始終沒送回回應，以前畫面會就此卡住。這個問題已經修好，現在碰到供應商連上卻無回應時，輪次與對話壓縮都不會再卡死。

English

FEATURE

Dashboard adds /rename to rename sessions

Several old records sit in the list, and you want to give one a clearer label without opening each one. Now you can select the target and enter /rename to rename that session directly without opening it first.

Picture standing at a bookshelf to swap a book's belly band: before, you had to pull the whole book out and flip through it to change the name, whereas now you can write the new name right away without opening the pages.
FEATURE

New /models command refreshes the model list from the server

You are not sure whether the models shown on screen are still the latest batch, and you do not want to guess. Entering /models fetches the currently available model list directly from the server again.

Think of walking up to a vending machine and pressing a refresh button: instead of guessing from memory, you pull the latest stocked item list straight from the warehouse.
BUGFIX

/hooks list now shows file names and settings in clear fields

Checking your automation setup no longer means guessing what raw commands do. Each row in the /hooks list now displays the file name of the hook (a small program triggered by a specific event). Settings are also listed in readable fields instead of dumping raw commands.

Open a breaker box: before, it was stuffed with a long string of cryptic raw wiring codes, and now each switch has its file name and settings printed right beside it.
FEATURE

More accurate MCP server inspection and toggle behavior

When adjusting or checking MCP (Model Context Protocol, a protocol that lets AI connect to external tools) servers, you now see clearer statuses and paths. In /mcps, hosted sections are now expanded by default unless they contain more than ten servers. Inside already-running terminal UI sessions, grok mcp disable and grok mcp enable now properly stop the corresponding servers. When running grok inspect on project-defined MCP servers, the reported config file location now accurately points to .grok/config.toml or .mcp.json. As a result, list expansion scope, stopping servers in active sessions, and config file paths all match the actual state.

FEATURE

Pressing Enter in /workflows opens the file for viewing and searching

When reviewing workflow definitions, you often need to check how the steps are written. Now, pressing Enter on an item in the /workflows list opens that workflow's file directly so you can browse and search its contents.

FEATURE

Hint shows the toggle shortcut when repeatedly collapsing thoughts in expand-all mode

When a response includes a long chain of thought steps, you might find yourself folding them up one by one without realizing expand-all mode is still on. While expand-all is enabled, if you keep collapsing thought sections individually, a hint appears showing the key chord that turns expand-all off.

As you switch off small lights one by one, someone watching you press several switches in a row points out where the master switch is.
BUGFIX

Typing and pasting on question cards no longer trigger shortcuts or overscroll

Entering your own answer on a question card used to run into input issues. Now, typing or pasting an answer is no longer misinterpreted as a shortcut. While typing an answer, the question card list also no longer scrolls past the last option.

FEATURE

Improved controls in dashboard dispatch and peek reply boxes

When you want to clear a mistyped word mid-sentence, you no longer need to tap backspace repeatedly. Pressing Ctrl+W in the dashboard dispatch and peek reply boxes now deletes the previous word. While a dispatch message is waiting on an image transfer, the peek reply box still accepts keystrokes and pasted content normally.

BUGFIX

Fixed placement of background tasks and workflows after resuming a session

When you paused halfway through a task and reopened the record to continue, some items would end up out of order. That issue is fixed: after resuming a session, background tasks and workflows now appear in the right order in the transcript.

BUGFIX

Fixed selection offset and syntax error message in search and filter bars

When searching in the block viewer, it used to be easy to select the line covered by the search bar. The search bar no longer mistakenly selects the line of text hidden underneath it. When an invalid regex (regular expression, a syntax for matching strings with symbols) is entered, the search and filter bars now directly display bad pattern.

FEATURE

Dead links in replies now appear as plain text

Replies sometimes include dead links, which the screen used to render as clickable hyperlinks. Now dead links in replies appear only as plain text rather than clickable links.

BUGFIX

Phase timers after /goal pause now start from zero

When checking phase timing after using /goal pause, the screen used to keep showing stale time. Now phase timers after /goal pause start from zero and no longer display leftover old time.

BUGFIX

grok update output no longer includes internal IDs or config files

When checking screen messages after updating the tool, a few lines of IDs and filenames meant for developers used to get mixed in. Now grok update has removed these internal items from its output and no longer displays experiment IDs or config file names.

BUGFIX

Sign-in screen no longer names an environment variable when pasting a key

When copying a saved credential into the account verification box, the page used to also mention the name of a system parameter. Now when you may have pasted a saved key, the sign-in screen no longer displays an environment variable name.

BUGFIX

Turns and compaction no longer hang when a provider connects without responding

During conversation turns or content compaction, if a provider established a connection but never sent back a response, the screen used to freeze. This issue is now fixed, so when a provider connects without responding, neither turns nor conversation compaction will hang anymore.
