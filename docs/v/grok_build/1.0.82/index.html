Grok Build 1.0.82

發布日期：2026-11-11

繁體中文

新功能

沙盒新增 minimal 與資料夾寫入控制

想讓 Grok 在專案資料夾裡幫忙做事，又想控制它能不能直接改動你啟動程式的那個資料夾？現在可以透過沙盒（限制程式存取範圍的隔離環境）來細部設定。 這次新增了 minimal 沙盒設定檔，以及 workspace_write 選項。建立自訂沙盒設定檔時，就能用它們控制啟動資料夾的寫入權限。

借用實驗室的工作台時，以前你沒辦法單獨控管眼前這張桌面能不能塗寫，現在除了有精簡版守則，還能直接設定那張桌面可不可以寫入。
新功能

grok update 改交自我更新版接手

想替手邊的 Grok 升級，只要打開終端機執行 grok update。在需要的情況下，這個指令現在會把更新任務轉交給放在 ~/.grok/bin 路徑底下的自我更新版本來接手執行。

新功能

grok -p --resume 需有效工作階段 ID

用指令列接續先前的對話紀錄，漏填編號常常要等程式跑起來才發現不對勁。現在執行 grok -p --resume 時，必須提供有效的工作階段 ID。 如果參數後面留空或給了空值，指令會在一開始就直接拒絕執行。

問題修復

/debug tps 不再計入重試與壓縮等待

想查看目前 Grok 的輸出速度，許多人會輸入 /debug tps 來檢查每秒處理的 token（AI 處理與計費的文字單位）數量。 這個指令算出來的每秒速率，現在會把模型重試的等待時間，以及對話自動壓縮時的等待時間排除在外。

跑馬拉松的人看平均配速時，以前連在補給站停下來喘氣的時間都算進去，現在會把這些等待時間扣掉。
問題修復

無頭模式不再觸發多餘回合摘要呼叫

用腳本讓 Grok 在背景自動執行任務，常會開 headless（沒有終端機視窗或視覺介面的無頭執行模式）。這類執行現在不再觸發多餘的模型呼叫來生成回合摘要。

問題修復

有 Grok Node 設定時 hook 不共用身分

有些使用者會在環境裡搭配 Grok 自己的 Node 執行環境設定，並掛上 hook（特定事件發生時被觸發的小程式）。過去只要存在這組 Node 設定，hook 彼此就會共用同一個識別身分。 現在只要環境裡有 Grok 自己的 Node 設定，各個 hook 就不會再共用同一個身分。

新功能

對話紀錄新增訊息收合鍵與邊緣自動捲動

對話越聊越長，在滿頁文字裡重讀自己提過的問題或反白選字常會卡手。 遇到較長的使用者訊息，現在直接在對話紀錄裡按 Enter 或 Ctrl+F，就能把該則訊息展開或收合。 從對話紀錄開始拖曳選取文字時，只要游標拉到窗格邊緣，畫面就會立刻自動捲動。

讀很長的紙本卷軸時，以前得整卷攤開慢慢滑，現在可以把太長的那段先折起來，手一拉到邊界卷軸也會跟著捲動。
新功能

Ctrl+O 複製最新回覆；複製行內程式碼帶反引號

想把 Grok 給的答案貼進筆記或文件，以後不必再用滑鼠慢慢反白整段話。 按下 Ctrl+O，就能直接複製最新一則助手回覆。 從表格、提問卡片或全螢幕檢視器裡複製文字出來時，行內程式碼前後現在也會一併附上反引號（用來標示程式碼的成對撇號）。

翻食譜書想影印重點時，以前得自己拿紙遮住邊角，印出來還少了螢光筆標記，現在按一下就能複製整段，連標註記號都一起帶走。
問題修復

登入畫面顯示與多視窗狀態處理修正

換帳號重登或在舊版 Windows 環境操作，登入步驟很容易出岔子。 登入畫面現在在舊版 Windows 主控台也能正常顯示畫面。登出帳號或中途取消登入後，下次回到登入畫面也會從頭重新開始。 使用瀏覽器登入時，會依照當下儲存的那筆登入資訊來完成手續。要是另一個視窗已經先把這筆登入移除了，這次登入就會被拒絕。

問題修復

畫面未出現或剛切換時不再誤觸按鍵與點擊

打字或點滑鼠比畫面快半拍，過去很容易意外送出確認或點錯按鈕。 詢問是否信任資料夾的提示還沒出現在畫面上之前，預先敲的按鍵現在不會被讀入。 在歡迎畫面上點按時，如果介面剛好在下一個畫面更新前變動，那一下點擊也不會再觸發錯誤的動作。

問題修復

提問互動時保留輸入草稿並修好上方向鍵

畫面跳出提問要你回應，手邊可能正要打字作答，或是順手編輯排隊中的提示詞。 畫面上開著提問視窗，你正在編輯一筆排隊中的提示詞時，就算那列排隊項目突然消失，輸入框裡的草稿現在也會保留下來。 在提問的文字作答區裡，只要游標位在最上面那一行，按上方向鍵就會直接移回前一個選項。

問題修復

修正精簡模式縮放與開登入選單的游標閃爍

拉動視窗邊緣調整大小，或打開畫面挑選登入方式，打字的那條線過去會不停跳動。這個問題已經修好，現在在精簡模式縮放視窗，或開啟登入選擇器時，游標都不會再閃爍。

新功能

API 金鑰模型提示改為只顯示一次

打開模型清單切換模型，畫面上會附帶一則關於 API 金鑰（向服務驗證身分的專屬密碼）模型的提醒。這則提醒現在只會在你第一次打開任何模型清單時出現，之後就不會再顯示。

新功能

Windows Git 輔助工具改用隨附 MinGit

在電腦上用 Grok 追蹤檔案修改紀錄，背後需要相關小程式幫忙處理。Windows 上的 Git（追蹤檔案修改歷史的版本控制工具）輔助工具，現在改用程式隨附的 MinGit 執行檔。

English

FEATURE

Minimal sandbox profile and folder write controls

Want Grok to work inside a project folder while controlling whether it can modify the folder where you launched it? You can now fine-tune that through a sandbox (an isolated environment that restricts program access). This update adds a minimal sandbox profile and a workspace_write option. When creating a custom sandbox profile, you can use them to control write permissions for the launch folder.

When borrowing a lab workbench, you used to have no way to separately control whether the desk in front of you could be written on; now, besides a streamlined set of rules, you can directly set whether that desk allows writing.
FEATURE

grok update hands off to self-updating build

To upgrade your copy of Grok, just open a terminal and run grok update. When needed, this command now hands off the update task to the self-updating build located under ~/.grok/bin.

FEATURE

grok -p --resume requires a valid session ID

When resuming a previous conversation from the command line, a missing ID often goes unnoticed until the program is already running. Running grok -p --resume now requires a valid session ID. If you leave the argument blank or pass an empty value, the command refuses to run right at the start.

BUGFIX

/debug tps excludes retry and compaction waits

To check Grok's current output speed, many users run /debug tps to see how many tokens (text units AI uses for processing and billing) are processed per second. The per-second rate calculated by this command now excludes wait times from model retries and automatic conversation compaction.

A marathon runner checking average pace used to include time spent catching a breath at aid stations, and now those wait times are subtracted.
BUGFIX

Headless runs skip extra turn-summary calls

Scripts that run Grok automatically in the background often use headless mode (running without a terminal window or visual interface). These runs no longer trigger unnecessary model calls to generate turn summaries.

BUGFIX

Hooks keep separate identities with Grok Node settings

Some users configure Grok's own Node runtime settings in their environment and attach hooks (small programs triggered when specific events occur). Previously, whenever those Node settings were present, hooks shared the same identity. Now, even when Grok's own Node settings are in the environment, individual hooks no longer share a single identity.

FEATURE

Transcript message folding and edge autoscroll

As a conversation grows longer, rereading your earlier questions or selecting text across a full page can feel clunky. For longer user messages, pressing Enter or Ctrl+F directly in the transcript now expands or collapses the message. When dragging to select text from the transcript, the view now autoscrolls immediately as soon as the cursor reaches the pane edge.

Picture reading a long paper scroll where you used to unroll the whole thing and slide through slowly; now you can fold away the overly long section, and the scroll moves along as soon as your hand reaches the edge.
FEATURE

Ctrl+O copies latest reply; inline code keeps backticks

When you want to paste Grok's answer into notes or a document, you no longer need to drag your mouse over the whole block. Pressing Ctrl+O directly copies the latest assistant reply. When copying text from tables, question cards, or the fullscreen viewer, inline code now also includes backticks (paired marks used to delimit code) around it.

Imagine wanting to photocopy a key passage from a cookbook: you used to cover the margins with paper by hand and still lose your highlighter marks on the copy, whereas now one press copies the whole passage along with its markup.
BUGFIX

Sign-in rendering and multi-window state fixes

Switching accounts or working on legacy Windows can easily trip up the sign-in flow. The sign-in screen now renders properly on the legacy Windows console. After logging out or cancelling mid-login, returning to the sign-in screen starts fresh from the beginning. Browser sign-in completes against the login currently stored. If another window has already removed that login, the sign-in attempt is refused.

BUGFIX

Prevent premature keystrokes and stale welcome-screen clicks

Typing or clicking ahead of the screen used to make it easy to confirm by mistake or hit the wrong button. Before the folder trust prompt appears on screen, keystrokes typed ahead of time are no longer accepted. When clicking on the welcome screen, if the UI happens to change right before the next frame updates, that click no longer triggers the wrong action.

BUGFIX

Keep composer drafts during questions and fix the up arrow

When a question pops up for your response, you might be about to type an answer or editing a queued prompt. While a question is open and you are editing a queued prompt, your draft in the composer is now preserved even if that queued row suddenly disappears. In a question's text answer field, pressing the up arrow key now moves straight back to the previous option whenever the cursor is on the top line.

BUGFIX

Fix caret flicker when resizing in minimal mode or opening the sign-in chooser

Dragging a window edge to resize it, or opening the screen to pick a sign-in method, used to make the typing line jump around nonstop. That issue is fixed, so the caret no longer flickers when resizing the window in minimal mode or opening the sign-in chooser.

FEATURE

API-key model note now shows only once

When you open a model list to switch models, the screen includes a note about models that use an API key (a secret credential for verifying your identity with a service). That note now appears only the first time you open any model list and will not show up again afterward.

FEATURE

Windows Git helpers switch to bundled MinGit

Tracking file change history with Grok on your computer relies on small helper programs behind the scenes. Git (a version-control tool that tracks file change history) helpers on Windows now use the bundled MinGit binary.
