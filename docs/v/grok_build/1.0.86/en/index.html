Grok Build 1.0.86

Released: 2026-11-14

Release notes

FEATURE

URLs and File Links in Chat Open Effortlessly

Pasting web addresses or organizing local files in chat used to leave you with links you could not open directly. Now URLs typed in user messages appear as styled clickable links matching assistant links. When reading in Pretty mode, reference-style links that gather URLs at the end of a message display the same as inline links written directly in a sentence. Even when the confirmation card is visible on screen, holding Cmd and clicking or using Ctrl+click still opens links directly. If a path contains %20 space encodings, clicking the file link now opens the correct file instead of falsely reporting it missing.

FEATURE

Minimal-Mode /mcps Adds Server Source and Tool Summaries

When checking the list of connected MCP (a protocol that lets AI connect to external tools) servers with /mcps in minimal mode, the screen used to show only names. If you want to verify which external services are connected and what they can do, the list now labels each server's source location along with a summary of the tools it provides.

When checking a power strip, you used to see only a row of outlets without knowing which cord belonged to what; now each plug is labeled with its source appliance and purpose.
BUGFIX

Fix Tasks Pane Text Flickering While Work Is Running

When you handed work off to a background helper and watched progress in the Tasks pane, the subagent activity text shown there used to flicker constantly as it updated. That issue is now fixed, so the text no longer flickers while work is running.

BUGFIX

Double-Click on Thinking Blocks and Blank Row Areas Restored

When trying to collapse chat content or adjust the layout with a mouse, double-clicks occasionally stopped responding or a slight drag turned into highlighted text selection. Now double-clicking a thinking block (the collapsible area where AI shows its reasoning steps) folds or expands it properly again. Dragging from blank areas of rows no longer triggers a text selection, while preserving the original fold and unfold clicks.

FEATURE

Shortened Long File Paths Keep File or Folder Names Visible

When you narrow the window or dig into deep directories for a file, a truncated long path used to leave only a string of parent folders at the start without showing the target. Now long file paths shown in narrow columns stay recognizable after shortening. In four places—the change directory picker, Persona Source path, How-to Guides tip, and @-file search—overly long paths now prioritize keeping the final folder or file name visible. Paths ending in one or more slashes now shorten correctly as well, keeping the final folder name readable.

Picture writing a shipping address on a narrow label: previously only the city and district fit while the street number got cut off, whereas now the final destination always stays visible despite the tight width.
BUGFIX

Panels Stay Crash-Free and Hints Intact on Short or Narrow Terminals

When resizing a terminal window very short or narrow to compare with other screens, opening the search panel used to crash right away and key hints got sliced mid-word. Now the file-search and prompt-history panels no longer crash when the terminal is very short. Calling up the @ file picker in the dashboard now opens without crashing even on terminals shorter than 10 rows. On narrow terminals, key hints at the bottom of permission cards are no longer cut off mid-word. The cancel-turn panel now uses the correct text color and ellipsis when space gets narrow.

Think of sticky notes arranged on a desk: a smaller table used to send the whole stack sliding off or fold the writing in half, but now all the key labels stay intact no matter how short or narrow the window gets.
BUGFIX

Display Fixes for Pickers and Resume Session Cards

When browsing past conversations or picking items from a list, wrapped long text, halved wide characters, or half-filled highlights made menus hard to read. Resume session cards now keep long text and their ellipsis on a single line. Multi-line prompts in the session picker now show their ellipsis on the same row. Message previews and picker rows no longer get cut off when encountering wide characters such as Chinese or full-width text. Selected items in pickers now highlight their full row height. Content-search results in the resume picker also appear under a shorter heading.

FEATURE

Extensions Modal Sizing and Label Notice Adjustments

When opening the extensions modal to install or toggle items, the frame used to be noticeably narrower than other modals and result notices vanished in a flash. The extensions modal now keeps the same width as other modals instead of shrinking narrower. Pending action labels in the modal now consistently start with a capital letter. Result notices shown after extension actions now stay visible as long as other messages.

FEATURE

Layout and Hint Improvements for Settings and Feedback Modals

When adjusting options in the settings or feedback modals, overly long descriptions getting cut off or not finding a close button on a small screen could easily leave you stuck. Settings toggles and feedback messages now use consistent labels. Long setting descriptions in /settings now fit completely within the modal without being cut off by the border. When the terminal is too small, feedback and settings modals now show an Esc hint.

FEATURE

Clearer Command Error and Reset/Export Notice Formatting

When a command failed or preferences were reset, inconsistent prompt wording on screen often forced you to guess what went wrong. Error messages for failed actions now include the reason in a single sentence. Errors when running grok -p --resume with other flags (extra switches passed when running a command) are also clearer than before. Toast messages shown for settings resets and voice errors now follow a consistent format. Status messages seen after exporting a conversation with /export also match the style of other notices. Output messages across several CLI subcommands now use consistent punctuation and path quoting.

FEATURE

Updated borders and prompt text on welcome and sign-in screens

Every time you open the tool to complete account verification or check for new updates, the first steps you see are now tidier. The box on the welcome screen for entering your auth token (a credential for sign-in verification) now has rounded corners. Update notices on the same screen now align consistently. A few tips and labels on the welcome screen also use more consistent wording. The messages shown after copying during sign-in now read "Copied!", "Copy sent: verify paste", and "Copy failed".

FEATURE

Aligned text and styling across goal windows and dashboard sections

When switching between the main screen, goal modals, or the minimal view to check progress, the same information used to look different across views, which could easily get confusing. Todo lists in goal overlays now match the styling of the main Todo pane. Goal status labels displayed in the status bar and the goal modal now use consistent wording. Plan approval text in minimal mode now matches the fullscreen version. The dashboard footer now has even padding, and the location caption brightens on hover.

BUGFIX

Fixed item counts in file lists and overflow messages

When checking how many files the tool scanned at once, miscounted numbers or approximate counts make it hard to verify whether anything was missed. List tool rows now show the correct number of files and folders. Overflow messages now pluralize properly and display exact item counts.

FEATURE

Unified punctuation for status messages and preview dimensions

The three loading dots, terminal title capitalization, and image dimension formatting used to vary across views, and now symbol formatting is consistent throughout. Loading messages and input placeholders now use a consistent Unicode ellipsis character. Status messages and terminal titles also follow consistent capitalization rules. The transcript line indicating there is nothing to retry no longer ends with a period. Image preview overlays now use the multiplication sign when displaying dimensions.
