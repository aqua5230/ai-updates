Grok Build 1.0.72

發布日期：2026-10-27

繁體中文

新功能

對話輸出支援點擊跳轉，相對路徑與子代理標籤直達目標

翻閱終端機的對話紀錄時，經常需要查對助理提到的程式碼檔案或背景任務。

如同閱讀附帶豐富註腳的研究報告，以前讀到引用的附件名稱還得自己手動搜尋檔案路徑，現在只要滑鼠輕輕一點，就能直接翻開對應的文件頁面或作者備忘錄。

現在輸出中出現的相對檔案路徑，只要檔案位於目前工作階段的資料夾內，點擊就能直接開啟。紀錄裡提到的子代理（subagent，負責特定分工的輔助模型）與背景任務編號，點擊後也會直接切換到該檢視畫面或印出任務輸出。回覆中的 PR 編號點擊即可開啟遠端合併請求頁面。回覆完成後，文中提及的子代理更會換成好讀的標籤連結以開啟對話紀錄。在 Warp 終端機操作時，點擊折行的長網址也會開啟完整連結，不再只截取第一列。

新功能

工作流程檢視支援方向鍵導覽，快速穿梭階段與代理清單

推進多階段的自動化工作流程時，需要頻繁檢視各個執行環節中代理人的狀態。

好比用電視遙控器選取影集分季，按右鍵直接切入特定季度的集數選單，透過上下鍵挑選集數後按確認播放，按左鍵就能立刻退回季別目錄。

現在輸入 /workflow runs 進入詳細檢視畫面，可以完全透過鍵盤快速穿梭。按下向右鍵 → 或使用滑鼠點擊，能將焦點移至該階段的代理清單；按下向上鍵 ↑ 或向下鍵 ↓ 可選取特定代理，按下 Enter 就會開啟該代理；若想回到階段列表，只要按下向左鍵 ← 即可返回。

問題修復

回饋草稿獨立分列顯示，切換分頁重新整理維持選取

準備向開發團隊回報問題時，暫存的草稿如果和其他工具訊息混在一起，往往不容易翻找。

就像辦公桌上的專用待辦便條夾，以前所有草稿跟一般工具雜物塞在同一個抽屜，切換工作視角再回頭時便條還會移位；現在草稿獨立陳列，即使離開再回來也能精準夾在原本選取的那一頁。

現在回饋草稿（feedback draft，尚未送出的意見回報）會單獨成列顯示，不再擠在工具列群組內部。點選開啟其中一筆時，會直接顯示 /feedback 的草稿分頁並鎖定該筆內容。當草稿清單重新載入時（例如離開分頁後再返回），先前選取的草稿狀態也會完整保留。

問題修復

刪除確認預設移至取消，輸入審查備註不再誤觸核准

在終端機執行清理或審查等重大操作時，最怕手指敲太快不小心按錯鍵而造成意外改動。

跟填寫重要申請書的勾選欄一樣，以前筆尖預設停在確認簽署，稍微晃動或碰到按鍵就可能直接送出；現在焦點預設停在取消欄位，必須明確按下特定按鍵才會執行。

現在執行 /delete 指令時，確認提示預設停留在「Cancel」（取消）選項。按下鍵盤的 Enter 不再直接刪除工作階段，讀者必須明確按下 1 才會執行刪除。在計畫審查中輸入說明備註時，輸入框已能正確接收每一個字元，輸入以英文字母 a 開頭的備註時，不會再誤將計畫直接核准。

新功能

思考區塊支援自訂折行寬度，切換目錄即時更新派送框標籤

面對終端機裡長篇的推導內文或切換目錄時，版面排版與即時狀態回饋對工作節奏影響甚大。

宛如翻閱電子書時自訂版面邊距與章節標頭，以前調整內文欄寬毫無反應，換到新章節時書名也慢半拍；現在既能自由約束文字寬度，切換篇章時頂部路徑標示也會即時更新。

在 /settings 設定中，[ui].max_thoughts_width 現在能正確控制思考區塊（thinking block，模型產生推理過程的文字框）的折行寬度上限，解決了先前設定後完全無效的問題。在儀表板畫面中，只要按下快捷鍵 Ctrl+L 或透過 /cd 選取新的資料夾，派送框（dispatch box）上邊框就會立刻顯示最新資料夾名稱，無需等待後續動作刷新。

問題修復

自訂端點模型修復工具綱要錯誤，每輪不再跳出 HTTP 400

串接外部伺服器端點使用自訂模型時，每當模型試圖呼叫工具，最怕通訊協議格式對不上。

恰似拿轉接頭連接非原廠周邊設備，以前插頭上的接腳規範只要有一點出入，每次啟動設備就會直接跳電報警；現在通訊綱要規格完全符合標準，連線後每輪工具調用都能順暢進行。

透過 Responses API 搭配自訂網址（base_url）使用自訂模型時，先前每一輪只要發起 use_tool，就會因為結構規範不符而觸發 HTTP 400 錯誤。這項問題已經修好，自訂端點模型在每輪對話調用工具時不再報錯中斷。

問題修復

MCP 工具呼叫節省一半上下文，修復標準輸入輸出長行截斷

替 AI 掛載外部工具來擴充能力時，工具回傳資料的長度與穩定度直接決定了整場對話的品質。

好似快遞站簽收包裹回執，以前每件貨品都會重複影印兩次塞滿存檔箱，傳輸遇上震盪時長清單還會被撕毀截斷；現在單次回報只附一份單據，即便中途讀取受干擾也不會遺失內容。

許多開發者會使用 FastMCP 或官方開發套件擴充功能。現在這類依據 MCP（Model Context Protocol，讓 AI 連接外部工具的協定）建置的工具，傳回結果給模型時只會傳送一次而非兩次，每次呼叫消耗的上下文空間直接減半。透過標準輸入輸出（stdio）運行的伺服器，若讀取流程中途遭到中斷，也不會再遺失長回覆列的一部分，面對龐大的工具清單也能完整接收。

English

FEATURE

Relative Paths and Subagent Labels Link Directly on Click

When reviewing transcripts in the terminal, you often need to check code files or background tasks mentioned by the assistant.

Reading through an annotated research report once meant manually searching for cited attachments; now a single click directly opens the referenced document page or author memo.

Relative file paths in the output now open directly on click when the file exists under the current session folder. Clicking a subagent (auxiliary models handling specialized tasks) or background task ID mentioned in the transcript now switches to that subagent view or prints the task output. Clicking a pull request number in a reply opens the remote pull request page. Once a reply finishes, mentioned subagents are replaced with readable label links to open their transcripts. When working in Warp, clicking a URL that wraps across rows opens the full link instead of only its first row.

FEATURE

Arrow-Key Navigation for Workflow Runs Between Phases and Agents

When driving multi-phase automated workflows, you frequently need to check the status of agents across each stage.

Picture using a TV remote to navigate seasons of a show: pressing right jumps into an episode list for a season, up and down pick an episode to play on confirmation, and pressing left returns to the season directory.

Entering /workflow runs to open the detail view now allows full navigation purely from the keyboard. Pressing → or clicking with the mouse focuses a phase's agent list. Pressing ↑ or ↓ picks a specific agent, pressing Enter opens it, and pressing ← returns to the phase list.

BUGFIX

Feedback Drafts Stand Alone, Preserving Selection Across Tab Reloads

When preparing to report an issue to the development team, drafts mixed in with tool messages are often hard to locate.

Think of a dedicated desk clip for to-do notes: loose drafts once mingled with miscellaneous tools inside a drawer and shifted when looking away, but now drafts stand on their own and stay clipped to the selected page even when you step away and return.

Feedback drafts (unsent feedback reports) now appear on their own rows instead of being crowded inside a group of tool rows. Opening one immediately displays the /feedback Drafts tab with that entry selected. When the draft list reloads (such as after leaving the tab and returning), the previously selected draft state is also fully preserved.

BUGFIX

Delete Confirmation Defaults to Cancel, Preventing Accidental Plan Approvals

When running major operations like cleanup or reviews in the terminal, accidental keystrokes can trigger unintended changes.

A critical application form once placed your pen by default on the approval box where a slight slip could submit it; now focus rests on cancel, requiring an explicit keystroke to proceed.

Running the /delete command now places confirmation on "Cancel" by default. Pressing Enter no longer deletes the session directly, requiring an explicit press of 1 to execute the deletion. When entering notes during plan review, the input field properly accepts every character. Typing a note that starts with a no longer mistakenly approves the plan.

FEATURE

Custom Wrapping Width for Thinking Blocks and Instant Dispatch Box Label Updates

Facing long reasoning output or switching directories in the terminal, layout structure and instant state feedback heavily influence your workflow rhythm.

Adjusting margins and chapter headers in an e-reader once produced no response when changing column widths while header titles lagged behind; now text width conforms reliably and top navigation updates instantly when switching sections.

In /settings, [ui].max_thoughts_width now properly controls the maximum wrapping width for thinking blocks (text boxes displaying model reasoning steps), resolving an issue where the setting previously had no effect. In the dashboard, pressing Ctrl+L or picking a new folder with /cd immediately displays the latest folder name on the top border of the dispatch box without waiting for subsequent actions to refresh.

BUGFIX

Custom Endpoint Models Fix Tool Schema Errors, Eliminating HTTP 400 Failures

When connecting to external server endpoints to use custom models, mismatched protocol formats are a major hazard whenever a model tries to invoke tools.

A third-party peripheral plugged into an adapter once tripped the breaker whenever pinout standards differed slightly; now communication schemas conform precisely, allowing smooth tool execution on every cycle.

When using custom models on the Responses API with a custom URL (base_url), every turn calling use_tool previously failed with an HTTP 400 error due to schema mismatches. This issue has been fixed, and custom endpoint models no longer abort with errors when calling tools during each turn.

BUGFIX

MCP Tool Calls Halve Context Usage, Fixing Truncation on Stdio Long Lines

When attaching external tools to expand AI capabilities, the length and stability of returned data directly determine conversation quality.

Courier receipts at a delivery hub once filled archive bins by printing duplicates for every package while transit bumps ripped long manifests; now each report attaches a single slip, preserving contents even when reading encounters interruptions.

Many developers use FastMCP or the official SDK to extend features. Tools built with MCP (Model Context Protocol, a protocol connecting AI to external tools) now return results to the model once instead of twice, cutting context usage by half per call. Servers running over stdio no longer lose part of a long reply line when a read is interrupted, ensuring large tool lists are received in full.
