Claude Code 2.1.179

發布日期：2026-06-16

繁體中文

新功能

連線斷掉不再吐原始錯誤、轉圈不再卡住，遠端背景任務也不再僵死

連線出狀況時不再嚇到你、也不再假裝還在跑。

如果 Claude 回答到一半連線斷掉，以前會直接丟一段原始錯誤訊息（raw error，給工程師看、未經包裝的報錯）給你，而且轉圈動畫會卡在「running tool」（執行工具中）不動；現在會把你已經收到的那部分回答保留下來，不會整個消失。遠端工作階段（remote session，連到別台機器跑的對話）裡，背景任務以前會在兩輪之間一直顯示「still running」（還在跑）像僵在那裡，現在狀態更新鮮準確。另外遠端工作階段載入外掛（plugin，擴充功能的附加元件）也變快了。就像看電視直播，以前訊號一斷就蹦出亂碼錯誤畫面、轉圈卡死，而且字幕機明明播完了還顯示「播放中」；現在斷訊會留住最後畫面、狀態老實、換台也更快。

問題修復

Linux 與 WSL2 不再卡死：捲動恢復、超大資料夾不再撐爆工具說明

Linux 和 WSL2（在 Windows 裡跑 Linux 的子系統）兩個會把整個工作階段搞到不能用的問題修好了。

在 WSL2 下用 Windows Terminal 或 VS Code 時，滾輪捲動以前會壞掉（這是 2.1.172 版的回歸，regression，改一個東西卻不小心弄壞另一個的狀況），現在恢復正常。另外在 Linux 上，如果你用沙盒（sandbox，把程式關在限制範圍裡跑的安全機制）的 denyRead／allowRead（禁止讀／允許讀的規則）對一個超大資料夾樹設了 glob（用萬用字元一次匹配很多路徑的規則寫法），以前會讓 Bash 工具的說明文字爆膨到巨大、整個工作階段卡到不能用，現在修好了。就像翻一本目錄亂掉的厚重年鑑，以前翻不到下一頁、或某個章節的索引突然印了幾千頁把書撐爆；現在翻頁正常、索引也精簡了。

問題修復

按 Ctrl+O 看得到子代理的對話紀錄、點輸入框能拿回焦點

查看子代理（subagent，Claude 分身去辦小事的代理）的兩個面板操作修順了。

你按 Ctrl+O 想看某個子代理的對話紀錄（transcript，逐字留下的完整對話歷程）時，以前什麼都不顯示，現在能正常看到。另外，當焦點（focus，鍵盤輸入目前對準的目標）停在子代理面板或底部資訊列時，你用滑鼠點一下輸入框，以前焦點不會跳回輸入框、害你打字打到一半沒反應，現在會正常回到輸入框。就像翻閱某位同事的工作紀錄本，以前打開是空白的、而且喊他回座位他卻還黏在茶水間；現在紀錄看得到、一喊就回座。

問題修復

問卷不再把單字當評分、歡迎畫面不再疊一堆廣告

兩個會誤判你輸入、或塞太多東西給你的小毛病修好了。

一輪對話剛結束時，只輸入一個數字時，不會再被當成工作階段評分。歡迎畫面以前會把好幾個宣傳橫幅（promotional banners，推銷新功能的廣告條）疊在一起，現在一次最多只顯示一個。就像服務生在你吃完飯時，以前把你隨口講的一個數字當成滿意度打分數，而且門口還貼了三層傳單擋住視線；現在問卷不會亂猜、門口也只留一張海報。

English

FEATURE

Dropped connections stop spitting raw errors, the spinner stops sticking, and remote background tasks stop looking frozen

Connection hiccups no longer startle you or pretend to still be running.

If the connection drops while Claude is mid-answer, you used to get a raw error (an unvarnished message meant for engineers) dumped in your face, and the spinner would stick at "running tool"; now the partial answer you'd already received is preserved instead of vanishing. In remote sessions (conversations running against another machine), background tasks used to keep reading "still running" between turns as if frozen; their status is fresh and accurate now. Remote-session plugin (add-ons that extend features) loading is faster too. Like watching a live TV broadcast that used to throw a garbled error screen the instant the signal cut, freeze its spinner, and leave the caption machine reading "now playing" after the show ended — now a cut keeps the last frame, the status stays honest, and channel changes are quicker.

BUGFIX

Linux and WSL2 stop seizing up: scrolling works again, and huge folders no longer bloat the tool description to death

Two issues on Linux and WSL2 (the subsystem that runs Linux inside Windows) that could make an entire session unusable are fixed.

Mouse-wheel scrolling in WSL2 under Windows Terminal and VS Code used to break (a regression in 2.1.172, regression meaning a change that accidentally broke something else); it works again. And on Linux, if you set a sandbox (the mechanism that traps a program inside a restricted zone) denyRead/allowRead rule as a glob (a pattern using wildcards to match many paths at once) over a huge directory tree, it used to bloat the Bash tool's description text to an enormous size and freeze the whole session; that's fixed. Like thumbing through a heavy yearbook whose index was scrambled — you couldn't turn the page, or one chapter's index suddenly ran to thousands of pages and burst the binding; now pages turn fine and the index is trim.

BUGFIX

Ctrl+O shows a subagent's transcript again, and clicking the input box reclaims focus

Two panel operations for inspecting a subagent (an agent Claude splits off to handle small chores) are fixed.

When you pressed Ctrl+O to view a subagent's transcript (the verbatim full conversation history), it used to show nothing; it displays properly now. And when focus (the target your keyboard input is currently aimed at) was sitting on the subagent or footer panel, clicking the input box used to fail to jump focus back — so your typing would go unresponsive mid-sentence; it returns to the input box properly now. Like opening a colleague's work logbook that used to come up blank, and calling them back to their desk only to find them still glued to the break room — now the log shows and they come back the moment you call.

BUGFIX

The survey stops reading a single word as your rating, and the welcome screen stops stacking ads

Two small nuisances that misread your input or shove too much at you are fixed.

Right after a turn finished, typing a single-digit reply will no longer be captured as your session rating (a 1-to-5-style satisfaction score). The welcome screen used to stack multiple promotional banners (ad strips plugging new features); now at most one promo shows per session. Like a waiter who, after your meal, used to read one casual number you mumbled as a satisfaction score, while the doorway was plastered with three layers of flyers blocking your view — now the survey stops guessing and the doorway keeps just one poster.
