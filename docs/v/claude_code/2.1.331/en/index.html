Claude Code 2.1.331

Released: 2026-11-23

Release notes

FEATURE

Code Mode in Terminal Supports Four Cloud Platforms

Enterprises and developers running terminal sessions through cloud services previously could not enable Code Mode. Amazon Bedrock and Google Cloud's Agent Platform are now supported. Microsoft Foundry and Claude Platform on AWS can use this mode as well.

Think of switching your home to a different electric utility: once you plug in, your existing appliances keep running without buying a whole new set of equipment.
FEATURE

Gateway Adds oidc.groups_jsonpath

When authentication returns group data wrapped inside a list of objects, you can now read it directly from matching entries. Administrators can add the oidc.groups_jsonpath key to the Claude apps gateway to read groups with a compact version of JSONPath (a query syntax for picking fields from a data structure). This query syntax supports a small subset of the RFC 9535 standard.

Picture receiving a long itemized bill where you used to scan the whole page, and now placing a stencil over it so only the matching group names show through.
FEATURE

claude doctor Adds API Connectivity Check

If you cannot reach the API and want to check the connection, you can run claude doctor. This diagnostic command adds an API connectivity check section that tells you directly whether the API is reachable. When it succeeds or fails, the screen includes the HTTP status code or error message; if the test did not run, it also explains why it was skipped.

Like a diagnostic scanner at an auto repair shop, plugging it in not only tells you if the engine runs smoothly, it also prints the fault code or notes which item was not tested this time.
FEATURE

Tap-Mode Dictation Shows Notice on Auto-Stop

Realizing mid-sentence that the microphone stopped long ago can happen with voice input too. Now when using tap-to-start voice dictation, a reminder notice pops up on screen whenever it ends automatically after 15 seconds without recognized speech or upon hitting the 2-minute per-session limit.

A coin-operated karaoke booth cuts off the mic and rings a bell when time is up, and dictation now displays a notice when it stops on its own.
FEATURE

New Environment Variable Avoids Proxy Truncating Compressed Responses

If a company or team network proxy cuts off compressed model responses mid-stream, conversations often fail halfway through. You can now set the environment variable CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION to request uncompressed response content and avoid truncation. However, enabling this option is not yet recommended on self-hosted runners (machines set up by a company or individual to run automated tasks) or Remote Control.

Just as with ocean freight, when you worry a vacuum-sealed bag might get slashed, you ship in the original box instead, though certain routes are off-limits for now.
FEATURE

Gateway Supports Sending IdP Hostname via Proxy

When managing a Claude apps gateway with oidc.use_proxy: true enabled, write the configuration file as follows: {"oidc": {"use_proxy": true}} The new environment variable (a setting read when starting a program) can be set to CLAUDE_GATEWAY_IDP_CONNECT_BY_HOSTNAME=1. Even with NO_PROXY (the list of addresses that bypass the proxy) set, sign-in requests still pass the HTTPS identity provider's hostname to the proxy.

Imagine a freight service with a "direct delivery, skip the transfer hub" list: once this special label is attached, encrypted packages still hand their destination address to the transfer hub.
FEATURE

Model Request Traces Add Usage and Model Details

For administrators and developers using telemetry tracing: when checking logs in the past, you often could not see the actual operation, which version responded, or how many resources were spent. Now these trace records include the operation name, the model that actually responded, and usage metrics. When counting input usage, prompt caching (temporarily storing repeated content for direct reading) is included as well. The input token (text unit processed and billed by AI) count in these model request trace records does include this usage.

Comparing this to checking a maintenance work order, the form used to say only that a job was dispatched, whereas now it lists the task performed, which machine was used, and the consumption including spare materials.
FEATURE

Plugin Manifests Add Independently Removable Optional Packages

Installing a plugin only to be forced into a bundle of unused extras is frustrating for both developers and users. Plugin authors can now add optionalDependencies to a plugin manifest to list optional dependent plugins. Those optional items install alongside the main plugin, and afterward you can disable or uninstall any of them on their own at any time without affecting the main plugin.

It feels like buying a sofa that comes with throw pillows: they arrive together at your door, yet you can put away any pillow you do not want whenever you like.
FEATURE

Confirmation Options Put "Yes" First While Defaulting to "No"

When running /ide to stop auto-connect, or calling /clear, /compact, or /rewind in a subagent view, the option order in the confirmation dialog has changed. The option list now puts "Yes" on the first line and "No" below it, while the default cursor still starts on "No". If you press "Down" and then Enter out of old habit, you will now select "No".

Suppose a remote control swaps the confirm and cancel buttons vertically: even though the cursor still starts on cancel, pressing down the old way picks the wrong one.
FEATURE

Adjust Retry Rules for PermissionDenied Hook

When the PermissionDenied hook (a small program triggered automatically when a specific event occurs) returns retry: true, retrying now has an extra safeguard. Claude only resends the refused call if you actually asked for that call.

Resending registered mail at a post office counter works the same way: the clerk first verifies that you were the one who sent the letter before mailing it again.
FEATURE

Managed plugin marketplaces will auto-update by default

For administrators managing enterprise or team-controlled environments: if your team uses managed settings to centrally list plugin sources, take note of an upcoming rule change. In a future release on or after November 30, 2026, plugin marketplaces listed in extraKnownMarketplaces will auto-update by default. If you do not want a specific marketplace to upgrade automatically, remember to add "autoUpdate": false to its entry to turn it off manually.

Consider a newspaper subscription: after the set date, delivery happens automatically every day by default, and you have to post a stop-delivery notice first for any paper you do not want to receive.
FEATURE

Check Windows registry managed settings before upgrading

If your environment pushes settings centrally through system policies, make sure there are no mistakes in them before updating. Administrators on Windows who rely on the registry for managed settings should inspect those entries before upgrading. Because policy settings in HKLM take precedence over the local managed-settings.json, a broken value in the registry can prevent the program from starting.

When headquarters issues a bulletin, it overrides local branch rules, so a misprint on that main notice can keep the entire branch from opening that day.
BUGFIX

Code Mode session resume and long output fixes

Code Mode in the terminal fixes several issues affecting execution and output. Resuming a session in a different permission mode with --resume or --continue no longer loses thinking or the prompt cache; a session started in a mode that asks still keeps that mode's limits on scripts. Typing ! or a slash command while a script is still running no longer fires off a request every second. Long script outputs no longer lose their middle section, and Claude now receives a file path to the full uncut text. When running with --bare, Claude is now properly informed of what its scripts can call. Tool search also displays more of an MCP (a protocol that lets AI connect to external tools) tool's description, including its limits, formats, and defaults.

BUGFIX

Fixes for narrow and short terminal layouts and lists

When screen space is pulled narrow or squashed short, key hints, choices, and text can easily get cut off or cramped. Single-line tool results in narrow windows now include an ellipsis when truncated. The Auto mode tab in /permissions no longer leaves stray Markdown stars, and a hook's reason for stopping a forked skill no longer prints twice. /diff no longer hides key hints or fails to select files in windows of 24 to 26 rows. Files added with git add -N are also listed in Git repositories with no commits yet. Short windows now show enough themes during first-run setup, and tall screens like /usage no longer come out garbled. When running /bug in fullscreen, a long report no longer covers the "Yes" and "No" buttons, and "Yes" stays visible even in very short windows. Fullscreen /cd and /add-dir trust prompts now display their choices in fewer rows, and the launch prompt keeps the folder path visible when it has many warnings.

BUGFIX

Fixes for hanging plugin installs and partial updates

Several issues that caused hangs or missing components when installing or auto-updating plugins have been resolved. An interrupted or failed plugin update no longer leaves behind a partial folder that later loads with missing skills or other components. Commands such as claude plugin install and marketplace add no longer hang with no output when managed settings require an approval that cannot be prompted. The plugin auto-update notice now lists newly installed dependency plugins separately from the updated plugins.

BUGFIX

Fixes for subagent messaging and Workflow agent cleanup

When splitting complex work across multiple background helpers in parallel, messages could occasionally disappear or resources could stay open after the work finished. Claude now receives a clear notification when permission rules on the Agent tool block and drop a queued message sent to a subagent that has already ended. Permission rules restricting a subagent's model, such as Agent(model:*), no longer mistakenly block follow-up messages to a subagent started on this version with no model specified. After a Workflow agent hands back its report, its background shells (programs that interpret and run commands) and MCP servers now exit properly instead of staying running.

BUGFIX

Fixes for hung tools, long reply timeouts, and freezes

When a connection stalls or waits for a response, the terminal no longer waits indefinitely or freezes up. MCP tool calls no longer hang for up to 30 minutes when a local or WebSocket server returns a malformed reply. When a reply goes silent while Claude is still thinking, turns and subagents in cloud sessions no longer fail immediately, and long replies elsewhere no longer time out right away. Claude Code automatically retries the request once. Pressing Esc or clicking Stop when reading a cloud or network file stalls no longer waits about a minute or more. The CLI no longer freezes on certain replies, and quoted text no longer disappears or shows up twice.

BUGFIX

Windows startup, install, and memory stability fixes

Installation flow, startup stability, and command responsiveness have all been improved on Windows. Running /desktop no longer downloads the older Claude Desktop installer, and it no longer triggers a false update prompt even if an older installation folder is left behind. Startup now works properly even when managed settings in the registry contain non-ASCII characters such as Japanese. A possible crash when the machine is nearly out of memory has been fixed. The first Bash command in a session also runs faster on machines without custom shell start-up files.

BUGFIX

Fixed repeated permission prompts on FAT32 drives

When writing files to FAT32 or exFAT drives during certain plugin sessions on Windows, you previously had to click Allow every single time. This issue is fixed, and permission prompts no longer pop up repeatedly.

BUGFIX

Fixed Windows Remote Control missing new subagent steps

When tracking task progress in a Windows Remote Control client, a newly started subagent could already be working without the screen listing what it did. This issue is fixed, and those steps now display properly.

BUGFIX

Fix PushNotification status misreporting in headless runs

When running automated tasks such as scheduled runs in headless mode (running without a terminal window), PushNotification previously reported that the terminal was active during its first minute. This has been fixed, and it now accurately reports whether a mobile push was requested.

BUGFIX

Fix `/install-github-app` skipping steps

After running /install-github-app found no repositories and showed setup warnings, it previously skipped the repository selection step. Pressing Esc to go back from the workflow list or sign-in steps also failed to work. Both issues have been fixed.

BUGFIX

Fix conversation compaction losing summary on certain XML tags

When trimming down a long conversation midway through, the condensed summary could previously lose a section if the discussion happened to quote certain markup syntax. Now, when running /compact or auto-compact, the summary content stays intact even when specific XML tags appear in it.

BUGFIX

Fix Remote Control messages appearing above replies

When sending the next message just as the text on screen was finishing, the conversation order could previously get mixed up. In Remote Control, a newly sent message will no longer appear out of place above that reply.

BUGFIX

Fix Stop hooks missing the last reply

In Claude Desktop, Stop hooks configured to read the conversation transcript previously missed the last reply. This has been fixed, and SubagentStop hooks now wait for that reply to appear before running.

BUGFIX

Fix failures reading notebooks with certain outputs

When asking Claude to inspect a notebook containing execution results, it previously failed to read the following outputs. Outputs that are null (no value) can now be read normally. Error outputs without a traceback (call trace information from when an error occurred) will also no longer cause notebook reads to fail.

BUGFIX

Fix rewind deleting files after a failed restore

When using rewind to roll files back to a previous state, if the restore step failed midway, it would previously delete the files. This has been fixed, so files are no longer deleted after a failed restore.

BUGFIX

Fix auto mode refusing to stop `/loop`

In auto mode, when asking Claude to stop a scheduled /loop, its stop call was previously sometimes refused, causing the next scheduled wake-up to keep running. This has been fixed.

BUGFIX

Fix hooks not saving skill allow rules across settings files

When using a PermissionRequest hook, trying to save allow rules like Skill(name:*) to a settings file outside local settings previously failed. This has been fixed, and they can now be written to settings files in other scopes.

BUGFIX

When blocked by your team's pooled group budget, the "Ask your admin" screen previously asked you to request raising your own limit. If an admin had just approved your request, it also continued to display "Request sent". Both incorrect prompts have been fixed.

BUGFIX

When Claude Code was busy handling other work, hold-to-talk voice dictation used to disconnect early and drop several words. This issue is now fixed, so hold-to-talk dictation no longer cuts off early or drops words while busy.

BUGFIX

When connected to a self-hosted external interface, if it returned a command request missing a name, the entire conversation used to crash and stop. Now such an unnamed tool call fails with an error instead, and the existing session continues.

When asking a question and only wanting to pull a few lines of code to discuss, the system used to cram the whole document into the conversation. Now, when specifying line numbers with a mention like @file#10-12, only lines 10 to 12 are attached.

BUGFIX

Fix Accidental Triggers from Quick Double Clicks in VS Code Panel

When double-clicking quickly, the second click previously could press a newly appeared button or row, or accidentally start a second compaction on the context usage circle. This accidental trigger issue in the VS Code panel is now fixed.

BUGFIX

Fix Leftover Tab Helper Processes When Typing @

Typing @ in VS Code without a browser connected previously left a helper process running in the background per tab. This issue is fixed, and processes are no longer left behind unless Claude in Chrome's service cannot be reached.
