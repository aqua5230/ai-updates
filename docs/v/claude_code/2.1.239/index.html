預算估算納入美區溢價，額度耗盡立即停損

你設定了預算上限，卻老是抓不準何時該停手或何時額度重設。現在輸入 /cost、查看狀態列或指定 --max-budget-usd 10.0 旗標時，針對有資料落地限制的工作區，系統會將僅限美國推論的 1.1 倍加成自動計入花費預估。當月度花費額度耗盡時，用量上限提示現在會同步標明你的工作階段（session）或每週額度何時重置。若你開啟了持續重試模式 CLAUDE_CODE_RETRY_WATCHDOG=1，一旦遇到組織花費上限或額度用光，程式會立即失敗結束，不會再無休止地空等重設。VSCode 橫幅裡的查看用量按鈕也調整至警示文字同一行。

這好比智慧電表不僅在計費時把尖峰加成算得一清二楚，在用電超標時也會列出各項額度何時重置，遇到總開關跳電時更會果斷切斷供電，不再讓電器徒勞空轉。

代理伺服器計費防重複，Bedrock 與網頁連線更穩

在公司內部網路透過代理伺服器使用 Claude 時，連線與計費更加可靠。以前在 Bedrock 平台後方遇到移除回應標頭的代理伺服器，系統會誤以為串流（streaming）失敗而私下以非串流重跑，造成 API 計費莫名翻倍；現已修正。同時，若在 Bedrock 搭配 SSO 與 awsAuthRefresh，啟動前的憑證（credentials）預先檢查現在會遵循 export HTTPS_PROXY="http://proxy.corp.com:8080" 代理變數，解決卡死問題。在網頁版工作階段中，來自 Bash 等工具前往 non-API 網域的請求也會正確走代理連線，落實網域白名單。

如同貨物經由海關通道進出，通道剝掉標籤不會被重複扣稅，人員換證走專用窗口，確保物流全在許可路徑通行。

隊友上線名單一覽無遺，Windows 跨工作階段通訊

就像拿對講機呼叫隊友時，通話機上會清楚顯示自己的呼號，螢幕也能列出頻道內所有在線的隊員，就算隊呼開頭帶有斜線符號也不會變成幽靈人口。

現在多代理人（agent）協作的通訊機制全面完善。執行 ListAgents 或輸入 /list-agents 時，清單中會列出所有在線的活隊友，不再像以往只顯示子代理與其他工作階段而漏掉身旁隊友。工作階段（session）現在能透過 ListAgents 獲知同儕用來聯絡自己的名稱；若誤向自己發送 SendMessage，系統會明確提醒那是你自己的名字，而非回報找不到該對象。此外，標題以 / 開頭的工作階段不再顯示為無標題且可正常通訊，Windows 平台也正式支援跨工作階段傳訊，跨機器協作與 macOS 及 Linux 同步。

長期任務背景防打擾，目標還原與容器保活

把耗時的任務交給背景執行，你不再需要被頻繁的打擾打斷工作節奏。現在使用 /goal 執行長任務時，簽到間隔會逐步拉長，從 30 分鐘延長至 1 小時，之後每 2 小時一次，不再每半小時重複打擾。若你透過 claude --resume 挑選並接續工作階段（session），系統會自動還原該對話中進行中的活躍目標。針對遠端與雲端工作階段，在執行耗時的 SessionStart 或 Setup 掛鉤（hook，特定事件觸發的小程式）期間會持續發送保活訊號，防止容器在掛鉤執行途中被當成閒置而回收。此外，閒置背景工作者重啟後也能穩定維持原有的計畫模式。

這好比參加長途耐力賽，沿途補給站會隨著賽程拉長而自動拉開打卡間距避免打擾跑者，選手暫停回帳棚休息後重返賽道依然能接續目標，後勤車輛也持續回傳心跳訊號防止被判定棄賽。

遠端遙控標題同步限流，手機傳圖與分頁清理

當你用手機或遠端遙控操控電腦上的 Claude 時，多裝置協作變得更穩定。現在當兩個處理程序共用同一個背景任務狀態時，遠端遙控的標題同步會自動去重並進行速率限制，解決標題瘋狂洗版的問題。透過手機上傳至遠端工作階段（session）的圖片，現在會附帶本機儲存檔案路徑，讓 Claude 能直接將圖片複製進新建立的檔案中。如果你的帳號尚未開通 Remote Control 功能，終端機與 claude doctor 會顯示更清晰易懂的診斷說明。此外，在 Chrome 瀏覽器整合中，輸入 /clear 會關閉該工作階段的分頁群組，執行 /resume 或結束程式時也會順手清理空白群組。

這有如跨國團隊共用的遠端戰情白板，兩地同時更新進度時不再瘋狂閃爍洗版，隊員隨手從手機上傳的現場照片會清楚標記檔案櫃編號，下班或清空白板時也會順手把用完的暫存便籤整組撕除。

自訂對話標題長久留存，路徑識別與目錄容錯

辛辛苦苦為對話取了自訂名稱，卻在聊了幾輪後突然在清單裡找不到。這次修復了多項接續工作階段（session）的歷史紀錄問題。以前為對話改名後只要後續對話超過約 64 KB，自訂標題就會在 /resume 選單中消失，即使後續對話超過約 64 KB，標題仍會留在 /resume 清單中。使用 claude -c 或接續功能時，路徑若僅有底線、連字號或點號等符號差異，系統不再錯誤抓取其他資料夾的對話。只是重新開啟對話或檔案被外部觸碰，不會再被誤判為最近更新而擾亂排序。在全專案模式下，若對話原本的工作目錄（例如已被刪除的工作樹副本）已不存在，系統會直接在當前目錄接續，不再叫你切換進不存在的資料夾。

就像辦公室的檔案櫃，抽屜上的自訂標籤不會因為文件越塞越厚而脫落，翻閱檔案時不會把順序弄亂，即使原本歸檔的辦公桌拆除了，也能就地在手邊的桌面攤開繼續處理。

全螢幕支援雲端平台，焦點防誤觸與深色對比

就像走進升級後的巨幕影廳，剪票員只在進場時貼心引導座位且三次無人回應就自動安靜，觀眾轉頭拿爆米花點擊螢幕聚焦時也不會誤觸緊急按鈕。

全螢幕模式（fullscreen mode）的初次體驗與操作細節迎來重要修正。在 Bedrock、Vertex、Foundry 等以往排除的雲端平台上，現在也會提供單次全螢幕提示，新安裝環境更會預設直接以全螢幕啟動。如果終端機環境無法回應全螢幕提示，系統在連續提示 3 次後便會自動停止詢問，不再每次啟動都跳出提示洗版。當終端機視窗失去焦點時，你隨手點擊視窗切換焦點，不會再誤按授權提示或送出按鈕。而在深色主題 dark-ansi 下，全螢幕展開工具結果時文字顏色與背景同色的對比度問題也已徹底排除。

全螢幕表單支援捲動，面板與對話框排版修復

在全螢幕下叫出長表單或設定面板，常遇到按鈕被邊界切斷或擋住最新對話。現在全螢幕模式下的視窗排版與彈跳對話框變得更清晰。當 MCP（讓 AI 連接外部工具的協定）的互動表單高度超出終端機視窗時，表單會自動縮放貼合視窗，隱藏欄位可透過捲動瀏覽，而接受與拒絕按鈕會固定在底部始終可見。輸入 /config 或 /model 等斜線指令叫出設定面板時，對話內容會保持固定在面板上方，不再被面板直接遮蔽。此外，在 Claude 正在輸出回覆時打開 /workflows 工作流詳細對話框，視窗也不會再超出終端機而導致標頭被擠出螢幕外。

這如同影廳側邊浮現的互動控制面板，長條選單能隨意上下滾動且底部的確認與取消鍵永遠置頂可見，彈出設定表單時也不會硬生生遮住正在播放的主畫面。

Readline 快速鍵對齊 Bash，文字選取與搜尋修復

習慣終端機快速鍵的開發者，現在游標移動與編輯更順手。在 ~/.claude/settings.json 加入 {"keybindingFlavor": "readline"} 後，單字跳轉與刪除（Alt+F、Ctrl/Option+→、Alt+D，可用 Ctrl+Y 貼回）對齊 Bash 並以標點分詞。搜尋框按 Ctrl+Backspace 改為刪除單字。Shift 延伸選取後 selection:copy 不再漏字。游標在 [Pasted text #N] 內以 Ctrl+W、Ctrl+U、Ctrl+K、Option+Backspace、Option+D 或 vim df/dt 刪除不留損毀片段。代理人視圖 vim 模式按 Escape 切回 NORMAL 模式並保留輸入。

猶如鋼琴家在琴鍵上滑音，跳轉精準停在音符上，剪下片段不漏音也不破壞樂譜。

密碼輸入防外洩，過濾瀏覽器終端滑鼠雜訊

在終端機輸入登入驗證碼或移動滑鼠時，敏感字串與雜訊字元容易意外洩漏或干擾輸入欄位。以前在密碼遮罩輸入框中輸入的敏感文字，若按兩次 Esc 清除，可能會殘留在歷史紀錄或被 Ctrl+Y 意外貼出；現在機密文字已被嚴格隔離。在瀏覽器型終端機中，滑鼠移動回報若分段寫入，曾會將 "35;150;7M" 等座標字串誤塞進提示欄，現已全面過濾乾淨。

這好比在提款機輸入密碼時上方加裝了防窺遮光罩，按完清除鍵後不會在暫存剪貼簿留下痕跡，滑鼠在螢幕旁晃動也不會誤輸入雜訊代碼。

Shell 模式補全保留路徑前綴，腳本執行零阻礙

當你在命令列前加上驚嘆號切換至 Shell 模式（以 ! 開頭），並按下 Tab 鍵補全本機腳本路徑時，指令能直接正確執行。以前輸入 ./script 並按 Tab 鍵進行自動補全時，系統會自動剔除前方的 ./ 前綴，導致補全後的指令因為缺少當前目錄路徑而無法被 Shell 辨識與執行；現在補全時會完整保留 ./ 標記。

如同在快遞包裹上填寫收件地址時，自動校正地址會完整保留代表同一社區的門牌前綴，快遞員不會因缺少起點標記而找不到門牌。

外掛雲端同步獨立管理，市集根目錄設定生效

在雲端與本機同步外掛時，套件管理變得井然有序。在雲端工作階段（session）中，由 claude.ai 同步的外掛會明確標記為 name@synced，你可以透過 claude plugin enable <name>@synced 或 claude plugin disable <name>@synced 獨立開關，且永不覆蓋本機自行安裝的同名外掛。此外，在外掛市集設定 {"metadata": {"pluginRoot": "packages"}} 後，純外掛來源名稱會如說明文件所述正確解析至該子目錄下。

如同工匠專屬工具箱，從總部借來的公用工具會貼上專用標籤獨立收納，不僅能各自獨立取用，也絕不會覆蓋自己手邊同名的私家工具。

遠端 MCP 伺服器短暫中斷自動復原，連線更穩固

就像天文觀測站與遠端望遠鏡連線時，偶爾遭遇大氣干擾造成短暫訊號中斷，在線路恢復後系統會自動重新連線，不會讓昂貴的儀器永久停擺。

遠端 MCP（讓 AI 連接外部工具的協定）伺服器的容錯與連線穩定度大幅提升。以前在雲端工作階段中途重連，或是透過 SDK 的 setMcpServers() 動態更新伺服器清單時，若遠端 MCP 伺服器遭遇短暫的 5xx 伺服器錯誤，連線會永久卡死在失敗狀態；現在連線重試修復後能順暢復原並繼續提供服務。

工作樹沙盒相容修復，目錄刪除容錯與規則排除

清理暫存目錄或設定 Git 排除規則時，路徑問題不再使程式崩潰。從已刪除目錄啟動 Claude Code 會印出清晰診斷。工作階段（session）目錄若途中遭刪除，系統不再當機。掛鉤（hook，觸發的小程式）改由專案根目錄或家目錄執行，避免 ENOENT 錯誤。在 Git 工作樹（worktree，平行副本）中，.worktreeinclude 以 **/ 開頭的規則能正常比對已忽略資料夾內的檔案；在設定 extensions.worktreeConfig 的儲存庫中，Linux 沙盒不再因缺少 .git/config.worktree 使 Git 指令失效。若在設定檔加入：

{"claudeMdExcludes": [".claude/rules"]}

無論指向規則目錄或符號連結（symlink，捷徑檔）本身皆能排除。

如同大型工地拆除臨時通道時自動導向空地，標籤無論標記捷徑或入口皆能引導工人避開管制區。

Python SDK 升級指令上線，自動遷移 1.x 規格

升級舊版 Python 專案變得更省時省力。全新加入的 /claude-api upgrade 指令能自動將專案中的 anthropic SDK 從 0.x 順暢遷移至 1.x 版本，並同步更新技能內的 Python 參考文件與呼叫慣例（例如逾時設定改用 anthropic.Timeout 代替舊的 httpx.Timeout）。

這好比鐵路全面升級高鐵規格時，派出專用的換軌工程車自動調校全線所有車廂的連接規格與轉向架，讓老舊列車迅速適應全新提速標準。

Alpine Linux 原生擴充支援，貼圖剪貼與音訊就緒

就像為輕量化跑車換上專屬設計的超輕量輪胎，不再因規格不合而被底盤拒於門外，在極限賽道上也能完全發揮各項性能。

針對採用 musl 標準函式庫的 Alpine Linux 環境，Claude Code 改為載入專屬 musl 編譯二進位模組，徹底解決以往因 glibc 格式不相容而被執行環境拒絕載入的問題。現在輕量容器與 Alpine 系統下，原生圖片貼上、系統剪貼簿讀寫與音訊擷取擴充功能皆能隨開即用。

UTF-8 BOM 檔案相容，代理人與自訂指令正常載入

在 Windows 或特定文字編輯器中建立說明文件時，常因隱藏的檔頭標記導致自訂功能無故失效。以前定義代理人（agent）、技能與自訂指令的 .md 檔案若開頭包含 UTF-8 BOM，會被系統默默忽略而形同虛設。現在系統能正確辨識這種位元組順序記號並順利載入檔案。

如同圖書館掃描器升級後，即使書籍封面印有額外的防偽印記或特殊編碼標籤，也能精準讀取書名並順利歸檔。

啟用語音聽寫不再跳出提示，啟動畫面乾淨無擾

開啟語音輸入功能後，終端機啟動畫面變得更清爽。若你已經在設定檔 ~/.claude/settings.json 中加入了以下設定啟用語音聽寫：

{"voice": {"enabled": true}}

系統啟動時會正確識別你已開啟功能，不會再每次重複跳出無謂的 /voice 功能提示與教學。

如同舞台上的專業收音麥克風，一旦後台完成通電與靜音指示燈設定，前台螢幕就不會反覆亮起開機教學提示，讓演出流程保持乾淨流暢。

`/insights` 深入分析輸出濾除多餘標籤，格式更乾淨

當你執行 /insights 指令深入分析對話歷史與專案洞察時，產生的報表內容更加乾淨俐落。以前在使用部分模型生成分析結果時，回覆內容中常會夾雜模型輸出的字面 <message> 標籤，把報表排版撐得亂七八糟；現在系統會自動把這些標籤濾掉。

如同演講者的即時字幕投影，系統會自動濾除演講稿內部的提詞註記與排版符號，讓觀眾看到的螢幕文字始終清晰易讀。

主題顏色設定全面生效，自訂狀態徽章色彩

就像賽車儀表板允許車手自訂不同轉速與檔位的警示背光色彩，客製化調色能如實呈現，不再被系統預設配色強制覆蓋。

自訂介面主題的色彩細節獲得了完整支援。以前在終端機主題設定中自訂 effort 或 ultracode 等狀態徽章的顏色時，系統會默默忽略你的設定並維持原廠預設顏色；現在自訂主題覆寫已能被系統精準讀取，並如實套用至各項狀態徽章。

工具呼叫超長路徑中間省略，終端排版維持單行

在深層專案目錄下觀察工具執行狀態時，終端機畫面排版更整齊美觀。當 Claude 呼叫 Edit、View 或 Bash 等工具時，工具使用列若遇到超長的檔案路徑，系統現在會自動在路徑中間加入省略符號（例如 src/.../utils.ts）進行截斷，確保整行資訊維持在同一行顯示，不再因路徑過長自動折行而弄亂終端機畫面。

如同登機證列印超長姓名時會在中間自動縮寫，既完整保留首尾關鍵字，又確保版面整齊單行不換行。
