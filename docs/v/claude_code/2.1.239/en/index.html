Claude Code 2.1.239

Released: 2026-08-21

Release notes

FEATURE

Budget estimates include US inference premium, with immediate stop on quota depletion

When setting strict budgets, knowing exactly what you are spending and when limits reset is essential.

Now when running /cost, checking the status line, or passing --max-budget-usd 10.0, workspaces with data residency requirements automatically factor in the 1.1× US-only inference surcharge. If your monthly spend limit is reached, the warning dialog explicitly tells you when your session or weekly limit resets. Furthermore, persistent retry mode with CLAUDE_CODE_RETRY_WATCHDOG=1 now exits immediately on organization spending caps or out-of-credit errors rather than waiting forever. The "View usage" button in VSCode has also been shifted inline with the alert text.

Like a smart power meter that factors in peak-hour tariffs, shows exact recharge times when quota runs out, and immediately trips the main circuit breaker during a blackout to keep appliances from running idle.
BUGFIX

Proxy billing duplication fixed, stabilizing Bedrock and web connections

Connecting through corporate proxies to reach Claude is now much safer and smoother.

Previously, when using Bedrock behind proxies that stripped response Content-Type headers, the client mistakenly assumed streaming failed and secretly re-ran turns non-streaming, silently doubling API costs; this double-billing glitch is now completely resolved. Furthermore, when using Bedrock with SSO profiles and awsAuthRefresh, startup credential checks properly honor export HTTPS_PROXY="http://proxy.corp.com:8080", eliminating startup freezes. In web sessions, requests from Bash or other tools to non-API anthropic.com domains also route through the session proxy to enforce organizational allowlists.

Like goods moving through a customs transit corridor — stripped shipping labels won't trigger duplicate clearance tariffs, inspectors use dedicated checkpoint lanes for credential renewal, and all traffic remains strictly within approved channels.
FEATURE

Teammate visibility in agent lists, with cross-session messaging on Windows

Like using a walkie-talkie channel where your radio screen clearly badges your own callsign and lists every active teammate on the frequency, without turning slash-prefixed names into ghosts.

Multi-agent coordination and session messaging are now fully refined.

Running ListAgents or typing /list-agents displays active teammates alongside subagents and other sessions, so reachable peers never look absent. A session now discovers its own peer-facing address via ListAgents, and sending a SendMessage to your own name explicitly informs you that it is yourself rather than claiming the agent does not exist. Titles starting with / are no longer rendered as "(untitled)" or broken in routing, and Windows users now enjoy cross-session messaging on equal footing with macOS and Linux.

FEATURE

Non-intrusive background goals, with goal restoration and container keep-alive

Running background tasks no longer interrupts your workflow with non-stop pings.

When using /goal for long-running jobs, check-in prompts now back off progressively (from 30 minutes, to 1 hour, to every 2 hours) instead of constantly buzzing you every 30 minutes. Resuming a session with claude --resume automatically restores its active goal. For remote and cloud sessions, executing lengthy SessionStart or Setup hooks (scripts triggered on events) continuously sends keep-alive heartbeats to keep the hosting container from being reaped mid-hook. Cloud workers restarting after being idle also cleanly preserve their active plan mode.

Like an endurance marathon where checkpoint staff space out check-ins to let runners focus, returning athletes seamlessly resume their course targets, and support vans transmit steady heartbeats to prevent accidental disqualification.
FEATURE

Remote Control sync rate-limiting, mobile image paths, and Chrome cleanup

Controlling Claude from your mobile device or via Remote Control is significantly more polished.

When two processes share a background task, title synchronizations to Remote Control are deduplicated and rate-limited to stop runaway loops. Images uploaded from mobile into remote sessions now include their saved local file paths, enabling Claude to copy them directly into newly created project files. When Remote Control is not enabled for your account, claude doctor provides much clearer guidance. Additionally, in Chrome integration, running /clear closes the session's tab group, while /resume and clean exits tidy up lingering empty groups.

Like a shared international war room whiteboard where simultaneous updates stop flickering, mobile field photos carry exact folder index tags, and clearing the desk wipes away all transient sticky notes.
BUGFIX

Session titles preserved past 64KB, with smart path matching and deleted directory fallback

Naming your conversations keeps your workspace organized, but long sessions used to lose their custom titles.

Renaming a session now keeps its title in /resume even after the conversation grows beyond ~64 KB. Path matching in claude -c and /resume properly distinguishes directories that differ only by _, -, or . separators instead of accidentally loading foreign chats. Merely touching or reopening a session file no longer falsely marks it as updated or disrupts its display order. In all-projects mode, if a session's previous directory (such as a removed worktree) no longer exists, Claude resumes safely in your current directory rather than asking you to cd into a ghost folder.

Like an office filing cabinet where drawer labels stay firmly attached as folders grow thick, casual browsing never scrambles alphabetical order, and dismantled desks let you open files on your current tabletop.
FEATURE

Fullscreen mode on cloud platforms, focus misclick protection, and dark theme contrast

Like entering a modern IMAX theater where ushers guide you to prime seats and quiet down after three unanswered prompts, and refocusing your view never triggers an accidental button press.

Fullscreen terminal rendering is now much smoother across Bedrock, Vertex, Foundry, and previously excluded setups.

Setups on Bedrock, Vertex, Foundry, and previously excluded environments now receive the one-time fullscreen offer, with fresh installs defaulting to fullscreen. If your terminal cannot answer the setup prompt, the inquiry automatically ceases after three launches rather than nagging indefinitely. Clicking into an unfocused terminal window only restores focus and no longer accidentally submits permissions or activates interactive buttons. Under the dark-ansi theme, expanded tool output text is no longer rendered invisibly in the same color as the background.

BUGFIX

Scrollable fullscreen forms, pinned panels, and workflow dialog fixes

Opening tall forms or configuration panels in fullscreen mode no longer clips essential buttons or buries recent messages.

When an MCP elicitation form exceeds terminal height, it neatly fits the viewport with scrollable fields while the Accept and Decline buttons remain pinned and visible at all times. Slash-command panels like /config and /model keep the active conversation pinned above them instead of covering your latest messages. Opening the /workflows dialog while Claude is actively streaming a response also properly constrains window dimensions, ensuring dialogue headers never scroll out of view.

Like an on-screen interactive control panel where long option menus scroll freely, confirmation buttons stay firmly anchored, and settings overlays never obscure the main show playing behind them.
BUGFIX

Readline keybindings align with Bash, fixing text selections and search deletion

Terminal power users will find cursor navigation and line editing much more natural.

Configuring {"keybindingFlavor": "readline"} in ~/.claude/settings.json matches Bash word manipulation exactly: Alt+F and Ctrl/Option+→ jump to word boundaries, Alt+D deletes forward to word ends (restorable with Ctrl+Y), and punctuation acts as word dividers. In search boxes, Ctrl+Backspace deletes entire words instead of single characters. Text selections extended with Shift+Arrow keys are reliably grabbed by selection:copy. Deleting text with Ctrl+W, Ctrl+U, Option+Backspace, Option+D, or vim df/dt while inside [Pasted text #N] placeholders no longer leaves corrupted placeholder markers. In agent view with vim mode active, pressing Escape switches cleanly to NORMAL mode while preserving typed text.

Like a pianist gliding effortlessly across familiar keys — navigation stops precisely on each intended note, while copying phrases or cutting bars preserves every musical notation without missing a beat.
BUGFIX

Masked input leak protection and browser terminal mouse noise filtering

Entering credentials or moving the mouse in web terminals used to risk leaking sensitive secrets or injecting stray text.

Masked fields like login verification codes no longer leak into prompt history or let cleared secrets be pasted via Ctrl+Y after double-pressing Esc. Browser-based terminals no longer leak fragmented mouse tracking strings like "35;150;7M" into your input prompt when mouse reports arrive across multiple writes.

Like a secure ATM keypad fitted with an anti-peeping shield, where clearing credentials leaves no trace in the clipboard buffer and moving your hands nearby never injects stray sensor codes.
BUGFIX

Shell mode Tab completion preserves `./` path prefixes

When switching to shell mode with an exclamation mark (!) and pressing Tab to autocomplete executable scripts, commands now execute seamlessly.

Previously, Tab completion on a ./script path dropped the leading ./ prefix, leaving a bare command name that the underlying shell could not resolve or run; completion now faithfully retains ./.

Like an address autocompletion system that keeps local neighborhood district prefixes intact on package labels, ensuring delivery couriers can find local destinations immediately.
FEATURE

Cloud plugin synchronization isolation and marketplace plugin root resolution

Managing plugins across local environments and cloud accounts is now completely conflict-free.

In cloud sessions, plugins synced from claude.ai are designated with a name@synced suffix, can be independently controlled with claude plugin enable <name>@synced or claude plugin disable <name>@synced, and will never overwrite local custom plugins sharing the same name. In plugin marketplaces, configuring {"metadata": {"pluginRoot": "packages"}} now properly resolves bare package source names under that subdirectory as documented.

Like a master craftsman's portable toolbox where company-issued loaner tools carry clear identification tags, allowing independent toggling without ever replacing favorite personal tools.
BUGFIX

Remote MCP servers automatically recover from transient 5xx reconnect errors

Like an astronomical observatory communicating with a remote telescope where brief atmospheric interference never permanently severs the telemetry link once the weather clears.

Remote MCP (protocols connecting AI to external tools) servers recover gracefully from transient connection drops.

When reconnecting mid-session in cloud environments or reconfiguring servers dynamically via the SDK's setMcpServers(), encountering a momentary 5xx server error no longer leaves the remote MCP server permanently broken; it automatically recovers and resumes tool availability.

BUGFIX

Worktree sandbox fixes, missing directory fallback, and symlink exclusions

Cleaning up temporary project directories or managing complex Git ignore patterns is now error-free.

Launching Claude Code from a deleted working directory prints a helpful diagnostic message instead of throwing an unhandled stack trace. If the session working directory disappears mid-session, hooks (event-driven helper scripts) automatically fall back to executing from the project root or home directory rather than failing with ENOENT errors. In Git worktrees (parallel repository working copies), .worktreeinclude patterns starting with **/ successfully match paths inside gitignored folders, and in repositories with extensions.worktreeConfig set, Linux sandboxes no longer break git commands when .git/config.worktree is missing. Adding rule exclusions:

{"claudeMdExcludes": [".claude/rules"]}

cleanly excludes symlinked rule files when referencing the link name or parent directory.

Like navigating a major construction site where dismantled scaffold walkways automatically guide workers back to safe central plazas, while inspection guides follow detour signs seamlessly.
FEATURE

Automated Python SDK migration to 1.x via `/claude-api upgrade`

Modernizing older Python codebases is now straightforward.

The new /claude-api upgrade command migrates your Python project's anthropic SDK from 0.x to 1.x automatically, updating the skill's Python reference and API patterns for 1.x conventions (such as configuring timeouts with anthropic.Timeout rather than httpx.Timeout).

Like deploying specialized rail-conversion engineering engines during a high-speed network upgrade to adjust every carriage coupling, bringing existing rolling stock up to modern mainline specifications.
FEATURE

Alpine Linux native add-ons load for clipboard, image paste, and audio

Like outfitting a lightweight racing car with custom lightweight tires tailored specifically for its bespoke chassis, ensuring all peripheral components function smoothly.

In lightweight Alpine Linux environments built on the musl standard C library, Claude Code now loads dedicated musl-compiled native add-ons instead of glibc binaries rejected by the runtime.

Developers running inside Alpine containers can now enjoy native clipboard access, native image pasting, and audio capture without compatibility hitches.

BUGFIX

UTF-8 BOM support for agents, skills, and custom commands

Creating configuration docs in certain text editors often introduces invisible header bytes that caused custom behaviors to fail silently.

Markdown .md definitions for declarative agents, skills, and custom commands that begin with a UTF-8 BOM (byte order mark) were previously ignored without warning. Claude Code now parses and activates them reliably.

Like a library scanner that reads barcodes and titles flawlessly even when book covers feature unusual anti-counterfeiting embossed stamps.
BUGFIX

Startup tip silenced when voice dictation is enabled via settings

Enabling voice dictation now keeps your terminal startup interface clean and uncluttered.

If you have already enabled voice dictation by adding the following snippet to ~/.claude/settings.json:

{"voice": {"enabled": true}}

Claude Code properly recognizes your configuration on startup, permanently silencing the redundant /voice onboarding tip.

Like a professional studio microphone that skips repetitive power-on tutorial overlays once its soundboard switches and mute indicators are configured.
BUGFIX

Clean `/insights` formatting without extraneous XML message tags

Running /insights to analyze conversation history and generate codebase usage trends now yields cleaner reports.

When querying certain underlying models, literal <message> tags previously leaked into the generated insights output; they are now stripped before the report is shown.

Like a live speech teleprompter that automatically filters out internal directorial cues and stage annotations, displaying only polished text to the presenter and audience.
BUGFIX

Custom theme color overrides respected for effort and ultracode status badges

Like a performance cockpit where drivers customize dashboard alert backlights to their preferred hues without the factory defaults overriding their choices.

Custom theme styling for terminal badges is now fully supported.

Configuration overrides for the effort and ultracode status badge colors were previously ignored by the interface renderer; Claude Code now honors your custom theme colors across all status indicators.

FEATURE

Tool-use rows truncate long file paths in the middle

Monitoring tool activity in deep directory structures is significantly cleaner.

When Claude invokes tools like Edit, View, or Bash, excessively long file paths on tool-use rows are now truncated in the middle with ellipses (such as src/.../utils.ts). This ensures tool output rows fit neatly on a single terminal line without awkward line wraps scrambling your display.

Like a boarding pass that abbreviates long middle names while preserving the first and last names, keeping ticket layouts crisp and single-lined.
BUGFIX

Request pipeline race fix, policy resend prevention, and compaction reminder refinement

Like an automated security turnstile with anti-duplicate logic that never debits rejected cards twice, never misinterprets cancelled queues, and prevents old credentials from triggering duplicate entries.

Pipeline execution now cleanly avoids unintended request duplicates.

Pressing Esc with a prompt queued no longer triggers a race condition that prematurely idles the session and causes resubmissions to repeat prior actions. Requests rejected by organizational policy checks are no longer re-sent before the rejection reason is displayed. Context compaction reminders have also been updated to ensure skill arguments are not accidentally re-executed as fresh user requests.

BUGFIX

JetBrains terminal edit pauses resolved and WebFetch memory release

Editing files within IDEs and fetching web resources no longer suffers from unexpected pauses or memory leaks.

In JetBrains IDE terminals, a 5-second pause during Edit and Write tool calls when connected to the Claude Code plugin has been resolved. Furthermore, WebFetch cache entries properly expire and free up system memory after 15 minutes as intended, rather than hoarding memory for the remainder of the session.

Like clearing off a cluttered desk where tools put away immediately stop stalling work and expired scratch drafts get discarded on schedule to keep the workspace open.
BUGFIX

OpenTelemetry trace continuity for hook-deferred tool executions

Observing tool execution flows with OpenTelemetry while using custom interception hooks is now reliable and unbroken.

Previously, tool executions deferred by a PreToolUse hook started a brand-new trace, fragmenting telemetry data into disconnected chunks; deferred tool calls now properly resume within the parent turn's original OpenTelemetry trace.

Like package shipping where a parcel held temporarily at a checkpoint resumes transit under its original tracking number, preserving a complete start-to-finish delivery timeline.
