Linux 啟動崩潰已修好

剛把 Claude Code 開起來卻立刻關掉，連畫面都還沒來得及用嗎？這個啟動時崩潰的問題，已在採用 glibc 2.44（Linux 程式共用的基礎函式庫）的 Linux 發行版修好。Arch Linux、CachyOS 與 Fedora Rawhide 都是更新說明點名的例子；若你使用其中之一，現在可以再試著啟動。這像門鎖明明配了正確的鑰匙，門卻在轉開前自己彈回；門鎖修好後，鑰匙便能把門打開。

en

Startup crash fixed on affected Linux distributions

Does Claude Code close as soon as you try to open it, before you can even use the window? That startup crash is fixed for Linux distributions using glibc 2.44 (a shared foundation library for Linux programs). Arch Linux, CachyOS, and Fedora Rawhide are the examples named in the update, so users of those distributions can try starting it again. It is like a door lock that springs back just before a matching key can turn; after the lock is repaired, the key can open the door.
