Linux 啟動崩潰已修好

剛把 Claude Code 開起來卻立刻關掉，連畫面都還沒來得及用嗎？這個啟動時崩潰的問題，已在採用 glibc 2.44（Linux 程式共用的基礎函式庫）的 Linux 發行版修好。Arch Linux、CachyOS 與 Fedora Rawhide 都是更新說明點名的例子；若你使用其中之一，現在可以再試著啟動。這像門鎖明明配了正確的鑰匙，門卻在轉開前自己彈回；門鎖修好後，鑰匙便能把門打開。

en

Startup crash fixed on affected Linux distributions

Does Claude Code close as soon as you try to open it, before you can even use the window? That startup crash is fixed for Linux distributions using glibc 2.44 (a shared foundation library for Linux programs). Arch Linux, CachyOS, and Fedora Rawhide are the examples named in the update, so users of those distributions can try starting it again. It is like a door lock that springs back just before a matching key can turn; after the lock is repaired, the key can open the door.

zh-CN

Linux 启动崩溃已修好

刚打开 Claude Code 就立刻退出，连界面都还没来得及用吗？这个启动时崩溃的问题，已经在采用 glibc 2.44（Linux 程序共用的基础函数库）的 Linux 发行版上修好。Arch Linux、CachyOS 和 Fedora Rawhide 都是更新说明点名的例子；如果你使用其中之一，现在可以再试着启动。这像门锁明明配了正确的钥匙，门却在转开前自己弹回；门锁修好后，钥匙便能把门打开。

ja

対象の Linux ディストリビューションで起動クラッシュを修正

Claude Code を開こうとした直後に落ち、画面を使う前に閉じてしまうことがある。その起動クラッシュは、glibc 2.44（Linux プログラムが共用する基礎ライブラリ）を採用する Linux ディストリビューションで修正された。更新では Arch Linux、CachyOS、Fedora Rawhide が例として挙げられており、これらを使っているなら改めて起動を試せる。正しい鍵を差しても、回る直前に鍵穴が跳ね返してしまう扉のようなものだ。鍵穴が直れば、鍵は扉を開けられるのである。

ko

영향받은 Linux 배포판의 시작 충돌 수정

Claude Code를 켜자마자 종료되어 화면을 쓰기도 전에 닫히는 일이 있었는가? 이 시작 충돌은 glibc 2.44(Linux 프로그램이 함께 쓰는 기초 라이브러리)을 사용하는 Linux 배포판에서 수정됐다. 업데이트는 Arch Linux, CachyOS, Fedora Rawhide를 예로 들었으므로, 이 배포판을 쓴다면 다시 시작해 볼 수 있다. 맞는 열쇠를 꽂아도 돌아가기 직전에 자물쇠가 도로 튕겨 내던 문과 같다. 자물쇠를 고치면 열쇠로 문을 열 수 있다.
