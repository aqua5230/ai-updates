Claude Code 2.1.198

Released: 2026-07-01

Release notes

FEATURE

Subagents run in background by default and auto-commit code

When you dispatch a subagent (an AI assistant running errands for you), you no longer have to twiddle your thumbs waiting for it to finish before talking to the main agent again; they now run independently in the background by default! The main agent can keep helping you while the assistants work and report back when done.

Moreover, if an assistant modifies code inside an isolated Git worktree, it will now automatically commit, push, and open a draft PR (pull request, the process for merging code) when it finishes, instead of pausing to ask for your permission. It's like upgrading from standing over your assistant's shoulder while they type, to dispatching ten assistants to their desks simultaneously; they do the work in parallel and automatically leave the finished reports on your desk without wasting a second of your time.

FEATURE

Platform support leaps forward: Chrome version lives, AWS joins as failover

You can now use Claude smoothly across even more platforms! The highly anticipated "Claude in Chrome" feature is officially generally available, letting you operate seamlessly right in your browser.

If you use multiple server setups, the system now includes Claude Platform on AWS (an enterprise cloud channel) as a provider. Even better, if the primary server doesn't have the AI model you requested, it's now smart enough to automatically try the next backup server in line (failover chain) rather than just giving up. Furthermore, when logging in via AWS or Mantle, if your authentication key expires mid-task, it will automatically refresh it (awsAuthRefresh) instead of halting the program and demanding you log in again. It's like using an ATM: previously, if a machine was empty, it sent you home; now it automatically wires the cash from a neighboring bank's vault, and gracefully renews your card if it happens to expire while you're standing there.

BUGFIX

UI and visual fixes: Better highlights, no more dead UI

A slew of visual glitches and UI dead-ends have been resolved.

Markdown tables will finally wrap cleanly instead of overflowing the screen in fullscreen mode, and syntax highlighting for code has been noticeably sharpened. If you double-click a URL, it will now select the entire address including the https:// part, and Mac users can successfully Cmd-click links to open them even when in fullscreen mode. On the dashboard side, background tasks will no longer endlessly deceive you with a stuck "Running" status after they actually finish; and if you switch Git branches outside the app, your /diff panel will obediently refresh instead of locking up with stale data. Even the API retry experience has improved: instead of a never-ending spinning wheel during a server traffic jam, it will explicitly hand you a link to the server status page. It's like putting on a proper pair of glasses: tables and colors that used to distort or blur are now crisp and readable, and broken street signs have been replaced with clear, helpful directions.

BUGFIX

Network drops no longer abort turns, and agent teams stay connected

We've improved network and agent connection stability.

Previously, a brief network drop mid-response (like an ECONNRESET transient error) would instantly abort the entire turn; now it knows to back off and auto-retry instead of giving up. For sandboxed processes (isolated secure execution environments) repeatedly accessing the same host, it no longer spams excessive background classifier requests. On Macs running background agents, the frustrating "no route to host" for local networks and the "Reconnecting…" message flashing every 52 seconds when the panel was open have been fixed. If you run agent teams, a teammate that dies from an API error will now explicitly report "failed" to the lead instead of disappearing, and messaging a stuck teammate will instantly wake it up to retry. It's like a phone call that used to hang up at the slightest static, or a coworker who vanished when stuck; now the call auto-redials, and the coworker raises their hand for help, ready to resume as soon as you tap their shoulder.

BUGFIX

Fixed a series of command and UI glitches

We've patched a bunch of minor glitches that caused hangups when switching commands and views.

For example, starting a session in plan mode (where the AI writes a plan before executing) will now properly auto-allow read-only tool calls; and when you create a conversation branch using /branch, it now correctly derives its default name from your first real prompt instead of the compacted summary. If you use claude attach <id> to join an agent view, pressing the left arrow no longer falsely kicks you all the way back to the shell. The mysterious errors where /desktop couldn't determine the working directory after worktree changes, or where .claude/rules/ failed to load via symlinked paths, are fixed. Furthermore, you can now trigger /login directly from the agents view, the earliest agents no longer drop off the workflow progress list in SDK/desktop apps, and running claude --bg with --print is now correctly rejected upfront instead of silently creating an unattachable ghost session. It's like using a car's GPS: it used to freeze if you took a slight detour or kicked you out of the car if you pressed 'back', but now the dashboard is fully reliable and takes you exactly where you want to go.

FEATURE

New data visualization skill and removal of the old agents wizard

When designing charts or dashboards, you can now use /dataviz for guidance and color checking.

It comes complete with a runnable color-palette validator to ensure your color choices don't blend into an unreadable mess. Meanwhile, the old /agents wizard (the step-by-step setup tool) has been retired. From now on, if you want to create or manage subagents, simply ask Claude to do it for you, or edit the files in the .claude/agents/ directory directly. It's like your company finally abolishing those tedious multi-page paper request forms; now, whether you need a fresh chart or want to hire a new assistant, you just tell your secretary what you want and it's done—and you get an expert color designer thrown in for free.
