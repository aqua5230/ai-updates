預設旗艦模型升級 Opus 5.5，訂閱方案與思考力度設定全面同步

想換更強的模型又顧成本？旗艦模型 Claude Opus 5.5（claude-opus-5-5）現已成為預設 Opus 模型並提供 1M 上下文。其定價為每百萬 token（AI 處理與計費的文字單位）輸入 4 美元、輸出 20 美元。讀取快取（把算過或查過的結果暫存起來直接用）費用為每百萬 0.20 美元。Pro 與 Team Standard 方案的預設模型也從 Sonnet 改為 Opus，與 Max、Team Premium 及 Enterprise 看齊。在思考力度方面，舊版儲存的設定不再套用到 Opus 5.5 等新模型；Opus 4.7、Opus 4.8 與 Fable 5 也不再讓出廠預設值覆蓋 -p、SDK、專案或設定檔的 effortLevel。

這就像車廠推出性能更強的旗艦引擎並標配給更多車系，各車型的油門偏好也獨立記憶而不互相干擾。

檔案寫入嚴格核對真實路徑，自動模式安全審查全面增設退避防護

檔案權限與自動執行交錯時，寫入流程較不會因判定失準卡住。透過符號連結（指向另一個位置的捷徑檔）寫入檔案時，提示詞會明確指出實際寫入的落點位置。如果真實目標落在專案目錄外，acceptEdits、允許規則與自動模式都不再放行。在自動模式下，如果安全檢查拒絕審查某項操作，該操作會直接被拒絕一次，並提示重試沒有幫助。若安全檢查沒有任何回應，系統會逐步延長重試間隔，連續十次無回應就會停止該輪對話並顯示說明訊息。此外，當模型呼叫 Write 工具時傳入 path、file_text、file_content 或多餘的 description 等非標準參數，也能正確通過驗證。

這好比門禁警衛檢查送貨單，遇到捷徑會核對真實門牌，遇到審查無回應時也會拉長等候間隔而非狂按電鈴。

點擊視窗喚回前景時，不再誤觸游標底下的搜尋器、分頁列、代理與工作流程列、指令連結或選單。對話框取消按 y 或 n 鍵直接確認關閉，改用 Enter 確認與 Esc 取消（可在 keybindings.json 綁定 confirm:yes 與 confirm:no 還原）；文字輸入框也不再因快捷鍵遺失輸入的英數或空白。

這如同觸控螢幕加入了防誤觸保護，喚醒視窗時不再誤按底下的按鈕。

終端機重繪輸入畫面，語音聽寫中斷與指令暫存取回機制全面修復

需要輸入、語音或暫存提示詞時，跨環境的互動較能維持原樣。在 Windows 終端機中，按 Enter 清理不可見字元後會重新繪製畫面，讓你能看清楚送出的實際文字。不可見字元清理也不再誤刪波斯文與阿拉伯文用來連接字尾的零寬不連字元。語音聽寫方面，按下 Ctrl+C 會立即停止麥克風收音，在轉錄處理過程中按下 Esc 能順利取消，在轉錄檢視畫面與 vim NORMAL 模式下長按空白鍵也不會意外啟動聽寫。啟動掛鉤（特定事件發生時被觸發的小程式）執行時按 Esc，或是編輯、倒帶讓提示詞回到輸入框時，IDE 選取的內容不會再遺失。使用 Ctrl+S 暫存的 ! shell 模式提示詞，取回時依然維持 shell 模式，暫存後輸入 / 也能立即列出檔案路徑。

這宛如錄音筆與草稿夾，暫停錄音時立即切斷收音，抽屜裡的草稿拿出來時依然保有原本的分類標籤。

這宛如圖書館的借閱檢索卡，換班管理員沿用同一份調閱紀錄，省去重新翻找書庫的等待時間。

外掛市集更新支援憑證庫，保護 Skills 目錄並拒絕偽冒市集名稱

維護外掛與技能來源時，更新與設定較不易出錯。背景外掛市集自動更新現在支援 Git 憑證庫（存登入證明的地方），私有儲存庫市集不再每次都重新複製或無法更新。當你從追蹤分支或標籤的 GitHub 儲存庫或 Git 網址更新外掛時，installed_plugins.json 會更新為最新修訂版本，不再保留安裝時的舊紀錄。執行 claude plugin update 時，若官方市集的快照檔案為連結或體積過大，也不會再將外掛版本誤標為未知。在技能方面，當 ~/.claude/skills/ 內包含列出技能名稱的 manifest.json 時，該目錄下的技能不再被意外移入 .trash 資料夾。同時，新增外掛市集時若名稱模仿保留的官方市集名稱會直接被拒絕，已新增的也會停止載入。

這如同市集管理員核對商家的營業登記證，確保商品清單準確更新並防範冒牌攤位進駐。

這如同汽車儀表板校正了燈號顯示，關閉的設備以暗色圓圈呈現，不再與故障紅燈混為一談。

清單頁首頁尾快捷鍵正常運作，全螢幕畫面重繪與按鍵提示全面校正

這好比電視遙控器的選台按鈕，按到底時穩穩停在最後一頁，畫面刷新鍵也回歸直覺操作。

API 訊息格式與代理轉發修正，修復損毀工作階段紀錄還原問題

工作階段拖得越久，越怕一筆壞紀錄讓整段對話停擺。對話請求不再因為角色順序問題而拋出系統角色必須在助理訊息之前的 API 錯誤。開啟顧問模式時，若在不支援 advisor_20260301 標籤的代理伺服器或閘道後方遇到 API 400 錯誤，系統會自動不帶該標籤重試請求。當工作階段儲存的歷史紀錄中包含無法載入的 MCP（Model Context Protocol，讓 AI 連接外部工具的協定）工具錯誤通知時，對話與 /compact 不再每輪報錯。當儲存的轉錄紀錄包含格式損毀的系統訊息或缺少檔案清單的記憶體儲存通知時，復原工作階段不再發生崩潰。全螢幕長工作階段若發生損毀，損壞的快取（把算過或查過的結果暫存起來直接用）訊息清單現在會自動重建，避免跳出無法復原的介面錯誤而中斷。

這宛如檔案修復程式在讀取損毀日誌時，自動剔除殘缺便籤並重建索引，讓後續作業平穩推進。

檔案讀取防止具名管道卡死，設定檔舊格式相容性全面提升

設定檔在變動或留下舊格式時，設定介面仍能穩定使用。當設定檔或編輯後重新讀取的檔案在讀取過程中被具名管道替換時，Claude Code 不再無限期卡死等待。此外，當某個設定項目已經移至 settings.json，但 ~/.claude.json 中仍然殘留 null 或 "false" 等舊值時，開啟 /config 不會再發生崩潰，各項開關偏好也能被正確讀取。

這好比智慧讀卡機讀取新舊規格的存摺時，遇到格式轉換殘留的空白欄位也能正常開機。

背景子代理訊息可靠傳遞，LSP 支援、對話壓縮與中斷退出全面修正

依靠背景子代理處理工作時，交接、訊息與工作階段較能接續。在無頭模式（沒有終端機視覺介面的執行模式）與 SDK 工作階段中，當背景子代理正在結束該輪對話時，傳送給它的訊息不會再默默遺失。當啟動子代理的主對話在讀取報告前執行了壓縮，已完成子代理的調查結果也不會再丟失。當 LSP 外掛啟用時，背景子代理現在能順利使用 LSP 工具進行程式碼語意分析。在背景子代理執行期間，按下兩次 Ctrl+C 即可順利退出，不再需要連續按三到四次。復原包含未完成背景代理、shell 或工作流程的工作階段時，不會再於你輸入前自行啟動模型對話。此外，在非詳細模式下展開子代理交接訊息時，不再顯示內部的來源前言字串。

這好比專案總監調派外勤調查小組，收件匣即便壓縮歸檔也不會遺失外勤員回傳的結案報告。

背景任務正常退出碼不再誤判，空字元環境變數與暫存目錄異常處理

讓背景工作處理日常任務時，非關鍵狀況和環境問題更容易看清。背景 shell 任務回傳良性的非零退出碼（例如未找到匹配項的 grep 指令）時，不再被誤報為執行失敗。當傳入工作階段的環境變數中包含空字元時，背景工作階段 claude --bg 現在依然能正常執行 Git、掛鉤（特定事件發生時被觸發的小程式）、外掛與其他輔助程式。當暫存目錄已滿、沒有寫入權限或屬於其他使用者時，執行 claude agents 會顯示明確的錯誤訊息，不再停留在無回應的空白畫面。跨工作階段通訊的啟動警告也做了說明改進，清楚指出可以使用 --debug-file 將除錯日誌寫入你指定的檔案路徑。

這宛如快遞調度中心的後台派工系統，查無信件的空跑不會被誤判為車輛故障，遇到路徑受阻時也能清楚出示通行證。

支援自訂 MCP 說明文字長度上限，移除伺服器後重新加入直接連線

你可以透過新增環境變數 CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH，自訂工作階段內所有 MCP（Model Context Protocol，讓 AI 連接外部工具的協定）伺服器的工具說明與指示文字長度，打破原先 2,048 個字元的預設限制。此外，先前使用 claude mcp remove 移除 MCP 伺服器後，若以相同名稱重新新增該伺服器，介面可能會停留在需要認證的錯誤狀態；現在系統會直接重新連線，無需手動重覆登入。

這如同通訊轉接器解除了電報字數上限，重新插拔同名裝置時也會立即恢復通訊連線。

雲端審查敏感設定檔安全防護，遠端工作階段 Diff 檢視與權杖輪替修正

這宛如雲端同步協作系統，在伺服器繁忙重連時自動換發安全證書，多人編輯長篇備忘錄時也不會吃掉中間段落。
