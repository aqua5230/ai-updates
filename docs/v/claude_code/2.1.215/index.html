Claude Code 2.1.215

發布日期：2026-07-19

繁體中文

新功能

檢查與程式審查改由你親自叫出來

你要交付一份改動，卻想先自己檢查一輪時，現在得明確輸入 /verify 才會啟動驗證技能（幫你檢查結果的內建流程）；想請它檢視程式碼，也要輸入 /code-review 才會啟動程式碼審查技能（找出程式問題的內建流程）。

Claude 不會再自行猜測你何時需要它們。這像工具箱裡兩把檢查尺：以前它會自己抽出來量，現在把決定權還給你；需要時叫它一聲即可。不必擔心它在你沒要求時多做一次檢查，也別忘了，想用時要親自下指令。

English

FEATURE

Verification and code review now start only when you ask

Before handing over a change, you may want one last check.

Now you must explicitly type /verify to run the verification skill, Claude's built-in checking workflow. To have it inspect code, type /code-review to run the code-review skill, its built-in workflow for finding code issues. Claude will no longer guess when either is wanted. Think of two measuring tools in a toolbox: it used to pull them out on its own; now you hold the handle. Call for one when needed, and it will not add an unasked-for check to your work.
