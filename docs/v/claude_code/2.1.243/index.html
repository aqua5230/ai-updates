/usage 新增循環用量拆解，閒置喚醒自動摺疊

就像保全巡邏打卡鐘，如果保全每隔一段時間只是路過且一切正常，打卡記錄會自動摺疊成單一行，不必在記錄簿上印出滿滿的重複字句。 當你在終端機使用 /loop 執行循環任務時，系統現在能更清楚掌握執行細節。輸入 /usage 指令會顯示全新的 Loops 拆解資訊，列出每個循環的執行次數、總 token（計費與計量文字單位）、每次平均 token 與最後執行時間，方便你一眼揪出暴衝或過度頻繁的循環任務。此外，當 /loop 連續喚醒卻沒有任何待辦事項時，終端機會把這些無事可做的喚醒紀錄摺疊成單一行，不再頻繁洗版。

模型選單支援自訂排序，雲端平台指令即刻生效

你現在能隨心所欲整理模型清單了。在設定檔加入 modelPicker 設定，即可自訂 /model 挑選器中的模型順序與標籤，甚至支援 Vertex 與 Bedrock 的自訂模型識別碼，可選擇附加在內建清單後或直接完全取代。在挑選器中選取 Ultracode 也已修復，會確實套用至當前工作階段（session）。模型挑選器與內建的 claude-api 技能同步更新，將 Sonnet 5 每百萬 token 為 2 與 10 美元的定價標示為標準牌價，而非限時優惠。此外，在 Bedrock、Vertex、Foundry 或關閉遙測的環境下，輸入 /model、/fast 與 /effort 指令會立即執行，不再排隊等待當前回合結束。這宛如餐廳換上自訂特選菜單，顧客點選招牌菜能立即備餐，省去在點餐機前久候的時間。

提示詞快取存活期獨立設定，主對話延長一小時

企業受管定價計算真實成本，來源優先級清楚標記

企業內部統一派發設定時，費用計算與設定來源變得更加透明。管理者現在可透過受管設定配置 modelPricing。這讓 /cost 指令、狀態列（status line，終端機最底下那行即時資訊）與遙測費用統計直接採用公司合約中的個別模型單價與折扣乘數，不再只顯示公開牌價。輸入 /status 時新增了 Skipped sources 資訊行，清楚列出雖然存在（例如 managed-settings.json）但因較高優先級來源生效而未被採用的設定檔。而在 /mcp 與 /plugins 清單中，由組織統一管理身分驗證的 claude.ai 連接器也會加上 managed 標記。如同企業員工憑合約特約享有專屬折扣，報銷清單上能清楚查驗計費來源與派發標記。

免金鑰 Console 帳號登入，SSH 網址複製與公告修復

就像大樓訪客登記處，員工只要出示總部工作證就能直接感應通關，不必每次手動填寫臨時通行金鑰。 登入驗證流程有了諸多貼心改善。現在執行 /login 前往 Anthropic Console 時，新增了免金鑰的「使用 Console 帳號登入」建議選項，方便禁止建立 API 金鑰的企業員工快速登入。透過 SSH 遠端連線登入時，登入網址會立即顯示，按下鍵盤 c 鍵會誠實回報網址如何複製而非一律回傳成功，全螢幕模式下也會附帶選取文字的提示。此外，登入網址等超出容器邊界的文字不會在畫面重繪時遺失前幾欄內容，登入後首度啟動工作階段（session）時由伺服器管理的企業公告 companyAnnouncements 也會正常顯示。

網頁版 GitHub 狀態即時檢查，舊版工具驗證相容

在網頁版使用 Claude Code 搭配 GitHub 專案時，連線狀態一目了然。針對尚未為網頁版綁定 GitHub 的 claude.ai 使用者，系統會主動跳出提示引導你前往 /web-setup 進行設定。在狀態列（status line，終端機最底部的即時狀態行）輸入 /status，現在會明確標示 Pro 或 Max 方案在網頁版的 GitHub 連線狀態，未連線時也會附上 /web-setup 連結。此外，如果你的電腦上安裝的是尚未支援 gh auth token 的舊版 GitHub CLI（GitHub 命令列工具），/web-setup 不會再因為讀不到該指令而無限次重複要求你重新登入。此舉有如儀表板上的連線檢測燈號，主動指引尚未驗證的通訊線路並相容既有的舊款通行證。

子代理運行模型透明化，背景任務喚醒與視圖修復

就像工地的派工白板，看板上明確標註每位副手使用的是哪一款精密機具與出力等級。 派遣子代理處理任務時的狀態掌握度更上一層樓。現在輸入 /tasks 或打開代理詳細對話框時，清單會明確列出每個子代理運行的模型名稱以及思考努力等級（effort level）。如果背景子代理正在等待它指派的最後一個背景 Bash 指令執行，系統修復了指令完成後子代理未被喚醒的狀況，現在會如期接續後續工作。在 VSCode 編輯器中，你在 Focus 視圖中手動展開的區塊，也不會再因為子代理頻繁呼叫工具而被強制自動摺疊收合。

遠端外部工具斷線自動重連，桌面授權與錯誤排除

連接外部工具時的穩定性大幅提升。在非互動 -p 模式或透過 SDK 呼叫時，遠端 MCP（讓 AI 連接外部工具的協定）伺服器若遇到網路斷線，現在會自動嘗試重新連線。重試失敗後系統會明確回報錯誤，工作階段（session）不再永久失聯。針對支援用戶端中繼文件之服務如 Linear，修正了從桌面版應用程式啟動 MCP 登入時跳出重新導向網址無效的錯誤。若使用者的 ~/.claude.json 設定檔中包含格式錯誤的 MCP 伺服器項目，輸入 /status 時會清楚印出出錯的檔案路徑，不再顯示缺少檔名的空白提示。類似重要專線遇到線路瞬斷時會主動自動重撥，通訊錄遇到錯誤條目也會精確指明檔案位置。

外掛市集相依性正確解析，重載語言工具安全預警

開發自訂外掛（plugin）時的除錯體驗更為流暢。當你透過 --plugin-dir 參數同時載入多個外掛時，修正了宣告 marketplace 欄位的外掛相依性永遠無法解析的問題，現在本機相依套件能正常關聯。執行 /reload-plugins 指令時，若停用了最後一個支援 LSP（語言伺服器協定，提供程式碼定義跳轉與補全的服務）的外掛，系統會確實卸除殘留的 LSP 工具。同時，若外掛變更會引發重新讀取整個對話紀錄，指令會在執行前主動跳出安全警告，避免讀取流程被無預警中斷。彷彿工具箱在更換模組時能正確卡緊相依配件，並在卸下舊工具或重整抽屜前主動發出提醒。

自動模式暫存鎖死修復，過載等候與初始權限修正

就像車輛的自動巡航功能，不會因為先前路況管制快取了暫存停用標記，就在路況恢復後繼續把功能鎖死。 讓 Claude 自行執行任務的自動模式（auto mode，讓 AI 不逐一詢問就自主執行工具的模式）修復了多項卡住問題。以前若伺服器端曾暫時停用該功能並被暫存，後續特徵旗標抓取失敗時會導致自動模式永久不可用，現已排除此問題。當 API 短暫過載並要求重試時，自動模式呼叫工具在等候約 1 分鐘後不會再被錯誤判定為暫時無法使用而直接拒絕。在 VSCode 擴充套件中，剛安裝完成或尚未抓取特徵旗標前啟動的工作階段（session），也會正確採用你自訂的預設模式或自動模式，不再強制退回預設權限模式。

歷史工作階段無限滾動，暫存傳送與通知修復

接續過往對話的操作體驗更為順暢。輸入 /resume 挑選歷史對話時，清單不再受限於最近 50 個工作階段（session），現在只要向下捲動就會持續載入更多對話記錄。當你使用 claude --teleport <session> 指令傳送至其他工作階段時，若當前目錄有未提交的程式碼變更，系統會主動詢問是否將變更放入 stash 暫存並繼續，不再直接退出程式。針對雲端工作階段，在對話中途重啟後，若有未完成的掛鉤（hook，特定事件觸發的小程式）或背景任務通知，系統會以正常的接續訊息送出，不會再誤把通知內容當成使用者的提示詞。這好比翻閱無限延伸的檔案抽屜，在跨機器搬移文件前主動提示將未歸檔草稿放入暫存夾。

終端機歷史搜尋防毀損，對話改名與按鍵修正

命令列介面的各項互動細節獲得全面修復。輸入 /clear 清除對話畫面時，先前透過 /rename 設定的自訂工作階段（session）名稱會完整保留在提示列中，不再意外消失。當歷史檔 ~/.claude/history.jsonl 中混入損毀項目時，按 Ctrl+R 搜尋歷史或按方向鍵上鍵不會再崩潰中斷，能穩定瀏覽其他指令。在支援特殊按鍵編碼（例如 modifyOtherKeys 或 kitty 協定）的終端機裡，修正了按 Ctrl+[ 無法退出 Vim 插入模式的問題。此外，緊接在 Emoji 表情符號後方輸入的錯字，拼字檢查 spellcheck 現在也能正確標上紅色底線。其概念有如翻開厚實筆記本抽換內頁時，封面標籤依然完好留存且自動跳過字跡破損的歷史頁面。

容器跨工作階段通訊修復，收件通訊端逾時釋放

就像大樓住戶專用的對講機系統，即使住戶身處非 root 獨立隔間內也能正常通話，且佔線超過 30 秒未說話就會自動切斷以釋放線路。 多對話協作的通訊管道現在更穩健了。在 2.1.232 版進行通訊端資料夾強化後，使用者命名空間與無 root 容器內的跨工作階段（session）傳訊功能曾被默默關閉，這次修復徹底解決了此問題。同時，跨工作階段收件匣的通訊端（socket）機制加入防護，若連線進入後在 30 秒內未傳送任何完整的行，系統會自動中斷該連線，因此發送資料的腳本應在資料準備完畢後再建立連線。

遠端遙控環境中斷自動恢復，跨機器提示更清晰

遠端操控對話時的連線韌性顯著提升。當伺服器在中途遺失環境時，執行 claude remote-control 不會再直接退出而丟下連線中的遠端工作階段（session），現在具備自動恢復機制。針對非管理員或擁有者角色的 Team 與 Enterprise 團隊成員，修正了停止並重啟 claude remote-control 後工作階段偶爾卡死的問題。此外，當你嘗試接續一個遠端遙控權限正被其他終端機佔用的對話時，提示訊息現在會清楚說明其他機器上的工作階段無法看見或連線至當前機器。這相當於遠端連線基地台在伺服器重開時能自主重連，並在控制權被佔用時清楚標示跨機器隔離。

沙盒主動嘗試外連請求，代理大小寫相容與違規攔截

在受管網路環境下使用沙盒（sandbox）執行指令時，連線判斷更為靈活。沙盒環境中的 Bash 工具提示詞不再預先列出所有允許的網域清單，讓 Claude 能主動發起網路請求，方便你在執行當下核准新主機，避免 AI 預設未列出的主機皆被封鎖而直接放棄。當被攔截的指令依然回傳成功代碼 0 時（例如 curl 印出代理伺服器的 403 錯誤頁面），工具執行結果不會再遺漏沙盒的網路違規細節。此外，本機 IDE 連線現在同時相容大寫 NO_PROXY 與小寫 no_proxy 設定，避免本機連線誤走代理伺服器。正如警衛室不再預先封閉未登記的訪客通道，而是允許訪客提出申請並由管理員當場核准放行。

伺服器無回應三分鐘自動重試，錯誤排版與限流重置

就像撥打客服專線，若對方線路完全無聲，系統在約 3 分鐘後會主動重試一次，確定無回應便明確顯示錯誤訊息。 遭遇網路異常與額度重置時的體驗變得更加可靠。以前當 Anthropic API 完全沒有啟動回應時，工作階段（session）可能會陷入 10 分鐘以上的漫長無聲等待；現在請求會在約 3 分鐘後自動逾時並重試 1 次，若依然無回應則明確顯示 API Error: No response from API。驗證失敗、模型無法使用等用戶端產生的錯誤訊息，現在會以標準的錯誤行格式顯示，不再被誤渲染成 AI 的回覆文字。此外，當工作階段在閒置期間跨過限流視窗重置時間點，狀態列（status line，終端機最底部的即時狀態行）與 /usage 不會再殘留重置前的舊使用量百分比。

CI 環境共享授權令牌，用量遙測精確歸屬組織

在持續整合（CI）與企業環境中執行時，身分驗證與用量歸屬更加完善。在 CI 的工作負載身分同盟環境下，同一個作業中的多個處理程序現在會共用已兌換的 token（授權令牌）。系統不會再因重複兌換單次有效的令牌而導致失敗，若兌換遭拒也會直接顯示伺服器回傳的錯誤訊息以便快速排除。針對直接使用 ANTHROPIC_AUTH_TOKEN 向 Anthropic API 進行身分驗證的工作階段（session），其使用量遙測數據現在會正確歸屬至你的所屬組織，落實企業的資料處理政策。在 VSCode 中使用 Claude 帳號登入時，擴充套件本身的用量遙測也同步套用該歸屬規則。這如同出差團隊共用同一張換領證明完成各項任務，並將所有公務開銷精確歸戶至所屬部門。

啟動加速免等外部工具，下載瘦身與記憶體隨選載入

啟動速度與記憶體佔用迎來全方位瘦身優化。現在啟動時不再被沙盒與 MCP（讓 AI 連接外部工具的協定）初始化卡住首頁畫面，直接啟動會跳過子指令註冊，設定檔與工作流的讀取也變得更輕量。安裝檔與自動更新改採 zstd 壓縮，以 Linux x64 為例下載體積從原本的 340 MB 大幅縮減至約 75 MB；內建技能與提示詞經過壓縮後，原生二進位檔體積也縮減約 2 MB。在執行階段，程式碼改為隨選載入而非全部常駐記憶體。每個工作階段（session）約可節省 40 至 70 MB 記憶體，長久運作時也會在堆疊增長時提早進行垃圾回收以降低峰值用量。這好比跑車全面進行輕量化改裝，既縮減零件體積也只在需要時調用模組以節省引擎負擔。

代理定義格式嚴格驗證，指令替換與思考層級修正

就像海關申報檢查，若旅客遞交了格式毀損或無法辨識的文件，查驗窗口會直接退回並清楚指出格式錯誤，不再假裝沒看見。 命令列參數與自動化規則的防呆驗證全面收緊。使用 --agents 參數啟動時，若傳入無效的 JSON 或格式錯誤的代理人定義，程式不再默默略過，而是會像 --mcp-config 一樣立即印出明確錯誤並退出。在掛鉤（hook，特定事件觸發的小程式）條件中，修正了類似 Bash(cat *) 的判斷條件在遇到包含 $() 或反引號指令替換時誤觸發不相干指令的問題。此外，若在關閉思考功能的狀態下設定了 xhigh 或 max 思考等級，錯誤訊息會明確指出該等級名稱、是哪項設定關閉了思考，並提示改用 /effort high 解決。

macOS 桌面點擊授權，瀏覽器連線與長對話歷史保留

跨平台與編輯器整合的各項操作體驗更為穩固。在 macOS 上使用電腦操作（computer use）功能時，點擊桌面、Dock 應用程式列或 Finder 視窗現在需要透過存取對話框授予 Finder 權限，符合一般應用程式的安全授權規範。針對 Chrome 瀏覽器外掛整合，修復了自動更新刪除舊版本後導致瀏覽器與 Claude Code 連線中斷的問題，原生連線程式現在改透過穩定的 claude 啟動器載入。在 VSCode 長時間對話的工作階段（session）中，修剪過長歷史紀錄時會優先移除舊的工具操作細節，確保你的訊息與 Claude 的回覆文字持續完整可見。如同辦公大樓嚴格控管各處出入口授權，長久對話記錄也能妥善去蕪存菁以保留核心發言。

起動速度とメモリ効率が大幅に向上した。起動時にサンドボックスや MCP（外部ツール連携プロトコル）の準備で画面描画がブロックされなくなり、単体起動時のサブコマンド登録省略や設定読み込みの軽量化が行われた。インストーラーと自動更新は zstd 圧縮を採用し、Linux x64 のダウンロードサイズが約 340 MB から約 75 MB へ削減され、プロンプト等の圧縮によりバイナリも約 2 MB 小さくなった。さらにコードを常駐させずオンデマンドで読み込む設計へ刷新された。セッション（session）あたり約 40〜70 MB のメモリを節約し、ガベージコレクションの早期実行でピーク時メモリも抑制される。車体を軽量化し、必要な機能だけを動的に呼び出して燃費を向上させるようなものである。

エージェント定義の厳格な検証、フックのコマンド置換と推論設定を修正

書類に不備があった際に窓口が見過ごさず、具体的な誤りを指摘して差し戻すようなものである。 コマンドライン引数と自動化ルールの入力検証が強化された。--agents を指定して起動した際、無効な JSON や不正なエージェント定義を無視せず、--mcp-config と同様にエラーを出力して直ちに終了する。フック（hook）の条件分岐において、Bash(cat *) などの条件が $() やバッククォートを含む無関係なコマンドで誤作動する問題が修正された。また思考機能が無効な状態で xhigh や max の推論レベルを指定した際、該当設定と無効化原因を明示し、/effort high への変更を案内する。

macOS 操作の Finder 権限要求、Chrome 連携と会話履歴の保持

外部アプリやデスクトップ操作の安全性が高まった。macOS でのコンピュータ操作（computer use）機能において、デスクトップや Dock、Finder のクリック時にアクセス確認画面を通じて Finder の権限許可が求められるようになった。Chrome 拡張機能連携において、自動更新で旧バージョンが削除された後に接続が切れる不具合が修正され、安定した claude 起動プログラム経由で起動するようになった。VSCode の長いセッション（session）では、履歴削除時に古いツールの実行行から優先して間引かれ、ユーザーの質問と Claude の返答テキストが画面上に残りやすくなった。オフィスの入退出権限を適切に管理し、議事録の要約時に細かい作業メモだけを省いて重要な発言を残すようなものである。

기업용 중앙 관리 설정을 배포할 때 비용 계산과 설정 적용 출처가 한층 투명해졌다. 관리자가 modelPricing 관리 설정을 배포할 수 있게 되었다. 이에 따라 /cost 명령어와 상태 표시줄 및 원격 측정 비용 통계에서 표준 정가 대신 회사의 계약별 모델 단가와 할인율이 반영된다. /status를 실행하면 Skipped sources 항목이 표시되어 managed-settings.json 같은 설정 파일이 존재하더라도 우선순위가 높은 설정에 밀려 적용되지 않은 출처를 명확히 보여준다. /mcp 및 /plugins 목록에서도 조직에서 인증을 관리하는 claude.ai 커넥터 옆에 managed 표시가 붙는다. 법인 전용 할인율이 영수증에 바로 찍히고, 적용되지 않은 사내 규정 우선순위가 안내판에 명시되는 것과 같다.

API 키 없는 Console 계정 로그인 지원, SSH 인증 복사와 사내 공지 표시

서브에이전트 모델과 추론 강도를 표시하고, 완료 알림과 뷰 축소를 수정했다.

작업 현황판에 각 조수가 사용하는 장비 모델명과 출력 등급이 적혀 있는 것과 같다. 서브에이전트 작업 모니터링이 한층 명확해졌다. /tasks나 에이전트 상세 대화상자에서 각 서브에이전트가 실행된 모델명과 추론 노력 수준(effort level)을 한눈에 확인할 수 있다. 백그라운드 서브에이전트가 마지막 Bash 작업 완료 후 잠에서 깨어나지 못하던 현상이 해결되어 작업이 정상적으로 이어진다. VSCode의 Focus 뷰에서 사용자가 펼쳐 둔 섹션이 서브에이전트의 도구 호출 중에 저절로 접히던 현상도 바로잡았다.

원격 MCP 연결 끊김 자동 재접속 지원, 데스크톱 인증과 설정 오류를 수정했다.

외부 도구 연동 안정성이 크게 향상되었다. 비대화형 -p 모드 및 SDK 호출 환경에서 원격 MCP(외부 도구 연동 프로토콜) 서버 연결이 끊겼을 때 자동으로 재연결을 시도하거나 실패를 명확히 보고한다. 재접속 실패 시에도 오류가 출력되어 세션(session)이 멈추지 않는다. Linear 등 메타데이터 문서를 지원하는 서버에서 데스크톱 앱을 통해 MCP 로그인을 시도할 때 잘못된 리다이렉트 URI 오류가 나던 문제를 해결했다. 아울러 ~/.claude.json 파일에 잘못된 MCP 서버 설정이 있을 때 /status가 파일명 없이 마침표만 찍던 오류를 고쳐 올바른 파일명을 표시한다. 직통 전화가 끊기면 자동으로 다시 걸어주고, 주소록에 오류가 생기면 문제된 파일을 정확히 짚어주는 것과 같다.

플러그인 종속성 문제를 해결하고, LSP 도구 재로드 시 경고를 제공한다.

플러그인 개발 및 확장 기능 관리가 한결 깔끔해졌다. --plugin-dir 옵션으로 여러 플러그인을 함께 불러올 때, marketplace 필드가 선언된 플러그인 종속성이 인식되지 않던 문제를 바로잡았다. /reload-plugins 명령어를 실행할 때 마지막 LSP(Language Server Protocol, 코드 완성 및 정의 조회를 지원하는 프로토콜) 플러그인이 비활성화되면 잔여 도구를 깨끗이 정리한다. 아울러 플러그인 변경으로 대화 내역을 다시 읽어야 하는 경우 작업 전 경고를 띄워준다. 도구함의 부속품이 서로 맞물려 고정되고, 서랍을 비우기 전에 미리 확인을 구하는 것과 같다.

자동 모드 잠김 현상 해결, 과부하 재시도 및 초기 권한 모드를 개선했다.

임시 도로 통제가 풀린 뒤 자동차의 정속 주행 기능이 정상적으로 다시 켜지는 것과 같다. 자동 모드(auto mode, 확인 없이 도구를 스스로 실행하는 모드)의 여러 멈춤 현상이 해결되었다. 서버 측 임시 비활성화 상태가 캐시된 뒤 플래그 조회가 실패해도 시작 시 자동 모드가 계속 잠겨 있던 문제를 고쳤다. API 일시 과부하로 재시도를 요청받았을 때, 약 1분 대기 후 도구 호출이 불가하다며 거절당하던 현상도 바로잡았다. VSCode 환경에서 설치 직후 플래그를 불러오기 전에 시작된 세션(session)도 기본 권한 모드로 밀려나지 않고 사용자가 설정한 기본 모드나 자동 모드로 올바르게 열린다.

세션 선택기 무한 스크롤 지원, 작업 임시 저장과 알림 전송을 개선했다.

지난 대화를 다시 이어 나가는 과정이 훨씬 편리해졌다. /resume 실행 시 최근 50개 세션(session)만 보여주던 한계가 사라져, 아래로 스크롤하면 이전 대화 내역을 계속해서 불러온다. claude --teleport <session> 명령 사용 시 커밋되지 않은 변경 사항이 남아 있어도 즉시 종료되지 않고, 변경 내용을 stash로 임시 저장하고 작업을 계속할지 물어본다. 클라우드 세션에서 대화 도중 재시작되었을 때 보류 중이던 훅(hook)이나 백그라운드 작업 알림이 프롬프트 대신 정상적인 후속 메시지로 전달되도록 수정했다. 서류 보관함을 끝없이 넘겨볼 수 있고, 자리를 옮기기 전에 미완성 문서를 임시 보관함에 넣어두는 것과 같다.

터미널 검색 오류 방지, 세션 제목 유지 및 키 입력 문제를 해결했다.

터미널 명령어 입력 환경이 한결 안정적으로 다듬어졌다. /clear로 대화를 비울 때 /rename으로 지정한 세션(session) 이름이 입력창에서 사라지지 않고 유지된다. ~/.claude/history.jsonl에 손상된 기록이 섞여 있어도 Ctrl+R 검색이나 위쪽 화살표 기록 탐색이 멈추지 않고 부드럽게 넘어간다. modifyOtherKeys나 kitty 프로토콜을 사용하는 터미널에서 Ctrl+[ 입력 시 Vim 삽입 모드를 빠져나가지 못하던 문제를 고쳤다. 이모지 바로 뒤에 입력한 오타에도 맞춤법 검사 밑줄이 정상적으로 표시된다. 노트의 속지를 교체해도 표지 라벨이 그대로 남고 찢어진 페이지를 건너뛰며 기록을 넘겨보는 것과 같다.

루트리스 컨테이너 세션 간 통신을 복구하고, 유휴 소켓 연결을 자동 해제한다.

개별 방 사이에서도 인터폰 통화가 정상 연결되고, 30초 동안 말이 없으면 통화 회선이 저절로 끊기는 것과 같다. 세션 간 메시지 전송 기능이 한층 안정화되었다. 2.1.232 버전의 소켓 디렉터리 보안 강화 이후 사용자 네임스페이스 및 루트리스 컨테이너 내부에서 세션(session) 간 통신이 꺼지던 문제를 해결했다. 또한 수신 소켓은 30초 이내에 온전한 한 줄을 보내지 않는 연결을 자동으로 끊으므로, 메시지를 전송하는 스크립트는 데이터를 모두 준비한 뒤 연결해야 한다.

원격 제어 환경 끊김 시 자동 복구 지원, 재시작 및 타 단말 안내를 개선했다.

원격으로 대화를 다룰 때 접속 유지력이 크게 강화되었다. 서버 환경이 중간에 끊기더라도 claude remote-control이 그대로 종료되어 세션(session)이 방치되지 않고 자동으로 복구된다. 관리자나 소유자 권한이 없는 Team 및 Enterprise 구성원이 프로세스를 껐다 켰을 때 세션이 멈추던 문제도 해결했다. 다른 터미널에서 원격 제어 중인 대화를 열려고 할 때, 다른 기기의 세션에서는 현재 기기를 볼 수 없거나 접근할 수 없다는 안내문이 표시된다. 원격 중계기가 일시 장애 후 자동으로 재접속되고 다른 단말이 제어 중일 때 접속 제한을 명확히 알려주는 것과 같다.

샌드박스 네트워크 요청 시도를 지원하고, 프록시 대소문자 예외를 처리했다.

샌드박스 환경에서 명령어를 실행할 때 네트워크 요청 처리가 한결 매끄러워졌다. Bash 도구 프롬프트에서 허용 호스트 목록을 미리 나열하지 않도록 변경하여, Claude가 먼저 요청을 시도하고 사용자가 승인할 수 있게 했다. 차단된 명령어가 정상 종료 코드 0을 반환하더라도(예: curl이 프록시의 403 페이지를 출력한 경우) 샌드박스 위반 세부 정보가 도구 결과에서 누락되지 않는다. 아울러 대문자 NO_PROXY와 소문자 no_proxy를 모두 인식하여 로컬 IDE 통신이 프록시로 잘못 전달되는 일을 막았다. 경비실에서 미등록 방문자를 무조건 돌려보내지 않고 출입 신청을 받아 관리자가 즉석에서 승인하는 것과 같다.

API 무응답 시 3분 후 자동 재시도, 에러 서식과 사용량 리셋을 수정했다.

통화 중에 아무 소리가 들리지 않으면 약 3분 뒤 전화를 한 번 다시 걸어보고 여전히 불통이면 오류를 띄우는 것과 같다. API 장애와 한도 갱신 처리가 정확해졌다. Anthropic API 응답이 전혀 오지 않을 때 10분 이상 먹통이 되던 문제를 고쳐, 약 3분 후 요청을 중단하고 1회 재시도한 뒤 실패하면 API Error: No response from API를 명확히 출력한다. 인증이나 모델 사용 불가 등 클라이언트 내부 에러 문구가 모델 답변처럼 출력되지 않고 오류 서식으로 표시된다. 세션(session)이 쉬는 동안 사용량 갱신 시점이 지나면 상태 표시줄과 /usage의 이전 사용률이 최신으로 바뀐다.

CI 환경 토큰 공유와 실패 안내, 조직 원격 측정 귀속을 지원한다.

지속적 통합(CI) 환경과 기업 내 사용량 추적이 개선되었다. CI의 워크로드 아이덴티티 연동 환경에서 한 작업 안의 프로세스들이 교환된 토큰(token)을 함께 공유한다. 일회용 토큰 재교환 오류를 방지하고, 거절 시 서버 에러 메시지를 띄우며 즉시 종료된다. ANTHROPIC_AUTH_TOKEN으로 직접 인증하는 세션(session)의 사용량 원격 측정이 소속 조직으로 정확히 집계되어 기업의 데이터 처리 정책이 적용된다. VSCode 확장 프로그램에서도 Claude 계정으로 로그인했을 때 조직으로 데이터가 정상 귀속된다. 출장팀이 발급받은 하나의 통행증을 함께 사용하고 모든 업무 경비가 소속 부서로 바르게 청구되는 것과 같다.

시작 속도 가속, zstd 다운로드 압축과 온디맨드 메모리 절약

시작 속도와 메모리 사용 효율이 개선되었다. 시작 시 샌드박스와 MCP(외부 도구 연동 프로토콜) 초기화가 화면 표시를 지연시키지 않고, 하위 명령어 등록을 건너뛰며 설정 조회가 가벼워졌다. 설치 및 자동 업데이트 파일에 zstd 압축을 적용하여 Linux x64 기준 다운로드 용량이 약 340MB에서 약 75MB로 줄었고, 번들 텍스트를 압축해 바이너리 크기도 약 2MB 줄였다. 실행 중에는 코드를 메모리에 상주시키지 않고 필요할 때 불러온다. 세션(session)당 약 40~70MB의 메모리를 아끼며, 긴 작업 시 메모리 청소를 앞당겨 최대 사용량을 낮춘다. 차량을 경량화하고 필요할 때만 부품을 가동하여 엔진 부담을 덜어주는 것과 같다.

에이전트 정의 검증을 강화하고, 훅 명령어 치환과 추론 강도 오류를 수정했다.

잘못된 서류를 무심코 넘기지 않고 어디가 틀렸는지 짚어주며 반려하는 출입 심사대와 같다. 명령어 인자와 자동화 규칙 검증이 한층 엄격해졌다. --agents 옵션으로 실행할 때 잘못된 JSON이나 에이전트 정의를 그냥 넘기지 않고 --mcp-config처럼 명확한 에러와 함께 즉시 종료된다. 훅(hook) 조건에서 명령어 치환 규칙이 개선되었다. Bash(cat *) 같은 조건이 다른 명령어 치환 구문이나 역따옴표가 들어간 무관한 명령어에 오작동하던 문제를 고쳤다. 아울러 생각 기능이 꺼진 상태에서 xhigh나 max 추론 수준을 지정하면, 비활성화된 원인 설정과 함께 /effort high로 변경하라는 해결책을 알려준다.

macOS 데스크톱 접근 권한 확인, Chrome 연동과 대화 기록 유지를 개선했다.

데스크톱 및 에디터 연동 동작이 더욱 안정적으로 바뀌었다. macOS에서 컴퓨터 제어(computer use) 기능 사용 시 데스크톱 화면, Dock 또는 Finder 창을 클릭할 때 접근 권한 창을 통해 Finder 승인을 거치도록 보안 절차를 맞추었다. Chrome 확장 프로그램 연동에서 자동 업데이트가 이전 버전을 정리한 뒤 연결이 끊기던 문제를 해결하여, 이제 안정적인 claude 실행 프로그램을 통해 띄운다. VSCode 환경의 긴 세션(session)에서는 대화 기록을 정리할 때 오래된 도구 실행 내역을 먼저 지워 사용자의 질문과 Claude의 답변이 가려지지 않게 보호한다. 사무실 출입 권한을 꼼꼼히 확인하고 회의록을 정리할 때 잡무 기록을 먼저 털어내어 중요한 발언을 보존하는 것과 같다.
