Claude Code 2.1.243

Released: 2026-08-24

Release notes

FEATURE

/usage adds Loops breakdown, with idle wake-ups folded cleanly

Like a security patrol clock where routine passes with nothing to report collapse into a single line instead of filling up the entire logbook.

When running recurring tasks with /loop, monitoring execution details is now much easier.

Running /usage introduces a dedicated Loops breakdown that details per-loop run counts, total tokens, tokens per run, and the last run timestamp, making it easy to spot runaway or chatty tasks. Furthermore, consecutive wake-ups where Claude has nothing to do are now folded into a single terminal line instead of printing every single empty turn.

FEATURE

Customizable model picker ordering, with instant commands on cloud platforms

You can now curate your model lineup exactly as you prefer.

Adding the modelPicker setting lets you customize the /model picker with an ordered, labeled list of models (supporting any identifier spelling, including Vertex and Bedrock IDs), either appended to or replacing the built-in selection. Selecting Ultracode in the picker is also fixed and now applies directly to the current session. The picker and bundled claude-api skill show Sonnet 5's $2/$10 per Mtok pricing as standard list price rather than a temporary promotion. Furthermore, /model, /fast, and /effort execute immediately on Bedrock, Vertex, Foundry, or when telemetry is disabled instead of queueing until the turn ends.

Like a customized cafe menu where signature selections are prepared immediately without waiting for the ordering queue to flush.
FEATURE

Independent prompt cache TTL controls for main sessions and subagents

Like an office filing system where active master files stay accessible on the desk for 1 hour while transient errand notes expire after 5 minutes.

Users connecting via API keys or cloud providers can now independently configure prompt caching lifetimes.

The newly added promptCacheTtl and subagentPromptCacheTtl settings allow you to keep a 1-hour prompt cache on the main conversation to minimize redundant processing, while keeping short-lived subagents on a 5-minute cache to balance storage costs.

FEATURE

Contracted model pricing in cost estimates, with clear managed settings sources

Enterprise configuration distribution and cost tracking are now much more transparent.

Organizations can configure the modelPricing managed setting. This allows /cost, the status line, and telemetry metrics to reflect custom contracted rates and discount multipliers instead of public list prices. Running /status now includes a Skipped sources line that explicitly enumerates managed configuration files (such as managed-settings.json) that are present but ignored due to higher-precedence sources. Additionally, claude.ai connectors in /mcp and /plugins whose authentication is managed by your organization are clearly badged with a managed tag.

Like corporate employees receiving contracted enterprise discounts, with expense logs clearly itemizing policy sources and authentication badges.
FEATURE

Keyless Console sign-in option, with polished SSH login and announcements

Like building security granting badge tap access so employees no longer need to write down temporary access codes.

The authentication experience has received multiple refinements.

Under /login → Anthropic Console, a keyless "Sign in with your Console account" option is now available (and recommended) alongside API key creation, allowing organizations that forbid manual API keys to sign in cleanly. Over SSH, the sign-in URL renders immediately, pressing c accurately reports how the URL was copied rather than always claiming success, and fullscreen hints explain how to select text. Long URLs overflowing container boundaries no longer lose their leading columns during repaints, and server-managed companyAnnouncements correctly display upon startup right after logging in.

FEATURE

GitHub connection status for web sessions, with legacy GitHub CLI support

Connecting web-based Claude Code sessions to your GitHub repositories is now much smoother.

For claude.ai users who haven't yet linked GitHub for Claude Code on the web, a helpful tip guides you directly to /web-setup. Checking /status displays a dedicated line showing whether GitHub is connected for your Pro or Max web workspace, pointing you to /web-setup whenever it isn't. Furthermore, running /web-setup no longer gets stuck repeatedly demanding logins when an older GitHub CLI installation without the gh auth token command is already authenticated.

Like a dashboard status light that points out unlinked communication channels while remaining fully compatible with older security badges.
FEATURE

Subagent model and effort visibility, with reliable wake-up and view persistence

Like a workshop job board detailing the specific machinery and effort ratings assigned to each technician.

Inspecting subagent tasks is now far clearer.

Running /tasks or opening subagent detail dialogs explicitly displays the exact model and effort level assigned to each agent. When background subagents run long Bash jobs, an issue where agents failed to wake after their final background task completed has been resolved, ensuring uninterrupted workflow continuations. In VSCode, sections you manually expand inside the Focus view will no longer spontaneously collapse whenever subagents execute background tools.

BUGFIX

Remote MCP reconnection in headless runs, with desktop auth and status fixes

Connecting to external tools via MCP is now significantly more dependable.

In non-interactive -p runs and SDK sessions, dropped connections to remote MCP (Model Context Protocol) servers now automatically reconnect or report an explicit failure instead of silently hanging. For services supporting client ID metadata documents such as Linear, MCP server sign-in initiated from the desktop application no longer fails with an invalid redirect URI error. Additionally, when ~/.claude.json contains a malformed MCP server configuration, /status explicitly prints the offending filename instead of displaying an unhelpful dot without a path.

Like a dedicated hotline automatically redialing dropped lines while misconfigured address books cleanly point to the exact file requiring attention.
BUGFIX

Marketplace plugin dependency resolution, with LSP reload warnings

Plugin development and lifecycle management are significantly more dependable.

When loading multiple local plugins together via --plugin-dir, dependencies declaring a marketplace field now resolve smoothly rather than failing indefinitely. Running /reload-plugins properly removes the LSP (Language Server Protocol) tool once the final LSP-providing plugin is disabled. Additionally, if an LSP plugin modification requires re-reading the entire conversation history, the command proactively surfaces a warning before proceeding.

Like a modular toolbox locking interdependent attachments into place while warning you before reorganizing entire drawers.
BUGFIX

Auto mode transient lockup fixes, overload retry, and VSCode launch defaults

Like a vehicle cruise control system recovering promptly after a temporary road closure instead of remaining permanently locked out.

Auto mode (where Claude acts without prompting for approval on every action) has received critical reliability fixes.

If a temporary server-side disable was cached, subsequent feature flag fetch failures will no longer keep auto mode permanently disabled at startup. When the API experiences brief overload and requests client retries, tool calls in auto mode will no longer be rejected as "temporarily unavailable" after waiting about 1 minute. In VSCode, sessions started before feature flags finish their initial fetch (such as immediately after installation) now cleanly open in auto mode or your configured default mode rather than falling back to default permission prompts.

BUGFIX

Infinite scrolling for session picker, with teleport stash prompts

Picking up past conversations is now much smoother.

Running /resume is no longer capped at displaying the 50 most recent sessions; scrolling down continuously fetches older conversations. When running claude --teleport <session> with uncommitted git changes, the CLI prompts to stash your changes and proceed rather than abruptly exiting. In cloud environments, sessions resuming after a mid-turn restart now send pending hook or background task notifications as regular continuation messages instead of mistaking them for user prompts.

Like browsing through an expandable filing drawer that safely stashes draft notes into temporary storage before moving across desks.
BUGFIX

Terminal history resilience, session title preservation, and keybinding fixes

Everyday terminal interactions are now significantly more reliable.

Running /clear preserves your renamed session title in the prompt bar for the new session instead of dropping it. When ~/.claude/history.jsonl contains a malformed entry, searching history via Ctrl+R or pressing the up-arrow no longer breaks command browsing. Terminals that encode modified keys (such as modifyOtherKeys or kitty protocol) now properly exit Vim INSERT mode when pressing Ctrl+[. Furthermore, spellcheck accurately underlines misspelled words typed immediately following an emoji.

Like swapping pages in a binder while keeping drawer labels intact and gracefully skipping over torn historical notes.
FEATURE

Cross-session messaging in rootless containers, with socket idle timeouts

Like an apartment intercom allowing residents in isolated rooms to communicate freely while hanging up on lines that stay silent for 30 seconds.

Inter-session communication is now significantly more dependable.

Following directory security hardening in version 2.1.232, cross-session messaging that silently disabled itself inside user namespaces and rootless containers has been restored. Furthermore, the cross-session inbox socket now closes any connection that fails to send a complete line within 30 seconds, so custom scripts should connect only when payloads are ready to transmit.

BUGFIX

Remote Control environment auto-recovery, role fixes, and cross-machine notices

Remote session control is significantly more resilient against network interruptions.

When a server drops its environment mid-session, claude remote-control automatically recovers instead of exiting and stranding attached sessions. For Team and Enterprise members without admin or owner roles, sessions served by claude remote-control no longer get stuck after being stopped and restarted. When resuming a conversation currently locked by another terminal, the prompt explicitly informs you that sessions on other machines cannot be viewed from or reach your current host.

Like a remote base station that automatically reconnects after dropouts while clearly warning when another terminal holds active control.
FEATURE

Sandboxed Bash network requests on demand, proxy casing, and violation logs

Network handling inside the execution sandbox is now much more flexible.

The sandboxed Bash tool prompt no longer pre-lists allowed hosts, encouraging Claude to attempt requests so you can approve new domains on the fly instead of having the model assume unlisted hosts are blocked. When a blocked command exits with code 0 (such as curl outputting a proxy 403 page), the full network violation details are preserved in the tool results. Furthermore, local IDE connections now honor both uppercase NO_PROXY and lowercase no_proxy environment variables to prevent local traffic from routing through HTTP proxies.

Like a checkpoint guard allowing visitors to request entry for live supervisor approval rather than turning everyone away at the gate.
BUGFIX

Three-minute API timeout with auto-retry, clean error lines, and usage refresh

Like a phone call that redials once after 3 minutes of dead silence and clearly reports the issue if the line remains dead.

Handling API dropouts and rate limits is now much more predictable.

If the Anthropic API never begins streaming a response, requests no longer sit silent for 10+ minutes; they now time out after ~3 minutes, retry once, and surface API Error: No response from API if unresolved. Client-generated error messages (such as authentication or model availability errors) render as explicit error lines instead of normal model output. Furthermore, idle sessions accurately reset the status line rate_limits and /usage percentages once windows reset.

FEATURE

Workload identity token sharing in CI, with enterprise telemetry attribution

Automated CI workflows and organization telemetry tracking have been significantly upgraded.

Under workload identity federation in CI pipelines, multiple processes within a single job now share the exchanged token instead of attempting to reuse a single-use token. Rejected exchanges fail fast alongside informative server messages. For sessions authenticating directly against the Anthropic API using ANTHROPIC_AUTH_TOKEN, usage telemetry is accurately attributed to your organization so its data-handling policies apply. In VSCode, extension telemetry similarly routes to your organization when signed in via a Claude account.

Like a field crew sharing a single master entry voucher while all corporate expense logs route directly to company accounts.
FEATURE

Instant startup skipping MCP blocks, zstd binary compression, and on-demand memory

Startup speed and memory footprints have been thoroughly optimized.

Startup no longer blocks its initial frame on sandbox and MCP bring-up, bare launches skip subcommand registration, and settings or trust-store lookups are significantly lighter. Installation and auto-update downloads now use zstd compression, shrinking the Linux x64 binary download from ~340 MB down to ~75 MB, while compact prompt storage shaves ~2 MB off the final binary. During execution, code loads on demand rather than keeping the entire bundle resident. Each session saves roughly 40–70 MB memory, and garbage collection triggers earlier in long sessions to tame peak heap memory.

Like a sports car undergoing comprehensive weight reduction, minimizing package sizes and engaging auxiliary components only when needed.
BUGFIX

Strict agent definition validation, hook substitution, and thinking effort fixes

Like an official checkpoint rejecting malformed paperwork with clear instructions rather than waving invalid documents through.

Command line inputs and automation rules now feature stricter validations.

When launching with --agents, malformed JSON or invalid agent definitions will no longer be silently ignored; the CLI exits immediately with a descriptive error, matching --mcp-config. Hook if conditions like Bash(cat *) no longer mistakenly fire on unrelated commands containing $() or backtick substitutions. Additionally, setting effort levels to xhigh or max while thinking is disabled triggers a clear error naming the configured level, the offending setting, and /effort high as the fix.

FEATURE

macOS desktop Finder permissions, Chrome reconnects, and VSCode history trimming

Desktop integrations and extension reliability have been polished.

On macOS, computer use actions that click the desktop, Dock, or Finder windows now explicitly require granting Finder permission via the system access dialog, aligning with standard application security policies. In the Claude in Chrome extension, connection drops caused by auto-updates cleaning up past binaries are resolved by having the native messaging host launch through the stable claude launcher. In VSCode long sessions, history trimming prioritizes dropping older tool-activity rows first, ensuring your prompts and Claude's replies remain visible.

Like an office building managing access checkpoints while archiving historical meeting transcripts by pruning routine logs to preserve key statements.
