Claude Code 2.1.281

Released: 2026-09-23

Release notes

FEATURE

Claude apps gateway adds Bedrock role assumption and guardrails

When enterprises centrally manage model traffic in the cloud, the gateway adds an assume_role field in upstream settings.

This allows the gateway to call Amazon Bedrock using temporary credentials assumed through STS, across other AWS accounts if needed, while supporting one session per developer. Upstreams also support configuring guardrail: {id, version} to require all requests to pass through a specified safety guardrail.

Picture headquarters dispatching dedicated trucks to branch facilities where they put on site-specific passes, while every vehicle passes through a security gate to filter out prohibited items before departure.
BUGFIX

Claude apps gateway expands Desktop policies and fixed telemetry labels

When organizations uniformly configure development environments, the gateway's desktop policy block adds several control keys.

Administrators can configure blockReadsOutsideWorkingDirectories to prevent reading files outside working directories. Enforcing disableBypassPermissionsMode to disable bypass permissions mode is also supported. The gateway configuration file can also add fixed telemetry labels to login and session traffic via telemetry.resource_attributes. If a managed MCP server path begins with a format that current Claude Desktop does not support, the gateway refuses to start to ensure safety.

FEATURE

Added attribution setting to hide commit and PR attribution

To keep code repository history clean, you can now add "attribution": false in settings to turn off all commit and pull request tool attribution.

If multiple team members share a configuration file, keep the full curly-brace object format to prevent older CLI versions from skipping the entire settings file when encountering an unknown format.

This works like removing a word processor's watermark when dispatching an official document, keeping the resulting records solely focused on your work.
{

FEATURE

MCP adds URL-mode elicitation so servers can request browser-based flows

When external services require you to complete login or authorization on the web, MCP servers on the 2026-07-28 protocol version can now ask Claude Code to open a browser screen.

If the server cannot confirm subsequent completion, the terminal avoids leaving a stuck waiting dialog on screen.

Think of an ordering kiosk displaying a web payment link so your phone opens the checkout screen directly, without leaving the counter display stuck in a loading loop.
FEATURE

Send now moves running tools to background instead of cancelling turns

When Claude is executing a time-consuming command and you have already prepared follow-up questions or new tasks, pressing a shortcut (Ctrl+Enter or Ctrl+X Ctrl+S) smoothly transitions running tools to the background.

You do not have to wait for them to finish, and typing ahead will not abort the prior conversation turn.

A chef simmers soup on the stove while stepping into the living room to hand off the next report to a colleague, letting the pot bubble quietly without forcing anyone to wait by the burner.
FEATURE

Auto mode review covers read-only commands and recommends permission savings

For hands-free tool execution, auto mode with the server-side classifier enabled now routes read-only and sandboxed commands through server review, actively blocking them if flagged.

Direct Anthropic API connections can opt in to review via CLAUDE_CODE_AUTO_MODE_SERVER=1. Entering /insights in the terminal also estimates how many manual confirmations auto mode saved in your recent sessions.

FEATURE

Auto mode improves restart cache reuse and denial intent handling

When resuming a session in a new process after an interruption, the auto mode permission classifier now directly reuses its earlier prompt cache.

This saves time by retrieving cached computation. When you deny a dangerous action, Claude now understands you are rejecting the intended outcome rather than only the specific line of phrasing, avoiding repeated attempts with synonymous commands.

Tell a butler not to buy a certain pastry, and he understands you want to avoid that dessert altogether rather than visit another convenience store to bring it back.
FEATURE

Enhanced deletion protection adds variable path checks and timeout denials

When tools in auto or bypass permissions mode prepare to run recursive deletion commands containing variable substitution, such as rm -rf "$(pwd)", they now pause to ask for confirmation instead of running unprompted.

Safety protections also flag targets where a shell variable is followed by a top-level directory name or contains only a backslash. In unattended sessions, the confirmation prompt waits 2 minutes before automatically denying the command with a rewrite hint, preventing workstations from hanging indefinitely on unhandled keystrokes.

FEATURE

Self-hosted runners use files for system prompts and count instruction files

When building self-hosted runners for automation pipelines, long system prompts can now be passed as private file paths via --system-prompt-file, preventing launch failures from oversized command-line text.

Startup prompt size warnings also count all related instruction files and @-imports together. In headless mode, mounted directories added via --add-dir no longer send duplicate rule files to the model.

BUGFIX

Fixed resumed sessions dropping reasoning due to changed message format

Multiple session resumption mechanisms have been thoroughly overhauled when resuming incomplete conversations.

Previously, parallel tool calls, MCP reconnects, or interrupted turns could resend modified conversation history, causing the API to drop prior reasoning context. Oversized sessions no longer restore only their last few messages, restarts during pending permission prompts no longer break prompt caching, and manual resumes after interrupted tool calls no longer insert hidden messages. Damaged history records are now repaired automatically at startup.

FEATURE

Improved resume speed and cache restoration for long compacted sessions

Session loading efficiency is significantly improved when handling large projects and long conversations.

When reopening sessions that read many files, restoring the file cache is much faster, and contents match the files exactly as they were read. Resuming compacted long sessions in the Agent SDK and Claude Desktop is also smoother. If a massive first prompt triggers a prompt length limit, the system now summarizes that prompt on its own during recovery to keep the conversation going.

BUGFIX

Fixed stream drops and state loss from premature proxy disconnects

Streaming fault tolerance is strengthened when connecting through enterprise proxies or gateways.

Previously, a stream cleanly closed by a proxy could be mistaken for a complete response, and duplicate events could trigger tool calls twice. Dropped stream events now properly preserve partial responses and web search results that have already arrived. Fixes also resolve interface crashes during API request retries, duplicate empty requests after dropped connections, and lost stop reasons when trailing frames contain only usage data.

BUGFIX

Fixed API retry loops, rate limit waits, and HTML error parsing

When unparseable tool calls alternate with output-limit truncation, turns no longer retry indefinitely while ignoring --max-turns.

The retry watchdog in CLAUDE_CODE_RETRY_WATCHDOG sessions no longer sleeps silently and uncapped on server errors. Fast mode also stops firing rapid back-to-back retries upon receiving Retry-After: 0. When proxies return HTML error pages for 429 or 502 codes, the terminal extracts the HTTP status rather than printing raw markup.

BUGFIX

Fixed tool hangs from oversized images, long names, and memory reads

Edge case stability is strengthened when invoking tools for multimedia and heavy workloads.

When a tool returns an oversized image, sibling tool calls in the same batch no longer hang unanswered or abandon the turn. Fixes also resolve conversations getting permanently stuck when tool names exceed 200 characters, false tool failures when memory usage cannot be read due to exhausted file descriptors, and delays or uncancelable background page rendering when reading PDFs larger than 3 MB.

BUGFIX

Fixed file tool handling for null-byte paths and duplicate parameters

Parameter validation logic has been corrected across multiple file handling tools during code editing.

When using Read, Write, Edit, or NotebookEdit, file paths containing a null byte now fail with a clear error instead of aborting the entire turn. Write calls that provide identical path and content values across two duplicate parameter names are also no longer rejected.

A mail carrier returns a misaddressed envelope with an explanatory note rather than going on strike and walking home.
BUGFIX

Fixed sandbox command exclusion matching and added port binding guidance

When developing inside the macOS sandbox, Claude points to sandbox.network.allowLocalBinding if a local development server fails to bind a port.

Fixes also correct sandbox excludedCommands matching for specific Git commands and tagged commit messages, resolve $TMPDIR write failures when CLAUDE_CODE_TMPDIR is customized, and prevent permission rules with NUL bytes from expanding into wildcards or accessing network mount paths.

BUGFIX

Fixed duplicate MCP connections, hook waits, and headless handshake hangs

When connecting to host-side MCP servers in headless mode, remote sessions now wait only a few seconds before recovering if the host stops responding mid-handshake.

Blocking event hooks also wait for MCP server connections before firing. Fixes also resolve duplicate connections caused by URL casing or trailing slashes, and sync status bar login indicators when authenticating from another process.

FEATURE

Filtered MCP app resources and improved attachment caching and screen readers

When listing or @-mentioning MCP resources in the terminal, resource lists skip MCP Apps UI resources to keep prompts clean.

Remote Control connections reuse sockets and cached files for previously downloaded attachments in the session, saving bandwidth. Screen readers navigating the /mcp list also announce disabled servers clearly as "off" rather than "pending".

BUGFIX

Plugins add MCP validation checks and fix project-scope management commands

When developing or installing plugins, running claude plugin validate now checks for dropped .mcp.json entries, undeclared ${user_config.*} variables, and insecure URLs, without mistaking privacy or support URLs for unknown fields.

Fixes also resolve uninstall errors for project-scope plugins reporting as enabled, prevent omitted --scope update flags from defaulting to user scope, and fix empty plugin loads from directories containing marketplace files.

FEATURE

Plugins name offending packages on errors and improve hook paths and caching

Error reporting is clearer when debugging and managing plugin packages.

When a plugin hook fails, error messages name the offending plugin directly. The validator also warns if shell hooks leave ${CLAUDE_PLUGIN_ROOT} unquoted, avoiding breaks on paths with spaces. Marketplaces that keep local clones on connection failure are no longer marked as refreshed, and uninstall routines explain when files remain because other plugins use them.

BUGFIX

Improved plugin list layout and scrolling, and fixed marketplace updates

Opening /plugin in the terminal aligns installed plugins into neat columns for status, name, type, and details.

Mouse wheel scrolling navigates the list smoothly without moving background panes. Fixes also prevent repeated Enter presses from triggering duplicate updates or uninstalls, stop held y keys from instantly adding marketplaces before prompts can be read, and show confirmation prompts after resolving all items on the Errors tab.

FEATURE

Session artifacts collapse to footer pills with improved copy and compression

Artifacts generated during conversations are now consolidated into a single footer pill below the prompt (such as ⧉ name).

Clicking it opens the /artifacts menu to view all outputs from the session. The artifact design skill asks Claude for direct, plain prose, large artifact uploads over slow connections are automatically compressed, scripts from unpkg.com are allowed, and Remote Control sessions retain the Artifact tool.

BUGFIX

Fixed background agent reports, scheduled routines, and retry loops

For long-running remote workflows, cloud sessions now report finished background agents to Claude even if worker restarts occur immediately after completion.

Scheduled tasks and /loop wakeups no longer retry every second upon delivery failure, preventing Claude Code from exiting at turn end. Fixes also resolve interfaces stuck on "needs approval" during overlapping prompts, deliver missing turn-start notices on scheduled turns, and avoid false policy-disabled notices while org policies load.

BUGFIX

Fixed macOS keychain credential loss and optimized interactive startup time

On macOS, writing credentials while the keychain is locked or right after wake no longer drops stored MCP OAuth tokens or deletes keychain entries.

Cloud authentication refresh processes release localhost ports upon exit. Interactive startup defers Git reads and model-upgrade checks until after the first frame renders, while stopping unexecutable policy retries to make terminal sessions ready faster.

BUGFIX

Fixed setting source forwarding for sub-sessions and checked workspace trust

Launching background sessions via claude --bg now checks workspace trust before running project hooks instead of executing unprompted.

Settings restrictions set via --setting-sources are forwarded to teammate, /bg, and worktree sessions. Fixes also resolve errors in non-interactive sessions when directories are deleted mid-session, and eliminate startup waits on managed settings requests when no plugins or MCP servers are configured.

FEATURE

Multi-agent loads JSON files and batch execution supports worktree hooks

Launching multiple agents via --agents now accepts a path to a JSON file and permits an empty prompt.

Running /batch works outside Git repositories as long as a WorktreeCreate hook provides agent worktrees. Synced skills from claude.ai display by their short names, and /deep-research improves reliability on long research briefs.

BUGFIX

Fixed Vim mode key actions and improved queued messages and pasted text

When using Vim mode in the terminal, fixes correct motion behaviors for dj, cw, 1G, and dot repeat inserts, preventing exclamation-mark text from mistakenly triggering shell mode.

Messages queued while Claude is working now display above the spinner and preserve IDE selections. Single-line pasted text is no longer split across unexpected lines, creating a smoother command-line input experience.

FEATURE

Improved agent panel hints and focus, and updated background progress row

In the multi-agent panel, footer key hints reflect custom keybindings without showing redundant switch prompts for the active agent.

Clicking an agent row updates the keyboard cursor, while pressing Esc deselects the highlighted row without interrupting running turns. The background workflow row below the prompt adds a progress bar, elapsed time, and token counts, making background task progress clear at a glance.

FEATURE

Improved workflow list layout and added confirmation before stopping reviews

Viewing workflows via /workflows leads each row with its status icon and elapsed time, preserving the run name and duration on narrow terminals.

Standardized double-press cancel across dialogs and protected rapid keystrokes

Opening dialogs such as /hooks, /mcp, or /memory in the terminal now closes the active dialog on a double press of Ctrl+C or Ctrl+D without exiting the application.

Burst keystrokes from remote input or window switching no longer trigger stale selections. Fixes also prevent pressing 1 from accidentally confirming directory deletions in /permissions and stop rapid Shift+Tab presses from landing on wrong permission modes.
