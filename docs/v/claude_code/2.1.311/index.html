Claude Code 2.1.311

發布日期：2026-10-26

繁體中文

新功能

自託管執行器支援保留閒置工作階段，遇唯讀倉儲限流自動略過啟動

你在自建伺服器上透過執行器跑自動化任務時，主機上常會還留著沒跑完的行程。

好比租用會議室開跨部門會議，以前只要投影機連線異常，整間會議室就直接被系統取消鎖死；現在會議室會先略過故障的投影機照常開門，若散會後還有討論小組在白板前整理紀錄，門禁也不會立刻熄燈鎖門。

如果你使用 self-hosted-runner 執行任務，現在新增了 --hold-idle-file 與 --max-hold-min 兩個參數。當你的主機回報有先前留下、仍在執行的行程時，閒置的工作階段（session，指一段持續連線的互動過程）會被保留下來。 另外，過去在啟動階段若新增的唯讀倉儲遭遇速率限制，例如收到 HTTP 429 錯誤或 Git 包裝程式以代碼 75 退出，整個工作階段會直接啟動失敗。現在自託管執行器會自動略過受限的唯讀倉儲，讓主工作階段順利開啟。

新功能

終端機輸入 ultrathink 啟用極高思考力度，支援運算中動態拉高

面對特別棘手的架構重構或演算法除錯，你可能會希望模型花費更多時間徹底深思。

就像開車上坡踩油門降檔，以前出發前設定巡航就不能改，遇到陡坡只能慢速爬；現在行進中踩踏板能立刻注入動力，儀表板增壓燈也只在真正出力時亮起。

在互動終端機輸入 ultrathink，就能讓 Anthropic API 上的 Opus 5.5、Sonnet 5.5、Haiku 5.5 與 Fable 5.1 模型，以極高力度（xhigh effort）深層思考。即使 Claude 已開始回答，中途輸入 ultrathink 也能拉高該輪剩餘運算的思考深度。 彩虹文字特效也同步調整。彩色效果只在該關鍵字確實能拉高思考力度的位置出現；若是在引號內或檔案路徑中提及，介面將保持正常文字顏色。

問題修復

思考力度提示快取未命中納入警告，用量清單完整揭露消耗

當你切換不同模型規劃工作或審查程式碼時，快取未命中可能在不知不覺中消耗寶貴額度。

如同水電帳單列出詳細明細，以前更換特殊家電造成的突發耗電全被隱藏，讓人摸不清額度花去哪裡；現在儀表會在切換不同規格設備時主動提示耗損，帳單也會印出大額開銷。

在計劃模式下調整思考力度時，若計劃模型與當前工作階段的模型不同，/effort 指令現在會主動提醒提示快取（把重複內容暫存起來直接使用）未命中，讓你評估額外成本。 /usage 指令也補上了顯示，過去遺漏的大型提示快取未命中現在會如實列出。執行 /code-review 時，Claude 會優先考慮思考力度，只在明確要求時使用最高等級。此外，模型名稱移除了無實質效果的 [1m] 後綴，但仍相容該舊寫法。

新功能

對話突破二十萬記號自動壓縮，讀取記憶與摘要確認機制完善

進行長篇對話或處理大型專案時，對話歷史累積過長容易觸發長度上限。

一如圖書館整理堆積如山的研究筆記，以前筆記寫滿固定頁數便直接拒絕翻頁，甚至還可能翻出已作廢的舊草稿；現在館員會主動將厚重資料裝訂濃縮後讓你繼續書寫，裝訂前還會重新檢查重點摘要有沒有確實寫上。

在標準情境工作階段中，單次請求若超過 20 萬個 token（AI 處理與計費的文字單位），以往工具會直接中斷並提示需要 1M 上下文點數。現在工具會主動壓縮對話歷史，替你整理脈絡後直接繼續執行，不再中途停擺。 這項自動壓縮機制也修正了檔案狀態讀取錯誤。如果工作階段稍早修改過 MEMORY.md 或 CLAUDE.md，先前在自動壓縮後模型會讀到未更新的舊版內容，這項問題已經修好。 此外，當模型產生的壓縮回覆遺漏了摘要內容時，工具會在替換現有對話前再次向模型索取摘要，確保對話紀錄順利延續。

問題修復

嚴格落實停用壓縮設定，回溯確認訊息修正為刪除後續紀錄

有些團隊因為審計要求或排錯需求，必須完整保留每一步的對話原始脈絡。

好比法院審訊紀錄必須逐字存檔，以前即便交代全程錄影，部分書記官仍會自作主張節錄大意；現在只要掛上禁令牌，所有成員與選單都嚴格禁止濃縮文字，調閱紀錄時也會清楚告知是將後續筆記抽除。

設定 DISABLE_COMPACT 環境變數時，代理隊友不再自動壓縮歷史紀錄。輸入 /rewind 呼叫回溯選單時，也不再提供「從此處摘要」或「摘要至此處」的選項。 設定檔與模組環境中的 DISABLE_COMPACT 現在只能關閉壓縮，不能反向重新開啟。執行 /rewind 時，確認畫面已修正為告知後續訊息會被移除，而非誤稱對話將被分叉；警告訊息也更正了手動與 Bash 編輯絕不受程式碼還原影響的說法。

問題修復

子代理支援動態連線外部工具，修復重複觸發掛鉤與資源清除

讓主代理拆分子任務到背景平行執行時，背景代理往往需要獨立的目錄與工具支援。

宛如派遣專案小組到獨立會議室作業，以前只要協調人提早離席，會議室白板就會被清空，門口打卡鐘每分鐘還狂響兩次；現在支援工具稍晚送達也能順利接收，小組未完工前會議室絕不提前清空。

子代理啟動後，若遇到連線較慢的 MCP（Model Context Protocol，讓 AI 連接外部工具的協定）伺服器，連線完成後已能正常使用其工具。 子代理使用的隔離工作樹（worktree，Git 讓同一專案平行開多份副本的功能），不再於背景子代理仍在工作時被提早刪除。SubagentStop 掛鉤（特定事件發生時被觸發的小程式）改為結束時才觸發一次，不再每分鐘重複兩次。背景代理等待終端機喚醒時不再誤開新輪次；雲端或背景工作階段重啟時，已完成的技能也不再重複執行。

問題修復

代理團隊恢復保留任務清單，輸入快捷鍵對齊離開行為

使用多代理團隊協同作業時，中斷後重新連線往往依賴系統完整保留待辦事項。

跟專案團隊在白板前排程一樣，以前午休回辦公室重新召集時，白板上的待辦工作便條全被擦拭一空，甚至還把新分支的進度貼回舊看板；現在重新進場白板依然完整，交談時也不會重複遞交相同的便條。

在代理團隊工作階段中，使用 --resume、--continue、/resume 或 --session-id 重新連線，或是 /clear 與當機重啟後，工作清單不再被清空。執行 /branch 分支時，也不再誤把進度寫入原始工作階段的清單。 在個別代理交談分頁中，若有訊息等待發送，按方向鍵 ↑ 改為正常的歷史紀錄呼叫，不再重複送出訊息。在代理檢視畫面中，輸入框為空時連按兩次 Ctrl+D 即可退出，與主要提示列行為一致。

新功能

遠端控制連線阻擋即時回報，雲端協作工具重啟不遺失

當你人在外面透過手機或遠端終端機連回電腦工作時，連線穩定度與訊息歸屬至關重要。

猶如利用衛星電話遠端指揮基地營運作，以前遇到中繼線路阻擋時訊號會卡在連線中無聲乾等數分鐘，助理代發的公文還會被蓋上你本人的私章；現在線路受阻會立刻回報，附件超量或磁碟已滿也會說明原因，重啟系統後裝備依然完好。

遠端控制若被網路 Proxy 阻擋，不再卡在 Connecting 兩分鐘。手機版中 Claude 發給雲端或遠端工作階段的訊息，不再誤標為你發送。 附件因磁碟滿或超過 20 個被略過時會提示原因。Cowork 雲端工作階段抓取與搜尋卡住改為 300 秒逾時；重啟不再因指定 agent 遺失工具。使用 /teleport 或 claude --teleport 載入已壓縮工作階段時，會提示本地不含摘要前訊息。

新功能

背景守護服務支援排程崩潰重啟，指引與重生指令精準回報

把繁重任務丟給背景服務處理時，最怕背景行程突然無聲無息終止。

就像大樓夜班巡邏系統異常，以前中控台建議按下的開關是早已拆除的舊按鈕，即使查無紀錄仍先盲目啟動發電機；現在設有定時巡邏的異常中斷會自動重啟，系統也會給出明確的重新接班指引。

背景工作階段處於釘選、連線中，或設有排程任務與喚醒時，若在輪次間崩潰，現在會自動重啟。 背景服務無回應時，錯誤提示改為建議執行 claude daemon stop --any 並說明會終止所有背景工作階段，不再建議已停用的指令。執行 claude respawn <id> 時，會先檢查該識別碼是否存在，避免找不到工作階段卻白白啟動背景服務。 背景行程結束時的訊息不再給予無法兌現的重啟承諾，並說明如何恢復工作階段。從支援超連結的終端機開啟背景工作階段時，狀態列（顯示在終端機最底下的狀態列）連結現在能正常點擊。

問題修復

MCP 專案路徑精確對應，清除認證與遠端狀態顯示修復

管理各專案外接的自訂工具時，設定檔存放路徑與連線狀態標示若失準會增加除錯負擔。

好比辦公大樓的訪客門禁系統，以前在分部登記設備時系統會把子隔間誤當成獨立公司，免換證的會議室在重設門禁卡後還被誤亮紅燈；現在設定路徑皆正確溯源至所屬專案，通行證核發狀態也如實標示。

在倉儲子目錄執行 claude mcp add、claude mcp remove 或 /mcp 時，設定會對應到 ~/.claude.json 中的專案項目，不再誤指向當前子目錄。 claude mcp list 與 claude mcp get 連線失敗時不再重複印出錯誤碼。在 /mcp 中，免登入的遠端 MCP（讓 AI 連接外部工具的協定）伺服器清除認證後不再誤報失敗；未發送憑證的遠端伺服器也不再誤報已通過認證。

問題修復

中斷指令遇下載即時生效，外掛目錄識別與技能快取優化

請模型抓取外部資料或載入擴充外掛時，反應停頓或目錄誤判會打亂開發節奏。

一如圖書館借閱多冊參考書，以前只要其中一本在運送中，按下取消借閱就必須等到運送逾時才能離開櫃檯，把整箱書籍歸還時還會被當成同一冊登記；現在取消操作能即刻停止等待，十分鐘內查過的書單也能直接調閱。

當外部工具伺服器未回應資源讀取或技能仍在下載時，按下中斷鍵現在會即時生效，不再等到連線逾時。 使用 --plugin-dir 指定包含多個外掛的資料夾時，若頂層含有空的 .mcp.json，不再誤載為單一外掛。此外，設定 CLAUDE_CODE_SYNC_SKILLS 且未啟用功能旗標抓取的工作階段，現在會直接重複使用本機其他工作階段在 10 分鐘內取得的 claude.ai 技能清單，省去頻繁重新查詢的時間。

問題修復

檔案巨量改動不再停頓虛報，超長清單與比對預覽修復

當專案中的設定規格繁複或單次修改涉及數千行時，檔案編輯工具的渲染效率直接影響操作流暢度。

如同文字編輯器校對超長卷軸，以前遇到連續排版的長條目整台機器就會卡死數秒，一次替換上千處文字後統計甚至荒謬地顯示為零；現在翻閱寬版卷軸不會算錯行數，沒有文字異動時也不會突然彈出比對視窗。

在單一檔案中修改數千行時，Write 與 Edit 工具不再卡頓長達 5 秒或誤報變更了 0 行。CLAUDE.md 含有極長清單條目時，啟動與讀寫檔案後的長時間凍結問題已修復。 Write 工具在預覽寬度超出終端機的行時，不再跳行與算錯隱藏行數。在全螢幕寬終端機中，編輯後若無內容需要比對，比對面板不再自動彈出。

問題修復

Shell 指令逾時保留部分輸出，沙盒衝突與環境描述修正

在命令列執行耗時的建置工作或背景腳本時，指令的執行狀態與權限邊界是判斷進度的依據。

宛如在安全防護室內操作長耗時機具，以前只要計時器一響，工作台上的半成品就會整盤收走不留紀錄，門口的警報器每天上班還對著老員工複誦同一套守則；現在時間到了會保留已加工的零件，防護室路徑重疊時也不會卡死。

Shell 指令達到逾時上限時，結果會保留顯示迄今的輸出，並說明命令仍在背景執行。 Linux 下當 --plugin-dir 同時為加入的目錄且開啟阻擋讀取工作目錄外部檔案時，沙盒工具 bwrap 無法建立檔案的錯誤已解決。Bash 工具描述不再聲稱工作目錄在呼叫間永久保留，環境區塊不再標註未執行的 Shell（例如用 zsh 卻標出 fish）。設定檔權限規則警告改為每位使用者只顯示一次，直到規則變更。

新功能

產物支援依錨點路由多重視圖，智能劃分頁面與文件型態

請 Claude 製作互動展示或撰寫長篇報告時，產物的呈現形式直接影響閱讀與分享體驗。

比照設計公司交付專案成品，以前不管是互動原型還是正式合約，全用同一種資料夾交付，切換章節時網址標籤也不會跳轉；現在互動圖表會被製作成可點擊操作的展示網頁，長文文字則整理成方便傳閱修訂的文件。

產物工具改進了成果型態的判斷邏輯。當你需要解說性文字、視覺圖表或具備按鈕等互動功能的作品時，Claude 會將其生成為獨立的產物頁面（page）。如果是適合團隊持續修訂、日常傳閱的純文字內容，則會建立為產物文件（document）。 如果單一產物中設計了多個切換視圖，現在系統會根據連結末端的 #name 錨點來精確路由至對應畫面。 這項視圖切換機制也修正了解釋說法。過去 Claude 在引導讀者切換不同檢視畫面時，會誤稱瀏覽器網址列保持不變，現在這段說明已更新為正確的路由行為。

問題修復

修正編輯器外掛虛假安裝提示，螢幕報讀回饋與問題清單簡化

使用輔助工具或命令列設定開發環境時，操作狀態的真實反饋是避免誤判的前提。

猶如到服務櫃檯申請設備與無障礙語音導覽，以前安裝手續還在轉圈或中途失敗，系統就直接亮綠燈宣稱安裝成功，語音廣播裡甚至充斥著視覺用的箭頭符號；現在安裝失敗會如實回報，語音模式下取消的表單也不會被櫃檯誤收。

在 /ide 安裝擴充套件時，不再於 VS Code 尚未裝完或失敗時回報已安裝，JetBrains 未安裝時也不再誤報成功。 螢幕報讀模式下，審查計劃時若按 Esc 放棄輸入回饋，不再誤送取消的文字。在 /permissions 刪除規則時，語音會即時提示已刪除允許規則。向使用者提問時，問題清單改為簡潔文字呈現，去除箭頭與符號。

新功能

訂閱受限精準指引帳單設定，快取網路驗證加速工具啟動

每天頻繁啟動命令列工具時，每次開啟等待數秒的網路驗證會累積出明顯的時間成本。

跟持會員卡走進商務中心一樣，以前只要距離上次進門不到一小時，閘門仍要連上遠端主機反覆核對兩次身分，扣款卡關時櫃檯還叫個人會員去問根本不存在的公司主管；現在短時間內出入能快速通關，通行碼失效時也會提醒重抽號碼牌。

Pro 與 Max 帳號在距上次檢查一小時內啟動，會自動跳過兩次網路請求以加速啟動。僅帶有選項與參數值的啟動（例如 claude --model opus）流程也經過優化。 Pro 與 Max 用戶無法使用訂閱時，提示訊息改為引導至帳單設定，不再誤叫用戶詢問管理員。貼上的登入碼被拒絕時，提示文字現在會說明代碼可能已過期或已使用，並提示重新登入。

新功能

雲端平台深層思考防閒置中斷，遵循不重試標記避免卡住

On Google Vertex AI, Microsoft Foundry, and AWS platforms, endpoints send thinking progress updates, so they are no longer misjudged as idle and cut off. Requests are no longer retried when the API marks them not to retry, preventing conversations from stalling or retrying indefinitely. When the Anthropic API connection drops, the error first suggests checking the proxy or gateway, followed by the VPN or firewall. Bedrock, Mantle, Vertex, and Foundry now load model settings from an official signed file, which can be disabled by setting CLAUDE_CODE_MODEL_CATALOG=off.

BUGFIX

Lost Backslashes and Pasted Image Paths Fixed, File Picker Supports Negation Rules

When typing commands, pasting text, or selecting files in the terminal, having characters swallowed by the interface interrupts your train of thought.

Organizing a manual on a typewriter used to mean that pasting an image path caused the typewriter to impulsively clip the text and paste a photograph, print brackets while omitting backslashes, or even fail to locate files noted as exceptions in the index; now original text is preserved intact, and misclicks on a scrollbar can be cancelled simply by moving away.

A lone backslash inside quotes or brackets, like "\" or (\), no longer disappears from replies. When pasting text containing an image path, such as ! open /tmp/shot.png, it no longer mistakenly attaches the image and drops the path text. When typing @ to select files, negation rules in .ignore and .rgignore are now supported, correctly selecting re-included files. While the prompt contains text, the feedback draft card no longer displays shortcut keys to prevent key conflicts. Clicks on scrollbars in fullscreen lists now trigger only upon releasing the mouse button, allowing you to cancel by moving away.

SDK Transcripts Preserved in Order, JSON Control Character Escaping and Post Checks

When connecting automation scripts or integrating messaging software, data format rigor determines whether downstream services can parse correctly.

Handling mail dispatch in a registry office, special seal stamps used to cause errors during system filing, and automated messengers forwarding documents frequently ignored notices posted right at the doorway; now special characters are escaped and packaged using standard codes, and the recipient's intake guidelines are reviewed before delivery.

Issues where claude -p and SDK sessions saved transcript messages out of order or retained retracted messages have been resolved. Before messaging an unnamed Slack channel, Claude now checks that channel's topic for posting rules. In addition, the explanation for claude purge clarifies that it deletes data only on this machine, without affecting anything stored by Anthropic.

When scheduling automated tasks in a cloud-hosted environment, organizational member turnover should not permanently lock automated workflows.

FEATURE

[Code Review] Automatic retry on transient server faults, clear closure when retries fail

When relying on automated review bots during pull requests, occasional cloud connection hiccups can stall the inspection process.

Submitting assignments through an online portal, brief network drops previously led the system to immediately register a failed submission, leaving students uncertain whether to keep waiting or retry manually; now line faults trigger one automatic reconnect with clear status updates, and a failure to parse the material triggers a definitive notice to stop waiting.

Code review sessions that fail to start due to transient server faults are now retried once automatically, and the check run clearly indicates that a retry is in progress. If the model still cannot analyze a change during the automatic retry, the check run explicitly states that no further automatic review will start, preventing teams from waiting indefinitely without updates.
