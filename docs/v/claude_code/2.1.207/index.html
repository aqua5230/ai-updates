Claude Code 2.1.207

發布日期：2026-07-11

繁體中文

終端機不再卡頓，長回覆畫面不亂跳

現在你看 Claude 吐出落落長的表格或程式碼時，打字和捲動都會滑順無比。以前只要遇到超長的清單或段落串流（streaming，答案一邊生成一邊逐字顯示），終端機畫面就會卡住，而且等它講完還會莫名其妙往上跳回開頭；現在這些顯示問題都修好了。就像看新聞台底下的跑馬燈，以前字太多會卡住甚至整條重播，現在不管塞多少字都順順跑過。

自動模式全面開放，設定不再跟著專案跑

想放手讓系統自己做事，自動模式（auto mode，讓 Claude 不逐一問你就自己執行的模式）本來就有，但現在於 Bedrock、Vertex AI 與 Foundry（企業透過 AWS 或 Google Cloud 等雲端服務租用 Claude 的通道）上預設就能用了。以前你要先手動設定環境變數（開程式之前預先塞給它的隱藏開關，一般使用者看不到）才會開放。同時，這項開關現在只讀跟著你這個人、每個專案都適用的全域設定檔，不再去讀跟著資料夾走、別人給你的專案裡可能藏著一份的專案內設定，避免你換個專案就不小心被打開。就像巡邏機器人本來就會巡邏，只是現在出廠預設就打開這功能，而且它只聽你手上的總遙控器，不會因為走到不同倉庫就自己切換模式。

AWS 平台連線變快、升級模型，Windows 不再死當

用 Bedrock、Vertex 或 AWS 上 Claude 平台的人，系統現在預設會幫你掛上最新的 Opus 4.8 模型，而且也不會像以前那樣，每講一句話就跑去向 IAM Identity Center 要一次新憑證（credentials，證明你是合法使用者的金鑰），速度快多了。對 Windows 使用者來說，如果 AWS 憑證卡住（例如背後處理程序當掉），系統現在最多等你 60 秒就會自己中斷，不會整個程式死當在那裡。就像進遊樂園玩，以前每玩一項設施都要重新查驗一次身分證，而且驗票機當機你只能站著枯等；現在買一次票就能玩到底，驗票機卡住一分鐘就會有人來放行。

任務列表與深研功能更好讀，不卡畫面也不忘記名字

查看代理的任務清單時，介面變得聰明很多。現在你重複貼上同一段文字，它只會把原本摺疊的佔位符展開，不會刷兩筆紀錄佔空間；卡住等你的任務，會直接秀出卡在哪個問題跟「等了 3 分鐘」，不會只印兩次死板的時間戳。深研（Deep research，讓 Claude 大量爬網找資料的功能）也會明確印出它正在查哪個網站的網域，不再一律顯示「未知」。還有，背景任務不會再忘記自己因為計畫而取的名字，重開進過工作樹（worktree，讓同一個專案多開幾份平行工作副本的 Git 功能）的任務也不會一片空白了。就像醫院的掛號看板，不再只顯示冰冷的「未知病人」與時間代碼，而是會告訴你「王大明，在 3 號房，已等候 5 分鐘」，清楚明瞭。

遠端遙控更穩固，代理團隊不怕收到毒信件

讓多隻 Claude 互相合作的代理團隊現在更強韌了。以前只要團隊信箱（mailbox，代理們互相傳話的檔案）裡混進一則格式錯誤的壞訊息，整個團隊就會陷入無限崩潰的迴圈，每秒報錯直到你手動刪檔；現在它們懂得出錯時直接忽略並繼續工作。而針對遠端遙控，網路斷線或是憑證（證明你是合法使用者的金鑰）更新重連後不再漏接任務進度，你在手機跟網頁版上也能正常看見桌機版 App 跑的背景任務與工作流進度了。就像一間辦公室，以前收到一封亂碼傳真全公司就停擺，現在會把它扔進垃圾桶繼續辦公；出差在外的主管，也能順暢看到辦公室裡的進度白板。

補上外掛設定的破口，防範惡意指令偷塞

這次收緊了外掛（plugin，擴充 Claude 功能的附加元件）的安全鎖。以前外掛設定如果放在專案資料夾裡，心懷不軌的專案就能利用環境變數的寫法，偷偷把惡意指令混進你的終端機裡（這叫 shell injection 攻擊）；現在直接禁掉這種寫法，並且不再讀取專案層級的外掛設定，只讀取個人設定、--settings 參數以及 managed settings。此外，在非互動模式（non-interactive run，像 SDK 那樣不跳提示直接跑的模式）下，也不會再跳過安全授權對話框，把你偷偷標記成「已同意」。就像公司的門禁系統，以前會不小心讀到訪客自己印的假識別證，或者讓走後門的人免簽名就混進來；現在只認總公司發的卡，而且所有人一律得過警衛這關。

清除 Git 殘留垃圾，指令權限不再大驚小怪

你混用其他 Git 工具時，不會再被 Claude Code 留下的殘留設定卡住了。以前當你把工作樹（worktree，讓同一個專案多開幾份平行工作副本的 Git 功能）全砍光時，Git 設定檔裡會殘留一行設定，導致其他第三方 Git 工具讀不懂而卡死；現在它懂事後會順手清乾淨。另外，在讀取忽略檔（告訴系統別管哪些檔案的名單）或路徑規則時遇到括號打錯，或者只是要把多餘的輸出丟進虛無的 /dev/null，系統以前會嚇得停止運作或是大動作問你權限，現在它變聰明了，能正確分辨這些無害的動作。就像搬家公司以前撤走後會在牆上留下殘膠害下一個房客裝潢失敗，或者看到你把垃圾丟進垃圾桶還要跳出來問「確定要丟嗎」，現在他們搬得一塵不染，也不會管你怎麼丟垃圾。

儲值不怕輸錯錢，更新也不再覆蓋你的自訂捷徑

這次修復了幾個常讓你嚇一跳的系統行為。儲值額度時如果手滑貼上時間戳（timestamp，像 2026-07-13 這種日期時間字串），系統以前會不聲不響剝掉非數字的部分、把剩下的數字整串黏成金額——貼個日期可能瞬間變成兩千多萬的天價；現在會直接報錯擋下，而且一次買超過一千美金會要求你多打字確認，避免荷包大失血。如果你為了方便自己改過啟動 Claude 的捷徑檔，自動更新也不會再粗暴地把它蓋掉。同時，系統內部正常的更新對話，不會再被防火牆誤判為你在進行 prompt injection（提示詞注入攻擊，把惡意指令藏進對話騙 AI 亂做事的手法）了。就像你去提款機，亂按密碼不會再隨便吐錢出來，而且銀行升級軟體時不再把你自訂的快速鍵洗掉，防盜警鈴也不會因為銀行員自己補鈔票而亂響。

English

Terminal stops lagging and transcripts stop jumping on long responses

When Claude spits out massive tables or code blocks, typing and scrolling will now stay buttery smooth. Previously, streaming (responses appearing word by word as they generate) very long lists or paragraphs would freeze the terminal, and when the answer finished, the screen would inexplicably jump back to the top; these display glitches are now fixed. Like a news ticker at the bottom of a TV screen — it used to stutter or reset when the headline was too long, but now it scrolls steadily no matter how much text you feed it.

Auto mode is open to all platforms, and its settings no longer roam with the project

Auto mode (the mode where Claude acts without asking you step by step) has always been there, but now it's available by default on Bedrock, Vertex AI, and Foundry (channels where enterprises rent Claude through cloud services like AWS or Google Cloud). Previously, you had to manually set an environment variable (a hidden switch stuffed into the program before it opens, which regular users never see) to enable it. Meanwhile, this toggle now only reads from the global settings file that follows you across all projects, and no longer reads from project-level settings that follow the folder (where someone else's project might hide a copy), ensuring the mode doesn't accidentally turn on just because you switched repositories. It's like a security robot that always knew how to patrol, but now comes with the feature enabled out of the box, and takes orders solely from your master remote, refusing to change behaviors just because it walked into a different warehouse.

AWS connections speed up, models upgrade, and Windows stops hanging forever

For people using Bedrock, Vertex, or the Claude Platform on AWS, the system now defaults to the latest Opus 4.8 model, and it no longer frantically begs IAM Identity Center for fresh credentials (the keys proving you're a valid user) on every single API request, speeding things up significantly. For Windows users, if AWS credential fetching stalls (like a stuck background process), the app now bails out after 60 seconds instead of hanging indefinitely. It's like visiting a theme park: you used to have to show your ID at every single ride, and if the scanner broke, you just stood there forever; now one ticket covers the whole park, and if a scanner hangs for a minute, a worker waves you through.

Agent views and Deep Research are much more readable, skipping blank screens and forgotten names

The agent task list is a lot smarter about what it shows you. Pasting the exact same text a second time now just expands the existing folded placeholder instead of printing a redundant duplicate; tasks blocked waiting for you now prioritize the question holding them up and display a friendly "waiting 3m" clock instead of two robotic timestamps. Deep research (the feature where Claude heavily crawls the web for information) also now explicitly badges which website hostname it is reading, instead of tagging everything "unknown". Furthermore, background sessions won't forget the name they got from a plan, and reopening sessions that entered a git worktree (a Git feature that gives one project several parallel working copies) will no longer pop up completely blank. Like a hospital waiting room display upgrading from cryptic "Patient Unknown, 14:00" codes to "John Doe, Room 3, waiting 5 mins," making everything instantly readable.

Remote Control stays solid, and agent teams survive toxic messages

Agent teams that collaborate on tasks are much more robust. Previously, a single malformed message ending up in a teammate's mailbox (the file agents use to pass notes to each other) would throw the entire team into a catastrophic crash loop, tossing an error every second until you manually deleted the file; they now know how to shrug it off and keep working. For Remote Control users, task status updates no longer drop into the void when your network hiccups or your credentials (the keys proving you're a valid user) refresh, and mobile/web clients now correctly mirror the background agent and workflow progress hosted on your desktop app. It's like a bustling office that used to freeze completely if it received a single unreadable fax — now they just toss it in the bin and keep working, while the boss traveling abroad can still perfectly see the progress whiteboard back at headquarters.

Plugin settings are battened down to stop sneaky injections and auto-consents

We've battened down the security hatches for plugins (add-ons that extend Claude's capabilities). Previously, if plugin configs lived in a project folder, a malicious repository could use variable syntax to sneak nasty commands straight into your terminal (a shell injection attack); this syntax is now completely rejected, and plugin settings are no longer read from project-level files at all, only user, --settings, and managed settings are honored. Furthermore, non-interactive runs (like SDKs that run without prompting the user) will no longer silently record you as "consented" to security policies without actually showing you the dialog. Like a corporate security gate that used to occasionally accept a visitor's home-printed badge or let back-door VIPs bypass the sign-in sheet; now it strictly honors only HQ-issued cards, and everyone signs the book.

Clearing out Git residue and stopping oversensitive command prompts

Your other Git tools and everyday commands no longer trip over a setting Claude Code left behind. When you completely removed your last worktree (a Git feature that gives one project several parallel working copies), a stray line of configuration used to be left behind in your Git config, breaking other third-party Git tools; it now sweeps up after itself. Also, when parsing malformed brackets in ignore files (lists telling the system which files to skip) or path rules, or dealing with commands that just harmlessly piped output into the /dev/null void, the system used to panic, break file reads, or stop everything to ask for permission. Now it accurately assesses these safe scenarios. Like a moving crew that used to leave glue residue on the walls ruining the next tenant's paint job, or a security guard who jumped out to ask for ID just because you tossed a crumpled napkin into the trash can — they now leave the place spotless and let you throw away garbage in peace.

Safe top-ups, preserved custom launchers, and no more false alarms

A few startling system behaviors have been smoothed out. If you accidentally pasted a timestamp while topping up your credits, the system used to blindly strip it down to digits and charge some random amount; it now halts with an error, and any amount over $1,000 requires you to explicitly type a confirmation to save your wallet from a catastrophic slip. If you customized the launcher script that opens Claude, the auto-updater will stop rudely overwriting it on every release. Also, totally normal internal system chat updates will no longer falsely trigger the "prompt injection attack" alarms. It's like going to an ATM: mashing the keypad won't randomly withdraw a weird amount of cash, the bank's software update won't erase the custom PIN shortcuts you set up, and the burglar alarm stops screaming every time a bank teller legitimately refills the money tray.
