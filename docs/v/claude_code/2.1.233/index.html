GitLab 合併請求可直接開工作樹

同事丟來 GitLab 的合併請求網址時，現在可把網址交給 --worktree，也能在 claude agents 檢視裡直接辨認它。工作樹（worktree，Git 為同一專案開出的平行副本）讓你另開一份地方查看修改，不必離開手邊工作。⟦這像收到一張待辦房間的門牌；網址一貼，便能走進另一間房核對內容，而非先手抄房號。⟧ 合併請求會顯示成 !N，因此清單裡能看出它是 GitLab 的項目。

閘道可把使用者身分交給後端記帳

公司透過 apps gateway 連到 Anthropic 上游服務，又想知道費用算在誰身上時，可選擇開啟 forward_user_identity。這個設定會把已登入使用者的身分放進 headers（隨請求附上的資訊欄位）。再交給閘道後方代替你轉送請求的 proxy。⟦像包裹經過收發室時附上寄件人卡片，後方的記帳人便能把運費記到對的人名下。⟧ 此設定是選用項目；不開啟便不會轉送這份身分資訊。

Linux Bash 可替失控建置設記憶體上限

在 Linux 用 Bash 工具跑建置，若擔心失控的建置拖住工作階段，可選擇設定 CLAUDE_CODE_TOOL_MEMORY_LIMIT。它會替 Bash 指令啟用 memory cgroup（替一組程式設下記憶體界線的 Linux 機制）。⟦像共用儲物間替一台攪拌機劃出固定容量；它的材料塞滿自己的格子後，不能再占用整間空間，其他人的東西仍放得下。⟧ 這是選用支援，目的是避免失控的建置讓整個工作階段停住。

WebFetch 網址快取保存時間可自行設定

同一個 WebFetch 工作階段裡，想調整網址快取保存多久，現在可設定環境變數 CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS。快取（cache，把查過的結果暫存起來直接用）會在工作階段內保存網址查詢結果；這個變數專門調整它的存活時間。⟦像替已查過的電話簿頁面貼上有效期限標籤，到期前可直接翻那頁，到期後才重新查號。⟧ 預設值仍是 15 分鐘，沒有因這項設定而改變。

雲端關機等權限時，不再誤報遺失工作階段

Claude 正等你回應權限提示，雲端環境卻在此時關閉，先前偶爾會把雲端工作階段標成遺失。這次修正針對的正是「等待權限」與「環境關閉」同時發生的情況，也不把環境關閉誤當成工作階段遺失的錯誤依據。⟦如同櫃檯正等你簽名，辦公室卻先熄燈；現在不會因此把你的案件判成不見了。⟧ 之後遇到這種順序，工作階段不會再被錯誤標記為 lost。

MCP 長連線遇逾時不再反覆重開

使用會在固定時間結束長連線的 serverless 主機時，MCP v2 連線先前可能不停重開 subscriptions/listen 串流。MCP（Model Context Protocol，讓 AI 連接外部工具的協定）透過這條串流接收訂閱資訊。⟦像對講機的通話被建築物規則切斷後，舊作法會不斷重撥同一通；現在不再陷入反覆接通又斷線。⟧ 因此，面對會終止長持連線的伺服器，連線不會無止盡重啟。

桌面版與 VS Code 的權限提示會觸發通知掛鉤

你在 Claude Desktop 或 VS Code 裡等權限提示，若設了 Notification hook，先前它可能沒有反應。Notification hook（通知掛鉤，特定事件發生時被觸發的小程式）原本應在需要權限時告訴你。⟦像門鈴已接好線，訪客按了卻不響；現在有人要求進門時，鈴聲會跟著響起。⟧ 這項修正只針對兩個指定環境中的權限提示，讓掛鉤能正常觸發。

Linux 閒置沙盒不再佔滿單一 CPU 核心

Linux 上開著沙盒卻沒有操作時，先前有些閒置工作階段仍會讓一個 CPU 核心維持 100% 使用率。沙盒（sandbox，隔開程式可碰範圍的受限環境）本應在你沒動作時安靜待著，而非持續消耗處理器。⟦像空無一人的房間裡，風扇卻一直全速轉；現在沒人使用時，不會白白耗住那一台風扇。⟧ 修正後，啟用沙盒的閒置工作階段不再出現這個單核心滿載問題。

同名技能遮住內建指令時，別名仍可使用

你在 -p 模式執行，或載入 plugins、MCP 後輸入 /checkup、/review，若使用者或專案技能恰好同名，先前可能看到「Unknown command」。技能（skill，教 Claude 完成特定工作的說明組）名稱相撞時，不該讓內建別名失效。⟦像社區裡新開一家同名店，舊店的招牌卻被整塊蓋住；現在兩個既有別名仍找得到入口。⟧ 這次修正涵蓋 -p，以及 plugins 或 MCP 已載入的情況。

指令參數不會再被當成模板標記重算

技能或指令收到參數後，先前參數內容可能再被展開成 template markers（模板標記，會被程式替換的特殊符號）。這會把原本只是輸入值的文字，再當成另一輪要處理的指示，改變原有輸入的意思。⟦好比表單收件員已把你寫的姓名放進欄位，卻又把姓名當成填表規則重新解讀。⟧ 現在參數代入一次後便保留其值，不會被再次展開成模板標記。

Windows 特殊路徑不能繞過網路路徑檢查

Windows 路徑若用 NT 的 \??\ device prefix 拼寫，先前可能繞過 UNC 路徑驗證，留下 NTLM 憑證外洩風險。UNC 路徑驗證（檢查網路共享位置寫法的安全檢查）原本就該攔住這類路徑。⟦像大樓正門的證件檢查做得完整，卻有一扇寫法不同的側門沒被納入；現在側門也進了同一道檢查。⟧ 這項修正關閉的是透過該特殊前綴造成的 NTLM credential-leak 漏洞。

自架執行器啟動時不再改寫工作樹

啟動 claude self-hosted-runner 時，現在會先建立工作階段分支，且不必改寫工作樹。工作階段（session，一次持續工作的連線與狀態）一開始少了會擋住 agent 啟動的兩次伺服器往返。⟦像劇團開演前先在後台把分場表放好，不必把整個舞台重新布置完才准演員上場。⟧ 因此，這個 runner 的工作階段啟動時間獲得改善，agent 不再被那兩次往返阻住。

閘道轉送上游錯誤原文，方便看懂問題

apps gateway 接到 Vertex、Foundry 或 AWS 上 Claude Platform 回傳的 400 或 413 錯誤時，現在會帶出上游服務自己的錯誤訊息。上游（upstream，請求原本要送往的服務端）說明能讓你看到它實際拒絕的理由。⟦像客服把倉庫退貨單的原話交給你，而非只說「出問題了」，你才知道該改哪一項。⟧

apps gateway 的自動壓縮錯誤已修正

使用 apps gateway 的 auto-compact 時，這項錯誤已修正。auto-compact（自動壓縮，將較早對話整理得更短以騰出內容空間）是 gateway 替工作階段整理內容的流程。⟦像整理員把塞滿的資料夾換成精簡摘要，原本卡住的整理步驟現在能完成。⟧ 因此，透過 apps gateway 進行自動壓縮時，不再受這項錯誤影響。

外掛驗證可找出技能說明檔格式錯誤

準備檢查 plugin 時，claude plugin validate 現在會查看單獨存在的 .claude/skills 資料夾。它會回報其中 frontmatter（檔案開頭給工具讀取的欄位）無法解析的 SKILL.md。⟦像出版前先翻開資料夾裡每本說明書的扉頁，哪本的基本資料讀不出來，便直接標給你。⟧ 即使 .claude/skills 是裸資料夾而非完整結構，驗證也會納入檢查。

螢幕閱讀器可用數字選擇努力程度

使用螢幕閱讀器調整 /effort 時，選擇器現在會呈現成編號清單，並要求輸入對應數字。螢幕閱讀器（screen reader，把畫面內容讀出聲的輔助工具）需要能循序讀懂每個操作選項與目前選擇。⟦像語音點餐不必在看不見的按鈕間猜位置，只要聽完菜單後說出菜號。⟧ 此外，提示文字和對話框文字不再被裁切，讀到的內容能完整保留。

列印模式會提示未認得的模型 ID

用 print mode 送出 Claude Code 不認得的 model ID 時，現在 stderr（標準錯誤輸出，程式用來報告問題的文字通道）會寫出 [claude-code:unrecognized_model]。這條診斷訊息告訴你請求確實帶了未識別的模型 ID。⟦像寄件櫃檯在收據蓋上「地址查無」章，而非讓包裹悄悄進入未知路線。⟧ 若想不再看到它，可用 modelOverrides 將該模型 ID 對應到已知模型。

非 GitHub 儲存庫不再收到錯誤的 App 設定提醒

你的儲存庫 origin remote 在 gitlab.com 或 bitbucket.org 時，GitHub app 設定提示不再冒出來。origin remote（儲存庫連向遠端來源的位置）既不是 GitHub，就不該叫你設定 GitHub app。⟦像火車站不會把前往另一座城市的旅客帶到錯誤月台；現在目的地不是 GitHub，便不發那張車票。⟧ 同時，enterprise marketplace 提示會涵蓋不是 GitHub 的內部 Git 主機。

較新模型預設不用待辦工具，仍可用環境變數取回

使用 Opus 4.8、Sonnet 5、Fable 5、Mythos 5 或更高版本模型時，TaskCreate、TaskGet、TaskUpdate、TaskList、TodoWrite 這些待辦與任務追蹤工具不再提供。這是既有工具可用範圍的變更，不是新增工具。⟦像工具箱換了新版內裝，這批型號先把待辦抽屜收起；需要的人仍可把抽屜裝回。⟧ 要恢復它們，設定環境變數 CLAUDE_CODE_ENABLE_TODO_TOOLS=1。

Windows Bash 權限調整收回過寬規則

Windows 的 auto mode 對一般 cd <dir> && <command> > file Bash 指令反覆停下要求手動核准，這個 2.1.232 回歸問題已修正。同時，2.1.232 對 Cygwin 風格符號連結與輸入重新導向 < file 的 Bash 權限改動被撤回。⟦像門禁先把普通的進出與兩種指定通道都攔下；現在普通路線恢復通行，而過寬的兩條規則先收回，等待較精準版本。⟧ 較窄的版本會在後續版本回來。

Open a worktree straight from a GitLab merge request

When a teammate sends a GitLab merge-request URL, you can now give that URL to --worktree and recognize it in the claude agents view. A worktree is a parallel copy of a Git project, so you can inspect changes somewhere separate from current work. ⟦It is like receiving a room number on a work order: paste the address and walk into that room, rather than copying its number first.⟧ Merge requests appear as !N, making their GitLab identity visible in the list.

Gateway can pass user identity to proxy accounting

If your company connects to Anthropic upstreams through an apps gateway and needs to assign spending to people, it can opt into forward_user_identity. This setting puts the signed-in user's identity into request headers for a proxy behind the gateway. ⟦It is like attaching a sender card to a parcel at the mailroom, so the accountant down the line can charge delivery to the right person.⟧ Leave it off and that identity is not forwarded.

Linux Bash can cap memory for a runaway build

When a build runs through the Bash tool on Linux, you can opt into CLAUDE_CODE_TOOL_MEMORY_LIMIT if a runaway build might stall the session. It enables a memory cgroup, Linux's boundary for the memory available to a group of programs. ⟦It is like giving one mixer a fixed storage compartment: once its ingredients fill that compartment, they cannot take over the whole storeroom, and everyone else's things still fit.⟧ The optional limit keeps a runaway build from stalling the session.

Set WebFetch URL cache lifetime yourself

Within one WebFetch session, you can now set CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS to choose how long its URL cache lasts. A cache keeps a URL lookup result for direct reuse during the session; this variable controls that lifetime. ⟦It is like putting an expiry label on a phone-book page you already checked: use that page until it expires, then look up the number again.⟧ The default remains 15 minutes.

Cloud shutdown during a permission wait no longer loses session

If Claude was waiting at a permission prompt and the cloud environment shut down, a cloud session could occasionally be marked as lost. This fix covers that exact overlap: waiting for permission while the environment closes. ⟦It is like a desk clerk waiting for your signature when the office lights go out; the case is no longer declared missing because of that.⟧ In that situation, the session is no longer wrongly marked lost.

MCP long connections stop reopening after timeouts

With a serverless host that ends long-held streams at a fixed timeout, an MCP v2 connection could keep reopening its subscriptions/listen stream. MCP is the protocol that connects AI to outside tools, and this stream receives subscription information. ⟦It is like an intercom call cut off by building rules, where the old behavior kept redialing the same call; it no longer cycles through reconnecting and dropping.⟧ Such servers no longer trigger endless stream reopening.

Permission prompts trigger notification hooks in Desktop and VS Code

If you use a Notification hook while working in Claude Desktop or VS Code, it may previously have stayed silent for a permission prompt. A Notification hook is a small program triggered by an event and should notify you when permission is needed. ⟦It is like a wired doorbell that did not ring when a visitor pressed it; now the bell sounds when someone asks to enter.⟧ The fix covers permission prompts in those two environments.

Idle Linux sandbox stops filling one CPU core

On Linux, an idle session could keep one CPU core at 100% even when sandboxing was enabled. A sandbox is a restricted environment that limits what a program can touch, and it should sit quietly when unused. ⟦It is like a fan running at full speed in an empty room; when no one is using the room, it no longer consumes that fan for nothing.⟧ Idle sandboxed sessions no longer hit that single-core saturation.

Bundled aliases still work when same-named skills shadow them

In -p mode, or after loading plugins or MCP, entering /checkup or /review could produce “Unknown command” if a user or project skill had the same name. A skill is a set of instructions that teaches Claude a particular job, and a name collision should not hide bundled aliases. ⟦It is like a new shop with the same name covering an older shop's whole sign; now both bundled aliases still have a visible entrance.⟧ The fix covers -p and the loaded plugin or MCP cases.

Command arguments no longer get re-read as template markers

After a skill or command received an argument, its value could be expanded again as template markers: special symbols the program replaces. That treated input text as another instruction to process. ⟦It is like a form clerk placing your written name in a field, then reading the name again as instructions for filling out the form.⟧ Now an argument keeps its value after substitution instead of becoming template markers again.

Windows device paths cannot bypass network-path checks

On Windows, a path spelled with the NT \??\ device prefix could bypass UNC path validation and expose an NTLM credential-leak vector. UNC validation is the safety check for network-share path spelling and should catch such paths. ⟦It is like a building's main entrance checking badges while a side door written differently was left outside the same check; now that side door is checked too.⟧ The fix closes the leak route created through that special prefix.

Self-hosted runner starts without rewriting worktree

When starting claude self-hosted-runner, the session branch is now created without rewriting the worktree. A session is the connection and state for one continuous stretch of work, and its start no longer waits for two server round trips that blocked the agent launch. ⟦It is like placing the scene list backstage before a play, rather than rebuilding the whole stage before actors may enter.⟧ The runner's session starts faster because those two round trips no longer block the agent.

Gateway forwards upstream error message itself

When an apps gateway receives a 400 or 413 error from Vertex, Foundry, or Claude Platform on AWS, it now carries the upstream service's own message. An upstream is the service the request was meant to reach, so its message tells you why it rejected the request. ⟦It is like support handing you the warehouse's exact return slip instead of saying only “there is a problem,” so you know what to change.⟧

Apps gateway auto-compact bug is fixed

A bug in auto-compact on apps gateway is fixed. Auto-compact condenses earlier conversation to make room for more content in a session. ⟦It is like an organizer replacing an overstuffed folder with a shorter summary, so the filing step that was stuck can now finish.⟧ Auto-compact through apps gateway is no longer affected by this bug.

Plugin validation finds malformed skill description files

When checking a plugin, claude plugin validate now examines a bare .claude/skills directory. It reports SKILL.md files whose frontmatter, the fields at a file's beginning for tools to read, cannot be parsed. ⟦It is like opening the title page of every manual in a folder before publication and marking any whose basic details cannot be read.⟧ Validation includes .claude/skills even when it stands alone rather than inside a full structure.

Screen readers can choose effort with numbers

When using a screen reader to change /effort, the selector now appears as a numbered list and asks for a typed number. A screen reader is an assistive tool that reads screen content aloud and needs an ordered way to convey choices. ⟦It is like ordering by voice without guessing among unseen buttons: hear the menu, then say the dish number.⟧ Hint text and dialog text are no longer clipped either.

Print mode flags unrecognized model IDs

If print mode sends a model ID Claude Code does not recognize, stderr, the program's text channel for reporting problems, now writes [claude-code:unrecognized_model]. The diagnostic line tells you the request went out with an unknown model ID. ⟦It is like a mailing counter stamping “address not found” on the receipt instead of quietly sending a parcel onto an unknown route.⟧ Map that ID with modelOverrides to silence the line.

Non-GitHub repositories stop getting wrong app setup tip

If a repository's origin remote is on gitlab.com or bitbucket.org, the GitHub app setup tip no longer appears. An origin remote is the repository's destination for its remote source, so a non-GitHub destination should not ask for GitHub app setup. ⟦It is like a station not sending travellers for another city to the wrong platform; when the destination is not GitHub, it does not issue that ticket.⟧ The enterprise marketplace tip now covers internal Git hosts that are not GitHub.

Newer models hide todo tools by default, with an opt-in return

On Opus 4.8, Sonnet 5, Fable 5, Mythos 5, and newer models, the task-tracking tools TaskCreate, TaskGet, TaskUpdate, TaskList, and TodoWrite are no longer available. This changes the availability of existing tools; it does not add a new tool. ⟦It is like a new layout for a toolbox that stores the todo drawer away for these models, while people who need it can still put the drawer back.⟧ Set CLAUDE_CODE_ENABLE_TODO_TOOLS=1 to restore them.

Windows Bash permission change narrows back overly broad rules

On Windows, auto mode repeatedly stopped for manual approval on ordinary cd <dir> && <command> > file Bash commands; that 2.1.232 regression is fixed. At the same time, 2.1.232 Bash permission changes for Cygwin-style symlinks and input redirection < file have been reverted. ⟦It is like access control stopping ordinary passage and two named lanes; ordinary travel resumes, while the two overbroad rules are withdrawn until a narrower version returns.⟧ A narrower version will arrive in a later release.

GitLab 合并请求可直接开工作树

同事发来 GitLab 合并请求网址时，现在可把网址交给 --worktree，也能在 claude agents 视图里直接认出它。工作树（worktree，Git 为同一项目开出的并行副本）让你另开一份地方查看修改，不必离开手头工作。⟦这像收到一张待办房间的门牌；网址一贴，便能走进另一间房核对内容，不用先手抄房号。⟧ 合并请求会显示成 !N，因此清单里能看出它是 GitLab 项目。

网关可把用户身份交给后端记账

Linux Bash 可替失控构建设内存上限

WebFetch 网址缓存保存时间可自行设置

GitLab 병합 요청에서 바로 워크트리를 연다

동료가 GitLab 병합 요청 URL을 보내면 이제 그 URL을 --worktree에 넘길 수 있고 claude agents 화면에서도 알아볼 수 있다. 워크트리(worktree, 같은 Git 프로젝트에 병렬 작업 사본을 만드는 기능)는 현재 작업을 떠나지 않고 다른 곳에서 변경을 살피게 한다. ⟦작업 지시서에 적힌 방 번호를 받으면 주소를 붙여 넣고 그 방으로 들어가는 일과 같다. 번호를 따로 옮겨 적을 필요가 없다.⟧ 병합 요청은 !N으로 표시되어 목록에서 GitLab 항목임을 알 수 있다.

게이트웨이가 사용자 신원을 뒤쪽 기록 장치에 넘긴다

회사가 apps gateway로 Anthropic 상위 서비스에 연결하고 비용을 누구에게 돌릴지 알아야 한다면 forward_user_identity를 선택해 켤 수 있다. 이 설정은 로그인한 사용자의 신원을 headers(요청에 붙는 정보 칸)에 넣는다. 이어 게이트웨이 뒤에서 요청을 대신 중계하는 proxy에 보낸다. ⟦소포가 발송실을 지날 때 보내는 사람 카드를 붙이면 뒤쪽 경리 담당자가 배송비를 알맞은 사람에게 적는 것과 같다.⟧ 켜지 않으면 그 신원 정보는 전달되지 않는다.

Linux Bash에서 폭주 빌드에 메모리 상한을 건다

Linux에서 Bash 도구로 빌드를 돌릴 때 폭주한 빌드가 작업 세션을 멈출까 걱정되면 CLAUDE_CODE_TOOL_MEMORY_LIMIT를 선택해 설정할 수 있다. 이는 Bash 명령에 memory cgroup(프로그램 묶음이 쓸 메모리 경계를 정하는 Linux 기능)을 켠다. ⟦공용 창고에서 믹서 한 대에 정해진 수납칸을 주는 일과 같다. 재료가 그 칸을 채워도 창고 전체를 차지할 수 없어서 다른 사람 물건도 들어간다.⟧ 이 선택 사항은 폭주 빌드가 세션을 멈추지 못하게 한다.

WebFetch URL 캐시 보관 시간을 직접 정한다

한 WebFetch 세션 안에서 URL 캐시를 얼마나 보관할지 정하고 싶다면 환경 변수 CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS를 설정할 수 있다. 캐시(cache, 찾아본 결과를 잠시 보관해 바로 쓰는 기능)는 세션 안에서 URL 조회 결과를 보관하며 이 변수는 그 기간을 정한다. ⟦이미 찾아본 전화번호부 쪽에 유효 기간 딱지를 붙이는 일과 같다. 기간 안에는 그쪽을 바로 보고, 지나면 번호를 다시 찾는다.⟧ 기본값은 그대로 15분이다.

권한을 기다리는 중 클라우드가 꺼져도 세션을 잃었다고 잘못 알리지 않는다

Claude가 권한 확인을 기다리는 중 클라우드 환경이 꺼지면 클라우드 세션을 잃었다고 잘못 표시하는 일이 가끔 있었다. 이번 수정은 권한 대기와 환경 종료가 겹치는 바로 그 경우를 다룬다. ⟦창구 직원이 서명을 기다리는데 사무실 불이 먼저 꺼져도 그 일을 사라진 사건으로 처리하지 않는 것과 같다.⟧ 이 순서로 일어나도 세션은 더 이상 lost로 잘못 표시되지 않는다.

MCP 장기 연결이 시간 제한 뒤 계속 다시 열리지 않는다

오래 잡아 둔 스트림을 정해진 시간에 끝내는 serverless 호스트에서는 MCP v2 연결이 subscriptions/listen 스트림을 계속 다시 열 수 있었다. MCP(Model Context Protocol, AI를 외부 도구에 연결하는 프로토콜)는 이 스트림으로 구독 정보를 받는다. ⟦건물 규칙 때문에 인터폰 통화가 끊긴 뒤 예전에는 같은 상대에게 계속 다시 거는 모습과 같았다. 이제 연결과 끊김을 되풀이하지 않는다.⟧ 이런 서버에서도 스트림이 끝없이 다시 열리지 않는다.

Desktop와 VS Code의 권한 확인이 알림 훅을 작동시킨다

Claude Desktop이나 VS Code에서 권한 확인을 기다리며 Notification hook을 설정했어도 예전에는 반응하지 않을 수 있었다. Notification hook(알림 훅, 특정 일이 생기면 작동하는 작은 프로그램)은 권한이 필요할 때 알려야 한다. ⟦배선된 초인종을 방문객이 눌러도 울리지 않다가 이제 들어오려는 사람이 있으면 울리는 모습과 같다.⟧ 이 수정은 그 두 환경의 권한 확인을 대상으로 하며 훅이 정상 작동하게 한다.

유휴 Linux 샌드박스가 CPU 코어 하나를 가득 쓰지 않는다

Linux에서 샌드박싱을 켜도 사용하지 않는 세션이 CPU 코어 하나를 100%로 계속 쓸 때가 있었다. 샌드박스(sandbox, 프로그램이 건드릴 수 있는 범위를 제한한 환경)는 쓰지 않을 때 조용히 있어야 한다. ⟦아무도 없는 방에서 선풍기만 최고 속도로 돌아가는 모습과 같다. 이제 사용자가 없으면 그 선풍기 하나를 헛되이 차지하지 않는다.⟧ 유휴 샌드박스 세션에서는 이 단일 코어 포화가 일어나지 않는다.

같은 이름의 스킬에 가려져도 기본 별칭을 쓸 수 있다

-p 모드이거나 plugins 또는 MCP를 불러온 뒤 /checkup, /review를 입력하면 사용자나 프로젝트 스킬의 이름이 같을 때 예전에는 “Unknown command”가 나올 수 있었다. 스킬(skill, Claude에게 특정 일을 가르치는 설명 묶음)의 이름이 겹쳐도 기본 별칭이 사라지면 안 된다. ⟦동네에 같은 이름의 새 가게가 생겨 오래된 가게 간판을 통째로 가리는 모습과 같았다. 이제 두 기본 별칭은 여전히 입구를 찾을 수 있다.⟧ 이 수정은 -p와 plugins 또는 MCP가 불러와진 경우를 포함한다.

명령 인수를 템플릿 표식으로 다시 읽지 않는다

스킬이나 명령이 인수를 받은 뒤 그 값이 template markers(템플릿 표식, 프로그램이 바꾸는 특별한 기호)로 다시 펼쳐질 수 있었다. 단순한 입력 글자를 또 처리할 지시로 다루는 문제였다. ⟦서류 담당자가 적힌 이름을 칸에 넣은 뒤 그 이름을 작성 규칙으로 다시 읽는 모습과 같다.⟧ 이제 인수는 한 번 들어간 뒤 값을 유지하며 템플릿 표식으로 다시 펼쳐지지 않는다.

Windows 장치 경로로 네트워크 경로 검사를 우회하지 못한다

Windows에서 NT \??\ device prefix로 경로를 쓰면 예전에는 UNC 경로 검증을 우회해 NTLM 자격 증명 유출 경로가 될 수 있었다. UNC 경로 검증(네트워크 공유 위치의 경로 표기를 확인하는 보안 검사)은 이런 경로를 막아야 한다. ⟦건물 정문은 출입증을 확인하지만 다르게 적힌 옆문은 검사 밖에 둔 모습과 같았다. 이제 옆문도 같은 검사를 통과한다.⟧ 이 수정은 그 특수한 접두사를 통한 NTLM credential-leak 경로를 닫는다.

자체 호스팅 실행기가 워크트리를 다시 쓰지 않고 시작한다

claude self-hosted-runner를 시작할 때 이제 워크트리를 다시 쓰지 않고 세션 브랜치를 만든다. 세션(session, 한 번 이어지는 작업의 연결과 상태)은 시작할 때 agent 출발을 막던 두 번의 서버 왕복을 기다리지 않는다. ⟦공연 전에 무대 뒤에 장면표를 놓고 배우가 들어오기 전 무대 전체를 다시 꾸미지 않는 모습과 같다.⟧ 이 runner의 세션은 그 두 번의 왕복에 막히지 않고 시작한다.

게이트웨이가 상위 서비스의 오류 메시지를 그대로 넘긴다

apps gateway가 Vertex, Foundry 또는 AWS의 Claude Platform에서 400이나 413 오류를 받으면 이제 상위 서비스의 오류 메시지를 함께 전달한다. 상위 서비스(upstream, 요청이 원래 도달할 서비스)의 설명은 왜 거절됐는지 보여 준다. ⟦상담원이 창고의 반품 전표 원문을 주고 “문제가 있다”라고만 말하지 않는 모습과 같다. 그래서 무엇을 고쳐야 하는지 안다.⟧

apps gateway 자동 압축 오류를 수정

apps gateway의 auto-compact 오류를 수정했다. auto-compact(자동 압축, 세션에 더 많은 내용을 담을 자리를 만들려고 앞선 대화를 더 짧게 정리하는 기능)는 gateway가 내용을 정리하는 흐름이다. ⟦정리 담당자가 꽉 찬 서류철을 짧은 요약으로 바꾸어 멈췄던 정리 절차를 끝내는 모습과 같다.⟧ apps gateway를 통한 자동 압축은 더는 이 오류의 영향을 받지 않는다.

플러그인 검사가 형식이 깨진 스킬 설명 파일을 찾는다

plugin을 확인할 때 claude plugin validate는 이제 단독 .claude/skills 폴더도 살핀다. 그 안에서 frontmatter(도구가 읽도록 파일 첫머리에 두는 항목)를 해석하지 못하는 SKILL.md를 알린다. ⟦출판 전에 폴더 속 안내서마다 첫 페이지를 열어 기본 정보를 읽지 못하는 책에 표시하는 일과 같다.⟧ .claude/skills가 완전한 구조 안에 있지 않아도 검사 대상이다.

스크린 리더에서 숫자로 노력 수준을 고른다

스크린 리더로 /effort를 바꿀 때 선택기는 이제 번호 목록으로 보이고 해당 숫자를 입력하라고 한다. 스크린 리더(screen reader, 화면 내용을 소리 내어 읽는 보조 도구)는 선택지를 순서대로 전해야 한다. ⟦보이지 않는 버튼 위치를 짐작하지 않고 메뉴를 들은 뒤 음식 번호를 말하는 음성 주문과 같다.⟧ 힌트 글과 대화 상자 글도 더는 잘리지 않는다.

인쇄 모드가 알지 못하는 모델 ID를 알린다

print mode에서 Claude Code가 알지 못하는 model ID로 요청을 보내면 이제 stderr(표준 오류 출력, 프로그램이 문제를 알리는 글자 통로)에 [claude-code:unrecognized_model]가 적힌다. 이 진단 줄은 요청이 인식되지 않은 model ID로 나갔음을 알려 준다. ⟦우체국 창구가 소포를 알 수 없는 길로 조용히 보내지 않고 영수증에 “주소 없음” 도장을 찍는 일과 같다.⟧ 이 줄을 없애려면 modelOverrides로 그 ID를 알려진 모델에 대응시킨다.

GitHub 밖 저장소에는 잘못된 앱 설정 안내를 띄우지 않는다

저장소의 origin remote가 gitlab.com 또는 bitbucket.org에 있으면 GitHub app 설정 안내가 더는 나오지 않는다. origin remote(저장소가 원격 원본으로 연결되는 곳)가 GitHub가 아니면 GitHub app 설정을 요구하면 안 된다. ⟦기차역이 다른 도시로 갈 승객을 잘못된 승강장으로 보내지 않는 일과 같다. 목적지가 GitHub가 아니면 그 표를 내주지 않는다.⟧ enterprise marketplace 안내는 이제 GitHub가 아닌 내부 Git 호스트도 다룬다.

새 모델에서는 할 일 도구를 기본으로 빼고 환경 변수로 되돌린다

Opus 4.8, Sonnet 5, Fable 5, Mythos 5와 그보다 새 모델에서는 TaskCreate, TaskGet, TaskUpdate, TaskList, TodoWrite 같은 작업 추적 도구를 더 이상 쓸 수 없다. 이는 기존 도구의 사용 범위를 바꾸는 일이지 새 도구를 더하는 일이 아니다. ⟦도구 상자의 새 내부 구조에서 이 모델들은 할 일 서랍을 우선 넣어 두되 필요한 사람은 다시 꺼낼 수 있는 모습과 같다.⟧ 되돌리려면 환경 변수 CLAUDE_CODE_ENABLE_TODO_TOOLS=1을 설정한다.

Windows Bash 권한 변경에서 너무 넓었던 규칙을 되돌린다

Windows의 auto mode가 일반 cd <dir> && <command> > file Bash 명령에서 수동 승인을 요구하며 거듭 멈추던 2.1.232 회귀 문제는 고쳐졌다. 동시에 Cygwin식 심볼릭 링크와 입력 리디렉션 < file에 대한 2.1.232 Bash 권한 변경은 되돌렸다. ⟦출입 통제가 보통 통행과 두 지정 통로까지 모두 막던 모습과 같다. 보통 길은 다시 열고 너무 넓었던 두 규칙은 더 좁은 판이 돌아올 때까지 거둔다.⟧ 더 좁은 판은 뒤 릴리스에서 돌아온다.
