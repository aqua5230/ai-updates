Claude Code 2.1.197

發布日期：2026-06-25 ~ 06-30

zh-TW

預設模型升級成 Sonnet 5，記憶容量暴增到一百萬字，價格還打折

你打開 Claude Code 現在預設用的就是 Sonnet 5，原生支援一百萬 token（AI 讀寫文字時切出來的最小單位，大約等於零點幾個字）的記憶視窗（context window，AI 一次能記住多少對話內容的容量），等於同一個對話能塞進更多的程式碼或文件還不會忘記前面講過什麼。即日起到 8 月 31 日，每百萬 token 只要 2 到 10 美元的促銷價。

對話裡的檔案附件可以直接點開，不用自己去資料夾裡翻

以前 AI 在對話裡提到或附上一個檔案，你想看實體檔案在哪還得自己切到 Finder（macOS 的檔案總管）裡找。現在按住 Cmd（Mac）或 Ctrl（Windows/Linux）點一下附件，就會直接在檔案總管裡跳出來、選好給你看。像收到包裹不用自己去倉庫翻箱子，按一下貨單就直接帶你走到那一格架子前面。

查看 MCP 外掛清單不會再偷偷啟動陌生專案裡藏的伺服器

MCP（Model Context Protocol，讓 AI 連接外部工具的協定）伺服器以前只要你下 claude mcp list 或 get 這種「查清單」的指令，就算是還沒被你信任的專案，只要它的設定檔（.claude/settings.json）裡自己寫好「已核准」，也會被默默啟動執行。現在不會了：不信任的工作目錄會老實顯示「⏸ 等待核准」，光是查清單不會觸發任何程式執行。這就像你以前只是「看」陌生人的名片夾，結果名片自己跳出來打電話；現在光看不會打電話，要你親自按下確認才行。

喚醒背景工作不會再把整段對話紀錄誤刪、逼你重講一次

背景工作（background job，丟給 AI 在背後默默跑、你可以先去忙別的事的任務）以前偶爾會因為系統誤判對話紀錄檔案壞掉，喚醒時就把整段紀錄永久刪掉，還自動把你原本的指令重跑一次——等於白做工還搞丟記錄。現在系統改成「先把可疑檔案移到旁邊」，絕對不會直接刪除，你的對話紀錄保住了。像以前醫院弄丟病歷會直接燒掉重建檔案，現在改成先封存在另一個櫃子，至少東西還在。

開「跳過所有權限確認」模式時，現在會老實告訴你風險，不會默默改成別的模式

--dangerously-skip-permissions（危險跳過權限確認，讓 AI 不問你同意就直接執行所有動作的開關）這個參數以前有個 bug：你明明開了它，系統卻偷偷把它降級成「自動模式」（auto mode，仍會在風險動作前問你），子代理（被主任務分派出去做事的小 AI 助手）也沒真的套用跳過權限的設定，而且不會跳出風險警告告訴你發生了什麼。現在修好了：你開這個開關，系統就老實顯示風險聲明、子代理也會確實套用同樣的跳過權限設定。這就像你按下「跳過安檢」的按鈕，警衛卻偷偷還是把你攔下來檢查、也不告訴你為什麼——現在按下去就真的跳過，而且會先提醒你「這樣做有風險喔」。

程式碼審查指令變更省，同樣品質但少燒四分之一額度

/code-review（叫 AI 幫你審查程式碼找問題的指令）背後原本拆成五個各自獨立的「抓問題小幫手」分別跑一輪，現在合併成一個一起跑，審查品質不變，但消耗的 token（AI 讀寫文字計費的最小單位，你的用量額度就是用這個算的）少了大約四分之一。這就像原本派五個保全分頭巡邏五次，現在改成一個熟練的保全一次巡完全部範圍，一樣巡得到、但人事費省了四分之一。

在終端機模式打指令時，檔案路徑會即時跳出來讓你選，不用自己一個字一個字拼

在 Claude Code 裡按 ! 切換到 bash 模式（直接打終端機指令、不經過 AI 對話的模式）打字時，現在輸入檔案路徑會即時跳出自動完成（autocomplete，打到一半就幫你列出可能的選項讓你選）建議清單，不用自己記清楚資料夾名稱再一個字一個字打對。就像你在搜尋引擎打字，還沒打完它就先幫你列出你可能要找的東西。

`/clear` 清空對話後，`/rewind` 現在可以把清空前的內容拉回來

/clear（清空目前對話、讓 AI 忘記前面講過什麼的指令）以前一旦按下去，前面的對話就真的回不去了。現在 /rewind（倒帶，把對話拉回之前某個時間點的指令）支援連 /clear 之前的內容都能拉回來，等於多了一次反悔的機會。像你以前按下碎紙機就真的沒救了，現在碎紙機旁多了一台還原機，可以把紙條重新拼回去。

從任務面板停掉的背景代理人，這次是真的停了，不會自己又活過來

背景代理人（background agent，被分派出去獨立工作的子 AI）以前你在任務面板按下「停止」，結果它過一陣子又自己悄悄醒過來繼續跑，等於你的停止指令沒被真正遵守。現在修好了：按下停止就是永久停止，不會詐屍。就像你以前拔掉吸塵器插頭，它過幾分鐘又自己插回去運轉；現在拔掉就是真的關機。

AI 一個字一個字吐出回答時，現在不會再把你的電腦風扇逼到狂轉

AI 用串流（streaming，AI 一邊想一邊把文字逐字吐出來、不用等全部想完才顯示的方式）方式輸出回答時，系統以前是每收到一點新文字就立刻重新畫一次畫面，很耗電腦資源。現在改成把文字更新合併、每 100 毫秒（千分之一秒）統一刷新一次，CPU（處理器，電腦的大腦，負責執行運算）使用量降低了大約三分之一強。這就像以前服務生每端一口菜就跑一趟廚房，現在改成湊滿一輪菜再一起端出來，跑的趟數少了，人也不會那麼喘。

en

Default model upgraded to Sonnet 5 — memory jumps to a million words, and it's cheaper too

Claude Code now defaults to Sonnet 5, with a native 1-million-token context window (context window, how much of the conversation the AI can remember at once; a token is the small chunk of text the AI reads and writes in) — meaning one conversation can now hold more code or documents without the AI forgetting what came before. From now through August 31, pricing is a promotional $2-$10 per million tokens.

File attachments in chat are now clickable — no more digging through folders yourself

When the AI mentions or attaches a file in chat, you used to have to switch to Finder or Explorer yourself and hunt for it. Now Cmd-click (Mac) or Ctrl-click (Windows/Linux) on the attachment jumps straight to that file, already selected, in your file manager. It's like a delivery slip that walks you straight to the right shelf instead of making you dig through the warehouse yourself.

Listing MCP plugins no longer secretly starts servers hidden in untrusted projects

MCP servers (Model Context Protocol, the standard that lets the AI talk to external tools) used to spin up just from running the read-only claude mcp list/get commands, even in a project you hadn't trusted yet, as long as its own settings file (.claude/settings.json) had self-approved itself. Not anymore — an untrusted workspace now honestly shows '⏸ Pending approval', and merely listing servers no longer triggers anything to run. It's like flipping through a stranger's business cards used to dial their number by itself; now looking doesn't dial — you have to press confirm yourself.

Waking a background job no longer wipes its entire conversation and forces a redo

Background jobs (tasks you hand off to the AI to run quietly while you do something else) used to occasionally have their entire conversation permanently deleted on waking, whenever the system misread the transcript as corrupted — and then it would auto-rerun your original prompt from scratch, wasting work and losing history. Now the suspect file just gets set aside instead of deleted, so your transcript survives. It's like a hospital that used to burn a medical record it thought was damaged and start a new one from scratch; now it just files the old one in another drawer instead — at least it's still there.

The "skip all permission checks" flag now honestly warns you of the risk instead of quietly switching modes

--dangerously-skip-permissions (a flag that lets the AI act without asking your permission first) had a bug: turning it on used to silently downgrade it to 'auto mode' instead (which still asks before risky actions), without showing the risk disclaimer, and subagents (helper AIs spawned to do part of the work) didn't actually inherit the bypass either. Now it's fixed — flipping the switch shows the real risk warning, and subagents genuinely inherit the same bypass. It's like pressing a 'skip security check' button that secretly still stopped and searched you anyway, without telling you why — now pressing it really does skip the check, after first warning you it's risky.

Code review got leaner — same quality, a quarter less quota burned

/code-review (the command that has the AI review your code for problems) used to run five separate 'issue-finder' passes behind the scenes. Now they're merged into one pass — same review quality, but token usage (token, the unit the AI's reading/writing is metered in, which is also what your usage quota counts) drops by roughly a quarter. It's like replacing five separate security guards each patrolling once with one experienced guard who covers the whole route in a single pass — same coverage, a quarter less payroll.

Typing commands in terminal mode now auto-suggests file paths as you go, no more spelling them out yourself

When you press ! in Claude Code to drop into bash mode (typing raw terminal commands directly, bypassing the AI), typing a file path now triggers live autocomplete (autocomplete, a suggestion list that pops up partway through typing) — no need to remember and spell out exact folder names yourself. It's like a search engine that starts suggesting what you're looking for before you've finished typing.

After `/clear` wipes the conversation, `/rewind` can now bring back what came before it

Once you ran /clear (the command that wipes the current conversation so the AI forgets everything before it), there used to be no going back. Now /rewind (the command that rolls the conversation back to an earlier point) can reach back to before a /clear, giving you a second chance. It's like a paper shredder that used to be final — now there's a reconstruction machine next to it that can piece the strips back together.

Stopping a background agent from the tasks panel now actually stays stopped — no more resurrections

Background agents (helper AIs spawned to work independently) used to occasionally wake themselves back up and keep running a while after you'd hit 'stop' in the tasks panel — your stop command wasn't really being honored. Now it's fixed: stopping an agent is permanent, no resurrections. It's like a vacuum cleaner that used to plug itself back in and start running again a few minutes after you unplugged it; now unplugging it actually means it stays off.

While the AI streams its answer word by word, your computer's fan no longer has to work overtime

When the AI streams its answer (streaming, writing text out token by token instead of waiting until it's fully done), the system used to redraw the screen every single time a little new text arrived, which was hard on your machine. Now text updates are batched and redrawn once every 100 milliseconds (a thousandth of a second), cutting CPU usage (CPU, your computer's 'brain' that does the actual computing) by roughly a third. It's like a waiter who used to run to the kitchen for every single bite of food, now waiting to carry out a full round of dishes at once — fewer trips, less out of breath.
