Claude Code 2.1.247

Released: 2026-08-26

Release notes

FEATURE

SendFeedback drafts bug reports on session errors for quick review

When something goes wrong in a session, Claude can now use the SendFeedback tool to automatically draft a feedback report for you.

You can review the details and send it straight from /feedback, saving you from manually copying error logs and writing bug reports. If you prefer not to have drafts generated, you can turn them off by setting {"feedbackDrafts": false} in your configuration.

It is like a lab record system that gathers observations into a report draft after a failed test, waiting for a researcher to review it before submission.
FEATURE

Custom spinner tips allow organizations to rotate in-house guidance

Organizations that want to display custom guidance while Claude is thinking can add spinnerTipsOverride to ~/.claude/settings.json.

Like an office lobby display board that shows internal notices alongside the standard announcements.

Paste this complete setting:

{"spinnerTipsOverride": {"label": "Team tips", "tipsFile": "~/.claude/team-tips.json"}}

tipsFile points to a separate tips file, and label is its display name.

Tip entries can include {id, text, cooldownSessions, priority} and rotate alongside built-in tips.

FEATURE

Bash prompts offer a one-keystroke switch into auto mode

When a Bash permission prompt appears in your terminal, it now includes a helpful tip pointing toward auto mode.

A self-service laundry screen can confirm this wash while suggesting an automatic program, with one button that both starts the current wash and enables automatic selection.

A single keystroke allows you to select "Yes, and switch to auto mode", granting permission for the current command while immediately engaging auto mode so you don't have to keep approving routine operations.

FEATURE

/claude-api cost-optimize profiles spending and works through cost levers

To rein in API expenses on an existing codebase, you can now run /claude-api cost-optimize to profile your project's Claude API spend.

It guides you systematically through key cost levers including caching, batch processing, effort levels, and model choices. It also assists in token hygiene, testing one measured change at a time.

It is like having a financial auditor inspect your operational bills line by line, methodically tweaking cost dials and measuring the precise savings after each adjustment.
FEATURE

/claude-api skill expands coverage across the Admin API suite

Managing enterprise API resources is now much simpler with the updated /claude-api skill, which extends coverage across the Admin API suite.

Like an event producer using one backstage control sheet to coordinate attendee lists, invitations, venues, equipment labels, and usage reports, while also arranging partner identity links and a self-managed vault code.

It supports organization members, invites, workspaces, API keys, and rate limit reports. Workload identity federation (WIF) is fully included. Customer-managed encryption keys (CMEK) are also supported for enterprise security.

BUGFIX

Rapid arrow and Enter sequences accurately trigger the selected menu item

Rapidly navigating interactive menus no longer triggers the wrong item due to timing latency.

Previously, typing a rapid sequence of arrow keys and Enter in history search, /config, /mcp, /skills, background tasks, or /model could accidentally act on the row directly above your target; input event processing is now fixed to reliably target your current selection.

Like an elevator panel that eliminates button lag, stopping precisely at the floor you selected even when you tap the controls in rapid succession.
BUGFIX

Sub-agents handle 404s via fallback chains and detailed diagnostics

Sub-agents no longer crash outright when their initial API call encounters a 404 model not found error.

Like a switchboard that tries backup extensions when the main line cannot connect, then records the failure type, status, case ID, and extension name if every line fails.

Instead, they now transition smoothly through the session's fallback model chain, and if the operation still fails, the error sent back to the parent agent includes the error type, status, request id, and model name.

BUGFIX

Large error outputs no longer wedge sessions with prompt length errors

Hooks or background agents that dump megabytes of error output can no longer flood the conversation history and wedge the session on "Prompt is too long".

The system now prevents excessive diagnostic output from overwhelming the context window, keeping your terminal responsive.

Like a dam's spillway routing away excess water during a storm so the reservoir does not clog and interrupt its normal supply.
BUGFIX

Ctrl shortcuts trigger reliably under non-Latin layouts in kitty terminals

Using Ctrl keyboard shortcuts in terminals supporting the kitty keyboard protocol now works reliably under non-Latin keyboard layouts such as Cyrillic.

Previously, switching input layouts prevented modifier key combinations from firing; keyboard event translation is now fixed across all keyboard configurations.

Like a multi-language keyboard controller that accurately resolves core shortcut signals regardless of which alphabet layout is currently active.
BUGFIX

Split mouse reporting packets no longer leak raw text into prompts

Mouse tracking reports that arrive split across stream reads directly after an escape prefix will no longer dump stray text fragments like <35;150;7M straight into your prompt input.

Like a telegraph printer that recognizes split control signals, preventing raw coordinate numbers from leaking onto the printed letter as plain text.

Input stream buffering now properly reconstructs split control sequences.

BUGFIX

Bash sandbox cleanup preserves dotfile-managed settings symlinks

Users managing dotfiles with tools like nix/home-manager or GNU stow no longer risk having their configuration link erased.

Previously, when the Bash sandbox cleaned up after running a command, if the ~/.claude/settings.json symlink was repointed outside the sandbox's writable area, the cleanup routine deleted the symlink; the sandbox now safely preserves these links.

Like a cleanup crew that recognizes an external reference label on a storage box, keeping your carefully organized configuration shortcuts intact.
BUGFIX

/terminal-setup merges keybindings into Zed keymaps without overwriting

Running /terminal-setup to configure keybindings for the Zed editor no longer wipes out your entire keymap configuration.

Like adding a new entry to an address book by jotting it on an empty line, rather than replacing the whole notebook with a blank one.

Instead of completely overwriting keymap.json, the command now cleanly merges its required keybindings into your existing file, preserving all your personal custom shortcuts.

BUGFIX

/rename warns when registry updates fail instead of silently confirming

When running /rename to rename your session, the interface no longer gives a silent confirmation if the session registry cannot be updated.

It now explicitly alerts you that other sessions might still display the old name, ensuring you are aware of the registry state.

Like a registration desk informing you that while your name tag is updated locally, other department screens might still reflect your previous name until sync completes.
BUGFIX

Agent summaries retain custom system prompts during context compaction

Sessions launched with --agent now maintain their custom system prompt during context compaction.

Previously, running /compact or using "Summarize from here" caused the summary to be generated under the generic default system prompt; it now strictly preserves the conversation's own prompt instructions.

Like an assistant summarizing a project workshop according to the project's unique guidelines, rather than reverting to a generic corporate template.
BUGFIX

Dead background agent sessions fail promptly with a restart key

In the claude agents list, background sessions whose terminal host process died will no longer remain stuck displaying "opening…" forever.

Like an airport status board that clearly marks a cancelled flight with the underlying reason within seconds and provides a rebooking prompt, instead of staying frozen on boarding status.

The row now marks itself as failed within seconds along with the failure reason, and pressing Enter immediately restarts the session.

BUGFIX

Output write failures cap memory growth and mark where output was lost

If a hook or background task cannot write to its output file, the system no longer buffers the data indefinitely in memory, preventing unbounded memory growth.

Additionally, the log file now records an explicit note indicating where output was lost.

Like a printer running out of paper that stops filling memory buffers to avoid crashes, later marking the exact point where pages were dropped once writing resumes.
BUGFIX

GitHub App setup over SSH clarifies copy channels and displays URLs

Running /install-github-app over an SSH connection now handles clipboard and browser limitations gracefully.

The copy shortcut explicitly reports how the sign-in URL was copied rather than falsely claiming universal success, and if no browser can be opened remotely, the URL prints immediately to the screen.

Like a remote dispatcher who clearly explains which channel sent your authorization link, displaying the URL on screen immediately when a direct browser launch isn't possible.
BUGFIX

Commands carried into the background report cleanly upon completion

Shell commands handed off from the foreground to background sessions no longer log internal errors or display a misleading [exited with code -1] banner upon completion.

Like passing a baton to a relay teammate who finishes the lap smoothly, without the scoreboard mistakenly displaying a disqualification code at the finish line.

Background task status is now reported cleanly upon normal termination.

BUGFIX

Multi-scope plugin installations protect active cache directories

Installing a version-less marketplace plugin across a second scope no longer purges and recreates its active cache directory.

This eliminates the risk of disrupting existing, active sessions that are currently executing the plugin.

Like setting up shared office equipment in a second room without unplugging the active server in the hallway that the first room is still using.
BUGFIX

Remote Control sessions broadcast live working-tree diffs to clients

Remote Control sessions launched via /remote-control now reliably broadcast the working-tree diff to connected clients.

Like a screen-sharing presenter who accurately projects the live edit diffs, ensuring all remote attendees see precisely what is being modified.

Previously, attached clients could not see pending file modifications; this sync issue is resolved so remote collaborators see current changes in real time.

BUGFIX

Self-hosted runners delay running state until startup completes

Self-hosted runner sessions no longer report a "running" status before Claude Code has actually booted up.

This eliminates premature "Claude is waiting for your input" notifications fired by the Claude desktop app while initialization is still underway.

Like a theater that keeps its opening light off until its set and lighting are ready, avoiding an early signal that the audience may enter.
BUGFIX

Gateway setups complete first-run initialization without public endpoints

First-run setup no longer abruptly aborts with "Unable to connect to Anthropic services" when managed settings configure gateway sign-in for Claude apps while standard Anthropic endpoints are blocked.

When a museum's main entrance is closed, a guide can still use the designated service corridor to bring a new visitor to the check-in desk rather than cancelling admission.

Initial configuration proceeds smoothly over the designated gateway channel.

BUGFIX

Cloud sessions preserve newly toggled permission modes after sending messages

In cloud sessions across web, desktop, and mobile apps, rapidly toggling your permission mode right after dispatching a message no longer causes the UI to flicker back to the prior mode.

State synchronization now ensures your updated mode remains active regardless of network transmission timing.

Like an image editor that preserves the tool you just selected when you switch tools at the same moment you save, instead of reverting to the previous one.
BUGFIX

Resumed cloud sessions report lost background tasks after container restarts

If a cloud session's container restarts between turns while background agents, shells, or monitors are active, the resumed session no longer silently drops into limbo.

It now explicitly reports any lost work and background processes that were interrupted.

Like an office assistant who hands you an incident briefing after an unexpected power reset, clearly detailing which background tasks were interrupted instead of acting like nothing happened.
FEATURE

Plugin marketplace hardens safety against invisible names and output escapes

Plugin marketplace security has been hardened against terminal tampering.

Like an official market inspection that bans vendor signs with invisible ink or hidden tripwires, ensuring public boards display text safely.

Plugin names containing control or invisible characters are now strictly rejected, and all text supplied by marketplaces rendered in /plugin and claude plugin is escape-safe.

FEATURE

Bedrock and Vertex sessions explicitly report MCP server connection failures

In Bedrock, Vertex, Foundry, or telemetry-disabled sessions, Claude is now explicitly informed when a configured MCP (Model Context Protocol) server fails to connect, instead of hallucinating that the tools do not exist.

Like a radio operator clearly reporting that a remote supply depot line is down, so the commander knows tools exist but are temporarily unreachable, rather than assuming they were never assigned.
FEATURE

Sonnet 5 expands auto-compact thresholds to 967K on 1M context windows

Sonnet 5's default auto-compact threshold now scales to its full 1M context window.

Sessions on the 1M window will automatically compact context at approximately 967K tokens instead of roughly 934K tokens, unlocking more working room for long interactions.

Like moving the review bookmark further back in a massive notebook, allowing you to fill up to about 967K units of notes before initiating a summary pass.
FEATURE

Cross-session peer messages collapse to single lines with Ctrl+O expansion

Peer messages sent across sessions are now collapsed by default into a single-line preview showing Message from @<sender>: <first line>.

You can press Ctrl+O at any time to expand and read the full body without cluttering your main stream.

Like loose-leaf study notes that show only a chapter heading and first line until you use a shortcut to open the full page.
FEATURE

Markdown hyperlinks pointing to network paths render as plain text

Terminal hyperlinks rendered from Markdown now enforce safer formatting rules.

Link targets that point to network or automounter paths, contain control characters, or lead with invisible characters are automatically rendered as plain text rather than clickable links.

Like access control that downgrades a suspicious keycard or one with hidden symbols to an ordinary paper card that cannot open a door.
FEATURE

Prompt PR badge skips refocus checks when data is under a minute old

The pull request badge in the prompt footer now optimizes its GitHub network calls.

When refocusing your terminal window, it skips the GitHub re-check if the previous check occurred under a minute ago, saving bandwidth and keeping your prompt snappy.

Like a watch that doesn't ping satellites every second you glance at it, relying on a check performed less than a minute ago to conserve battery.
FEATURE

Analytics remain completely off from startup for gateway and OAuth setups

Telemetry and analytics now remain disabled starting from process startup, rather than waiting until after login, whenever managed settings enforce gateway login or a custom OAuth deployment is active.

Like a privacy-conscious meeting room that switches its recording equipment off as the door opens, rather than waiting for a visitor to finish checking in.
FEATURE

Claude apps gateway sign-ins explicitly identify Claude Code clients

Gateway sign-in requests for Claude apps now explicitly identify Claude Code to the authorization server.

Like stage equipment labelled with its theater company and version, so the control desk can identify its source and apply the matching rules.

Requests include a surface=claude_code parameter during device authorization and specify a claude-code/<version> User-Agent header.

FEATURE

Organization enforcement exits on unreadable managed settings

Enforcement of organization sign-in policies now immediately exits at startup if the administrator's managed settings cannot be read.

Even if host-supplied or per-user Windows registry settings exist, the tool will refuse to launch without verified administrative policies, closing potential security bypasses.

If the central recipe cannot be read, the kitchen does not start cooking; notes left by the venue or an individual beside the stove cannot replace the official instructions.
