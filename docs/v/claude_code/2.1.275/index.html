應用程式商店在下載安裝新套件前，先由安全掃描器過濾掉安裝腳本並隱藏下載網址中的帳號密碼。

Artifact 發布共享指引強化，跨裝置接續與例行任務自動更新

當工作階段（session）換機恢復或暫存區被清空時，更新失敗的問題已修復。系統會自動還原該頁面最後發布的版本。

共同編輯線上公佈欄海報，具備修改權限的成員可以直接在原圖版覆蓋更新，不必每次都複製出一張新的草稿。

發布與讀取結果現在會清楚標明瀏覽權限與分享選單選項，初次發布時改為要求單字分頁圖示，並在頁面包含空位元組時發出警告。被賦予編輯權限的共享頁面會直接在原處更新，不再另行建立複本。例行任務在執行時能自動儲存並重新發布你可編輯的頁面，省去反覆詢問的步驟。

提示詞快取命中率提升，遙測設定示警與方案用量查詢共用

當你在 --system-prompt 中加入 __SYSTEM_PROMPT_DYNAMIC_BOUNDARY__ 標記時，分界線以上的文字現在會進行全域快取（cache，把計算過的結果暫存起來直接取用）。在對話壓縮或恢復執行後，記憶檔案的時間標註不再於每次請求間變動，有效解決了快取失效的問題。回覆中偶爾出現的多餘標籤已修正。同一台機器上的編輯器視窗與非互動工作階段（session）現在會共用一分鐘內查詢過的方案用量，避免重複呼叫端點。啟動時若設定的遙測小幫手執行失敗，系統會主動發出警告。

辦公室共用電話簿，同仁查詢同一支分機時直接查看櫃檯一分鐘前剛翻開的那一頁，避免所有人重複打去總機詢問。

檔案搜尋與讀取不再卡住，沙盒指令狀態碼精準回報

使用 Grep、Glob 或輸入 @ 搜尋檔案時，若搜尋結果超出上限，程式不再發生記憶體不足或卡死，ripgrep 遇到大量警告時也會正確回報錯誤。自訂檔案建議指令或輸入 @. 時，檔案建議不會再被 MCP（讓 AI 連接外部工具的協定）資源排在下方。在記憶體吃緊導致大檔案無法解碼時，讀取工具現在會明確回報錯誤而非無回應。Linux 沙盒環境下使用 Zsh 時，失敗的 Bash 指令不再誤報成功結束代碼，且沙盒環境已支援寫入名為 hooks/ 或 config/ 的專案目錄。

圖書館檢索系統在遇到超出借閱上限的龐大藏書清單時，能精準回傳搜尋結果而不至於讓查詢終端機當機。

工作階段還原容錯強化，損毀記錄與啟動異常自動修復

恢復工作階段（session）時的穩定性現在更加健全。

檔案管理員在翻閱泛黃破損的卷宗時，主動撫平黏合損毀的書頁，接續先前的查案思路而不中斷。

全螢幕檢視流暢度升級，背景通知定位與選取複製修復

在全螢幕工作階段（session）中，背景任務的完成通知現在會即時關閉展開的工具列，並精準顯示在抵達位置，不再被壓在摺疊行底下。向上捲動瀏覽長篇檔案修改比對時，畫面不再短暫凍結或反白數秒。在斜線指令下拉選單開啟時快速打字或按住按鍵，不再觸發無法復原的介面錯誤而退出程式。在 claude --resume 選擇清單中用滑鼠選取的文字，現在能順利複製至剪貼簿。當終端機運作緩慢或暫停時，系統反應已獲得改善，輸出內容不會在等待期間持續落後。

禮堂的多功能投影幕在快速切換長篇簡報時保持畫面流暢，不會因為滑鼠選取文字或快遞通知抵達就突然閃退。

子代理訊息轉發完整保留，背景任務與復原指令穩定執行

當你在分支技能（forked skill）中啟動子代理時，--forward-subagent-text 輸出與 SDK 不再遺漏轉發訊息。在背景工作階段（session）中執行 /rewind 倒轉時，即使歷史備份未完全複製，也不會再還原出全零或遭截斷的損毀檔案。在檔案描述元耗盡的機器上透過標準輸入（stdin）執行指令時，背景工作單元不再異常崩潰重啟。自架執行器在收到關機訊號時會短暫等待當前輪次回報，避免丟失最終結果。帶有特定比對條件的 SubagentStop 掛鉤（hook，在特定事件發生時被觸發的小程式），也不會再對代理類型為空的子代理錯誤觸發。

劇團後台調度員在閉幕廣播響起時，耐心等候正在台前謝幕的演員退場並記錄最終成果，不遺漏任何謝幕環節。

權限設定規則精確套用，託管環境重啟與圖片存取順暢

安全警衛室在重新巡邏交接後，依然在門禁看板上保留先前未確認的訪客申請表單，不再重複敲門打擾住戶。

［VSCode］代理地圖視覺化升級，背景任務崩潰復原狀態更精準

［VSCode］對話捲動體驗改善，斜線指令排隊與發送設定自訂

當 Claude 正在處理任務時，新發送的訊息現在會整齊停留在對話最底部排隊，直到模型開始處理它。在此期間輸入的斜線指令，會在當前回答結束後依序執行，不再被當成純文字誤送給模型。當你向上捲動閱讀歷史訊息時，串流回覆不再強行將畫面拉回底部，若想徹底關閉發送時自動捲動至底部的行為，可新增以下設定：

{
  "claudeCode.scrollToBottomOnSend": false
}

發送訊息時捲動未對齊新回覆，以及權限卡片等待確認時畫面微幅跳動的問題均已修復。

會議室即時速記板在聽眾向上翻閱歷史發言時，不會強行把畫面拉回底部，讓每個人都能依照自己的節奏閱讀。

圖書館借書證在重新蓋章後，依舊以最後一次借閱的實際日期排序，分流出的研究筆記也完整保留原本的借閱權限。

［VSCode］MCP 伺服器支援重試，遠端遙控開關與外掛設定安全

當 MCP（讓 AI 連接外部工具的協定）伺服器清單載入失敗時，對話框中現在會主動顯示「重試」連結供你快速重新連線。在遠端遙控（Remote Control）連線中若想取消，再次輸入 /remote-control 即可立即關閉連線，且連線關閉失敗後狀態能正確顯示為已關閉。外掛管理對話框中不再外洩市集網址內輸入的密碼或權杖，並修正了無效安裝連結的彈窗問題。此外，若在環境變數設定中留下空的 CLAUDE_CONFIG_DIR，系統不會再將設定檔案錯誤存放在工作區目錄中。

遠端遙控開關在嘗試連線階段若被再次按下，能立刻中止連線程序，安全面板也不會暴露連接線路上的金鑰字串。
