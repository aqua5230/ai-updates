Claude Code 2.1.191

Released: 2026-06-24

Release notes

FEATURE

Rewind got stronger, and scrolling stopped jumping

You now have tighter control over your conversation history. Even if you've wiped your screen with /clear, you can still use /rewind to resurrect the conversation from exactly where it was before the wipe, saving you from accidental clicks. When reading long answers, the app used to forcefully yank your scrollbar to the bottom while the AI was still streaming new words, making it impossible to read earlier text; similarly, scrolling past the overflow cap in the agent roster would cause the whole panel to jump weirdly. These annoying visual interruptions are now fixed. It's like watching a live video stream where the chat used to violently auto-scroll whenever someone posted a new message; now you can peacefully scroll up to read older comments while the chat stays perfectly anchored.

FEATURE

Kill background tasks permanently, friendlier UI interactions

Stopping a background agent from the tasks panel will now prevent it from resurrecting. Previously, stopping a background agent from the tasks panel would see it resurrect like a zombie shortly after; now, stopping an agent permanently terminates it. If you paste an image into the claude agents panel, it will politely display a [Image #N] placeholder instead of littering the screen with the full, obnoxiously long file path; and if you type a builtin slash command like /usage to a background session, it now shows a helpful hint instead of blindly sending it as chat text. Other fixes include: login URLs no longer truncate when wrapping across lines in Windows Terminal, fullscreen Cmd-click links now work in Ghostty, comma-separated hook matchers no longer silently fail, the splash art won't overflow the default macOS Terminal window, disabled /voice modes now properly explain organizational restrictions, and approving a permission in the 'Recently-denied' tab finally saves properly upon closing. It's like replacing all the clunky tools in your office: the ex-employee who wouldn't leave is finally escorted out permanently, absurdly long email attachments auto-collapse, and the printer finally tells you exactly where the paper jam is. Everything is just crisp and intuitive.

FEATURE

Smarter network permissions and resilient MCP tools

The system is now much more resilient when facing network hiccups and external permissions. Network permissions inside the sandbox now remember your 'Yes' for the remainder of the session, sparing you from annoying popups on every single connection attempt. For MCP (external tool servers), if a transient network drop occurs while fetching capability lists or requesting OAuth tokens, it now smartly waits a beat and retries instead of instantly failing. If it hits a 404 Not Found error, the message explicitly names the failing URL and points you to your config. Additionally, in headless environments (running without a display/browser), it seamlessly skips the impossible browser popup and goes straight to prompting you to paste the URL. On the enterprise management side, forceRemoteSettingsRefresh now correctly sends a no-cache header, ensuring proxies don't feed you stale policies. It's like bringing a guest into a corporate building: instead of guards checking IDs at every single door, one sign-in at the front desk grants access for the whole visit; and if the internal intercom gets staticky, the system automatically dials again instead of throwing you out on the street.

FEATURE

Reduced CPU and memory drain for smoother long sessions

Performance during prolonged use has been significantly optimized. The system now coalesces terminal text updates to once every 100 milliseconds while the AI is streaming—keeping the animation perfectly smooth to the human eye while slashing CPU usage by an impressive 37%. We've also addressed the terminal output cache, stopping memory from ballooning out of control during exceptionally long conversations. It's like replacing a garden hose nozzle from a frantic wide spray to a steady stream; you get the exact same amount of water exactly where you want it, but the pressure pump uses half the electricity, ensuring the pipes never burst even if left running all day.
