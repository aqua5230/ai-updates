企業統一派發 MCP 外部工具，管理設定檔損毀時拒絕啟動

企業管理者能透過 managedMcpServers 設定，統一派發 HTTP 或 SSE 的 MCP（Model Context Protocol，讓 AI 連接外部工具的協定）伺服器，格式同 .mcp.json 並略過本機指令：

{
  "managedMcpServers": {
    "company-docs": {"url": "https://mcp.internal.example.com/sse", "type": "sse"}
  }
}

allowedMcpServers 改為僅管制使用者新增的伺服器；升級後若要封鎖 managed-mcp.json 伺服器，需改用 deniedMcpServers。若管理設定檔、drop-in 檔案、MDM plist 或 HKLM 值解析失敗，Claude Code 會拒絕啟動並指名來源。由 MDM 或管理設定檔設定的 policy helper 執行後，forceRemoteSettingsRefresh 強制重整也修復生效。這好比總務處配發公用設備，清單破損缺頁警衛就在大門攔下核對，絕不含糊放行。

無人主機新增授權旗標，需確認操作自動拒絕不卡死

無人值守的自動收發室遇到需要本人親簽的掛號信時，會依規定直接退回拒收，其餘免簽包裹則正常放行，絕不讓窗口卡死乾等。針對無人看管的無頭模式（headless，沒有終端機視窗的執行模式）伺服器，你可以透過完整指令執行：

claude --permission-prompts none

這項新旗標專門處理無人主機的自動化流程。只要遇到任何需要跳出對話框請求確認的操作，系統都會自動予以拒絕，而當前生效的權限模式（包含自動模式）則會持續在背後自主決策。當你在伺服器排程或 CI 流程中跑工作階段時，再也不用擔心某個未授權的操作讓整個流程無限期停擺。

Organizations can roll out managed MCP servers, and startup halts if managed config is corrupt

Administrators can now distribute HTTP or SSE MCP servers (Model Context Protocol, which connects AI to external tools) to every user via the managedMcpServers setting, using the same format as .mcp.json while skipping local commands:

{
  "managedMcpServers": {
    "company-docs": {"url": "https://mcp.internal.example.com/sse", "type": "sse"}
  }
}

allowedMcpServers now governs only user-added servers; to block managed-mcp.json servers after upgrading, use deniedMcpServers instead. If the managed settings file, a drop-in file, the MDM plist, or the HKLM value fails to parse, Claude Code now refuses to start and names the source. Additionally, forceRemoteSettingsRefresh now properly triggers at startup even after a policy helper configured by MDM or managed settings has already run. It is like a company issuing standard equipment: if the manifest is torn or unreadable, the guard stops everyone at the gate to verify rather than letting unchecked gear through.

Unattended hosts get a prompt-suppression flag to auto-deny blocking prompts

An automated mailroom, when presented with registered mail needing a physical signature, immediately turns it away while clearing normal parcels through, never letting the counter stall in endless waiting. For unattended headless servers — environments running without a visible terminal window — you can run the full command:

This flag is built for automated pipelines on unattended machines. Whenever an action would pop up a prompt asking for confirmation, it is automatically denied on the spot, while the active permission mode (including auto mode) continues making decisions in the background. Running scheduled jobs or CI pipelines in a session no longer risks a single unprompted action freezing the entire workflow indefinitely.
