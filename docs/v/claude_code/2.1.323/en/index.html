Claude Code 2.1.323

Released: 2026-11-12

Release notes

FEATURE

Experimental Code Mode arrives, calling tools by writing code

When organizing a batch of files, you might have Claude use different tools in sequence. Experimental Code Mode (a mode for running tools via scripts) lets Claude write JavaScript to call tools. JavaScript is a programming language used here to write out tool-calling steps. This feature requires opting in; to turn it on, or to turn it off for an organization, see the official documentation at https://code.claude.com/docs/en/code-mode.

When cooking, giving spoken instructions and writing a recipe are different ways to hand off a task; writing out washing and chopping as steps to follow helps explain what it means to arrange tool calls in a program.
FEATURE

Plugin spec validation upgraded to strictly check types and version compatibility

Installing a plugin checks engines["claude-code"] in plugin.json first: anything outside the range is not installed, updated, or loaded, and installs and updates pick the newest compatible version. Startup, claude plugin list, and claude plugin validate all warn that agent is deprecated, while the setting still applies. Type issues in validated TypeScript hooks (event-triggered programs) are listed as warnings, failing only with --strict; engine.create hooks that add, withhold, or replace $ nouns fail if written in an unaccepted form, though installed mods still load. A *, namespace, or negated hook on that event only observes, so adding or withholding must hook by name. unsetOptionCount counts unset userConfig options; isPromptCovered indicates when a dialog or field above the prompt covers the prompt. Additions or removals from tool.list apply to the model and every agent. When a language server fails to start, it names which server and what to check.

BUGFIX

Plugin marketplace loading fixes clarify error prompts and install details

When managing marketplace plugins, error reporting is clearer. /fast on and /fast off on Vertex now ask the config.set hook (an event-triggered program). New files created after a failed hot reload are no longer missed; one malformed entry in renames no longer breaks the rest. If a plugin enabled only by project settings is not installed, the message includes the install command, which also appears in text and stream-json -p runs. In SDK and Desktop sessions, load errors for managed plugins are listed in init.plugin_errors. When a --plugin-dir hook hangs or its worker crashes in text claude -p runs, it reports to stderr (diagnostic output). Not now explains when they load; installs fail if a submodule commit does not match the commit recorded by its repository. If an install command writes to stderr, a warning is shown even when it succeeds.

FEATURE

Bash permission checks close bypass gaps and guard sensitive path writes

When running a shell (command-line interface), previously missed prompts are now shown. Bash allow rules with * in a variable value warn at startup; writes to .git or .claude no longer offer "don't ask again". Allow rules for some lsof commands, certain non-default zsh options, attached wildcards, or combined sudo flags no longer skip prompts; Bash(NODE_ENV*) also asks. Commands wrapped in sudo or env, or parts of a command, are no longer missed; commands that may execute differently from how they were checked ask first. cat > file <<EOF is no longer labeled "Read 1 file". Under bypass permissions (skipping standard authorization) or a Bash allow rule, rm no longer misses the dangerous-removal prompt due to judging from the wrong folder. On Windows, file-reading commands with a wildcard or a file list all prompt; slow or busy machines give more consistent answers for the same command.

BUGFIX

Sandbox rules tightened to restrict cross-worktree commits and config sources

The sandbox (isolated execution environment) no longer switches off mid-session. When auto mode is unavailable, it starts in Manual mode which asks first; sandbox.excludedCommands no longer lets unnamed commands bypass it. Legacy config files are protected and file checkpoint copies are unreadable; symbolic links (shortcuts pointing elsewhere) in project settings no longer cause reads and checks to hit different locations. On Linux with CLAUDE_CODE_SUBPROCESS_ENV_SCRUB set and sandbox.enabled off, HTTP hooks no longer return 500. glab config set without --global or --host, and glab config edit --local, must now be run outside the sandbox. macOS, Linux, and WSL ignore write access granted via links inside writable folders that point elsewhere or to missing paths, requiring the real path instead. The GitLab merge request badge is limited to the repository the sandbox started in; on macOS, tools like lsof show less info about processes not started by the command.

FEATURE

Sensitive actions and worktree reviews tightened to prevent unauthorized external changes

Even after a tool is approved, a permission check error still requires re-evaluation. If a check errors after a PreToolUse hook returns allow, it is treated as no response; if a check errors after PermissionRequest rewrites the input, it asks again or refuses when nobody can answer. Inline git in skills requires approval in bare-repository worktrees and similar locations, except in auto and bypass modes; /security-review also asks first. rewind no longer changes permission modes. On Linux with CLAUDE_CODE_SUBPROCESS_ENV_SCRUB set, read-only git no longer wrongly needs approval or gets refused by claude -p. On self-hosted runners with --trust-workspace false and VS Code untrusted folders, repository settings cannot disable hooks or toggle plugins. macOS refuses Space with Control or Option and more system shortcuts that require your grant.

FEATURE

MCP tool connection experience overhauled for better credential renewal and compatibility

When connecting to MCP (a protocol that connects AI to external tools), legacy settings now use the new core. claude plugin and claude mcp list no longer sign you out of a Console profile during token renewal. MCP_SDK_GENERATION=v1 now runs v2 with an earlier handshake and relaxed sign-in checks. claude mcp add --help switches to a local example and stops wrapping lines awkwardly. claude --bg --safe-mode no longer asks about servers it never starts. Sign-in pages in /mcp and /plugins now preselect Reconnect. Stopped MCP calls and shell commands both show that no result was recorded. SDK and claude -p callers can recover tools after removing and re-adding a server. A null entry in a tools list no longer ends headless (no-display) sessions.

BUGFIX

Background session accounts strictly isolated to prevent cross-identity sending

When continuing tasks in the background, sign-in identities no longer switch silently. If a named Anthropic profile is missing, changed, or overridden, or if an API key, auth token (sign-in credential), or workload identity from the launching shell switches to another sign-in, it stops and reports; setup tokens are excluded. Sessions open during an update must be reopened; older services that cannot keep the identity ask for a restart. Background sign-in clears previous logins and credentials across the computer, and a refused sign-in can leave no login. Restarts no longer jump between profiles and stored logins, and signed-out flags are cleared after signing in. When the gateway expires, running /login in another terminal lets the next message continue. The claude -p expired-login warning states that claude auth logout also deletes MCP logins and plugin secrets. Background /logout signs out across the computer, deletes that data, and ends the session. MCP is a protocol that connects AI to external tools.

BUGFIX

Enterprise gateway and proxy connection fixes clarify certificate updates and network errors

When enterprise sign-in fails, prompts now point out what to check. When a claude.ai login expires and a saved Console key is used instead, it no longer falsely reports a low balance. Certificate (proof verifying a server's identity) name-constraint errors fail immediately and tell you what to fix instead of retrying fruitlessly. When three or more sessions need a fresh sign-in at once, awsAuthRefresh and gcpAuthRefresh no longer run twice for the same request. A custom X-Api-Key no longer mislabels the billing organization as the ant auth login organization; Bedrock model refusals prompt you to enable the model. claude doctor and /status no longer falsely claim an unreadable linked managed settings file is still read. /login and claude setup-token explain rejected, unreachable, or timed-out requests along with what to check. claude.ai chats and Cowork tasks check plugin files for secrets before sending, asking first if a key may be present. TLS certificate errors behind HTTPS proxies are also fixed.

BUGFIX

Session resume and worktree jump fixes protect conversation history

When resuming work, history should not be lost. A launching program can set CLAUDE_CODE_RESUME_HINT_COMMAND so the exit hint shows its own resume command. After changing directories, temporary files are still cleaned up when cleanupPeriodDays expires. Discarding a reply on NFS or FUSE file systems no longer loses part of the saved history. claude --teleport no longer opens an empty session when history is not found, and claude -p --teleport reports an error if resuming fails. Interrupting a file transfer with a new message now states the right reason. CLAUDE_CODE_RESUME_INTERRUPTED_TURN no longer reruns turns stopped by a hook (an event-triggered program) returning continue: false. Remote lists now include files added with git add -N before the first commit. CLAUDE_CODE_TRANSCRIPT_LOCAL_GC no longer drops messages during concurrent rewrites while trimming.

BUGFIX

Local Session Messaging Raised to 100,000, Strengthening Agent Coordination

When multiple sessions on the same machine send messages to each other, the quota without a manual prompt increases from about 20 to 100,000 messages, including in the Desktop Code tab. Rapid messages no longer leave a session stuck as busy; claude agents status and input notifications are fixed. Esc now takes two presses to clear a prompt, and ctrl+y restores it. In claude attach and claude agents, you must press d within 800 ms after Ctrl+B to move to the background. A background service started without DISABLE_ERROR_REPORTING also inherits the value from the session's startup shell. claude rm and the agents view now say a session is "removed from the list" instead of deleting the conversation, and claude --resume still finds it. Split-pane agents verify their team lead and refuse requests once the lead ends; plan approvals must be re-sent after /clear or /resume. Workflow prompts marked by an app as not typed are no longer treated as your request.

FEATURE

Options Menu for Low Usage Credits and Fable Weekly Reset Times

When a model requires paid credits, you can choose how to continue first. When usage credits (separately billed resources) are turned off or used up, a menu offers stop, switch to usage credits, or upgrade. Fable's weekly limit adds a reset time and options menu, and -p, SDK, IDE, and cloud sessions also explain how to continue. Past the weekly limit, quick side requests on smaller models no longer cause credit notices to repeat or go missing. A refused wait request now reopens the menu, and failing to load your current spend limit no longer offers a lower limit. For setup tokens (credentials used for configuration) and CLAUDE_CODE_OAUTH_TOKEN, /usage keeps the session and weekly bars and explains why the rest are missing; the percentage beside a subagent is fixed, and hours only count periods with requests. Desktop sessions on third-party providers support CLAUDE_CODE_AUTO_MODE_MODEL in managed settings, taking effect once Desktop includes this version. Workflows in the desktop app's Code tab pause at a limit and continue after it resets.

FEATURE

Assumed Context for Unknown Models Raised to 1M, Higher Retry Delay Cap

When connecting a custom model, an estimated capacity is not the same as its actual capacity. The assumed context window (conversation capacity handled in a single pass) for unknown models changes from 200K to 1M; use /autocompact to compact earlier, or set CLAUDE_CODE_DISABLE_1M_CONTEXT=1 to stay at 200K. Sessions on third-party models with smaller capacities must set this beforehand, as filling up may fail every turn until /clear. claude -p warns on stderr when switching to another model; it no longer prints deniedModels and availableModels notes on every run. /model restores the highlight on the newest model. The maximum for CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS increases from 64000 to 300000 ms.

BUGFIX

Terminal Layout and Keybinding Fixes Improve Rendering and Screen Readers

In the terminal, pressing a key chord no longer sends its last key to the dialog input field when the action is unavailable; misspelled modifiers no longer bind the bare key. Accented characters no longer shift, leave stale copies, or disappear when wrapping, and long prompts no longer push the status line off screen. /btw no longer includes earlier replies; agent names are no longer hidden by labels. Screen reader mode is no longer cut off when the clock moves forward, nor does it drop dictated text, pasted text, or emoji. When no browser can open, /upgrade and Ctrl-clicked links display the address. Typing ø or Greek letters on Danish, Norwegian, Faroese, and Greek keyboards no longer triggers a false Option-key hint. /stickers now says the sticker pack is all claimed instead of opening a web page. First-run setup in Terminal.app explains Use Option as Meta key, which Option inputs stop working, and how to undo it before you agree. subagentStatusLine is removed; old files still load, and subagent rows use the default look.

BUGFIX

Large File Edits and Memory Protections Fixed, Resolving Device Hangs

Fixed out-of-memory errors on certain /proc files and hangs on devices and named pipes when reading special files. Non-streamed requests no longer fail outright on rejected images or thinking block errors. Long tool results with --no-session-persistence are removed on exit or interrupt. Out-of-memory errors when saving settings no longer block startup or sign-out cleanup. Docs documents can open in your browser from a terminal; startup re-reads managed settings that are being rewritten. Fixed /memory paths and previews opening the wrong artifact. Pro and Max accounts are no longer offered feedback drafts that their organization would refuse. The worktree creation tip now includes .claude settings. Windows path resolution failures no longer falsely report that a directory was deleted. Linux no longer looks up /home directly on autofs; set CLAUDE_CODE_AUTOMOUNT_ROOTS when the automount root is deeper than one level below /. /skill and @file typed between two files no longer take effect.

BUGFIX

WebFetch Table Alignment Fixed and Nested Page Memory Improved

When asking Claude to fetch web tables, blank cells no longer shift later values out of alignment. WebFetch (the tool that retrieves web page content) preserves empty cells and rechecks organization policy and CLAUDE_CODE_DISABLE_WEB_FETCH on every call. Chrome tools now display their names in the fullscreen transcript and subagent progress; interactive --chrome sessions explain when organization policy disables them. When no admin setting can enable the feature, it no longer tells you to contact your admin; the connection prompt now tells you to restart with claude --chrome. Speed and memory use are improved on deeply nested pages. Chrome and desktop browser tools refuse some escaped or JSON-text inputs and tell Claude how to rewrite them.

A ledger clerk used to skip blank spaces on a statement, shifting every later amount into the wrong column; now those blanks stay in place so readers do not have to guess which column each figure belongs to.
FEATURE

Subagent Progress Heartbeats, Early Memory Release, and Telemetry Resilience

When checking subagent transcripts, one bad entry no longer drags down the whole set. A single invalid OTEL_RESOURCE_ATTRIBUTES entry still keeps the rest of the attributes, and /status names the excluded one. The Remote Control, agent view, Workflows, and Artifact off switches in SDK managedSettings take effect again. OTEL_LOG_ASSISTANT_RESPONSES=0 no longer records background agent replies. When an official plugin skill launches a custom agent, agent.name is recorded as custom; named MCP exports follow the current connector directory. MCP is the protocol that lets AI connect to external tools. When a subagent compacts, relevant hooks (event-triggered programs) receive agent_id and agent_type. After safeguards stop a forked skill or workflow agent, Claude can retry with a narrower prompt or tell you instead of taking over the work itself. Transcripts of finished agents are also freed sooner.

BUGFIX

Cloud Session Restart Resilience Keeps Schedules and Approvals Intact

After a cloud task restarts, recent replies should not disappear. Stopping the machine right after history is rewritten no longer makes transcripts unreadable; restarts in long conversations no longer drop answers or unanswered messages. /clear, /resume, and /branch no longer interrupt scheduled tasks from an ended session. Plan approvals arriving after a restart in cloud, self-hosted runner, and SDK sessions no longer falsely report not being in plan mode. Naming an attached image's file no longer falsely reports it missing; receiving files on resume no longer triggers an unexpected model call; container shutdowns partway through no longer drop middle text, and first-try Cowork skill uploads are fixed. When a self-hosted on-demand runner's work order is superseded, the exit code reverts to 1; 2.1.321 and 2.1.322 had changed it to 0. Self-hosted sessions waiting on a connector approval or in-tool sign-in pause at the idle or lifetime limit; late replies resume from a fresh clone (copied repository). In cloud scheduled tasks, a PostToolUse hook from your own settings can no longer replace the plan in ExitPlanMode's result.

FEATURE

[Remote Control] Network Reconnects and 30-Day Identity Retention

When checking work on your phone, disconnection states should be clear. Switching Wi-Fi or reconnecting a VPN no longer leaves sessions disconnected for over a minute; usage credit prompts also appear on your phone, and terminal-only prompts are no longer marked as running. Restarting in the same folder after more than 4 hours no longer changes the computer's identity, which is kept for up to 30 days. When the disk stops responding, sessions left running after shutdown, finished jobs holding slots, and startup failures stalling the host are all fixed. With DISABLE_TELEMETRY or DO_NOT_TRACK set, your phone still shows permission details; running background subagents no longer falsely report as idle. In verbose or debug mode, a tool command that is a number, boolean, or object no longer causes the host to exit or stop reading output. When the computer disconnects before Claude starts, the list shows an error or idle status; disconnects no longer falsely report that the environment was deleted. When the computer running a session is signed out of Claude Code, the error screen offers a Try again button.

FEATURE

[VSCode] Live Command Output in Editor and Untrusted Folder Prompts

When editing files in VS Code, progress is directly visible. Live output from running Bash or PowerShell commands appears under the command card. Untrusted folders prompt on first launch; declining leaves project settings and MCP (a protocol that connects AI to external tools) servers unused. When usage credits are off, clicking buy no longer counts as agreeing to pay for Fable; a process restart before a new chat's first prompt no longer falsely reports that history could not be loaded. Old replies that failed to parse no longer linger, and queued messages after compaction are no longer missed. Reloading no longer repeatedly asks you to relaunch the terminal; pasting a code shows "Signing in…" until sign-in finishes. Switching models clears the Fable limit notice, and usage credits are no longer mentioned when turned off or used up. Multi-line edits on files with CRLF (line-ending format) open the diff tab; switching sessions stops dictation recording. Proxy certificate errors include instructions; when the sandbox is on, opening a session from the web no longer switches branches automatically and explains why.

FEATURE

[Claude Code on the web] Stronger auto-reconnect on the web, clearer permission and schedule status

When web tasks get stuck, the reason is explained clearly. Upload failures list the reason, and when a repository lacks permission, sign-in has expired, or single sign-on hides organizations, you can reconnect GitHub. Reopening a paused self-hosted session no longer gets stuck on Starting or leaves behind Sending/Stop, and pending approval prompts no longer disappear. Failures to add network secrets list each host and any determinable reason, and the notice stays until you dismiss it manually. GitHub Enterprise pull request updates link back to your own server. Large logs download in full. New sessions from iOS with a repository get their own branch. Disconnected sessions reconnect automatically, and Try again is no longer sent as a message. Even after five minutes with no output, the Stop button remains. Scheduled tasks missing a required sandbox send a failure notification. Removing a repository no longer moves its trigger, and Save waits until you pick a new repository. Git clone and fetch (copying and pulling updates) taking over ten minutes no longer cut off at the very end. Self-hosted environments can select No repository, and deleting a session warns if related scheduled tasks will pause.

FEATURE

[Claude Tag] Slack integration added to Enterprise compliance search, refining channel permission controls

When asking Claude for help in Slack, approval cards should not appear where Claude cannot post. In DMs with Claude, private or Slack Connect channels no longer show the Approve and post card, and Claude also receives the reason it cannot post. Slack conversations on Enterprise plans are now included in the Compliance API (an interface for organizations to audit records) in beta, letting you list sessions and read transcripts. Before an admin turns off Claude Tag for the organization, a confirmation step explains what stops. Scheduled tasks in channels across Enterprise Grid workspaces can call Slack normally. Channel settings can be retried if they fail to load. Network events on the Activity page can be filtered by Scope for download. Removing a connector removes the credentials (authentication proof) set on the connector while keeping the access bundles' own credentials. Channels appear right under their workspace. The Set for Claude Tag link opens the Slack page's Advanced tab to set the environment.

FEATURE

[Code Review] CSV export added to admin settings for detailed review cost tracking

When evaluating a team's budget consumption for code review tools, admins can now export the cost list directly as a table. Code Review admin settings now include a Download CSV button, letting you download a CSV report of review costs by month, week, or day for a single repository, a specific GitHub organization, or all projects.

Picture an office manager printing departmental cost-allocation sheets at month-end: instead of staring helplessly at a single lump-sum bill, you can now break down and verify expenses line by line by project and period.
