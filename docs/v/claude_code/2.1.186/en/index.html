Claude Code 2.1.186

Released: 2026-06-22

Release notes

FEATURE

Direct responses to bash commands and seamless MCP authentication

The terminal command experience just got a massive upgrade! When you use bash mode (starting with !), Claude will no longer just silently absorb the terminal output as context; it will now proactively respond and analyze the result right away (if you prefer the old silent behavior, you can toggle it off in your settings).

For external MCP tools that require authentication, you can now seamlessly log in or out directly from your shell using claude mcp login without being forced into an interactive menu. If you're working over an SSH connection, there's even a headless, no-browser fallback. And if you happen to typo a tool server's name, the CLI is now smart enough to suggest the closest match and cleanly truncate unwieldy lists. It's like having an assistant who used to just silently file away the receipts after running an errand, but now actively hands you a summary report; plus, you no longer have to walk all the way back to the lobby to fill out a security form to access the vault—you just swipe your card at the door, and the guard even recognizes you if you slightly misspell your own name.

BUGFIX

Background tasks and subagents behave predictably without visual glitches

Subagents and background tasks are now far more obedient and visually stable.

Previously, a background subagent hitting a permissions barrier would either quietly auto-deny itself or get stuck. Now, it neatly surfaces the permission prompt back to your main session, clearly identifying which assistant is asking, and pressing Esc will cleanly deny just that specific tool. We've also added a failsafe: if an agent fails a structured JSON schema validation 5 times in a row, it now automatically aborts instead of spiraling into an infinite loop. On the visual side, we've squashed a swarm of UI glitches: closing the agents view no longer leaves ghost text painted on your screen, background task previews won't flash ugly raw tool names before loading, switching into the agents view on light terminals won't blind you with a sudden dark-theme flash, and pressing Esc or Ctrl+C in the main view while agents run in the background is now perfectly responsive. It's like managing a team of interns: they used to panic silently or spin in circles when they hit a locked door, but now they text you for permission; and the broken security monitors tracking them have finally been fixed so you no longer see weird static flashes or lingering burn-in images.

FEATURE

Stronger network and sleep recovery, with enterprise platform updates

The system is much more resilient when your computer goes to sleep or network conditions shift.

Previously, if you closed your laptop while the AI was streaming an answer, you'd wake it up to an ugly 'Content block not found' or a JSON parsing error; the system can now flawlessly survive the hibernation cycle. For Enterprise and Team users, usage-based session costs are now correctly displayed again. If you use the Claude Platform on AWS, the /login menu now provides a 'refresh credentials' option so you can proactively renew your token before getting kicked out. We also fixed a bug with the Chrome extension where disabling the permissions gate broke tab-group isolation when running multiple terminal sessions. In agent teams, new teammates spawned into background window panes (like tmux) will now obediently inherit the leader's designated effort level (--effort). Finally, we've hard-capped API retries at 15 to prevent run-away loops from burning your wallet. It's like taking a nap while a massive document is printing: you used to wake up to a jammed machine and shredded paper, but now it pauses perfectly and finishes the job when you wake up. Plus, the boss's strict instructions on how thoroughly to do the job now successfully trickle all the way down to the newest interns without anyone slacking off.

FEATURE

Minor upgrades to UI, plugins, and skill management

We've sprinkled in a bunch of neat workflow and UI quality-of-life tweaks.

The Installed tab in the plugin manager (/plugin) now features a dedicated "Skills" section to keep your add-ons meticulously organized, and it will no longer falsely claim there are "more above" when you're already at the absolute top of the list. When diving into workflow details, you can now hit f to instantly filter by task status. The parser for your custom skill configurations (SKILL.md) is significantly more forgiving now: it gladly accepts kebab-case, snake_case, and camelCase syntax, and if your YAML format is slightly mangled, it will load the skill with empty metadata instead of silently crashing the whole thing. Additionally, the /review <pr> command now leverages the much more robust /code-review medium engine under the hood. On the cosmetic side: markdown strikethroughs now actually render as strikethroughs instead of showing literal ~~ tildes, text you selected with your mouse in the agent panel won't awkwardly remain highlighted after being deleted, and permission prompt option numbers are finally properly aligned even if the text overflows. It's like reorganizing your desk: all your specialized tools now have their own dedicated drawer, you can instantly filter your in-tray, and HR will successfully process your paperwork even if you accidentally capitalized a word wrong.
