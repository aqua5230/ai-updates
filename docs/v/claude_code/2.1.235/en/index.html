Claude Code 2.1.235

Released: 2026-08-18

Release notes

FEATURE

Optional real-time spellcheck underlines typos as you type

You can now turn on real-time spelling feedback while entering a terminal prompt.

When you enable the optional spellcheck setting, it uses your locally installed aspell, hunspell, or ispell tools to underline misspelled words as you type. To turn it on, add it to your ~/.claude/settings.json:

{"spellcheck": true}

This catches misspellings and prompt typos before you send the message.

Like having a personal proofreader hovering over your shoulder to scribble a red squiggly line under any typo the moment you write it.
BUGFIX

Prompt cache survives language server disconnects and reconnects

When language servers disconnect or reconnect in the middle of a session, your prompt cache will no longer be wiped clean.

Previously, any brief hiccup or reconnection with a language server invalidated the entire prompt cache, forcing subsequent turns to re-process tokens and waste credits. The cache is now safely preserved across mid-session language server reconnections.

Like a kitchen prep station changing hands for a moment while the chopped ingredients stay neatly in place, rather than making the next cook wash and chop everything again.
BUGFIX

Multi-line prompt highlights align accurately, and slash commands stop showing raw HTML entities

Multi-line prompt input highlighting and slash command characters now render cleanly.

Previously, syntax highlights for slash commands, keywords, and @ mentions could appear shifted by one or more characters across multi-line inputs. Additionally, running a slash command while Claude was actively streaming a response showed raw HTML entities instead of real characters. Both visual bugs are now resolved.

Like a video editor's timeline: colored bands align with their clips, and annotations added during playback appear as normal text rather than code.
BUGFIX

Terminal Markdown lists align properly at depth 3+ with hanging indents

When you read deeply nested Markdown lists in the terminal UI, third-level and deeper items now align properly, and wrapped lines use a hanging indent.

Previously, lists nested at depth 3 or deeper suffered from misalignment, and list items that wrapped across multiple lines lacked clean indentation.

Like an outline notebook where third-level sub-bullets and long paragraphs wrap cleanly aligned with the text margin instead of drifting into a jagged, unreadable mess.
FEATURE

Permission prompts tighten safety, preventing accidental blanket grants on Shift+Tab

Permission prompts are now much safer and more accurate about what you grant.

Previously, pressing Shift+Tab inside the permission comment field accidentally approved the edit and granted session-wide edit permissions instead of just closing the comment box. In addition, permission dialog text and "don't ask again" options now strictly match the true scope of the grant, and the "don't ask again" option is withheld whenever the full contents cannot be displayed.

Like pressing Back in a recipe app to close only its notes field; when the full recipe is not shown, it also withholds an "always follow this without asking" option.
BUGFIX

Notebook approval dialogs explain why unreadable cell contents could not be shown

Notebook cell delete and replace approval dialogs now state why content is missing when a read fails.

Previously, if Claude could not read a notebook file or an individual cell, the approval dialog silently omitted the existing content, making it look as though you were deleting an empty cell. The dialog now explicitly explains why the existing content could not be read so you can make an informed decision before approving the change.

Like a hospital test display that explains why a result cannot be shown rather than leaving the field blank and making it look as though no result exists.
FEATURE

Rapid dialog navigation selects your actual destination on Enter

Rapidly navigating dialogs with arrow keys and Enter now picks the correct option.

Previously, if you tapped an arrow key and immediately pressed Enter in quick succession, the dialog sometimes lagged behind and selected the previously highlighted choice instead of the one you just moved to. Dialog keyboard handling is now properly synchronized to catch fast keystrokes.

Like pressing buttons quickly on a vending machine and receiving the drink you actually stopped on, rather than the slot that was lit up a split second earlier.
BUGFIX

Agent tool lists available subagents when an omitted type lacks a default

When you omit subagent_type while calling the Agent tool in a session without a general-purpose default, you now get a clear error listing the agents available to you.

Previously, in sessions where the standard general-purpose agent was not supported, omitting the subagent_type parameter falsely advertised that a default was present.

Like walking up to a specialized service desk and receiving a clear list of today's available technicians on duty instead of being told a general handyman is available when none exists.
FEATURE

SendMessage rejects oversized cross-session payloads up front instead of dropping them

SendMessage now explicitly rejects oversized messages before delivery rather than dropping them into the void.

Previously, when sending data across different sessions, messages exceeding the cross-session payload limit were silently discarded without any warning or error, leaving developers wondering where the message went. The system now validates size constraints up front and immediately returns a refusal error so you can trim or chunk the content.

Like an email client warning that an attachment is too large before you press Send, rather than appearing to send it and then silently losing it.
PERF

Background cloud sessions optimize CPU and memory by halting full stream re-renders

Running cloud sessions like /ultrareview or /autofix-pr in the background now uses memory and CPU more efficiently.

Previously, whenever a background cloud session updated, its entire event stream was re-scanned and re-rendered from scratch. That no longer happens on every update.

Like a warehouse clerk jotting down incoming deliveries by simply appending a new line to the clipboard, rather than re-reading and redrawing the entire historical ledger on every single tick.
PERF

Embedded grep handles pathological patterns safely and fixes context lines for -m N

The embedded grep tool in native macOS and Linux builds is now much safer and more accurate.

When encountering pathological search patterns, grep now fails fast instead of exhausting system memory. Furthermore, combining -m N (maximum match count) with -A (after context) or -C (surrounding context) flags now prints the exact required context lines without dropping or duplicating them.

Like a spreadsheet that stops an unworkable formula before it consumes all memory, while showing exactly the requested neighboring cells.
FEATURE

Context limit error guides users to /config when auto-compact is disabled

The context-limit error message now gives actionable advice when auto-compact is disabled.

Previously, when conversations ran out of context window space with auto-compact turned off, the error gave no hint as to why compacting didn't happen. The system now explicitly warns you that auto-compact is off and directs you to run /config to turn it back on.

Like a piece of luggage alerting you that its built-in vacuum compression valve is switched off before declaring that it cannot fit another shirt.
FEATURE

Vim mode preserves NORMAL mode and cursor position across transcripts and panels

Vim mode now reliably preserves NORMAL mode and your exact cursor position across UI toggles.

Previously, pressing ctrl+o to toggle the detailed conversation transcript or closing an open panel would reset your Vim mode state and lose your cursor placement. The editor now remembers your active NORMAL mode state and cursor coordinates throughout these view transitions.

Like looking up an appendix note or closing a sidebar on an e-reader while your reading cursor and bookmark stay locked precisely onto the sentence you were reading.
BUGFIX

Expanded task list (ctrl+t) stays open when resuming sessions with unfinished tasks

The expanded task list (ctrl+t) no longer collapses on session restart if you still have active tasks.

Previously, whenever you resumed or relaunched a session with unfinished tasks, the task list UI always defaulted to a collapsed state. It now properly starts expanded so you immediately see the status of all pending items upon resumption.

Like returning to your desk to find the active task whiteboard still wide open, rather than having to manually unfold it every single time you walk into the room.
BUGFIX

Prompt footer reliably shows update restart notices after background installs

The prompt footer now reliably shows the "Update installed" restart banner after background auto-updates.

Previously, when an update finished installing quietly in the background, the footer notice failed to pop up, leaving you in the dark that a restart was needed to activate the new version. The notification now appears as expected so you know exactly when to restart and enjoy the latest release.

Like a retail store finishing a store refresh and lighting up a "Renovations Complete — Please Re-enter" sign at the register, instead of wrapping up in silence.
FEATURE

Remote Control claude rc applies enterprise gateway checks consistently at startup

Launching Remote Control via claude rc now performs the exact same enterprise-gateway availability check as interactive startup.

In corporate environments, standard interactive sessions verify gateway accessibility right at startup, but claude rc previously skipped this step, leading to inconsistent behavior. The check is now unified across both entry points to ensure reliable connectivity under enterprise policies.

Whether you press Start on the washing machine or start it remotely from your phone, it first checks that the water supply is available.
FEATURE

VS Code extension stops erratic tab jumping during window reloads and restores

VS Code users with multiple Claude panels open will no longer experience phantom focus jumping when reloading or restoring windows.

Previously, restoring a workspace containing several Claude tabs caused the cursor focus to spontaneously hop between tabs on its own. Focus is now cleanly preserved upon window reloads.

Like reopening a browser window with multiple tabs and having your focus stay locked onto the active tab you were actually reading, instead of flickering erratically between them.
