Claude Code 2.1.199

Released: 2026-07-02

Release notes

FEATURE

Network hiccups and rate limits no longer kill tasks; retries and partial progress kept

The system is now much more resilient against overloaded API servers or minor network blips.

Previously, if the server errored out mid-sentence, everything Claude had already streamed would vanish; now it saves that partial output with an "incomplete" notice. If you get temporarily blocked by a rate limit (a mechanism preventing too many rapid requests), the system will automatically retry with a delay instead of instantly failing your turn, and the retry cap has been significantly raised. If a subagent is cut off, it no longer lies about "success" but honestly reports the error or hands its partial work back to the parent agent. For hard connection errors like SSL certificate issues, it won't pointlessly burn through retries but will fail immediately and tell you exactly how to fix it. It's like a long-distance phone call: a burst of static used to drop the call and erase everything you just said; now it remembers what it heard and automatically redials for you.

BUGFIX

Background agents and connections debugged: No more infinite loops or offline errors

Background tasks are now vastly more robust.

Previously on Linux, if the system shut down uncleanly, corrupted leftover records would cause the background program to commit suicide every 50 seconds, taking all running tasks down with it. On Macs, background agents frequently failed to start over an SSH connection, and if you explicitly told a task to stop, the system would sometimes stubbornly auto-restart it right back up. These bizarre behaviors are now fixed. If your computer is starved for memory, tasks won't spit out a cryptic error anymore; they'll explicitly tell you to free up resources. Also, running Claude in different folders will no longer cause the Chrome extension to spam you with reconnect pages. It's like a company's timeclock system that used to trigger a building-wide blackout every minute if someone forgot to punch out yesterday; it's finally fixed, and everyone can work in peace.

FEATURE

UI and operation foolproof: Stacked skills, no bloated transcripts

You can now load up to five slash skills at once, and opening empty sessions no longer bloats your transcript file.

You can now stack multiple slash skills in one breath (like /skill-a /skill-b do XYZ) and it will properly load up to the first five, instead of stubbornly ignoring everything after the first. In the agent list, idle subagents now neatly collapse into a summary row instead of vanishing completely out of sight. If you accidentally type a model-switching command while looking at a subagent, it now warns you that this only applies to the main lead agent, rather than silently making unwanted changes. If your configuration file gets corrupted and needs resetting, the system now safely backs it up first instead of mercilessly wiping your old settings. It's like ordering at a cafe: the barista used to only make the first drink if you ordered two at once, but now remembers your whole order, and the register won't print a long blank receipt if you didn't end up buying anything.
