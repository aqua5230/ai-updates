AI 工具更新速報

最新版本：

  • Claude Code 2.1.306

    摘要（2.1.304）：自動模式新增引導設定，工作階段記錄不再重複堆積分類脈絡 若想放手讓 Claude 自動執行任務，卻擔心它摸不清專案架構，現在有新工具能先幫它建立背景認知。

  • Codex 0.163.0

    摘要：/config 支援跨類別搜尋設定，即時修改並提示重啟 當你想調整 Codex 的各項參數，卻記不清具體設定名稱藏在哪個分類時，現在直接輸入 /config 就能解決。

  • Antigravity 1.4.3

    摘要：/diff 與產物檢視器新增搜尋功能，支援跨檔案逐筆跳轉 比對大批修改內容時，要在冗長的變更清單中精準定位某個函式或變數往往相當費時。

  • Grok Build 1.0.62

    摘要：無頭模式等待背景工作接續對話，逾時中斷改回傳錯誤 當你寫腳本透過指令列自動處理任務時，最怕背景工作還沒做完程式就提早離場。

  • Muse Code 1.4.11

    摘要（1.4.10）：/blender 指令登場，參考圖直接重建為 3D 可編輯場景 當你手邊有一張概念設計圖或參考照片，想快速建立立體模型時，往往需要在建模程式裡從零搭建物件與燈光。

  • Usage 0.34.3

    摘要（0.33.10）：Windows 版恢復 hook 安裝與更新 若你在 Windows 電腦上使用時，曾碰過切換設定後毫無動靜，現在各項開關都能正常生效了。

  • GitHub CLI 2.102.0

    摘要：修復四處安全漏洞，防範非預期檔案寫入與驗證被繞過 下載、安裝技能或驗證產物時不再受惡意名稱所害，建議盡快升到 v2.102.0。
